## §2 臂定义与关键声明

### §2.0 🔴 Magnus 纬度混杂（明示声明；C 裁定第二项）

**机制** `[推断]`：T = base_t(φ) − lapse_c·H 过 Magnus 非线性（q = Magnus(T)）后，**即便 H 被完全打乱**，base_t(φ) 仍把纬度暗通道压印进 W（→u）场。⇒ 旧批 arm2「置换零模型」**不是纯净几何零模型**，其显著 C-b 不能独证「地形起作用」。

**读数**（`the-world-data/bare_world/lat_mode_diag_s2_20261013.json`，数据仓 commit `c02b4fb`；`[实测]`@`27a2698` s2/seed42，仅构造 + 全场读数、无 tick）：

| base_t 档 | 臂（同 role） | corr_cell(u,\|lat\|) | corr_cell(temp,\|lat\|) | temp 域 (°C) | u 域 |
|---|---|---|---|---|---|
| classic（旧档） | arm2 / arm4 | **−0.936 / −0.931** | −0.972 / −0.972 | [−36.2,+29.2] / [−31.7,+28.4] | [0.025,4.70] / [0.035,4.70] |
| uniform（空档） | arm5 / arm8 | **−0.015 / −0.010** | +0.001 / +0.039 | [−0.73,+19.3] / 同 | [0.72,2.98] / 同 |
| insolation（自然档） | arm6 / arm7 | **−0.922 / −0.918** | −0.978 / −0.978 | [−43.6,+27.6] / [−38.4,+26.8] | [0.016,5.24] / [0.022,5.22] |

要点：① 空档**杀掉**纬度压印（−0.94→−0.015）；② 自然档保留（且更陡的）纬度通道——**它是「自然界一致」而非「去混杂」**，其 Δz 测的是「自然气候梯度**之上**的地形增量」；③ 空档 u 全域收窄 [读数]，审 Δz 时的机械因素见 §4。

## §3 读数口径（观察侧；引擎零标签）

### §3.1 斑块与邻接
沿旧文 §2.1 + 修订留痕后口径：斑块 = 容量场 `cap>0` 连通域（4 邻 + 经度 wrap、极行豁免）；邻接口径 = **跨域格对 Chebyshev ≤ d**（**d=2 主报 / d=3 并列**）；面积权 = `world.cell_area`。

### §3.2 特征与聚类（特征沿旧文 §2.2 五维不变）
f1 log 面积 / f2 面积权 |lat| / f3 mean(cap) / f4 mean(u)（u = W / `env_probe.w_mean`）/ f5 cap 的 CV；臂内 z-score（总体 std；std<1e-12 整维置 0 并记账）。

### §3.3 聚类主口径：**k=2 钉死**（C 裁定第一项）
KMeans 实现与超参同旧文（k-means++ / `rng=default_rng(0)` / n_init=10 / Lloyd ≤300 轮 / 取 inertia 最小）。**所有 C-b / ARI 主判据一律用 k=2 标签**；k∈3..6 与轮廓系数**仅附录**（描述性，随报不作判据、不选 k）。

### §3.4 判据（fixed-k=2）

1. **C-b（每臂）**：d=2 纯度 obs、置换 null（1000× 标签置换，`rng=default_rng(0)`）μ±σ、z=(obs−μ)/σ；臂内显著线 **z>3.0**（沿旧批线）。
2. **归因增量（主判据，每对 null→treatment）**：**Δz = z_t − z_n**（同 k=2 同批次；d=2 主判据 / d=3 复验）。**通过线 Δz ≥ 3.0** ⇒「本批在该档下检出地形增量」；Δz < 3.0 ⇒「本批在该档下未检出地形增量」（数值照报，不圈地）。线理由：与旧批 z>3 同一「3σ 超越」尺度口径。
   - **自洽锚（重读旧批 classic 对）**：旧批 fair-k=2 读数 z_d2 = 10.51(arm2) → 10.33(arm4)，**Δz = −0.18 < 3** ⇒ 本判据自洽地拒绝旧批「地形增量」读法——与 C 裁定「不可分」一致。旧批该两值为历史 `[读数]`（单列脚本复算），本批升级版脚本将复算校准（§5）。
   - **一致性核对**：Δz 与「配对 ARI」应同向（分区若几乎同构 ⇒ Δz 应小）；若出现 Δz≥3 且 ARI≈1 的矛盾 ⇒ 停读查因照报。
3. **辅读（随报，不进主判据）**：k=2 全臂 ARI 矩阵（主对 5-8 / 6-7）；corr_cell(u,\|lat\|) 与 corr_cell(temp,\|lat\|)（机制核查；预期锚 [读数] 见 §2.0）；**径流型簇差动**（k=2 两簇逐簇报：河格占比（river_mask=acc≥p98）/ 富集比 vs 全 patch 基线 / f5 / f3 / f4 / \|lat\|）——承接旧批最稳差动信号；供给记账（沿旧文 §2.5：Σcap、Σcap×area、vs 语境位移%）。
4. **次要读法（预注册登记，防事后）**：**u 残差口径**（C 裁定第三项第二支）——斑块级 OLS `f4 ~ a + b·f2` 取残差替换 f4（f2 保留），全臂统一重聚类 k=2 走同套 C-b；d=2 报 obs/z 与配对 Δz′。不进主判据，结果照报。

### §3.5 供给记账
沿旧文 §2.5：Σcapacity 与 Σ(capacity×area) 四臂对照（语境 = 本批 5 为位移基准），归一化走全局面积权均值；不设硬容差，供后续批立线。

### §4.2 判读树（按两对 Δz 预写读法；不预测数值）

| | P2（自然档 6→7）Δz≥3 | P2 Δz<3 |
|---|---|---|
