### 8.1 J-A（AR1）零模型——**窗轴置换**

| 要素 | 写死口径 |
|---|---|
| 置换对象 | **窗槽位（window slot）**：一个窗槽 = 该窗的 16 块 `(kills_w, occ_w)` 向量，**成对整体搬移**（带 occ，kills 与 occ 永不分离） |
| 作用粒度 | **run 级**：每 run 抽**一个**窗轴置换 π（40 窗上的置换），**同一 π 施加到全部 16 子块**（保块间窗对齐——只有共同重排才不引入假的空间错位） |
| 零样本数 | L=**200** 抽次；RNG=`default_rng(seed+7000)` 独立流，**不消费主 RNG**（`rd_*` 同规） |
| 统计量 | `ΔAR1 = AR1_obs − mean_L(AR1_null)`，run 级=块间均值（承 §二）；seed 级 Fisher z → 合并单侧 t 下界，判定链路 §二/§三 不变 |
| 破坏/保持 | 破坏=跨窗时间序；保持=每块自身计数分布 + 每窗内空间共现结构 + 总量经验分布 |

- **T5 必红项（简单元退化守卫）**：以下实现**必须**被简单元测出 Δ≡0 并判红——①"窗内 tick 置换"（窗计数对窗内 tick 序不变 ⇒ null≡obs）；②"同窗跨块值交换"（不触时间轴）。实现不红 ⇒ 管道有 bug，禁跑。
- **T6 注入守卫（阳性对照）**：注入测试合成 run，注入必须是**跨窗耦合**（如某块死亡率脉冲跨窗持续 / 块状态 carryover）⇒ `ΔAR1` 必须显著>0；反向守卫：仅**窗内 tick 聚簇**（无跨窗自相关）注入 ⇒ `ΔAR1` 不得显著>0。两向不过 ⇒ 管道无效，止步上板。

### 8.2 J-B①（块间死亡密度 CV）零模型——**同质风险抽样**（非置换）

镜 F3 成立：CV 是 16 块值的**对称函数** ⇒ 任何"块标签置换"零模型 null≡observed ⇒ Δ≡0 永不过。**原 §二"CV 的零模型=块标签置换"字样由本节替换**（属 PI 裁"非锁破"范围内的实现化修正，同声明头）。

| 要素 | 写死口径 |
|---|---|
| 密度定义 | `d_w,b = kills_w,b / (occ_w,b × 250)`；`occ=0` 的块窗**不入 CV**（该窗按 16−n₀ 块计）；任一 run 内 occ=0 窗块占比 >20% ⇒ 该 run 该判据 fail-loud（S4′ 同族） |
| 零模型 | **同质风险 Poisson 抽样**：`λ̂ = Σ_{w,b} kills / Σ_{w,b} (occ×250)`（run 级池化）；每窗每块 `kills*~Poisson(λ̂ × occ_w,b × 250)`（**带 occ**：逐块曝光进入 λ）；按窗算 CV* 再跨窗均值得 CV*_null |
| 作用粒度 | run 级；L=**1000** 抽次；RNG=`default_rng(seed+7100)` 独立流 |
| 统计量 | `ΔCV = CV_obs − mean_L(CV*_null)`；seed 级 z 合并、单侧下界>0 ⇒ J-B① 过（§二/§三 不变） |
| 破坏/保持 | 破坏=块间**风险差异**（超出曝光差异的部分）；保持=逐块曝光结构 + 期望总死亡数 |

- **T5 必红项**：CV 的任何**置换式**实现（块标签/窗标签置换）⇒ Δ≡0 必红。
- **T6 注入**：合成 run 注入**块间风险异质**（部分块 λ 乘子>1，逐窗持续）⇒ ΔCV 必须显著>0。

### 8.3 J-B②（跨窗块序 Spearman）零模型——**逐窗独立块标签置换**

| 要素 | 写死口径 |
|---|---|
| 观测统计量 | 40 窗各得 16 块密度序（§8.2 密度定义同）；`ρ = mean over 全部窗对 (w<w′) 的 Spearman(序_w, 序_w′)`（跨窗结构稳定性；窗对 = C(40,2)=780 对均值） |
| 置换对象 | **块标签**，(kills, occ) **成对随标签搬移**（带 occ） |
| 作用粒度 | **逐窗独立**：每零抽次、每窗**各自独立**抽一个 16 块标签置换（窗间、抽次间均独立）；L=**200**；RNG=`default_rng(seed+7200)` 独立流 |
| 统计量 | `Δρ_S = ρ_obs − mean_L(ρ_null)`；seed 级 z 合并、单侧下界>0 ⇒ J-B② 过（判定链路不变） |
| 破坏/保持 | 破坏=块身份跨窗一致性；保持=每窗值的多重集（含极值/拓扑贡献的边际结构——这正是 F11 敏感性项要单独剥的东西） |

- **T5 必红项**："全窗共用**同一个** π"实现（只重命名块，不破坏跨窗一致性）⇒ Δ≡0 必红。
- **T6 注入**：合成 run 注入**跨窗持续块间排序**（块危险度乘子固定绑定块号）⇒ Δρ_S 必须显著>0；仅逐窗随机块乘子（无持久排序）⇒ 不得显著>0。
