## 一、待测量的精确形式（**跑前锁定**）

### 1.1 主指标（判定门用）

| 项 | 定义 |
|---|---|
| **统计量** | **Spearman 秩相关 ρ**（`scipy` 不必；现有 `_rankdata` + Pearson-on-ranks 实现即可） |
| **被解释变量（y）** | **剩余终身繁殖数** = `_rs_children[id] − _rs_cc0[id]` |
| **解释变量（x）** | **观测时的 g15**（`_rs_g15[id]`，个体初值 `uniform(0,1)`） |
| **观测单元** | 每个 `_id` 在**首次**落入非饱和窗时记一行（现实现：`_rs_observed`） |
| **样本** | **非饱和窗**（`P < 0.9 × max_count`）= 主口径；**含死亡个体**（`_id` 键控，不随死亡压缩） |
| **辅助（同报，不用于门）** | OLS `slope_g15`（控 `age`、`energy`）——**必须标注"辅助列禁单独引用于门判定"**（R90-a） |

### 1.2 🔴 口径纪律（三条，缺一不可）

1. **辅助列禁单独引用**（R90-a）：`slope_g15` 只作辅助。**理由（D-24 实证）**：`zero_s43` 的 OLS = **+15.19** 而 ρ = **−0.0099**（协变量方差塌缩 ⇒ 斜率爆炸）。
2. **按区制分层报**（R90-b）：按 `final_pred_frac` 分两层（**< 0.9 / ≥ 0.9**），**两层不得合并均值**（R38③）。分层结果**各自报 ρ + n**。
3. **`zero` 臂仪器自检**（R90-c）：见 §三。

## 二、判定规则（**G-A 用的就是这个**）

### 2.1 主判定：`oracle` vs `zero`

> **G-A 的 ⑤ 支路通过 ⟺ 同时满足 (i) 统计显著，(ii) 方向为正，(iii) 达到最小效应量。**

| 条件 | 阈值 | 说明 |
|---|---|---|
| **(i) 统计显著** | `oracle` 的 ρ **显著 > `zero` 的 ρ**（单侧，CI 不含 0） | 用 Fisher z 或 bootstrap CI（§四.2） |
| **(ii) 方向** | `median(ρ_oracle) − median(ρ_zero) > 0` | 与 G-A 现逻辑一致 |
| **(iii) 最小效应量** | 🔴 **`ρ_oracle ≥ 0.10`**（**提案 d**） | 见 §四.1 |

## 三、R90-c：`zero` 臂仪器自检断言（**天然正对照**）

**原理**：`zero` 臂 = 漂变零模型，**g15 被冻结在初值**（D-24 实测 `mean_g15 = 0.5000 / 0.4999 / 0.5002`）
⇒ **g15 与适合度的真实关联必须为 0** ⇒ 若实现有 bug（口径错、键控错、排序错），ρ 会显著偏离 0。

**断言（建议写进实现）**：

```
对 zero 臂每个 seed： |ρ| ≤ 4 / sqrt(n − 3)        # 约 4 个标准误
```

`[实测]` **D-24 的 zero 三臂全部通过该断言**：

| seed | ρ | n | `4/√(n−3)` | 通过 |
|---|---|---|---|---|
| 42 | −0.003597 | 185,627 | 0.009284 | ✅ |
| 43 | −0.009884 | 4,033 | 0.063010 | ✅ |
| 44 | +0.010437 | 4,968 | 0.056768 | ✅ |

⇒ `zero` 臂 ρ 均值 **−0.00101**、`max|ρ| = 0.0104` ⇒ **与"真关联 = 0"完全相容**。
⇒ **同时对照 OLS：`zero_s43` OLS = +15.19** —— **一个天然零对照同时给出 ρ≈0 与 OLS=+15.19，这就是 R85 最硬的证据。**

## 四、🔴 提案 d（内评新增，请裁定）：**"统计显著" ≠ "判据达标"**

### 4.1 问题：大 n 让"不重要的相关"也显著（我试算发现的）

`[实测]` 我用 **Fisher z** 直接对 D-24 的 `oracle` vs `zero` 做检验（该批已被 R84 定性为规格缺陷批，此处**只用来说明方法**）：

| 臂 | 合并 ρ（Fisher z 反变换） |
|---|---|
| oracle | **+0.0473** |
| zero | −0.0010 |
| 差异 | diff z = +0.0483，SE = 0.00856 ⇒ **z = +5.647，单侧 p ≈ 0.000** |

⇒ **"oracle ρ 显著 > zero"在 D-24 上已经成立（p≈0）**，**而这批的 G-A 明明不过**（⑥ 支路不过 + 回馈比 ≪ 保本）。

> ⇒ **教训**：**只报显著性，会让 ρ = 0.02–0.05 这种"可检出但不重要"的相关被当成阳性证据。**
> ⇒ 这与我在 21:10 帖提的「**判别力天花板**」（R78-4）是**同一族**问题——**指标必须同时给"能检出"与"够用"两把尺子。**

### 4.2 建议（两条）

**d-1. 最小效应量阈值**（写进判定）：

| `|ρ|` | 解读 | 可否作为阳性证据 |
|---|---|---|
| `< 0.05` | 可检出但**不重要** | ❌ **不得**（大 n 下几乎必然显著） |
| `0.05 – 0.10` | 弱证据 | 🟡 仅作辅助 |
| **`≥ 0.10`** | **达到 G-A 判定的最小效应量** | ✅ |

> 阈值依据：`|ρ| = 0.10` 对应 **g15 解释约 1% 的适合度方差**（`ρ² = 0.01`）——**已是"弱但真实"的下限**。**这是我建议的保守取值，请裁定者确认或改。**

**d-2. 公共 n 子采样**（写进实现）：

**问题**：`oracle` vs `zero` 两臂非饱和窗 n 差 3 个数量级（§〇）。
**做法**：每臂按 seed 取 `n_c = min(该臂各 seed 的 n)` 的子样本，重算 ρ（**固定子采样 RNG 种子**，保证可复现），再比较。
`[实测]` 按 D-24 计算的 `n_c`：`oracle` **5,470** ｜ `zero` **4,033** ｜ `main` 3,984 ｜ `control` 3,964 ｜ `sigoff` 4,073。

> ⚠️ **副作用（须一并预注册）**：子采样会**降低**两臂的 n ⇒ **功效下降**。故 **d-2 必须与 R91 的四点剂量测量/R44 功效预跑一起定**；若子采样后功效不足 ⇒ **加大 seed 数**（而不是放弃子采样）。
> ⚠️ **替代方案（若不采纳 d-2）**：改用**配对比较**（同 seed 跨臂配对，减掉 seed 效应）——但两臂 n 不等时配对仍不干净。**两条我倾向前者。**
