## 二、🔴 判据（天平 2026-10-03 锁定，R225）

### 主判据（三指标）

| # | 指标 | 精确定义 | H1 带（信号有信息） | H2 带（信号无信息） | 不定区间 |
|---|---|---|---|---|---|
| **①** | `pep_frac_read_moore` | **被擦除集**内"可直读（Moore 邻）"的比例（池化均值）；pep = 反事实 K16 中被 K=4 擦掉的格 | **≥ 0.80** | **≤ 0.50** | (0.50, 0.80) |
| **②** | `pep_d_med` | **被擦除集**内信号的中位距离（池化均值） | **≤ 2.0** | **≥ 3.0** | (2.0, 3.0) |
| **③** | `ΔR` | `pos_frac_read_moore − pep_frac_read_moore`（**差**，非比） | **≤ 0.05**（低差 ⇒ H1） | **≥ 0.25**（高差 ⇒ H2） | (0.05, 0.25) |

**单 seed 综合判**（T1 §3.1/3.2）：P1（pep 方向）与 P2（ΔR 方向）**同向**才可判；异向 ⇒ "判别不出"。

### 一致性锁（跨 seed）

| 条件 | 要求 | 理由 |
|---|---|---|
| **种子一致性** | **≥ 3/4 seed 同判**（同带） | 防单 seed 偶然性 |
| **池化离界余量** | 池化值离带界 **≥ 2×SD** | 防"刚好踩线"的弱信号 |

### H2 附加门（T1 §3.3-3）

| 条件 | 要求 | 理由 |
|---|---|---|
| **SNR ≥ 2** | `(0.862 − pep池化) / 种子间SD ≥ 2`；**仅用于判 H2** | 判"信号无信息"需高信噪比 |

**判 H2 但 SNR < 2 ⇒ 不定**（不判 H2）。

## 三、判读流程（已实现：`tools/tier1_judge.py`）

```
1. 读 4 seed CSV（the-world-data/p1c_erase/p1c_erase_s{207,208,209,210}_t3000.csv）
2. 逐 seed 池化（跨窗口平均）三指标；ΔR = pos_frac − pep_frac 现算
3. 逐 seed 判 H1/H2/不定（P1/P2 同向才可判；异向 ⇒ 判别不出）
4. 一致性检查（≥3/4 同带）
5. 池化离界检查（≥2×SD）
6. 若判 H2，检查 SNR = (0.862 − pep池化) / 种子间SD ≥ 2
7. 输出最终判定 + Markdown 判读稿
```

**运行**：
```bash
python tools/tier1_judge.py --data-dir the-world-data/p1c_erase --out docs/判读归档/Tier-1判读结果-20261004.md
```
