## 零、一句话

B19b 之后，B 线唯一还没回答的生态问题是：**把天气源从 A3 合成占位（`placeholder=true`）换成 J3 冻结的真天气核，生态读数相对「同配置 + 占位天气」基线会不会出现超出噪声带的增量**。
本批只回答这个**相对增量**：不评价天气本身（归 J3/AV），不下真实地球气候结论，不做长期稳定/承载力结论。

**先验（写在前，避免事后解释）**：B19 的五 seed 终局已差 2.2×（3,227–7,132），seed 异质性很大；
若真源效应小于 seed 噪声，**INCONCLUSIVE 是预期内的合法结论**，不得为凑结论加 seed、加 tick 或改带。

## 一、要回答 / 不回答

### 1.1 要回答

1. 配对增量：同 seed 下「真天气臂 − 占位天气臂」的生态读数差（主指标：终局存活 `final_alive`）；
2. 增量是否**超出偏差带**（超出 ⇒ `EFFECT`；带内 ⇒ `INCONCLUSIVE`）；
3. 方向与逐 seed 一致性（5 个 seed 的 Δ 符号是否同向）。

### 1.2 明确不回答

- 天气/气候好不好、真不真（J3 的事；本批只把真源当**输入**）；
- 真实地球、历史气候、未来预测；
- 承载力/环境容量/平衡态 K（B19b 已示 3 个收敛 seed 的 K 差 4.7×，本批不判 K）；
- 长期稳定（>2,000 tick）、多细胞（W4）、军备竞赛（B16/B17）、语言（L0–L4 阶梯）、资源双向反馈；
- 「耦合 vs 不耦合」的增量——两臂**都**耦合天气，本批只隔离**天气源**（见 §九.1）。

## 三、判据（J4 K0–K7，跑前写死）

### K0 基线复现（前置门，最便宜的真值检查）

A0 臂 5 seed 的 2,000 tick 读数必须**逐位**等于 B19（`results/biosphere/b19_uncapped.json`，sha256 `df0498c1…`，commit `37e6778`）：
`final_alive` = 3,227 / 3,311 / 7,132 / 2,607 / 5,706，且 `run_digest` 与资源三 sha 全等。
**不等 ⇒ 停批报 owner**；不得把差异归因于天气（A0 是同一天气核、同一代码路径）。

### K1 稳定性（逐 pass）

- 全程无 NaN/Inf（生物状态、资源容量/存量、atmo 出口 `t2m`/`precip`）；无异常退出；
- atmo 出口预注册带：`|t2m_c| ≤ 100`、`0 ≤ precip_mm_yr ≤ 1e5`（只作防发散护栏，**不是**物理判据）；
- 任一 pass 失败 ⇒ 该臂标 `stability_failed`，**不得**用其它 seed 的好读数遮盖。

### K2 确定性（逐 seed）

同 arm × seed 两遍：`run_digest` 逐位 + `amount/capacity/world_grid` 三 sha + `total_born`/`total_died` + `atmo.digest` 全等；
失败集合必须为 **∅**，否则整批只报"执行失败"，不得判读。

### K3 账本与同步（逐 pass）

- 生态：EAT 1:1 账本契约（`tests/test_bio_b18.py::test_eat_one_to_one`）+ 能量账本闭合（相对残差 < 1e-9）；
- 资源同步：`sync_max_abs_diff == 0.0`、`sync_hold_equal == True`、`sync_count == ticks//25`（=`80`；U3 口径已改为 `ticks//25`）；
- **大气侧不判守恒通过**：按附件 A 扣除/登记 `B-TOA` / `B-WATER` / `B-MASS`；水指标两列并报（含裁负口径 + 真闭合口径）。

### K4 耦合增量（主判据；唯一判 EFFECT / INCONCLUSIVE 的地方）

- **主指标**：`final_alive`（t=1,999）。
- **配对**：`Δ_s = A1_s − A0_s`（s = 42…46），因两臂同 seed 同配置，配对消除 seed 间巨大异质性。
- **偏差带**：`band = 1.4826 × MAD(A0 的 5 个 final_alive)`（MAD = 中位绝对偏差；1.4826 为 sd 等价归一）。**本定义 PROPOSED，冻结前由评审确认**；冻结后不得改。
- **判定**：
  - `|median(Δ)| ≥ band` ⇒ **EFFECT**：报方向 + 中位差 + 逐 seed 同号数（5/5 或 4/5 分档陈述）；
  - `|median(Δ)| < band` ⇒ **INCONCLUSIVE**（不是 PASS，也不是 FAIL）；
  - 生态门未过 ⇒ 两种都不判（见 K5）。
- **次要指标（纯描述，不判 PASS/FAIL、不进结论句）**：`peak_alive`、攻击死因占比、平均世代、陆地占用率、出生/死亡比。
  报告须独立成表并标注"描述性"。

### K5 生态前置门 R3/R6（目标 tick 口径）

- **≥3/5 seed 在 t=1,999 存活**，且每个存活 seed 全程 `N>0`（无首零）；
- 不满足 ⇒ **不判**（不是 FAIL），只报"生态门未过"；
- **50k tick 持续段在本批 scope 外**（T=2,000）⇒ 禁止写"R3/R6 全门已过"，只能写"目标 tick 部分满足"。
  若评审/owner 要求全门，须先立 50k tick 长跑预注册（另行成本评估）。

### K6 天气源真实性核验

- A1 臂 core：`synthetic is False`；记录 `interface_version`、core commit、adapter commit；
- A0 臂 core：`synthetic is True`；manifest/`probe` 中出现 `placeholder=True`；
- 任何一条不符 ⇒ 本批作废。

### K7 上限不绑定

全 pass `peak_alive < 100,000`（沿用 B19 J4）。

## 八、停手规则（硬）

1. **前置未满足**（J3 未 FROZEN / owner 未派工 / core 不是 `synthetic=False`）⇒ 不开跑。
2. 试点 >45 min 或投影 >8 h ⇒ 中止，**不缩协议**。

4. 稳定性失败（NaN/崩溃/发散）⇒ 停该臂、保日志、报 owner。
5. **连续两次 INCONCLUSIVE** ⇒ 停手报 owner；选项 = 提高耦合强度 / 延长积分 / 接受 INCONCLUSIVE 并限定表述；**不得改判据**（继承附件 A §四）。
6. 生态门未过 ⇒ 不判；不补 seed、不加 tick、不换 seed。
7. 跑后不改本件的判据、偏差带、T_max；要改须新预注册 + 新成本方案。

## 九、未做 / 风险（如实）

1. **只隔离天气源，不隔离"是否存在耦合"**：两臂都耦合天气；若评审要"无 atmo 臂"，需第三臂（+50% 成本），本草案默认不做、列为待裁项。
2. **2,000 tick 不给长期结论**：不判 K、不判平衡态；B19b 已示 3 个收敛 seed 的 K 差 4.7×，本批不碰 K 口径。
3. **真源本身带登记偏差**：`B-TOA +7.02 W/m²` 等；本批的 Δ 只能在"登记偏差下"表述，不得写"天气已验证"。
4. **噪声带粗糙**：跨 seed MAD（n=5）只是单批估计；INCONCLUSIVE 合法且预期可能发生。
5. **预期效应量未知**：若真源与占位源的差异（温度/降水场）很小，生态读数可能不变 ⇒ INCONCLUSIVE；这是**有效信息**，不得视为失败。
6. **接口风险归 A3**：adapter/真核的 bug 不在 B 写作用域；B 只做注入与判据接线。
7. **不做**：调参、换 seed、加 tick、多细胞（W4）、军备竞赛（B16/B17）、语言（L0–L4）、资源双向反馈、承载力结论。
8. **不重判 B18/B19/B19b**：它们的读数与 K 表述保持不变；B20 是新的两臂实验。
9. **合成/真源不可比的历史臂**：B16/B17 时代的无天气臂代码不同，**不得**拿来当第三臂（跨纪元不可比）。
10. **成本未含 adapter 的 IPC/序列化开销**：试点是唯一实测锚，超 8 h 即中止。
