## 一、🔴 判定形态（**R105 锁定，跑前不得改**）

### 1.1 规则原文

> **⑤ 支路通过 ⟺ `合并 ρ` 的种子级 95% 单侧 CI 下界 > 0**

### 1.2 精确算法（**实现层请照此，勿自由发挥**）

| 步 | 操作 |
|---|---|
| 1 | 每个 **seed** 算一个 ρ（`Spearman(g15, 剩余终身繁殖数)`，非饱和窗、含死亡个体、`_id` 键控） |
| 2 | 逐 seed 做 **Fisher z 变换**：`z_i = atanh(ρ_i)`（`n_i` = 该 seed 的个体数） |
| 3 | 簇级统计：`z̄ = mean(z_i)`，`s = sd(z_i)`（**ddof=1**），**单位 = seed**（R96） |
| 4 | **单侧** 95% 下界：`L = z̄ − t_{0.95, n−1} · s / √n`，**n = seed 数 = 6** |
| 5 | **判定：`L > 0` ⇒ 通过**（报告时反变换回 ρ 尺度：`ρ̂ = tanh(z̄)`，CI 亦反变换） |
| 6 | **辅助同报**（不参与判定）：`slope_g15`（OLS，**禁单独引用于门判定**，R90-a）、逐 seed 的 ρ 与 `n`、原始 + 共同 n 子采样两列（R95） |

**三条明确（v2 未写清，实现层易错）**：
1. **检验在 z 尺度做、报告在 ρ 尺度**（不是对 ρ 直接做 t）；
2. **单侧**（方向已由机制预设为"正"；R105 原词为"CI 下界 > 0"）；
3. **`n` = seed 数（6），不是个体数** —— 个体级 n（10³–10⁵）**禁止代入**（R96：伪重复）。

### 1.3 设计备择 μ（floor 的**新身份**）

| 项 | 值 |
|---|---|
| **设计备择 μ** | **ρ = 0.10**（= 原 R94 floor；Cohen 小效应下限，`[文献]` 网评 21:56） |
| 在 **z 尺度** | `z_μ = atanh(0.10) = 0.1003` |
| **身份变更** | 🔴 **不再是判定门槛**，只用于**功效设计**（R105 明确） |
| 判定是否引用 μ | ❌ **不引用** —— 判定只看 `L > 0` |

## 二、seed 数 = 6（依据 + 我的独立复算）

`[实测]` 我按 **R44 的输入**独立复算（μ = 0.10、σ = 最大方差臂 main 的跨 seed sd = **0.0769**）：

| n | R2-**z**（σ 已知，1.645） | R2-**t**（σ 未知，MC 临界值） | R44 报（t） |
|---|---|---|---|
| 3 | 0.731 | **0.445** | 0.448 |
| 4 | 0.833 | **0.637** | 0.634 |
| **6** | 0.940 | **0.863** ✅ | **0.858** |
| 8 | 0.980 | 0.950 | — |
| 12 | 0.998 | 0.995 | 0.995 |

⇒ **我的复算与 R44 的 t 列吻合到 ±0.005** ⇒ **R105 选 n=6 的依据成立**（n=4 仅 0.637 < 0.8；**σ 需由 seed 估计 ⇒ 必须用 t，z 列偏乐观**）。

**两条 σ 相关的诚实提示**：
1. **σ = 0.0769 来自 D-24 仅 3 seed** ⇒ 该 σ 自身的相对不确定度很大（3 点估 sd）⇒ **实际功效可能低于 0.863**；
2. σ 取的是**观测到的最大方差臂**（main）；**若 ⑤ 校准批的 oracle 臂方差更大**，功效会再降。
⇒ **建议：⑤ 校准批完成后，用该批实测 σ 复核一次功效**（若显著 > 0.0769 ⇒ 按 R44 原则加 seed，而不是硬跑）。
