## 七、零模型实现化定义（§八补件 @`a0feedb` 原文并入，一字不动）

### 7.1 J-A（AR1）= 窗轴置换
置换对象=**窗槽位**（该窗 16 块 `(kills, occ)` 向量成对整体搬移，kills/occ 永不分离）；作用粒度=**run 级**：每 run 抽**一个** π（窗轴上），**同一 π 施加全部 16 子块**（保块间窗对齐）；L=**200**，RNG=`default_rng(seed+7000)` 独立流不消费主 RNG；`ΔAR1 = AR1_obs − mean_L(AR1_null)`。T5 必红项：窗内 tick 置换/同窗跨块值交换 ⇒ Δ≡0 必红（实现不红=管道 bug 禁跑）；T6 注入守卫：跨窗耦合脉冲 ⇒ ΔAR1 显著>0，仅窗内聚簇 ⇒ 不得显著>0，两向不过 ⇒ 管道无效止步。

### 7.2 J-B①（CV）= 同质风险 Poisson 抽样（非置换；镜 F3+PI 裁"非锁破"替换原"块标签置换"字样）
`d_w,b = kills_w,b/(occ_w,b×250)`；occ=0 块窗不入 CV（该窗按 16−n₀ 计），单 run occ=0 窗块占比 >20% ⇒ 该判据 fail-loud；`λ̂ = Σkills/Σ(occ×250)`（run 级池化），逐窗逐块 `kills*~Poisson(λ̂×occ×250)`（**带 occ**）；按窗 CV* 跨窗均值得 null；run 级 L=**1000**，`seed+7100`；`ΔCV = CV_obs − mean_L(CV*_null)`。T5：任何置换式实现必红；T6：块间 λ 乘子异质注入必显著>0。

### 7.3 J-B②（跨窗 Spearman）= 逐窗独立块标签置换
观测=全窗对（A 档 C(40,2)=780／B 档 C(240,2)=28680，**逐 run 全对均值**）Spearman ρ；置换对象=块标签，`(kills, occ)` 成对随迁；作用粒度=**逐窗独立**（每零抽次每窗各抽一个置换）；L=**200**，`seed+7200`；`Δρ_S = ρ_obs − mean_L(ρ_null)`。T5："全窗共用同一 π"实现必红；T6：跨窗持续块序注入必显著>0，逐窗随机乘子不得显著>0。**null 列不入侧车**（复算不依赖引擎，GAP-B 同族纪律）；L 值/常数偏移为实现细节不入判据语义。
