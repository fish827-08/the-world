## 二、窗与切点（家规沿用）

n=每 run 采样行数（2000t/sample100 ⇒ **n=20**）；**index 式**（PI 裁②）：
- 首段 F = 窗 1–5（k=int(0.25×20)=5）均值；
- **中段 M = 窗 8–13 均值**（中央 6 窗，index 式定位：floor(0.35n)..ceil(0.65n)−1 → 7..12 零基 ⇒ 第 8–13 窗一基；n 变则随比例缩放）；
- 末段 L = 窗 16–20 均值；
- **峰值 P = max(窗 1..20 的 g15_mean)**，峰值增益 **peak_gain = P − F**。
逐 run 先算、再逐 seed、再档内聚合（池化=逐 run 加权，N1 §3.1 家规）。
