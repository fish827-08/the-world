## 三、主判据（🔴 R225 跑前锁定，跑后不改；修订只走修订令）

### 3.1 指标与口径

| 项 | 锁定内容 |
|---|---|
| **指标** | `pos_frac_read_moore` —— **记忆保留格（d>0 子集）可被邻居 Moore 直读的比例**（P1-c 原口径，"世界记忆里的信息是不是私有"的直接测量） |
| **run 级聚合** | 逐对池化：该 run 全部采样点的 (个体×槽) 距离对合并计算（= summary.json `pooled.pos_frac_read_moore`，`[代码]` `p1c_erasure_probe.py:481-493` 加权池化实现） |
| **档级聚合** | 🔴 **逐对池化跨 seed**：`档值 = Σ(run池化值 × run距离对数) / Σ(run距离对数)`，run 数 = 生态门存活 run（§四）。**30 窗等权口径只作披露列，不判定**（依 R370·板帖 §二/§三：两口径差 ≈0.02，须跑前定一）——此即 PI 请 N1 显式锁定的"池化口径"条款 |
| **判定方向** | 沿阶梯 **D0→D1→D2→D3**（密度降序）取**首个 ≤0.50 的档** = 目标密度档 |

> 🔴 **语义澄清（依 R370 ②，防错抄复发）**：T1 锁定稿 §3.1 的 `pep_*` = **被擦除集**（K16 反事实中被 K=4 擦掉的格），`pos_*` = **保留集**。本批主判据取 **`pos_*`（记忆格）**——因判据语义是"记忆里的事邻居能不能直接读到"（私有信息），而非根因判别量。
> **阈值 0.50 的新用途声明**：T1 锁定稿中 ≤0.50 是 `pep_*` 的 H2 带界；本稿把**同一带值**应用于 `pos_*`（派工单字面"可直读率 <0.50 ⇒ 私有信息成立带"）。**这是新应用，不是改判据**——带界数值未动，判定对象按派工单语义选定。请镜 N4 重点审此条（§六-4 附灰区处置）。

### 3.2 档级判"落带"的三重锁（全过才算"该档 <0.50 成立"）

| # | 锁 | 规则 | 出处 |
|---|---|---|---|
| S1 | **种子一致** | 该档存活 run 中 **≥3/4**（且存活 run ≥3）逐 run 池化值 ≤0.50 | 沿用 T1 §3.3-1 形态 |
| S2 | **离界余量** | `0.50 − 档级池化值` ≥ 2×**种子间 SD**（存活 run 池化值的样本 SD，ddof=1） | 沿用 T1 §3.3-2 形态 |
| S3 | **同向确认** | 该档 `pep_frac_read_moore`（被擦除集，同口径池化）**亦 ≤0.80**（不落 H1 带）且 `pos_d_med ≥ 2.0` | 防"只降保留集、擦除动力学反向"的读法污染 |

- S1–S3 任一不满足 ⇒ 该档判 **"不定"**，继续看下一档；四档全不定 ⇒ 见 §3.4 判后动作的"未达带"分支。

- **灰区红线**：档值落 0.50–0.80 ⇒ 只报"灰区"，**禁止挑边**（R7.2 三段式）；`[实测]` Tier-1 基线 D0 档 pos ≈0.86–0.92（P1-c 锚 0.862 `[实测·数据仓 p1c/]`），预期对照档落灰区之上，若对照档本身 ≤0.50 ⇒ 异常，先查代码漂移再判读。

## 六、可判别性与证伪点（自查，供镜 N4）

1. **几何可达**：D3 档斑块间距 ≈46.5 格 `[推算]` ⇒ 个体一生踩点若跨 2 个斑块，`pos_d_med` 即远超 3.0 格界；活动半径随食物稀疏应扩张（MVT），A1 提供独立佐证 ⇒ **本阶梯理论上存在"落带空间"**，判据不是恒假。
2. **证伪点 ①（机制链断）**：若密度降到 D3 而 `pos_frac_read_moore` 仍 ≥0.80（H1 带）⇒ 甲案机制链被证伪（稀疏未导致远行/远行未入记忆）⇒ 上板，转 N3 捕食/庇护所路线评估。
3. **证伪点 ②（生态先崩）**：若 D2/D3 全崩溃而 D1 未落带 ⇒ "私有信息带在本装置族内不可达（生态门内）"⇒ 同样上板重议，**不得**以"缩短 ticks/砍 seed"救数据。
4. **口径风险披露**：主判据从 `pep_*`（T1 原文）换到 `pos_*`（派工单"记忆格"字面）——若镜认为应双指标同判（pos ≤0.50 ∧ pep ≤0.50），**请在 N4 审时改此条**，跑前改属合法修订（T1 §3.5"跑前可改、跑后不可"同规）；跑后本稿即冻结。　`[文档]` **N4 审结（镜，2026-10-04）**：本条维持原设计（`pos_*` 单指标主判 + S3 同向确认），审结唯一修订 = S4 NaN 条（已补 §3.2）。
5. **功效边界（诚实条款）**：4 seed 估种子间 SD 自身不确定度大（3 自由度）；S2 余量门在 σ 高时可能"真落带也判不定"——**判不定就是判不定**，不加 seed 救判定（加 seed 属新批，须重走起跑令）。
