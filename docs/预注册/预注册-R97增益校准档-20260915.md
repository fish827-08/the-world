## 〇、一句话

> 给 oracle 加一个**显式、可审计、绝不进科学判读**的"增益档"：把每发送者的**终身额度上限**由 `1×` 抬到 `m×`（`m ∈ [1.2,1.5]`），使"通信有**净**收益"这一情形在仪器里可达；再验证**仪器能否在此情形下检出正选择差**。
> **它校准的是「行为响应」通道（L0/⑤），不是「信息携带」（L1）。**

---

## 一、构造与该档的精确定义（含 C-2 例外）

### 1.1 唯一变更点（最小变更）

```python
# simulation/config.py
@dataclass
class OracleConfig:
    ...
    gain_multiplier: float = 1.0     # 1.0 = 现状（保本封顶）；仅 oracle 臂 + 显式传参可 ≠1

# simulation/sphere_engine.py（额度式唯一改动）
budget = gain_multiplier * EMISSION_COST * self._emit_count[safe] - self._oracle_gain[safe]
```

- **默认 `m = 1.0` ⇒ 与现状逐位兼容**（沿用 `reputation_enabled/reputation_weight` 先例：新参数必有默认值 + `from_dict` 旧存档回退）。
- ⇒ 结构性上限由 `1.0` 变为 `m`：`ratio = min(m, c × donation / SIGNAL_COST)`，`c` = 转化率（`applied/emissions`）。

### 1.2 🔴 C-2 例外与**独立注入登记**（R100 条件 1）

| 项 | 内容 |
|---|---|
| 事实 | 抬 `m` ⇒ 逐发送者可收回馈 > 其发射成本 ⇒ **超出成本的部分是「凭空生成」的能量** ⇒ **`Σenergy` 不再守恒（C-2 在本档不成立）** |
| 不主张禁止 | **造净收益本身就要求破坏 C-2**；本档把它变成**可审计、可报告、写明的例外** |
| **独立计数器** | 新增 **`system_energy_injected`** = Σ `max(0, 实付 − 该笔对应的成本额度部分)`（**只计超出成本的部分**），**独立于** `_oracle_transfers`（后者是真实 S→R 转移，两者**不得混记**） |
| 落地 | `engine.oracle_stats()` 增 `system_energy_injected` + `gain_multiplier` + `is_calibration_arm`；进 **summary** 与 **manifest** |
| 三处明示 | **design（本稿）/ 预注册（本稿）/ 板帖** 三处均须写明：「**C-2 在本档不成立，本档与守恒档不可比**」 |

> 口径澄清（防误读）：`_oracle_transfers` 记"转移了多少"，`system_energy_injected` 记"其中多少是新增"；**`ratio` 仍按 `_oracle_transfers / (emissions×SIGNAL_COST)` 定义不变**，其 >1 的部分即来自注入。

## 二、七条件逐条落笔（R100 §一）

### 条件 1 —— 净注入登记
见 **§1.2**：独立计数器 `system_energy_injected`（只计超成本部分）→ `oracle_stats()`/summary/manifest；**design/预注册/板帖三处明示 C-2 例外**。

### 条件 2 —— 收窄通过含义 + 反向声明（**最重**）
- **收窄**：G-A 通过 ⟹ "**当接收者因信号而获益时，仪器能检出正选择差**"。
  **不得**表述为"信号携带信息""出现语言""信息性通信"。
- **反向声明（写进本稿并随结论引用）**：**本档不能证伪 L1（信息量）**——本档只校准 L0/⑤ 通道。
- **不做**：本档**不**"顺手"加入"信息必要性"（那属另一构造级变更，须单独预注册）。
- **机理（须写入 docstring/板帖）**：发送者获回馈的唯一条件是"某接收者落到**有食物且被该发送者标记过的格子**"⇒ **不要求解码，也不要求信号是找到食物所必需** ⇒ 把 `g15` 调到 1.0 无差别广播者亦可持续领取增益 ⇒ **被选择的性质 = "广播能带来（别人的）收益"，非"信号携带信息"**。

### 条件 3 —— `eco_gate_pass` 本档不适用
- 明示：**本档不以"过生态门"为验收**；且 `eco_gate_pass` 含 `last >= 10000` 硬编码（**短程批恒 False**，见 **F-R17**）。
- 本档生态**只报**：`灭绝数` / `N 分布（按 pred_frac 分层）` / `pred_frac`，**并必报注入量**。
- 明写：「**种群差异不可归因于生态健康**」（净注入抬高总能量 ⇒ 种群上升是**机制性**的）。

### 条件 4 —— "最小充分"可执行判据 + 锁 m
> **校准成功 ⟺ 在 R44 所定 seed 数下：`m ∈ [1.2,1.5]` ∧ 各 seed 的 ⑤ ρ **方向一致为正** ∧ **合并 ρ ≥ 0.10**（R94 floor）。**
> **一旦满足即锁定 `m`，不得因"想更稳"上调**；**仅"未达 floor"时允许上调，且 ≤2 轮**。
> ⇒ 阳性由此获得**与注入强度无关**的含义：**注入刚好够检出**。

### 条件 5 —— 机器强制拒收（"会不会被读进去"）
- **判读脚本必须显式拒绝 `is_calibration_arm=True` 的行进入任何 G-A / E-BM 判定**，并**打印被排除行数**。
- 落地：`experiments/d24_six_gates.py` 入口增过滤（读 `switches.is_calibration_arm`）；**与实施同期**，并带单测（构造一行 `is_calibration_arm=True` ⇒ 必须被排除且计数 +1）。

### 条件 6 —— 各 seed 内配对 + 跨 seed 下分位（**非均值**）
- **批**：`m ∈ {1.0, 1.3, 1.5}` × seed（**各 seed 内配对**）⇒ 3 seed 时 **9 run**。
- **判据统计量**：**跨 seed 的 `ratio` 下分位 / 最小值**（**不得用均值**）。
- **并存报**：每 seed 的 `ratio` **与** 区制（`pred_frac` 分层）。

### 条件 7 —— 随机信号自检（边界证明）
- 用 **`signal_mode="random"`**（信号与个体状态无关 ⇒ **无信息**）**跑同一档**。
- 预期/判读：若 `ratio`、ρ 同样上升 ⇒ **实证"增益不依赖信号内容"**（即 §二条件 2 的机理），作为本档**边界证明**；这正是 V-1 **C-4（内容无关）**的可执行检验。

## 四、批设计与判据（实施后执行）

### 4.1 标定点（保留 `d=1.0`，`m=1.3` 为起点）
- `donation = 1.0`（固定）、`m ∈ {1.0, 1.3, 1.5}`、`arm=oracle`、`max_count=3240`、**tick 固定**（沿用 ④ 批的 8000 以可比；若功效不足按 R44 加长/加 seed）。
- 🔴 **下限风险（内评 §8.1，须写进本稿）**：`m` 只是**上界**；要真正达到 `m` 需 `c × d / SIGNAL_COST ≥ m`。
  `[实测]` `c` 逐 run ∈ **[0.047, 0.36]** ⇒ `d=1.0, m=1.3` 需 **`c ≥ 0.13`**；**低于 0.13 的 seed 上 `ratio` 由转化率决定（可能落在 0.47–0.94）⇒ 不在 [1.2,1.5]**。
  ⇒ 故判据用**跨 seed 下分位**（条件 6），**不得**按均值/期望宣称"约 1.3"。
- **seed 数**：**由 R44 功效预跑定**（ρ v2 已实测 3-seed 结构不足：CI 半宽 ≈0.147 > 0.10）⇒ **R44 功效预跑是本档/C 步的硬前置**。

### 4.2 判定

| 结果 | 含义与后续 |
|---|---|
| 各 seed ρ 方向一致为正 ∧ 合并 ρ ≥ 0.10 ∧ `ratio` 下分位 ∈ [1.2,1.5] | **校准成功 ⇒ 锁定 m** ⇒ 进入 C 重跑（科学臂 m=1.0）→ 重判 G-A |
| `ratio` 下分位 < 1.2 且 ρ 未达 floor | 允许**上调 m（≤1.5 内）≤2 轮**；每轮**预注册预期位移**（R101 防困死纪律） |
| ≤2 轮仍不达标 | **停下、上板、`fish` 裁**（不得直奔 1.5 求稳） |
