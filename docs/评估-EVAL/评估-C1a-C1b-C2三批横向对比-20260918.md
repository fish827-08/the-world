## 三、C2 机制归因：随机 vs 真信号（**配对符号检验，n=6**）

配对设计：**同配置、同 seed，唯一差异 = 信号内容**（`state` vs `random`）。方向取 `rand − state`。

| 指标 | Δ 中位 | 正 / 负 | 双侧 p | 判定 |
|---|---|---|---|---|
| 末态 N | **+0.5** | 3 / 3 | 1.0000 | 不可区分 |
| `pred_frac` | +0.064 | 3 / 3 | 1.0000 | 不可区分 |
| `rho` | +0.021 | 4 / 2 | 0.6875 | 不可区分 |
| `codebook_conv` | +0.009 | 3 / 3 | 1.0000 | 不可区分 |
| 探针B `resp_b_delta` | +0.003 | 4 / 2 | 0.6875 | 不可区分 |
| `argmax_flip_rate` | +0.030 | 4 / 2 | 0.6875 | 不可区分 |
| `ratio`（oracle 保本比） | **+0.143** | 4 / 2 | 0.6875 | 不可区分（rand **略高**） |

⇒ **7/7 指标全部不可区分**。逐 seed（Δratio）：s42 −0.061 / s43 −0.232 / s44 **+0.223** / s45 +0.063 / s46 **+0.330** / s47 **+0.349**。

**诚实边界**：n=6 的功效只能检出**很大**的效应（本例「全 6 seed 同向」才有 p=0.031）。所以正确表述是
**"不可区分"**，**不是**"证明内容无用"——「无效应」的结论需要更大 n 或更窄的观测区制（见 §五）。

|---|---|---|---|

跨批证据（r97cal 8k 24 run + 本批 60k）合起来才支撑 R108「校准达成」。

### 4.2 信号内容对 ratio 无贡献（C2 配对）

随机内容下 ratio 中位 **1.114**，真信号 **1.058** ⇒ **rand 不低反高**（4/6，p=0.688）。
⇒ **`ratio` 的 1.0–1.3 水平是"转帐 + 增益"的机械底**，与"信号是否携带信息"无关。

**对 R120 的两点数据支撑**：
1. ✅ **支持弃「60k 绝对带 [1.2,1.5]」**——即便内容全随机，ratio 也常落在 1.0–1.27（6/6 ≥ 1.0）。
2. 🔴 **补充建议**：**配对口径的 null 应以「随机臂」为准**，m1.0 基线只能剥离"增益档效应"，**剥离不了"机械转帐效应"**。
   （即：`oracle_m1.3 − m1.0` 测的是增益档；`state − random` 才测内容 ⇒ 两者是不同的量，别混用一个 x。）

## 五、🔴 结构性发现：**区制二分**（三批 30 run 无一例外）

按「饱和 tick 占比」（N ≥ 3240 的 tick 比例）分层：

| 层 | run 数 | 占 30 | 末态 N | `pred_frac` | 含义 |
|---|---|---|---|---|---|
| **饱和层**（**曾触顶**，占比中位 0.70） | **20** | 67% | **3240**（顶上限） | 0.152 – 0.870 | 繁殖撞 `max_count`；**"谁繁殖"由槽位序号抽签**（R42 实测） |
| **捕食层**（**从未触顶**，占比 = 0.00） | **10** | 33% | 363 – 3063 | **0.844 – 0.999**（中位 0.991） | 99% 死亡来自捕食；种群被压到承载之下 |

（20 + 10 = 30 ✓）

- **首次触顶 tick：3000–8000**（60k 的 5–13% 处）⇒ 大部分时长在饱和层度过。
- **10 个"从未触顶" run 的 `pred_frac` 全部 ≥ 0.844** ⇒ **非饱和 ≠ 健康**：非饱和样本**全部来自捕食崩塌**。
- **边界例**：`C2/rand_s47` 唯一"半程" run —— **触顶后后段跌出**（占比 0.283、`pred_frac` 0.870）。

> 🔴 **自我更正②（2026-09-18 19:29）**：本节初稿写「饱和 19 / 捕食 11」，**两数各差 1**。
> 错因：把「饱和占比 < 0.5」的**筛选输出**（11 行，含 `C2/rand_s47` 的 0.283）当成了「占比 = 0」层，且与「占比 ≥ 0.28」层**重复计数**。
> 已改为按**"是否曾触顶"**二分：**20 / 10**（和 = 30 ✓）。**核心结论不变**（区制二分、无中间区制）。同错已同步更正板帖。
- ⇒ 本构造下 **⑤（选择梯度）的非饱和窗样本 = 捕食崩塌样本**——这正是 V-7/R81 实测的"非饱和窗样本量差 20–46×"的**动力学原因**：
  主臂（饱和）的窗口是薄片，捕食臂的窗口才是主体。
- ⇒ **`rho` 在本构造内不可解读**：饱和层里选择压被抽签抹掉（教训 14），捕食层里"选择"由捕食而非资源竞争主导。
  **两个层都不是 C2/C4 想要的"资源竞争选择窗"**。这解释了为什么五个臂族的 `rho` 中位数全在 ±0.015 内——
  **可能真的没选择，也可能只是没有可观测选择的窗口**（当前数据**无法区分**）。

**边界声明**：以上为**描述性发现**，不是判读。它指向的是**构造/判据层面的缺口**（V-7 的延续），
而不是"语言涌现失败"。
