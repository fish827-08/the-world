## 二、双轨并行安排

```
主线（科学贡献：定界）             支线（mini-world：反事实沙盒）
─────────────────────────         ─────────────────────────────
P0 生态门（阻塞）                  M1 选型 ✅ 已裁定（A 强制表达 + 学习瓶颈维）
  ↓                                  ↓
P1 判据工具（零模型/CI/口径）        M3 代码成本/判据设计/污染检查/统计功效 ← 待做
  ↓                                  ↓
P2 验 C3（R2 声誉权重）              M5 实现规格 → 立项实现（1–2 周）
  ↓                                  ↓
P3 判 L0 ← ────────────── 支线结果可交叉印证主线诊断
  ↓
P4 补 C2 设计缺口
```

**交叉印证点（重要）**：
- **支线信号起来了** ⇒ 机制栈可用，问题在生态侧 ⇒ **主线方向得强支撑**
- **支线信号起不来** ⇒ 机制栈本身有缺口 ⇒ **应停止在主线继续投入生态修复，先补 C2**（`战略定位` §四）

⇒ 支线**有判决主线方向的权力**，不是"玩具项目"。

## 三、条件分支（决策树）

```
P0 生态门
├─ ✅ 过门
│   ├─ P2 验 C3
│   │   ├─ 有超额量（g15 升）→ 条件链继续 → P3 判 L0 → 有望触及 L1
│   │   └─ 无超额量          → 强阴性结论（"缺 payoff 通道"获实证）→ 转 P4 补设计缺口
│   └─ 同时做 mini-world → 交叉印证
└─ ❌ 不过门（修复后仍崩）
    ├─ 先查是否**又一处实现缺陷**（本项目的教训：先怀疑实现，再怀疑机制）
    └─ 若确认机制性 → 生态构型需改（世界尺度/资源/密度），此时才回到 R1 的生态重构选项
```

> ⚠️ **分支纪律**：不过门时**第一反应必须是"找实现缺陷"**，而不是"归因给机制"。
> 依据：本轮 `nb[:4]` 事故——一个编号错误被当作"机制必然"讨论了数小时，`[研究员]` 溯源才纠正。
