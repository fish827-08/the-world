### 3.2 🔴 预判 1：**G-A 会不过**（且是全部完成臂里最要紧的一条）

G-A 要求 `oracle > zero`（⑤ 与 ⑥ 双向都要 CI 不含 0 且为正）。实测：

| 比较 | oracle | zero | 方向 |
|---|---|---|---|
| ⑥`resp_triple` | **0.0223 / 0.0035** | **0.1210** | ❌ **oracle 只有 zero 的 1/5 ~ 1/35** |
| ⑤`slope_g15` | −0.0204 / −0.4417 | −0.5657 | ❌ oracle 更接近 0，**不是"更高"** |

⇒ **两个指标都反号。G-A 必不过。**
（且 oracle 的 ⑥ 也**低于主臂** 0.0333/0.0654 ⇒ 连"中间态"都算不上，是**偏弱的**那一侧。）

### 3.3 🔴 为什么不过：**机制量级差 2 个数量级**（我已复算）

| 量 | 值 |
|---|---|
| 发射成本 | **0.1 能量 / 次**（`SIGNAL_COST`） |
| 繁殖阈值 | **(0.25 + g2×0.65) × max_energy = (0.25~0.90) × 300 = **75 ~ 270 能量** |
| 单次转移 `donation` | **0.05 能量** ⇒ **占阈值下限的 0.067%** |
| **实测 `oracle_return_ratio`** | **0.0272 / 0.0624**（= 总回馈 ÷ 总发射成本） |
| ⇒ 平均回馈/次发射 | **0.0027 / 0.0062 能量** |
| ⇒ **净收益/次发射** | **−0.0973 / −0.0938 能量 ⇒ 仍为负** |
| **保本线** | **1.0** ⇒ **差 16 ~ 37 倍** |

> ⇒ **oracle 不但没能把信号基因从"净亏"变成"净赚"，连"保本"都差 16–37 倍。**
> ⇒ **所以 oracle 臂的 g15 没有正向响应，是"机制没在工作"，不是"信号无价值"。**
> ⇒ 脚本 `:232-233` 正好预警了这一情形：*"`oracle_return_ratio` ≪1 ⇒ 回馈偏弱，**G-A 不过时优先查此参数**"*。

**根因（`[推断]`，须 V-1 复核）**：V-1 的 C-9 把单次发射的**累计**回馈封顶在 `SIGNAL_COST`（0.1）——**"保本"语义**。但**实测每次发射的实际回馈只有 0.0027–0.0062** ⇒ 说明**绝大多数发射根本没有产生任何转移**（发射了，但接收者没落到该格 / 归因窗口过期 / 接收者没吃到食物 ⇒ `true_sig` 不成立）。
⇒ **瓶颈在"发射→成功通信"的转化率极低**，而不只是 `donation` 的数值。

### 3.4 🟠 预判 2：**G-D 的"可读"会掩盖方向矛盾**

主臂 ⑤ 非饱和窗斜率 = **+1.36 / +0.41 / −0.31** ⇒ **三 seed 里一个反号**。
G-D 只要求"非 None 且 ≥2 个"⇒ **会过**，但**方向不一致** ⇒ ⑥/⑤ 的**臂间结论会很脆**。

## 四、后续如何发展（三层：先修仪器 → 再过门 → 才谈科学）

### 4.1 第一层：修 G-A（**必须**，且要先做诊断再调参）

**不要把 `donation` 直接乘 37 倍**——那会让信号变成"净赚"，等于换了机制。按序做：

| 步 | 动作 | 目的 |
|---|------|------|
| **1** | **诊断"发射→成功通信"的转化率**：在 oracle 代码里**分开记** ①发射次数 ②归因成功次数（`_last_sender` 命中）③`true_sig` 成立次数 ④实际转移次数 | 现在只有聚合的 `return_ratio`，**不知道卡在哪一环**。`[推断]` 瓶颈在②③ |
| **2** | 若卡在**归因**（`_last_sender` 被覆盖/窗口过期）⇒ 调 `persistence` 或改归因规则（V-1 §六 第 3 点本就待裁） | 归因是实现问题，改它不改机制语义 |
| **3** | 若卡在**`true_sig` 少**（接收者没落到有食物的信号格）⇒ 这是**生态/行为问题**，不是 oracle 参数问题 | 说明"成功通信"本身稀有 ⇒ 需重新设计"成功"的定义 |
| **4** | 三者都排除后，**才**考虑把"保本封顶"从 `SIGNAL_COST` 上调（例如到 10–40 倍），并**明确登记为"补贴"而非"补偿"**（V-1 O-7 语义） | 只有在确认机制通了之后才加强度 |
