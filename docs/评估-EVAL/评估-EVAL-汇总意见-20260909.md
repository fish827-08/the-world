## 总评（6 模型共识）

项目是**一流水准的工程实现 + 未闭合的科学探索**：双路径逐位对拍、快照续跑、隐式选择压审计是同类项目前 5% 的纪律。但**头条结论链在科学上多数不成立**——元宝指出"把三个机械必然（热扩散收缩、食物富余、状态泄露编码）误读为三个演化涌现（文化趋同、高信任、信号保留）"，且评分卡 45% 权重是同一个方差量的三个函数（互相共线）。

## 一、数据级发现（元宝+豆包，已亲验部分）

### D1【实锤】`sig_density` 恒为 0 是脚本 bug —— 已在代码确认
- `run_long_experiment.py:64` 用 `e.signal_field` 取属性，**但引擎里正确属性名是 `e.signals`** → `hasattr` 恒 False → 恒 0
- 后果：大世界"信号在稀疏世界更有价值"（g15=0.69）的**观测支撑不存在**；g15 平稳未动而 g16 从 0.34 崩到 0.088（被选择形态对照）→ g15 更像中性漂变
- 修复：1 行（`e.signal_field` → `e.signals`），重跑大世界后结论才能成立

### D2【实锤】`cult_div` 计算口径冲突 —— 已在代码确认
- `run_long_experiment.py:66` 用 `interpret.std()`（全体池化），`run_segment.py`/`long_run_l4l5.py` 用 `.std(axis=0).mean()`（逐信号位）
- 后果："小世界 0.001 vs 大世界 0.116"的差异**可能部分是估计量差异而非现象**，须统一规范函数后重算

### D3【结构性】`cult_div` 是图热扩散方程的解，不是文化演化
- 文化学习 `interpret[i] += α·(mean(邻格成体)−interpret[i])` = 图拉普拉斯迭代 → 唯一不动点是全局常数向量 → **cult_div 必然单调趋近 0**，速率只由图连通性（密度）决定，与信号有无、选择有无无关
- 若中性对照（解释表不参与决策）复现 cult_div 曲线 → 该指标作废
- 同理 `trust` 是食物富余度代理变量（假信号判定门槛 0.3 < 语义编码 0.5 → 假信号按定义几乎不可能 → trust 单调爬向 1；小世界 0.92/大世界 0.99 = 食物够吃与否的差别）

### D4 评分卡失真：基线（未演化快照）就 56.94/100
- `generational_stability=1.0`（满分）、`interpretation_consistency=0.9972`（近似满分）、`signal_context_mi=0` 占 20% 权重且恒定 → 综合分无区分"有语言/无语言"能力
- `baseline_lang_metrics.json` 产物与代码阈值漂移（`_interpret_score` 下 0.5694 应判"涌现中"却写"无语言迹象"）
- 建议：废弃 0~100 综合分 → 改**相对零模型的超额量 + 效应量 + CI**（如 Δcult_div = 实验 − 中性对照）

### D5 核心理论缺口（元宝，比"缺指代对象"更根本）
信号是**指示符（index）不是符号（symbol）**：
- 无**任意性**（arbitrariness）：pattern = 物理状态的硬编码函数，能指-所指不可漂移 → 无同义/多义/文化协商
- 无**信息不对称**：感知半径（8 邻格）= 信号传播半径（1 格），且感知零噪声、决策 argmax → **信号携带的信息是接收者已有信息的严格劣化子集，信息论价值 ≤ 0** → "通信没有生态位"
- 无**组合性**：单格单 uint8，多发射者覆盖写 → 符号串数据结构不存在，语法原理上不可达
- 无**联合收益**（豆包）：信号只是移动打分副产品，无"通讯成功→发送/接收双方获益"支付，无直接选择

### D6【量纲 bug】移动决策实际由群居项主导（元宝）
- `soc·densities`（未归一化 bincount，量级 5~20+）压过感知/信号项（量级 ≤1）
- 后果：**Q2"密度效应"可能是量纲失衡的相变而非社会动力学**；g14 只乘在被淹没的第一项上
- 修复：`densities` 归一化或 `log1p`，新增 `movement.w_social` 进 config

### D7 世代时间锁死（元宝，数据）
- 大世界 46.2 万 tick = **仅 25 代**（世代 ≈18500 tick ≈ 7.7 世界日，顶到寿命上限）
- **语言涌现要的是代数不是 tick 数**；25 代在文化演化理论里 = 0。不是"时间不够"，是"参数把世代锁死"
- 修复方向：压缩世代时间（rotation_period 2400→300~600，或寿命基准缩 1/8~1/4），目标 100 万 tick → 500~2000 代

## 四、后续路线（6 模型综合，采纳版）

### D0 止血（1~2 天，先于一切新特性）
1. 修 `sig_density` bug（`e.signal_field` → `e.signals`），重跑大世界 → 结论才能成立
2. 统一 `cult_div` 为规范函数（`.std(axis=0).mean()`），回填大小世界数值
3. `densities` 归一化 + 新增 `movement.w_social`（一行，可能是 Q2 全部"密度效应"的替代解释）
4. 重跑 `baseline_lang_metrics.json`；废 0~100 综合分

### D1 建立零模型体系（3~5 天）——从"模拟"到"实验"的分水岭
- 三个开关进 config：`neutral_genes` / `signal_disabled` / `signal_mode: state|random|evolved`
- 小世界 30 万 tick × 5 seed × {主实验, 三对照} → 预期 cult_div/trust 曲线在对照中复现 → 证实/证伪 A1/A2
- `signal_context_mi` 补 1000 次置换检验

### D2 语言机制最小重构（1~2 周）——Q1 真正答案，只做三件
1. **任意性**：pattern 由个体可遗传码本（(16,16) 编码矩阵）决定，映射可漂移可协商
2. **信息不对称**：感知半径 8→4（曼哈顿邻域），信号传播 2~3 格（扩散卷积，近零成本）+ 感知噪声 `sigma_perceptual∈{0,0.05,0.2}` + 移动 softmax(tau) 替代 argmax
3. **Steels 式对齐交互**：同格相遇概率性解读表对齐（带噪声）——语言是协商出来的不是广播出来的
- **明确推迟 L8/L9/L10**：它们依赖"信号已有语义"，此处修好前是成本不是收益

### D3 时间刻度重构（与 D2 并行）
- 压缩世代时间：rotation_period 2400→300~600 或寿命基准缩 1/8~1/4 → 目标 100 万 tick 产出 500~2000 代
- `year_length/lifespan` 比值进 config 成为一等公民参数；季节等寿命刻度定后再上
- 判定标准：涌现季节性迁徙/囤积，而非"体验感"

### D4 性能（2~4 周）
- **厚核薄驱**：把 8~12 次 PyO3 调用融合为单边界 `step_tick`（Python 只留 init/观测/存档/预言机）—— 吃纯 Rust 七~八成收益，保对拍/快照/观测资产
- fusion 达标（N=12000 ≥400 tick/s）后再评估纯 Rust 主权化（Rust 持状态 + 零拷贝 numpy 视图快照）
- 多进程多 seed（每 seed 一进程绕 GIL）→ 吞吐线性
- 暂缓：slots 模式（覆盖删除破坏 RNG 消费序）、事件驱动（破坏对拍）

### D5 科学叙事与复现性
- 对外叙事改为"**构建语言涌现最小充分条件的测试平台**"
- 每个实验报告强制 Observed/Inferred/Assumed 三栏区分（元宝：这是"结论强于证据"的共同根源）
- manifest 扩展：commit hash + Rust build profile + sim_core 指纹 + 输入快照 hash
- 数据（13.7MB snapshot）移出 git（LFS/外部存储）；GitHub Actions CI（pytest + Rust build + 2 分钟冒烟同 seed 断言）
- 分支治理：l9-terrain-season 拆三（L8/L9/季节），特性先下沉再合入；language-signal 补测试

### 百万代结论
**撤出主线**。主实验形态 = **千代 × 十 seed × 有对照**（单个 200 万 tick 实验重构后 ~20 分钟，10 seed × 10 配置 ≈33 小时完全可行）。统计功效来自重复，不来自长度；"百万代"在当前架构是算力幻觉。
