## 三、产出概率漏斗（这是本次最该看的部分）

### 3.1 按 L 阶梯逐层

| 层 | 判定什么 | 累积概率 | 依据 |
|----|---------|---------|------|
| **L0** | g15 在稳态维持（有发送者获益时） | **~65%** | `[推断]` **2Ns 论证**：单次发射成本 0.1，而 oracle 单次回馈 ≤0.5、每次进食 ≈1.5 能量 ⇒ `s ≈ 0.05–0.3`，`N≈3240` ⇒ **`2Ns ≈ 300–2000 ≫ 1`** ⇒ 定向选择压倒漂变。**"发的多的人活得好"是机制的必然，不是偶然** |
| **L0′ 无补贴版** | **不加 oracle**，g15 自发维持 | **~15%** | `[实测]` R19 十臂 **7/10 定向下降**（0.5 → 0.025–0.320）；只有 3 个升、且只有 7–10 代。**没有发送者获益通道时，选择方向是"关闭信号"**——这是实测，不是猜 |
| **L1** | 信号携带信息（`codebook_conv` / MI 显著） | **~30%** | `[主观+推断]` 关键风险：**g15 上升只提高"发射频率"，不一定提高"语境区分度"**。当前 16 pattern 只由 4 bit 状态决定（`:701 state = e_bin*4 + f_bit*2 + n_bit`），**结构容量本来就低** |
| **L2** | 任意性（码本偏离恒等且社群收敛） | **~12–18%** | `[主观]` 机制已在（码本突变 `:1197` + Steels 对齐 `:998-1002`），但**没有选择压力去偏好"任意"而非"指示"**；任意性更像副产品而非被选择项 |
| **L3** | 组合性 | **~4–8%** | `[主观]` **这是我 15:45 已判"实质缺失"的两处设计缺口直接封死的**：**W-F3 MDL 紧凑性偏差缺失** ⇒ 系统没有"用更少模式表达更多"的压力；**W-F4 Steels 失败反馈缺失** ⇒ 没有"沟通失败→修正"的回路。**不补这两个，组合性在原理上就长不出来** |
| **L4** | 语义接地 | **<3%** | `[主观]` 需要前四层全部成立 |

### 3.2 一句话

> **"能发表的科学结论" ≈ 90%（几乎必得，因为阴性结果+这套对照本身就是结论）。**
> **"语言涌现"（放到 L2）≈ 12–18%；放到 L3 ≈ 4–8%。**
> **两者之间的落差不来自悲观，而来自两个具体的设计缺口（W-F3 / W-F4）——它们是可以补的，但补了要重新跑。**

### 3.3 最可能的失败模式分布（`[主观]`）

| 若卡住，卡在哪 | 概率 | 含义 |
|---------------|------|------|
| **L1 卡住：g15 升了，但 `codebook_conv`/MI 不显著** | **~45%** | 最可能的结局。信号变成"多但空"——高频发射的仪式化行为，不带语境信息。**这本身是有价值的结果**（"收益通道解决了存活，没解决信息"） |
| 全臂衰退（g15→0） | ~20% | 连 L0 都没到；说明成本结构仍占优 |
| L1 过、L2 不过（码本不收敛/退化） | ~20% | 有信息但约定不稳 |
| L1/L2 过、L3 不过 | ~12% | 停在"词汇"层 |
| L3 过 | **~4–8%** | 真正的组合性 |

**这不是唱衰，是给排期加缓冲的依据**：每批预留一轮返工。

> ✅ **但也应记下反面**：D-24 用 25 分钟抓出了会让标杆批彻底作废的 bug —— **R47「小规格验证先行」是今晚最大的方法论胜利**，它把一次 3.7 h + 整夜的风险换成了 25 分钟。
