## 二、核心结论（R105 据此锁定判据）

1. **最大方差臂**：⑤ρ = `main`（σ = 0.0769）；⑥tri = `zero`（σ = 0.0588）
   ⇒ **R44「方差臂特异」前提被实测确认**（臂间 σ 差 **7.4×**）。
2. **现稿判据「各 seed 方向一致为正 ∧ 合并 ρ ≥ 0.10」功效不可达 0.8**：
   - 「全一致为正」功效 = **p+ⁿ**（p+ = 0.903）⇒ **反功效**规则（n 越大越难过）；
   - 「合并 ρ ≥ floor」是**点估计门槛** ⇒ 真实效应恰等于 floor 时功效恒 ≈ **0.5**（与 n 无关）
     ⇒ **与 R88「判定点落中性边界」（教训 18）同型**。
   - 精确联合功效（蒙特卡洛）：**0.465 / 0.438 / 0.379 / 0.229**（n = 3/4/6/12）——随 n **递减**。
3. **唯一可达 0.8 的形态 = R2**「合并 ρ 的**种子级 CI 下界 > 0**」：
   - z 口径（σ 已知，**不现实**）：n = 4 → 0.831；
   - **t 口径（σ 未知 ⇒ 保守，应采用）**：n = 4 → 0.634（不足）、**n = 6 → 0.858 ✅**。
4. **个体层样本量跨度 136×**（3,836 – 522,425）⇒ Fisher-z SE 0.0014–0.0162（饱和臂样本最少 ⇒ SE 最大）
   ⇒ 跨 seed 比较须与 **R95 公共 n 子采样**联动（并报两列）。
