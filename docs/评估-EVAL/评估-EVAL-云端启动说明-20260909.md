## 一、今晚任务 1：世代压缩敏感性扫描（最高优先，纯实验不改引擎）

**目的（D3）**：大世界 46.2 万 tick 仅 25 代（世代 ≈18500 tick ≈ 7.7 世界日，顶满寿命）。语言涌现要的是**代数不是 tick 数**；压缩 `rotation_period` 2400→300~600，目标把 200k tick 内的世代数从 ~25 提到 500~2000，且生态不断裂。

**脚本行为确认**：`--rotation-period` 会自动派生寿命（`_lifespan = day×(1+g3×7)`），改 rp 即同步压缩寿命与世代；`--segment 50000` 每 5 万 tick 落一次快照（防断续跑）；每 2000 tick 追加一行到 `experiments/long_<tag>.csv`。

**批次**（小世界 60×120，patchy，200k tick，每档 2 seed 起步）：

```bash
# rp 2400 = 对照组（=当前行为）
python experiments/run_long_experiment.py --rows 60 --cols 120 --ticks 200000 --segment 50000 --tag gen_rp2400_s1 --seed 42
# 压缩档位
python experiments/run_long_experiment.py --rows 60 --cols 120 --ticks 200000 --segment 50000 --tag gen_rp1200_s1 --seed 42 --rotation-period 1200
python experiments/run_long_experiment.py --rows 60 --cols 120 --ticks 200000 --segment 50000 --tag gen_rp600_s1  --seed 42 --rotation-period 600
python experiments/run_long_experiment.py --rows 60 --cols 120 --ticks 200000 --segment 50000 --tag gen_rp300_s1  --seed 42 --rotation-period 300
```

若 rp300 生态崩（N 拉不满 / 大灭绝），补一档 `--rotation-period 450` 试中间值。判读完如趋势稳定，再各补一个 seed（_s2）消随机侥幸。

**判读标准（三点，写进报告）**：
1. **max_gen 净增**：200k tick 内从 ~25 代提到 500~2000 代（看 CSV 末行 max_gen）。
2. **生态稳定性**：N 能否在 50k tick 内拉满容量、老死比例不崩（换代加快不应触发大灭绝；若幼体维持费 ×1.6 在高代际下失衡，记录之）。
3. **基因方向**：g14/g15 曲线相对 rp2400 对照是否开始脱离漂变样（选择梯度显现的早期信号）。

**产出**：`results/gen_scan/` 汇总表（每档：max_gen / 世代间隔 / 终局 g14,g15,trust,cult_div,N）+ 每档 CSV 都在 experiments/。报告三栏 **Observed / Inferred / Assumed** 区分。分支 `feat/gen-scan` 提交。

## 二、任务 2：D1 零模型三开关（实现 + 四臂对照，任务 1 顺利后做）

> D1 是"从模拟升级为实验"的分水岭（元宝 M1 gate）。核心逻辑：**若 cult_div/trust 曲线在"基因不演化 / 不发信号 / 随机信号"对照中高度复现主实验，主实验叙事推倒重写**——这是最有价值的产出。

### Spec（SimConfig 三开关，进 config + fingerprint）

| 开关 | 类型/默认 | 语义 | 实现要点（保持 RNG 消费顺序不变） |
|---|---|---|---|
| `neutral_genes` | bool=False | 基因断线：所有个体基因固定 0.5，只影响行为不演化 | 采用**读取侧冻结**：在引擎读取基因的入口（移动决策得分、繁殖继承、信号发射概率）把基因值替换为 0.5 常量；写入侧照常，不碰 RNG 顺序 |
| `signal_disabled` | bool=False | 不发信号：发射概率恒 0（g15 读数保持但行为无信号） | 信号发射处短路（模式=0 或发射概率*=0），接收/解读照常 → 对照"信号有无" |
| `signal_mode` | str="state" | 信号编码模式：`state`（现状=状态哈希）/ `random`（独立 rng 随机模式）/ `evolved`（D2 码本，暂未接线） | `random` 用**独立 rng**（如 `np.random.default_rng(seed+offset)` 预生成模式序列），严禁消费主引擎 rng（破坏对拍） |

接线与测试要求：
- 三开关全部进 `SimConfig.fingerprint()`（A2 审计要求：新增键必须入指纹，否则不同配置产生相同指纹 = 复现塌方）。
- 双路径一致性：Python/Rust 双路径下三开关行为逐位一致（复用现有引擎级对拍框架）。
- 新增 pytest：每开关至少 2 例（生效性 + 与主实验 N/礼次序一致），保持全量 164+ passed。

### 四臂实验（小世界 300k tick × 3 seed）


**预期与结论口径**：主实验的 cult_div/trust 曲线在对照臂复现 → 当前"A1 文化趋同 / A2 高信任"叙事不成立，需在报告中明确标注并推倒重写叙事；`signal_context_mi` 若已实现，补 1000 次置换检验（p<0.05 才算 MI 显著）。分支 `feat/zero-model`。

## 三、后续主任务：D2 信息结构重构（科学杠杆最高，扫描与 D1 收尾后开）

分支 `feat/info-structure`，**只做四件事，别加别的**：

1. **学习瓶颈（最致命，DeepSeek C3）**：解读表不遗传；幼体从有限 (信号, 后果) 观察样本归纳映射——Kirby 迭代学习的枢纽，目前被"整表 EWMA 平滑继承"短路。
2. **任意性**：signal pattern = 个体可遗传码本[状态]（(16,16) 编码矩阵），能指-所指可漂移可协商。
3. **信息不对称**：感知半径 8→4 邻 + 感知噪声 `sigma_perceptual∈{0,0.05,0.2}` + 移动 softmax(tau) 替代 argmax。
4. **Steels 式对齐**：同格相遇概率性解读表对齐（带噪声）——语言是协商出来的不是广播出来的。

**硬门槛**（不满足不合并）：Python/Rust 双路径逐位对拍（新机制同样对拍，维持 164+ passed）；`validate_gene_wiring` 双写一致；**明确推迟 L8/L9/L10**（依赖"信号已有语义"，修好前是成本不是收益）。

**唯一验收判据（元宝 M2 gate）**：g15 在无手调补贴下从 0.5 上升。
