## 1. fish 的原始问题（三轮）

1. **主问**：设计了一个网格世界（有食物、生物、捕食者、信号基因），但**信号基因总是难以维持**——发送信号得不到收益（"食物在哪里"），接收者却获得净收益；发送需要能量，**找不到维持稳态的能量中间值**：耗能低 ⇒ 谁都能发 ⇒ 全世界噪音；耗能高 ⇒ 很快被淘汰。为此加入了 **Oracle**（发送者可分得接收者因信号找到食物而获得的能量的一部分），但这**实际不现实，只当作测量"发送者需要多少能量才能平衡"的仪器**。问题：**后续该从什么地方设置信号的能量？不能总用 Oracle。**（要求从**生物语言进化**与**数学可行性**两个角度给建议与问题所在）
2. **架构问**：网格世界（每生物占一格）、食物**斑点分布不均匀**，如何设置信号系统、以及生物的**感知信号 / 记忆 / 学习**架构。

## 2. DeepSeek 的答复（按轮整理）

### 第 1 轮：核心诊断 + 生物进化角度 + 数学可行性

**核心判断（开篇）**：

> 「你的核心矛盾**不是**"信号能量取多少"，而是：**发送者为什么要发？**」演化上，一个信号基因要稳定，必须让**发送者的包容适应度净增**；接收者受益不够，因为**自然选择不会为接收者的收益买单**。Oracle 相当于**外生补贴**，它能帮你测"影子价格"，但**不能作为机制**，因为它**破坏了能量守恒、局部因果和欺骗惩罚**，最后会**选择出"发信号骗补贴"的个体**。

#### 一、生物语言进化角度

**(1) 信号不是一开始就是"语言"，先有线索，再有信号**
蜜蜂舞蹈、长尾猴警报、鸡的食物呼叫都不是凭空出现。最初往往是：**发现食物者转向食物、停留、啄食 → 附近个体"偷听"这个线索 → 接收者受益后演化出对这些动作的敏感 → 发送者再演化出更明显的动作（仪式化）**。
⇒ 建议**先做线索阶段**：发送者**不额外耗能**，只是行为副产品；接收者偷听。等接收者响应稳定后，再让发送者演化出信号基因。这样低耗能不会立刻变噪音，**因为信号还绑定在真实行为上**。

**(2) 食物位置信号天生难稳定，因为发送者与接收者利益冲突**
食物可独占时，告诉别人等于制造竞争者。要稳定必须改变生态或关系：**亲缘选择**（`rB > c`，Hamilton 条件）／**互惠**／**声誉**（欺骗者被降信誉）／**群体选择**／**合作觅食**（斑块大、需防御或合作猎杀时发送者也受益）／**交配收益**。
⇒ 「如果食物小、可独占、无亲属、无重复互动，那么**任何正成本信号都难稳定**。**这不是能量参数问题，是博弈结构问题。**」

**(3) 不要把信号基因设成"总是发"，要设成条件策略**
低耗能导致人人发，是因为**表达条件太宽松**。真实信号基因通常：只在发现**大**食物时发／只在附近有**亲属/合作者**时发／只在自身**能量高于阈值**时发／只在**信誉高**时发／发送后**有冷却时间**／**信号强度与食物质量成正比**。
⇒ 这样即使单次成本低也不会全是噪音；接收者只对高信誉、高强度、特定上下文的信号响应。

**(4) 语言组合性必须晚于稳定指称**
组合性需要：已有稳定的信号-意义映射／双方都有净收益／接收者能解码序列／组合的**信息增益 > 额外的发送与解码成本**。
⇒ 「如果单信号都不稳定，组合性只会增加成本，不会自发出现。**先做"食物信号""捕食者信号"两个稳定指称，再做组合。**」

#### 二、数学可行性

设：食物信息价值 `V`（接收者因信号找到食物的净能量）／发送成本 `c`／发送者因接收者行动获得的直接+间接收益比例 `s`（含亲缘 `r`、互惠贴现 `w`、声誉、交配、群体收益）／接收者支付给发送者的能量 `p`。

- 发送者发信号条件：**`sV + p > c`**
- 接收者响应并支付条件：**`V − p > 0`**
- ⇒ 存在**交易区间 `c < p < V`**，**当且仅当 `V > c`**
- ⇒ 「如果 `V` 很小或 `c` 很大，信号不可能稳定。**如果 `s = 0` 且 `p = 0`，发送者净亏，任何 `c > 0` 最终淘汰。** Oracle 相当于**强制 `p > c`**，而且往往 `p` 与**信息质量脱钩**，所以会**奖励 spam**。」

**(1) 信号能量应由边际收益决定，不是拍一个固定值**
设信号强度 `S`、成本 `c(S)`、接收者正确解码概率 `q(S)`：
- 接收者收益 `B_R = q(S)·V − (1 − q(S))·L`
- 发送者收益 `B_S = s·B_R − c(S)`
- **最优信号强度满足边际条件 `s·dB_R/dS = dc/dS`**
- 例：`c(S) = aS²`、`q(S) = 1 − e^(−kS)` ⇒ 可解出一个**中间强度**：「低强度噪音大，高强度成本高，**中间值由边际收益决定，而不是全局常数**」

**(2) 用信誉替代 Oracle**：每个个体有信誉 `R`，接收者只以概率 `σ(R)` 响应；诚实后信誉升、欺骗后降。诚实条件涉及「未来响应收益 − 欺骗短期收益 + 未来损失」。⇒ **不需要中央分配，接收者的"不响应"就是惩罚。**

**(3) 用局部互惠市场替代 Oracle**：接收者因信号找到食物后**自愿**把一部分能量给发送者；**支付基因本身也要有收益**（支付者未来更可能收到信号，非支付者被发送者拒绝）；发送者可优先给高信誉、曾支付过的个体发信号 ⇒ 形成**局部信息市场**，价格 `p` 由供需与演化决定，只要 `c < p < V` 双方都有收益。

**(4) 亲缘是最简单的数学解**：同巢 `r = 0.5` 时，只要 **`0.5V > c`** 就应发信号。⇒ 可**先做亲缘群体**让食物信号在家族内稳定，再逐步引入互惠与声誉。

#### 三、Oracle 的问题所在（对方列 6 条）

1. **外生补贴破坏选择梯度**——发送者收益不来自自身行为，而来自全局分配，会演化出骗信号
2. **奖励频率而非信息质量**——只要发就可能分能量，选择偏向**多发**而非发真信息
3. **不满足能量守恒和局部性**——真实世界的能量转移必须来自接收者或亲属/群体，不能凭空出现
4. **测到的阈值不可迁移**——Oracle 测的是**影子价格**，告诉你需要多少补贴，但不能直接当真实机制
5. **单一能量参数无法同时解决可信度和成本**——低耗能噪音、高耗能淘汰，是因为缺少**状态依赖、频率依赖、空间结构和重复博弈**
6. **食物信号本质是竞争信息**——「不改变生态，只调能量，通常无解」

#### 四、建议的实现路线（7 步）

无信号基线（测食物发现率、能量预算、信息价值 `V`）→ **线索阶段** → **招募阶段**（只在**大**食物斑块发信号，发送者因群体防御/共享份额受益）→ **亲缘阶段**（`rV > c`）→ **互惠/声誉阶段**（接收者支付，发送者优先回报，欺骗降信誉）→ **指称稳定**（食物信号、捕食者信号分别稳定）→ **组合性**（两信号序列，解码收益 > 额外成本）

**信号能量设置原则**（原文）：`c` 初始可设食物价值的 **1%–5%**，但**关键不是这个数**；必须让发送者从 `sV` 或 `p` 中获超 `c` 的收益；**若 `s = 0`，不要指望任何 `c` 能稳定**；信号强度成本可设 `c(S) = aS²` 用边际条件调 `a`；接收者只响应超阈值的信号，发送者有冷却、**局部传播、距离衰减**。

> **一句话（原文）**：「Oracle 可以当**测量仪器**，但真实机制应把"接收者收益"通过**亲缘、互惠、声誉、市场或群体选择**部分回流给发送者。**信号能量不是找一个神奇中间值，而是让 `c < sV + p`，并让欺骗者受到未来惩罚。**」

### 第 3 轮：模态选择 —— 声音传播 vs 原地驻留标记

**结论（原文）**：「**不是二选一**。建议**混合模态**。」

| 维度 | 声音传播 | 原地驻留标记 |
|---|---|---|
| 时效 | 瞬时（几帧到几十帧） | 持久（几十到几百帧） |
| 空间 | 波前扩散、**可判断方向** | **固定点**，形成路径/梯度 |
| 来源 | **可带来源 ID，易做声誉惩罚** | **来源弱**，需签名/气味密码 |
| 成本 | **每次发射**，功率平方 `c ∝ S²` | **一次性** `c ∝ M₀²` + 维护/衰减 |
| 接收者 | 附近所有个体，易偷听 | 路过所有个体，易偷听 |
| 欺骗 | **可立即追溯、降信誉** | 难追溯，过时标记多 |
| 适合 | **警报、召唤、组合序列** | **食物位置、路径、领地** |
| 稳定条件 | 亲缘 / 互惠 / 声誉 / 群体选择 | 亲缘 / 回访 / 群体 / 互惠支付 |

> 「声音更像"广播"，标记更像"环境修改"。**两者都会产生公共物品问题**：发送者付成本，别人搭便车。**所以都必须有能量回流。**」

**数学条件**：
- **声音**：`c_s = a·S₀²`；感知半径 `R ~ √(S₀/θ)`；附近接收者数 `n`、每人收益 `V`、发送者共享比例 `s`、接收者支付 `p` ⇒ 发送者净收益 **`s·n·V + n·p − c_s > 0`**
- **驻留标记**：`c_m = b·M₀²`；衰减 `M_{t+1} = (1 − d)·M_t`；持续时间 `T ~ ln(M₀/θ)/d`；总读取次数 `n ~ ρπR²T` ⇒ 净收益 **`s·n·V + n·p − c_m − c_维护·T > 0`**
- ⇒ 「如果发送者发完就走，且无亲缘、无回访、无支付，`s ≈ 0`，**标记基因也会淘汰**」
- **能量设置原则**：声音 `c_s = a·S₀²`（进化调 `a`）；标记 `c_m = b·M₀² + d·M·T`（进化调 `b, d`）；**不找固定中间值，找边际条件 `s·dB/dS = dc/dS`**

**推荐实现：食物用标记，警报用声音**
- 食物标记：格上存 `food_mark[type] = {强度, 来源ID, 时间戳, 质量估计}`；发送条件 = **只在大食物斑块发 / 强度与食物量成正比 / 自身能量高于阈值 / 附近有亲属或合作者 / 有冷却**；衰减 `M *= 0.95`（每步蒸发）；接收者读邻域标记强度、**沿梯度移动**、按来源信誉决定是否响应。发送者收益来源四条：**亲缘 `rV > c` / 回访（自己以后回来吃）/ 互惠（回报标记或直接支付）/ 群体选择**
- 捕食者警报（声音）：声音包 `{类型, 来源ID, 强度, 时间, 位置}`；每步向邻居扩散 `S_next(x) = (1−decay)·S(x) + diffusion·Σ(邻居S − S(x))`；接收者超阈值才响应、按信誉决定逃跑或忽略、**方向由波前梯度或时间差判断**；发送者直接收益 = 自己逃跑 / 亲属逃生 / 群体混乱降低被捕食概率 / **声誉提升**

**组合性与语言**：声音/动态信号**更适合时间序列组合**（如 `FOOD + PREDATOR`）；驻留标记更像**空间语法**（路径、边界、食物梯度）。「**先稳定单信号，再做组合。单信号不稳，组合必崩。**」

**常见坑（6 条，原文）**：
1. **声音全局广播** ⇒ 全是噪音。**必须局部、衰减、有限感知**
2. **标记永不衰减** ⇒ 过时信息、标记噪音。必须蒸发、容量限制、覆盖
3. **来源不可识别** ⇒ **无法惩罚欺骗**。声音带 ID，标记带签名
4. **食物可独占还发信号** ⇒ 发送者亏。必须大斑块、亲缘、互惠或群体收益
5. **用 Oracle 替代真实回流** ⇒ 会选出骗补贴的 spam 个体
6. **支付基因无收益** ⇒ 支付者被淘汰。支付者必须未来更可能收到信号

**推荐路线**：`V0` 无信号（测食物发现率）→ `V1` 食物驻留标记 + 亲缘群体 + 只在大斑块发 → `V2` 加声音警报（捕食者）→ `V3` 加来源 ID 与信誉（欺骗降信誉）→ `V4` 加互惠支付 → `V5` 声音序列组合（`FOOD + PREDATOR`）

> **一句话（原文）**：「**食物位置用驻留标记，捕食者/召唤用声音**；标记成本按初始强度平方 + 衰减维护，声音成本按功率平方；**发送者收益靠亲缘、互惠、声誉、回访，而不是 Oracle**。**模态选择不解决激励问题，激励相容才决定信号基因能否稳定。**」
