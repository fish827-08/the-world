## 〇、一句话结论

**"基本的简单语言涌现"（信号在稳态维持 + 携带环境信息）大概率做得到，约 1–2 个月量级；
但"任意性符号系统"需要重新设计而非调参，"组合性/语义接地"不在本项目可预见范围内。**
**当前处于 L0 之前——连"信号在稳态维持住"都尚未达成。**

## 一、统一判据阶梯 L0–L4（本文件最重要的一节）

> 立此阶梯的目的：本项目曾把 g14=0.834 读作"语言涌现征兆"，后被六模型评审全面推翻。
> 教训是**没有预注册判据时，任何数字都能被讲成好消息**。今后对外表述一律锚定本阶梯。

| 级 | 名称 | 判据（可判定） | 当前状态 |
|----|------|--------------|---------|
| **L0** | 信号稳态 | 稳态 g15 > 0.5，且跨 ≥5 seed 可复现；种群过生态门 | ❌ 未达成（14/14 与 15 run 全部 peak-then-revert） |
| **L1** | 携带信息 | 信号↔环境/上下文 MI 显著高于漂变零模型基线 | ⚠️ MI 已有 0.1275→0.295 非零读数，但未在稳态信号上测到 |
| **L2** | 任意性 | 能指与所指解耦：同一意义在不同群体映射到不同信号；跨群码本分化且非热扩散产物 | ❌ 信号是自身状态编码（指示符），无任意性 |
| **L3** | 组合性 | 有限信号集表达复合意义，且可被新个体习得 | ❌ 16 模式实际只用 4 种，信号空间过小 |
| **L4** | 语义接地 | 符号稳定指向世界状态，可作伪（可撒谎） | ❌ 远超当前设计 |

**纪律**：任何"语言涌现"类表述必须写明对应到哪一级；未过判据的不得写成"涌现"。

## 三、三条结构性障碍（为什么难，不是为什么慢）

1. **信号是指示符不是符号** `[代码]`：信号内容 = 发送者自身状态编码，接收者本可直接感知该状态，
   信号的边际信息价值被自身可观测性抵消。16 模式实际只用 4 种。
2. **生态复杂性与语言涌现互相干扰** `[推断]`：在 60×120 球面 + 20 基因 + 捕食/植物化/能量收支的环境里，
   信号要与大量生存压力竞争有限的适应度收益 → g15 被淘汰（项目最初就发现："发射耗能 > 接收收益"）。
   当前 info-asym ON 崩溃到 N=2~400，是这一张力的极端表现。
3. **无统计推断机制** `[实测]` F-D3：全仓库零 CI / 零假设检验，
   导致"看到了信号上升"和"信号真的上升了"无法区分——这是 G3 不通过的直接原因。

## 三·补、12:07 重大更新：崩溃主因是**实现缺陷**，不是机制必然

`[代码]`+`[实测]` 依据：`[研究员]` 2026-09-12 11:50 帖（A4 第一轮攻坚）。

| 项 | 内容 |
|----|------|
| **主因 H1** | `nb[:4]` 取到 `{上左,上,上右,左}` = **半平面**，不是注释/AGENTS.md 所称的 Von Neumann 4 邻 `{上,下,左,右}`；净位移 `drow=-0.750 / dcol=-0.250` ⇒ 个体**只能向北/向西**移动 |
| **判别实验 E1** | 5 臂 × 3 seed × 1500 tick：A1 偏置+噪声 **24** ≪ A2 正交VN **74** ≤ A4 正交+argmax **124** ≈ A0 全 8 邻 **105** |
| **结论** | **"只有 4 个感知格"本身不致病（A4≈A0），致病的是"取错了那 4 个"**；noise/tau 为次因（−40%） |

**这改变了什么**：
1. **P0 生态承载力从"机制攻坚"降级为"修一个 bug"**——修复面被限定在"把 `nb[:4]` 换成真正的 VN 子集"一处（R12 裁定：不算削弱 C1）。
2. **再次印证 R8**：崩溃是失败模式，**不是**任何命题的证据。此前"信息不对称导致崩溃"的因果叙述含有严重混淆变量，须降级改写。
3. **L0 可达性上调**，量级从 1–2 月收缩到 2–4 周（修 bug + 过生态门 + R2 判读）。
4. **但 L2 之后的判断不变**：信号是"发送者自身状态编码"的指示符，这属于设计层面，与本次 bug 无关。

**附带需处置**（研究员 F1–F5，见 §五 裁定 R13–R15）：`radius=6` 静默 no-op；ON 臂从未跑过 Rust（"两路径一致"证据强度被高估）；R4 批实测 `arbitrary_codebook=false`（只开 3/4 机制）。

## 四、战略建议：双轨（`[推断]`，**待项目所有者拍板**）

### 主线（科学贡献，不动）
继续条件表 C1–C5 的证伪路线。产出是**定界性结论**："我们证明了在 X 条件下信号不可维持 / Y 条件为必要"。
负结果与定界在有生 ALife 领域是可发表的正当贡献，且与项目已建立的"能证伪自己"的声誉一致。

### 支线（验证目标，建议新增）—— 极简沙盒 `mini-world`
**目的**：回答一个被主线生态复杂性掩盖的问题——**在剥离生态竞争后，本引擎的机制栈到底能不能长出信号？**

#### 代码量实测评估（`[代码]` 2026-09-12 12:16，所有者读码核对）

| 需要的能力 | 现状 | 代码量 |
|-----------|------|--------|
| 缩小世界 | `--rows/--cols` **已是 CLI 参数**（默认 60/120） | **0 行** |
| 改初始个体数 | `PopulationConfig.initial_count=200` 存在，CLI 未暴露 | ~1 行 |
| 关闭捕食 | `PredationConfig` **无 enabled 字段**；设 `attack_gene_gate=1.0` 可使攻击永不触发 | 0 行（变通）/ ~10 行（正式开关） |
| 私有信息位 + 协作场景 | **引擎无此机制** | 这是真成本 |

**结论：缩小世界几乎零代码，真正成本在设计而非代码。**

#### ⚠️ 设计修订：mini-world 应为「反事实沙盒」，不是「缩小版生态」

原设想（缩小 + 资源充足 + 无捕食）有致命漏洞：**没有选择压力就没有选择**——
若信号仍需发送者付成本、收益全归接收者，g15 照旧被淘汰，mini 版将重演主线的失败。

修订：**强制 g15 常开（不许信号被淘汰），测下游能否长出结构**。
- 测 C2/C4（码本是否分化、信号是否携带信息），**绕开 C3** ⇒ 不污染主线 R2 的自变量
- 问题变为反事实：**"如果信号不被淘汰，它会不会自己长出结构和信息量？"**
- 会 ⇒ 机制栈下游可用，问题确定在 C3 一处；不会 ⇒ 机制栈本身有缺口，主线继续投生态修复无意义，应先补 C2（MDL 紧凑性偏差 / Steels 失败反馈）

价值：**把"能不能看到语言"拆成两个可分别证伪的问题**，而主线目前把两者混在一起。

#### E1 复跑结果（`[实测]`，`[本地开发]` 12:1x，尚未提交）

1500 tick × 3 seed，R4 真实口径（uniform / N0=200 / Python 路径）：

| 臂 | N_end 中位 |
|----|-----------|
| 信息不对称关闭（8 邻参照） | 105 |
| **当前 bug 状态（nb[:4] 偏置）** | **24** |
| **修正后（真正 Von Neumann 四邻）** | **120** |
| 对角线四邻 | 92 |
| `radius=6`（静默 no-op） | 80 |

⇒ 研究员 H1 假设**复现成立**；且 **`vn_r4(120) ≥ off_r8(105)`**
⇒ **信息不对称本身完全不致死，先前崩溃是 100% 的 bug**；「信息不对称导致崩溃」的因果叙述须作废。

**价值**：若 mini-world 里信号起来了 ⇒ 证明机制栈可用，问题在生态侧，主线方向得到强支撑；
若起不来 ⇒ 机制栈本身有缺口，应停止在主线上继续投入生态修复，先补 C2 设计缺口。
**这是一个低成本、高信息量的分岔判决实验。**
