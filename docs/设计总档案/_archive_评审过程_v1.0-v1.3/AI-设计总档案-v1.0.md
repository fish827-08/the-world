## §0 执行摘要

**项目**：球面有限世界（60×120=7200 格），让语言/符号系统从进化中涌现。
**目标**：不是找"最小充分条件"，而是**让语言真的涌现出来**（含任意性、组合性）。
**手段**：不用LLM、不用神经网络、不用"猜对发奖"式捷径；只用**死规则 + 生态选择压**。

**🔴 核心结论**：过去 20 天、12 个新纪元、约 200 机时未能产生语言进展，
**根因不是机制不够，而是信号系统在数学上不可能被选择保留**（详见 §1）。

**修复清单只有三行**：

| # | 改什么 | 位置 |
|---|---|---|
| 1 | 信号内容不再由"自身状态"自动计算 | `simulation/sphere_engine.py:109` |
| 2 | 允许写多格（产生长度维度） | `simulation/sphere_engine.py:3664` |
| 3 | `reputation_weight` 从 0 抬起 + `donation ≥ SIGNAL_COST` | `simulation/config.py:604` / `:763` |

**预计投入**：M0→M4 全程 **≈ 6–7 机时**（走 `use_sim_core=False` Python 路径，不做 Rust 下沉）。

## §1 病根诊断（必读，是全部设计的前提）

### 1.1 四个断点（代码级事实）

| # | 断点 | 证据位置 | 后果 |
|---|---|---|---|
| **B1** | 信号内容 = 发射者自身状态的硬编码公式 `state = e_bin*4 + f_bit*2 + n_bit` | `sphere_engine.py:109` | 生物只能"报告状态"，**无选择权** |
| **B2** | `f_bit`（脚下食物）、`n_bit`（邻居数）**接收者本来就能直读** | 同上 + 项目自己的注释 `sphere_engine.py:141-146` | 信号在重复说接收者已知的事⇒ **边际信息价值 = 0** |
| **B3** | 每次发射只写**1 格** | `sphere_engine.py:3664` `write_many(e_flat, patterns)` | **无长度维度 ⇒ 组合性结构上不可能出现** |
| **B4** | 决策只读 `sig_present`（有无），**不读 `marks` 内容**；且 `reputation_weight=0.0` 使 `sig_weight ≡ trust×0.5` 为常数 | `sphere_engine.py:3169` / `config.py:604` | **"有信号"与"无信号"对决策影响完全相同** ⇒ 大脑未通电 |

### 1.2 逻辑链（为什么必然退化）

```
信号内容 = 接收者自己看得见的状态
  ⇒ 接收收益 = 0
  ⇒ 发射纯付出（SIGNAL_COST=0.1，占max_energy 1/6000）
  ⇒ 突变"关闭发信号"在所有环境都更优
  ⇒ g15 被选择关闭
  ⇒ 16 种模式塌成 4 种（仅能量档）
```

🔴 **关键推论：这不是参数问题。调参无法改变这条链。**

### 1.3 陷阱：`signal_alphabet="8"` 档（**项目自己的正确设计，从未被正式跑过**）

`sphere_engine.py:141-155` 的注释（内评 2026-09-19）明确指出：

> 「改为『非当前格命中』后，该位指向**接收者无法直读的个体历史（另一些格位）** ⇒ 才符合 B③ 的原始意图」

该档 `state = e_bin*2 + mem_bit`，其中 `mem_bit = 1` ⟺ 发射者记忆中**存在一个 ≠ 当前格**的富食点
⇒ 语义 = "**我知道别处哪儿有食物**" ⇒ 这正是"私有信息才有交流价值"（Nowak-Krakauer / 蜜蜂逻辑）。

🟢 **本设计直接采用该档作为 M1 的信号内容来源。**

### 1.4 现有的正确资产（**不要重做**）

| 资产 | 位置 | 用途 |
|---|---|---|
| 信号物理层（4 子格/任意格写入/衰减/稀疏推进） | `world/signal_field.py:92, 104, 126` | **零改动可用** |
| `_interpret` 解读表 `(n,16)`，初值随机 + 在线学习 | `sphere_engine.py:1430` / `:3060` / `:3184` | **"大脑"本体，直接复用** |
| 任意性码本（可遗传可漂移） | `config.py:590` | M3 共享词典的基础 |
| 学习瓶颈（不遗传，观察学习） | `config.py:584` | M3 的"重新学一遍"机制 |
| Steels 对齐（同格相遇时对齐） | `config.py:607` | M3 横向对齐 |
| 8 邻含对角 = 3×3 九宫格 | `world/sphere_world.py:281` | **R3 读取范围** |
| `use_sim_core=False` Python 路径 | D2 惯例 | 新机制走Python，规避 Rust 逐位对拍 |

## §2 目标与判据

### 2.1 阶梯（沿用 `docs/决策与评审/战略定位-20260912`，勿另立）

| 级 | 判据 | 现状 |
|---|---|---|
| **L0** | 信号稳态（跨 seed 可复现，非peak-then-revert） | ❌ 未达成（g15 被关闭）|
| **L1** | 携带信息（信号↔对象有信息关联，超漂变零模型） | ❌ 未达成 |
| **L2** | **任意性**（符号与所指解耦；跨群分化且非热扩散） | ❌ 未达成 |
| **L3** | **组合性**（有限符号表达复合意义，新个体零样本可学） | ❌ 未达成 |
| **L4** | 语义接地 / 递归 | 🔴 不在可预见范围 |

🔴 **纪律**：任何"涌现"表述必须写明对应级别；未过判据的**不得写成涌现**。

### 2.2 本档案的成功定义

| 里程碑 | 判据 | 判负含义 |
|---|---|---|
| **M1** | `g15`（SIGNAL_STRENGTH）**末段均值不低于首段**；`mem_bit` 读取率 > 0.5 | 信号系统在此装置下仍无法存续 ⇒ 停止信号线，报天平 |
| **M2** | 计费改造臂的**无效 bit 占比**显著低于对照臂 | 成本结构不敏感 ⇒ 转"极端稀缺信道"方案 |
| **M3** | 同state→code 一致率 > 0.3 **且** 跨群分化显著高于随机 **且** 分布熵不下降 | 任意性路线受阻 |
| **M4** | `context independence` > 0：表达 12 情境所需新样本 < 1/12 | 🔴 **诚实记录为阴性**（见 §7.3） |

### 2.3 🔴 M3 的双向判据（防误判，**必须两条同时满足**）

- ✅ 一致率**上升**（共享成功）
- ✅ 分布熵**不下降**（未退化为"全群说同一个词"）
- ⛔ **只看第一条会把"退化成单一词"误判为成功**

## §3 总体架构

### 3.1 信号系统三层（`[推断]` 但已由代码确认框架）

```
发射端                                    接收端
┌─────────────────────┐                ┌─────────────────────┐
│ L2 载体层（缺失）    │                │ L3 解读层（未通电）  │
│· 写什么（基因选）   │ ──── 九宫格 ──→ │ · 读多格成有序串     │
│ · 写几格（基因选）   │                │ · 查 _interpret      │
│ · 在哪写（基因选）   │                │ · 串匹配度→移动倾向  │
├─────────────────────┤                ├─────────────────────┤
│ L1 内容层（存在但私有）│               │ L1 内容层            │
│ codebook[N,16] 可遗传│                │ 同一 state→不同 code │
│ 🔴 per-individual     │                │ ⇒ 天然方言           │
└─────────────────────┘                └─────────────────────┘
```

### 3.2 环境与记忆的关系（信号燃料）

```
记忆（"我知��别处有食物"，4/4+8/8 复现）  ⇒ 私有信息来源
食物气味（引导生物到更多斑块，24/24 复现）  ⇒ 远距离私有信息
庇护所（待建）                          ⇒ 同时给"选择压"+"私有信息"
```

⚠️ **这三者不是独立研究方向，是线A（共享词典）的燃料。**

## §7 判负处置手册（**必须提前写死，禁止事后找补**）

### 7.1 六类判负与规定动作

| 判负类型 | 可能原因（按概率） | 规定动作 |
|---|---|---|
| **信号仍被关闭**（`g15`↓）| C3 收益不足 / 无私有信息可用 | ① 查 G4 私有信息率 ② 若 ≈0 ⇒ `8` 档未生效，**停调参查装置** ③ 若 > 0 但收益不足 ⇒ `reputation_weight` 提一档，**只准一次** |
| **噪音率不降** | 计费未生效 / 占位太便宜 | ① 查 G3 序列长度是否 > 1 ② 查限流是否 fail-loud ③ **若机制确认生效仍无效 ⇒ 转"极端稀缺信道"**（群内仅留少数广播位）|
| **一致率不升** | 垂直传递未接上 / 选择压不足 | ① 查继承源是否真换 ② 若已接上 ⇒ 承认 per-individual 是设定，**加"群体层码本"对照臂**分离 |
| **分布熵下降** | 无负反馈 | 启用 A3 负反馈（已占用信号降权）|
| **组合性不涌现** | 🔴 **Kuciński et al. 2021 定理生效**（组合性需归纳偏置）| **不得追加批**。三条出路：① 门控加强为"必须两段才有效" ② 加第二层（帧）③ **诚实记录阴性并写清边界**（见 7.3）|
| **装置层缺陷** | 两套真值源类问题 | 走 `check_bg_lottery` 式守卫 + **全批作废，只登记不解读** |

### 7.2 判负的**正向价值登记**（阴��不是废品）

| 阴性结果 | 价值 |
|---|---|
| 组合性在无 NN/无奖励下不涌现 | 🔴 **首次给出 ALife 领域该边界的量化证据**（对照 Kuciński 2021 只给"有偏置时可达"）|
| 双峰在缺频率依赖下不可能 | 已完成（`证伪-双峰…`），**可作方法学文献** |
| 信号无私有信息时被选择关闭 | 支撑"符号接地需要私有信息"的定量论据 |

### 7.3 🔴 组合性若失败，**怎么写**（这是科学结论，不是失败）

必须写明：
1. 在**无神经网络、无显式奖励、无归纳偏置**条件下，未观察到组合性涌现
2. 与 Kuciński et al. 2021（**有归纳偏置 + 噪声**）的**条件差异**
3. 效应量与判据信噪比（**若信噪比 <1，须写明"本判据无法检测"而非"不存在"**）
4. 🔴 **不得写成"语言不可能涌现"** —— 只写"在本装置与本判据下未观察到"
