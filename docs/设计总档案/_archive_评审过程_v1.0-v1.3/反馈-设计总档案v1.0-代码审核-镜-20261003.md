## 🔴 硬伤 1：§1.3 的 `mem_bit` 前提**未验证**，且我实测发现它可能恒为 0

**档案主张**（§1.3 / R1.2）：采用 `signal_alphabet="8"` 档，`mem_bit = 1` ⟺ 发射者记忆中**存在一个 ≠ 当前格的富食点** ⇒ "接收者无法直读" ⇒ 私有信息 ⇒ **M1 全部希望所系**。

**我的核实**（`[代码]` `sphere_engine.py:3590-3594`）：

```python
elif food_rich.any():
    rich_idx = np.flatnonzero(food_rich)
    ptr = int(self._mem_ptr)
    self._work_memory[rich_idx, ptr] = cur_flat[rich_idx]
    self._mem_ptr = (ptr + 1) % 4
```

🔴 **`_work_memory` 只在 `food_rich`（当前格食物丰富）时写入，且写的是"当前格"**。
⇒ **`mem_bit` 的成立条件是"生物曾经站过富食格"**。

⚠️ **与天平 R344 错 3 的关系（重要，别重复劳动）**：天平说 `"8"` 档"**代码路径已存在**"⇒ 我**同意**（`:3647` 确实有 `if self._alpha == "8":` 分支）。
🔴 **但我补的那一刀是**：**路径存在 ≠ 输入会非零**。`mem_bit` 的**数据源**是 `_work_memory`，而它的写入条件是 `food_rich` ⇒ **真正的风险不在"档位有没有实现"，在"记忆有没有内容"**。
天平查的是**发射端分支**；我查的是**记忆供给端**。⇒ 两条**互补，不冲突**。

⚠️ **冲突点**：
1. 档案 §8.2 冻结了 rd（资源动力学）相关批；而 **rd 的整个设计就是"让食物变稀缺"**（耗竭—恢复轮作）
2. `[文档]` 我上一轮实测的因果链：世界**空间上无差异**（饱和度全域 0.94–0.96）⇒ 生物**到处都能吃到** ⇒ `food_rich` 容易满足

⇒ **要么"稀有信息"让信号更有价值，要么"太稀有"让信号无内容。** 档案**没有对这一点做任何判据**。

**我的实测建议（零机时）**：

## 🟡 澄清 1：§1.1 B4 说"`reputation_weight=0` 使 `sig_weight` 为常数" ⇒ 我认为**这条断了因果链**

**档案原文**（B4）："决策只读 `sig_present`（有无），**不读 `marks` 内容**；且 `reputation_weight=0.0` 使 `sig_weight ≡ trust×0.5` 为常数 ⇒ **"有信号"与"无信号"对决策影响完全相同** ⇒ 大脑未通电"

`[代码]` 我复核了公式（`sphere_engine.py:3167-3170`）：
```python
sig_weight = self._trust[gi] * (0.5 + rep_w * self._trust[gi])
score = (perc[:, None] * (food_ratio[nb] * 0.5
                          + sig_present[nb] * sig_weight[:, None])
```
⇒ `rep_w=0` 时 `sig_weight = trust × 0.5`，**是常数没错**。
🔴 **但"常数"不等于"无影响"**：`sig_present[nb]` 是**变量**（邻格有信号=1，无=0）⇒ `score` 仍有差异，差异 = `perc × trust × 0.5 × sig_present`。
⇒ **"有信号 vs 无信号"并非"完全相同"**，而是"**权重固定、不可按可信度调节**"。

**这会影响 §1.2 逻辑链的一环**：
```
现状：发射纯付出 ⇒ g15 被关闭
```
⇒ 🔴 若"有信号/无信号"仍有差异，那"关闭发信号"就是**放弃了 `perc×trust×0.5` 的加分**⇒ **它仍可能是"净亏损"（付 0.1 换 ≤0.5×perc×trust）** ⇒ **链子成立，但成立点在"收益上界小于成本"而非"收益恒为零"**。

⇒ **建议改写 B4 的措辞**（不动结论，只求准确）：把"对决策影响完全相同"改为"**权重不可按可信度调节**"。

⚠️ 这不是"推翻档案"，是**把论据从错的换成对的**。🔴 建议天平核。
