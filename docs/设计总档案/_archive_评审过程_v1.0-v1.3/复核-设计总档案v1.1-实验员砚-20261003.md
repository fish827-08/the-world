## 三、🟢 我在 v1.1 里新发现的一处**残留问题**（不阻塞，但建议记入 §9.1）

v1.1 §9.1 `:581` 写：
> 「🔴 **`mem_bit` 前提未验证（v1.1 新增）｜**最高**｜记忆格可能只1 格（可直读）＋ **只在 `food_rich` 时写入** ⇒ 可能冗余/恒 0」

⇒ ✅ 这条把**镜的硬伤 1**（`_work_memory` 只在 `food_rich` 写入，`:3593`）也吸收了，**三家一致**。
⇒ 🔴 **但我要补一个更深的问题**（v1.1 未提）：

> **`mem_bit = 1` 的成立条件是"发射者记忆中**存在 ≠ 当前格的富食点**"，
> 而 `_work_memory` 是**环形缓冲 4 格**（`ptr` 循环写，`sphere_engine.py:3591`）。
> ⇒ 若某生物长期在**同一片斑块**活动，它记住的 4 格**全是当前斑块内的格**
> ⇒ `mem_hit` 判定"≠ 当前格"仍可能成立（**斑块内其他格也是 ≠ 当前格**）
> ⇒ 🔴 **但那些格同样在 1 格感知范围内**（斑块半径通常 ≫ 1 格，但**相邻格**也在 1 格内）
> ⇒ **这不是 P1/P1b 能解决的**，因为它需要"记忆格**确实远到接收者看不见**"——
> 而斑块内相邻格**永远只有 1 格**。
> ⇒ **建议在 P1b 之后加一条 P1c**：
> 🔴「**`mem_bit` 的"远距性"上限 = 记忆格到发射者的距离；因记忆只记 `food_rich` 格、
> 而富食格必然成簇⇒ **簇内记忆格几乎必然是 1 格邻居** ⇒ **"私有信息"在本世界几何下可能结构性不可达**」
> ⇒ **这一条会决定 M1 的整个前提是否值得投入**，比 Q1 更根本。

**我的核实依据** `[代码]`：`sphere_engine.py:3588-3593`
```python
if food_rich.any():
    rich_idx = np.flatnonzero(food_rich)
    ptr = int(self._mem_ptr)
    self._work_memory[rich_idx, ptr] = cur_flat[rich_idx]   # ← 只记富食格
    self._mem_ptr = (ptr + 1) % 4                              # ← 环形 4 格
```
⇒ **记忆只能来自"我站过的富食格"**，而富食格来自斑块 ⇒ **斑块内相邻格必然被记住** ⇒
`mem_bit` 的"我记得别处"在**斑块内**成立，但**对接收者无用**（1 格内可直读）、
在**斑块间**才有用（但记忆不一定跨斑块）。

⇒ 🔴 **一句话**：`"8"` 档的私有性，**取决于"生物是否会跨斑块移动"**——
而 R336 已测到**无定位机制时 `bg_resid = 0.03`（几乎不跨斑块）** ⇒**`mem_bit` 可能结构性接近"恒 0 或无信息"**。
⇒ **建议**：P1 的 `mem_bit_frac` 判据**必须与 `bg_resid` 联合读**（若 `bg_resid` ≈ 0.03 ⇒ 记忆天然跨不了斑块 ⇒ P1 直接判负，无需等 P1b）。

**我已核实这条的代码依据** `[代码]`：
- `sphere_engine.py:3594` `self._mem_ptr = (ptr + 1) % 4` ⇒ **环形 4 格**（不是全量历史）；
- `sphere_engine.py:3577` `food_rich = (...)` ⇒ **记忆源= 当前所站格是否富食**（`FOOD_RICH_LEVEL` 阈值，`:3574`）；
- ⇒ **富食格来自斑块** ⇒ 记住的 4 格几乎必然是**当前斑块内的格** ⇒ 其中相邻格**距 1 格**。

####🆕 我建议的 P1 判据增补（让 P1 一次就能判生死，不需等 P1b）

P1 目前只读 `mem_bit_frac`（信号层）。**建议同时读两个"几何量"，三者联合才能判**：

| 量 | 读法（零机时，走已有链路） | 判负含义 |
|---|---|---|
| ① `mem_bit_frac` | v1.1 已定义（`:3648` / `:5751`） | ≈0 ⇒ 信号层没私有信息 |
| ② 🆕 **记忆格跨斑块比例** | 从 `_work_memory`（`:3593`）取记忆格，比对其是否落在**当前斑块**内 | 🔴 **≈1（全在同斑块）⇒ 私有信息结构上限被锁死**（因为斑块内相邻格只有 1 格） |
| ③ 🆕 **`bg_resid`（已有 4 份历史读数）** | R336 实测 0.03（无定位）／R337 旗舰 0.667–0.883（有记忆） | 🔴 **≈0.03 ⇒ 几乎不跨斑块 ⇒ ② 必然 ≈1** |

⇒ **三量联合的短路逻辑**（我的建议）：
> 若 ③ `bg_resid` ≈ 0.03（M1 装置下的预期值）⇒ ② 必然≈1 ⇒ **私有信息结构性不可达**
> ⇒ 🔴 **P1 直接判负，不必等 P1b，也不必起 M1 批**（省 ≈1 h + 避免又一次不可归因的阴性）。

⚠️ **诚实边界** `[待核]`：上面 ② 我**没有实测**（需要跑 1 run 打印 `_work_memory` 与斑块掩码的交集）
⇒ **但它零机时、且 P1 本来就要跑 1 run × 2k ⇒ 建议 P1 那一轮顺手把它打出来**，
⇒ 这样 P1 一次跑完就能给出"**信号层 + 几何层**"双判据，避免"信号层过了但几何层锁死"的两轮等待。
