## 一、fish 的原话

> **"生物读取所在九宫格的信息，一次性可以全读取，能量消耗一致，因为生物已经看到了，
> 不应该让他由于能量看不见，自然界中的生物读取信息的能量消耗还是比发出信息低一点吧。"**

拆成三条可执行裁定：

| # | 裁定 |
|---|---|
| 1 | 🔴 **读取九宫格 = 一次性全读，能量消耗一致**（**不按字、不按次计费**） |
| 2 | 🔴 **读取成本必须低于发出成本**（"自然界…读取比发出低一点"） |
| 3 | 🟡 **成本差异的正确归属是「移动」，不是「读取」**（"想看远处就得走过去，而走路本来就要花能量"） |

## 二、🔴 三人请重点核的第1 条：**我们自己的一个规约被推翻了**

### v1.3 原文（作废）

> **R3.5**：由生物自己决定读多少 ⇒ 不设固定上限；**每次继续读都扣能量，读不下去就自然停**

### 为什么作废

若读1 格与读 9 格消耗**相同**，则"继续读"这个动作**没有价格** ⇒
**"读不下去就停"这条路径永远不会触发** ⇒ 该规约是一段死逻辑。

### v1.3 修订（现行）

| 规约 | 内容 |
|---|---|
| **R3.5** | 由生物自己决定读多少，但**决定机制不是能量，而是大脑** ⇒ 落在① **移动**（唯一真成本门槛）② **大脑注意力**（哪几格内容真正进决策）|
| **R3.5b**（新）| **槽位权重本身可进化** —— 谁进决策、谁被忽略由 `_interpret` 权重与基因决定，**不由成本决定** |
| `g_read_patience` **语义变更** | 从"读取上限"→彻底改为 **"注意力倾向"**（低 = 只看最显著那格/ 高 = 纳入更多格）|

## 三、🟢 第 2 条：**信号的真实价值被这条裁定明确了**

> **信号 = "省路的广告"**

```
九宫格免费看 ⇒ 想知道远处的事必须【走过去】（真成本：能量 + 时间）
             ⇒ 信号告诉它"那边值得去"
             ⇒ 接收者省下这段路的能量与时间
```

**⇒ 发送者为什么付得起这笔钱，账算通了**（它花钱发信号，别人少走路）。
**⇒ 完全内生，不需要任何外部奖励函数** —— 符合 fish 一贯的"不猜对发奖"约束。

| 规约 | 内容 |
|---|---|
| **R4.6**（重写）| `read_cost` **必须低于** `SIGNAL_COST`（⚠️ **取代 v1.3 原"收发对称"**）|
| **R4.6b**（新）| 🔴 **建议 M1 辅助读数：「信号省路效应」** —— 有信号的兽**移动距离更短 / 能量支出更低** |

## 五、🔴 第 4 条：**风险表一条风险的"原因"变了，请核**

| 项 | 内容 |
|---|---|
| **原表述** | "读取成本 = 0 ⇒ 必然全读 ⇒ 组合性退化为固定窗口" |
| **⚠️ 作废原因** | 那个判据的前提是"成本**太重**"，而 fish 现在定的是"成本**平坦**"⇒ **判据形式变了，不是同一条** |
| **v1.3 修订后** | 🔴 **风险 = 九宫格内"读多少"完全没有成本信号** ⇒ 组合性可能退化为"**固定窗口看全部**" |
| **应对** | 🟡 **R3.5b 槽位权重可进化**（注意力机制）—— **不再依赖计费机制**，比原方案更简单 |
