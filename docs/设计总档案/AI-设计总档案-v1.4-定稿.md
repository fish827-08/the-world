#### 🔴 P1-b 的分母下限（天平 R345 意见 1）

`mem_bit_frac = _mem_bit_on / _mem_bit_n`（`:1522`）是**条件概率**，
分母只算"走了状态编码的发射" ⇒ 🔴 **若 `signal_gene`（g15）本身低、发射次数少，统计噪声极大**。

⇒ **判据须双条件**：`mem_bit_frac > 0` **且** `_mem_bit_n ≥ 阈值`
（否则"零观测"分不清是"没有"还是"样本太少"）。阈值由 M0 实测确定。

#### 🔴 P1-c · 距离/可达性门（**v1.2 新增，依据镜 B + 砚 P1c**）

⇒ **若距离实测很近，根因是"世界缺空间异质性"（饱和度全域 0.94–0.96），

**⇒ P1-c 判据（纯测量，不预设结论）**：

### P2 · 内容项消融门（天平错 2＋ 镜澄清 1 + 砚 Q10：**三家一致**）

**质疑**：§1.1 B4 原写"内容通道未生效"是**错的**。实测（`sphere_engine.py:3180-3187`）：

```python
nb_sigs = self.signals._marks[nb]                                    # 取内容
interp  = np.where(nb_sigs > 0, self._interpret[gi[:,None], nb_sigs], 0.0)
score   = np.where(has_sig[:,None], score + (0.4*perc)[:,None]*interp, score)   # 🔴 已进 score
```

⇒ 🔴 **内容项（`_interpret` × `0.4×perc`）一直在生效，且未被 `rep_w` 门控**。
真正的问题是：**"有无"通道的 `sig_weight` 在 `rep_w=0` 时退化为常数 `trust×0.5`**。

⚠️ **`sig_present` 仍是变量**（镜澄清 1）⇒ 有信号/无信号**仍有差异**（= `perc×trust×0.5`），
**不是"影响完全相同"**，而是"**权重不可按可信度调节**"。

**⇒ 前置动作**：M1 的对照臂**必须能区分"内容项"与"有无项"各自的作用**
⇒ 见 §6 E-101 新增的**内容项消融臂**（关掉 `0.4×perc×interp`）。
**否则 M1 出了阳性无法归因是哪一项起的作用。**

## §0 执行摘要

**项目**：球面有限世界，让语言/符号系统从进化中涌现。
**目标**：不是找"最小充分条件"，而是**让语言真的涌现出来**（含任意性、组合性）。
**手段**：不用LLM、不用神经网络、不用"猜对发奖"式捷径；只用**死规则 + 生态选择压**。

🔴 **目标档位 = 480×960（460,800 格）**，`--device s2`（镜硬伤 2修正）
⚠️ `SimConfig` 默认值是 `60×120=7200`（`config.py:25-26`），但**全部近期实验档都是 480×960**
（`tools/device_presets.py:22`：`rows=480 cols=960 patches=1700 pop=10000 rgm=1.195`）
⇒ 🔴 **本设计一律显式传 `--device`，禁吃默认值**（否则与 S2-6/旗舰全部历史读数不可比，`斑块间距~15 格`等已标定尺度全部失效）。

## §1 病根诊断（必读，是全部设计的前提）

### 1.1 四个断点（代码级事实）

| # | 断点 | 证据位置 | 后果 |

| **B1** | 信号内容 = 发射者自身状态的硬编码公式 `state = e_bin*4 + f_bit*2 + n_bit` | `sphere_engine.py:109` | 生物只能"报告状态"，**无选择权** |
| **B2** | `f_bit`（脚下食物）、`n_bit`（邻居数）**接收者本来就能直读** | 同上 + 项目自己的注释 `sphere_engine.py:141-146` | 信号在重复说接收者已知的事⇒ **边际信息价值 = 0** |

> ⚠️ **v1.1 修正**：B4 原写"决策只读 `sig_present`、不读 `marks` 内容 ⇒ 大脑未通电" —— **该表述错误**。

### 1.2 逻辑链（为什么必然退化）

```
信号内容 = 接收者自己看得见的状态
  ⇒ 接收收益 = 0
  ⇒ 发射纯付出（`SIGNAL_COST=0.1`，**占 max_energy 的 0.033%（默认 300）~ 0.017%（13.5 标定档 600）**）
  ⇒ 突变"关闭发信号"在所有环境都更优
  ⇒ g15 被选择关闭
  ⇒ 16 种模式塌成 4 种（仅能量档）
```

🔴 **关键推论：这不是参数问题。调参无法改变这条链。**

### 1.3 陷阱：`signal_alphabet="8"` 档（**项目自己的正确设计，从未被正式跑过**）

`sphere_engine.py:141-155` 的注释（内评 2026-09-19）明确指出：

> 「改为『非当前格命中』后，该位指向**接收者无法直读的个体历史（另一些格位）** ⇒ 才符合 B③ 的原始意图」

该档 `state = e_bin*2 + mem_bit`，其中 `mem_bit = 1` ⟺ 发射者记忆中**存在一个 ≠ 当前格**的富食点
⇒ 语义 = "**我知道别处哪儿有食物**" ⇒ 这正是"私有信息才有交流价值"（Nowak-Krakauer / 蜜蜂逻辑）。

## §2 目标与判据

### 2.1 阶梯（沿用 `docs/决策与评审/战略定位-20260912`，勿另立）

| 级 | 判据 | 现状 |
|---|---|---|
| **L0** | 信号稳态（跨 seed 可复现，非peak-then-revert） | ❌ 未达成（g15 被关闭）|
| **L1** | 携带信息（信号↔对象有信息关联，超漂变零模型） | ❌ 未达成 |
| **L2** | **任意性**（符号与所指解耦；跨群分化且非热扩散） | ❌ 未达成 |
| **L3** | **组合性**（有限符号表达复合意义，新个体零样本可学） | ❌ 未达成 |
| **L4** | 语义接地 / 递归 | 🔴 不在可预见范围 |

🔴 **纪律**：任何"涌现"表述必须写明对应级别；未过判据的**不得写成涌现**。

### 2.2 本档案的成功定义

| 里程碑 | 判据 | 判负含义 |
|---|---|---|
| **M1** | `g15`（SIGNAL_STRENGTH）**末段均值不低于首段**；**发射率不降**；🔴 **「会读」= 行为改变率 > 0**（🔴 **读取成本已定为 0**，故**不得**用"读取是否耗能"作代理指标 ⇒ 只能测"读到的串是否改变了移动") | 信号系统在此装置下仍无法存续 ⇒ 停止信号线，报天平 |
| **M2** | 计费改造臂的**无效 bit 占比**显著低于对照臂 | 成本结构不敏感 ⇒ 转"极端稀缺信道"方案 |
| **M3** | 同state→code 一致率 > 0.3 **且** 跨群分化显著高于随机 **且** 分布熵不下降 | 任意性路线受阻 |
| **M4** | `context independence` > 0：表达 12 情境所需新样本 < 1/12 | 🔴 **诚实记录为阴性**（见 §7.3）|

⚠️ **v1.1 修正（天平异 4／砚 Q2）**：M1 判据**不用"mem_bit 读取率 > 0.5"** —— 该指标
① 依赖尚未存在的仪表（会卡在"仪表还没做完"），② **在本装置下可能恒不可达**，
③ **即使测到了也可能不含信息量**（读到但没用）。
⇒ 改为**过程量 + 可解释口径**：

| 替代判据 | 口径 | 为什么 |
|---|---|---|
| **① 私有信息发射占比** | `mem_bit=1` 的发射数 / 总发射数 | 测"信号里是否真带私有信息"，而非"是否被读到" |
| **② 行为改变率** | 收到信号 vs 未收到，**移动方向差异率**（= 自己的 G5）| 测"读到之后有没有用" |

### 2.3 🔴 M3 的双向判据（防误判，**必须两条同时满足**）

- ✅ 一致率**上升**（共享成功）
- ✅ 分布熵**不下降**（未退化为"全群说同一个词"）
- ⛔ **只看第一条会把"退化成单一词"误判为成功**

## §3 总体架构

### 3.1 信号系统三层（`[推断]` 但已由代码确认框架）

```
发射端                                    接收端
┌─────────────────────┐                ┌─────────────────────┐

├─────────────────────┤                ├─────────────────────┤
│ L1 内容层（存在但私有）│               │ L1 内容层            │
│ codebook[N,16] 可遗传│                │ 同一 state→不同 code │
│ 🔴 per-individual     │                │ ⇒ 天然方言           │
└─────────────────────┘                └─────────────────────┘
```

## §7 判负处置手册（**必须提前写死，禁止事后找补**）

### 7.1 六类判负与规定动作

| 判负类型 | 可能原因（按概率） | 规定动作 |
|---|---|---|
| **信号仍被关闭**（`g15`↓）| C3 收益不足 / 无私有信息可用 | ① 查 G4 私有信息率 ② 若 ≈0 ⇒ `8` 档未生效，**停调参查装置** ③ 若 > 0 但收益不足 ⇒ `reputation_weight` 提一档，**只准一次** |
| **噪音率不降** | 计费未生效 / 占位太便宜 | ① 查 G3 序列长度是否 > 1 ② 查限流是否 fail-loud ③ **若机制确认生效仍无效 ⇒ 转"极端稀缺信道"**（群内仅留少数广播位）|
| **一致率不升** | 垂直传递未接上 / 选择压不足 | ① 查继承源是否真换 ② 若已接上 ⇒ 承认 per-individual 是设定，**加"群体层码本"对照臂**分离 |
| **分布熵下降** | 无负反馈 | 启用 A3 负反馈（已占用信号降权）|
| **组合性不涌现** | 🔴 **Kuciński et al. 2021 定理生效**（组合性需归纳偏置）| **不得追加批**。三条出路：① 门控加强为"必须两段才有效" ② 加第二层（帧）③ **诚实记录阴性并写清边界**（见 7.3）|
| **装置层缺陷** | 两套真值源类问题 | 走 `check_bg_lottery` 式守卫 + **全批作废，只登记不解读** |

### 7.2 判负的**正向价值登记**（阴性不是废品）

| 阴性结果 | 价值 |
|---|---|
| 组合性在无 NN/无奖励下不涌现 | 🔴 **首次给出 ALife 领域该边界的量化证据**（对照 Kuciński 2021 只给"有偏置时可达"）|
| 双峰在缺频率依赖下不可能 | 已完成（`证伪-双峰…`），**可作方法学文献** |

### 7.3 🔴 组合性若失败，**怎么写**（这是科学结论，不是失败）

必须写明：
1. 在**无神经网络、无显式奖励、无归纳偏置**条件下，未观察到组合性涌现
2. 与 Kuciński et al. 2021（**有归纳偏置 + 噪声**）的**条件差异**
3. 效应量与判据信噪比（**若信噪比 <1，须写明"本判据无法检测"而非"不存在"**）
4. 🔴 **不得写成"语言不可能涌现"** —— 只写"在本装置与本判据下未观察到"
