## 一、为什么叫 SX-1（起名溯源，fish 22:55 问）

**先说结论：这个名字起得不好，我改。**

| 成分 | 原意 | 问题 |
|---|---|---|
| `SX` | 计划中的**"交叉"（crossover）**实验 | 🔴 **`X` 读不出来**。"smell × rd" 里的 `×`（乘号）被误写成了字母 X ⇒ 后来被读成 "SX"。**这是命名失败的根因** |
| `1` | 该主题的**第1 号** | 🟡 可以，但没有信息量 |

**根因**：`X` 在本项目里已经承载了两个意思 —— ① **装置档代号**（A 支 / B 支，历史上还用过 "X 支"）；
② **乘号**（"气味 × rd"）。**一符两义 = 必然被误读。**

⇒ 🔴 **命名纪律（本规范 §二）**：**实验代号里禁止用 `X`**（避免与乘号、支别代号混）。

## 二、实验代号命名规范（🆕 本次立规）

### 2.1 结构

```
<机制>_<变量>_<编号>_<变体>
```

| 段 | 取值 | 例|
|---|---|---|
| **机制** | `smell` / `rd` / `mem` / `dev`（装置）/ `mix`（混合） | `smell` |
| **变量** | 本批**唯一变化的处理**（不是装置！） | `rd`（本批测的是"rd 在有气味下如何"） |
| **编号** | 两位数，**同机制同变量递增，跨批不复用** | `01` |
| **变体** | 臂/组名，**用 `-` 分隔** | `a1` `b1` |

### 2.2 硬约束

1. 🔴 **禁用字母 `X`**（乘号/支别双重歧义）；
2. 🔴 **禁用无意义缩写**（不许出现 `t1` / `tmp2` / `final_new2` 这类"想到什么写什么"）；
3. 🔴 **禁止覆盖复用**：同一代号**永不指向两个不同装置的批**（跨批可比性靠代号唯一性保证）；
4. ✅ **代号一经上板即冻结**，要改必须新起编号并写映射关系。

### 2.3 三组臂名（A0/A1/B1）的来源 —— 这组名字是好的，保留

| 臂 | 含义 | 为什么这么叫 |
|---|---|---|
| **A0** | rd 关 + 气味关 = **基线** | `A` = 第一个因素（rd）｜`0` = 该因素**关**（0 层） |
| **A1** | rd **开** + 气味关 | `A1` = 第一个因素**开**（1 层）⇒ **= S2-6 的 on 臂**（可对照） |
| **B1** | rd 开 + 气味**开** | `B` = 第二个因素（气味）｜`1` = 该因素**开** |

⇒ **这就是"析因设计"的标准记法**（factor letter + level）。`A0/A1/B1` 是**教科书级**命名，
**与 `SX-1` 不是同一水平的东西**——所以我改 `SX-1`，**保留 `A0/A1/B1`**。

### 2.4 新代号映射（🔴 冻结）

| 旧代号 | 🆕 **新代号** | 含义 |
|---|---|---|
| `SX-1` / `smellx_rd` / 21:40 版"24 run × 40k" | 🔴 **`smell_rd_01`** | 气味 × rd，18 run × 10k，A 支 |

**一句话记住新代号**：`smell_rd_01` = **smell** 机制 +测**rd** 变量 + 第 **01** 号。

## 三、实验记录规范（长实验 vs 短实验）

> **为什么分两档**（fish 22:55 问）：长实验动辄几小时到几十小时、可能隔夜、可能换人接手
> ⇒ 必须留**能被别人接手**的记录；短实验分钟级 ⇒ 只需**能复现**的最小记录。

### 3.1 🔴 短档实验（≤ 5 000 tick 或 ≤ 20 min）

| 项 | 要求 |
|---|---|
| 记录位置 | `docs/实验台账.md` 对应节，**追加一行表格行**即可 |
| 必填 | 代号 / 装置（`bg_low` + `patches` + `pop`）/ seeds / ticks / **一句话结论** / 产物路径 |
| ❌ 不要求 | 独立判读稿、预注册稿 |
| 判据 | **跑前必须写进台账**（哪怕一行）—— 事后补 = 无效 |

### 3.2 🔴 中档实验（≤ 20 000 tick，天平批准）

短档全部要求 **＋**：
- **预注册稿** `docs/设计文档/预注册-*.md`（跑前锁定，禁事后改判据）；
- **独立判读稿** `docs/R<编号>-<主题>批判读-<日期>.md`；
- 完整度自检（run 数 / 行数 / 末 tick / `stop` 字段 / 装置回显）；
- 上板结论帖。

### 3.3 🔴 长档实验（> 20 000 tick，fish 批准 + 多次审核）

中档全部要求 **＋**：
- **专用目录** `_rerun_logs/<代号>/` ＋ 数据仓 `the-world-data/<代号>/`；
- **检查点规则**（跑多久算够/ 不够怎么判，**跑前写死**）；
- **续跑方案**（`--save-every` / 快照；云端沙盒有清理周期 ⇒ 必带）；
- **每2 h 上板报到**（长跑时无人盯 = 断点）；
- **免费回归项**（若与其他批同 world，可拿短段做逐位对拍 ⇒ 判读前必做）。

### 3.4 🔴 三档共同硬要求

1. **起跑前**：`docs/实验台账.md` 写"**计划行**"（含§〇 六项必查清单逐项打勾）→ **再起跑**；
2. **署名**（见下 §四）：**产物、判读稿、提交、上板** 四处署名必须一致；
3. **回填**：跑完 **24 h 内**补"结果行"（含**作废批也留行**，注明作废原因）；
4. **产物入数据仓**：主仓 `.gitignore` 含 `results/` ⇒ **产物必须复制进数据仓并 push** 才算交付。

| ③ 判读稿/预注册稿 | 文首"立稿：`[角色·花名]` <日期>" | 读文首 |
| ④ 板上帖子 | `### [角色] · YYYY-MM-DD HH:MM`（花名只作签名档） | 板面 |
