## 四、§九-2 RNG 消费方式写明（载体实测口径，配对设计含义照实呈报）

`[代码]` 事实链：
1. **斑块生成 = 独立流**：`world/resource_field.py:167-172`——`rng = default_rng(patch_seed)`（`patch_seed = config.seed`，`sphere_engine.py:813`），`centers = rng.choice(n_cells, size=patch_count, replace=False)`；**不消费引擎主 rng**，探针/引擎主流起点不受 patches 影响。
2. **跨档斑块非嵌套**：`replace=False` 下 size 不同 ⇒ 抽样序列不同（非前缀关系）⇒ D1 的 850 个斑块**不是** D0 的 1700 之子集；"seed 配对"消的是**同一 seed 个体初态/基因噪声**，不消斑块几何生成差（该差 = 处理本身的一部分）。
3. **主流计数级同构、值级分叉**：引擎主 rng（`sphere_engine.py:719` CountingRNG）初始消费 = 基因 `:1336`、解读 `:1430`、撒点 `:1575-1583`（`rng.choice(_patch_cells, size=_n_patch, replace=True)` + `rng.integers`）——**抽取次数只依赖 n/_n_patch（同 seed 同 pop ⇒ 跨档相同）**，但 `_patch_cells` 内容随档变 ⇒ **取值随档分叉**；此后生灭改变个体数 ⇒ 流按动力学自然分叉（处理效应，非污染）。
4. 探针与 home-range 均纯观测、不消费 RNG（§三）。

⇒ 预注册 §九-2 的"配对是否足以消生成噪声"照实移交砚判读（载体侧结论：**各 run 内部自洽可复现；跨档比较须按 §一"同码同纪园内"约束读**）。

## 五、R277 起跑四要素映射（逐 run manifest）

`--run-matrix` 每 run 落 `the-world-data/p1c_density/manifest_d{patches}_s{seed}.json`：
- ① **全 argv** = probe summary.argv + 完整复现命令；
- ② **装置回显** = summary.readback + `verify_readback()` 与 §2.2 锁定值**逐字段核对**（readback 位 6 项 + rows/cols/initial_pop/rgm/ring_depth/patches + ticks/sample；任一失配 ⇒ 该 run 记异常，末尾汇总 fail-loud 非零退出）；
- ③ **代码 commit 指纹** = `git rev-parse HEAD` + dirty 标志（**dirty 且未 `--allow-dirty` ⇒ 整批拒跑**，指纹不唯一不开跑）；
- ④ **逐项核对表** = `field_check`（§2.2 锁定值快照 + 预注册路径引用）。

## 六、S4/止步/生态门机械位（§3.2-S4 镜 N4 修订 + §四）

- S4：任一存活 run `pos_frac_read_moore` NaN/None ⇒ 档判"不定" + `s4_nan` 记录 + `--aggregate` **rc=3**（上板，不静默）。
