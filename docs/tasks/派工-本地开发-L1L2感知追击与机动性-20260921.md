## 一、实现前必须钉死的四条硬约束（违反任一条即退回）

### H1 🔴 **默认关 = 逐位等价**（含 RNG 消费数不变）

`sphere_engine.py` step 5 的现存契约（**逐字**）：
```
# RNG 契约：保持每 tick 消费 P 个 uniform 不变（rng.random(P) 原样），只改阈值。
```
⇒ L1/L2 的**所有开关默认关**时，`RNG` 调用序列、参数、消费数与旧代码**逐位相同** ⇒ C7 逐位对拍必须过。

### H2 🔴 **不得新增每 tick 的随机抽取**

本轮改动**必须复用**现有 `rng.random(P)`（移动判定）与 `rng.integers(0, len(nb))`（选格）调用，**只改参数或阈值**。
⇒ 若某设计需要"额外抽一次判定冲刺"⇒ **退回重设计**（会破坏 H1 与跨批可比性）。
⇒ ⚠️ 注意：同一 `u` 与两个阈值比较会引入**相关性**，**不可**用来做"独立的两次判定"。

### H3 🔴 **开关开启时必须强制 Python 路径（fail-loud）**

复用现有机制（`_d2_asym` 同族）：新增条件并进 `_d2_asym`（或等价的强制项），
**且**在 Rust 侧显式 `NotImplementedError`/硬报错 —— **绝不允许"打开开关后静默走 Rust 变成 no-op"**。
（理由：这正是 PR `feat/predator-dash` 的翻车方式，见 R145 §二。）

### H4 🔴 **机动性必须同时作用于追击与逃脱**

**禁止**只在捕食成功率上乘一个系数（那是旧 dash 的形态）。
机动性 = **移动能力**，追与逃**共用同一物理** ⇒ 不需要任何"给捕食者加成/给食草者减伤"的人为偏置。

## 二、L1 感知层（**移动决策加两项**）

### 2.1 现状（可复核坐标）

`step 5) 移动`，score 现有项（Python 侧）：
```
score  = perc * (fr * 0.5 + sp * sig_weight)
score += soc * densities[nb]              # soc = (g13 − 0.5) × 2
score += mem_grad_gain * perc * g         # A′ 记忆朝向梯度
score += 0.3 * perc * mem_in_nb
score += 0.4 * perc * interp              # 信号内容
```
🔴 **现状：决策完全不看"邻居是谁"** ⇒ 捕食者不朝猎物走、猎物不避捕食者 ⇒ 出手时 **76–89% 邻格无猎物**（R143 实测）。

### 2.2 新增两项（建议形态）

```
prey_avail[i] = (# 邻格中存在的其他个体) / (# 有效邻居)          ← 猎物可得性
threat[i]     = Σ_{j∈nb} max(0, g16_j − attack_gene_gate) / (# 有效邻居)   ← 威胁强度

score += w_seek × perc × g16_i        × prey_avail    ← 捕食者朝猎物走
score -= w_fear × perc × (1 − g16_i)  × threat        ← 非捕食者回避威胁
```

**为什么两项都"有条件的"**（而不是简单加性）：捕食者才需要趋猎物、被吃风险高者才需要恐惧；无条件加性会让所有人行为趋同，**分化就消失了**。

### 2.3 权重载体（**请内评复核**）

| 权重 | 建议 | 理由 |
|---|---|---|
| `w_seek` | **接管预留位 `g17 DIET`**（食性 → **追猎倾向**） | 语义贴合；**可演化** ⇒ 符合"由进化自己发现权重"（fish 一贯主张） |
| `w_fear` | **固定配置字段**（默认 0；建议初值 0.5） | "怕被吃"是普遍理性，**不给它自由度** ⇒ 少一个可调参数、防"调参凑结果" |

⚠️ 接管 `g17` 必须走**加基因五步曲的变体**（不扩位、不改索引，符合 C3 G4 预留位接管规则）：
`Gene.DIET` 语义名/`GENE_SEMANTICS`/`GENE_TRAIT_NAMES`/`GENE_META` + `sim_core/src/genes.rs` 常量名 + `validate_gene_wiring` + 基因注册表测试。

## 三、L2 机动层（**移动距离可变的底层物理**）

### 3.1 🔴 一个决定性的好消息（实现成本大幅下降）

`_step_population` 的**步骤顺序**（`[代码]` 实测）：
```
step 5  移动        ← 猎物先动
step 5.5 捕食（g16） ← 捕食者后动，猎物只从"自己当前格的邻居"取
```
⇒ **逃脱机制天然存在**：猎物只要移出捕食者的邻格就抓不到。
⇒ **只需让"移动距离"可变，无需重构 tick 顺序、无需改捕食射程。**

### 3.2 首选方案（请老工在实现侧设计稿中细化/否决）

```
候选格集：从"1 圈邻居"扩展到"距离 ≤ 2"的球面邻域（r=1 与 r=2 的格合并）
采样    ：仍在候选集上按 softmax(score) 采样（**抽取次数不变 ⇒ 满足 H2**）
机动性  ：mob_eff[i] = g18_i × age_factor_i          ← g18 接管为 MOBILITY
          2 圈候选的加权 = mob_eff（mob 高者更可能被选到远处）
移动耗能：move_cost_ind × (1 + κ × (d² − 1))，d ∈ {1,2}，κ 建议 1.0 ⇒ d=2 时 **×4**
能量门槛：d = 2 需 energy > dash_min_energy（建议 0.1 × max_energy）⇒ **饱才能冲、饿冲不动**
捕食射程：**保持 1 格不变** ⇒ 追不上就吃不到
```
⇒ 天然产出三态：**快捕食者**（g16 高 + g18 高）/ **快逃跑者**（g16 低 + g18 高）/ **中间最差**（g18 低 ⇒ 追不到也逃不掉）。

⚠️ 球面拓扑注意：`r=2` 邻域须用**球面距离/两跳邻居表**，**不得**直接套 5×5 方形窗口（极点是特例，`neighbors(0)` 返回 cols 个邻居）。

### 3.3 ★ fish 指定：**老幼移速减小**（由机动性派生，而非外加惩罚）

```
age_factor:  幼体(age < 0.15×寿命)   → young_mob_mult（建议 0.55）
             成年(0.15–0.75)          → 1.0
             老年(age ≥ 0.75×寿命)    → old_mob_mult（建议 0.55）
```
⇒ 老幼跑不动 ⇒ 更常留在捕食者邻格 ⇒ **"捕食者更倾向捕食老幼"由物理自动产生**。

🔴 **由此带来一个设计简化（请内评裁定）**：R141 的「捕食脆弱性权重 `vuln = 1 + w_e·(1−能量比) + w_j·幼体 + w_o·老年`」**建议降级为备选** —— 因为"老幼脆弱"现在是**跑不动的物理后果**，不再需要一个外加的成功率乘子。
⇒ **两条不要同批开**（否则说不清是谁的锅，违反"一次改一件事"）。

## 五、🔴 必须新增的观测量（fish 指定：死亡时年龄/总寿命比率 + 总寿命数）

| 列/字段 | 定义 | 落点 |
|---|---|---|
| **`death_age_frac_hist_0..9`** | 死亡时 `age / lifespan(该个体 g3)` 的 **10-bin 直方图**（累计计数） | summary **与** CSV 各一份 |
| **`lifespan_mean / p50 / var`** | 存活个体的**总寿命**分布（= `2400 × lifespan_mult × (1+7·g3)`） | summary + CSV |
| `juvenile_mortality` / `adult_mortality` / `senile_mortality` | 分年龄组死亡率（分子分母均分列） | summary + CSV |
| `mob_mean / mob_std` | 机动性（g18）分布 | summary + CSV |
| `dash_frac` | 实际走出 **2 格**的移动占比（验证"这一层真在动"，防恒定退化） | summary + CSV |
| `frac_energy_gt_cap` | 能量超上限个体占比（应恒 0） | summary + CSV |
| `prey_avail_mean` / `threat_mean` | L1 两个感知量的实际取值（防恒定退化） | summary + CSV |

🔴 **`dash_frac` 与 `mob_std` 是"闸门指标"**：若 `mob_std ≈ 0` 或 `dash_frac ≈ 0` ⇒ 这一层没在动 ⇒ **不跑正式批**（R128 的冒烟闸门先例）。
