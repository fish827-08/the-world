# 协议 —— 云端自审与自优化（2026-09-24 立；依据 fish 09-24 指令 + R194）

> **背景**：fish 决定「后续的开发和实验全交云端，本地确定好方案和方向」⇒
> **本地（`[所有者]`）不再做逐阶段人工复核**。
> 本协议把**过去由外复核发现的问题**，反向编译成云端**机器可执行**的自审清单 + 自判三态 + 自优化回路。
>
> **目标**：在**没有人替你看**的条件下，仍然不让缺陷流进下一阶段。
> **归属**：本协议 = 云端的**交付门槛**，与 `AGENT.md §12`（Pre-Flight）、`§14.6`（阶段交付）、
> `§14.7`（Python 优先）**并列**；冲突时以本协议更严者为准。

## 〇 为什么这套能顶替人工复核（先复盘：过去命中过什么）

过去 9 次外复核共命中约 20 条，**没有一条需要"聪明"才能发现**——全部落在 **7 个可机械化的类型**里：

| 类 | 类型 | 真实事故（可追溯） | 当时本地怎么发现的 |
|---|---|---|---|
| **A** | **代码 ≠ 声明**（C9） | 13.4 `kill_patch_only` 注释写"只有斑块格会死"，实现是主通道全格生效（死 3600 格 = 50%）；F1 注释写"0~8"而实际被 **15× 弱化** | 逐行读代码 + 拿注释去核实现 |
| **B** | **传了没生效**（no-op） | 13.5 `bg_production_zero` **少一行接线 ⇒ 完全不生效**（老工实测发现）；13.4 胃容量 CLI"传了没进来" | 传参后**读回**产物，发现值没变 |
| **C** | **有测试 ≠ 不变量被验过** | 13.4 容量守恒**运行期漂移** −0.395%/6k（测试只在 `t=0` 断言 ⇒ 漂移不被发现） | 拿更长 tick 跑 + 逐点核对 |
| **D** | **不可自证**（C4） | R136 §一 增量 2：PC-1 三臂的 `switches.arm` **全为 `main`** ⇒ 臂间开关差无法从产物自证 | 打开产物找键，发现键在、值是错的 |
| **E** | **口径/极性/缺失值** | `resp` 关档应 `None` 却写 `0`；`cap_residual_frac`（仪器）vs `over_cap_frac`（现象）同名不同物；**净量 vs 单参数**（13.5 `eff×assim` 互相抵消 ⇒ 校准方向反转，R187） | 逐个读数问"它到底是什么口径" |
| **F** | **平台/环境** | a4 在 **Python 3.14 崩**（P0）；pytest `--basetemp` 复用 ⇒ **假失败**（实测 2 次）；`python -c` 反引号被 bash 吃掉（F-R33，5 次） | 换环境重跑 / 看真实报错栈 |
| **G** | **参数名/结构** | F-R21：preset 键写 `gain_multiplier`（下划线）而 argparse 只认 `--gain-multiplier` ⇒ 参数不被识别；F-R32：**同名 preset 被 dict 字面量静默覆盖** ⇒ E-027 跑错配置 | 静态扫源码 + 展开 preset 核参数 |

🔴 **结论**：这些全是「**检查姿势**」问题，不是「水平」问题。
⇒ 姿势可以写成清单、写成脚本 ⇒ **云端就能自查**。本协议就是这个转化。

## 一 🔴 三条反自欺护栏（不可协商）

| # | 护栏 | 为什么 |
|---|---|---|
| **1** | **判据不可自改**。派工单/协议/设计稿里的**判据、阈值、口径、目标值**，云端**只能执行，不能修改** | 自审若可自改判据，就退化成**自我欺骗**。历史上"反功效阈值"陷阱就是这么来的（先看效应量再倒推阈值）。任何"改阈值让它过"的念头 ⇒ **立刻按 Blocker B8 停下回板** |
| **2** | **没有证据包的回板 = 未完成**（见 §六） | 本地不逐阶段看，但会**事后抽验**。抽验的入口只能是证据包 |
| **3** | **必须做一次红队自审**（adversarial pass）：以"**假设我要推翻自己**"的立场，专门找**能让阴性结果无法解读**的点 | 阴性结果最常见的失效不是"机制无效"，而是"**前提不成立**"（C8：a4 硬编码 `distribution="uniform"` ⇒ 六批 null 不可读作"信号无用"）。这类点只有在敌对立场下才找得出来 |

**补充（第 4 条，操作层）**：关键检查**不许靠"我读过代码了"**，必须留下**脚本输出**。
⇒ 这是本协议与"请仔细检查"的全部区别。

## 二 自审清单

### 2.1 开工前（**已有制度，照旧**）

`AGENT.md §12` Pre-Flight C1–C9 + `§12.2.1` 前提冒烟（正式批前：**1 run × ≤2k tick**，逐项报开关/前提/多臂/守卫/**早期速率**）。
云端额外自查：本次改动**属于哪一类**（A–G）⇒ 在回板里点名。

### 2.2 交付前（**本协议新增，DEL-1 ~ DEL-10**）

| # | 查什么 | 怎么查（**机械**） | 判据 | 溯源 |
|---|---|---|---|---|
| **DEL-1** | **C7 关档逐位等价** | `python tools/self_audit.py digest` | 12 个基线文件**全绿**（实测 128 passed / 118s） | R181 |
| **DEL-2** | **文档声明 = 代码实际** | `python tools/self_audit.py c9` ＋ **把本次新写的注释逐条拿去核实现** | 无"未找到"字段；**每条新注释都能指到实现行** | C9（立起来当天两次命中） |
| **DEL-3** | **每个新开关"真生效"** | 冒烟传参 ⇒ ① `switches` 读回值 **== 传入值**；② 该量**轨迹与关档不同**（不同 ⇒ 非 no-op） | ①② 都过；**缺②就等于没证明** | 13.5 bgzero；13.4 胃容量 |
| **DEL-4** | **默认 = 现状** | 不传新参数 ⇒ digest 不变（同 DEL-1） | 逐位等价 | §14.6 阶段边界 |
| **DEL-5** | **preset 真能跑** | `python tools/self_audit.py cli` ＋ `batch_runner.py --preset X --dry-run` | 无未注册开关；**run 数 == 预期**；参数齐全无 Warning | F-R21 / F-R32 |
| **DEL-6** | **不变量在运行期成立** | 断言必须**包含 `t>0` 的采样点**（不只 `t=0`） | 至少 1 个运行期断言 | 13.4 容量漂移 |
| **DEL-7** | **缺失值语义** | 非适用档写 `None`，**禁写 0**（"没测" ≠ "测出零"） | grep 本次新增读数 | R120 |
| **DEL-8** | **测试真的覆到新代码**（**变异测试**） | 故意把新接线改坏（或注释掉）⇒ 测试**必须变红** ⇒ 恢复 | ≥1 例；**若改坏还全绿 ⇒ 测试无效** | "有测试" ≠ "不变量被验过" |
| **DEL-9** | **交付卫生** | `python tools/self_audit.py git` | 无未提交 / 无未推送 / 不在 `main` / HEAD 无入禁文件 | 零号规则 |
| **DEL-10** | **证据包** | `python tools/self_audit.py pack --phase Sx --include <路径>` | 生成 `MANIFEST.md` + `SHA256.txt` | 本协议 §六 |

🔴 **DEL-3 的 (2) 与 DEL-8 是本协议的核心发明**，专门堵 B 类（no-op）与 C 类（假测试）：
过去这两类**只能靠外复核发现**，因为写代码的人不会怀疑自己接的线。

## 三 🔴 一票否决 Blocker（命中任一 ⇒ **立即停，回板，不许自决**）

| # | Blocker | 为什么一票否决 |
|---|---|---|
| **B1** | C7 基线 digest **变了**，但**未登记纪元**或未声明"这是构造级变更" | 变纪元还跨批比较 ⇒ 整批结论不可读 |
| **B2** | 新开关**默认关时非逐位等价** | 旧批不可比；且违反 §14.6 阶段边界 |
| **B3** | 开关/参数**读了但不生效**（no-op），或**无法从产物读回**（C4 缺口） | 13.5 bgzero、R136 `switches.arm` 都属此类 ⇒ 产物不可解读 |
| **B4** | **文档/注释声明 ≠ 代码实际**（字段名/语义/阈值/单位对不上） | C9；会让复核者按错误前提判定 |
| **B5** | 判据在**无处理对照臂**上"过线"（探测器失效） | 判据失效 ⇒ 整批结论是噪声 |
| **B6** | **世代不足**（<30 代 或 <40k tick）却下"分化/涌现"结论 | 第四态「纪元不足·判据不可执行」；本项目已两次踩 |
| **B7** | **证据包缺失**，或代码**未 push**（零号规则：未 push 不算交付） | 无法事后抽验 |
| **B8** | **改动了判据 / 阈值 / 口径 / 目标 K**（任何"让它过"的改动） | 唯一会摧毁自审可信度的行为（护栏 1） |

**降级权**：B1–B8 只有 `[所有者]` 能降级为 `[非阻塞]`；**云端不得自行降级**。

## 四 自判三态（G / Y / R）

| 态 | 条件 | 处置 |
|---|---|---|
| 🟢 **G** | 全部 DEL 通过、无 Blocker | **可自主推进**（见 §八）；回板只需一句话 + 证据包路径 |
| 🟡 **Y** | 仅剩 `[非阻塞]` 项（不影响结论可读性） | 自修（**≤2 轮**，§五）；2 轮后仍黄 ⇒ **允许带着已登记的"已知偏离"推进**，但必须在回板里列为「已知偏离」并写清影响面 |
| 🔴 **R** | 命中任一 Blocker | **停，回板**；附最小复现 + 已试过哪几条路 + 卡点 |

🔴 **Y 的边界**：允许"带着偏离推进"的**只有**「不影响本阶段结论可读性」的项。
判断标准 = 一句话检验：**"如果这项偏离存在，本阶段读数还读得出来吗？"`读不出来` ⇒ 它就是 Blocker，不是 Y。**

## 五 自优化回路

```
       ┌──────────────────────────────────────────────┐
       │  写代码 / 改配置                             │
       └───────────────┬──────────────────────────────┘
                       v
              self_audit.py all  +  冒烟 + 红队自审
                       v
                 ┌─────┴─────┐
              🟢 G?          否
                 │            │
                 │            v
                 │    分类：可自修 / 不可自修
                 │       ├─ 可自修 ⇒ 修 ⇒ **重跑**（轮次 +1）
                 │       │            轮次 > 2 ⇒ 升级为"不可自修"
                 │       └─ 不可自修 ⇒ 回板（最小复现 + 已试 3 条路）
                 v
            交付（下一阶段内工作 / 回板）
```

🔴 **回路三条禁止**：
1. **不许为了过审而放宽检查**（改检查 = B8）；
2. **不许把 Blocker 自行降级**为"已知偏离"；
3. **不许"重跑一次碰运气"**——每次重跑必须在回板里说清**改了什么**；说不出改动 = 没改。

## 六 证据包规范

```bash
python tools/self_audit.py pack --phase S1 \
    --include _rerun_logs/<批名> \
    --include "experiments/*_out.txt" \
    --note "S1 冒烟：3 个 preset × 1 run × 2k"
```

产出（**只记哈希与元数据，不复制文件** ⇒ 不撑仓库）：

```
_audit/S1/MANIFEST.md     # 分支/HEAD/gitee 同步状态/未提交数/当前纪元/文件表/说明
_audit/S1/SHA256.txt      # sha256sum 格式，可 `sha256sum -c` 复核
```

🔴 **编写要求**：证据包必须**自解释** —— 事后抽验的人**先看证据包、后看代码**，
所以要能回答："这批跑的**是哪个档**（switches）？**改了什么**（diff/commit）？**结论的数从哪来**（原始日志）？"

## 七 回板模板（固定 7 问，**逐条答，不许空**）

```markdown
### [云端·开发] · YYYY-MM-DD HH:MM

**1. 本轮做了什么**：<阶段号 + 交付物 + commit 短哈希 + 分支>
**2. 自判态**：🟢 G / 🟡 Y / 🔴 R —— 逐类结论（A–G 七类，命中哪类、怎么查的）
**3. 🔴 读代码后发现的与设计稿/派工单不符之处**：<**空着 = 没读**（这是历史命中率最高的一问）>
**4. 已知偏离**：<有意的、非阻塞的；写清影响面与"为什么本阶段读数仍可读">
**5. 我「没测」什么**：<写 `n/a`，**禁写 0**；并说明为什么现在不需要测>
**6. 下一阶段需要什么**：<前置条件 / 需要的放行 / 预计 run 数×tick 数×seed 数 与耗时实测区间>
**7. 证据包**：`_audit/<phase>/MANIFEST.md` + `SHA256.txt`｜digest = `<值>`｜测试 = `<passed>/<failed>`
```

**答第 3 问的方法**：拿设计稿/派工单的**每一句断言**去核代码。本项目实测：这一问**几乎每次都命中**。

## 八 🔴 授权边界（"保证能推进"的落点）

| 动作 | 云端可否自主 | 备注 |
|---|---|---|
| 阶段**内**继续（写代码 / 测试 / 冒烟 / 加读数） | ✅ **G 时可自主** | 这是本协议要解锁的核心：**不必等本地点头** |
| 修 bug、补测试、加**读数列**（不改机制） | ✅ 可 | 加读数不算构造级变更 |
| 连续推进同阶段的多个小任务 | ✅ 可 | 只要每步自审 G |
| **进入下一阶段**（S1→S2…，§14.6） | 🔴 **必须回板等放行** | 阶段闸门不放开 |
| **跑正式批**（R117/R118） | 🔴 **必须 fish 明确命令** | 同计划内串行段可自动接力 |
| 改**判据 / 目标 K / 方案 / 纪元号** | 🔴 必须回板 | 护栏 1 |
| 合并到 `main`、推 `gitee-archive` | 🔴 禁止（`[所有者]` 执行） | 分支纪律 |
| **放宽自审检查 / 降级 Blocker** | 🔴 **禁止** | 护栏 1 |

> 🔴 **一句话**：**自审全绿 ⇒ 云端自己往前走；自审命中 Blocker ⇒ 停下回板。**
> 这两种情形之外的"等本地确认"都是**不必要的阻塞**。

## 九 工具

`tools/self_audit.py`（2026-09-24 入库，纯 stdlib，**只读**；`pack` 只写 `_audit/`）：

| 命令 | 查什么 | 耗时实测 |
|---|---|---|
| `all` | c9 + cli + git | ~3 s |
| `c9` | `AGENT.md §十三` 声明字段 vs 代码实际（当前 55 个字段，全部可找到） | 2.2 s |
| `cli` | 29 个 preset / 445 个 run 的开关 ↔ 目标脚本 argparse 注册（并报出用 `parse_known_args` 的脚本） | <1 s |
| `git` | 未提交 / 未推送 / 分支 / HEAD 入禁文件 | 1.0 s |
| `digest` | 跑 12 个含 C7 基线的测试文件 | **118 s**（128 passed） |
| `pack` | 生成证据包（MANIFEST.md + SHA256.txt） | <1 s |

> 🔴 工具**只覆盖 A/B/D/G 四类里的*静态可判*部分**；C/E/F 类与 A 类的"语义层"仍须人（你们自己）过。
> **工具绿 ≠ 自审绿**：脚本是**下限**，不是上限。

## 十 本地不审，但会**事后抽验**

- `[所有者]` 会**随机抽 1 个阶段**做独立复现：**先看证据包、后看代码**，不看回板叙述。
- 抽验失败 ⇒ ① 该阶段退回；② **该角色自审可信度下调**（后续阶段改为逐阶段审）。
- ⇒ 所以：**证据包的质量 = 你的自由度**。写得越自解释，抽验越省事，后面的门越松。
