## 四、正式批（tmux `world-e057`）

```bash
tmux new-session -d -s world-e057 \
  "cd ~/world/the-world/.worktrees/lh_e057_run && \
   ~/world/the-world/.venv/bin/python -u -m experiments.e057_repw_batch \
   --run --data-dir ~/world/the-world-data --lanes 2 2>&1 | tail -50 > ~/world/e057_tmux.out"
```

· **lane 数=2**：与 E-056 实证形制一致（`run_e056.sh` 的 `laneA & laneB & wait` = 2 并发 × 各 4 串行）。
  PI 令文写"4 lane"，2 核 1.9 G 机 4 并发会超卖内存 ⇒ 取 2 并已在板上披露（R387 假设入产出）。
· **断点续跑**：`--run` 重复执行即续 —— 判据 = CSV+summary 在场**且回显键核得过**（核不过 ⇒ 自愈重跑）；
  `--strict-resume` 退化为"在场即跳"。
· **fail-loud**：探针 rc≠0 或回显键（`reputation_weight_effective` / `info_structure_enabled_effective`
  / meta `rep_w`,`rep_w_solo` / `rd_enabled_effective` / `signal_alphabet_effective`）任一不符
  ⇒ 停该 lane、status 记 ABORT、整体 exit 4。非 Linux 平台 `--run` 直接拒（R117/R398 代码门）。
· **逐 run manifest**：`e057_repw/e057_manifest.json`（R277 四要素 rows/cols/patches/pop 逐字段
  + 全 argv + 载体 HEAD/base + 回显摘 + rc）；`e057_logs/status.txt` 逐 run 一行。
· **跑完 ping 砚**：`e057_logs/PING_YAN.txt` 落文本 + stdout 打印；实际板上/@ 由编排人执行
  （云机无人值守不写 `_share`，那是 share-lock 仪式领地）。
· 产物归档：`cd ~/world/the-world-data && git add e057_repw e057_logs && git commit && git push`。
