## 〇、先纠正一条：**"亲属关系"我们已经满足，不需要做**

我在派工前核了代码（`sphere_engine.py:4020/4026`）：

```python
self._flat  = np.concatenate([self._flat,  self._flat[ri]])
self._sub_r = np.concatenate([self._sub_r, self._sub_r[ri]])
# 子代继承亲代的格 ⇒ 同时继承亲代的亚格位置
```

⇒ **子代出生在亲代所在的格**（连亚格位置都一样）。

对照 Reggia et al. 2001（*Artificial Life* 7(1):3-32）的发现②：**"亲代选择与子代放置限制在物理邻域 ⇒ 促进信号演化"**
⇒ **我们不仅满足，而且比文献要求更强（同格 vs 邻域）**。
⇒ **所以这条不是缺失项，不要动它**（改了反而可能破坏）。

**"语言涌现最小充分条件"的真实缺口只有两条**（见 §五）。
