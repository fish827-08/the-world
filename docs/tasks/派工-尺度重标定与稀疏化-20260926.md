#### A2 — 机械化清点（**不许手写清单**）

| 项 | 内容 |
|---|---|
| **目的** | 上一轮我们**手写清单漏了整整一类**（"每 tick 概率"），且是**方向性偏差**。本步把它变成机器的事 |
| **做法** | 写 `tools/tick_denomination_audit.py`：① 遍历 `SimConfig` 全部数值字段；② 扫 `simulation/*.py` / `world/*.py` 里出现的**字面量数字**（排除注释）；③ 对每个数给出**建议分类** + 证据位置（字段名/文件:行） |
| **四类（必须四类，不是三类）** | ① 每 tick 速率 ⇒ **×k**｜② tick 时长 ⇒ **÷k**｜③ 每 tick 衰减 ⇒ **^k**｜④ 🔴 **每 tick 概率 ⇒ `1−(1−p)^k`** |
| **不变类** | 量（`max_energy`/`capacity`）、比例（`*_frac`/`*_mult`）、计数（`patch_count`/`subdiv`/`expectation_size`）、基因参数 |
| **验收** | 人工只做**复核**；产出表落 `docs/`；**未分类项 = 0** |
| **已知陷阱（我们踩过的）** | `pleasure.expectation_size` **不是时长**（是数组宽度，误除会 IndexError）｜`move_cost` 在 subpos 路径是"每 tick"，在整数格路径是"每事件"——**必须按实际读法分类** |

| **产出** | 一张 7 行的对照表（这是 A 的**主要证据**） |

### ☁️ 阶段 C：P0.3 —— `subpos` 真累加器 + `gain` 定标（**云端，A 通过后**）

| 项 | 内容 |
|---|---|
| **目的** | 干掉 **F2**：① 零步悬崖 ② 顶格坍缩 |
| **C1 累加器** | `steps = floor(speed×subdiv + 0.5)`（**每 tick 独立四舍五入**）⇒ 慢个体**永远不动**。<br>改成 `pos_frac += speed·subdiv; steps = floor(pos_frac); pos_frac -= steps`（亚格余量跨 tick 保留）⇒ **零步% → 0，与 subdiv 无关** |
| **🔴 登记陷阱** | 新状态数组 `_pos_frac` 必须**同改四处**：`__slots__` / `__init__` / **出生扩容** / **死亡压缩**（漏一处 ⇒ 与个体错位、静默失效，我们已踩过一次） |
| **C2 gain 定标** | `gain = v_max / ā`，**`ā` 必须在目标配置上实测**（我们测到 **0.5998**，幼体占比 89.4%）⇒ `gain ≈ 1.667 × v_max`。**默认关档不变** |
| **C3 档位数校验** | `R = v_max × subdiv`；累加器到位后 **R ≥ 5 即够**（不再需要 20）；仍要报 `R` 与实测各档占比 |
| **验收** | ① 单测 + 全量绿 ② `experiments/speed_quant_probe.py` 复测：零步% 应 **≈0**、顶格% 应 **≈0**、占用档 ≥ 5 ③ C7 未漂移（默认关） |
| **产出** | commit + 板上报「加速度占比 / 零步% / 顶格% / 档位直方图」 |
