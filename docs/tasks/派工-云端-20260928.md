## 三、云启 ⛅（2 核 / 4 GiB）—— 气味场 v1 原型

### T8 · 🔴 气味场原型（**新模块，冲突面最小**）
- **新建 `world/smell_field.py`**：多通道标量场，`S ← decay × (S + 注入) + 扩散`；个体**只读自己格**（不违反"感知 1 格"）；
- **必须内置稀疏 + 降采样（R235 §八，红线）**：
  1. **1/8 网格**上算长程扩散 + 双线性插值回全分辨率（成本 ÷~64）；
  2. **每 k = 4 tick 更新一次**（÷4）；
  3. **源注入稀疏**（复用 R233 T-E 信号场活跃集模式）；
  🔴 **禁止"每 tick 全场稠密卷积"**（会把 N=0 地板 13.63→0.13 ms/tick 的成果吃回去）。
- **默认全关**：`smell_channels` 默认**空** ⇒ 零成本、逐位不变（回滚点）；
- **通道可配**（食物/猎物/风险/同类），v1 只要求**接口齐 + ①食物通道可用**（批 A/B 由 R238 排期决定，本批不跑科学批）。
- **实测性能**：**配对口径**（相对值 + N + 并发），并报分解（扩散 / 注入 / 插值）；
- **建写入点守卫**：比照 `tests/test_sparse_write_guard.py`（AST 派生写点 + 标签齐全）；
- 快照：气味场是新的全场量 ⇒ 必须进 `save_snapshot`/`load_snapshot`（+14.7 MB/档 @4 通道，可接受）。

**交付**：`world/smell_field.py` + 测试 + 性能数字 + 默认关逐位不变证据。
