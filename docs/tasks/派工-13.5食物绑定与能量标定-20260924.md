## 二、设计方法：**先定 K，再反推参数**（不要逐个拍数字）

```
K = Σ_斑块 名义再生(质量/tick) ÷ 人均需求(质量/tick)
人均需求 = 人均支出(能量/tick) ÷ ( eat_efficiency × 吸收率 )
```

- `eat_efficiency = 3.0`（现状，**不动**：它是"质量→能量"的固定换算）
- **新增 `assim_herb = 0.4` / `assim_carn = 0.8`**（文献：食草 0.36–0.78、食肉 0.47–0.92）⇒ 素食者人均需求 **0.762 ÷ (3.0×0.4) = 0.635 质量/tick**（现状 0.254 的 2.5 倍）
- 背景归零后 `Σ_斑块 名义再生` 现状 = **680 质量/tick** ⇒ **K ≈ 680 / 0.635 ≈ 1071**
  ⇒ 已低于软顶 ✓ 但**偏低**（人口只剩现在 ~55%）；若希望 K≈1600，把斑块再生上调 `1600/1071 ≈ ×1.5`（`patch_regrowth_mult` 2.0 → **3.0**，或 `regrowth_rate` 0.5 → 0.75，**二选一，禁两个都动**）

🔴 **注意**：`人均支出 0.762` 是在**食物丰裕**下测的；食物紧时移动更多 ⇒ 支出上升 ⇒ 实际 K **会低于**解析值。⇒ **解析式只用于定初值，最终以 §四 实测为准**。

## 三、③ 能量标定的字段清单（全部新增，默认值 = 现状行为）

| 字段 | 建议初值 | 含义（人话） | 理由锚 |
|---|---|---|---|
| `max_energy` | 300 → **600** | 体能上限（"电池容量"） | fish 09-23 数值 |
| `stomach_cap_mass` | **新增独立**，25 质量（= 75 能量 = 体能 **12.5%**） | 胃容量（"饭盒大小"）。**必须独立**，否则它会跟着 `max_energy` 一起变大，把"体能↑胃↓"抵消 | R166 §三坑②；fish 批"胃降到体能 10–15%" |
| `eat_threshold_frac` | **0.6** | 胃低于容量的 60% 才进食（"不饿不吃"） | fish 09-23 |
| `starve_frac` | 0.30（= 180 能量） | **饿死**：能量 < 30% **且** 胃空 | fish 给 175 |
| `exhaust_frac` | 0.17（= 100 能量） | **力竭**：能量 < 17% ⇒ **无论胃里有没有食都死** | fish 给 100；防"抱着食物饿不死的僵尸态" |
| `assim_herb` / `assim_carn` | **0.4 / 0.8** | 吸收率（"吃进去有多少变成能量"） | 文献（Reichle 1971 等） |
| `assim_return_frac` | **1.0** | 未吸收部分**回流到本格植物池**（碎屑回流，闭环） | fish 09-23；文献 86.5% 能量走碎屑通道 |
| `photo_max` | 0.1 → **0** | 关光合（食物无关的能量来源） | fish "先不加光合" |

**双阈值语义（必须写进 docstring + 单测）**：
`energy < exhaust_frac×max_energy` ⇒ 死（累死，无论胃）；否则 `energy < starve_frac×max_energy 且 胃≈0` ⇒ 死（饿死）。

## 四、验收批（已是现成的方法，见 R185）

**素食者 K 实验**：`predation.enabled=False` + `photo_max=0` + `soft_cap_target=0` + `max_count=12000` + patchy，跑 **4000 tick**（≈3–5 分钟/档）。
- **主判据**：末态 N 落在 **1200–1900**
- **辅证**：饿死累计数 ≫ 老死（食物绑定签名）；`mean_energy` 明显低于初始 ~200；N 曲线呈"攀升→平台 + 微波动"
- **反退化**：不得灭绝；`N/K_pred` 应在 0.8–1.1（若显著 <0.8 ⇒ 说明解析式与实际脱节，须回读数据说明原因）
