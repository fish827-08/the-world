## 六、🔴 裁定：不许为提速放宽 C7 / 用 float32

fish 问"能不能改对拍"。**裁定：不改。** 三条理由：

1. **C7 的作用是证明"加速没改变结果"** —— 这是所有跨路径实验可比性的地基；放宽成容差 ⇒ 证明能力归零。
2. **float32 的风险不是"精度差一点"，是行为分岔**：浮点阈值判定变了 ⇒ 分支可能不同 ⇒ 连 RNG 消费路径都可能变 ⇒ **不是误差，是结果不同**。
3. **而且不需要它**：瓶颈是 Python 解释器开销，不是浮点吞吐量 ⇒ **float64 下向量化就能拿到大部分收益**。

⇒ 若将来真要 float32（如 GPU），那是**纪元级变更**（旧结论全部重测），须 fish 拍板。
