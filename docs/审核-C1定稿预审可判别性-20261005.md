### 🟠 F3 · J-B①（CV）的零模型按字面读法可**恒等退化** ⇒ 结构性假阴性

砚稿 §二 line 16：「CV 的零模型 = **块标签置换**」。`dens_<b> = kills_<b>/(occ_<b>×250)`，而 **CV 是 16 个块值的对称函数**：

- 若置换作用于**整块**（kills 与 occ 一起换标签）⇒ 每窗 `{dens_0..dens_15}` **多重集不变** ⇒ 每窗 CV 逐位不变 ⇒ `null ≡ observed` ⇒ **Δ ≡ 0 ⇒ J-B① 单侧下界永不过**；
- 若只换 **kills**、occ 留原位 ⇒ 零分布被块间**曝光异质性**主导（检验的是"kills 与曝光是否配对"，不是"空间可预报"），且与 J-A 的置换口径互相牵动。

⇒ **必须写死一种，并逐 statistic 声明置换对象**（J-A 的 AR1 / J-B① 的 CV / J-B② 的 Spearman 未必同一个置换）。CV 的恰当零模型我倾向 = **同质风险下的抽样噪声**（`kills_b ~ Binomial(Poisson)`，曝光 = `occ_b×250`，可解析或参数 bootstrap）——**这是建议，口径归砚，签署归砚+PI**。
