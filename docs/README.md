## 纪律

- 新文档请按主题放入 `docs/` 下对应子目录；**不要**堆在仓库根
- 根目录只保留"必读 / 强引用"的 4 个文件（09-17 瘦身后）
- 归档规则：文件移入 `_archive/<日期>-<批次>/` 并**在 `_archive/归档记录.md` 登记**（R115）
- 实验数据（`.npz`/`.csv`/`.json`）**不入主仓库**（见 `AGENT.md` §十一）
- **`_share/` 与 `docs/` 边界**（R111）：**活的交流**（板/共识/待办/路线图/花名册）留 `_share/`；**资料与产出物**（评估/设计/预注册/派工/快照）进 `docs/`。历史帖子中的 `_share/评估-xxx` 旧引用 → 按 `_share/README.md` §一.2 对照表找新位置
- **索引维护（R261）**：新成品文档入对应子目录（命名带主题+日期）；新增子目录或大批交付后**更新本索引**；`_` 工作夹中间产物不进 docs/（定稿才归档）；废弃文档移 `_archive/` 并登记（F-R10 不删）
- 🔴 **文件存放规则（R342，2026-10-03）—— 优先级高于本节**：
  - **临时文件** → 系统 `%TEMP%`，**用完即删**（判据："丢了会不会影响复现/审计"）；
  - **需留存** → **必须放在 `the-world/` 内**（落点表见 `_share/规则-文件存放.md`），
    其中**编排器/判读脚本/预注册/判读稿一律必须入库**（不入库 = **未交付**）；
  - **明令**：the-world 文件**不得存放在 `the-world/` 之外**（桌面/系统 temp 之外的其他目录一律违规）；
  - **落点纪律**：归档进 `_archive/`（可 git 追踪），❌ **不要丢进 `_trash_local/`**（未入库 = 复现不了 = 等于没整理）。
- **巨石重构立项（R260）**：`sphere_engine.py`（6250 行）/`config.py`（1626 行）拆分已立项——纯重构逐位等价（C7 基线不动），**批跑间歇期**由轻舟执行，拆后跑逐位对拍验证
