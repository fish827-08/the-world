## 四、纪律（现行为准）

- **临时文件** → 系统 `%TEMP%`，**用完即删**；**需留存件必须放在 `the-world/` 内**。
- **实验数据**（`.npz`/`.csv`/`.json`）**不入主仓**（→ 独立仓 `the-world-data/`）。
- **归档流程**：`git mv` 进 `_archive/<日期>-<批次>/` + 登记 `_archive/归档记录.md` + 更新 `_archive/INDEX.md`。
- **新增汇报** → `docs/汇报/`；**状态变化** → `docs/项目状态.md` 原位更新（记入文末更新记录）。
