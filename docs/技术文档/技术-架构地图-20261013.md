## 七、快照与配置指纹（跨档续跑为什么会被拦）

- 指纹：`SimConfig` 子配置经 `asdict` 自动进 `fingerprint()`（config.py 各新增组的注释均有"挂进 SimConfig ⇒ 经 asdict 自动进指纹"）⇒ **新增开关自动获得"跨档续跑被拦"**，这是设计而非缺陷。
- 旧快照兼容：`from_dict` 旧存档回退默认值；`SNAPSHOT_VERSION` 变更（D2 后 v3）时旧档加载失败是**有意**的。

## 八、已知地形坑（写代码前必读）

1. **极区邻接非对称**：`SphereWorld.neighbors()` 在极区（rows{0,1,rows-2,rows-1}）**有向**（极点处返回整圈）⇒ 任何"局部/增量"算法触及这些行必须回退全量路径（实例：`_update_patch_centroid_incremental:298` 返回 False ⇒ 引擎回退 `_build_patch_centroid`）。
2. **新个体数组必进两清单**：出生扩容（`_grow_id_arrays`:5415 附近）与死亡压缩（§2.4 段 9）漏一处 = 静默错位；另有 ASM/血条/亚格/ARS/记忆 v2 各自的注册注释可作模板。
3. **RNG 顺序 = 行为契约**：任何"顺手换个抽取顺序"的改动都会改变全部历史读数；双路径（Python/Rust）必须消费同序同数随机数（预生成传入）。
4. **稀疏/惰性路径的范围锁**：`sparse_fields` 与 rd 子集化路径有"仅在掩码恒定档可用"的前提（见 :2950 段注释）；改这些路径前先查 `enable_lazy`/`_rd_mults_ok` 的前提校验。
5. **默认关 = 逐位等价**：新机制必须"关档回到旧行为逐位一致"，回归红线是 C7 digest 基线 `(574887, 11266.746993)`（小世界冒烟）——动了默认路径必须对这条基线负责。
