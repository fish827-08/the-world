### 1.2 为什么"越暖越湿"且无副热带沙漠（数学事实）

`Pr = q(T)×(1+orographic×H)`、`Et = et_frac×q(T)`、`yield = max(Pr−Et,0)` ⇒

- 净产水 ∝ q(T) 单调递增（Magnus q 随 T 指数增）⇒ **纬度越暖 → 产水越多**（赤道单峰、单调向两极递减）；
- `Et = 0.5q` 固定比例（默认 et_frac=0.5）⇒ "桶永远满"，蒸散**不受地面水量约束** ⇒ 模型锁死"越暖越湿"，无论 T 怎么改（EBM 或 classic）都复现不出 20–30° 干旱带。
- ⇒ **两件事缺一不可**：①打破"桶永远满"（蒸发受地面/海洋水量约束，且有海洋这个水汽源）；②引入 Hadley 环流的下沉支（副热带下沉 → 抑制对流 → 干旱）。前者是 C0b+动态水循环（C4a-2/3），后者是 C1（静态）与 C4a（动态）。

### 2.1 气候理论：C1 的物理锚点与"EBM 不负责沙漠"（★关键裁定依据）

**① Held-Hou 1980 给"副热带下沉支"纬度锚点。** 轴对称、近无粘、热力驱动模型预测 Hadley 环宽 φ_H ∝ (gHΔθ)^½/(Ωa)（完整式含 5/3 系数；H≈对流层顶高度）：H=10 km、Δθ=50 K 时 ≈20.4°，与观测 ≈30° 同带；副热带下沉支即 20–30° 干旱带的位置依据。另：**无自转 + 纯气压梯度力 ⇒ 每半球单一热力直接环流**（赤道升、极地下沉、低层回流）——本项目零科氏力设置是该单胞模型最干净的验证环境（C4a 方向正确性背书）。
来源：[Held & Hou 1980, JAS 37(3):515–533](https://journals.ametsoc.org/view/journals/atsc/37/3/1520-0469_1980_037_0515_naasci_2_0_co_2.xml)｜[单胞/三胞教材章（INFLIBNET）](https://ebooks.inflibnet.ac.in/esp08/chapter/19-winds-and-global-circulation-of-winds/)

**② 经典 EBM 参数齐备，可直接作 C4a-1 温度背板。** C·∂T/∂t = S(1−α) − (A+BT) + D∇²T（依次=热惯性｜净短波｜线性化红外出射｜经向扩散）。climlab 默认 A=210 W/m²、B=2.0 W/(m²·K)、D=0.555 W/(m²·K)、C=10 m 水当量 ≈4.2×10⁷ J/(m²·K)；Budyko 课本档 A=211.1、B=1.55、Q₀=340 W/m²；反照率按温度阶跃（冰雪高值/其余 ≈0.3），North 1975 有 Legendre 解析解。粗算全球均值 T̄=(S̄(1−α)−A)/B=(340×0.7−210)/2≈+14 ℃——与地球实况一致，参数组自洽；本仓现有 insolation 档剖面（赤道 ≈+28℃、极点 ≈−23℃，零自由参数）本质就是该 EBM 年平稳态的形态 ⇒ **C4a-1 验收锚：EBM 自洽稳态不得显著偏离现剖面**（差 > 数 ℃ 需查参数/离散）。
来源：[climlab EBM API](https://climlab.readthedocs.io/en/latest/api/climlab.model.ebm.html)｜[Budyko 1969](https://doi.org/10.3402/tellusa.v21i5.10109)｜[North et al. 1981 综述](https://doi.org/10.1029/RG019i001p00091)｜[Sellers/Budyko 简史（AIP）](https://history.aip.org/climate/simple.htm)

**③ ★ 副热带沙漠不能靠 1D EBM"自洽"求出来——C1 必须用显式纬度调制。** 三条依据：a) 一维 EBM 状态量只有温度、**没有湿度自由度**（climlab 亦然；其 MeridionalMoistDiffusion 只改热输运、不改降水）；b) 沙漠的物理成因是**环流下沉支**（下沉 → 增温 → 相对湿度降 → 抑制对流），不是能量平衡的直接产物；c) 连 CMIP3–6 的 GCM 都存在双 ITCZ 系统性偏差——降水带形状连完整动力模式都难自洽。⇒ 简化气候学惯例做法 = **高斯湿带 × 副热带干槽**：P(φ)=P₀·exp(−[(φ−φ_ITCZ)/σ]²)，σ≈5–10°（实况 ITCZ 宽约 20 纬距），20–30° 强干旱。先例：World Orogen（ITCZ 湿带 + 15–30° 干旱带启发式）。
来源：[Britannica 沙漠成因](https://www.britannica.com/science/desert/Environment)｜[npj Clim Atmos Sci 2023（副热带降水极小=Hadley 下沉支）](https://www.nature.com/articles/s41612-023-00356-9)｜[中科院大气所（CMIP 双 ITCZ 偏差）](https://iap.cas.cn/gb/lunbo/202504/t20250427_7617451.html)｜[World Orogen](https://github.com/raguilar011095/planet_heightmap_generation)

**④ ITCZ 季节移动的最小表达（C2 备用）。** φ_ITCZ(t)=a·δ(t−Δ)，a≈0.4、Δ≈30 天起步可调；实况标定口径：ITCZ 月均 1 月≈5°S、7 月≈12–15°N，最南/最北相对至日滞后约 2–2.5 月（海陆不对称）。
来源：[气压带风带季节移动](https://baike.baidu.com/item/%E6%B0%94%E5%8E%8B%E5%B8%A6%E9%A3%8E%E5%B8%A6%E5%AD%A3%E8%8A%82%E7%A7%BB%E5%8A%A8)｜[ITCZ 位置实况](https://m.baike.so.com/doc/7895293-8169388.html)

**⑤ 热扩散 vs 热平流（v20 §二-A 取舍问题的回答）——不是二选一，是分阶段。** 静止世界无风可平流：C1/C4a-1 阶段用**隐式扩散**（D∇²T 代表风对热量的再分配；隐式积分避免显式扩散的步长限制）；C4a-2 起风场出现后，热量输运交给**显式平流**（−∇·(vT)），扩散降级为次网格/数值滤波项。climlab 的"湿扩散随 Clausius-Clapeyron 放大"（MeridionalMoistDiffusion，K=(D/C)·a²(1+f(T))，f 由相对湿度 0.8 标定）可作 C4a-2 前的过渡近似——只改热输运不改降水，正合我们"先能量后水分"的阶段划分。
来源：[MeridionalMoistDiffusion 源码](https://github.com/brian-rose/climlab/blob/master/climlab/dynamics/meridional_moist_diffusion.py)｜[季节循环与热容量 courseware](https://climlab.readthedocs.io/en/latest/courseware/Seasonal_cycle_and_heat_capacity.html)｜[climlab 仓库](https://github.com/brian-rose/climlab)

**⑥ 大气被地面加热的机制核对（B 项前提）。** 大气对太阳短波近乎透明，**地面吸收短波后以长波（红外）/感热/潜热加热大气**；高空冷源于远离地面热源 + 上升绝热冷却（干 ≈9.8 / 湿 ≈6 / 环境 ≈6.5 ℃/km，即我们 `lapse_c` 的语义）＋ 红外散热。⇒ 我们的单层大气温度强迫应来自 **EBM 算出的表面温度**（不是直接短波分布）；C4a-1 的因果链 = 表面温度 → 单层大气温度/质量 proxy → 气压 → 风。热扩散/热平流的取舍见 ⑤。
来源：[v18 蓝图 §二-B（机制链）](../设计文档/设计参考-物理地基蓝图-子系统与开源借鉴-20261014.md)｜[BAMS 2025 简化 AGCM（单 notebook 全 Python 动力核；实现上限参照）](https://doi.org/10.1175/BAMS-D-24-0196.1)

### 2.2 大气动力学与数值方法：单胞成立 + 通量形式有限体积选型

**① 单胞/热力直接环流成立条件核实。** 无自转 + 地表均一 + 唯一水平力为气压梯度力 ⇒ 赤道暖升、高空向极、极地冷沉、近地回流，**每半球一个热力直接环流圈**；加入科氏力才退化为三圈。单圈环流从"温差 → 密度 → 静力平衡 → 气压梯度"即可自洽推出，**不需要科氏力**。⇒ C4a 路线物理方向正确；零科氏力 = 最干净的单胞验证环境（C4a-4 再加自转）。
来源：[Hadley cell](https://en.wikipedia.org/wiki/Hadley_cell)｜[Atmospheric circulation](https://en.wikipedia.org/wiki/Atmospheric_circulation)｜[LibreTexts 教材（无自转=单胞）](https://bio.libretexts.org/Courses/Gettysburg_College/01%3A_Ecology_for_All/02%3A_The_Physical_Environment/2.06%3A_Atmospheric_and_Oceanic_Circulation)

**② 数值方法五选一对比 → 通量形式有限体积（flux-form FV）。**

| 方法 | 守恒 | 稳定性 / 成本 | 裁定 |
|---|---|---|---|
| a) **通量形式有限体积** | **离散全局守恒**（ExoCubed 实测总质量漂移 ≈ 初始质量的 10⁻¹⁰，仅剩舍入） | 显式受 CFL；迎风/近似 Riemann 通量稳定 | **选** ✓ |
| b) Stam Stable Fluids（半拉格朗日+投影） | **不守恒**（插值耗散；投影只保证离散无散） | 无条件稳定，但每步解泊松、成本高 | 否 |
| c) FHP 格子气自动机 | 微观精确（布尔粒子数守恒） | 布尔噪声大、自由度低、浮点机低效 | 否 |
| d) LBM | 碰撞步守恒 | 需立方对称网格，球面极区不友好 | 否 |
| e) 朴素"气压→梯度→风→平流"链 | 中心差分会漂移 | 最简，但长时累积漂移风险 | 仅作教学对照 |

理由：① 唯一同时满足"质量/水量/能量可精确对账"的选项（守恒是红线）；② lat-lon 上只需一维通量差分 + 纬度面积权（cosφ），numpy 切片可向量化、CPU 友好；③ 稳定条件清晰（CFL）、行为确定可重放；④ Rust 下沉核小（一维通量 + 限幅），对拍容易。
来源：[ExoCubed 论文（总质量漂移 ~10⁻¹⁰）](https://arxiv.org/html/2403.06844v1)｜[Ullrich 球面高阶 FV](https://gmd.copernicus.org/articles/18/725/2025/)｜[Stable Fluids 守恒性分析](https://arxiv.org/html/2404.01931v2)

**③ 平流格式：走 FFSL（通量形式半拉格朗日，Lin & Rood）。** upwind 单调但一阶强耗散；半拉格朗日**不天然守恒**（需专门质量订正）；MacCormack 二阶需限幅器防振荡；守恒标准做法 = **面通量×面积逐步累加**（NASA fv 动力核同款 FFSL），经纬网格按 cosφ 面积权 + 极区旋转网格/滤波。
来源：[Lin & Rood 引文（GMD 15:6891）](https://gmd.copernicus.org/articles/15/6891/2022/)｜[NASA FFSL 守恒通量形式](https://earth.gsfc.nasa.gov/meso/models/mmf)

**④ CFL 与子步解耦（性能架构的物理依据）。** 显式浅水稳定条件 Δt ≤ min(Δx/(|u|+√(gh)))。量级：120×240、R=6371 km ⇒ 赤道 Δx≈167 km，60° ≈84 km，极区趋零——**限制来自高纬收缩而非赤道**；取重力波速 √(gH)≈280 m/s（H≈8 km），赤道限制 Δt≲10 min，高纬更紧 ⇒ 建议 3 子步 × Δt≈100–200 s，不够则**加极地滤波而非全局限小步**。"大气子步与主 tick 解耦" = split-explicit，是业务模式标准做法。
来源：[CFL 条件 Δt≤min Δx/(|u|+√gh)](https://link.springer.com/article/10.1007/s40808-025-02566-x)｜[纬度收缩需极地滤波（ExoCubed）](https://arxiv.org/html/2403.06844v1)

**⑤ 蒸发受地面水量约束（打破"越暖越湿"的标准答案）。** Manabe 1969 土壤水桶：容量 W_max（常 15 cm），降水入桶、超容溢出为径流，蒸散=β×潜在蒸散、β=W/W_max；FAO-56 双系数法给出可操作的干燥限制（Ke 受 TEW 限制、两阶段蒸发以 REW 分界——REW 常用 5–12 mm）。**落地为一句话规则：E_actual = min(E_potential, W_avail/Δt)**——天然防负水量、保质量守恒。
来源：[水桶模式（Manabe 1969 转引）](http://www.adearth.ac.cn/CN/10.11867/j.issn.1001-8166.1994.05.0026)｜[FAO-56 第 7 章（Ke/TEW/REW）](https://www.fao.org/4/x0490e/x0490e0c.htm)

**⑥ 无垂直维时"上升/下沉"的代理。** 浅水连续方程：垂直速度沿高度线性、由水平散度驱动 ⇒ **辐合=上升、辐散=下沉** 是有严格依据的代理；ω_proxy = −∇·(h·v) 可直接驱动对流/降水触发与温度反馈；单层浅水参数化深对流可用"质量汇"项。
来源：[GFD 讲义（w 与水平散度）](https://wk.baidu.com/view/33becf7dba0d6c85ec3a87c24028915f804d84ad.html)｜[浅水质量汇参数化（WCD）](https://wcd.copernicus.org/articles/5/1013/2024/)

**⑦ 工程参照。** BAMS 2025 简化物理 AGCM：**单 Jupyter notebook、动力核全 Python（无 Fortran）**、笔记本可跑 ⇒ 纯 numpy CPU 大气模式可行（C4a 同路的上限参照）。qgs（Python 两层准地转 + 陆面 + 浅水海洋，JOSS 论文）：学其模块化与验证文化，不学其准地转简化动力学。
来源：[BAMS 2025, DOI 10.1175/BAMS-D-24-0196.1](https://doi.org/10.1175/BAMS-D-24-0196.1)｜[qgs](https://github.com/Climdyn/qgs)｜[JOSS 10.21105/joss.02597](https://doi.org/10.21105/joss.02597)

### 2.3 水文与热物性：C0b 全套做法可核实、现有算法可复用

**① 海平面 = 目标陆比的分位阈值（非固定 0.5）。** 程序化星球主流做法：归一化高度场 → 按目标陆比取分位阈值定海平面；分布重映射 e'=e^γ（γ<1）调海岸线复杂度（γ<1 海岸更碎、陆比升高）；水位阈值同时定义生物群系分区。参照物：地球海 70.8% / 陆 29.2%；**大陆架 = 0～−200 m 浅海**（全球均宽 75–78 km、坡折外缘均深 130 m）。
来源：[Red Blob terrain-from-noise](https://www.redblobgames.com/maps/terrain-from-noise/)｜[大陆架均宽/深度](https://baike.sogou.com/v50214.htm)

**② 内流湖（盐湖）判定 = 复用现有 filled 场，零新算法。** priority-flood 论文给出 spill elevation 定义（使洼地能向外排水所需的最低抬升高程）；**"抬升格（filled>original）= 水体面、水位取 spill elevation" 是本项目的建模约定**（论文只提供算法与高程语义）；**沿溢流链是否达海**二分：达海 = 过水淡水湖、不达 = 终端内流湖（盐湖）。嵌套盆地参考 depression hierarchy；HydroSHEDS 用 ENDO 字段标内流。⇒ C0b 的湖模块只需"贴标签"层。
来源：[Barnes 2014 priority-flood](https://arxiv.org/abs/1511.04463)｜[嵌套洼地层级（spill elevation 定义）](https://pmc.ncbi.nlm.nih.gov/articles/PMC7995241/)

**③ 河流/下切。** stream-power：E=K·A^m·S^n，n≈1、m=0.5（0.4–0.6）为标准，模拟常用 K≈1e-5（率定范围 3.7e-6～9.5e-5）；Braun & Willett 2013 的 O(n) 隐式解为工程标准。本期不引入动态下切（静态世界）；A^mS^n 先当"河网强度标签"备用。
来源：[eSurf 6/77（m/k 范围）](https://esurf.copernicus.org/articles/6/77/2018/)｜[Braun & Willett 2013](https://doi.org/10.1016/j.geomorph.2012.10.008)

**④ 热物性三件套数值表（C0b 表面类型逐格赋值用）。**
- 反照率 α：新雪 .80–.90｜海冰 .50–.70｜沙漠 .40｜裸土 .17｜草地 .25｜森林 .17–.23｜**海洋 ≈.06（太阳高度角大时；近垂直入射 .02–.06，低角度迅速上升，掠射可 >.5）**，全天均 .068–.093；

来源：[反照率表](https://zh.wikipedia.org/wiki/%E5%8F%8D%E7%85%A7%E7%8E%87)｜[比热表](https://www.engineeringtoolbox.com/specific-heat-capacity-d_391.html)｜[导热率表](https://www.engineeringtoolbox.com/thermal-conductivity-d_429.html)｜[海洋混合层](https://www.zgbk.com/ecph/words?ID=171892)｜[反照率与太阳角度（海洋值；sciencenotes）](https://sciencenotes.org/albedo-in-science-definition-values-importance/)｜[climlab 季节循环与热容量（slab 海洋热容口径）](https://climlab.readthedocs.io/en/latest/courseware/Seasonal_cycle_and_heat_capacity.html)

## 5. 推荐本期落地方案：C0b + C1（实施设计与预注册要点；不含代码）

### 5.1 总原则

- 全部为**构造期静态**变更（零 tick 成本）；挂在 `env_field` 开关族下，**默认关**；关档 = 现行默认**逐位等价**（C7 回滚点；digest 对拍法沿用裁定二流程，保真基线 D0=`42143a45…4242`）。
- **无新随机需求**：不新增 RNG 消费（C0b 的阈值/标签/排序全确定；无随机重映射）。
- **无 Rust 改动**：C0b/C1 只改 Python 构造期场与因子；`sim_core` 不消费新入参 ⇒ 沿用现有 `env∧sim_core` fail-loud 闸（开档即炸，禁静默 no-op）。

### 5.2 C0b 设计（真实海拔 + 海平面 + 海/湖/河/陆表面层）

**文件面**：

| 文件 | 改动 |
|---|---|
| `world/env_field.py` | 主改动：H 米制化 → 海平面分位阈值 → 可选 e^γ 重映射 → priority-flood 种子由"极点行"改"海平面格" → 湖=`filled>H` → 溢流链标签（达海/不达）→ 河 = receivers 终点在海/湖 且 acc≥P98 → `surface_type` 层产出 + `sea_level_m/lake_mask/salt_lake_mask` 读数 |
| `simulation/config.py` | `EnvFieldConfig` 增字段（下表）+ 断言（陆比∈(0,1)、shelf≥0、γ>0、峰高>0 等）+ `from_dict` 向后兼容（旧档无键 ⇒ 回退默认=关） |
| `world/resource_field.py` | **C0b-② 子步**（第二笔提交）：海洋掩码乘性入口（同 patch/bg 掩码族，逐元素乘 ⇒ 子集语义同构；与 rd/sparse 的组合按现有 fail-loud 纪律处理） |
| `simulation/sphere_engine.py` | 接线透传新字段 + `env_note` 追加一行（开档标记）；两闸不动 |

**建议新字段**（全部默认关/安全值）：`c0b_enabled=False`｜`land_fraction=0.30`（目标陆比；地球档 0.292）｜`peak_altitude_m=4500.0`（H 归一化→米）｜`shelf_depth_m=200.0`｜`coast_gamma=1.0`（e^γ 重映射指数）。派生量不进配置（sea_level 分位由 land_fraction 定义）。

**机制要点**：
- 海平面 = 按目标陆比在 H_m 上取**分位阈值**（非固定 0.5；消"固定阈值调不准陆比"问题）；e^γ 重映射调海岸复杂度（γ<1 更碎）；
- priority-flood 种子 = 海洋格（H_m ≤ sea_level）——**取消"极点唯一出水口"**（现 seed42 被填 50.8% 成极海，失真）；球面无边界，海面即天然出口集合；
- 湖 = `filled > H_m`（现字段 `flood_filled` 已有同义计数，复用语义）；**淡水湖 vs 盐湖 = 溢出链沿 receivers 指针是否到达海洋**（O(n) 并查集/标签传播；嵌套盆地本期按"单层溢流面"近似，depression hierarchy 留待需要时）；
- 大陆架 = ocean ∧ (H_m > sea_level − shelf_depth_m)（浅海分段）；
- 河 = receivers 链终点 ∈ {海, 湖} 且 acc≥P98（river_mask 重定义；旧 P98 读数层保留兼容）。

**守恒不变量（构造期一次核账，进探针与单测）**：① 海陆面积比 == 1−land_fraction（分位定义 ⇒ 恒等，容差 1e-9）；② 流域闭合：Σ 陆地产水 = Σ 入海 + Σ 入湖蓄 + Σ 盐湖蓄（浮点容差）；③ surface_type 计数与 filled/acc 掩码逐位一致。

**性能预算**：分位 + 重映射 O(n)（毫秒级）；priority-flood 仅换种子（复杂度不变）；溢流链并查集 O(n·α)。合计估算 **+<0.5 s @s2**（现 2.52 s 基线上）——零 tick 成本。

**判据（开档验收）**：seed42 海比 ∈ 目标 ±0.5%；湖数 >0 且最大湖流域闭合；"极海"消失（对照 50.8% 失真读数）；诊断对照 = 陆比扫 0.2/0.3/0.5。

**零模型**：关档（现行"极点出水口"版，逐位等价）；对照臂 = 海陆比扫描。

### 5.3 C1 设计（静态副热带沙漠：显式纬度调制带）

**形式（推荐双高斯带）**：`Pr = q(T) × (1 + orographic×H) × band(φ)`，其中
`band(φ) = 1 + A_wet·G((φ−φ_itcz)/σ_wet) − A_dry·G((φ−φ_dry)/σ_dry)`，G(x)=exp(−x²)。
默认（可调）：φ_itcz=0°（赤道）、σ_wet≈8°（实况 ITCZ 宽 ≈20 纬距）、φ_dry≈±27°（Held-Hou 20–30° 带内）、σ_dry≈12°；幅度 A_wet/A_dry 按"**副热带谷底 Pr < Et ⇒ yield=0**"标定（默认 et_frac=0.5 ⇒ 谷底 band <0.5）。**band 面积权均值归一=1**（保持全球产水总量不变，对照干净；同 f_g/f_c 归一纪律）。

**机理注（重要）**：净产水 = max(Pr − Et, 0) ⇒ 只要副热带 band 压到 <et_frac，**C1 不依赖蒸发约束即可造出零产水（沙漠）带**——"桶不再永远满"（蒸发受地面水约束）留给 C4a-2 做动态版。C1 只修**降水侧形状**，不碰 Et。

**文件面**：`world/env_field.py` 的 Pr 行 ×band(φ) + `_factor` 前归一；`config.py` 增 `c1_enabled=False`、`itcz_deg=0.0`、`itcz_width_deg=8.0`、`dry_deg=27.0`、`dry_width_deg=12.0`、`wet_amp`、`dry_amp`（断言 + 旧档回退默认）。

**判据（开档验收，场级）**：
① 纬带剖面三层结构：赤道峰 / 20–30° 谷（谷底 yield≈0，带宽 ≈15–25°）/ 温带次峰；
② k=2 尺度（裁定三分尺度判据）纬向结构可见、k≥3（地形尺度）不引入混杂；
③ C0b 同开时：同纬度沿海 vs 内陆梯度（海陆对比）。

**零模型**：关档逐位等价；对照臂 = 无 band（现默认）。

**预注册要点（实施后跑批前锁死；跑批另报 budget、守机时窗）**：装置 = s2 / 2000t / N=0（纯场诊断，非生物臂）；seed42 + ≥3 seeds 形态稳健性；读数 = 纬带剖面 + 海陆对比 + 流域闭合；主判据 = 副热带带存在（谷/邻带比 < 阈值）；辅 = 温带次峰与赤道峰位置。场级跑批规模低于四臂，窗内可完成。

### 5.4 快照 / 测试 / 纪律清单

- **快照**：新字段进 config 指纹（旧存档回退默认）；surface_type 等静态层由 seed+config **确定性重建**（不落盘）——与 env 场现行策略一致；跨版本续跑保真若成需求，随 SNAPSHOT_VERSION 升级评估。

**依赖顺序一句话**：②③（本期，静态空间格局）→ ①（能量自洽 = 风的燃料）→ ④（水循环闭合，动态）→ ⑤（生物接口）。前三件完成后即满足"空间异质性 + 时间异质性齐备且全部守恒可对拍"的放生物门槛（v18 §四）。

**每步通用纪律**（与全报告一致，不重复展开）：新机制默认关 + 关档逐位等价；判据未过不下"涌现"结论（L0–L4 阶梯）；跑批先预注册、另报 budget、守机时窗；诊断数据落 the-world-data。

**其余项：何时做 / 不做（触发条件）**：

| 项 | 裁定 | 触发条件 / 说明 |
|---|---|---|
| 河流侵蚀/沉积（D 层，stream-power m=0.5 / n=1 / K≈1e-5） | 值得做，**不阻塞** | 需要"地貌动态"表现（河谷下切/三角洲可见）时再排期；在此之前 A^mS^n 先当"河网强度标签"备用（§2.3-③） |
| 雪线/冰川（+反照率正反馈） | 值得做，**不阻塞** | ① 落地后（温度可算、α 表已备）且需要寒区分层（生物/群系用）时 |
| 风生洋流（Stommel–Munk / Sverdrup）+ 海洋热库 | 值得做，**不阻塞** | ① 风场存在后自然接入（风应力旋度驱动）；海洋 50 m 混合层热容随①一并落（§2.3-④） |
| C2 雨带季节移动 | 廉价，**排期** | 现有 δ(t) 直接接 ITCZ 相位 φ_ITCZ(t)=a·δ(t−Δ)（§2.1-④）；排 C0b/C1 之后、随③可选 |
| C3 随机天气事件 | **排队，硬触发** | **行为层（储藏/对冲/迁徙）实验启动前必须就位**——静态气候在数学上排除这些策略的选择优势（§2.4-⑧）；标准件照抄 + 预注册 |
| 板块构造/地幔对流（GAIA） | **不做** | 深时尺度（百万年）对生物演化无意义；静态噪声 + 侵蚀足够（v18 §三-D） |
| 完整 GCM / 云微物理 / 逐线辐射传输 | **不做** | 一律参数化替代（EBM + 单层浅水 + 桶模型）；复杂度上限参照 = BAMS 2025 单 notebook |
| 冰期/米兰科维奇循环 | **不做** | 除非将来研究深时气候（当前无计划） |
