### 教训 1 — 「K=2 双稳态」是背景倍率抽奖 bug，不是涌现

- **现象**：批 E-037（2026-09-28~29，`s2_depletion_probe`）曾判「rd 产生 K=2 留守/出走双稳态 ⇒ C4 达成，S3 放行」（`docs/实验记录.md:51`）。后经复核，该装置落入「抽奖」族，结论**不再被引用为涌现证据**，相关脚本归档、**禁止引用其结论**（`experiments/archive/README.md`）。
- **根因**：`ResourceDynamics.from_field` 曾用 `cap[~mask][0]`（背景**第 0 个格**）反推全局背景倍率。旧装置带低产能带（`bg_low_prod_frac=0.4`）时，该格恰好落在带内的概率 ≈40% ⇒ 同一装置随机分成 A 支「纯斑块」/ B 支「全图可产」两支。`[实测]` 12 个 world：旧档 3/12 判成 B 支，且恰好是当时 60k 实测的 167/170/172 三个 B 支 ⇒ 根因确凿。
- **现在的防线**（三层）：
  1. **装置层**：R320（2026-10-01，fish 拍板）撤绿洲带——`bg_low_prod_frac=0.0` ⇒ 背景格容量恒 0 ⇒ 反推判据恒真 ⇒ 抽奖从参数上消失（`tools/device_presets.py:34-44`）。
  2. **代码层**：R328 甲案——`from_field` 直读显式字段 `rfield.bg_production_zero`，不再反推（`world/resource_dynamics.py:213-222`，已入 main）。
  3. **回归守卫**：`tools/check_bg_lottery.py`（防将来重开绿洲带时抽奖复活）。
- **通用读法**：任何「装置级随机分叉」的读数，先问一句「这个分叉是参数抽出来的，还是动力学跑出来的」。

### 教训 2 — Magnus 纬度压印：H 置换零模型不纯净

- **现象**：纯斑块四臂批的 arm2 是「H 空间置换零模型」（打破地形的空间结构，用于空间归因对照）。复核发现**置换后水分场仍带纬度梯度** ⇒ arm2 不是纯净的几何零模型；叠加主判据 fair-k 复核下四臂不可分 ⇒ 2026-10-13 owner 裁定 **C：本批不下单边结论**。
- **根因**（代码级）：W（水分）链 = `H →(lapse-rate)→ T →(Magnus 饱和水汽压)→ q → Pr/Et → W`。温度基准 `base_t = lt.base_temperature(cells)` 是**纬度的函数**（`world/env_field.py:173-175`）⇒ 置换 H 只打断了地形通道，**base_t 纬度暗通道仍在**。
- **现在的防线**：预注册显式声明该混杂；下一批 amend 预注册做**去混杂设计**（臂内关 base_t 纬度梯度，或先把 W 对 `|lat|` 回归取残差再入聚类）；聚类主判据**钉死 fixed-k**（不随数据选 k）。裁决与设计口径：`docs/汇报/话事人传达-20261013-C裁定与接手开发任务.md` §一；本批读数 `docs/汇报/汇报-20261011-纯斑块世界四臂.md`。
- **通用读法**：置换零模型要证「置换后**所有**空间结构都被打断」——沿链路逐项查有没有别的空间通道。
- **关联可固化发现**：本批最稳的差动信号 = `runoff_gain` 造出「径流型簇」（arm2/arm4 有、arm3 无），地形连贯性改变其形态（碎块 vs 连贯河道）。

### 教训 3 — W(gate) 的 0.582 跳跃间断：对账脚本会静默错一位

- **现象**：旧稿引用 `W(g)` 表「`g=.3 → 1.0720`」，据此对账会得错值；严格 `g > gate` 下实际 `W(0.3) = 0.49`——那个 1.0720 是**右极限**。
- **根因**：`W₀(g) = p(g)·s₀(g)·E_prey·r` 整块定义在 `𝟙[g > gate]` 掩码上；`g = gate` 恰是格点，函数在 `g=gate` 处**跳跃间断**（0.582 的台阶）。任何拿 `W(gate)` 单点对账的脚本都会静默跨过间断。
- **现在的防线**：`s0_kernel/arms.py` 用 `gate_inclusive` 参数**显式暴露边界约定**（默认 `False` = 引擎字面语义）；预注册里落字更正原引用（`docs/预注册/落笔-双臂S0-H2-20261009.md:128`）。
- **锚点**：`s0_kernel/arms.py:19-22`、`:108-122`；原始表格 `docs/设计文档/证伪-双峰在现行捕食公式下不可能-20260924.md:142`。
- **通用读法**：引用公式表时写清定义域与边界含不含；间断点两侧取值分开列。

### 教训 4 — 性能不能线性外推（种群越大越慢）

- **现象**：短跑（小种群）外推 2.9 ms/tick；云机 20,000 tick 实测 ≈12.2 ms/tick（慢 ~4×）——owner 早就提醒过「种群增大减速」。
- **根因**：单 tick 成本随存活数 N 上升（向量化操作、记忆/感知段都随 N 放大）；短跑起始 N=200，长跑爬到几千上万 ⇒ 用短跑均摊值外推长批必然低估。历史同期读数 151–181 ms/tick @N2000-2300 同向。
- **现在的防线**：批预算按**实测 tick 成本 + 种群曲线**报（拿不准就报区间 + 分批）；新机制改动前先跑 1 run × 2000 tick 性能冒烟（C1 硬门禁）；机时墙 R228（23:00 止、24:00 断电）兜底。同族教训：E-051 编排器「外推 2.8 h 实测 6.3 h」（`docs/实验记录.md:50`）。
- **锚点**：归档原帖 `_archive/2026-10-10-退役团队-归档/_share/讨论板.md:11411`。

### 教训 5 — 约 50 个测试红是环境族（GBK 解码），不是代码回归

- **现象**：本机全量 pytest ≈53 红，首次见到极易误判为「刚改崩了」。
- **根因**：子进程 stdout 写 UTF-8，父进程 `subprocess.run(text=True)` 未指定 encoding ⇒ 中文 Windows 上按 locale **GBK 解码** ⇒ reader 线程 `UnicodeDecodeError` ⇒ output=None ⇒ 下游 TypeError/mojibake。相关测试最后改动在 10-05/10-07，属**存量环境族**，与代码改动无关。
- **现在的防线**：对账纪律 =「失败集合与清单一致、零新增才算过」，不看 pass 数绝对值；新写 subprocess 测试**两端钉 UTF-8**（env `PYTHONIOENCODING=utf-8` + `run(encoding="utf-8")`）；脚本入口 reconfigure stdout（样板 `experiments/run_bare_world.py:204-208`）。
- **清单与口径**：`ONBOARDING.md` §1.4（52 固定 + 1 并发 flake；含 1 例 ULP 最末位）。

### 教训 6 — `kin` 通道曾是 ones 占位假实现（无真实亲缘）

- **现象**：气味场 `kin` 通道曾被当成「真实亲缘信号」使用/解读。
- **根因**：该通道的数据源只是 `np.ones(P)`——全体存活个体**等权**覆盖，没有任何亲缘计算（曾为占位实现）。
- **现况与防线**（如实登记语义，防复读旧解读）：`kin` 源 = 全体存活个体（与 `prey` **同源**，读端用途不同；`simulation/sphere_engine.py:2877`、`:2898`）；「聚集（join）」响应由 **g13 基因**门控：`sal_join = w_join·Ŝ_kin(own)·(2·g13−1)`（`:3253-3258`）⇒ 它是「同种在场强度 + 个体结群倾向」，**不是亲缘识别**。任何「kin selection / 亲缘」读法必须先核这一点。
- **锚点**：`world/smell_field.py:52`（kin 通道语义表）；`simulation/config.py:1308`（四通道裁定）。

### 教训 7 — 旧大批实验无效的原因族：引用历史结论前必须查有效性

- **现象**：历史批结论直接拿来对比，常发现不可复现/不自洽。
- **根因**（三类，常叠加）：
  1. **默认值回落**——探针忘传装置参数 ⇒ 静默吃代码默认（60×120 微型档），跑出「另一个装置」的数据而无任何提示（R275/批 A 事故 ⇒ R278 §三 防呆立项）；
  2. **半硬编码**——档位参数写死在脚本里，跨档对比时口径漂移；
  3. **抽奖 bug**（教训 1 族）。
- **现在的防线**：
  1. 装置预设防呆 `--device s2`：未知档 fail-loud、显式值优先并打印覆盖提示、回显实际生效全字段（`tools/device_presets.py` 模块 docstring 五条原则）；
  2. **R5.6 纪律**：正式批必须显式 `--device s2`，吃默认值 ⇒ 与历史读数不可比；
  3. 归档脚本逐件标注「哪条线、为何归档、对应结论是否有效」——K=2 族**仅供复现、禁引结论**（`experiments/archive/README.md`、`tools/archive/README.md`）。
- **通用读法**：引用任何历史结论前，先查 ① 装置档 ② 代码树（manifest/code_tree_sha256）③ 该装置是否在「无效族」清单里。

## 二、关键决策记录（6 条）

### D1 — 撤 `patch_mask` 人为倍率层：斑块不自组织于「人为规定」

- **决策**（PI 裁 2026-10-08，采纳「实质 = 撤人为倍率层」的读法）：不再用二值斑块掩码乘倍率来「人为规定哪块地高产」，产能空间格局改由底层规则自组织生成（地形 → 水分 → 产能因子）。目标形态 (a)：`patch_mask` 退出产能/再生、移动评分与感知、Rust 入参等**行为路**，只保留 ① 记忆质心来源 ② 事后分组维度；形态 (b)（数组整个删）留作备选、不预锁。
- **为什么**：fish 原话「斑块/森林·草原·荒漠群系改成底层规则实现，**不人为规定**」——人为倍率层等于把答案写进装置；同时红线 2 写死：**群系标签永不进判据前置**（否则判读等于换皮重生）。
- **现状**：ENV 场模块已落地（`world/env_field.py`，默认关 = 旧行为逐位等价）；产能格局的机制性替换在纯斑块世界线推进中（四臂批 → 裁定 C → amend 预注册后下一批）。
- **锚点**：`docs/设计文档/设计-ENV-FIELD-物理场与格子产能-20261008.md` §二/§六（`:29`、`:209`、`:222`）。

### D2 — 纯斑块世界先行：先无生物环境，再放生物

- **决策**（owner 拍板 2026-10-11，修订版）：先做**无生物**的底层规则世界（斑块 → 地形 → 河流/汇流），看斑块会不会**自发分化**成不同类型；全规则一次到位、≤4 实验（一半对照）、单 run ≤2000 tick。
- **为什么**：有生物时，生物行为会把底层规则的信号搅进「生态读数」里，机制归因不干净；无生物装置里，任何分化只能是底层规则造出来的。
- **现状**：M0 装置 `experiments/run_bare_world.py`（四臂）+ ENV 场在 main；四臂批已跑并裁 C（见教训 2）。
- **锚点**：`docs/设计文档/设计-纯斑块世界-底层规则自组织-20261011.md`（§十五 拍板记录）；`docs/项目状态.md` v6/v7/v8。

### D3 — 禁 GPU

- **决策**：全项目纯 CPU（NumPy + Rust/多线程）；GPU 不进现役路径。
- **为什么**：① **逐位对拍（C7）在 GPU float 上不可保证**——浮点非结合性 + 驱动/硬件差异 ⇒ 行为分岔，「同配置逐位一致」直接失效；② 当前规模（480×960）下数据传输开销 > 计算收益。R9.3 明文：**C7 不放宽、不用 float32**（R210 裁定：「放宽 ⇒ 证明能力归零；float32 ⇒ 行为分岔」）。
- **现状**：GPU 是否在「扩大世界 10 倍后」评估仅为远期备注（`docs/技术文档/L7d-Rayon并行化技术文档.md:184`），不是路线。
- **锚点**：`docs/设计总档案/AI-设计总档案-v1.4-定稿.md:424-425`、`:734`。

### D4 — 坚持逐位一致（C7）：宁慢不放宽

- **决策**：Python↔Rust 双路径（以及一切优化改写的路径）**同配置逐位对拍**是回归红线：函数级 + 引擎级两层；RNG 消费顺序必须一致（随机数在 Python 侧预生成按序传入 Rust）。
- **为什么**：这是「优化没有偷走能力」的唯一硬证据——一旦允许逐位漂移，「性能优化」与「行为改动」无法分离归因，所有跨版本读数失去可比性。配套：所有历史读数以 digest/指纹钉死（现状钉子 `tests/test_energy_probe.py:150`，digest `(574887, 11266.746993)`）。
- **锚点**：`docs/设计总档案/AI-设计总档案-v1.4-定稿.md:424`（R9.2 不可丢）；`AGENTS.md` 关键约束 1。

### D6 — 守恒闭合先行：先证「账对」，再谈生态与涌现

- **决策**：在「生态活不活、信号涌没涌现」之前，先做**能量闭合审计**——独立账本（通道登记 INJ/TRF/DIS/ESC，逐 tick 恒等式 `measured − predicted = 残差`，`close()` 是唯一会合点，**禁同账自证**），先在零引擎依赖的合成闭环（S0′）上跑通，再谈引擎真实世界。
