# digital-life-sphere 深度技术评审报告（DeepSeek V4 Pro · 2026-09-08）

> **一句话总评**：工程上是一流的（双路径逐位对拍、快照续跑、隐式选择压审计都做得扎实），科学上卡在一个具体位置——Kirby 模型的"学习瓶颈"被解读表整表遗传短路了，信号没有指代对象也没有组合结构，因此再延长时间也涌不出组合性语言；性能上百万代在"合并 PyO3 调用 + 纯 Rust tick 环"之前不可行。

## A. 科学方法论

**结论**：观测框架方向正确但证据强度不足。指标"必要不充分"——cult_div 无空间维度、语言分析只做终态快照；密度对比实验混淆了 4 个变量且单 seed 无统计检验。30 万 tick≈17 代，g14"强正选"与 cult_div"趋同"的解读均过度。

**论据**：
1. **指标充分性**：`cult_div = _interpret[:P].std(axis=0).mean()`（`experiments/long_run_l4l5.py:82`）是全种群标差，无法检测"方言"——需要空间化（分区 cult_div + Moran's I）。`language_analysis.py` 的 7 维度（熵/Zipf/MI/解读一致性）方向正确，但仅对快照做终态分析，缺时间序列。g14/g15 频率是裸均值，无置换检验/置信区间。
2. **混淆变量**：密度对比（0.69 vs 0.15）同时混淆了世界面积（7200 vs 80000 格）、种群规模（5000 vs 12000）、实验时长（30 万 vs 44.8 万 tick）与 seed（各 1 个），不能归因于密度。trust 0.92/0.99 不是演化量——g22 信任阈值未接线（`config.py:120-122`），trust 是习得状态，其稳定只说明生态平衡而非选择。
3. **30 万 tick 证据强度**：基线 60 万 tick 时 max_gen=34 → 约 1.8 万 tick/代 → 30 万 tick 仅约 17 代，0.52→0.74 无法区分选择与漂移/瞬态。cult_div→0.001 在"整表继承 + EWMA 向邻格成体 + 无地理隔离"下几乎必然发生（`sphere_engine.py:775-785`），不能作为共享符号系统的早期征兆。另注意文档间不一致（g14 0.74 与 0.83 并存于综合报告/路线），需统一口径。
4. **提高可信度所需**：≥10 seed/实验 + 报告均值±CI；零信号对照（同 seed、g15=0 关闭发射）；预注册语言涌现标准（MI 置换检验阈值、位移指代测试、Zipf R²）；世系追踪（g14 高值谱系是否单一起源）。项目已有一个好的证伪样本（方案 A 负面结果：trust 崩 0.029、g15 长期衰减），应把"先证伪"制度化。

## B. 系统架构

**结论**：Python+Rust 双路径对"快速迭代期"合适，对"3 年/百万代"不足——48% 的 Python 包装是 rayon 扩围动不了的（Amdahl 上限≈1.6~1.9x）。瓶颈判断基本正确。性能排序：合并 PyO3 调用 → 纯 Rust tick 环 → 多进程多 seed → rayon 扩围 → 事件驱动。观测/性能分离策略正确，前提是逐位对拍契约贯穿。

**论据**：
1. **栈评价**：三层对拍（函数级/引擎级/pytest，L1-L6 汇总 §6.5）与 RNG 消费序一致性是极好的正确性资产。代价是每特性双实现：L8/L9/季节启用时"Rust 自动回退 Python"（分支清单:13）→ 10x 性能回退，意味着这些特性当前不可用于长实验。3 年尺度下，Python 参考路径应降级为"测试预言机"，运行时只留 Rust。
2. **瓶颈判断对否**：基本正确。L7d 文档自证"每 tick 约 12 次跨语言调用，合并可省 30-40%"、"Python 侧 np.where/np.bincount 占 40%+"。rayon 确实只覆盖 4 个最简单的纯逐元素函数（stage1/stage2/pleasure/regrow），高价值的 movement/predation/reproduction 未并行。但即使全部 rayon 化，48% Python 包装不动，总加速上限 1/(0.52+0.48/16)≈1.9x。
3. **百万代可行性换算**：现世代间隔≈1.8 万 tick（44.8 万 tick/25 代），百万代≈2e10 tick；@80 tick/s 需约 8 年。即使 20x（纯 Rust）仍约 5 个月——必须叠加"快世代配置"（见 Q5）。
4. **观测/性能分离**：赞成，两个约束：(a) 观测期结论必须在纯 Rust 引擎上逐位复现（现有对拍基建使风险可控）；(b) "稀疏大世界+长 tick"的观测本身已撞性能墙（44.8 万 tick 耗时约 3h@38-57 tick/s），P4 长实验线在纯 Rust 前无法规模化。

## C. 演化与语言理论

**结论**：机制具备 Kirby 模型"载体+传递"骨架，但缺三个必要条件：信号无指代对象（仅发射者自身状态哈希）；无多符号"话语"结构；最关键——解读表整表遗传，学习者从不需从稀疏样本重建映射，组合性的涌现机制被短路。密度依赖结论方向符合生态理论，但证据被混淆变量污染。

**论据**：
1. **指代缺失**：`signal.rs` 模式 = e_bin(2 位)+f_bit(1)+n_bit(1)，只编码发射者当格自身状态 → 纯指示语。实测信号-语境 MI=0（状态指南 §5.2）。缺果实类型、捕食者方位、远距斑块、时间/季节等可指代对象（L10a 仅部分覆盖）。
2. **结构缺失**：信号场每格 1 个 uint8 模式、无序列发射 → 语法按构造不可能。需 ≥2 槽连续发射或复合标记。
3. **学习瓶颈缺失（最致命）**：幼体解读表 = 亲本继承+噪声（`sphere_engine.py:840,919-922`），文化学习 = 向邻格成体全表 EWMA（α=0.1）。学习者拿到完整 16 维映射，从不做"从(模式,后果)样本归纳"——Kirby ILM 中"迭代学习→瓶颈→可压缩→组合性"的枢纽在此被短路。修复方向：解读表不遗传，幼体从有限观察样本重建（瓶颈=样本数）。
4. **密度依赖是否符合理论**：符合。信号是公共品，高密度下信息冗余+搭便车 → g15 弱选（0.35/0.257）、假信号通胀致 trust 崩 0.005；低密度信息价值高 → 保留 0.69。这与信号演化论（诚实信号稳定性依赖可验证性/冗余度）一致。但保留 g15≠沟通：g15-信号行为相关仅 0.046~0.186（L7d 文档），75% 信号集中在模式 14（退化态）。
5. **时间量级**：100 万 tick=55 代，语言文化动力学需 10^3~10^4 代，差 2 个数量级；但未补缺口 3 前，纯延长时间预期收益低。

## Q1~Q5 回答

- **Q1（路径完备性）**：不完备。缺三样：指代对象、话语结构、学习瓶颈，其中学习瓶颈是"必补项"（见 C3）。社会结构/性选择是二阶问题，先补瓶颈。
- **Q2（最佳密度）**：0.15 未确立为最优——单 seed 且混淆世界大小与时长。做法：固定 80000 格，max_count 扫 4000/8000/12000/24000 × ≥5 seed。理论预期存在中间最优，超阈值后搭便车主导。
- **Q3（寿命/世界年）**：反对寿命放大 45~360 倍（每代≈700 万 tick，百万代不可行）。保留寿命 1~8 世界日，缩短 year_length 至 3~30 日（分支已设 3）让个体一生经历≥1 完整季节；360 日/年仅作记账。验证：囤积/迁徙等季节行为。
- **Q4（移速-尺度-性能三角）**：降速优先（停留选项+移动成本+冷却），配合 L8 地形做隔离；扩世界是最后手段。验证指标见 D4。
- **Q5（性能路线）**：数值收益/工作量——**A 扩围 rayon**：1.5~2x（Amdahl 上限≈1.9x@16 核），2~4 周；**B 纯 Rust 引擎**：5~20x，4~8 周（对拍基建已备，风险低）；**C 事件驱动**：1.2~2x，现活跃率高收益有限，且破坏 RNG 消费序、对拍代价高，暂缓至 N≥5 万或引入睡眠。**推荐序**：先合并 12 次 PyO3 调用为 1 个 tick_kernel（白捡 30-40%，1~2 周）→ B 纯 Rust tick 环 → 多进程多 seed → A 的 movement/reproduction 收尾。**百万代**：现状不可行（≈8 年@80 tick/s）；B + 快世代配置（寿命 1 日、成熟 0.15 日 → ≈600 tick/代）→ 6e8 tick，500-1000 tick/s 下 7~14 天/seed，3 年尺度可行。**观测/性能分离**：正确，前提是纯 Rust 引擎逐位复现观测期结论（三层对拍保证）并坚持多 seed 并行。
