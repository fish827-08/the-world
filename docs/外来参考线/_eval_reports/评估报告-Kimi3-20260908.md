# digital-life-sphere 深度技术评审报告（Kimi 3 · 2026-09-08）

> **一句话总评**：工程纪律（双路径逐位对拍、快照续跑、隐式选择压审计）是同规模项目中的一流水准；科学上的核心短板是"信号没有指代对象 + 文化传递无瓶颈"导致语言涌现被结构性排除；性能上一个关键事实需要纠正——PyO3 跨界调用本身不是瓶颈（µs 级），Python 编排层才是（48%），因此正确路线不是"合并调用"而是"整个 tick 下沉"。

## A. 科学方法论

**结论**：指标体系搭得专业（7 维度语言分析、Observed/Expected 诚实标注），但统计纪律不足：关键对比全是单 seed、无置信区间；部分指标在数学上无分辨力；密度结论被 4 个混淆变量污染，当前只能算"有趣的观察"而非"发现"。

**论据**：
1. **混淆变量**：密度对比（0.69 vs 0.15）同时改变了格数（7200/80000）、N（5000/12000）、密度与 seed——四变量同变，无法归因于密度。补法极便宜：固定 200×400，N 扫 4000/8000/12000/24000 × 3 seed。
2. **指标分辨力**：Zipf R²=0.70 建立在仅 5 个活跃模式（16 个为构造天花板）上，无统计意义；generational_stability 的 avg_correlation=1.0 只有 1 对世代样本；language_emergence_score 的 7 项权重系设计者手调，复合分 56.94 掩盖了"解读一致性 0.997 + 语境 MI=0"这类自相矛盾的信号——建议只报子分、不报加权总分。
3. **时间尺度**：602k tick / max_gen=34 → 约 1.8 万 tick/代，30 万 tick 仅约 17 代；g14 0.52→0.74 在 17 代尺度无法区分选择与漂变，缺中性对照（g14 断线）与置换检验。
4. **好实践应制度化**：隐式选择压审计（A1/A2）在同类项目中罕见；建议把"预注册涌现判据 + 零信号（g15=0）对照"补进 A3 扫描协议。

## B. 系统架构

**结论**：栈选型（Python 编排 + Rust 数值核）对当前迭代期正确。但"每 tick 12+ 次 PyO3 跨界调用"被高估为瓶颈：按每次调用 1~5µs 计共 15~60µs，小世界 0.72ms/tick 下占 2~8%，大世界 15ms/tick 下 <0.5%。真正的 48% 是 Python 侧 numpy 编排。rayon 只覆盖 4 个纯元素级函数，Amdahl 上限约 1.1x，与实测扩线程仅 +2.7% 吻合。纯 Rust 收益 5~20x 真实存在，但风险不在技术而在资产。

**论据**：
1. **开销定性**：经核实每 tick 恰有 12 次跨界调用（regrow、stage1/2、consume_many、signal_emit、step_movement、predation_and_culture、reproduce_batch、fruit_charge、eat_fruit、pleasure_update），均为 numpy 零拷贝借用。合并调用只能省 FFI 固定费，动不了 48% 的编排——只有把编排循环本身移进 Rust（单边界 tick_kernel）才能两头通吃。
2. **rayon 扩围**：实测 par_iter 仅见于 regrow/light_temp/stage1/pleasure 四处。最值得并行的是 step_movement(29%)+predation(11%)：前者逐个体无依赖、RNG 可预生成按索引消费；后者用"并行计算+串行应用"消竞态（L7 文档方案 A 正确），预期 1.5~1.9x。另注意 lib.rs 全程无 `py.allow_threads`（不释放 GIL）：批处理无碍，但未来 WebSocket 观测桥（模块五）会被长调用阻塞，需进程隔离预案。
3. **纯 Rust 重写的收益-风险**：收益 = 消掉 48% 编排 + 全部跨界，5~20x 可信。两个风险被低估：(a) 逐位对拍体系依赖 Python 参考路径这个"预言机"，全 Rust 后预言机消失，行为漂移将无锚可校，可观测性/可复现性同步受损；(b) 双实现税已在征收——L8/L9/季节分支启用即回退 Python（10x 回退，特性对长实验不可用），说明维护双路径已近带宽极限。**推荐路线**：rayon 化 movement/predation → 单边界 tick_kernel（Python 只留 init/观测/存档）→ Python 降级为测试预言机。这既拿性能又保住观测性，可持续。
4. **experiments/ 与 tests/ 评审**：tests/ 18 个文件按特性命名、164 例，函数级/引擎级/注册表三层结构清晰；改进点：缺 pytest marker 分层（slow/parity 混跑），feature/language-signal 增量 37 行无测试（分支清单自认），应设"增量必带对拍测试"硬门槛。experiments/ 把结果 CSV/JSON 与脚本混放入库，违背项目自定的 results/s2/<exp>/manifest.json 约定；建议脚本与产物分目录、产物 gitignore，并补 README 建立"脚本→科学问题"索引（现有 9 个脚本定位需读源码才能猜）。

## C. 演化与语言理论

**结论**：感知-信号-信任-记忆-解读表骨架完整，但按 Kirby 迭代学习模型，组合性涌现的必要条件"传递瓶颈"被整表 EWMA 继承短路：学习者直接拿到完整 16 维映射，永远无需泛化，系统必然收敛到整体式单义解。cult_div→0.001 不是"语言早期征兆"，而是该结构的数学必然。密度-信号关系方向符合信号演化理论，但证据等级应降半格。

**论据**：
1. **瓶颈缺失（最致命）**：幼体=亲本表+噪声，文化学习=邻格成体全表 EWMA(α=0.1)。Kirby 模型中组合性来自"学习者只能从稀疏样本重建语言"的压缩压力；此处无压力，故 16 模式→5 活跃、语境 MI=0。修复：解读表不遗传，幼体从有限 (信号, 后果) 样本归纳——全项目当前科学杠杆最高的一处改动。
2. **指代缺失**：信号=发射者自身状态哈希（能量/食物/邻居 4 位），无外部指涉物；MI=0 是结果而非意外。L10a 果实信号（"此处有食物"）方向正确，应升为一等公民。
3. **trust 悬空**：trust 稳定 0.92~0.99，但 g22 信任阈值未接线、信号-行为相关仅 0.046~0.186——信任系统近似中性挂件，"稳定高值"不构成合作涌现证据。
4. **密度理论**：信号作为公共品，高密度下冗余+假信号通胀→信任崩（实测 0.005），低密度下信息稀缺→保留，符合诚实信号稳定性理论；但"g15 保留 0.69"≠"信号被使用"（行为相关≈0），保留也可能只是低成本中性搭车，需 g15 断线对照区分。

## Q1~Q5 回答

- **Q1（路径完备性）**：不完备。缺指代内容、传递瓶颈、接收方收益耦合（被理解是否影响 fitness 目前仅经 0.4 移动权重间接传导）。三者补齐前，加时间/加社会结构均无济于事。顺序：瓶颈 → 指代（L10a）→ 社会结构/性选择（二阶）。
- **Q2（最佳密度）**：0.15 不是已确立的最优，只是两点连线。理论预期倒 U 形（过疏无交互、过密信任崩），用 D-2 实验定位峰值；时空异质密度（斑块+地形制造局部密度梯度）大概率优于任何均匀密度。
- **Q3（寿命/世界年/四季）**：反对寿命放大 45~360x——每代 1.8 万 tick 已是性能死穴。保留寿命 1~8 世界日、year_length=3~30 日（个体一生经历多轮季节）是更优设计；360 日/年仅作记账单位。判定标准应是"是否涌现季节性迁徙/囤积"，而非"体验感"。
- **Q4（移速-尺度-性能）**：降速优先。日位移 0.33 圈是地理隔离的直接杀手：加"停留"选项 + 提高 move_cost + L8 地形屏障，把日位移压到赤道周长 1/10 以下；扩世界 24x 成本线性、隔离收益次线性，是最后手段。
- **Q5（性能路线/百万代）**：百万代现状不可行（≈1.8e10 tick @80tick/s ≈ 7 年）。但要先问必要性：文化动力学量级是 10^3~10^4 代，"百万代"更像工程执念——建议改为"多 seed × 万代系综"作为主实验形态。性能排序（收益/风险）：rayon 扩围（1.5~1.9x）→ 单边界 tick_kernel（再 2~4x）→ 多进程 seed 并行（线性）→ 纯 Rust 全引擎仅在前三步不足时启动，且必须保留 Python 路径作预言机。不建议事件驱动（破坏 RNG 消费序，对拍成本高于收益）。
