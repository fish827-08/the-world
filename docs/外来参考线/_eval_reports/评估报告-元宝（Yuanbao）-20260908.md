## 0. 总体判断（先给结论）

这是一个**工程质量明显高于科学效度**的项目。Rust/PyO3 双路径下沉、CSR 邻接索引、双路径逐位对拍、隐式选择压审计（A1/A2/A4）——这套工程纪律在同类业余/独立研究中属于前 5%，甚至超过不少正式课题组的原型。文档中"未观察到组合信号/语法/可指代符号"的诚实标注，也说明作者有合格的证伪意识。

但**当前的核心结论链条在科学上不成立**。一句话概括：

> 项目把"图上的热扩散收缩""食物富余度""状态泄露编码"三个**纯机械的必然结果**，误读为"文化趋同""高信任社会""信号系统保留"三个**演化涌现**；并且把这三个量装进一张权重自定的评分卡，占了 45% 权重。

具体有三条致命问题（证据在 A 节展开）：

1. **`cult_div` 不是涌现指标，是 EWMA 平滑在图上的必然收敛量**。它在任何配置下都会单调趋近 0，速率只由图连通性（即密度）决定。中性漂变、关掉信号、关掉选择，它照样下降。
2. **`trust` 不是社会变量，是食物富余度的一对一代理变量**。0.92 / 0.99 的差别，是"食物有没有被吃光"的差别。
3. **大世界实验里 `sig_density` 全程恒为 0**（`long_large.csv` 每行都是 0），却据此得出"信号系统在稀疏世界更有价值"的头条结论。这条因果链没有数据支撑。

还有一个结构性死结：**大世界 46.2 万 tick 只跑了 25 代**（`max_gen=25`）。语言涌现（Kirby 迭代学习、Steels 命名游戏）需要的是**代际传递瓶颈的数量**，不是 tick 数。25 代在任何文化演化理论里都是零。这不是"时间不够"，是**参数把世代时间锁死在 ~18500 tick**，跑再多 tick 也换不来代数。

好消息是：这些全部是可修的，而且**修复成本远低于继续堆特性**。真正缺的不是 L8/L9/L10，是三样东西：**信息不对称**、**零模型对照**、**代数**。L8~L10 全做完也补不上这三个洞。

## A. 科学方法论评审

### A1【致命】`cult_div` 是热扩散方程的解，不是文化演化

`culture.rs` 的文化学习实现是：

```
interpret[i] += alpha * (mean(邻格成体的 interpret) - interpret[i])   # alpha = 0.1
```

这在数学上是**图上的离散热方程**（`I ← I + α·L·I`，L 为拉普拉斯算子）。对一个连通图反复施加这个算子，唯一的不动点是**全局常数向量**，且收敛是指数的。这意味着：

- `cult_div = interpret.std(axis=0).mean()` **必然**单调趋近 0；
- 收敛速率只取决于**图的连通性**（邻域重叠程度），即**种群密度与聚集度**；
- 它与"解读表是否被选择""信号是否有意义""文化是否在演化"**完全无关**。

这条推断被项目自己的数据完美印证：

| 实验 | 密度 | 图连通性 | cult_div 终值 |
|---|---|---|---|
| 小世界 60×120, N=5000 | 0.69 | 稠密（邻域高度重叠） | **0.001**（几乎完全收缩） |
| 大世界 200×400, N=12000 | 0.15 | 稀疏（大量空格，邻格成体常为 0） | **0.117**（收缩慢，卡住） |

`long_large.csv` 里 cult_div 从 0.298 缓慢降到 0.117 后**长期平台化**——这正是稀疏图上热扩散"局部未混合"的典型形态。文档把这解读为"文化多样性保持"，但它是**扩散没跑完**，不是**多样性被维持**。

**后果有多严重**：`language_emergence_score` 里 `cultural_diversity`（10%）和 `interpretation_consistency`（15%，定义 `1 - std/0.3`，是 cult_div 的严格单调函数）和 `generational_stability`（20%，相邻世代均值向量相关性，当所有世代收敛到同一常数向量时被人为抬高）**三个维度是同一个方差量的不同函数**，三者合计 **45% 权重**且**互相共线**。这不是评分卡，这是一个自由度被数了三遍。

**必须做的验证（成本极低，半天）**：
- **中性对照**：把 `interpret` 从移动决策中断开（设权重 0），保留全部学习/突变/漂变，跑 30 万 tick。若 cult_div 同样从 0.25 → 0.001，则该指标作废。
- **空信号对照**：强制所有个体不发射（`g15` 效果置 0）。若 cult_div 行为不变，则"解读表趋同 = 共享信号系统早期征兆"的说法作废。
- 我预期两个对照**都会复现主实验的 cult_div 曲线**。如果复现了，请把这三个维度从评分卡删掉，或改为**相对于中性基线的超额量**（见 A5）。

### A2【致命】`trust` 是食物富余度的代理变量，不是社会信任

信任更新（`sphere_engine.py:641-648`）：

```
had_signal = sig_present[target] > 0
has_food   = food_ratio[target] > 0.3      # food_threshold
真信号 → trust += 0.05 ;  假信号 → trust -= 0.1
```

而 `food_ratio = grid / capacity ∈ [0,1]`（`:617`）。关键在于：**"假信号"的判定门槛（0.3）低于信号的语义编码门槛（0.5）**——`signal.rs:80` 中 `f_bit = resource_grid > 0.5 * capacity`。于是：

- `f_bit=1`（信号说"这里有食物"）⟹ `food_ratio > 0.5 > 0.3` ⟹ **按定义必为真**；
- `f_bit=0` 时只有当 `food_ratio ≤ 0.3` 才算假，落在 `(0.3, 0.5]` 区间时**仍判为真**。

所以除非环境被吃到 30% 容量以下，**"假信号"在定义上几乎不可能出现**，trust 单调爬向 1。这直接解释了：

- 小世界 N=5000 / 7200 格：`trust 0.92`；早期 N=5000 爆发实验 `trust → 0.005`（食物被吃光）；
- 大世界 80000 格 / N=12000：再生 40000/tick vs 消耗 6000/tick，**食物绝对过剩**，`trust 0.99`。

**trust 测的是"资源供需比"，不是"社会信任水平"。** 用 trust 论证"高信任环境已具备，语言涌现的社会基础已就绪"是循环论证：它等于在说"食物够吃"。

同理，报告里"信号系统在稀疏世界更有价值"的因果（低密度→假信号少→信任不崩→g15 有正收益）整条链都是这个食物效应的重述，而非独立的社会动力学。

### A3【致命】大世界 `sig_density` 全程为 0，头条结论无数据支撑

`long_large.csv`（大世界 100 万 tick 实验）的 `sig_density` 列，**从 tick 2000 到 tick 462000 全部为 0**：

```
2000,1393,0.0174,0,...,0.8536,0.298012,...
462000,11999,0.1500,0,...,0.9926,0.116855,...
```

而综合报告 §4.1 正是用这个实验宣称"大世界 g15 保留 0.69 → 信号系统在稀疏世界更有价值"。

两种可能，两种都很糟：

- **统计口径 bug**：`sig_density` 没接对真实信号场 → 那么"信号保留"的结论缺乏观测证据；
- **信号确实没发射**：那么 g15=0.69 的"保留"恰恰是**中性漂变**（既不发射也无成本收益，选择系数 ≈ 0），而不是"有正收益被保留"。注意 g16（攻击基因）同期从 0.34 崩到 0.088——**被选择的基因长这样**；g15 平稳不动，是**无选择**的典型形态。

**无论哪种，这条结论当前都不能写进任何对外材料。** 请在合入前先定位 `sig_density` 的统计路径（`long_run`/`run_segment` 中该字段的来源）。这是本次评审中**最需要立刻处理的一条**。

顺带：`baseline_lang_metrics.json` 里 `signal_context_mi` 子分为 **0**（MI 完全为 0），但综合报告把它列为语言涌现的 7 个核心维度之一并给了 20% 权重。一个恒为 0 的维度占 20%，评分卡的可信度存疑。

### A4【严重】没有零模型，所有"演化发现"都无法与漂变区分

`mutation_rate=0.05`、`mutation_sigma=0.05`、24 基因位、N=5000、30 万 tick。在这个参数下，**遗传漂变本身就能产生可观的基因均值漂移**。而目前所有结论（g14 0.52→0.74+ 是"唯一强正选"、g15 被"保留/淘汰"、g16 频率依赖）都**没有与中性基线比较过**。

必须建立的三条 baseline（这是把项目从"模拟"升级为"实验"的分水岭）：

| 对照 | 做法 | 回答的问题 |
|---|---|---|
| **中性基因对照** | 把目标基因从表型映射中断开（保留突变/遗传/漂变） | g14 上升到 0.74 里有多少是漂变？ |
| **空信号对照** | `g15` 效果置 0，其余不变 | cult_div/trust/g14 的曲线是否改变？ |
| **随机符号对照** | 信号 pattern 改为均匀随机（与状态无关） | 现有"状态哈希信号"的表现是否优于纯随机？ |

第三条尤其重要，见 C 节。

### A5【严重】评分卡是打分表，不是检验

`language_emergence_score` 的问题不止共线：

- **权重任意**：0.15/0.10/0.10/0.20/0.10/0.20/0.15 无出处、无拟合、无验证。
- **"最佳区间"任意**：如 `culture_score = max(0, 1-|cd-0.1|/0.1)` 假设 std=0.1 最优；`vocab_score` 假设归一化熵 0.7 最优。这些数字没有理论或经验依据。
- **没有置换检验**：`signal_context_mi` 拿到 0.05，比 0 高多少才算"有指代"？需要对信号-语境配对做 1000 次置换，取零分布上分位。**不做置换检验的 MI 数值不可解释。**
- **产物与代码不一致（复现性硬伤）**：`baseline_lang_metrics.json` 记录 `total_score=56.94`，但同一文件的 `interpretation` 字段写"无语言迹象"。而当前 `_interpret_score` 的阈值下 0.5694 应输出"语言涌现中"。说明该 JSON 由旧版代码生成且未被重跑——**产物与代码已经漂移**。

更要命的是：**基线（尚未演化的初始快照）就拿了 56.94/100**。其中 `generational_stability=1.0`（满分）、`interpretation_consistency=0.9972`（近乎满分）。一张让"还没开始演化的系统"拿 57 分、且两个维度直接满分的评分卡，**不具备区分"有语言"和"无语言"的能力**。

**建议**：废弃 0~100 综合分；改为**一组相对于零模型的超额统计量 + 效应量 + 置信区间**，例如：
`Δ_cult_div = cult_div(实验) − cult_div(中性对照)`，配多 seed 的均值±标准差。这在科学上可辩护，在对外交流时也不会被一句话打穿。

### A6【中等】混淆变量清单（当前未受控）

| 混淆变量 | 影响 | 控制建议 |

## B. 系统架构评审

### B1 结论：Python 编排 + Rust 核的**分层是对的**，但**主权归属错了**

先说对的：保留 Python 做编排/统计/实验矩阵/落盘，把热路径下沉到 Rust —— 这是过去十年科学计算社区（NumPy→JAX、PyTorch、polars、duckdb）反复验证的"双语言"范式，没有更好的替代。放弃 Python 全量重写是正确决定；上 GPU 对这个以稀疏邻域遍历为主的工作负载基本无效（分支密集、随机访存、每 tick 强依赖），文档"GPU 完全用不上"的判断是对的。

**问题在于主权**：当前是"Python 持有世界状态，Rust 做无状态函数调用"。`Q5` 自评的 **Python 包装占单 tick 48%** 就是这个架构的直接代价 —— 每 tick 多次 PyO3 跨界，每次都要做数组切片、形状校验、`i64`/`f64` 拷贝。而且这个数字是**结构性的**，不是调优能解决的：只要 tick 循环在 Python，48% 就在那里。

现状的量化证据：大世界满种群 68~80 tick/s（`long_large.csv` 中 `rate` 从 333 降到 42~56），rayon 只覆盖 4 个函数（LightTemp/pleasure/regrow/stage1），而 `step_movement` 29% + `predation` 11% 仍是单线程。

### B2 三年 / 千-百万代尺度，推荐架构：**Rust 主权 + Python 外挂观测**

```
[建议目标态]
Rust:   World + Engine + tick loop + RNG + 全部热路径（唯一状态持有者）
        ↓ 每 N tick 暴露一次只读快照（零拷贝：Arc<Buffer> / numpy 视图）
Python: 实验编排、统计聚合、落盘、可视化、ad-hoc 分析（不参与 tick）
```

关键设计点：

1. **tick 循环下沉**。这是唯一能消除 48% Python 包装开销的办法。Python 侧调用从 `engine.tick()` × 1e6 次变成 `engine.run(1_000_000, callback_every=1000)` × 1 次。
2. **零拷贝快照**。用 PyO3 把 `&[f64]` 以 `numpy` 数组视图（不复制）暴露给 Python，或 `Arc<Vec<f64>>` 供统计层只读借用。避免每 1000 tick 全量拷贝 12000 个体 ×（24 基因 + 16 解读 + 120 期望）≈ 20 MB。
3. **RNG 主权在 Rust**。用 `rand::rngs::StdRng` + 显式 seed，配合"预生成随机数数组按索引消费"的既有纪律（项目已经做对了这点，直接平移）。可复现性由 Rust 侧单线程序保证，rayon 并行时按索引取预生成数组——项目的 L7d 方案（预生成全部随机数）是**正确且唯一可接受**的选择，请勿改用"每线程独立 rng"（那会摧毁可复现性）。
4. **Python 只保留"观测面"**：`observatory` 通过零拷贝视图拿数据，不写回。

预期收益：保守 5×，乐观 10~20×（与项目自评的"选项 B 5~20x"一致）。**这是唯一能让"百万代"从 PPT 变成数字的路径。**

### B3 具体技术债与建议

| 问题 | 证据 | 建议 |
|---|---|---|
| `np.delete`/`concatenate` 每 tick 多次 | L7c 已识别 | **不要做 slots 模式**（L7c 文档自己也警告"覆盖删除会改变个体顺序 → 影响 RNG 消费顺序"，这是正确性的定时炸弹）。在 Rust 主权架构下改用 `Vec` + swap-remove + 稳定 ID 映射，或预分配 slot 池 + 显式 free-list。**总之：先做 B2，slots 问题自然消失。** |
| rayon 只覆盖 4 函数，movement/predation 单线程 | Q5 | 在 B2 之后并行化会变得简单（无 GIL 竞争、无跨界）。移动决策天然可并行（写 `new_flat[i]`，无竞态）；捕食用文档已选的"计算与应用分离"（方案 A），正确。 |
| 双路径维护成本 | 6 个 Rust 核 + Python 参考实现 | 短期保留（它是**正确性资产**，也是本次评审能发现 A1~A3 问题的间接原因）。B2 完成后，Python 参考实现降级为"黄金参考测试"，不再进热路径。 |
| `_expectation (N,120)` = 12000×120×8B ≈ 11.5 MB | L7 §8.3 | 多数情境从未被访问。改为 `HashMap` 惰性分配或降维（能量5×食物4×邻居3×信号2 中信号维几乎无信息，可砍到 60）。 |
| 大世界 200×400 的 `_nb_table` | 80000 × stride | 极点格邻居数为 `cols=400`，stride 需按最大邻居数分配 → 内存放大。改用 CSR 存变长邻居表。 |
| 可复现性元数据 | fingerprint 仅含 config | 需扩展：代码 commit hash、Rust 编译 profile（release 有 FMA，1ULP 差异）、`sim_core.so` 构建指纹、输入快照 hash。**没有这些，明年的你无法复现今天的实验。** |

### B4 关于"3 年尺度"的现实主义提醒

按当前参数，60 万 tick ≈ 1.43 h（N=5000）。若 B2 达成 10×，则 600 万 tick ≈ 1.4 h，一年 8760 h 可跑约 3700 万 tick。听起来很多——**但大世界 46 万 tick 才 25 代**，3700 万 tick ≈ 2000 代。这在文化演化尺度上仍属"刚起步"（Kirby/Griffiths 的迭代学习实验通常数百至数千代，且每代有明确的传递瓶颈）。

**所以架构优化必须与 C/D 节的参数重构并行**：光跑得快，跑的仍是"25 代/46 万 tick"的低效演化。真正的杠杆在**缩短世代时间 + 提高每代的信息传递事件数**，那是算力之外的收益，而且免费。

## C. 演化与语言理论评审（重点）

### C1【理论核心】当前信号是**指示符（index）**，不是**符号（symbol）**

这是整个项目最本质的理论缺口，也是 Q1 的真正答案。

`signal.rs` 的模式编码：

```
pattern = e_bin(2位, 发射者能量档) * 4  +  f_bit(1位, 该格食物>50%容量) * 2  +  n_bit(1位, 同格拥挤)
```

这意味着信号的含义是**由物理状态硬编码、不可变、且与生俱来**的。而自然语言的定义性特征是 **Saussure 的能指-所指任意性（arbitrariness）**：/dog/ 这个音串与"狗"之间没有物理必然联系，正因如此，映射才能被文化演化重新协商、才能漂移、才能产生同义词与多义词、才能组合。

当前模型的直接后果：

1. **能指漂移不可能发生**——映射被写死在代码里；
2. **组合性不可能涌现**——没有符号串机制：一个格子只存一个 4-bit pattern，多发射者同格是"后写覆盖先写"（`signal.rs:13`），**信号无法叠加、无法序列、无法嵌套**。L1-L6 文档预期路径里的"组合性→语法"两步，在现有数据结构上**在原理上不可达**，不是时间问题；
3. **符号空间实际只有 15 个可用态**（`pattern=0` 不写信号），且其中 2 位编码发射者自身能量、1 位编码密度——对接收者真正有信息量的**只有 f_bit，即 1 bit**。

### C2【理论核心】信息半径重合 → 信号在信息论上严格冗余

`movement.rs` 中接收者的决策：

```rust
let mut s = perc * (food_ratio[nbc] * 0.5 + sig_present[nbc] * 0.5 * trust_val) + soc * densities[nbc];
```

**接收者直接读取邻格的 `food_ratio`（连续真实值），同时信号只提供 `f_bit = (食物>50%容量)`（1 bit 粗糙值）。**

信号携带的信息是接收者已有信息的**严格劣化子集**。在任何信息论意义下，这个信号的价值 ≤ 0。这解释了：

- 为什么 `g15` 反复被淘汰（0.473 → 0.301）；
- 为什么必须靠手调参数（发射成本 0.5→0.1、信号权重 0.3→0.5）才能勉强维持 g15 在 0.31~0.46；
- 为什么把权重调到 0.5 之后 g15 仍不稳定。

L1-L6 文档把这称为"演化诚实反馈：没有接收者的信号系统必被沉默者摧毁"——**这句话本身是对的，但归因错了**。不是"没有接收者"，是"接收者不需要它"。

> **语言涌现的第一必要条件是信息不对称**：你知道我不知道的事。当前模型中，个体感知半径（8 邻格）= 信号传播半径（1 格），感知零噪声、决策零噪声（argmax）。在这个世界里，**通信没有生态位**。

这不是调参问题，是模型结构问题。**在修好这一点之前，任何特性（L8/L9/L10）都只是给一个没有通信需求的种群加装饰。**

### C3 已具备要素的真实完备度

项目自评"Kirby 模型全要素齐备"。逐项核对：

| Kirby/Steels 要素 | 项目实现 | 判定 |
|---|---|---|
| 空间异质化（有可说之事） | L1 斑块资源 | ✅ 但 `distribution` 默认 `uniform`，实验是否启用 patchy 需确认 |
| 信号载体 | 16 模式场，50 tick 衰减 | ⚠️ 实为单 uint8 整值，无空间子结构、无组合能力 |
| 学习瓶颈（bottleneck） | 幼体向邻格成体 EWMA α=0.1 | ⚠️ 是**平滑**不是**瓶颈**。真正的瓶颈是"从有限样本重构"（如 4 槽记忆 + 采样） |
| 代际传递 | 繁殖继承 + 噪声 N(0,0.1) | ✅ |
| 任意性（arbitrariness） | — | ❌ **缺失，且是当前最关键的缺失** |
| 组合性（compositionality） | — | ❌ **数据结构上不可能** |
| 传递-使用循环（Steels 命名游戏） | — | ❌ 缺失。个体只"发射状态"，从不就信号进行交互/协商/对齐 |
| 反欺骗 / 代价信号 | L5 信任学习 | ⚠️ 判定门槛错位（A2），实际退化 |
| 有限记忆 | 4 槽工作记忆 | ✅ 但只用于"记住食物格"，未参与通信 |

**结论：缺的不是"内容维度"（Q1 的猜测方向），而是任意性 + 组合性 + 交互对齐这三件结构性要素。** 加"果实信号/季节信号"（L10a）只会让指示符多几个比特，**不会让它变成符号**。

### C4【严重】`densities` 量纲失衡：移动决策实际由群居项主导

`movement.rs:93`：

```rust
let mut s = perc * (food_ratio[nbc] * 0.5 + sig_present[nbc] * 0.5 * trust_val)
          + soc * densities[nbc];
```

- `food_ratio ∈ [0,1]`，`sig_present ∈ {0,1}`，`perc ∈ [0,1]` → 第一项 ∈ **[0, 1]**
- `soc = (g13-0.5)*2 ∈ [-1,1]`，而 `densities = np.bincount(flat)` 是**未归一化的每格个体计数**（`sphere_engine.py:660`），聚集处可达 **5~20+** → 第二项 ∈ **[-20, +20]**

**第二项比第一项大一到两个数量级。** 移动决策实际上由群居项主导，感知/信号/记忆/解读四项合计只是微扰。这带来三个后果：

1. **Q2 的"密度效应"可能不是社会效应，而是这个量纲失衡的相变**：密度 0.69 vs 0.15 → `densities` 均值差 ~4.6 倍 → 移动行为结构性不同。报告的"低密度→假信号少→信任不崩→信号有价值"这条链，有必要先排除这个更朴素的解释。
2. **g14 的选择梯度来源可疑**：g14 只乘在被淹没的第一项上。
3. 修复很简单：`densities` 除以 `max_count_per_cell` 或改用 `log1p` 压缩，或显式乘一个 `w_social` 系数（config 里其实已有 `PleasureConfig.w_social=0.2`，但那是愉悦度，不是移动项）。

**建议在 config 中新增 `movement.w_social` 并做敏感性扫描**——这与 A1/A4 的对照实验可以合并成同一批扫描，成本极低。

### C5【严重】决策是确定性 argmax，无探索、无噪声

`movement.rs:142`：`if (max_score - min_score) < 1e-9 { 随机 } else { argmax }`。

即：**只有当所有邻格得分完全相同时才随机，否则总是选最高分**。这造成：

- 个体是**完美信息 + 完美决策者**，没有感知噪声、没有选择噪声；
- 生态学上这消除了"探索-利用权衡"，也消除了**次优通信的生存空间**（在噪声世界里，一个 70% 准确的信号仍有价值；在完美世界里，它的价值严格为负）；
- 演化上，确定性选择让适应度地形变得"尖锐"，容易早熟收敛到局部最优。

建议：改用 **softmax 选择**（温度参数 `tau` 进 config），或给 `food_ratio` 加感知噪声 `N(0, sigma_perceptual)`。**加感知噪声这一项，可能比 L8+L9+L10 加起来对语言涌现的推动都大**——它同时创造了信息不对称（个体看到的与真实不同）和通信价值（多一个信息源就能降低方差）。

### D2 语言机制的最小正确重构（1~2 周）——**Q1 的真正答案**

1. **让信号变成任意符号**：`pattern` 由个体自己的"码本"决定（如增加一个可遗传的 `(16,16)` 编码矩阵，或简化为 `pattern = 个体码本[状态]`），使映射可漂移、可协商。**这是任意性的最小实现。**
2. **让感知半径 < 信号传播半径，并加感知噪声**：
   - 感知半径降到 **1 格（4 邻）**，信号传播到 **2~3 格**（信号场做一次扩散核卷积，成本极低）；
   - `food_ratio` 加噪声 `sigma_perceptual`（进 config，扫描 0 / 0.05 / 0.2）。

3. **加入 Steels 式的对齐交互**：同格个体在相遇时以小概率做一次"解读表对齐"（向对方均值靠拢，带噪声）。这提供了传递-使用循环，也是"语言"区别于"信号"的关键——**语言是协商出来的，不是广播出来的。**

**明确建议推迟**：L8 地形、L9 尸体、L10 果实。它们的价值依赖于"信号已有语义"，在 C1/C2 修好前，它们是成本而非收益。特别是 L9 能量守恒——工程上优雅，但对语言涌现没有直接贡献（它不改变信息结构）。

## E. Q1~Q5 逐条明确建议

### Q1 语言与智能涌现路径是否完备？缺口在哪？

**不完备，但缺口不在你猜的地方。** 不是"时间尺度"、不是"信号内容维度"、也不是"结构性选择压（社会结构/性选择）"。

三个结构性缺口，按重要性：
1. **任意性缺失**——信号是状态的物理函数（`signal.rs:88`），不是可协商的符号。没有任意性就没有能指漂移、没有同义/多义、没有文化演化。（C1）
2. **信息不对称缺失**——感知半径（1 格 8 邻）= 信号半径，感知零噪声、决策零噪声 argmax。信号携带的信息是接收者已有信息的严格劣化子集，**信息论价值 ≤ 0**。（C2、C5）
3. **组合性不可达**——单格单 uint8、多发射者覆盖写，不存在符号串的数据结构。文档预期路径中的"组合性→语法"在当前实现上**原理上不可达**。（C1）

**明确建议**：优先做 D2 的三件事（任意码本 / 感知半径<信号半径+感知噪声 / Steels 式对齐交互）。**这三件不做，加任何特性都无效；这三件做了，L8~L10 才真正有价值。**

### Q2 种群密度最佳值：0.15 就是"语言涌现友好"密度吗？

**不是，而且 0.15 这个数字本身是被污染的结果。** 两个理由：

1. **`densities` 未归一化**（`sphere_engine.py:660` 用原始 `np.bincount`），导致 `soc * densities` 项（量级 ±20）压倒感知/信号项（量级 ≤1）。所谓"密度效应"很可能是**这个量纲失衡引发的移动行为相变**，而非社会动力学。（C4）
2. **大世界 `sig_density` 全程为 0**，所以"0.15 下信号保留 0.69"这条证据本身不成立；g15 平稳不动而 g16 从 0.34 崩到 0.088——**g15 的形态是"无选择"，不是"被正选"**。（A3）

**明确建议**：
- 先把 `densities` 归一化 + 新增 `movement.w_social`，再做密度扫描；
- 密度不要作为独立变量扫描，改用**有效接触率** `R = (平均邻域成体数) × (感知半径 / 世界半径)`，这才是决定文化传播速率的充分统计量；
- 扫描区间建议 `R ∈ [0.5, 20]` 对数取点，每个点 5 seed。**预期：cult_div 的收敛速率是 R 的单调函数，与"语言"无关**（A1 的热扩散预测）——如果这个预测被证实，就别再用 cult_div 当涌现指标了。
- 时空异质密度（斑块 + 季节性聚集）是**好主意**，但请在修复 C2 之后再做，否则你只是在给一个没有通信需求的种群做城市规划。

### Q3 寿命 / 世界年 / 四季刻度

**当前刻度在演化上是无效的，但问题不在"世界年=360 日"，而在"每代 tick 数太多"。**

硬数据：`long_large.csv` 中 46.2 万 tick → `max_gen=25`，即**世代时间 ≈ 18500 tick ≈ 7.7 世界日**（已顶到寿命上限 8 日）。25 代在任何文化演化理论里都约等于零。

**明确建议**：
- **不要按 Q3 想的那样"放大寿命 45~360 倍"**——那会让世代时间更长、代数更少，是反向操作。
- 正确方向是**压缩世代时间**：`lifespan = day × (1 + g3×7)`（`:393`）的基准从"一昼夜"改为"一昼夜的 1/8~1/4"，或把 `rotation_period` 从 2400 降到 300~600。**目标：让 100 万 tick 产出 500~2000 代，而不是 25 代。**
- 四季：一年 = 3 世界日（`SeasonConfig.year_length=3`）时，寿命 1~8 日的个体**平均只能经历 0.5~2.7 个季节周期**，而且个体活不到感受"年"的尺度。**要么把年缩短到 < 1 个平均寿命**（让每个体一生经历 3~10 个季节），**要么先别上季节**。我倾向后者：季节要等寿命-世代刻度定下来再加，否则又是一个无法归因的混淆变量。
- 世界年 360 日本身无所谓——它只是标签，真正起作用的是 `year_length / lifespan` 的比值。**请把这个比值作为一等公民参数进 config 并扫描。**

### Q4 移速-世界尺度-性能三角

**"降速"和"扩世界"都是错的杠杆。正确的杠杆是"降感知半径 + 加感知噪声"。**

现状：0.33 日环游一圈 → 地理隔离为零 → 无方言、无分化。文档提出"降速 24 倍或扩尺度 24 倍"，两者都直接撞性能墙（扩尺度性能线性下降）。

**明确建议**（成本近零，效果远好于二者）：
1. **感知半径从 8 邻降到 4 邻（曼哈顿邻域）**，把信号传播半径提到 2~3 格（信号场做一次 3×3 扩散卷积，Rust 里几乎免费）。**这一步同时解决了地理隔离（个体对 2 格外一无所知 → 世界"变大"了数倍，且不需要增加一格内存）和信息不对称（C2）。**
2. **给感知加噪声** `sigma_perceptual ∈ {0, 0.05, 0.2}`。噪声让世界对个体而言"不确定"，从而让信息（信号）产生价值。
3. **移动决策改 softmax(tau)**，替代 argmax（C5）。
4. 移速与世界尺度**保持现状**——它们在修复 1~3 之后自然会重新校准，现在动它们是过早优化。

按"有效世界尺度 = 世界半径 / 感知半径"计，把感知从 8 邻降到 4 邻 + 信号传 2 格，**等效于把世界扩大 4~8 倍而不花一分算力**。这是本次评审里性价比最高的一条建议。

### Q5 性能路线与百万代可行性

**选项 A（rayon 化剩余热路径，1.5~2×）在当前架构下不值得做；请直接做选项 B（纯 Rust 引擎 + Python 只观测）。**

理由：48% 的 Python 包装开销是**结构性的**——只要 tick 循环在 Python，rayon 化只在剩下 52% 里做文章，天花板就是把 48% 之外的部分压到接近 0，总收益不到 2×，却要付极高的对拍复杂度（L7d 文档自评"复杂度极高"）。而 B 方案一次性消除这 48%。

关于"百万代（1e6 代）"：**在当前参数下不现实，在重构后也不现实，但这不重要。**

- 现实的目标不是 1e6 代，而是 **1e3~1e4 代 × 5~10 seed × 多配置**。按 Q3 的建议压缩世代时间到 ~200 tick/代，1e4 代 = 200 万 tick。以重构后 600 万 tick/小时计，**单个实验 20 分钟，10 seed × 10 配置 = 33 小时**。这完全可行，而且比"1e6 代 × 1 seed"科学价值高得多——**统计功效来自重复，不来自长度。**
- 请把"百万代"这个目标从路线图里删掉，换成"**千代 × 十 seed × 有对照**"。前者是算力幻觉，后者是可发表的科学。

## F. 如果这是我的开源科研项目：6 个月路线

| 月份 | 主题 | 交付物 | Gate（退出条件） |
|---|---|---|---|
| M1 | 止血 + 零模型 | `sig_density` 定位；三对照实验；`densities` 归一化；置换检验 | 主实验 vs 中性对照的 cult_div/trust 曲线对比图（**无论结果如何都算达成**） |

| M3 | Rust 主权化 | tick loop 下沉 + 零拷贝快照 | N=12000 达 400+ tick/s，且同 seed 逐位可复现 |
| M4 | 语言机制验证 | 感知半径<信号半径 + Steels 对齐 | 出现**信号-语境 MI 显著高于置换零分布**（p<0.01，多 seed） |

## G. 结语

这个项目最稀缺的资产不是代码，是**作者的诚实**：`L1-L6` 文档里那句"未观察到组合信号/语法/可指代符号"，以及 A1~A4 那套主动审计自己隐式选择压的方法论，在独立研究里非常罕见。**本次评审的全部批评，都建立在这份诚实之上**——正因为结论是诚实记录的，才能被证伪，才值得被证伪。

需要警惕的只有一件事：**A1~A3 指出的问题，其共同模式是"把机械必然误读为演化涌现"**。这个模式一旦固化进对外叙事，后续所有特性都会围着它打转。所以 D0 那三件事（核查 `sig_density`、重跑 baseline、归一化 `densities`）请务必在最前面做——它们只需要 1~2 天，却决定后面 6 个月的方向对不对。

**最后一句**：这个项目的科学问题应该从"语言会涌现吗"改成"**语言涌现的最小充分条件是什么**"。前者在这个模型规模下十年内不会有答案，后者是可以在 6 个月内做出真正贡献、并且经得起领域专家检验的问题——而且否定性结果（"信息不对称是必要条件"）同样是贡献，甚至更有价值。
