# 六模型评审汇总报告与后续发展规划（2026-09-08）

> 评审对象：`digital-life-sphere` @ main（附 4 分支）
> 参与报告：DeepSeek V4 Pro / Kimi 3 / ChatGPT 5.6 Luna / Claude Sonnet 5 / 豆包 2.1 Pro / 元宝（Yuanbao）
> 汇总原则：本报告只收"多报告交叉印证 + 单一报告的独有硬发现"；贡献比按"独特且可执行的发现 × 证据深度（是否读了原始 CSV/JSON/源码）"加权。

## 一句话总评

六份报告高度收敛：**工程纪律一流（双路径逐位对拍、快照续跑、隐式选择压审计），科学效度不足（单 seed、无零模型、指标自证）**；且语言涌现被当前机制**结构性排除**——信号无指代、无组合结构、解读表整表继承使 Kirby 学习瓶颈被短路。最尖锐的一份（元宝）进一步证明：cult_div 趋同、trust 高值、"稀疏世界信号更有价值"三个头条结论可能分别是"图热扩散的必然解""食物富余度的代理变量""无数据支撑的推断"。修复优先级：先止血数据 bug 与零模型，再重构信息结构，最后才是架构下沉与特性叠加。

## 一、六报告共识（高置信结论，可直接作为决策输入）

1. **工程层**：Rust/PyO3 双路径 + 三层对拍 + CSR 邻接 + 快照/RNG 复现 + 隐式选择压审计（A1/A2/A4）属同规模独立项目前 5% 水准，是正确的正确性资产，应长期保留。
2. **科学层**：全部头条结论基于单 seed（SEED=42）、无置信区间、无置换检验、无零模型，只能算"观察"而非"发现"；密度对比（0.69 vs 0.15）同时混淆世界面积/种群规模/时长/seed 四变量。
3. **理论层**：信号 = 发射者自身状态哈希（index，非 symbol），无外部指称、无序列结构、无任意性 → 组合性/语法在现有数据结构上**原理上不可达**，与时间无关。解读表"整表继承 + 全邻域 EWMA"是平滑不是瓶颈，Kirby ILM 的"压缩→组合性"链条被短路（DeepSeek/Kimi/豆包/元宝四份独立指出）。
4. **Q3/Q4 方向**：六报告一致反对"寿命放大 45~360 倍"（世代时间更长 = 反向操作）与"扩世界 24 倍"（线性掉速、隔离收益次线性）；一致主张**压缩世代时间**（rotation_period 2400→300~600 或寿命基准改小，目标 100 万 tick 产出 500~2000 代而非 25 代）与**降速/降感知半径 + L8 地形屏障**做地理隔离。
5. **Q5 方向**：rayon 扩围收益被 Amdahl 定律锁死在 1.5~2x（48% Python 包装不动）；正确方向是"tick 循环下沉 Rust"（厚核薄驱 → 纯 Rust 引擎），预期 5~15x；"百万代"当前不可行且**非必要**——文化动力学量级是 10³~10⁴ 代，应改为"千代 × 多 seed × 有对照"系综（统计功效来自重复，不来自长度）。

## 二、关键分歧与裁决建议

| 分歧点 | 各报告立场 | 裁决建议 |
|---|---|---|
| 性能第一步：合并 PyO3 调用 vs 直接 tick 下沉 | DeepSeek 建议先"合并 12 次调用省 30-40%"；**Kimi 定量纠偏：FFI 本身 µs 级（占 2-8%/<0.5%），48% 是 Python 编排本身，合并无用，必须整 tick 下沉**；豆包提出"厚核薄驱 step_tick"折中 | **采纳 Kimi 纠偏**：跳过分步合并，直接做单边界 step_tick 下沉，用一次 profiling 实验最终裁决（半天成本） |

## 四、必须立即修正的事实清单（六报告交叉确认，M0 内完成）

1. **冻结"信号在稀疏世界更有价值"结论**：sig_density 恒为 0（元宝 A3 + 状态指南自认 bug），先定位统计路径。
2. **统一 cult_div 口径**：全部脚本改用 `.std(axis=0).mean()`（豆包），重算 long_small/long_large CSV，再谈 0.001 vs 0.116。
3. **对齐 trust 判定门槛**：food_threshold 0.3 与 f_bit 编码门槛 0.5 错位导致"假信号几乎不可能"（元宝 A2）→ 显式参数化并对齐。
4. **归一化 densities**：加 `movement.w_social`（元宝 C4），排除"密度效应=量纲相变"的替代解释。
5. **废弃 0~100 语言综合分**：改为一组相对零模型的超额统计量 + 效应量 + CI；重跑 baseline_lang_metrics（产物已与代码漂移）。
6. **统一对外口径**：测试数（164 passed / 159+5f / 98+3f 三套说法）、文档-实现漂移（L7 伪代码 s_bit=0 vs signal.rs 已实现；"田字格"名实不符）。

## 五、后续发展规划建议（6 个月，合并六报告）

**M0 止血周（1~2 天，先于一切特性）**：执行上述 6 项事实修正；期间不出任何新对外结论。

**M1 零模型体系（3~5 天）——从"模拟"到"实验"的分水岭**：
- 三个对照开关进 SimConfig 并入 fingerprint：`neutral_genes`（基因断线）/ `signal_disabled`（空信号）/ `signal_mode: state|random|evolved`（随机符号）；
- 所有长实验 ≥5~10 seed，报中位数+IQR/CI；MI/Moran's I 配 1000 次置换零分布；预注册 E1~E4 判据（Luna 框架）。
- 预期（元宝）：cult_div/trust 曲线在对照组高度复现主实验 → 叙事推倒重写，这本身就是最有价值的产出。

**M2 信息结构最小重构（1~2 周）——科学杠杆最高，只做四件事**：
1. **学习瓶颈**：解读表不遗传，幼体从有限（信号,后果）样本归纳（Kirby 链条的枢纽）；
2. **任意性**：pattern = 个体可遗传码本[状态]，让映射可漂移可协商（Saussure 任意性最小实现）；
3. **信息不对称**：感知半径 ≤ 信号传播半径 + 感知噪声 `sigma_perceptual`（0/0.05/0.2）+ 移动决策 softmax——让信号携带接收者没有的信息（信息论价值 > 0）；
4. **Steels 式对齐交互**：同格个体小概率解读表对齐（语言是协商出来的，不是广播出来的）。
Gate（元宝 M2）：g15 在**无手调补贴**下从 0.5 上升——这是唯一有意义的验证标准。

**M3 架构迁移（2~4 周，可与 M2 并行）——Q5 的答案**：
- 第一步直接做单边界 `step_tick` 下沉（厚核薄驱，采纳 Kimi 纠偏：跳过分步合并）；零拷贝快照（PyO3 numpy 视图）；RNG 主权在 Rust（预生成数组按索引消费纪律平移）；
- 第二步才 rayon 化 movement/predation（计算/应用分离）；**L7c slots 不做**（元宝：正确性定时炸弹，B 方案后自然消失）；
- Python 参考实现降级为黄金测试预言机；多进程 seed 系综（GIL 隔离）作为吞吐乘数。
Gate（元宝 M3）：N=12000 ≥400 tick/s 且同 seed 逐位可复现。

**M4 实验线（持续）**：
- 密度 × 信任对称化 × 再生率三因素析因（≥5 密度点 × 5 seed），以通讯准确率/MI 而非 g15 保留率为判据；时空异质密度（L8 地形）在 M2 修复后启用；
- 世代时间压缩先行于季节：`rotation_period` 2400→300~600，目标 100 万 tick=500~2000 代；`year_length/lifespan` 比值作为一等参数扫描后再上四季；
- L10a 果实信号（指代）随 M2 一等公民；L9 尸体、L8 地形、L11+ 性选择按序后排。

**M5 复现性基建 + 叙事重构（持续）**：
- manifest 扩展（commit hash/编译 profile/二进制 hash/输入快照 hash）、CI + 2 分钟冒烟对拍、快照数据移出 git（Git LFS/外部存储）、`docs/adr/`；
- 每份实验报告强制 Observed / Inferred / Assumed 三栏；科学问题从"语言会涌现吗"改为"**语言涌现的最小充分条件是什么**"（否定性结果同样可发表）；
- 6 个月交付物：《最小充分条件测试报告》（M6，元宝路线），明确回答"信息不对称是否为必要条件"。

**3 年尺度校准**：按 M2+M3 完成后 600 万 tick/小时计，千代级（≈200 万 tick）× 10 seed × 10 配置 ≈ 33 小时/组——科研生产线成立；"百万代"保留为远期 stretch goal，不作为路线图硬目标。
