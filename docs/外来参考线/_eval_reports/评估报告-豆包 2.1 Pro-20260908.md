# digital-life-sphere 深度技术评审（计算演化生物学 + 复杂系统架构）

> **一句话总评**：工程完成度与双路径对拍纪律在同类个人研究项目中属上游，真正的短板不在算力而在"科学推断层"——头条涌现结论建立在单 seed、口径不一的指标和缺零模型之上；架构上应做"厚核薄驱"融合而非立即纯 Rust 重写。

---

## A. 科学方法论

**结论（≤3 行）**
1. 观测指标体系初具雏形，但"文化多样性"等核心指标跨脚本口径不一致，直接削弱跨实验可比性。
2. 对照/多 seed/统计检验只覆盖了短扫描，头条长实验仍是 N=1 轨迹，证据强度不足以支撑"涌现/密度最优"结论。
3. 缺零模型（null）与先验判据，"涌现"是事后加权打分，存在阈值自证风险。

**论据**
- **指标口径冲突**：`cult_div` 在 run_long_experiment.py:66 用 `interpret.std()`（N×16 全体池化标准差，混入了不同信号位的基线差），而 run_segment.py:128、long_run_l4l5.py:82 用 `.std(axis=0).mean()`（逐信号位、跨个体分歧，才是正确口径）。大小世界"0.001 vs 0.116"很可能部分来自估计量差异而非现象本身，须统一为单一规范函数后重算。
- **多 seed 覆盖错配**：仅 run_sensitivity_all（3 seed）与 patchy_vs_uniform（3 seed）做了多种子，且 summary 只报均值、不报离散/置信；承载涌现主张的 run_long_experiment/run_segment/long_run_l4l5 全部硬编码 SEED=42。g14 0.52→0.74、trust 0.92~0.99 都是单条轨迹，无法区分选择效应与漂变/初值偶然。
- **缺零模型与检验**：全仓无 t-test/bootstrap/置换检验；language_analysis.py 的 Zipf、Moran's I、归一化 MI 是亮点，但综合分权重与归一化分母（0.5/0.3）、分级阈值均手设，且没有"打乱信号"零分布做基线——MI/Moran's I 在空间自相关数据上本就为正，无 null 无法判断显著性。
- **混淆变量未隔离**：密度结论（0.15 vs 0.69）只有两点、各 1 次，且密度同时共变于"资源被吃空速率"和审计清单自己标出的信任非对称（+0.05/−0.1）。建议先补 factorial，再谈最优密度。

## B. 系统架构（本评审重点）

**结论（≤3 行）**
1. 瓶颈不是 FFI 延迟，而是**边界切分层级过低**：每 tick 8 个固定 + 条件/果实共 10~12 次 PyO3 调用，Rust 从不拥有主循环，Python 在核间反复重建中间量，这才是 profile 里"Python 包装 48%"的来源。
2. rayon 只并行在 4 个**非最热**核上；占 29% 的 step_movement、11% 的 predation_and_culture 仍是串行 for 循环，Amdahl 决定了 Option A 上限仅 1.6×(4 核)/1.8×(8 核)——与团队自估 1.5~2× 一致，但要知道这就是天花板。
3. 不建议现在大爆炸式纯 Rust 重写；建议"厚核薄驱"：把整条 tick 管线融合成一次 `step_tick` 调用，可吃掉 Option B 约七到八成收益，同时保住 Python 观测/快照/对拍资产。

**论据**
- **跨界调用清单（Rust 路径，按序）**：regrow→stage1→consume_many→(邻格觅食 consume_many)→signal_emit→stage2→step_movement→predation_and_culture→(reproduce_batch)→pleasure_update；开果实再加 fruit_charge/eat_fruit。单次 FFI 本身仅百 ns 级、可忽略，真正代价有三：① GIL 全程持有、核间必回 Python；② 同一中间量重复物化——密度 `np.bincount(flat)` 每 tick 在 563/621/1103 重算 3 次，food_ratio/sig_present 反复构建，伴随 `.astype/.copy/.reshape`；③ 每次出生/死亡对约 20 个 SoA 数组做 np.concatenate（893–978 行）。这些正是 48% 的构成。
- **rayon 覆盖错位**：用 rayon 的是 regrow、pleasure、step_vectors(stage)、LightTempRust（全格场，每 tick 一次）；最重的 movement/predation 及 signal/reproduce 全串行。且全仓无 `allow_threads`，每个细颗粒核各自承担一次 rayon fork-join 屏障，N=5000 的轻算术下并行净收益会被调度开销侵蚀。
- **纯 Rust 重写的收益—风险**：收益侧，去掉 48% Python 单线程部分单线程即得 1/0.52≈1.92×，再叠加整 tick 级并行与布局优化，现实区间 5~15×，20× 需多核+内存重构同时成立。风险侧：① Python 是当前快速迭代生态机制的层，规则迁入 Rust 会显著拖慢科学迭代（项目真正稀缺的是实验周转而非 FPS）；② observatory/persistence/快照+RNG 续跑是成熟资产，纯 Rust 须等价重建遥测与检查点，否则实验矩阵与可复现性倒退；③ 机制（L8–L11）尚未稳定，现在重写将随每个特性反复返工。**可持续性上，"Python 参考实现 + Rust 加速核 + 逐位对拍"本身是优质科学资产，应保留这一性质。**
- **experiments/ 可读性**：三类脚本（benchmark/一次性探针/正式实验）平铺；run_long_experiment 与 run_segment 近乎重复（139/138 行），指标代码复制粘贴且口径分叉；脚本直接读 `e._genes/_trust/_interpret` 等私有属性，耦合脆弱；CSV 与代码混放、文档称 results/ 但实际无此目录，且临时 CSV 不带 config 指纹/git sha，不可严格追溯。建议分 `benchmarks/ hypotheses/ analyses/ common/`，下沉统一的 config 构建、规范指标、CSV+manifest 写出与种子列表。
- **tests/**：17 个按特性命名、Rust/Python 逐位对拍覆盖扎实（test_sim_core 376 行等）是明显优点。缺口：conftest 仅 8 行 sys.path、缺共享 fixture（如 rust/py 引擎对）；缺能量守恒等不变量测试、文化传递（EWMA 有界/收敛）性质测试、长程黄金轨迹回归；性能哨兵放在 experiments 而非 tests，未纳入门禁；language-signal 分支增量 37 行**无测试**却改动选择压，合入前必须补对拍。

## C. 演化与语言理论

**结论（≤3 行）**
1. 个体认知前置（感知/记忆/RPE/学习）与种群传递（Kirby 迭代学习）已齐备，但缺最关键的**通讯选择闭环**：信号没有共享外部指称、没有"接收方动作→双方收益"的耦合，通讯只是移动打分的副产品，不受直接选择。
2. 现机制会驱动"趋同塌缩"而非"结构化"：幼体每 tick 对全部成体邻域做均值+EWMA，是无瓶颈的富信息平均，恰是共识而非组合性的来源。
3. "低密度更利语言"方向真实但被中介污染，是资源驻留时间×非对称信任更新的产物，不是普适定律。

**论据**
- 对照 Lewis/Skyrms 信号博弈，缺四要素：① **指称语义**——16 模式是发送者自身状态哈希（能量/食物/邻居位），非关于远端对象的定向信号；② **联合收益**——接收方仅把信号作为移动得分一项，没有"通讯成功则发送/接收双方获益"的支付，故信号信息量没有被选择维持的理由；③ **组合性基底**——解读表是"整模式→标量"，无双层切分（duality of patterning），结构上无法产生语法；④ **传输瓶颈**——Kirby 产生组合性依赖学习者只见到少量样本，当前"全邻域均值"反其道而行，解释了 cult_div→0.001。
- 信任稳定缺机制支撑：信号成本恒定 0.1（无 handicap 成本-质量耦合），个体匿名、无身份/无重复博弈/无伙伴选择，网络互惠无法建立，只剩一个全局 trust 标量。
- **密度-信号关系**：高密度下食物被快速吃空→"有信号却无食物"的假信号增多→非对称的 −0.1（2 倍于 +0.05）把 trust 压到地板→社会信息权重×trust 归零→g15 被中性化/淘汰；低密度下食物驻留、信号保持"诚实"。因此 0.15 只是"这套非对称规则+当前再生率下不惩罚信号"的密度，需 density×信任非对称×再生率 的析因实验拆解；L10a 果实/季节信号增加了候选指称（方向正确），但不补联合收益闭环与瓶颈，只会增加词汇候选而不会语法化。

## D. 下一步行动（排序清单）

- **P0 方法卫生（低成本，先于一切结论）**：① 统一 cult_div 等指标为规范函数，引擎提供公开遥测 API，禁止实验脚本读私有属性；② 头条长实验上 ≥8–10 seed，报中位数+IQR/CI，为 MI/Moran's I/通讯准确率配打乱信号零模型，先验登记涌现阈值。
- **P1 廉价性能（直接打 48%）**：③ 密度每 tick 只算一次并复用 food/sig 数组，落地 slots(T5/L7c) 消除每 tick 约 20 次 concat/delete，再重测 profile；④ 仅对 step_movement、predation_and_culture 两个串行热核上 rayon，预期≤1.8×，不做更多。
- **P2 科学机制**：⑤ 实现最小信号博弈闭环（指称+定向信号+接收动作+联合收益）与学习瓶颈，以"通讯准确率/MI 对 null"作为头号涌现终点；⑥ 做密度×信任非对称×再生率多种子析因，并入 L8 地形产生时空异质密度与地理隔离。
- **P3 尺度演进**：⑦ 把 8~12 个核融合为单一 Rust `step_tick`（厚核薄驱），profile 达标后再评估是否纯 Rust；⑧ 用"缩短年相对寿命"而非"寿命放大 360×"重定日历，再据真实 tick 预算规划长实验。

## Q1~Q5 回答

- **Q1 涌现路径是否完备/缺口**：不完备，缺的不是时间而是**通讯选择闭环、指称 grounding、传输瓶颈、组合性基底**四者；认知与传递层已够。优先级：先补机制闭环与零模型判据，再谈延长时间，否则跑再久也只得到趋同。
- **Q2 最佳密度**：不要锁定 0.15。现仅两点、各单 seed，且与信任非对称/再生率混淆。建议做三因素多种子扫描并以通讯准确率（非仅 g15 保留率）为判据；生态上更应采用 L8 地形驱动的**时空异质密度**，而非单一全局最优。
- **Q3 寿命/世界年/四季刻度**：目标应拆为"经历季节"与"世代交叠以利文化学习"。推荐**缩短年**（沿用 l9 分支 year_length≈3 日的思路）使成熟≈1 季、寿命≈1 世界年即可历经四季；避免寿命放大 45~360×，那会让世代周期与运行时同时爆炸。落地后须验证幼体学习窗口仍能接触足够成体。
- **Q4 移速-尺度-性能三角**：**降速+屏障，不扩世界**。扩 24 倍是线性掉速且已撞性能墙；地理隔离靠降低扩散相对周长的比例 + L8 水域/山地屏障（分支已有，成本最低）。用基因的空间自相关（Moran's I）/混合时间量化隔离，替代"一生绕几圈"。
- **Q5 性能路线与百万代可行性**：先正名——**tick≠代**。1e6 tick 现在即可行（小世界约 12 分钟、大世界约 4 小时）；但一代≈成熟期=360~2880 tick，1e6 代在大世界最短估计也要连续约 60 天、小世界约 3 天，当前架构不现实，二者相差 360~2880 倍而非调参可弥合。路线：先做 P1 廉价优化（上限约 1.8×）→ 再做融合 step_tick 的厚核（现实 5~15× 的主要来源）→ 机制稳定（P3 之后）才评估纯 Rust；百万代实验须在厚核+缩短世代日历后重新立项。
