## 三、最近关键数据（已核实）

### 1. 零模型四臂（D1，300k tick × 3 seed）
- g14 四臂全部 0.47~0.50 → **旗舰"g14 强正选"不复现**
- g15 跨臂跨 seed 方向不一致 → 近中性漂变
- sigdis 臂 trust **恒 0.5000** → trust 是食物富余度代理
- cult_div 不发信号也趋同 → 图热扩散机械必然
- ⚠️ neutral 臂失效（全冻结→灭绝 2/5/2）；修正设计（只冻结目标位）未执行

### 2. D2.1 参数网格——**seed 维无效，参数维有效**
- 7 组配对：3 组逐字节全等，4 组共享前缀 → 实为 1 条轨迹
- **但**：不同 lr 产出不同轨迹；14/14 终局 g15 < 0.5 且全部 peak-then-revert
- → **诊断为可复算、与 seed 维无关**；"2 seed 复现"表述作废

### 3. lr 细扫（云端已完成，`d6c5fca`）
- lr={0.05,0.075,0.125}×s{42,43} 全部完成；**全部 peak-then-revert，终局 <0.5**
- 结论：**无发送者私利时稳态 g15>0.5 机制性不可达** —— 战略诊断的经验闭环

### 4. battle 参数验证
