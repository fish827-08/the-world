## 三、共同维护规则（已写入 `_gitee_review/AGENTS.md`）

1. 影响方向的更改 → 追加 ROADMAP；状态变化 → 更新 STATUS。
2. **append-only**：历史不删不改，改判 = 追加 + 标注旧结论。
3. 证据标签：`[实测]/[代码]/[文献]/[推断]`；来源指向上游。
4. 事实以 `_eval/BASELINE.md` 为准；不重复收细粒度数据。
5. 版本号随内容推进；维护者署名 + 日期 + commit。
