# 实验记录（Experiment Log）

> **用途**：**每一次实验/批跑的永久记录**——目的、配置、规模、时长、结果摘要、数据位置。
> **建立**：2026-09-18（fish 指示："找个文档记录一下每一次实验，时长结果目的等等，用于专门记录实验……**从这个实验到以后所有实验都要记录**"）
> **维护**：批次完成后由**实验执行者**追加一行（本线 `[所有者]`/天平 维护格式与编号）；**只增不改**（更正另起一行）。
> **纪律**：本表只记**事实**（数字/状态）；**判读结论**见 `_share/路线共识.md` 与判读报告——**表内不写科学结论**。
> **数据位置约定**：run 产物在 `_rerun_logs/<批次>/`（本地工作树）+ `the-world-data/_rerun_logs/<批次>/`（入库）；快照在 `_rerun_logs/<snapshot-dir>/`。

## 字段说明

| 字段 | 含义 |
|------|------|
| 编号 | `E-###`，按启动时间递增（补录部分亦按时间序） |
| 日期 | 启动日期（本地时区） |
| 批次 | `batch_runner` 预设名 / 自定义批次名 |
| 目的 | 这批要回答什么（一句话；`[文档]`=有出处，`[推断]`=据配置重建） |
| 配置 | 臂 × seed × tick 等关键参数（摘要） |
| 规模 | run 数（并发数） |
| 时长 | 墙钟：启动 → 最后 run 完成（`[实测]`=有 mtime 跨度佐证） |
| 结果摘要 | 完成/失败数 + 关键**数字**（不判读） |
| 数据 | 产物路径 |
| 状态 | ✅ 完成 ／ ❌ 作废 ／ 🔄 进行中 |
