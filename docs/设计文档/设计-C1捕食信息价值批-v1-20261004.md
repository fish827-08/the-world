## 二、四必办（PI 17:47 派单原文 · 逐条落实）

### ① 分块粒度定稿（默认建议 4×4）

**裁定 = 每边 4 块 · 全球 4×4 = 16 子块**（`rd_block_id ∈ [0, 15]`）。

**歧义说明**：需求清单 §二 表 `rd_block_dead_dens` 写"建议 4×4 格粗块，块数 = **25** 块/图幅子样"——"4×4"与"25 块"字面矛盾（4×4 = 16，5×5 = 25）。**本稿按 4×4 = 16 子块定**（**用户 17:47 消息明说"默认建议 4×4"** ⇒ 优先），备注：若砚判读需要 5×5 = 25 子块 ⇒ §九-2 板上指路，我改 `n_block_rows = n_block_cols = 5` 一行，不影响其他章。

**几何定义（球面适配）**：
- **纬度带 4 分** = `lat_band = int(row × 4 / world.rows)`，row ∈ [0, 479] ⇒ band ∈ {0, 1, 2, 3}；
- **经度带 4 分** = `lon_band = int(col × 4 / world.cols)`，col ∈ [0, 959] ⇒ band ∈ {0, 1, 2, 3}；
- **块编号** = `block_id = lat_band * 4 + lon_band`（0–15）；
- **极点处理**：等距圆柱投影极点附近纬线密集，band 0/3 面积不等 —— 与 §四 J-B 跨窗 Spearman 稳定性判据**同一 partition 一致**即可（判据不看面积，看**跨窗序稳定**），面积不等**不构成偏差**（`[假设]`，若砚判读需要面积加权 ⇒ §九-2 指路，我加 `rd_block_area_weight` 列）。

**块数功效核算**（`[推算]`，供 §七性能）：
- 16 子块 × 40 窗/run = **640 计数/run**；
- 8 seed × 2 臂 = 16 run ⇒ 总样本 10240 block-window 观测；
- 10k tick 内被捕食死亡事件（r198 重算死亡率 31–42% 底 · pop 末估 3000–10000 · 单 run 死亡事件 ≈ **1000–4000 次** · `[实测·r198/需求清单 §三]`）⇒ 每 block-window 平均 ≈ 0.15–0.6 死亡（稀疏）；
- AR1 置换零模型功效：n=40 窗 × 16 块独立事件 ⇒ AR1 逐块算（16 个 AR1/run）⇒ 8 seed 合并 CI ⇒ §四 J-A 判据形态；
- **若单块样本过稀**（0.15 期望值使块内 AR1 方差大）⇒ §八 假设位**"块内 AR1 汇总为 run 级均值 ⇒ seed 级合并"** 兜底（不违 R96 伪重复，seed 级 n = 8）。

## 七、性能预算

- **单 run 预算**：10k tick ≈ 26–30 min（R372 反推 Tier-1 8–9 min/3000t）；
- **16 run ÷ 4 路并行** ≈ 1.8–2h < 3h（R372 本机限内 · 云机 3.5h 备份口径）；
- **加列耗时**（`[推算]` 每采样窗 · 250t 窗 ⇒ 每 250 tick 一次计算）：
  - `rd_block_dead_dens[16]` ≈ 一次 `bincount(block_id)` + 除存活秒时 ≈ **O(N)** 单次 ≈ 0.05 ms/tick 平摊；
  - `rd_block_ar1[16]` 40 窗序列聚合**只在 run 末尾**算 ≈ 0 ms/tick；
  - `rd_block_ar1_null[16]` 置换 1000 次 run 末尾**一次性**算 ≈ 0 ms/tick（不进采样循环）；
  - `rd_block_cv` / `rd_block_stability` 派生列 run 末尾 ≈ 0；
  - `rd_<channel>_read` 每窗 ASM Ŝ_⟨channel⟩ × 后续经历**逐窗** ≈ 0.1 ms/tick（读 ASM 既有列，不重算）；
  - `rd_flee_gain` 逐窗读 `_fear_term_*` ≈ 0.02 ms/tick；
- **合计 ≈ 0.17 ms/tick 平摊**（旗舰 ms/t ≈ 61–124 参考 §六 E-052 判读 §三） ⇒ **≪ 10% 预算**，`ms/t` 影响 <1%（`[推算]`）；
- **超预算降频方案**（本设计不预期）：若置换零模型 1000 次过慢 ⇒ 减到 500 次并披露 `rd_block_ar1_null_n_perm`；仍超 ⇒ `--rd-channel` 单通道跑，`rd_flee_gain` 拆独立开关。
