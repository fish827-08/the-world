## 二、🔴 接线前必须算清的一件事：subpos 会**削弱跨格频率**

这是本文最重要的一节，**不做校准就会把波 1 变成反向改动**。

### 2.1 问题

| | 移动者每 tick 位移 | 跨格？ |
|---|---|---|
| 老逻辑（无 L2） | 恒定 **1 格** | 100% |
| 老逻辑（含 L2） | `1 + dash_frac` ≈ **1.12–1.24 格**（实测 `dash_frac` 12–24%） | 100% |
| **subpos（朴素实现）** | `quantize(mob_eff × gain)`，`mob_eff` 实测均值 **≈ 0.27** | **仅位移 ≥ 1 格时才跨格** |

⇒ 若直接取 `speed = mob_eff`，平均位移只有 **0.27 格** ⇒ **只有约 1/4~1/3 的"移动决策"真的跨格** ⇒ **跨格频率暴跌 ~70%**。

**后果**：遭遇率下降（P0.6 的诊断结论正是"瓶颈 = 猎物供给 / 找不到人"）⇒ **波 1 会削弱波 2 想强化的东西**。这正是 **C8 前提对账**要抓的那类错误（"机制按意图接线了吗" 之外的 "**机制意图 = 科学问题所需的前提吗**"）。

### 2.2 校准方案（推荐）

```python
speed = clamp(mob_eff × subpos_speed_gain, 0.0, subpos_speed_max)   # 单位：格/tick
steps = speed_steps(speed, subdiv)                                   # 量化到 0/0.25/.../speed_max
```

| 参数 | 初值 | 依据 |
|---|---|---|
| `subpos_speed_gain` | **4.0** | `mob_eff` 均值 ≈ 0.27（2k 冒烟实测）⇒ `0.27×4 ≈ 1.08` 格，接近历史 `1+dash_frac` 的 **1.12–1.24** |
| `subpos_speed_max` | **2.0 格** | subpos **本身包含 L2 的冲刺语义**（L2 只有 1/2 两档，subpos 是它的一般化）⇒ 上限必须 ≥ 2，否则"快的人无法补偿慢的人" |
| `subpos_min_energy_frac` | 0.2 | 沿用 L2 的**纯能量阈值**口径（`energy ≥ frac × max_energy`）⇒ 两机制同型，不新造一套 |
| `subdiv` | 4 | 0.25 格粒度（fish 指定） |

🔴 **判据（不是"平均 steps"，而是"跨格频率"）**：

> `mean_flat_moves_per_tick`（每 tick **真正换格**的个体比例）必须落在历史批同量级（`≈ move_prob × 1.0`，具体值由冒烟取基线）。
> **只报 `mean_steps` 会掩盖问题** —— 位移 0.75 格在 `steps` 上有值、在 `flat` 上等于没动。

### 2.3 若校不准怎么办（预注册的处置）

- 偏离 **< 10%** ⇒ 接受，登记实测值。
- 偏离 **10–30%** ⇒ 调 `speed_gain` **一次**（记录调前/调后）。
- 偏离 **> 30%** ⇒ **回板讨论**，不得连续调参凑数（fish 01:27 纪律）。
- 🔴 **不得**为了"保住遭遇率"而把 `speed_max` 提到 3+ 格 —— 那等于偷偷把世界变"更快"，是另一个机制（须独立立项）。

## 四、H3 互斥（为什么必须有）

`subpos` 与 `l2_dash` **都是"走多远"的乘子**：

- `l2_dash`：`1 格 / 2 格`（两档，概率闸由 `rand_choice % 100` 触发，**盲选目标**）
- `subpos`：`0 / 0.25 / … / 2.0 格`（多档，确定性由 `mob_eff` 给出，**沿用 score 选出的方向**）

同开 ⇒ 一个个体可能"被 L2 判为冲刺（目标换成 2 圈格）"**且**"被 subpos 判为走 0.5 格" ⇒ 语义冲突，且 `dash_frac` 与 `steps` 两个读数互相污染 ⇒ **归因不干净**。

⇒ **构造期硬报错**（fail-loud，不静默换路径）。这与项目既有 H3 传统一致（`l2_dash` / `corpse_enabled` 都这么做）。

## 十、"静止"策略：定量分析 + 文献先例 + 语义反转（fish 09-23 00:30 提出）

### 10.1 fish 的三个问题 → 代码事实

| 问题 | 现状 |
|---|---|
| 极点食物少 | ✅ **已实现**：`capacity = cell_area × capacity_per_area`，`cell_area ∝ cos(纬度)` ⇒ 极区容量 ≈ 赤道的 2.6% |
| 极点耗能高 | ✅ **已实现**（移动侧）：`move_cost_ind = move_cost × cold_penalty × (0.5+g6)`，`cold_penalty = 2 − 活动度`；且资源再生带温度因子（`≤−20°C` 时**再生≈0**，"极地冰封"） |
| 极点移速慢 | ❌ **未实现** ⇒ 本波可加（`speed` 已在此处，见 10.4） |

⇒ **fish 要的"越靠极点越易死"已经成立两条**，第三条（移速）本波补齐。

### 10.2 🔴 决定性数字：**静止**在我们模型里**能活**（这是构造巧合）

参数（默认）：`capacity_per_area=40` ｜ `regrowth_rate=0.5` ｜ `eat_amount=0.5` ｜ `eat_efficiency=3.0` ｜ `move_cost=0.4` ｜ `max_energy=300`

赤道一格（`cell_area ≈ 1`）独占时的静止收支：

```
取食入（质量→能量）= eat_amount × eat_efficiency = 0.5 × 3.0 = 1.5 能量/tick
格再生             = regrowth_rate × 温度因子     = 0.5 质量/tick
⇒ 取走 0.5 质量、补回 0.5 质量 ⇒ 存量**恰好动态平衡**
⇒ 静止净收入 ≈ 1.5 − 维持(实测 0.8–1.5) ≈ +0.2 ~ +0.7 能量/tick  ⇒ **能活，还能繁殖**
```

🔴 **注意 `eat_amount(0.5) == regrowth_rate(0.5)` 是构造巧合**（同量纲、同数值）。
它使"**一个静止个体独占一格**"成为**可持续策略**。而平均密度只有
`1944 / 7200 = 0.27 个体/格` ⇒ **静止在空间上平均可行**。

⇒ **fish 的担心成立**：朴素接入亚格坐标后，**"静止"会成为一个真实的备选策略**，
若选择压进一步偏向省能量，就会朝"一群不动的生物"漂移。

**但**：`uniform`（均匀）世界里"移动"**恒劣于**静止（移动只花钱、不赚钱）；
只有 **`patchy`（空间异质）** 才让移动有价值（去更富的格）。我们实验用的正是 patchy ✓ ——
所以风险是"**部分静止**"而非"全军静止"，但**必须监控**。

### 10.3 文献先例（三条，回答"已有先例怎么处理"）

| 先例 | 结论 | 对我们的用法 |
|---|---|---|
| **Andersson 1981** *On optimal predator search*（TPB 19:58） | 捕食者在 **连续移动** 与 **停顿—移动（pause-travel）** 间选择；用更新过程算**净能量摄入率**。🔴 **停顿时猎物检测率高于移动时**；**"移动能耗显著上升 ⇒ pause-travel 优于连续移动"**；最优停顿时间（giving-up time）**随猎物密度/可检测性上升而下降**，最优移动长度**随可检测性上升而增加** | ✅ **"停顿"必须换来信息收益**，否则只是省能量的退化；🔴 这给了"**停顿时视野/检测提升**"一个**理论必需性**（不是锦上添花） |
| **Cobbold & Stana 2020** *Bull Math Biol* 82:26 | **部分定居种群可以胜过全扩散种群**（在气候速度不太大时：既能存活于全扩散者灭绝的速度，又有更高密度） | ✅ "**部分静止**"是**正当生态位**，不是 bug；判据应盯"**占比是否失控**"而非"是否有人静止" |
| **Legrand et al.** *Proc R Soc B*（异质连通性下的扩散演化） | **极端扩散死亡率（50%）⇒ 选择极端定居个体** | ⇒ 若把移动成本抬太高，**就会**选出全定居 ⇒ **不能靠"加移动成本"来调控**，那样正好反了 |

### 10.4 设计：把"移动概率"改成"停留概率"（fish 明确要求）+ 纬度调速

**(a) 语义反转**（采纳 fish）

现在：`move_prob = g0(MOVE_PROB) × (1−g19) × (1−stay_prob)` ⇒ **默认不动，以概率移动**。
改成：**默认移动，以概率停留**，且**停留概率由状态/信息驱动**（不再是固定参数）：

```python
stay_prob_eff = clip(sim.stay_base                       # 基座（新参数，默认 0.0 = 默认走）
                     + sim.stay_food_k  * food_here      # 本格还有食 ⇒ 停着吃
                     + sim.stay_signal_k * has_signal    # 收到信号 ⇒ 停（去看/听）
                     + sim.stay_fear_k  * threat_near,   # 邻域有威胁 ⇒ 停（隐蔽）
                     0.0, sim.stay_max)                  # 上限（防"全停"）
moved = rng.random(P) >= stay_prob_eff                   # 🔴 RNG 形状不变（I3）
```

🔴 **必须保留 `rng.random(P)` 的形状**（每 tick 每人一次）⇒ 与 L2 的位域契约兼容（I3）。
`stay_max < 1.0` 是**硬性反退化闸**：任何个体都有下限的移动概率。

**(b) 纬度调速**（补 fish 的"极区移速更慢"）

```python
speed_cap = speed_max × (lat_floor + (1 − lat_floor) × cos(纬度))    # lat_floor 默认 0.3
```

⇒ 赤道 `speed_cap = speed_max`；极区 = `0.3 × speed_max`。依据：低温降低运动能力
（与我们已有的 `cold_penalty` 同族，但那条只管**耗能**、这条管**速度上限**）。

**(c) 🔴 必须同时给的"反退化"读数**（否则退化发生了看不出来）

| 读数 | 含义 | 警报线 |
|---|---|---|
| `immobile_frac` | 连续 N tick 未换格的个体占比 | **> 0.7 持续 ⇒ 退化** |
| `mean_flat_moves_per_tick` | 真正跨格的频率（§2.2 主判据） | 与历史同量级 |
| `steps_frac[0]` | `steps=0`（白移动）占比 | 若 ≈ 1 ⇒ 速度映射塌成常数 |

**(d) 若真出现退化，按序干预**（**不是**靠加移动成本 —— 文献 10.3 第三条说明那会反选出全定居）：

1. **打破 10.2 的巧合**：调 `regrowth_rate`（0.5 → 0.3）或 `eat_amount`（0.5 → 0.7），
   使"静止独占一格"不再平衡 ⇒ 静止者会慢慢吃空本格 ⇒ 必须移动。
2. **停顿时给信息收益**（文献要求，且**顺带服务项目主命题**）：停顿时视野/检测半径提升
   ⇒ 停顿不再是纯省能量，而是**换取信息**。
3. **降低移动成本**（fish 的方案）⇒ 让移动的相对代价变小。
4. 只有以上都不够，才考虑"静止者的风险"（如改"同格不可互吃"）—— **改动最大，最后考虑**。
