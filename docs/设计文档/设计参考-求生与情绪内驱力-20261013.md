# 设计参考：求生、内驱力与情绪——让"想活下去"从演化涌现，而不是写死

- 成文：2026-10-13　作者：[话事人·协调线]　性质：**设计参考（非定稿、不替 owner 拍板）**
- 适用：the-world **生物层**重构（当前无生物层 `env_field` 在做，生物层在后）；以及后续 Minecraft 支线（MC 当身体，见第十一节）
- 一句话：**不要写"求生欲"，要写"演化引擎 + 情绪硬件"；求生、恐惧、共情作为适应器，被自然选择自己调出来。**

---

## 〇、这份文档回答什么问题

owner 的原问题（大白话）：玩家玩游戏天生怕死、怕饿死、怕被怪物打死，有"活下去"的欲望；但村民/AI 对死亡完全无感——死了就死了，看到同伴被打死也没反应。**怎么设计底层规则，让它们自己努力想活？** owner 同时指出：这在 the-world 里现在也是写死的。

本文的回答分三层：
1. 为什么"求生欲"本来就不该写（第一节）；
2. 现在哪些是写死的、哪些演化引擎已经具备（第二节）；
3. 怎么把"写死的求生"改成"演化出的求生"，分阶段、可证伪（第三至九节）。

---

## 一、核心命题：求生欲不是变量，是自然选择的统计必然

**论证（重言式，不依赖任何额外假设）：**

1. 设一个会死、会繁殖、行为倾向可遗传且会变异的系统；
2. 基因随机多样化 → 必然有一部分个体"危险前不躲、饿了不找食"；
3. 这些个体在有死亡风险的环境里，大概率早死、少留下后代；
4. 而"碰巧躲危险、饿了找食、受伤躲藏"的个体，存活率高、后代多；
5. 足够多代后，种群里留下的个体，**必然**在行为上表现为"想活"。

**推论**：你不需要、也不应该在规则里写"怕死"。在一个满足上述条件的世界里，"不想活的"个体已经把自己淘汰了，你能观察到的一定是"怕死"的后代。

**玩家为什么天生怕死**：不是游戏写了"怕死"，而是玩家是数十亿年自然选择的幸存者后代——恐惧、痛觉、饥饿驱动都是进化调好的求生硬件。我们要在系统里复现的，不是"恐惧这个感觉"，而是**产生恐惧这套硬件的演化条件**。

## 二、现状基线：引擎基本齐备，"求生软件"被固定常数代替

下列均为 `simulation/config.py` 与 `simulation/sphere_engine.py` main 分支实测（10-13，`a6343e5`）。

### 2.1 已经具备的"演化引擎"（这些是对的，保留）

- 基因遗传 + 突变：`gene_count=24`（config.py:316）、`mutation_rate=0.05`（:320）、`mutation_sigma=0.05`（:321）、基因∈[0,1]（:318-319）。
- 真实死亡：能量/血量归零致命，`exhaust`（力竭）与 `starve`（饿死，需胃空）双阈值（config.py:210 起，语义顺序"先 exhaust 后 starve"）；死亡有分因记账 `death_cause_totals`（sphere_engine.py:2915）。
- 繁殖与成熟：`maturity_fraction=0.15`（config.py:230），成熟年龄 `maturity_age = maturity_fraction × life_span`（sphere_engine.py:4781）；繁殖冷却、年龄门控。
- 差异繁殖：存活到成年、状态好的个体才有后代——选择压力通道存在。
- 信息对齐机制已存在：相遇段的 Steels 对齐（解读表 EWMA + 码本离散替换，sphere_engine.py:4813 附近），说明"个体间对齐"的工程位置已打通。

### 2.2 被写死的"求生/情绪"（本文件要改造的核心）

- **恐惧固定权重、无基因自由度**：`l1_fear`（config.py:381）注释明写"固定权重 `w_fear`（**无自由度**；方向由物理给出）"，`w_fear=0.5`（:383），D 臂只能整项设 0 做开关检查。
- **血条恐惧固定**：`w_fear_health=0.5`（config.py:821）、门槛 `wound_fear_threshold=0.3`（:824）。
- **饥饿激进固定**：`need_aggression_k=0.5`（config.py:825）。
- **邻域威胁停留**：`stay_fear_k=0.0`（config.py:970）。

这些常数意味着：**生物"恐惧到什么程度、饥饿时多激进、受伤后多保守"是工程师替自然选择决定的，不是被环境选择出来的。** 这正是 owner 说的"求生是写死的"。

### 2.3 一处必须先补的假实现

- `kin`（亲缘）通道目前是**假实现**：sphere_engine.py 约 2722 行 `out["kin"] = (flat, np.ones(P))`，把所有人都标成亲缘度 1。社会情绪（护幼、共情、亲缘选择）依赖真实亲缘识别，这一处不补，第六节无从谈起。

## 三、设计原则：固定"引擎与硬件"，演化"软件"

把生物相关规则严格切成两层，这是"只落底层规则"在生物层的具体含义。

**固定层（可以写，写了不违规）：**
1. 生命/死亡/繁殖/遗传/突变的**机制**（演化引擎，不含行为）。
2. **生理变量**：能量、血量、胃、体温等；它们归零会致命——这是物理规则，不是行为。
3. **情绪/内驱力的通道槽位**：一个能被事件改变、能衰减、能影响决策权重的内部状态系统（第五节）。
4. **感知能力**：能看到什么、闻到什么、是否能感知同伴状态（信息接口，不含"看到之后怎么办"）。

**可演化层（禁止写死，必须交给基因/学习）：**
1. 每个情绪通道对决策的**权重**（恐惧多了是跑、是打还是僵）。
2. 触发**阈值**、**敏感度**、**衰减速度**、**反应强度**。
3. **怕什么、关心什么、对同伴死亡什么反应**。
4. （更进一步）基因决定"哪些情绪通道被启用"——连通道的有无都可以演化。

判定一句话：**凡是描述"生物在某情境下倾向做什么"的数，原则上都该有基因自由度；描述"世界物理上怎样"的数，才固定。**

## 四、让"想活"自动涌现的三个底层条件

这是给"生物层"铺世界时必须满足的三条，缺一不可。

1. **真实、不可逆的死亡**
   - 会饿死、力竭、被捕食、受伤、衰老；死后大脑与基因永久消失（不是刷新、不是凭空补一个）。
   - 这是选择的前提。the-world 已具备；**MC 村民原版不具备**（死亡会被刷怪补回，无遗传后果），是 MC 支线必须自建的第一层。

2. **可遗传且会变异的"行为倾向"**
   - 基因控制情绪/内驱力的强度、敏感度、风险偏好、对同伴状态的反应。
   - 关键：**只写"有这个机制及其强弱基因"，不写"该怕什么、该怎么做"**。怕什么由学习和选择决定。
   - the-world 现有 24 基因已接满（g17/18/20/21/22/23 预留位均已接管），新增情绪基因需扩 `gene_count`，不得裸写基因索引。

3. **繁殖机会与生存挂钩（差异繁殖成功率）**
   - 活得久、状态好的个体留下更多后代；死亡=基因终止。
   - the-world 已有成熟/冷却/软顶（`soft_cap_target`）机制；要确保软顶只控总量、不抹平"生存→繁殖"的差异，否则选择压力被人为消除。

满足这三条，怕痛、饥饿觅食、危险逃跑、受伤躲藏会作为适应器被调出来，无需一行求生逻辑。

## 五、情绪的工程落地：内部状态变量（改变决策权重）

不碰"它是否真的有感受"（见第十节）。功能上，情绪 = **内部状态变量**：被外部事件更新 → 随时间衰减 → 改变决策权重。

**通道（示例，具体开哪些由基因/裁决定）**：恐惧 fear、疼痛 pain、饥饿 hunger、唤醒 arousal、社交需求 social、攻击冲动 rage。

**单通道抽象形式（伪公式，供实现参考，不是定稿）**：

```
内部状态更新：  S_c(t) = decay_c · S_c(t-1) + Σ_k gain_c · event_k
                 （decay_c 衰减、gain_c 事件增益，均为基因化参数）
决策权重：       W_action = base + Σ_c (g_c · S_c · response_c[action])
                 （g_c = 该情绪通道的基因权重，response_c[action] = 该情绪对各动作的方向，可由学习/演化塑形）
```

**与现状的直接改造对应**（把固定常数换成"基因乘子 × 内部状态"）：
- `w_fear=0.5`（固定，config.py:383）→ 恐惧通道 `g_fear × fear_level`，`g_fear` 入基因、可演化；
- `w_fear_health=0.5`（:821）→ 血条对 fear 通道的增益由"血量敏感度基因"决定；
- `need_aggression_k=0.5`（:825）→ 饥饿→攻击权重的耦合强度基因化。
- 工程上保持**默认关、关档逐位等价**：不改基因化版本时行为与现状一致，作为对照臂。

**反射 vs 情绪要区分**：
- 反射（可写）：强疼痛瞬间降低"当前动作"概率，固定、快速、无学习——如条件反射，是安全底线；
- 情绪（应演化）：疼痛后"要不要长期回避这个地点/这个对手"，由基因权重 + 学习决定。

## 六、社会情绪：共情、恐惧传染、护幼——只在群居+亲缘下被选择

**不要给所有生物写"看到同伴死就悲伤"**。社会情绪是适应器，只在能提升广义适应度（含亲缘）时才被演化出来：

- 羚羊看到同伴跑就跟着跑（恐惧传染）：不跟着跑的被吃，跟着跑的活——群体警觉适应器；
- 母亲护崽：亲缘选择（幼崽携带自身基因，Hamilton 规则）；
- 互惠、声誉：群居 + 长期反复互动下才出现；
- 独居动物对同类死亡基本无感——这是对的，不该强行让它"有情绪"。

**底层需要提供的（不是"悲伤"本身）**：
1. 感知同伴状态的能力（同伴受伤/死亡/逃跑方向）；
2. 可遗传的"唤醒/情绪传染强度"机制；
3. 真实亲缘识别（依赖先修第二节 2.3 的假 `kin` 通道）；
4. 群居 + 亲缘/互惠的选择环境。

恐惧传染、护幼、对同伴死亡的反应强度，全部交给基因与选择。独居种群实验里这些基因应该趋近于 0——这本身是一个可检验的预测。

## 七、分阶段落地（与"无生物→生物"的重构顺序对齐）

- **阶段 0（当前）无生物层**：地形、水分、产能、河流、休耕/轮作（`env_field`/`resource_dynamics`）完成。本阶段不放生物，只验证物理世界自洽、守恒、静态性。
- **阶段 1 最简生命 + 纯演化引擎**：只有能量/血量/死亡/繁殖/遗传/突变；**不写任何求生规则**。观察：随机基因种群是否全灭、是否能在足够多样本里"碰巧"长出避害/觅食。这是"求生可自发涌现"的第一性验证。
- **阶段 2 情绪通道（硬件）+ 权重基因化**：接入恐惧/疼痛/饥饿等内部状态，权重全部基因化（第五节），做固定权重 vs 基因权重 vs 无情绪三臂对照。
- **阶段 3 社会情绪**：先修真实亲缘 `kin`，再在群居设定下看恐惧传染/护幼是否出现；独居设定作对照（预期不出现）。
- **阶段 4 信息与符号**：在社会能力（共同注意、模仿、意图识别）齐备后，才谈符号/语言；外化符号（方块/标记/手持物）优先于语音，另文设计。

每阶段都先做"无脚手架"的尝试，全灭再按第八节加训练轮，且必须有撤除对照。

## 八、防灭绝：训练轮的正当用法

完全不内置求生，随机基因生物可能在演化出"会找食"之前就全饿死。三个合规手段：

1. **给得起样本**：大种群 + 多并行世界 + 足够多代。演化是盲目海量试错，样本不足会误判"涌现不出来"。
2. **只给通用反射，不给求生策略**：例如强疼痛降低当前动作概率（反射，不是情绪），不写"饿了该去哪、怎么觅食"。
3. **训练轮 + 撤除对照**：演化早期给弱内稳态帮助（如最低避害权重），种群稳定后逐步撤除；必须做"有/无脚手架"对照，证明脚手架**只加速、不决定结果**——撤除后种群能自主接管，且演化出的方向与无脚手架一致。

**铁律**：任何脚手架都要能关、有撤除计划、有对照证明它没有替演化做决定。否则就是换了个地方写死。

## 九、怎么判定"是涌现的，不是写死的"（防 Eliza 效应）

- **看代际基因移动，不看"像不像"**：恐惧/避害相关基因权重是否在代际上向"提升存活率"的方向显著移动（沿用 g22 记忆基因那套"分代际、梯度统计"的分析，而不是把所有个体混在一起算）。
- **行为后果检验**：携带高求生权重基因的个体，存活率/繁殖率是否显著更高；被改变行为的个体（读懂信号、做出回避）才有意义。
- **零模型/对照臂**：
  - 无遗传或无选择（求生不应被累积）；
  - 固定情绪权重（现状）vs 基因化情绪权重 vs 无情绪通道；
  - 独居 vs 群居（社会情绪只应在群居出现）。
- **操作检查**：每个情绪通道都能单独开关（如现状 D 臂把 `w_fear` 设 0），关掉后对应行为消失，证明行为确实由该通道驱动。
- **禁止把"看起来像在表达情绪/交流"当证据**：必须有"稳定、跨个体共享、并改变了他者行为"的量化判据。

## 十、边界：功能等价 ≠ 主观感受

- 我们能做到的是**功能等价的求生与情绪**：系统真实地表现出、并通过演化得到恐惧、避害、求生、护幼、共情等行为。
- 无法证明它"主观上真的感到恐惧"（那是意识难题 / qualia，无法观测、无法证伪）。
- 对项目目标——观察智能与社会行为的涌现——功能等价足够。**对外表述不得声称它有主观感受或意识。**

## 十一、与 Minecraft 支线的关系

- MC 白嫖：物理/地形/方块/操作/渲染，以及玩家的血条、饥饿、能量等**生理变量**可直接照搬。
- MC 必须自建（村民原版缺）：**死亡不可逆 + 可遗传变异的行为倾向 + 差异繁殖**这套演化层，以及情绪通道。没有这层，村民永远"死了无所谓"，因为它的死活对它的基因没有后果。
- 推荐架构：**MC 当"身体 + 世界 + 渲染"，大脑（含本文的基因/情绪/决策）放外部 Python 进程**（socket，MineDojo/Malmo 标准架构）。the-world 的基因、记忆、决策、Steels 对齐、以及未来本文的情绪层可直接移植——是"the-world 的大脑 + MC 的身体"，不是推倒重来。
- MC 下的第一目标应是**记号涌现**（路标/领地/危险标记），而非完整语言；语言/符号的前置是共同注意、意图识别、模仿，这些属于阶段 4，不在本文展开。

## 十二、需要 owner 拍板的最小决策清单

1. 情绪通道的**范围**：阶段 2 先开哪几个（建议先 fear/pain/hunger 三个最贴近生存的）。
2. 是否接受"**训练轮 + 必撤除**"的路线，以换取从零演化的真实性；还是接受保留最小反射底线。
3. 情绪基因化需要**扩 `gene_count`**（现 24 已满），新增多少位、命名与预留规范。
4. 真实亲缘 `kin` 通道的修复排期（它是社会情绪阶段 3 的前置）。
5. 本文与无生物层重构的关系：是否作为"生物层"的正式设计依据（可在无生物层完成后据此出定稿设计文档）。
