## 三、L1 设计（**逐候选**、信息自洽）

### 3.1 每 tick 预计算（全局一次）

| 量 | 定义 | 落点 | 备注 |
|---|---|---|---|
| `occ` | 已存在 —— `[代码]` :1325 `occ = np.bincount(self._flat[:P], ...)`（移动前位置占用） | 复用 | 0 成本 |
| `agg_field[c]` | 每格**威胁强度**：`Σ_{占该格 j} max(0, g16_j − attack_gene_gate)` | 新增 1 行（紧跟 :1325） | 1 次 `bincount(P)` |
| `prey_field[c]` | 每格**可食个体数**：`Σ_{占该格 j} 1[g16_j ≤ attack_gene_gate]` | 新增 1 行 | 🔴 **v2 按内评 §三 实质修正**：猎物 = "**可吃的（低 g16）个体**"，不是"任何活物" |

### 3.2 两项逐候选项（插在 :1570 之后、`if d2_softmax:` :1572 之前）

```
# ── L1a 追猎（g17 载体，权重带预注册上限）─────────────────────────────
# prey_occ[c] = 候选格 c 上的"可食个体"数（低 g16）⇒ 归一化为二值"这格有可吃的人吗"
prey_occ = np.minimum(prey_field[nb], 1)                       # 0/1
score = score + (w_seek_max * genes[idx, Gene.SEEK_TENDENCY]) \
                * perc * genes[idx, Gene.AGGRESSION] * prey_occ

# ── L1b 恐惧（固定权重，无自由度）────────────────────────────────────
danger = nb[agg_field[nb] > 0.0]        # 可见：我知道 1 圈里哪个邻居是威胁
if len(danger) > 0:
    cos_to_danger = self._memory_orientation_cos(int(self._flat[idx]), nb, danger)
    score = score - w_fear * perc * (1.0 - genes[idx, Gene.AGGRESSION]) * cos_to_danger
```

**为什么必须逐候选**（v1 的核心论证，R148 §一 已认账）：逐个体标量项对**所有候选**加同一常数 ⇒ `argmax` **逐位不变**、`softmax` **数学上无效应**（`[实测]` 概率差 9.6e-15、20 万次抽样 0 次改变选择）⇒ 按原字面实现会得到**静默 no-op**。

**信息自洽（最硬的一条纪律）**：两项**只用**"我自己的格 + 我 1 圈的格"——
- `prey_field[nb]` = 邻格有没有可吃的人（1 圈内可见）✓
- `cos_to_danger` = 用**我自己的坐标**与**邻居的坐标**算方向（两者都在 1 圈内）✓，且**复用现成 helper**（`[代码]` :2319 `_memory_orientation_cos`，返回逐候选 `max` cos，语义正好 = **背向给负分**；已与 Rust 逐字同式）

⚠️ **不得**用 `Σ_{d∈adj(c)} occ[d]` 这类"候选格的邻域聚合"—— 那需要**距离 2** 的信息（本项目 09-19 栽过的同一类错）。

**两条写死（内评 §三）**：
- 🔴 一切"占邻格比例"类量（`prey_avail`/`threat`）的分母 = **有效邻居数**（极区 `_nb_table` 有 `-1` 填充；用固定 stride 会**系统性低估极区**）。
- 🔴 威胁门槛**引用同一常量** `attack_gene_gate`（`[代码]` `config.py:231`），**不得复制字面量**（已因 `f_bit 0.5` vs `has_food 0.3` 付过学费）。

**权重载体（R148-5/6 定稿）**：

| 权重 | 载体 | 取值 | 预注册 |
|---|---|---|---|
| `w_seek` | `w_seek_max × g17`（`g17` = **SEEK_TENDENCY**，可演化） | `w_seek_max` ∈ **{0.5（B 臂）, 0.25（C 臂）}** | **上限 0.5**；**两档都过才算**，否则记「**参数依赖**」 |
| `w_fear` | `SimulationConfig` 固定字段（**不给自由度**） | 0.5（B/C）｜**0（D 臂）** | D = **操作检查臂**（回答"回避行为是否存在"），**不参与科学判据合取** |

**与既有 `densities` 项共线（内评 §三点名）**：`prey_occ` 与群居项 `soc×densities[nb]` 都随"邻格占用"单调 ⇒ **必须报 `corr(prey_avail, densities)`**；若 |corr| ≈ 1 ⇒ **"g13 下降"归因给 L1 还是替代关系不可分辨** ⇒ 写入 §九 已知限制（本批不解决，但必须读数）。

**量级自检（v2 新增）**：以 trait 均值估（`g17`≈0.5、`perc`≈0.5、`g16`≈0.4、`prey_occ`≈0.27）⇒ L1a 典型贡献 ≈ **0.0135**（vs 食物项 ≈0.19）；上限（trait 全满）≈ **0.5**。⇒ 不靠手调放大，改由 §七 **闸门 D** 实测"该项是否非退化"。

## 四、L2 设计（两段式冲刺 / 盲选）

### 4.1 为什么不用"扩候选集 + score 采样"（三条理由，R148-2 全部认账）

① **信息诚实**（最硬）：感知半径恒 1 格 ⇒ 个体**对 ring-2 一无所知**，给距离-2 格算 score = **凭空造信息**；② **几何反效**（§二.2/2.3）；③ 候选 8→24（极区 241）⇒ 决策内层循环近线性变慢。

### 4.2 两段式定义

```
第一段（走多远）：dash_i = 1  ⟺  四条同时成立
    ① l2_dash 开（臂变量）
    ② energy_i ≥ dash_min_energy_frac × max_energy     ← 纯能量阈值（fish 口径：仅此一条）
    ③ energy_i ≥ 4 × move_cost_ind_i                   ← 2 格成本闸
    ④ far_len[cell_i] > 0  且  (rand_choice_i % 100) < int(100 × mob_eff_i)
       mob_eff_i = genes[i, Gene.MOBILITY] × age_factor_i     ← g18 载体
第二段（选哪格）：
    d = 1 ⇒ **原有 score 机制（argmax / softmax）一行不改**
    d = 2 ⇒ strict 2 圈内**均匀盲选**：far[off[c] + (rand_choice_i // 100) % far_len[c]]
扣费：energy -= move_cost_ind_i × (1 + κ(d²−1))，κ=1.0 ⇒ d=2 时 **×4**（同步记 EC_MOVE）
```

- 🔴 **"盲选"是设计选择**：个体对 ring-2 无信息 ⇒ 均匀是**信息上诚实**的先验；"用信息换距离"的取舍交给选择。
- `age_factor`（fish 指定）：幼体(<`maturity_fraction`×**个体自己的** lifespan) / 成年 / 老年(≥`senile_fraction`×同) = **0.55 / 1.0 / 0.55**；复用 `config.py:101/102` 既有阈值，**不新造**（内评 §四：基准须为**个体自己**的 lifespan，用群体中位会让分组随 g3 分布漂移）。
- 老幼 `mob_eff` 低 ⇒ dash 概率低 ⇒ **"捕食者更倾向捕食老幼"是物理后果**（无需外加成功率乘子）⇒ R141 `vuln` **保持备选、与本批不同开**（R148 §六 追认）。
- ⚠️ **两个闸都是纯能量比较、判定顺序无关**（内评 §五）；新码**不得**出现"饱食/饥饿/satiety/hunger"语义（`attack_prob ∝ 饥饿` 是**既有**捕食段的事，不扩散）。

### 4.3 🔴 H2 合规论证：位域拆分**不是**"同一 `u` 比两个阈值"（R148-2a 要求文档化 + 受测）

**被禁止的写法**（H2 点名）：`u = rng.random()` 后 `u < move_prob` 与 `u < dash_gate` 两次比较 ⇒ 两事件强相关（`[实测]` `u<0.5` vs `u<0.3` 相关系数 **0.6536**）⇒ **不可当两次独立判定**。

**本设计用的是另一个抽数 `rand_choice` 的位域**：

| 项 | 值 |
|---|---|
| 来源 | `[代码]` :1505 `self.rng.integers(0, 1_000_000, size=Nm)` —— **已存在**，且 **softmax 路径下未被消费** |
| 位宽映射 | `lo = rc % 100` ⇒ **0–99**（1% 分辨率）｜`hi = rc // 100` ⇒ **0–9999** |
| 为何不相关 | `10^6 = 100 × 10^4` **恰好整除** ⇒ `rc ↦ (lo, hi)` 是到 `[0,100)×[0,10000)` 的**双射**，均匀源下每个 `(lo,hi)` 概率恒 `1e-6` ⇒ **两字段不相关**（数学性质，**不是**两次独立抽样） |
| `[实测]` 独立性 | n=1e6：`lo×hi` 列联表（100×100）**卡方 9775.6，df = 9801**（期望≈df ⇒ 无相关证据） |
| `[实测]` 冲刺概率 | mob = 0.25/0.5/0.9 ⇒ 实测 **0.2495 / 0.4991 / 0.8997**（理论 0.25/0.50/0.90；差异 = `int(100·mob)` 的 1% 量化） |
| `[实测]` 条件选格 | 冲刺者的选中格占比极差 **1.028–1.042**（近似均匀） |
| ⚠️ 模偏差 | `hi % far_len`：10000 不被 21–24 整除 ⇒ 相对偏差 **≤ +0.12%**（确定性、可忽略；20/16 恰好整除 = 无偏） |

🔴 **措辞纪律（R148-2a）**：本机制是"**一个已抽整数按位域复用**"，**不得**在任何报告里写成"两次独立判定/两次独立抽样"。正确表述 = **"同一抽数的两个位域；在均匀源假设下两字段不相关（已实测），但它们是同一次抽样的产物，不构成独立随机化"**。另：**关档必须逐位等价**（位域只在 L2 开启时使用），关档时平局回退（:1616–1617）**逐字保留原式**。

### 4.4 极区排除（R148-2b：**量化 + 分层 + 措辞**）

- 🔴 **措辞写准**：排除的是"**strict 2 圈规模 > FAR_CAP 的格**"（拓扑退化），**不是"极区个体"**。
- `[实测]` 排除集 = **480 格 / 6.67%**，**仅行 0/1/58/59**；`FAR_CAP ∈ [16,120]` 结果相同。
- 预注册报告要求：① 报 **`polar_pop_frac`**（极区**人口**占比，run 期实测）；② `g18_mean/std` 与 `dash_frac` **按极区/非极区分层**；③ **若 `polar_pop_frac > 10%` ⇒ 判据必须做区制/区域匹配**。

### 4.5 CSR 构造与 ABI

- 构造期一次：`_far_off[n_cells+1]` + `_far_cells[]`（int32）+ `_far_len[]`；用 `[代码]` `_nb_table`/`neighbors()` 语义（极点格走整带），**不得**套 5×5 方窗。
- **不动 Rust**（H3 硬报错即可）；`movement.rs::step_movement` **入参无 age** ⇒ 若日后下沉须扩 ABI 并同步 `age_factor`。

### 8.2 判据：「一主两支持」+ 三态（R148-4）

| 角色 | 判据 |
|---|---|
| **主** | **`g16` 的 `D_shape` 双峰**（对"营养级分化"构念最直接） |
| **支持（只报，不合取）** | ② `g18` 双峰 ｜ ③ 双峰位置相关性 |
| **判定** | 主过 + 支持过 = **分化**｜主过 + 支持不过 = **「分化证据不完整」**（独立状态，**不是**未分化）｜主不过 = **未分化** |

**口径锁定（内评 §六）**：
- `D_shape` 必须报 **`ΔD = D_obs − median(D_null)`**；**`D_null` 构造锁死** = 矩匹配单峰 + 同 n + **seed 级或块置换**（防"同个体跨 tick 重复"虚增 n）。
- ③ 的"两峰负相关"**不得**用个体级 Pearson（被中间态稀释）⇒ 用**按 g16 峰分组后的组间相关**或**混合模型两分量均值相关**；并报**有效 n = 每代独立个体数**。
- 方差作**描述列**；主用**稳健量**（IQR / 5–95 分位差）；**同 run 内配对**。
- 🚫 仍禁止把「g16/g18 均值变化」或「dash 用得多」写成"分化"。

**漂变判别（R148-8，零额外机时）**：B/C 的 `g18` 双峰必须**超过 A 臂的漂变基线**，**且**伴随 **`dash_frac` 的结构性分化**；否则 `g18` 双峰**不可采信**。

**预注册（R148-9）**：本批**允许"捕食率下降"为合法结果**；分化判据与"捕食率上升"**解耦** ⇒ **不得**因 `pred_frac` 下降而判本批失败。

**旧纪元标签（内评 §二）**：引用 180k / 300k（含"g15 死透不回"）时必须带**旧纪元**标注。

### 8.3 功效预跑（R148 §五.15）

冒烟（1 run × 2k）**只够查闸门、不够算功效** ⇒ 正式批前插一步：**同纪元 2–3 seed × 4k**，然后：
1. 主判据：用**同纪元对照臂**的 `D_shape` **seed 间 sd** 反算可检出 `|ΔD| = t·s_d/√n_seed`；
2. 支持③：在 **Fisher-z** 尺度算（与 R44 `r44_power_prerun.py` 同工具）；
3. **由功效反推 seed 数**（不再拍 6）。
