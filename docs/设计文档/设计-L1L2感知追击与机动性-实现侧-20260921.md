## 三、L1 设计（逐候选，信息自洽）

### 3.1 每 tick 预计算（**全局一次，不随个体重复**）

| 量 | 定义 | 落点 | 成本 |
|---|---|---|---|
| `occ` | 已经存在（S0 段，`[代码]` :1325 `occ = np.bincount(self._flat[:P], ...)`）——**移动前的位置占用**，正是"我能看见谁站在邻格" | 复用，**不新增** | 0 |
| `agg_field[c]` | 每格**威胁强度**：`Σ_{占该格的个体 j} max(0, g16_j − attack_gene_gate)` | 新增一行，紧跟 :1325 | 1 次 `bincount(P)` |

⚠️ `agg_field` 是**格域**（`n_cells` 长度），只为下一步索引用；**不代表个体能感知 2 圈**（见 3.3 的红线）。

### 3.2 两项逐候选项（插在 :1570 之后、`if d2_softmax:` :1572 之前）

```
# L1a 追猎倾向（g17 接管）：朝"有人站的格子"走
#   occ[nb] 可见（候选格就在我的 1 圈内）；归一化到 ~[0,1] 与 fr/sp 同量级
seek_occ = np.minimum(occ[nb], 2).astype(np.float64) * 0.5
score = score + SEEK_SCALE * genes[idx, Gene.DIET] * perc * genes[idx, Gene.AGGRESSION] * seek_occ

# L1b 恐惧（权重固定，不给自由度）：远离"危险的邻居方向"
danger = nb[agg_field[nb] > 0.0]          # 可见：我知道哪个邻居是威胁
if len(danger) > 0:
    cos_to_danger = self._memory_orientation_cos(int(self._flat[idx]), nb, danger)
    score = score - FEAR_SCALE * perc * (1.0 - genes[idx, Gene.AGGRESSION]) * cos_to_danger
```

- 🔴 **复用现成 helper**（`[代码]` :2319 `_memory_orientation_cos`，返回逐候选 `max` cos）：语义正好（**背向给负分**才是梯度），且它**已与 Rust `movement.rs` 逐字同式** ⇒ 未来下沉时不引入新几何代码。
- 🔴 **信息自洽（本轮最重要的一条设计纪律）**：两项**只用**"我自己的格 + 我 1 圈的格"就可以算
  （`occ[nb]` = 邻格有没有人；方向 = 用我自己的坐标 + 邻居的坐标算 cos）⇒ **不越过"感知半径恒 1 格"**。
  ⚠️ 对比：若用 `Σ_{d∈adj(c)} occ[d]` 这类"候选格的邻域聚合"，那需要**距离 2** 的信息 ⇒ **构念与通道不一致**（本项目 09-19 栽过一次的同一类错）。
- `danger` 用 `attack_gene_gate`（**同**捕食判据的阈值，`[代码]` `config.py:231` = 0.3），不做第二套阈值。
- `SEEK_SCALE`/`FEAR_SCALE`：**待标定项**（§十.3）。现状分数量级 `[代码]`：食物项 ≈0.19、群居项 ≈±0.25（`smw=1.0`）⇒ 建议初值各 **0.5**，并在冒烟里报出两项的**实际贡献均值**以确认非退化。

### 3.3 逐候选 vs 逐个体（对 §〇-A 的展开）

| 形态 | 候选格上的取值 | 对决策的效果 |
|---|---|---|
| 派工单 §2.2 字面（`prey_avail` 逐个体） | **常数** | 🔴 **无效应**（`[实测]` argmax 逐位相同；softmax 数学无效应、数值差 9.6e-15、20 万次抽样 0 次改变选择） |
| 本稿 §3.2（`occ[nb]` 逐候选） | 随候选格变化 | ✅ 真能改方向 |

⇒ 这不是"实现口味"，而是**"这一项到底编码了什么"**（教训库 #7）。**建议：把"逐候选"写成实现侧硬要求**，并在测试里加一条"若某项对所有候选完全相同 ⇒ 该测试失败"的**反退化断言**。
📌 顺带一条自己的教训：我第一稿把这条写成"softmax **逐位**相同"，**数值校验当场推翻**（浮点舍入 1e-15）⇒ 已改为"数学上无效应 + 数值差 1e-15 + 实测 0/20 万次翻转"。**"我证明了"必须落到"我验到了哪一档"。**

## 四、L2 设计（两段式冲刺）

### 4.1 为什么不用 §3.2 的扩集形态（写给裁定者）

| 问题 | 证据 |
|---|---|
| ① 距离-2 格的分数**不可观测** | `[代码]` 移动决策只看 `fr[nb]/sp[nb]/densities[nb]/nb_sigs`（全是 1 圈）；对距离-2 格，**食物/信号/占用都无法看到** ⇒ 给它们算 score = 凭空造信息（且与 D2 `perception_radius` 语义冲突） |
| ② 对猎物**反效**（几何实测） | `[实测]` §2.2/2.3：极区暴露 31.6%→**90.4%**；且扩集**同时**把所有个体的候选集增大 ⇒ "多走一步"变成"多走一步**并且**更容易停在危险格" |
| ③ 运行开销 | `[实测]` 候选 8→24（极区 241）⇒ 决策内层循环（含 `np.isin`、`list` 推导 :1565–1569）近似**线性放大**；`[推断]` 12k 批的单跑墙钟 +30–100% |
| ④ 归因变脏 | 扩集**同时**改"可达性"与"方向选择"⇒ L1/L2 不可分辨；两段式下 L2 不动任何 score ⇒ **L2 ⊥ L1** |

### 4.2 两段式定义

```
第一段（决定走多远）：dash_i = 1 当且仅当四条同时成立
    ① l2_on（臂变量）
    ② energy_i ≥ dash_min_energy_frac × max_energy          ← 纯能量阈值（fish 口径：仅此一条）
    ③ energy_i ≥ 4 × move_cost_ind_i                        ← 成本闸（不替代 ②）
    ④ far_len[cell_i] > 0  且  (rand_choice_i % 100) < 100 × mob_eff_i
       mob_eff_i = genes[i, Gene.DEFENSE] × age_factor_i
第二段（选格）：
    d = 1 ⇒ 原有 score 机制（argmax / softmax），**一行不改**
    d = 2 ⇒ 在 strict 2 圈里**均匀盲选**：far[off[c] + (rand_choice_i // 100) % far_len[c]]
扣费：energy -= move_cost_ind_i × (1 + κ(d²−1))，κ=1.0 ⇒ d=2 时 ×4
```

- 🔴 **"盲选"是设计选择，不是偷懒**：个体对距离-2 一无所知 ⇒ 均匀正是**信息上诚实**的先验；冲刺的代价（4× 能耗 + 放弃信息）与收益（脱离已知威胁 / 缩短已知间距）由**选择**去权衡 —— 这正是"机动性是自由度"的意思。
- `age_factor`（fish 指定）：幼体(<`maturity_fraction`×寿命) **0.55** / 成年 1.0 / 老年(≥`senile_fraction`×寿命) **0.55** —— **复用现成的两个阈值常量**（`[代码]` `config.py:101/102` 已在用），不新造阈值。老幼 `mob_eff` 低 ⇒ dash 概率低 ⇒ **"捕食者更倾向捕食老幼"由物理自动产生**（无需外加成功率乘子 ⇒ 与 §3.3 相洽，R141 的 `vuln` 权重保持**备选**、**不同批开**）。

### 4.3 位域拆分（H2 的无相关性实现）

`rand_choice ~ U{0..999999}`，且 `10^6 = 100 × 10^4` **正好整除** ⇒ `低 2 位 = rand_choice % 100` 与 `高位 = rand_choice // 100` 在均匀分布下**精确独立**。

| 字段 | 用途 | 精度 |
|---|---|---|
| `% 100` | 冲刺闸（与 `mob_eff` 比较） | 1% 分辨率（`mob_eff` 连续 ⇒ 闸门概率实际为 `floor(100·mob)/100`） |
| `// 100` | 格内选择（2 圈均匀；softmax 关闭时的平局回退） | ≥ `len(nb)` 足够 |

⚠️ **仅 L2 开启时**平局回退（:1616–1617）改用高位字段；关档**逐字保留原式**（H1）。

### 4.4 极区与球面拓扑

- `far[]` 用 **strict 2 圈**（2 跳可达、去掉自身与 1 圈）**集合**构造（`[代码]` 邻居表用 `neighbors()`/`_nb_table` 语义，极点格走整带；**不得**用 5×5 方窗）。
- **构造期一次性 CSR**：`_far_off[n_cells+1]` + `_far_cells[]`（int32）；同时算 `_far_len[c]`。
- 🔴 **极区排除**：若 `far_len[c] > FAR_CAP`（建议 **32**）⇒ 该格**不可冲刺**（`far_len=0`）。`[实测]` 这会排除极点邻带（ring2 130–241），保留赤道/中纬（20–24）。在 `switches`/summary 里报 `dash_ineligible_cells`，**不许静默**。
