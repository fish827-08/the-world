## 三、L1 设计（逐候选 / 信息自洽 / **v3 修正量级口径**）

### 3.1 每 tick 预计算

| 量 | 定义 | 落点 |
|---|---|---|
| `occ` | 已存在（符号锚点 `occ = np.bincount(self._flat[:P], ...)`，移动前占用） | 复用，0 成本 |
| `agg_field[c]` | `Σ_{占 c 的 j} max(0, g16_j − attack_gene_gate)`（威胁强度，格域） | 新增 1 行 |
| ~~`prey_field`~~ → **`lowagg_field[c]`** | `Σ_{占 c 的 j} 1[g16_j ≤ attack_gene_gate]` —— 🔴 **R149-6① 改名**：引擎里**邻格任何人皆可被吃**，它不是"可食集"，而是"**低攻击性个体（猎物代理）**"；旧名会误导（触发我方刚立的 C5 命名项） | 新增 1 行 |

### 3.2 两项逐候选项（插在 `score = score + 0.4 * perc * interp` 之后、`if d2_softmax:` 之前）

```
# L1a 追猎（g17 载体；权重带预注册上限）
lowagg_occ = np.minimum(lowagg_field[nb], 1)                    # 0/1 指示量
score = score + (w_seek_max * genes[idx, Gene.SEEK_TENDENCY]) \
                * perc * genes[idx, Gene.AGGRESSION] * lowagg_occ

# L1b 恐惧（固定权重，无自由度）
danger = nb[agg_field[nb] > 0.0]
if len(danger) > 0:
    cos_to_danger = self._memory_orientation_cos(int(self._flat[idx]), nb, danger)
    score = score - w_fear * perc * (1.0 - genes[idx, Gene.AGGRESSION]) * cos_to_danger
```

**逐候选的必要性**（R148-1 已认账）：逐个体标量 ⇒ 全候选取同值 ⇒ `argmax` 逐位不变、`softmax` 数学无效应（`[实测]` 9.6e-15 / 20 万次 0 翻转）。

**信息自洽**：`lowagg_field[nb]`（1 圈内可见）｜`cos_to_danger`（**自身坐标 + 邻居坐标**，1 圈内）⇒ **不越"感知半径恒 1 格"**；复用 `_memory_orientation_cos`（语义 = **背向给负分**，已与 Rust 逐字同式）。
⚠️ **禁** `Σ_{d∈adj(c)} occ[d]` 型"候选格的邻域聚合"（需要距离 2 信息）。

**两条写死**：分母 = **有效邻居数**（极区 `_nb_table` 有 `-1` 填充）｜威胁门槛**引用同一常量** `attack_gene_gate`，**不复制字面量**。

### 3.3 🔴 v3 修正：量级口径（内评 N2 —— v2 算错了）

- v2 用 `prey_occ ≈ 0.27`（那是**每格平均占用** λ），但 `lowagg_occ` 是**逐候选 0/1 指示量**。
- 正确：`E[lowagg_occ] = 1 − exp(−λ·p_low) ≈ 1 − exp(−0.270×0.30) ≈ **0.078**`（λ=0.2699 来自 `ak2_s42` 中位 N=1943.5；p_low≈0.30 待段一实测替换）
  ⇒ L1a 实际量级 ≈ **0.004（B 臂）/ 0.002（C 臂）**，**不是 v2 的 0.0135**。
- 🔴 **随人口强相关**：饱和态 `N=3240 ⇒ λ=0.45 ⇒ 0.1263`（比捕食态高 **62%**）⇒ 因**区制抽签**会让 A/B/C 落在不同区制，**绝对阈值尤其不可用** ⇒ 闸门改**相对份额 + 解析期望对照**（§七）。

### 3.4 自熄预注册（N2）

`lowagg_occ` 依赖"场上还有低 g16 个体"；**捕食者变多 ⇒ 猎物池缩小 ⇒ 该项自熄**（300k 实测 g16 直方图 100% 落 0.3–0.6 ⇒ 极端下 `lowagg_field ≡ 0`）。
⇒ 🔴 **预注册为允许结局**：「**猎物池枯竭 / 狂奔捕食**」，**不得**在事后被读成"没接线"。

### 3.5 权重载体

| 权重 | 载体 | 取值 | 预注册 |
|---|---|---|---|
| `w_seek` | `w_seek_max × g17`（`SEEK_TENDENCY`，可演化） | `w_seek_max ∈ {0.5(B), 0.25(C)}` | 上限 0.5；**两档都过才算**，否则记「参数依赖」 |
| `w_fear` | `SimulationConfig` 固定字段 | 0.5（B/C）｜**0（D 臂，操作检查）** | 外鉴/文献：**低通量下最优规避 ≈ 零** ⇒ **允许「fear 无效应」且不判失败** |

## 四、L2 设计（两段式冲刺 / 盲选）

### 4.1 形态

```
dash_i = 1 ⟺ ① l2_dash 开
             ② energy_i ≥ dash_min_energy_frac × max_energy
             ③ energy_i ≥ (1 + κ(2^p − 1)) × move_cost_ind_i
             ④ far_len[cell_i] > 0 且 (rand_choice_i % 100) < int(100 × mob_eff_i)
mob_eff_i = genes[i, Gene.MOBILITY] × age_factor_i
d=2 ⇒ far[off[c] + (rand_choice_i // 100) % far_len[c]]（**盲选**）
扣费 energy -= move_cost_ind_i × (1 + κ(d^p − 1))，κ=1.0，**默认 p=2 ⇒ ×4**
```
- ②③ 都是**纯能量比较、判定顺序无关**（内评已判口径合规）；新码**不得**出现"饱食/饥饿/satiety/hunger"语义。
- ③ 写成 `(1 + κ(2^p − 1)) × move_cost_ind_i`（**p 入公式**，为 R149-7 敏感性档留位）。
- 🔴 **"盲选"是设计选择**：个体对 ring-2 无信息 ⇒ 均匀才是信息诚实；"用信息换距离"交给选择权衡。

### 4.2 🔴 p 档解析成本曲线（R149-7；**零机时新实测**，`tools/l1l2_p_cost_curve.py`）

基线（`[实测]` calib1 **旧纪元** energy_ledger，人均）：`cost_move = 0.0778`｜`cost_meta = 0.8038`｜`net`（不含光合）`= 1.3931`｜**移动占(移动+维持) = 7.7%**

| dash 比例 f | p=1（×2） | Δnet | **p=2（×4）** | Δnet | p=3（×8） | Δnet |
|---|---|---|---|---|---|---|
| 0.2 | 1.20 | −1.1% | 1.60 | **−3.4%** | 2.40 | −7.8% |
| 0.5 | 1.50 | −2.8% | 2.50 | **−8.4%** | 4.50 | −19.6% |
| 1.0 | 2.00 | −5.6% | 4.00 | **−16.8%** | 8.00 | −39.1% |

**净收入归零的 `f*`（解析）**：p=1 → **17.9**｜p=2 → **5.97**｜p=3 → **2.56** —— **三档都 ≫ 1**。
⇒ 🔴 **判读**：**冲刺成本不构成"经济可行性边界"**（哪怕全员全程冲刺也吃不满净收入）⇒ `p` 调的是**收益/成本比**，不是可行域。⚠️ 旧纪元数据，段一冒烟须重测此表。

### 4.3 H2 位域合规（同 v2 + 入库）

`lo = rc % 100`、`hi = rc // 100`，`10^6 = 100 × 10^4` **恰好整除** ⇒ 双射 ⇒ 均匀源下两字段不相关（**数学性质，不是两次独立抽样**）。
`[实测]`（**权威件** `tools/l1l2_bitfield_check.py`）：χ² = **9775.6**（df 9801；cell 65–136）｜`corr(lo,hi) = +0.00085`｜冲刺率 **0.2495 / 0.4991 / 0.8997**｜禁止写法对照 **+0.6536**。
🔴 **措辞纪律**：**禁写"两次独立判定 / 两次独立抽样"**；正确表述 = 「同一抽数的两个位域；均匀源假设下两字段不相关（已实测），但它们是同一次抽样的产物，不构成独立随机化」。
🔴 **模偏差**：可达 `far_len` 只有 {12, 16} ⇒ **16 无偏**、**12 为 +0.08%**（确定性）。

### 4.4 极区排除

排除"**strict 2 圈规模 > `FAR_CAP` 的格**"（拓扑退化，**非"极区个体"**）= **480 格 / 6.67%**（行 0/1/58/59；`FAR_CAP ∈ [16,119]` 同集）。
报告：`polar_pop_frac`（**人口**占比，run 期实测）+ `g18` / `dash_frac` 按极区/非极区分层；**>10% ⇒ 判据须做区制/区域匹配**。

### 4.5 `age_factor` 的性质声明（外鉴提醒）

幼/老年 ×0.55 是**设计选择**（fish 指令），**不得**挂"老 = 慢"的文献结论（变温类群常相反：老 = 大 = 更快）。寿命基准用**个体自己的 lifespan**。

## 九、判据（一主两支持 + 三态 + **第四态**）

| 角色 | 判据 |
|---|---|
| **主** | `g16` 的 **`D_shape` 双峰** |
| **支持（只报，不合取）** | ② `g18` 双峰 ｜ ③ 双峰位置相关性 |
| **判定** | 主过 + 支持过 = **分化**｜主过 + 支持不过 = **「分化证据不完整」**｜主不过 = **未分化**｜**世代门或产物池门不过 = 「纪元不足·判据不可执行」**（与 R3 生态门同构，**不得**与"未分化"互相替代） |

**仪器口径（内评 23:06 §八 × 外鉴 §四 合流）**：
- 单位 = **run（seed）**（配对 ΔD、置换/秩；**禁池化算 p**）；run 内 `n_eff = T/(2·τ_int)`；个体级只取同 tick 同世代类 + 报 `DEFF`。
- `ΔD = D_obs − median(D_null)`；`D_null` **锁死** = 矩匹配单峰 + 同 n + **seed 级或块置换**；🔴 **第二零模型 = 镜像折叠单峰 null**（内评对 BC 的"矩匹配不匹三阶矩"批评对 `D_shape` 同样成立）。
- 🔴 **bin 半箱平移第二口径**（同向才判过）。
- 稳健量作主（IQR / 5–95 分位差），方差作描述；**同 run 内配对**。
- 🚫 **两级措辞红线**：「**拒单峰**」 ≠ 「**两分量混合为真**」（后者须 bootstrap LRT 过）。
- 🚫 禁把「均值变化」「dash 用得多」写成"分化"；旧纪元结论（180k / 300k）引用**必须带旧纪元标签**。

**功效**：段一 30 run 天然给**配对差 `s_Δ`** 的估计（**只用方差、不估效应**）；段二 `n=3` 的 MDE = **2.48 × s_Δ**；若段一暗示效应小 ⇒ 段二加 seed 或延长 tick（**预算优先加 tick 长度**，因 seed 不增世代）。
