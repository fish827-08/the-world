# 设计稿 —— 行动选择：从"加权融合"到"模式仲裁"

> 日期：2026-09-27 ｜ 作者：`[所有者·天平]` ｜ 状态：**🟢 R238 立项（设计冻结，待实施）**
> 起因：fish 提问"能不能设计算法让生物**根据不同条件自己决策**，而不是把食物/捕食者/同类气味**全部拿进来加权**" ⇒ 联网调研后给出可实施方案
> 依赖链：**S2（异质性）→ 气味场（R235）→ 模式仲裁（本稿）**

---

## 〇、一句话

- **现状 = command fusion（指令融合）**：所有线索（食物、信号、社交、记忆）**加权求和成一个 score**，谁权重大谁说话 —— 逃跑信号只让分数**降一点**，个体可能**仍然去吃**。
- **建议 = arbitration（仲裁）**：先按"显著度"选出**行为模式**（觅食 / 逃避 / 聚集 / 探索），**再在模式内行动**，模式之间**排他**。
- 这正是行为基机器人（behavior-based robotics）里 **ASM（Action Selection Mechanism）两大类别**的对立：**arbitration（竞争，只有胜者控制）vs command fusion（融合，全体共同贡献）**。

## 一、文献依据（2026-09-27 联网核验）

| # | 来源 | 对我们的用处 |
|---|---|---|
| 1 | **Brooks (1986) subsumption architecture**（"行为基机器人"奠基，综述：*Trends Cogn Sci* 1998, S1364661398011413） | 分层反射 + **优先级仲裁**（高层抑制低层）⇒ **无需中心世界模型**即可产生复杂行为；讨论里明确"**arbitration = 每个时刻决定执行哪个行为**是核心难题" |
| 2 | **Redgrave et al. (1999/2001)**，见 *Phil. Trans. R. Soc. B* 综述 "The ecology of action selection: insights from artificial life"（PMC2440771） | **脊椎动物基底神经节 = 不同 salience 输入之间的 winner-take-all 竞争** ⇒ **生物学原型**（不是我们发明的工程招） |
| 3 | **Seth (1998/2000)**，同上综述 | 用**内部"电池"水平调制感觉-运动传递函数**，**无需显式行为模块** ⇒ 自发出现 **appetitive/consummatory 模式切换** + **低电量时解除前进抑制（隐式优先级）**。⇒ "模式切换"可以用**很省的机制**实现 |
| 4 | **Bryson et al., "Improved Animal-Like Maintenance of Homeostatic Goals via Flexible Latching"**（Cog. Comp. 2010） | 🔴 **关键工程约束**：目标仲裁必须解决 **dithering（抖动）vs persistence（固执）** 的折中 ⇒ **迟滞 + 最小锁定时间**；否则个体会在两目标间**每秒抖动**（白烧能量） |
| 5 | **ASM 分类与演化**（*Neurocomputing* 2014, S0925231214000575） | arbitration 的短板是"败者信息全丢 + 优先级要人定"；fusion 的短板是"平均出来的控制量可能谁都不像 + 局部极小" ⇒ **两者各有病**，故需**可演化的仲裁参数**（我们用基因位承担） |

## 二、机制设计（the-world 版，四模式）

**模式与显著度（salience）**

| 模式 | salience（谁能赢） | 模式内怎么走 |
|---|---|---|
| **觅食** `feed` | `w_f · 食物气味(自己格) + w_h · hunger` | 朝"食物气味最强"的邻居走 |
| **逃避** `flee` | `w_r · 风险气味 × (1 + fear_gene)` | 朝"风险气味**最弱**"的邻居走 |
| **聚集** `join` | `w_k · 同类气味 × sociability` | 朝"同类气味/密度最强"的邻居走 |
| **探索** `explore` | **保底常数**（如 0.2，保证永不为空） | 随机游走（或朝未访问方向） |

**选择规则**：`mode = argmax(salience)`（**winner-take-all**）
+ **迟滞**（进入阈值 > 退出阈值，防边界抖动）
+ **最小锁定 `T_hold`**（如 20 tick，防 dithering）
+ **切换成本**（可选：切换一次扣少量能量，让"想清楚再换"有代价）

⇒ **与现状最根本的差别**：现状是**三件事加权融合**（可能"一边逃一边吃"）；新模式是**排他**（逃的时候不吃）。

---

## 三、🔴 为什么这对"语言涌现"是关键（不只是工程小改）

- **现状**：信号只是 score 里一个**连续小项**（`0.4 × perc × interp`，`sphere_engine.py:3270-3276`）⇒ 接收者的**行为结构不变**，只是权重微调。
  ⇒ **信号无法表达"这边有事 / 跟我来 / 有危险"这类"模式级内容"** —— 这正是 **E-019 / E-023「信号无内容」的机理**（不是信号弱，是**它没有能改的东西**）。
- **有了模式仲裁** ⇒ 信号可以**切换接收者的模式**（恐惧信号 ⇒ 接收者切 `flee`）⇒ **这是"信号有内容"最省力的一种落地**（先有"模式级内容"，多位编码可后置）。
- 且它直接服务 **C3（发送者回报）**：模式切换让信号有**明确后果**（不是"权重动一点"，而是**行为换了**）⇒ 发送者才可能获得净收益。
- ⇒ 与 R235（气味场通道）是**同一套设计的两半**：**气味场 = 线索来源**，**模式仲裁 = 线索→行为的映射**。

## 四、实现约束

1. **三处同式**（Python 参考 / Rust 热核 / 向量化快路径）—— 同 R232 / R234 纪律；只改一处 ⇒ 双路径对拍挂。
2. **新增状态**：`_mode (n,) int8` + `_mode_tick (n,) int32`（锁定计时器）⇒ **`__slots__` 四处登记 + 进快照**（R215 同族）。
3. **默认关**：`action_selection: "fusion"`（现状，逐位不变 = **回滚点**）/ `"arbitration"`（新）⇒ 默认 `fusion` ⇒ **C7 基线不动**。
4. **基因位扩张**（fish 已同意扩位）：每模式 1–2 个参数（阈值/权重），首批 4 模式 × 2 = **8 位**。
   🔴 **这是纪元级变更**（24 位基因是核心构造）⇒ 须**纪元登记** + **不得与在办批混跑**（`AGENT.md` §十三）。
5. **性能**：WTA 比融合**更省**（先比 4 个标量再算 1 套规则，不用算全套加权），但必须向量化；新增 `[估算]` **< 0.5 ms/tick**（须实测，R219 配对口径）。

## 五、预注册判据与反例（防止自欺）

**主判据**
- **模式切换率**落在预设带内（= 0 ⇒ 没切换；过高 ⇒ 抖动）；
- **逃跑模式下的被捕食死亡率**下降（模式是否真的有用）。

**支持判据**：饿死占比 ↓、单位能量位移效率 ↑、**四模式时间占比分布**（每模式都不该 ≈0 或 ≈100%）。

**🔴 反例预登记**
1. **抖动（dithering）**：无迟滞 ⇒ 模式每 tick 翻转 ⇒ 能量白烧 ⇒ **必须先做迟滞 + 锁定**，并**报告翻转频率**。
2. **"探索"变永久兜底**：salience 尺度没标定 ⇒ 所有个体永远走 `explore`（等于退化成现状的随机游走）⇒ 必须报告四模式**时间占比**。
3. **信号与模式耦合过强**：若信号直接改模式，可能"一喊全跑" ⇒ 反而抹平"信息不对称" ⇒ **首批先不把信号接到模式**（只用气味通道 + 内部 hunger），信号→模式留 S3/C3 批。
4. **优先级靠人定**（文献承认的 arbitration 短板）：首批阈值/权重**走基因位**，不写死常数（避免"我们替生物做决定"）。

**⚠️ 实施顺序**：**必须先有气味场**（否则 salience 无输入）⇒ 依赖链 **S2 → 气味场 → 模式仲裁**。
