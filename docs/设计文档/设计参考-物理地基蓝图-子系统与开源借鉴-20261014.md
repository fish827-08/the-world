## 一、先回答两个根本问题

### 1. 风的底层逻辑，到底是什么（精确链条）

```
太阳辐射（随纬度/昼夜/季节不均匀）
  → 地表受热不均 → 温差
  → 密度差（冷空气重、热空气轻）→ 气压差
  → 压力梯度力 → 空气流动（风）
  → 风携带热量（热平流）和水汽（水汽平流）
  → 暖空气上升/遇地形抬升、冷却、饱和凝结 → 降水
  → 凝结释放潜热、高空向极冷却下沉 → 环流闭合
```

**要给 owner 一个精确澄清（避免做偏）**：风的直接驱动是**压力梯度力**（来自温差），温差的根是**太阳辐射
不均 + 重力（冷重热轻）**。"热扩散（热传导）"不是风的原因，它扮演两种角色：
- 在**不显式建风**的能量平衡模型（EBM）里，一个热扩散项 D∇²T 把"风 + 涡动 + 洋流把热量从赤道送到极地"
  的整体效果**统计参数化**了（隐式代表风）；
- 在**显式建风**的 C4a 里，热平流（风带热）是主导，热扩散只留一个小项（代表未解析的小尺度湍流、
  并保证数值稳定）。

所以 owner 说的"热传导促成风"在 EBM 语境下成立（扩散就是隐式的风），在显式风语境下应表述为：
**热扩散是温度场的输运/平衡项，风是温差的显式流体响应。**

### 2. 什么该"给定"、什么该"涌现"（原则边界）

- **要避免的"人为规定"** = 直接写死格局/结果。例如：直接规定"20–30° 干旱"、直接画死某条河、直接设定
  某地产量。这些应由底层规则产生。
- **科学建模必须给定的（不算"人为规定结果"）**：
  - 物理定律：守恒（质量/能量/水）、流体方程、热力学、重力；
  - 常数与边界条件：太阳常数、自转速率、重力加速度、比热/气体常数、球面几何、海陆分布（由地形决定）；
  - 初始条件：种子、初始地形/温度场。
- **应让其自组织涌现的（格局/现象）**：风、洋流、雨带、副热带沙漠、季风、河流/湖泊/地貌、（之后的）
  生物分布与行为。
- 一句话原则：**给最少、最普适的定律和边界条件，让格局自己长出来；不写死结果，但也不奢望"物理常数
  本身"涌现。** 每加一层，都要能回答"关掉它 / 均匀化它，是否作为零模型可验证"。

## 二、开源借鉴清单（分层，成熟度高，按"可借鉴程度"排序）

> 原则：**借物理（方程、参数、过程分解、数值格式），不直接搬库**——详见第五节。

- **climlab（Python，Brian Rose，MIT，github brian-rose/climlab）**：过程导向气候建模包，模型=一组
  交互过程；含零维/扩散/湿 EBM（MeridionalMoistDiffusion）、辐射、季节循环、热容量。**EBM 与
  能量平衡（A 层）首选蓝本**；其"过程组件"架构很适合我们按需拆分。
- **SWAMPE（Python，二维浅水大气环流，用于系外行星，模块化，可改宜居行星）**：球面浅水 GCM，
  含风场、辐合辐散、辐射。**C4a 涌现大气环流（B 层）首选蓝本**——复杂度介于 EBM 与完整 GCM 之间。
- **NOAA/AMS "Simplified-Physics Atmosphere GCM"（BAMS 2025，单 Jupyter notebook，非线性原始方程）**：
  想看"完整但简化的 GCM 怎么组织"的教育参照。
- **qgs（Climdyn/qgs，Python）**：2 层准地转通道大气 + 简单陆地/浅水海洋耦合；大气-海洋耦合参考。
- **OpenSCM Two Layer（Python）/ simplEarth（Julia）**：两层（大气/海洋）热容量气候模型，季节滞后、
  海洋热库参考。
- **SimpleHydrology（weigert，C++，约 500★）**：程序化水文/河流/湖泊模拟。
- **TerraForge（terraforge.art）**：粒子-液滴水力侵蚀（惯性、携带能力、蒸发）、浅水管道流、
  stream-power 河流下切 `E = K·A^m·S^n`（Braun–Willett）、构造抬升、沉积、出露基岩。**D 层侵蚀/
  沉积首选蓝本**。
- **GAIA（deep time planet simulator）**：地核热→地幔对流→拖拽地壳，岩石柱（密度/温度/厚度/年龄），
  上覆侵蚀/降水/排水。**地质圈完整参照**（但板块部分大概率不做）。
- **Stommel–Munk / Sverdrup 环流（有讲义代码，如 team-ocean、rabernat 海洋学教程）**：风应力旋度 →
  双环流（gyre）、Sverdrup 平衡、β 平面。**洋流（C 层）蓝本**。
- **davidar sim-glsl（GPU 片元着色器，4 分钟跑完 40 亿年）**：以平均海平面气压 MSLP 驱动全局气候、
  一体化世界演化。**只参考逻辑链条，不抄代码**（GPU，违反我们禁 GPU 红线）。
- **Breeze（Julia，基于 Oceananigans，GPU）**：云/飓风/辐射物理全，但语言/GPU 重，仅取公式。

## 三、物理地基分层蓝图（现状 / 缺口 / 参照 / 优先级）

### A 能量与辐射层（驱动力；现在温度是"写死"的，根在这）

- 太阳入射几何：**已有**（`light_and_temperature.py` illumination/photoperiod，纬度/昼夜/季节 δ(t)）。
- 反照率 α（海/陆/雪/云反射不同）：**无**。
- 红外辐射出射（热了向外散热 A+BT）：**无**。
- 热容量（热惯性；海洋大、陆地小）：**无**。
- 经向热扩散 D∇²T（EBM 送热，隐式代表风）：**无**。
- 热平流（风带热）：**无**（随 C4a）。
- 云辐射反馈：**无（后期）**。
- 参照：climlab（辐射/扩散 EBM/热容量/季节）、OpenSCM two-layer。
- 优先级：**必做**——风的燃料、温度自洽的前提（C4a-1 先落）。

### B 大气圈（流体；涌现风/雨带/沙漠）

- 温度→密度/气压、压力梯度→风、质量守恒连续性、垂直运动（辐合/辐散）、水汽平流：**均无**。
- 蒸发/凝结/降水：**部分**（现为构造期静态 Magnus，非动态、不受地面水约束）。
- 科里奥利（自转）：**无（C4a-4 可选，单胞模型不需要）**。
- 参照：SWAMPE（球面浅水）、NOAA simplified GCM、qgs。
- 优先级：**必做**（C4a，C1 静态为过渡/对照）。

### C 水圈（地表水文 + 海洋）

- 地表汇流（priority-flood 填洼 + D8）：**已有**（`env_field.py:198-276`）。
- 河流命名层 river_mask：**已有**（仅读数层，不进产能）。
- 海平面/海洋、湖泊/内流盆地：**无（C0b）**；现状 seed42 50.8% 格被填成"极海"（极点出水口假设失真）。
- 土壤水/地下水：**无**（生物"喝水"接口，建议补）。
- 海温/海洋热库：**无**（与 A 层热容量联动）。
- 洋流（风生 gyre）：**无**（值得做，Stommel–Munk/Sverdrup）。
- 冰川/雪线、云（可见层）：**无（后期，雪线与反照率正反馈联动）**。
- 参照：SimpleHydrology、TerraForge、Stommel–Munk 洋流。
- 优先级：**海/湖/河（C0b）必做**（海洋=水汽源，C4a 前置）；土壤水建议；洋流/冰川值得做。

### D 岩石圈（地形）

- 地形：**已有**（3D 值噪声 fBm，静态，构造后不被改写）。
- 河流侵蚀/下切、沉积/三角洲、构造抬升：**无**。
- 板块/地幔对流：**无（基本可省）**。
- 参照：TerraForge（stream-power 下切/沉积）、SimpleHydrology；GAIA（仅当要做深时地质）。
- 优先级：侵蚀/沉积**值得做**（让地貌动态，时间尺度适中）；**板块/地幔现阶段不做**（深时太慢，
  对生物演化无意义，静态噪声 + 侵蚀足够）。

### E 物质与生物地球化学（为生物准备，大多随生物层一起做）

- 资源容量/再生：**已有**（抽象资源场 f_g/f_c，面积权均值归一守恒）。
- 土壤类型/矿物质、营养循环（N/C/P）、碳循环/大气成分：**无**。
- 优先级：**放生物前不需要完整化学循环**。这些在生物上线后随生物层做（生命重塑地球，如大氧化事件
  是生物驱动的，无生物世界先不做）。

### F 时间与尺度

- 昼夜：**已有**；季节 δ(t)：**已有（默认关）**。
- 随机天气事件（旱年/涝年）：**无（C3，后期）**；冰期/米兰科维奇：**无（可省）**。

## 四、最小充分物理地基（"放生物前"必须）vs 可省

**放生物前必须闭合（5 件，做完环境层即足以支撑生物）：**

1. **A 能量平衡闭环**：太阳入射 − 红外散热 − 热平流 + 热扩散，热容量（温度自洽，不再写死）；
2. **C0b 海陆/湖/河**：真实海拔 + 海平面，海洋作为水汽源（替换极海假设）；
3. **C1 静态环流**：先让副热带沙漠结果存在（低成本，作 C4a 对照锚）；
4. **C4a 动态涌现大气**：风、水汽输运、热平流、凝结降水（大气-水-能量闭环）；
5. **（建议）土壤水/地下水薄层**：把地表水量与将来生物"喝水/取能"接口打通。

完成后：空间异质性（海陆/气候带/地形/河湖）+ 时间异质性（昼夜/季节/天气）齐备，且全部守恒、可对拍。

**值得做、但不阻塞放生物：** 河流侵蚀/沉积（动态地貌）；雪线/冰川（+反照率正反馈）；
风生洋流与海洋热库；C3 随机天气事件。

**现阶段可省：** 板块构造/地幔对流（GAIA，深时太慢）；完整 GCM、云微物理、逐线辐射传输（用参数化）；
冰期/米兰科维奇循环（除非研究深时）。

## 五、借鉴原则（借物理，不搬库）

1. **取方程/参数/过程结构/数值格式，按我们架构重写**。第三方库（climlab/SWAMPE 等）可能依赖
   编译件/GPU/外部随机，直接引入会违反我们红线。
2. **必须满足既有红线**：确定性（CountingRNG、独立 RNG 流，不消费引擎 RNG）；Python↔Rust 双路径
   逐位对拍；新机制默认关、关档逐位等价（C7）；质量/能量/水守恒 + 不变量测试；动态场进快照或可
   确定性重建；s2=460,800 格性能（大气走粗网格 + 时间解耦，必要时 Rust 下沉）；**禁 GPU**。
3. **每个机制可降级、可对照**：先最简可跑版（如 1D/2D 小网格 EBM、浅水单胞），配零模型（均匀加热/
   关扩散/关自转），验证涌现再扩尺度。
4. **许可证与出处**：公式与数值方法无版权可直接用；抄代码须核对 LICENSE（多数 MIT/Apache），在报告
   与代码注释标来源，选型报告给链接。
5. **性能**：已实测（见天气设计文档第五节），动态大气全分辨率慢约 12 倍，4× 粗网格 + 每 10 tick/3 子步
   均摊约 +5%/tick；热扩散是邻居 Laplacian、热平流多平流一个温度场，粗网格下再 +20–30% 仍可控。
