## 二、🔴 首要发现：在 s3/E-056 装置下「只透传档位」是**空转**（实测，非推断）

引擎 `simulation/sphere_engine.py:3999`：

```python
rep_w = ifcfg3.reputation_weight if ifcfg3.enabled else 0.0
```

`InfoStructureConfig.enabled` 默认 **False**（`config.py:581`），而本探针的装置构建
`steady_k_probe.make_cfg` **从不设 `enabled`** ⇒ 只写 `reputation_weight` 不写总开关，
引擎把档位**清零**。实测（`_rerun_logs/lh_rpw/inert_proof.py`，40×80/pop60/patches20/
seed207/60t，Python 路径、memory_v2 关）：

| 组 | 形制 | 引擎状态摘要 |
|---|---|---|
| A1(rep_w=0.0) vs A2(rep_w=0.5) | `enabled=False`（= s3 现装置 = E-056 a 臂口径） | **逐位相同**（空转） |
| B1(rep_w=0.0) vs B2(rep_w=0.5) | `enabled=True` ＋ 其余六项 D2 机制关到中性（solo 形制） | **不同**（旋钮咬得住） |
| C1(rep_w=0.0) vs A1 | `enabled=True` 走 config 默认（学习瓶颈/码本/Steels/噪声/softmax **跟着全开**） | **不同** ⇒ 非单变量，不能当 rep_w 档 |

**直接后果**：砚《预注册-E057-rep_w档扫批》§一 line 24 写的「唯一变量
`--rep-w ∈ {0.05,0.2,0.5}` × seed 207–214 = 24 run」在现装置下**不成立** ⇒ 24 run 会跑出
**三组逐位相同的 run**（云机白跑）。故本卡不接受"只透传"的交法，把拦令做成硬门（§三 ②③）。

## 三、实装要点（新工具四律逐条落）

1. **CLI 两参**：`--rep-w`（float，默认 `_REP_W_DEFAULT = 0.0`）、`--rep-w-solo`
   （store_true）。常量块（`_REP_W_DEFAULT`／`_SOLO_OFF_FIELDS`／`_REP_W_LOCKED_TIERS`）
   放在 `SEEDS_USED` 之后（:137-150）—— 它们被当**默认参数值**用（`run_one`:1257、
   `_build_fresh_run`:1401、`_config_fingerprint_check`:1124），放文件尾会 `NameError`
   （首跑即抓到，已修）。
2. **默认关逐字节等价**：`rep_w == 0.0 ∧ ¬rep_w_solo` ⇒ 一个字都不碰 `info_structure`；
   `_summary_meta` 加**第五摘除条件**（同生同灭摘 `rep_w`/`rep_w_solo`）；banner 只在改档
   时追加；run 级四键只在改档时写。实证见 §四。
3. **不消费 RNG**：新增路径只做 config 赋值＋比较＋打印，无 `rng` 调用。
4. **fail-loud 四道守门**（`_build_fresh_run`，:1435-1504；CLI 前置 :1820-1831）：
   - **非负复刻**：`rep_w < 0` ⇒ ValueError。为何要复刻：本探针在**构造后赋值**，
     不触发 `__post_init__` 的 `assert reputation_weight >= 0`（`config.py:660`）
     —— F1 同型教训。CLI 侧同式 exit 2，且在**开 CSV 之前**（不留半成品文件）。
   - **空转禁令**：`_rw > 0` 而引擎生效值 ≤ 0 ⇒ RuntimeError（把「三档白跑」拦在装配期）。
   - **读回不符**：`_eff_rw != _rw` ⇒ RuntimeError。生效值取自**构造后的 `eng.config`**，
     不看 CLI／入参 ⇒ solo 接线被删／总开关被回退当场炸。
   - **solo 装配校验**：带 `rep_w_solo` ⇒ 回读 `enabled` 真值 ＋ 六项中性字段逐项相等。
5. **S1 读回守**：`eff_out` 增出 `reputation_weight` / `info_structure_enabled`；
   summary run 级四键 `rep_w_declared`／**`reputation_weight_effective`**／
   `info_structure_enabled_effective`／`rep_w_solo`。键名照砚锁定文本
   （预注册-E057 §一 载体旋钮行 @`7605da1`）—— 我原先写的 `rep_w_effective` 已改名。
6. **续跑防串档**：`reputation_weight` ＋ `info_structure_enabled` 进
   `_config_fingerprint_check` 逐字段核对 ⇒ 快照与命令行换档／换形制必拦。
7. **付款闸不动**：`git diff --name-only` = 只有 `experiments/s3_memory_probe.py`；
   `a4_verify_capacity.py` 的 `gate_delta` 四站点（:318/:659/:746/:1147）零改动。
