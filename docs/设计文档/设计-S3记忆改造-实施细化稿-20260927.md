## 一、开关与配置（config.py `InfoStructureConfig`）

| 字段 | 类型 | 默认 | 语义 |
|---|---|---|---|
| `memory_v2` | bool | **False** | v2 总开关。False = 现有行为逐位不变（回滚点）；True = egocentric v2 |
| `memory_dist_scale` | float | **15.0** | 精记忆距离衰减尺度 d0（= 斑块间距量级，R234 §一 实测）|
| `memory_degrade_thr` | float | **20.0** | 精→粗降级距离阈值（格）。**超过即永久降级**（不可逆）|
| `memory_coarse_gain` | float | **0.15** | 粗记忆增益 = 0.5 × `memory_gradient_gain`(0.3)（R236 §四-A）|
| `memory_ttl` | int | **1000** | 记忆时效（tick）。age > TTL ⇒ 槽视为空（首期扫描 {500, 1000, 2000}）|
| `memory_noise` | bool | **False** | 朝向噪声档。False = 精确路径整合；True = 记忆方位旋转叠加噪声（±1 档，`memory_noise_p`）|
| `memory_noise_p` | float | 0.1 | 噪声档：每 tick 以该概率扰动记忆方位 ±1 档 |

- assert（预注册）：
  - `memory_v2=True` ⇒ `memory_gradient == "orientation"`（v2 取代 v1 orientation 的世界方向版本，不与之并存）
  - `memory_dist_scale > 0`；`memory_degrade_thr > 0`；`memory_coarse_gain >= 0`；`memory_ttl > 0`；`0 ≤ memory_noise_p ≤ 1`
  - 🔴 构造期 fail-loud：`memory_v2 ∧ rd.enabled ∧ not bg_production_zero` ⇒ 报错退出（R236 §四-B-2：防 rd 搬移时质心/方位静默失效）
  - 🔴 运行时 fail-loud：`memory_v2 ∧ use_sim_core=True` ⇒ 报错（Rust 未下沉 v2，引擎守门，同 rd 先例）
- 现有 `memory_gradient`（"none"/"orientation"）与 `memory_gradient_gain`(0.3) **保留**；v2 只在 `memory_gradient="orientation"` 下生效，且其"世界方向"语义被 v2 覆盖（**不再使用**）——代码上：v1 orientation 分支在 `memory_v2=False` 时仍可用（为兼容/回滚），但**文档标注"不推荐"**（R239 §四）。

## 二、数据结构（新增/复用）

| 数组 | 形状 | 语义 | 状态 |
|---|---|---|---|
| `_heading` | (n,) int64 | **复用**：个体当前朝向（Moore 槽位 0–7，-1=未知/极区）。ARS 已在维护（:3491–3494 记步方向、:3399 失望右转、:930 初始化）| 已有，`__slots__` 已登记（:435）|
| `_mem_az` 🆕 | (n,4) int8 | **记忆方位 q**（自我参照系 Moore 槽位 0–7；-1 = 空槽）——**不存世界坐标** | 新增 |
| `_mem_dist` 🆕 | (n,4) float32 | **走过的距离 d**（写入时 0，每 tick + 本步格数；**只增不减** ⇒ 不可逆降级自然成立）| 新增 |
| `_mem_tick` 🆕 | (n,4) int64 | 记录 tick（时效判定 + 槽替换依据）| 新增 |

| `_mem_food` 🆕 | (n,4) float32 | 记录时刻食物比（留档，首期不参与打分）| 新增 |
| `_work_memory` | (n,4) int64 | **v2 下不再写入/读取**（v1 语义保留；v2 打分走 `_mem_az`）——避免语义混用 | 复用但 v2 旁路 |

- 快照：`_heading`（已有）+ 新增 5 数组 **同批登记 `__slots__`（四处）+ 进 save/load_snapshot**（R215 教训：ARS 六数组漏登的同族缺陷一次清干净）；新增数组初始值：`_mem_az=-1`、`_mem_dist=0`、`_mem_tick=-1`、`_mem_degraded=False`、`_mem_food=0`。

## 三、朝向与路径整合（egocentric 核心）

1. **`_heading` 更新**（复用既有机制，v2 不另起炉灶）：
   - 移动后由**实际位移** `(Δrow, Δcol)` 量化到 Moore 槽位——subpos 已在算 `_drow/_dcol`（:3509–3514，经度取最短路环绕）；ARS 关档时也须维护 `_heading`（v2 模式下强制；v1 下不改变现有行为）。
   - 极区：沿用既有豁免语义（-1 = 未知，记忆不旋转、不写入）。
2. **记忆方位旋转**（路径整合，每 tick 移动后）：
   ```
   δ = (heading_new − heading_old) mod 8          # 个体自我参照系相对世界旋转了 −δ
   q ← (q + δ) mod 8                              # 记忆方位在自我参照系里反旋，保持世界方位不变
   ```
   - 无噪声档（`memory_noise=False`）：精确旋转。
   - 有噪声档（`memory_noise=True`）：每 tick 以 `memory_noise_p` 概率将 q 扰动 ±1 档（`rng` 消费须**在 RNG 流契约内**——见 §五）。
3. **记忆写入**（站在富食格时，`food_rich` 判定同 v1）：
   ```
   选槽 = 最旧槽（_mem_tick 最小；全空则首个空槽）
   _mem_az[i, slot]   = (质心方向 − heading_now) mod 8   # 相对朝向："富食在我左前方"；质心方向由 patch_centroid 表查（构造期预计算，运行时 O(1)）
   _mem_dist[i, slot] = 0
   _mem_tick[i, slot] = tick
   _mem_degraded[i,slot] = False
   _mem_food[i, slot] = grid/capacity（当前格）
   ```
   - ⚠️ **质心方向怎么算（egocentric 关键）**：个体不知道质心世界坐标 ⇒ 写入时无法直接算"质心方向"。**解决**：写入时个体站在斑块内某格，质心方向 = **patch_centroid 表查出的质心格方向**（局部查表：质心格 → 相对当前格的世界 Moore 方位 → 减 heading = 相对朝向）。查表输入是"当前格 id"，输出质心格 id ⇒ **O(1)、无世界坐标暴露**（个体只得到一个 8 档方位值，永远接触不到坐标本体）。R236 §四-B-2 已认可静态质心首期方案。
4. **距离 d 更新**（每 tick 移动后，对所有非空槽）：
   ```
   d ← d + 本步格数（1 格/步；subpos 开则 0.125）
   if d > memory_degrade_thr 且 not _mem_degraded:  _mem_degraded = True   # 🔴 永久
   if age = tick − _mem_tick > memory_ttl: 槽视为空（打分跳过；不显式清，写入时覆盖）
   ```

## 四、打分公式（egocentric v2，预注册钉死）

对候选邻居格 `c`、记忆槽（非空 + age ≤ TTL 的槽集合）：

```
精记忆（_mem_degraded == False）：
  mem_score(c) = memory_gradient_gain × perc × cos(ang(c) − q) × exp(−d / memory_dist_scale)

粗记忆（_mem_degraded == True）：
  mem_score(c) = memory_coarse_gain × perc × cos(ang(c) − q)        # d 不进公式

对多槽：取 max（同 v1：只让最对准的槽说话）
```

- `ang(c)` = 候选 c 相对**当前 heading** 的方位 = `(dir(c) − heading) mod 8`，其中 `dir(c)` = c 相对当前格的世界 Moore 方位（局部：当前格 + 邻居格 + heading，**全程无世界坐标**）
- `cos(·)`：复用 ARS 既有 8×8 cos 矩阵（`_ars_cos`，Moore 槽位间夹角；4 邻经 `_VON_NEUMANN_IDX` 映射——:3487/:3412 既有先例）
- 打分落点不变：仍**逐候选格**（每个邻居一个 mem_score，叠加进总分，选最高邻居移动——R146/R149 L1 架构不动）
- **不可逆性**：`d` 只增不减 + `_mem_degraded` 永久 ⇒ "走近不能恢复距离记忆"（fish 规格）；重写该槽才可能回到精记忆（R236 §四-A："场恢复能清标记"登记为二期，首期降级即永久）

## 六、性能评估（预注册口径，T6 实施后实测报数）

- 新增每 tick 成本：`_mem_dist` 递增（向量化一次加法）+ 记忆方位旋转（仅非空槽）+ 打分多一次 8×8 cos 查表 + `exp`（精记忆槽）。N≈3000 全有记忆 ≈ 亚 ms 量级（须配对实测报数，R219 口径）
- 快照体积：5 新增数组 ≈ n×4×(1+4+8+1+4)B ≈ 480k×72B ≈ 35 MB/档（480×960 全档）——比 v1 的 23 MB 大 12 MB（多 `_mem_dist` float32 + `_mem_degraded` bool），与邻居表 29.5 MB 同量级，可接受
- 构造期：patch_centroid 标注一次（480k 格 BFS，一次性，不在 tick 内）
