## 一、δ 要回答什么（以及"坏结果"为什么也是结论）

| 已确立的事实（`[实测]`） | 对 δ 的含义 |
|---|---|
| 区制**二分**：20 SAT（顶到 `max_count`）／10 PRED（捕食崩塌），**无健康中间态** | ρ 在两种区制下都**不可解读**（饱和时繁殖≈抽签；捕食态选择由捕食主导）⇒ 需要一个**可观测选择窗** |

⇒ **δ 的目标不是"找一个好点"**，而是**测绘「SAT 比例随参数的变化曲线」**：
只有当某参数区域能把比例推到 **6:0（稳定不饱和）** 或 **0:6（稳定崩塌）** 时，才谈得上"可控区制"。
⇒ **若比例无论怎么动都不变 ⇒ 结论 =「本构造的选择窗**不由该参数**控制」** —— 这**同样是结论**，且它把"阴性读数的成因"钉死（比"找到格子"更有价值）。

## 二、🔴 本稿的核心决策：**一维杠杆选谁**

本板 21:17 帖列了三个候选（`max_count` / 资源再生率 / 捕食压）。本稿建议 **主扫 A = `max_count`**：

| 候选 | 物理含义 | 能否独立把比例推到两端 | 评价 |
|---|---|---|---|
| **A `max_count`**（承载力上限） | 种群上限 ⇒ **SAT 区制的定义量** | ✅ **判据的一端（SAT ⟺ N ≥ 0.9×`max_count`）由它定义** ⇒ 向下扫即**必然制造饱和**、向上扫即**远离饱和** ⇒ 是唯一**确定**的杠杆 | **建议主扫** |
| B 资源再生率（生产力） | 决定稳态 N 与"离饱和多远" | ⚠️ 间接（要通过稳态 N 才能影响 SAT） | 备选 |
| C 捕食压（攻击成功/攻击成本） | PRED 区制强度 | ⚠️ 只能移动 PRED 端；SAT 端不动 | 备选（见 §五 第二轮） |

**取值（6 点）**：`{1200, 1800, 2400, 3240, 4200, 5400}`
- 间隔 ≈ **1.5×**（近似对数）；下界 1200 **远低于**典型稳态 N ⇒ 该点应"必然饱和"；上界 5400 远高于现状 ⇒ 该点应"远离饱和"
- **含现行默认 `3240` 作锚点**（R41 的不饱和上限）⇒ 可与既有批次直接对照（见 §五）
- ⚠️ **不取更宽**：若一端已顶到 6:0 或 0:6，再往外扫是浪费（点数应花在**过渡段**）

## 四、🔴 预注册判据（**跑前锁定，禁事后调整**）

**① 区制分类（阈值写死，不得事后改）**

| 类别 | 判据 |
|---|---|
| **SAT** | 终态 `N ≥ 0.9 × max_count`（**比值写死**，与 gate/α 批同口径） |
| **PRED** | `pred_frac ≥ 0.9`（R38③ 既有阈值） |
| 过渡带 | 终态 N ∈ [1000, 0.9×max_count)（**只记录**） |
| 其他 | 上述之外（**记录**，不判读） |

**② 主读数**：每点报 **SAT 比例 k/6** + PRED 比例 + 中间态比例；附**非饱和 run 的 `pred_frac` 分布**（分层，禁合并均值 R38③）

**③ 判定（两条，互斥）**

| 结论 | 阈值（预注册） | 含义 |
|---|---|---|
| ✅ **该参数是杠杆** | **极值两点**（SAT 比例最高 vs 最低）的 **Fisher 精确检验 p < 0.05** | 参数能移动区制比例 ⇒ 存在**可控**的选择窗（后续可在过渡段加密） |
| ❌ **该参数不是杠杆** | 所有点的 SAT 比例 ∈ **[1/6, 5/6]**（即无点接近 6:0 或 0:6） | 「选择窗**不由该参数**控制」⇒ 阴性读数的成因钉死 |

> ⚠️ **只比较极值两点**是**预先写死**的选择规则（避免"事后挑最显著的一对" —— 6 点有 15 对，事后挑必然假阳性）；
> 且"最显著"的**期望假阳性**已在设计上被排除。若极值两点 p ≥ 0.05 ⇒ 一律判"非杠杆"（不做"换一对再试"）。

**④ 附带（不计判定）**：每点 N 中位 / `pred_frac` 中位 / ρ（记录用）；ϵ 线（不判读）
