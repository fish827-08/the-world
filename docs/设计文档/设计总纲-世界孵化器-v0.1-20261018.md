## 〇、一句话与四条边界

**一句话**：借一台成熟的 GCM 当气候引擎，自己造"世界—生命"的界面与"世界族 × 演化"的度量；**不重复造轮子，只造别人没有的那层**。

**四条边界（不做）**
1. 不做体素 3D 世界（2.5D：地表 2D + 水深/水层 + 多层大气）。
2. 不做完整 GCM（大气借现成；自研 C4a 降级为对照/后备）。
3. LLM 不放环内（只做环外探针，见 `Observer Zero` 教训）。
4. 不追跨硬件逐位（改三级确定性 + 统计等价门）。

## 一、项目归属：**在原仓库继续**（结论）

| 理由 | 说明 |
|---|---|
| 世界层就是 A 线地基 | C0b 地形/海陆/河流、`resource_field`、`sphere_engine`、viz、`the-world-data` 全部可复用 |
| 纪律栈是资产 | 默认关逐位、零模型、manifest、三档测试（1685 例）、legacy 分层——换仓库即丢 |
| 三线联调 | 气候—世界—生命在同一工作树，接口改动当天可验 |

**做法：单仓多包（monorepo）**

```
the-world/
  world/            # 物理世界（现有，复用；ClimateSource 在此扩展）
  simulation/       # 引擎（现有，复用）
  biosphere/        # 🆕 个体 / 基因组 / 发育 / 生态 / 演化 / 度量
    gpu/            #    Taichi kernel（与 CPU 参考实现并列）
  atmo_bridge/      # 🆕 外部 GCM 的进程/文件接口 + 重映射（薄层）
  experiments/      # 跑批入口（扩 run_bare_world → run_world / run_bio）
  tools/            # 面额审计、bench、设备预设（现有）
  tests/            # 三档（现有）
```

**不新建仓库**。若将来 Julia GCM 需要独立包，另开 `atmo/`（Julia 包，可 submodule），不污染 Python 仓。

## 二、技术选型（结论表）

| 层 | 选型 | 理由 | 风险/待办 |
|---|---|---|---|
| 世界/引擎 | 现有 `world/` + `simulation/`（Python+NumPy） | 已在跑、有测试、有数据 | — |
| **气候引擎** | **SpeedyWeather.jl**（Julia；GPU；可微；参数化可插拔） | 成熟、Windows 原生 CUDA、模块化、可做敏感性扫描 | 🔴 **许可证待核**；T31 分辨率粗（用现有 `env_field` 地形抬升做降尺度）；Julia 学习成本 |
| 气候对照 | ExoPlaSim（离线出气候表） | 独立血统做校验 | GPL：只离线用，不链接 |
| 气候接口 | 现有 `ClimateSource`（B3 `world/climate.py`） | 已抽好；加 `GCMTableSource` 即可 | 接世界时需定"刷新节拍" |
| **生物圈** | 新 `biosphere/`（Python 编排） | 复用世界数据结构 | — |
| **基因/发育** | **可变长基因组 + NEAT/CPPN 拓扑 + GRN 发育** | 前人验证过；L2/L3 层的"不写死" | 变长在 GPU 上要分桶 |
| **个体内核** | CPU 数组化 → **Taichi**（CUDA/Vulkan，Windows 原生） | 迁移最小；两段式提交可保 L1 可复现 | 禁原子操作；动态增删用 compaction |
| 批量世界 | 先多进程，后 GPU 批 | 世界族扫描是科学主战场 | 内存/IO |
| 演化度量 | OEE 度量（novelty / 演化活动 / 谱系）+ 行为分类器 | 可证伪、可预注册 | 需先定阈值 |
| 可视化 | 现有 viz（three.js） | 已有 | 2.5D 水层需加渲染 |
| LLM 探针 | 环外：读 probe → 提假设 → 设计下一批 | 不破坏确定性 | 需日志可重放 |
| 确定性 | **L0 逐位(CPU) / L1 同卡可复现 / L2 统计等价门** | 保住归因能力 | 新增纪律（下） |

**新增纪律（拟入 内部工程指南）**

> **统计等价门（L2）**：同 seed、同世界，CPU 参考实现 vs GPU 实现，5 seed × 1000 tick：
> 均值差 ≤1%、标准差差 ≤5%、关键分布 KS 检验 p>0.05、定性区制一致。
> **机制类结论只许 L0/L1 出；L2 只出趋势。**

## 三、系统架构（五层 + 接口）

```
┌────────────────────────────────────────────────────────────┐
│ Measure   probes / lineage / 行为分类 / OEE 度量            │
├────────────────────────────────────────────────────────────┤
│ Selection 能量→繁殖→死亡（世界内选择，无适应度函数）        │
├────────────────────────────────────────────────────────────┤
│ Biosphere 基因组 → 发育 → 感知 → 决策 → 动作意图            │
├────────────────────────────────────────────────────────────┤
│ World     2.5D 地表（地形/海陆/河湖/水深/斑块/季节）        │
├────────────────────────────────────────────────────────────┤
│ Climate   ClimateSource：Live（C4a/借来的 GCM）| Table      │
└────────────────────────────────────────────────────────────┘
```

**接口契约（冻结项）**

| 接口 | 方法 | 说明 |
|---|---|---|
| `ClimateSource` | `refresh(tick)` / `temperature_c` / `precip_mm_yr` / `wind` | 已有（未接的显式 `NotImplementedError`） |
| `World` | `surface_type` / `elevation` / `depth_layer` / `soil_water` / patch fields | 2.5D |
| `Biosphere` | `step()` 返回 **intents**（动作意图），由 `resolve()` 两段式提交 | **一格一写者**，保 L1 |
| `Measure` | `probe()` / `snapshot()` / `restore()` | 进 manifest |

## 四、B 线 MVP 设计（4–6 周可出第一批结果）

| 要素 | 设计 |
|---|---|
| **基因组** | 可变长（先固定 64 槽，允许插入/删除突变）；编码：传感器权重、动作阈值、粘附、信号、栖息偏好 |
| **发育** | GRN（N 个调控节点 × 阈值）→ 把基因组映射成控制器；**映射本身可演化** |
| **表型** | 传感器（食物/邻居/威胁/信号/水陆）× 动作（移动/吃/攻击/共享/发信号/繁殖） |
| **栖息** | `habitat ∈ {aquatic, terrestrial, amphibious}` **可演化**（登陆过程自己发生） |
| **动作成本** | 信号、攻击、共享都必须耗能（**没有成本就没有协作与交流**） |
| **选择** | 世界内：能量够就繁殖，能量空就死；**没有适应度函数** |
| **判据** | 五类行为从轨迹自动分类（觅食/逃避/追击/结群/信号）+ 谱系 + 交互网络 + **消融对照** |

**零模型（必须同跑）**：关信号通道 / 关捕食 / 关粘附 / 无空间结构（全混合）。

## 五、开发线路 W0–W6（串行；并行上限 2 条线）

| 阶段 | 目标 | 交付 | 退出判据 | 时间盒 |
|---|---|---|---|---|
| **W0** | 结构 + 纪律落地 | 目录骨架、接口冻结、统计等价门入 AGENTS、基线 bench | 档② 绿 + 基线数字 | 1 周 |
| **W1** | 气候换源 | SpeedyWeather 跑通 → `GCMTableSource` → 世界读它 | 三条剖面与自建模型同量级；关档逐位等价 | 2 周 |
| **W2** | B 线 MVP | `biosphere/`（CPU，点状 agent，可变长基因，六动作，2.5D 栖息） | 觅食/逃避稳定出现；消融可辨 | 2 周 |
| **W3** | 个体内核加速 | SoA + Taichi 决策 kernel（CPU/GPU 双实现） | ≥3× 加速；L1 同卡两次一致；统计等价门过 | 2 周 |
| **W4** | 多细胞/合作 | 粘附 + 组选择 + 作弊者观测 | 团大小分布 + 分化 + 作弊者频率 | 2 周 |
| **W5** | O 线（化学起源） | 守恒原子 + 反应 + 能量 + 隔室；RAF 闭合判据 | RAF 闭合 + 维持 + 关能量即消失 | 3 周 |
| **W6** | 世界族扫描 + 探针 | 世界族定义、批量跑、LLM 环外探针 | 首批跨世界结论 | 持续 |

**并行上限**：气候（W1）与生物圈（W2）可并行；O 线（W5）单独排，不与 GPU 化同时。

## 六、数据与实验制度

1. **世界族（world family）**：一组世界规则参数（斑块性/扰动频率/季节振幅/海陆比/摇篮类型）——**这就是你们母问题的自变量**。
2. 每个实验必须：预注册判据 + manifest + seed 清单 + 零模型 + 统计等价门 + 失败集合对账（基准 `{r110}`）。
3. 数据仓：`the-world-data/world_family/<族名>/`，每批一族、带 manifest。
4. 汇总件：`内部实验台账` 按族登记。

## 八、风险与中间里程碑

| 风险 | 应对 |
|---|---|
| 开放演化是公开难题（可能多年无结果） | 每级都有**可发表的中间判据**：RAF 闭合 → 多细胞 → 合作 → 交流 |
| 变长基因 + GPU 是最难组合 | 先 CPU 跑通 W2/W4，再分桶上 GPU；变长用"固定 64 槽 + 插删突变"折中 |
| 混沌 ⇒ 需要大量 seed | 世界族扫描优先并行**多进程**；GPU 批处理放 W3 |
| SpeedyWeather 许可证/耦合成本 | W0 内先核实许可证；耦合失败则退回 ExoPlaSim 离线表（接口不变） |
| 四条线同时开 | 严格 W0–W6 串行 + 并行上限 2 |
