## 一、复盘：R110-v1 的 Q1 为什么必须重做（三条结构性缺陷）

| # | 缺陷 | 证据 |
|---|---|---|
| **1** | **判据对象是"世界动力学"而非"仪器属性"** | v1 判 `ratio` 是否落 [1.2,1.5]。但 `ratio = min(m, 10·e)`，`e = c·p`（有效转化率）**由 run 动力学主导** ⇒ 落带窗口 `e ∈ [0.12,0.15]` **与 `m` 无关**。⇒ 该判据把"能否锁定增益档"交给了**被测世界**，等于**用世界的性质给仪器打分**（60k 下 `e` 的 seed 间离散 2.4× ⇒ 2/6） |
| **2** | 通过规则是**合取式** ⇒ **反功效** | v1 =「域内 ≥5/6 ∧ 至多 1 例外」。这与 R44 已判定的坏形态同族（"各 seed 全为正" = `p+ⁿ`）：**并列条件越多、越难过**，且与 n 反向 |
| **3** | 失败**无可诊断性** | 2/6 落带只告诉我们"`e` 太散"，而 `e` 是**结果变量** ⇒ **无法据此定位仪器哪里坏**（既不能指向封顶、也不能指向转化率、更不能指向构念） |

## 二、v2 的设计原则（三条，缺一不可）

1. **判据只能依赖仪器属性**：仪器自身可断言的是 ① **封顶不被突破**（`ratio ≤ m`）② **封顶是否按设计绑定**（当世界允许时 `ratio` 是否贴着 `min(m, 10e)`）。
   ⇒ 世界"允不允许"**不是仪器的成绩**，应作为**条件**记录，而不是计入失败。
2. **把"不可判定"从"失败"里剥离**：三态语义（`pass` / **`undecidable`（世界条件不足）** / `fail`）。
   ⚠️ 与 R110-v1 的 `insufficient`（**样本不足**）**不同**：v2 的 `undecidable` 是**逐 seed 条件判定**后的计数。
3. **门槛从功效推**：所有判定阈值由**功效预跑**给出（R44 方法），**不得**取观测到的效应量。

## 三、Q1-v2 判据（迁移性复核）

### 3.1 逐 (seed, 臂) 的**结构断言**（必需，任一违反 ⇒ 直接 `fail`）

| 断言 | 判据 | 违反含义 |
|---|---|---|
| **封顶不破** | `ratio_obs ≤ m + tol`（`tol = 1e-3`） | 保本封顶被突破（**F-R16 家族**）⇒ 判据失效，**不得**继续判读 |
| **封顶绑定** | 当 `10·e ≤ m` 时，`ratio_obs ≈ 10·e`（相对误差 ≤ 5%） | 实现与设计式不符（**契约↔实现不一致**家族） |

### 3.2 逐 seed 的**可判定性**（决定该 seed 进不进"分母"）

对每个 seed 定义：

```
e_seed = applied / emissions        # 有效转化率（**该 seed 的实测**）
bind_seed = (10 · e_seed ≥ RATIO_LO)          # 上限**有机会**把它推进目标带下沿
```

- `bind_seed = True` ⇒ 该 seed **可判定**（仪器的上限有机会起作用）
- `bind_seed = False` ⇒ **`undecidable`**：世界条件不足（`e` 太低 ⇒ 上限再高也进不了带）
  ⇒ **记入 `n_undecidable`，不计失败**（= 缺陷 1 的正面修正）

### 3.3 三态判定（**预注册，跑前锁定**）

| 态 | 条件 |
|---|---|
| ✅ `pass` | `n_dec ≥ 3` ∧ 可判定 seed 中 **落带数 ≥ ⌈0.8 · n_dec⌉** |
| ⚠️ `undecidable`（**不判**） | `n_dec < 3`（可判定 seed 太少 ⇒ **样本不足以判仪器**）⇒ 停下上板请裁 |
| ❌ `fail` | 结构断言被违反，**或** `n_dec ≥ 3` 而落带比例 < 0.8 |

**关键差异（vs v1）**：v1 把"世界 `e` 太低"记成**失败**；v2 把它记成 **`undecidable`** 并要求 `n_dec ≥ 3`。
⇒ 判据从此**只问"当世界允许时仪器是否达标"**。

> ⚠️ 防滥用（自检）：`undecidable` **不得**成为"永远不判"的后门。故设**硬上限**：若**连续两批**皆 `undecidable`
> ⇒ 视为**判据设计失败**（不是仪器失败），须上板重设（R53 精神：停下修仪器，不加 seed 绕过）。

## 四、G-A v2：**双口径并列** + 通过线 `x` 的推导规则

### 4.1 为什么需要 v2

`E-021` 的读数显示：被门控拦下的到达占 **中位约 36%**（`Δ_content` 远小于 `Δ_full`）⇒ **信号作用的大头可能来自"那格**有**标记"这一存在性（信标），而非码的**含义**`。
⇒ 若 G-A 只用"全量确认"口径，**阳性可能来自信标穿透** ⇒ **需要一条"只计真内容通信"的并列口径**。

### 4.2 两条口径（并列，**不一致时以门控臂为准**）

| 口径 | 定义 | 地位 |
|---|---|---|
| **① 全量确认**（原 G-A） | oracle 臂相对 zero 臂的 ⑤/⑥ 簇级 CI 不含 0 且方向为正 | **记录**（保留历史可比） |
| **② 门控确认**（**主判**） | **门控臂**（`gate_mode=delta_positive`, `gate_delta=content`）相对 **zero 臂**的 **ρ 簇级 CI 下界 > 0** | **主判据**：只有"扣除蹭归因后仍有正选择"才算仪器通过 |

> 理由：门控臂**改的是付款规则**（仪器构念），它把"存在性触发"从付款里剔掉 ⇒ **更接近机制真相**（R100 条件 5：门控臂属**仪器**，不构成科学阳性）。

### 4.3 通过线 `x` 的推导规则（**不得**取观测效应量）

```
x = min μ  s.t.  Power(rule = ②,  n = 6,  μ,  σ_gate) ≥ 0.80
```

- 规则 ② = **簇级配对/单臂 CI 下界 > 0**（R105 形态，单尾 t，n=6）
- `σ_gate` = 门控臂 ρ 的**簇级离散**（**零机时功效预跑**：以 E-021 的 gated 臂估方差 ⇒ **只用方差，不用效应量**）
- ⇒ `x` **由功效表给出**（与 R44 同一套工具/口径：`experiments/r44_power_prerun.py`），**跑前锁定**

**`[待补]` 本稿不写死 `x` 的数值**，因为 `σ_gate` 尚未做功效预跑（属**零机时**，可立即补）。
⇒ **交付顺序**：先跑零机时功效预跑 → 得 `x` → **预注册** → 才允许用 ② 判 G-A v2。
⚠️ **禁止**：先看 E-021 的门控臂效应量、再"倒推"一个刚好能过的 `x`（那是 R88 式"自我实现结案"）。

## 五、与 R110-v1 的对照与迁移

| | v1（R110-v1） | **v2（本稿）** |
|---|---|---|
| 判据对象 | `ratio` 落带（**世界动力学**） | **结构断言 + 条件化落带**（**仪器属性**） |
| 三态 | pass / fail / insufficient（样本） | pass / fail / **undecidable（世界条件）** |
| 通过规则 | 合取式（≥5/6 ∧ ≤1 例外） | **比例规则**（可判定 seed 中 ≥⌈0.8·n_dec⌉） + 结构断言前置 |
| 诊断力 | 低（失败指向 `e`，非仪器） | 高（失败必指向封顶/绑定/落带三者之一） |
| G-A | 单口径（全量确认） | **双口径并列，门控为主** |

**迁移纪律**：**已判结果不回改**（R110 冻结条款）；v2 只用于**未来批**。C1a 的 `fail` 记录保持原样。

## 六、边界与待裁

| ✅ 能得 | 🚫 不能得 |
|---|---|
| 「当世界允许时，仪器是否把 `ratio` 抬进目标带」 | 「仪器在世界**不允许**时也没问题」（那正是 `undecidable`，**不判**） |
| 「扣除蹭归因后是否仍有正选择」 | 「信号有价值 / L1 证据」（G-A 是**仪器门**，阳性含义仅限仪器可用性） |

**待裁三点**：
1. `n_dec ≥ 3` 的下限是否合适（6 seed 中至少 3 个"世界允许"）—— 亦可取 4；
2. `⌈0.8·n_dec⌉` 是否与 R105 的 n=6 口径一致（我会用同一功效表核）；
3. 门控臂口径的**对照**取 `zero` 还是取 `ungated`（本稿取 **`zero`**：门控臂 vs 漂变零模型 ⇒ 与 v1 的 G-A 对照一致）。
