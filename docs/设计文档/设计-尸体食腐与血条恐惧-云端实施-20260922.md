## 〇、为什么这两件一起做（一条因果链）

1. **已证**：捕食"一击必杀" ⇒ 猎物（=同类）被吃光（P0.6：3/4 seed 前几百 tick 崩到 8–9 只）
2. **尸体通道**解决"打完之后没有东西留下" ⇒ 把一次性收益变成**慢释放储备**
3. **血条机制**解决"一次就死" ⇒ 把掠夺变成**消耗战** ⇒ 猎物有**逃跑与恢复的机会**
4. ⇒ 两者合起来给"**捕食者生态位承载力**"一个**内生上限**（R156 §三 算出 `K_pred ≈ 2–10% 人口`），
   这正是 Geritz 1998 要求而我们一直缺的 **I<0 负频率依赖**

## 一、尸体—食腐通道（继承 R156，按 fish 批准定稿）

| 设定（fish） | 定稿 |
|---|---|
| 击杀后不立即转能量，留尸体斑块，存续一段时间 | ✅ 尸体 = 格状态 `corpse_energy[c]`，`corpse_decay_ticks=600`（≈世代时间，满足"Noy-Meir 脉冲可累积"） |
| 能量 ≈ 若干斑块，能供一段时间 | ✅ `corpse_energy_frac=0.9`（死亡时剩余能量 ×0.9 转入格） |
| 腐烂处更易长斑块 | ✅ `corpse_to_plant_frac=0.5`（归还植物池）+ `corpse_patch_boost=+50%/2000 tick` |
| 只有非素食者可食 | ✅ **按 g16 平滑调制**（fish 01:48 批准）：`scav_mult(g16) = g16^2/(g16^2+0.5^2)`（Hill, `scav_gate=0.5` 是**半效点，不是门槛**） |
| 老死也留尸体、能量低 | ✅ 用"死亡时剩余能量 ×0.9"自然实现（老死个体能量已耗尽 ⇒ 尸体自然很轻）**不做特判** |
| 尸体不能一次吃光 | ✅ 食腐**写进胃**（复用 `stomach`，容量 100）⇒ 天然限速；`corpse_cap_per_cell=3` |

🔴 **硬性纪律**：**不得用硬门槛**（`g16>0.3 才可食` 这类）。硬门槛会在收益上造成**不连续跳变** ⇒
进化把个体堆在门槛两侧 ⇒ 直方图出现峰/凹陷，**那是门槛的画像不是分化**（同族错误：E-030 的裸 BC 伪影）。

## 二、血条—受伤—恐惧机制（fish 01:48 构想 + 文献定稿）

### 2.1 文献：**你的构想有强支撑，但必须区分三个方向不同的框架**

| 框架 | 预测 | 文献 | 我们的适用性 |
|---|---|---|---|
| **RHP（资源持有潜力）** | **受伤/RHP 下降本身就足以解释撤退**；且**持有者占优**（攻方需更高 RHP 才能赢）；**只有 RHP 接近才升级** | **Parker 1974** *J Theor Biol* 47:223 | ✅ **直接适用**（我们的场景就是格斗 + 食物争夺）⇒ **血条低 ⇒ 撤退/恐惧** ✓ |
| **致命战斗的演化** | 🔴 **当"争夺资源的价值 ≥ 未来价值"时，会演化出重伤/致死**；未来价值≈0 时**永不放弃**（至少一方死） | **Enquist & Leimar 1990** *Anim Behav* 39:1（序贯评估博弈） | ✅ **解释了我们看到的"狂奔捕食→崩"**（饿到快死 ⇒ 未来价值≈0 ⇒ 致命战斗）；⇒ **血条 = "未来价值"的载体，加入它会降低致命战斗频率** ✓ |
| **败者效应** | 赢过者再赢 ≈2/3；**输过者再输 ≈2/3**（168 个效应量 meta 分析） | **Yan et al. 2024** *Anim Behav* | ✅ **受伤后更回避**的实证支持 |
| **资产保护 / 需求导向** | **能量（资产）低 ⇒ 更冒险**（没什么可失去 + 急需） | **Clark 1994**；Barclay et al. 2018 needs-based | ⚠️ **方向与上表相反** ⇒ 见下 |
| **能力导向** | **身体能力差 ⇒ 更谨慎**（无力应对威胁） | Barclay et al. 2018 ability-based | ✅ **这正是"血条低 ⇒ 恐惧"** |

### 2.2 🔴 由此定稿的一条**可检验的二分预测**（这是本设计的科学核心）

**把"血条"与"能量"当作两种独立状态，让它们对行为的作用方向相反**：

| 状态 | 低的一方 | 行为后果 | 理论 |
|---|---|---|---|
| **血条 `health`** | 受伤/虚弱 | **更恐惧**：主动攻击概率↓、逃离威胁权重↑、升级意愿↓ | 能力导向 + Parker RHP + 败者效应 |
| **能量 `energy`** | 饥饿 | **更激进**：主动攻击概率↑、接受更高风险 | 资产保护 + 需求导向 |

⇒ **两条方向相反 ⇒ 双因素臂可以分离它们**（见 §四 D 臂）。**若方向反了，也是结论**（记"与能力导向不符"），**不得事后改预注册**。
⚠️ 交 `[外鉴]` 复核这一条（R153 分工：外鉴管文献与方法论）。

### 2.3 机制细节（五项）

| # | 机制 | 定稿 |
|---|---|---|
| **H1** | **状态量** | 个体新增 `health ∈ [0,1]`，初值 1.0；进 `__slots__`、快照、CSV |
| **H2** | **捕食从"一击必杀"改为"消耗战"** | 捕食判定成功 ⇒ 目标 `health −= Δ`（`Δ = wound_base ×(0.5+0.5×攻击性)`，`wound_base≈0.35`）⇒ **`health ≤ 0` 才死**（死因仍记 PREDATION）。⇒ 猎物被咬一次**不死但变弱、更易再次被咬** = **分期付款** |
| **H3** | **争夺食物 / 保护食物（fish 要求）** | 同一格（或邻格）已有他人正在取食（果实或尸体）⇒ 高 g16 者可发起**驱逐战**。判定用 **RHP**：`RHP = health^a × (0.3+g16)^b × (energy/max_energy)^c`（初值 a=b=c=1），**取食方 ×(1+holder_adv=0.3)**（Parker 持有者优势）。败者：`health −= Δ_loser` + **被迫离开该格**（撤退）；胜者也要付代价（能量 + 小概率自伤） |
| **H4** | **升级规则**（Parker） | `|RHP_A − RHP_B| > 阈值` ⇒ **弱方立即撤退，不进入多轮**（避免无视差战斗）；接近 ⇒ 才多轮 ⇒ **自动省机时** |
| **H5** | **恢复** | 每 tick `health += heal_rate`（上限 1.0），**并扣代谢能量**（`heal_energy_cost`）⇒ 愈合不是免费的 |

### 2.4 恐惧项的载体（与已有 L1 恐惧项的关系）

已有 L1 恐惧项：`−w_fear × perc × (1−g16) × cos(候选格 ← 威胁方向)`（R146 加入，段一已判"接线成立但无处理效应"）。
**本设计不动它**，而是**新增一个血条载体**：`−w_fear_health × perc × (1 − health) × cos(候选格 ← 威胁方向)`。
⇒ 两项目标独立、可分别开关 ⇒ **归因干净**（段一已证它无效，不要再搅在一起）。

### 2.5 纪元与默认值（🔴 硬纪律）

- **全部默认关**：`corpse_enabled=False`、`wound_enabled=False`、`contest_enabled=False` ⇒ **旧行为逐位一致**（必须有 C7 基线测试）
- 开 + `use_sim_core=True` ⇒ **构造期硬报错**（H3 fail-loud，同 L1/L2；**不改 Rust**，先走 Python 路径）
- 登记 **`AGENT.md` §十三 13.3「受伤/尸体纪元」**，写明"旧批的捕食致死率/成功率口径不可与新批比"
- **真决斗三级拆分的口径要扩展**：`attempt → wound → kill`（现有 `_duel` 结构可复用）

## 三、参数表（初值 + 依据；全部须可 CLI 调 + `switches` 读回）

| 参数 | 初值 | 依据 |
|---|---|---|
| `corpse_energy_frac` | 0.9 | 留 10% 作分解即失 |
| `corpse_decay_ticks` | 600 | ≈世代时间（单代 500–1500 tick）⇒ 脉冲可累积（Noy-Meir / Schwinning） |
| `corpse_to_plant_frac` | 0.5 | 分解归还养分（Moore et al. 2004） |
| `corpse_patch_boost` | +50% / 2000 tick | fish 的"腐烂处长斑块" |
| `corpse_cap_per_cell` | 3 | 防极点/聚集处无界堆叠 |
| `scav_gate`（半效点）/`scav_s` | 0.5 / 2.0 | **平滑**，非门槛 |
| `wound_base`（每次成功攻击扣除的血条） | 0.35 | ⇒ 一次击杀需 **3 次成功**（现状是 1 次）⇒ 直接延长猎物存活 |
| `wound_heal_rate`（每 tick 恢复） | 0.001 | ⇒ 完全愈合需 1000 tick（≈ 1/10 寿命）|
| `wound_heal_energy_cost`（愈合耗能/tick） | 0.05 | 不可免费愈合 |
| `holder_adv`（持有者优势） | 0.3 | Parker 1974（持有人优势） |
| `escalation_gap`（不升级的 RHP 差阈值） | 0.25 | Parker：只有接近才升级 |
| `contest_cost_energy` | 0.5 | 驱逐的代价（防"免费赶人"） |
| `w_fear_health`（血条恐惧权重） | 0.5 | 与已有 `w_fear` 同量级，便于对照 |
| `need_aggression_k`（饥饿激进的强度） | 固定 0.5 | **D 臂设为 0 = 关掉"饥饿更激进"** ⇒ 分离二分预测 |
