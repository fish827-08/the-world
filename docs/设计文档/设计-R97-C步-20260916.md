### 2.2 Q1 —— `ratio` 域内复核（迁移性，**C 步的第一道闸**）

> 🔴 **判定前置（内评 21:38 §三 加固 1 / R107）**：**配对对照臂 `oracle_m1.0` 是判定的前提** ——
> **缺任一 seed 的配对基线 ⇒ 该 seed 不参与判定；配对全缺 ⇒ 整批判「不判」**（不得靠其余 seed 判）。
> 且判据常量**沿用 `r97_calibration_judge.py` 的 `CRITERION_VERSION = R107-v1`**（口径冻结，不得换读法）。

`[实测]` 依据：转化率 `c` **随 run 长度上升**（0.0509@3k → 0.1483@8k，D-27 口径澄清）
⇒ `ratio = min(m, c × donation / SIGNAL_COST)` 在 60k 可能与 8000t **不同**
⇒ **不得**默认把 8000t 锁定的 `m=1.3` 直接迁移。

判据（沿用 R107 域内口径 + 三条加固）：
- **适用域 = 生态门通过**（60k ⇒ `eco_gate_applicable=True`，R3 门本义适用）；
- **划法 A** = `pred_frac < 0.9`（R38③ 既有，非事后）；**划法 B** = 终态 `N ≥ 0.9 × max_count`
  （**加固 2：比值写死**，不手填绝对值）；
- 域内全部可用 seed 的 `ratio(oracle_m1.3) ∈ [1.2, 1.5]`，且 `ratio(oracle_m1.0) < 1.2`（基线不达标 ⇒ 增益档确是区分项）；
- **两划法结论必须一致**（不一致 ⇒ 不判）；
- 配对全正须附**单侧符号检验** p 值（加固 1 的量化要求）；
- **不过 ⇒ 停下上板**（R101 S 循环：≤2 轮，每轮预注册"预期位移"；**不得**自行改 `m` 或加 seed）。

> 🔒 **加固 3 表述额度**：C 步 Q1/Q2 的报告表述**只能**是「增益档在适用域内把 `ratio` 抬进目标带」；
> **禁止**「有信息者优于随机者」「信号有价值 / 构成 L1 证据」「仪器不灵敏」「仪器全链路已验证」
> （前两条由 `rand` 分布重叠 + 行为响应边界排除，后两条由本步范围排除）。

### 2.3 Q2 —— G-A 重判（仪器门）

按 D-24 口径的**修正形态**（R105/ρ v3 + R107 配对）：

| 支路 | 统计量 | 判据 |
|---|---|---|
| **⑤（主）** | `oracle_m1.3` vs `zero` 的 ⑤ ρ **簇级配对**（Fisher z、单侧 t、n=6） | **CI 下界 > 0** |
| **⑥** | ⑥ 三联（⑥a 暴露 / ⑥b Δ / ⑥=⑥a×⑥b） | 与 ⑤ 同向且 ⑥b > 0 |
| **前置** | Q1 通过 | 未过 ⇒ **不判 Q2**（判定点不得落在中性边界，教训 18） |

⚠️ **与 D-24 的差别**：D-24 时 `ratio≈0.03–0.10`（远低于保本线）⇒ 判定点落在中性边界；
C 步 `ratio≈1.2–1.5`（明确阳性一侧）⇒ **这一次才是 G-A 的有效检验**。

### 2.4 Q3/Q4 —— 科学侧（`main` vs `zero`）

| 项 | 判据 |
|---|---|
| ⑤ ρ | 簇级合并，CI 下界 > 0（R105 锁定：R2 形态、单侧 t、**n = seed 数 = 6**） |
| ⑥ | 三联报 + 与接收侧净效应并报（v1.1 §4.3.1） |
| G-B~G-F | 沿用 D-24 六门口径（`d24_six_gates.py`），在 60k + 生态门适用下重跑 |
| 生态门 | **R3 门本义适用**（60k）：多数 seed 存活至 60k 且 N>0 持续 50k |

### 2.5 必报（不论判定如何）

`ratio` 逐 seed + 分层（划法 A/B）｜ρ 逐 seed + z̄/s_z/CI｜⑥a/⑥b/⑥｜接收侧净效应 + 偿还截断率（`oracle_ledger`）｜域外/过渡带值（记录项）｜`rand` 对照（C2）｜provenance（`code_tree_sha256` 与 HEAD 解耦）

## 三、规模与时长（估算依据均为 `[实测]`）

| 段 | run | tick | 依据 | 估算墙钟 |
|---|---|---|---|---|
| **C1** | 24 | 60000 | D-24（15 run @60k@3240 实际 ≈5h，聚合 ≈45 t/s）⇒ `24×60000 / 45 ≈ 8.9 h` | **≈8–10 h** |
| C2 | 6 | 60000 | 同口径 ⇒ `6×60000/45 ≈ 2.2 h` | ≈2–3 h |

⇒ **C1 单段接近云端单夜窗口（00:00–12:00）上限**。三个降险选项（请裁定者择一）：
1. **缩 seed**：4 臂 × 4 seed = 16 run（≈6h）—— ⚠️ 但 **n<6 违 R105 功效结论**（n=4 功效 0.634 < 0.8）⇒ **不推荐**；
2. **两臂批分夜**（先 `oracle_m1.3`+`zero` 12 run 判 Q1/Q2；次夜 `oracle_m1.0`+`main`）—— **推荐**（每夜 ≈4.5h，留余量）；
3. **全 24 run 一夜**（≈9h）—— 可行但无余量，若中途失败重试会挤窗口。

`[建议]` **方案 2**：C1a = `oracle_m1.3` + `oracle_m1.0` + `zero`（18 run，≈6.7h）先判 Q1+Q2 的前置；
C1b = `main`（6 run，≈2.2h）判 Q3/Q4。**总仍是一夜可完成（≈9h）**，但**任一段失败不互相牵连**。

## 四、🔴 需裁定者明确的两处口径（设计层的真实张力）

### 4.1 校准臂要不要进 G-A？（R100 条件 5 与 C 步目的的张力）
- R100 条件 5：`is_calibration_arm=True` 的 run **被机器强制拒收于任何判定**；
- 但 C 步的 Q2（G-A）**恰恰要用 `oracle_m1.3`** —— 它必然带校准旗。

**`[建议]`**：把条件 5 的适用范围**收紧为"科学判定"**，并**显式允许"仪器门"使用已登记校准臂**，方式：
1. 判读脚本对**两个集合分别计算**（§2.1），各自的"被排除行数"照旧打印；
2. G-A 的报告段**强制打标**：`【仪器门 · 使用已登记校准臂 · 不构成科学阳性】`；
3. 新增单测：科学集**绝不含**校准臂（机器强制），仪器集**必须标注**。
⇒ 若裁定者认为"条件 5 不得有任何例外"，则 C 步需改用 **`m=1.0` 的 oracle 臂**做 G-A —— 但那样 `ratio<1.2`，判定点又回到中性边界（教训 18 重现）。**我建议前者**。

### 4.2 `oracle_m1.0` 是否带校准旗
- 带旗：整批（含基线）被科学判读拒收 ⇒ 防基线静默混入（R106 已"照准"此口径）；
- 不带旗：`m=1.0` 的 oracle 臂会**进入科学集**，与 `main` 混在一起 ⇒ **不推荐**。
**`[建议]` 带旗**（与 R106 口径一致）。
