**列命名口径**：`mi_*` = 互信息族；`g5_*` = 行为改变率族（既有 + I-1）；`*_last_over_first` = 末/首 25% 窗比值（**L0 稳态判据专用**）。

**I-5 CI 形态细则**（v1.1 R1）：
1. 每 run 池化 `I-5_run`（**逐对池化 = 全采样点合并算 MI，不逐窗**）；
2. seed 级 n（n = 存活 seed 数）⇒ Fisher z 变换：`z_i = atanh(I-5_run_i)`；
3. 合并 `z̄ = mean(z_i)`，样本 SD `s_z = stdev(z_i, ddof=1)`；
4. 单侧 95% CI 下界 `z̄_LB = z̄ − t_{0.95, n−1} · s_z / √n`；
5. 反变换回 I-5 尺度：`I-5_LB = tanh(z̄_LB)`；
6. **主判据 = `I-5_LB > 0`**（**禁**个体级 n = pop 代入，R96 伪重复红线；**禁**固定数值阈如 0.05——MI 尺度无先验依据，砚 Q4a）。

**I-6/I-7 窗口切点**（v1.1 R2 锁死）：
- **定义**：采样点按 tick 序排列（sample=100 ⇒ n_samples = ticks/sample = 30 窗），前 **25% 窗** = `first_windows = samples[:int(0.25 * n_samples)]`，末 **25% 窗** = `last_windows = samples[-int(0.25 * n_samples):]`；
- **数值**：n_samples=30 ⇒ `int(0.25 * 30) = 7` ⇒ 首 7 窗 / 末 7 窗；
- **一致性**：与砚 M1 骨架 **J1"末段/首段"** 同一切点定义（同一 25% 比例、同一 `int()` 边界处理）——**避免两套窗**；若砚 J1 实际定义与此不符 ⇒ §8.1 三方商讨（本稿按字面 25% 落，不猜）；
- **聚合**：`g15_last_over_first = mean(g15_mean in last_windows) / mean(g15_mean in first_windows)`（同 `emit_rate_last_over_first`）；分母 = 0 ⇒ fail-loud。

**已删（v1.1 R4）**：v1 §三/§四 "若砚 Q2 未答附 p1c 候选清单 / 私有信息通道是否复用 pos/pep"两段整体删；p1c `pos_*/pep_*` 家族不迁用 M1（口径污染）。

**默认不加**（砚 16:58 Q2 明列）：

- **码本熵 / Steels 对齐率**（C2 侧，R366 L0+L1 不引用——写了也不判）。
