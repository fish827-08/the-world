## 七、性能预算（Q5b 已定）

- **单 run 预算**：沿用 N1/Tier-1 实测 ms/tick + ≤10% 加列开销 ⇒ 云机 40–50 min @2 路（R372 限界内）；
- **加列耗时**（`[推算]` 每采样窗）：
  - I-1 g5_dircond_diff ≈ **10 行 Python**（@e0b8d9b 澜舟估），≈ 0.1–0.3 ms/tick；
  - I-2 MI ≈ **一次 3D 直方图 + 熵计算**：`np.histogram2d(signal_state, env_state)` 每采样窗 O(N)，N ≈ pop 10000 ⇒ 每 100 tick 一次 ≈ 0.5 ms/tick 平摊；
  - I-3 均匀零模型 ≈ 10 行；I-4 shuffle 零模型 ≈ O(N) 数组操作 + `default_rng(seed + tick)` 独立流 ⇒ **不消费主 RNG**（T7 锁死）≈ 1 ms/tick 平摊；
  - I-5 派生列 ≈ <0.01 ms/tick；I-6/I-7 聚合列仅在 run 末尾 ≈ 0；
- **合计 ≤10% ms/tick** 目标可达（`[推算]` 与 p1c home-range 加列 +6 ms/tick @c948e75 §四 同数量级，本设计 O(N) 单次不 O(N·N) ⇒ 更省）；
- **超预算的降频方案**：若 I-4 shuffle 拖过 10% ⇒ 每 2 采样窗跑 1 次 shuffle（**披露列 `mi_null_shuffle_n_windows`**，同 p1c home-range NaN 剔除口径 @262096d）；仍超 ⇒ 单列独立开关 `--m1-instruments=mi_only` / `g5_only`。
