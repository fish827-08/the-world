> 2026-10-10｜轻舟 `[本地开发·性能线]`｜状态：**定案待建**（骨架搭建中，分支 `feat/viz-v0`）
> 上游：owner 直令（"做可视化 + 组件专家团"）｜本稿 = v0 最小可用方案，求审。

## 〇、一句话

把实验运行变成"**看得到、可复查**"的本地 Web 应用：**世界回放**（球面 480×960 格逐帧渲染 + 实体叠加）＋ **指标仪表盘**（ECharts 读序列 CSV）。
总原则：**零侵入引擎**——导出器只读快照/序列的公开格式，不改 `simulation/`。

## 一、架构（两段一线）

```
[引擎快照 npz + 序列 CSV] → [导出器 viz/exporter（Python/NumPy）] → [静态数据包] → [前端 viz/web（Vite+React+TS）]
```

- **导出器**：读快照 → 驱动引擎续跑 N tick（每 k tick 采一帧）→ 输出 `meta.json` + `frames/`（uint8 栅格）+ `entities/`（Float32 实体缓冲）+ `series.csv`。
- **前端**：v0 纯静态（无后端）：加载数据包 → Canvas2D + ImageData 渲染世界 + ECharts 仪表盘。
- **数据面**：帧序列体积大 ⇒ **不入主仓**，落 `the-world-data/`（或 `_rerun_logs/`）；主仓只维护代码与契约。

## 二、技术栈（定案）

| 层 | 选型 | 理由 |
|---|---|---|
| 导出器 | Python（仓内 .venv）+ NumPy，**零新依赖** | 本机 venv 无 PIL（不用）；二进制帧直接 `np.tofile` |
| 前端构建 | Vite + React + TypeScript | 启动快；TS 类型守契约 |
| 世界渲染 | Canvas2D + ImageData（uint8→RGBA 上色） | 460k 格 = 960×480 像素位图，逐帧直写轻量；v0 不上 WebGL |
| 图表 | ECharts | 序列仪表盘成熟；按需引入 |
| 状态管理 | Zustand | 播放器状态（帧/播放/图层）小而集中 |
| 服务端 | 无（v0） | 静态数据包 + 本地静态服务；省运维 |

本机备查：Node v24.9.0 / npm 11.6.0（可用）。

## 四、数据契约 v0（要点；全文 `viz/CONTRACT.md`）

**1. `meta.json`**：契约版本、世界尺寸（rows/cols）、帧轴（start/end/stride/n_frames）、通道清单（key/kind/归一化分位/cmap）、源快照信息（路径/tick/配置指纹）。

**2. `frames/ch_<key>/<idx>.bin`**：每通道每帧一个文件，行主序 `uint8`，长度 `rows*cols`；等距圆柱投影 ⇒ 直接当位图。归一化参数（分位裁剪）在 meta，**只进诊断列**（不改数）。

**3. `entities/<idx>.f32`**：实体叠加缓冲（flat_idx / energy / mode 等列），Float32 小端；前端叠加为亮点（尺寸/色相按能量）。

**4. `series.csv`**：复用实验侧逐 tick 序列（实测列含 seed/arm/tick/pop/global_sat/abs_food/abs_cap/ms_per_tick/n_patches/patch_sat_*…），ECharts 直读。

**5. 通道清单 v0**（来源=快照实测键）：`resource_grid`（资源）、种群能量（按 `flat` 聚合到栅格）、`fruit_grid`；可选：`corpse_energy`、`smell_S`（有则出）。

**快照源键**（exporter 只读；实测自 `simulation/sphere_engine.py::save_snapshot`）：
SoA（`id/flat/sub_r/sub_c/energy/age/generation/health/mode/…`）、场（`resource_grid/resource_capacity/resource_patch_mask/fruit_grid/corpse_energy/signal_marks/smell_S`）、元（`tick/count/config_dict`(JSON)/`gene_count/config_fingerprint/snapshot_version`）。

## 七、约束与红线

- 帧数据/产物**不入主仓**；样例数据包放 `the-world-data/`。
- 导出器**只读**公开格式（npz/CSV），要新字段 → 走引擎快照正常流程，不在可视化线改引擎。
- 大世界帧预算：单通道 `uint8` = 460,800 B/帧；500 帧 ≈ 220 MB ⇒ 用 stride 降频、按需单通道；契约保留 `stride` 字段。
- 非目标（v0 不做）：实时联机渲染（运行时推流）、3D 视角、多 run 对比（M4+ 再议）。
- 后端无依赖新增：前端 `react/react-dom/zustand/echarts` + Vite 工具链；导出器 numpy-only。
