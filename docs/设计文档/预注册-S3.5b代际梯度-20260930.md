# 预注册：S3.5b 按代梯度补测

**日期**：2026-09-30
**负责人**：青梧（探针改造 + 本机跑批）
**裁定**：天平 R280 §四（采纳按代分层，派青梧执行）

---

## 一、实验目的

S3.5（R275）发现 g22（记忆权重基因）有正向选择趋势（方向一致率 11/16），但未达 2×SD_null 显著性。青梧诊断（R280 §四-1）：**全种群均值被老一代（gen0，g22≈0.5 初始随机分布）稀释**，新生代的选择信号被压平。

本补测用**按代分层统计**（gen0/gen1/gen2/gen3+ + latest）排除稀释，核心指标 = `g22_mean_latest − g22_mean_gen0`，验证选择信号是否在新生代中显形。

## 二、探针改造（分支 `qingwu/s35b_gen_g22`）

### 新增列（默认行为不变，旧列逐位保留）

| 列名 | 含义 |
|---|---|
| `g22_mean_gen0` | 第0代（初始个体幸存者）g22 均值（基线） |
| `g22_mean_gen1` | 第1代 g22 均值 |
| `g22_mean_gen2` | 第2代 g22 均值 |
| `g22_mean_gen3p` | 第3代及以上合并 g22 均值 |
| `g22_mean_latest` | 最新一代（max_gen）g22 均值（信号最纯） |
| `pop_gen0/1/2/3p` | 各代个体数（诊断代际结构） |
| `max_gen` | 当前最深代数 |

### 实现要点
- 只读 `eng._generation[:N]`，不改仿真逻辑
- 某代无个体 ⇒ 该代均值 NaN，pop=0
- N=0（灭绝）⇒ 全部 NaN/0
- C7：新增统计列不影响仿真行为，digest 不变

### 冒烟验证（1000 tick，seed=42，小世界）
- t=600 出现 gen1（8个体），gen1 g22=0.5696 vs gen0=0.4868
- t=1000 gen1=41个体，gen1 g22=0.5614 vs gen0=0.4750，全种群=0.5034（被稀释）
- **确认稀释效应存在，按代分层有意义**

## 四、主门判据

### 主门 A：新生代选择信号
`g22_mean_latest`（t=2000）配对差（on − off）> **2×SD_null**

- SD_null = off 臂种子间 `g22_mean_latest` 的标准差（自校准漂变噪声）
- 通过线：≥ 6/8 seed 配对差为正 **且** 中位配对差 > 2×SD_null
- 若通过 ⇒ 选择信号在新生代中显形，S3.5 的"纪元不足+稀释"诊断成立
- 若未通过 ⇒ 登记阴性，g22 选择效应确实弱，等旗舰 60k（~90代）复测

### 支持门 B：代际梯度单调性
on 臂 `g22_mean` 随代数递增（gen0 < gen1 < gen2 < gen3+）的 seed 数 ≥ 5/8

### 支持门 C：稀释效应量化
`g22_mean_latest − g22_mean`（全种群）的中位差值 > 0，证明全种群均值确实低估了新生代信号

## 五、反例登记

- 若某 seed 灭绝（pop=0）⇒ 该 seed 所有 g22 列为 NaN，不计入统计，登记为"灭绝反例"
- 若 max_gen < 1（无新生代）⇒ 该 seed 无法测代际梯度，登记为"代际不足反例"
- 若 on 臂 g22_latest < off 臂（反向选择）⇒ 登记为"反向反例"，不删除
