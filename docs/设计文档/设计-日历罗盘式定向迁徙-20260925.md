## §0 一句话

**不给个体"感知食物梯度"的能力（那条路已实测被信噪比堵死：食物带移动比个体随机运动慢 17–20 倍），而是给它真实鸟类用的两件东西 —— 一个日历（本地日照时长）和一个罗盘（自己的绝对纬度）—— 再加一个自由的基因位，让"要不要用、用多强"由选择压自己决定。**

## §1 为什么是它：文献依据

### 1.1 真实迁徙的机制（`[文献]`，检索 2026-09-25）

| 层 | 事实 | 出处（经综述转述） |
|---|---|---|
| **触发器** | **光周期（日照时长）是跨类群的主导触发**，且它是**先行信号**：光照变化**发生在食物变化之前**，且**绝对可靠**（不受天气/年际波动影响）⇒ 鸟在食物**还充足**时就开始迁徙 | Gwinner 1986/1996；Berthold 1996/2001 |
| **但不是纯外源** | 笼养数年、光照/食物/温度**全恒定**，鸟**照样**在春秋出现 **Zugunruhe**（迁徙不安：夜间躁动、朝迁徙方向反复起飞）⇒ **存在内源年度钟**；光周期只负责**对表**（内源节律会漂移） | 同上 |
| **方向也是内源的** | 恒 12h:12h 光周期下，鸟在"主观秋季"偏好**南**、"主观春季"偏好**北** | Gwinner & Wiltschko 1980 |
| **罗盘是复数套** | 太阳罗盘（Kramer 1949）＋星象罗盘（Emlen 1970）＋**地磁罗盘（用磁倾角而非极性）**（Merkel & Wiltschko ~1970）；每天黄昏用日光**重校准** | Cochran et al. 2004 *Science* |
| 🔴 **磁倾角 ≈ 纬度计** | 磁倾角与纬度**强相关** ⇒ 鸟的"罗盘"实质在**读自己的纬度** | 同上 |
| **跨类群共性** | 鸟类（光周期）／鲑鱼（光周期＋嗅觉印记）／海龟（温度＋磁感受）／帝王蝶（**保幼激素**）／有蹄类（**降雨·返青**，**非光周期主导**）。三条共性：① 光周期主导（例外见括号）② 导航永远是**多套罗盘组合** ③ 分清 **orientation（保持朝向）** vs **navigation（定位修正）** | `[文献]`，2026-09-25 检索 |

### 1.2 允许借鉴 / 不允许借鉴（划界）

| ✅ 允许借鉴（机制原理） | ❌ 不允许借鉴（物种细节） |
|---|---|
| "**日历＋罗盘**"这个最小配置（不需要"地图"） | 具体的磁感受器生理、褪黑素通路 |
| "**日照时长是先行信号**"⇒ 用它而非食物梯度 | 具体物种的迁徙日期/路线 |
| "**方向偏好可遗传**"⇒ 用一个基因位承载 | 具体基因座 |
| "**多套罗盘**"⇒ 我们只需一套（世界纬度是绝对的） | 星象罗盘（我们没有星空） |

🔴 **关键：我们不需要"地图"（navigation），只需要"罗盘"（orientation）** —— 因为我们的世界纬度是**绝对**的、每个个体都能读到自己的位置。这是相对真实鸟类**大幅降低**的难度。

## §2 机制（数学式）

### 2.1 两个新可观测维度（只加"能看见什么"）

| 维度 | 定义 | 为什么便宜 |
|---|---|---|
| **日历：本地日照时长** `P(φ, t) ∈ [0,1]` | 该纬度**该日内太阳在地平线上的时间占比** | 解析式，**零新物理**：太阳赤纬 δ(t) 已在算（13.7） |
| **罗盘：绝对纬度** `φ` | 每个个体**只读自己所在格** | 纬度场已存在（`world.latitude_of`），**不需要感知范围** |

日照时长的解析式（标准天球公式）：

```
cos(H₀) = −tan(φ)·tan(δ(t)) ,  H₀ = 半日角 ∈ [0, π]
P(φ,t)  = H₀ / π
```
- `H₀ = π/2`（P=0.5）⇒ 昼夜等长；`H₀ = 0` ⇒ 极夜（P=0）；`H₀ = π` ⇒ 极昼（P=1）。
- 太阳赤纬 δ(t) = `tilt_rad · sin(2πt / season_period)`（13.7 已有）。

🔴 **P 与 `illumination` 是两回事，绝不能互推。** `illumination` 是**光照强度**且被 `lat_base_ref` 的纬度因子乘过；`P` 是**昼夜时间占比**。用 illumination 反推 P 会把两个量混成一个（C9 型错误）。

### 2.2 迁移项（一行）

对个体 `i`（所在格 `c`），其候选邻格集合 `nb = {n₁…n_k}`：

```
A_i(t) = P(φ_c, t) − 0.5                     # 本地日照异常见量，∈[−0.5, 0.5]，>0 = 本地夏季
Δ|φ|(n) = |φ_n| − |φ_c|                       # 该候选移动"离极地更近/更远"
score(n) += w_mig · g23_i · A_i(t) · Δ|φ|(n)
```

**读法（人话）**：
- 本地正值夏季（`A>0`，白天长）⇒ 奖励**往极地走**（`Δ|φ|>0`）；
- 本地正值冬季（`A<0`，白天短）⇒ 奖励**往赤道走**（`Δ|φ|<0`）；
- **南北半球自动都对** —— 因为用的是 `|φ|` 而不是带符号的 `φ`，无需任何半球分支。

### 2.3 为什么这不是"把答案写进模型"

| 我们给了什么 | 我们没给什么 |
|---|---|
| ✅ 一个**可观测维度**（本地日照时长） | ❌ 没有写"日照<X 就往南" |
| ✅ 一个**可观测维度**（绝对纬度） | ❌ 没有给迁徙个体额外能量/繁殖奖励 |
| ✅ 一条**可被使用的通路**（`g23` 缩放） | ❌ 没有按季节打"方向偏好表" |
| ✅ `g23` **完全自由**（可为 0／任意正负） | ❌ 没有设定 `g23` 的"正确值" |

🔴 **纪律核心**：**`g23` 是自由的，收益完全来自未被改动的觅食/能量/繁殖账。**
⇒ 若迁徙无益，选择压会把 `g23` 压向 0 —— 机制**自己会证伪自己**。这正是它可被实验检验的原因。

## §3 实现规格

### 3.1 配置（`simulation/config.py`）

```python
@dataclass
class MigrationConfig:
    """13.8 日历—罗盘式定向迁徙（默认关 = 旧行为逐位等价）。"""
    enabled: bool = False     # 默认关 ⇒ 整块跳过 ⇒ C7 digest 不动
    gain: float = 50.0        # 全局权重 w_mig（实验旋钮；**不是**基因）
    min_abs_anomaly: float = 0.0   # |A| 低于此值不计（抑制春秋分附近的噪声翻转）；
                                   #   0.0 = 不设门槛（默认，最小实现）
```

挂进 `SimConfig`：

```python

```
⇒ **经 `asdict` 自动进指纹**（跨档续跑被拦），与 `subpos`/`resource_dynamics` 同规格。

### 3.2 基因位（`simulation/genes.py`）

- `Gene.RESERVED = 23` → **`Gene.MIGRATE_BIAS = 23`**（**值不变 ⇒ 基因组长度不变 = 24**）。
- 同步更新 `GENE_SEMANTICS[23] = "迁徙倾向（日历—罗盘）"`。
- 🔴 **必须先 `grep -rn "Gene.RESERVED"` 全仓**（实测当前仅 `simulation/genes.py:61` 一处定义 + Rust 侧 `sim_core/src/genes.rs:59 (G_RESERVED)` + `sim_core/src/lib.rs:89` 注册）。Rust 侧**只改注释/名字不改行为**，或**保持不动并在本文件登记**（二选一，必须回板说明选了哪个）。
- ⚠️ `g23` 在初始化时**已有随机值**（它一直被当预留位随机赋值）⇒ 开档时种群天然带 `g23` 变异 ⇒ **这正好是剂量—响应的原料**（见 §6）。**不要**把它初始化为常数。

### 3.3 光照侧（`world/light_and_temperature.py`）

新增方法（**不是**改 `illumination`）：

```python
def photoperiod(self, rows_or_flat, tick: int) -> np.ndarray:
    """日照时长占比 P ∈ [0,1]（半日角 / π）。无季节时恒 0.5。"""
```

要求：
1. **每 tick 缓存一次**（照 `_ensure_cache` 范式，新增 `_cache_photoperiod_all` / `_cache_pp_tick`）。
2. 🔴 **极点数值守卫**：`|φ| → π/2` 时 `tan(φ) → ∞`。必须 `φ_clip = clip(φ, −(π/2−ε), π/2−ε)`（ε=1e-9）**并断言结果 `np.isfinite(P).all()`**。这是本设计**最可能产生 NaN 并静默污染全批**的点。
3. `H₀ = arccos(clip(−tanφ·tanδ, −1, 1))`，`P = H₀/π`。
4. 无季节（`_season_on=False`，即 δ≡0）⇒ `P ≡ 0.5`，**不走 Rust 分支也不影响任何既有行为**。

### 3.4 引擎侧（`simulation/sphere_engine.py`）

**(a) 构造期**（`__init__`，与既有逐格数组同批）：
```python
self._lat_abs = np.abs(self.world.latitude_of(<每行>))[<行索引展开到格>]  # (n_cells,) 只读
```

**(b) 移动打分段**（`score` 计算处，`nb` 已就绪 ⇒ 与 `mem`/`interp`/L1 各项同一位置）：

```python
if _mig_on:
    self._mig_dec_n += 1
    _A = float(self._photoperiod_anom[self._flat[idx]])          # 本地日照异常见量
    if abs(_A) > _mig_min_abs:
        _dabs = self._lat_abs[nb] - self._lat_abs[_cell_i]        # 逐候选 ⇒ 不退化
        _m = (_mig_gain * float(genes[idx, Gene.MIGRATE_BIAS])) * _A * _dabs
        score = score + _m
        self._mig_term_sum += float(np.abs(_m).sum())
        self._mig_term_n += int(_m.size)
        if float(np.abs(_m).max()) < 1e-12:
            self._mig_zero_n += 1      # 自熄（A≈0 或候选同纬）
        if float(_m.max() - _m.min()) < 1e-12:
            self._mig_flat_n += 1      # 🔴 R148-1 反退化：对所有候选取同值
```
🔴 **必须同时记 `_mig_flat_n`**（R148-1 的教训：某项对所有候选同值 ⇒ `argmax` 逐位不变 ⇒ "接了却一行行为没改"）。同纬候选（极点行冗余槽位/同一行内移动）会天然产生 `_mig_flat_n>0`，**属预期，但必须报出比例**。

**(c) 统计容器**：在 `__slots__` 里登记上述所有新属性（🔴 引擎是 `__slots__` 类，未登记 ⇒ `AttributeError`），并加进 `reset()`。

## §4 前提与守卫（R127 冒烟必报）

| # | 前提 | 怎么验 | 不成立的后果 |
|---|---|---|---|
| **P1** | δ(t) 真在跑 | `delta_mean` 摆幅 ≈ `tilt_rad` | 季节没接上 |
| **P2** | `P(φ,t)` 真有纬度结构 | 同 tick 的北/南半球 `photoperiod` 均值**符号相反** | 日照时长接错 |
| **P3** | `P` 无 NaN / 无越界 | `isfinite` + `[0,1]` 断言 | 静默污染全批 |
| **P4** | 迁移项**非恒零** | `mig_zero_frac < 0.5` | `A≡0`（= M2 没拦住） |
| **P5** | 迁移项**非全同值** | `mig_flat_frac` 明显 < 1（预期极点行会贡献一部分） | R148-1 退化 |
| 🔴 **P6** | **量级不越权** | `mig_term_abs_mean` 与 `perc·fr·0.5` 项量级**同阶或更小** | gain 太大 ⇒ 覆盖觅食 ⇒ 全体撞极区饿死 |
| **P7** | 基因位真的在 | `switches.migrate_gene_slot == 23` | 接了别的位 |

🔴 **P6 是本设计最容易翻车、也最必须先测的**：`Δ|φ|` 每格 ≈ 0.05 rad，`A` 最大 0.5 ⇒ 单项 ≤ `0.025·gain·g23`；而觅食项 `perc·fr·0.5` ≤ 0.5。⇒ **`gain·g23 ≈ 20` 时两项同阶**。**S2 必须先扫 3 个 gain 档报量级，再定 S3 用哪个** —— 不许一个大 gain 直接上正式批。

## §5 判据（🔴 预注册，S3 开跑前不得修改 —— R194 B8）

### 5.1 形态：一主两支持 + 三态（R149/R151）

**主判据 D_mig（剂量—响应）**：
> 在迁徙臂内，**个体级**半季净纬向位移 `Δφ_i` 与其 `g23_i` 的**个体级相关系数 ρ**，按 seed 分层后合并，**显著为正**。

- 🔴 **必须是个体级，不是种群质心** —— R196 的教训：质心往返可以被"原地更替"伪造（他的三臂对照显示 R196 臂个体位移 6.16° **反而小于**无季节基线 7.49°）。
- 推断单位 = **世界种子**（个体级观测在 seed 内相关 ⇒ 合并时按 seed 加权，报 seed 层 ρ 的分布，不做个体级伪重复检验）。

**支持 1（对照）**：迁徙臂的个体级位移幅度 **> 空臂 A（有季节、无迁徙）**，配对 seed。
**支持 2（方向）**：高 `g23` 组的**半季位移符号**与 `sign(δ)` 的**一致率 > 0.5**（= 追随夏天，而非单向漂移）。

| 组合 | 结论 |
|---|---|
| 主过 + 支持过 | **定向迁徙成立** |
| 主过 + 支持不过 | **证据不完整**（报出是哪个支持失败） |
| 主不过 | **未成立** |

**第四态「纪元不足·判据不可执行」**：`观测 tick < 3 × season_period` ⇒ 不判。（迁徙是**一生内**行为响应，**不需要 30 代**；但 `g23` 的**进化**读数需要长批，另行标注。）

### 5.2 判读文件必须带

`世代列` ｜ `seed 分层` ｜ `g23 均值/标准差随时间` ｜ `mig_flat_frac` ｜ `P1–P7 前提表` ｜ 三臂全部读数（含**空臂**）。

### 5.3 必须预先声明的阴性解释

| 观察 | 允许的解释 | **不允许**的解释 |
|---|---|---|
| 位移 = 0 且 `mig_zero_frac ≈ 1` | **前提失败**（A≡0）⇒ 不可读作"迁徙无益" | ❌ |
| 位移 = 0 且 `g23` 全被压到 0 | **选择压淘汰了迁徙**（= 机制自证伪，**这是有效阴性**） | ❌ "还没跑够" |
| 位移 ≠ 0 但 `ρ(Δφ, g23) ≈ 0` | **全体同向漂移**（不是剂量—响应）⇒ 不支持"基因在起作用" | ❌ "迁徙成功" |
| 位移 ≠ 0 但个体**大量饿死** | gain 越权（P6 失败） | ❌ "迁徙成立" |
