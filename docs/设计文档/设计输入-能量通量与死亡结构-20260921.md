**世界尺度**：捕食总能量流 vs 食草通道量级 = **0.27%（E_prey=50）～1.62%（E_prey=300）**。

### 1.3 结论（🔴 采纳 fish 判断）

1. **一个个体一辈子平均只吃 0.29 个同类** —— 在**生命周期尺度**上，捕食几乎不产生能量。
2. 捕食收益占一生能量预算 **< 1%**（即使按最有利假设 E_prey 取满 300）⇒ **捕食基因没有任何被保留的理由**（成本确定、收益千分之几）。
3. ⇒ **E-030 的"未分化 + 单向扫荡"是这个能量不平衡的必然结果，不是"曲率不够陡"。**
4. ⇒ 推论：**要出双峰，必须在能量上支撑一个"捕食者生态位"——即把捕食通量提高 2–3 个数量级**（目标：捕食占能量预算 **30–50%**，而非千分之几）。

## 二、对 C 档的修订：**重心从"成本"转到"通量"**

原名"C 档风险化"里的两项（`attack_cost` 0.1→1.0–1.5、`transfer` 0.4→0.7–0.8）**最多把通量提高 ~4–8 倍 ⇒ 仍只有 1–3%**，**不足以支撑第二峰**。

**杠杆组合（乘法作用，目标 ×30–100）**：

| 杠杆 | 现状 | 建议 | 倍数 | 需改代码 |
|---|---|---|---|---|
| 攻击门槛 `attack_gene_gate` | 0.3 | **0.15** | 攻击者人数 ×~2 | 参数（已存在） |
| 出手系数 `attack_prob_coef` | 0.2 | **0.5** | 出手率 ×2.5 | 参数 |
| 成功率 `success_floor/ceil` | 0.1 / 0.9 | **0.35 / 0.95** | ×3–5 | 参数 + 公式（C 档已含） |
| 单次收益 `transfer_ratio` | 0.4 | **0.9** | ×2.25 | 参数 |
| **合计** | | | **≈ ×45** | ⇒ 通量到 **~10–40%** 量级 ✓ |

⚠️ **必须配套的平衡闸**（否则直接灭绝或"捕食者吃光一切"）：
- `attack_cost` **同步提高**（0.1→1.0–1.5）⇒ 让攻击是"有本钱的赌博"（fish 原意保留，但它**不是**通量杠杆）
- **比率依赖捕食**（云端 §二，Arditi–Ginzburg）⇒ 猎物稀时成功率自动下降，防灭绝
- 专性阈值（`g16>0.6` 不能吃斑点）**必须与此同批**，否则"能吃斑点 + 高捕食收益"的杂食者通吃

## 三、老死结构与方案（回答 fish 问②）

### 3.1 现状（实测）

| 臂 | 老死 | 饿死 | 被捕食 | **选择性死亡(饿+捕)** | 平均寿命 |
|---|---|---|---|---|---|
| ak0（有捕食） | **61.2%** | 7.2% | 29.1% | **36.3%** | 3695 |
| ak2（无捕食） | **66.2%** | 31.4% | 3.1% | **34.5%** | 6762 |

寿命公式：`2400 × lifespan_mult × (1+7·g3)` = **2400–19200 tick**；成熟 = 0.15×寿命；老年起点 = 0.75×寿命。

### 3.2 🔴 这解释了一个更根本的问题

**约 2/3 的死亡是"到时死"（`age ≥ lifespan`），对觅食/信号基因近似随机** ⇒ 只有 ~1/3 的死亡是"竞争性"的
⇒ **有效选择强度被稀释 ~3 倍** ⇒ 这是 **ρ≈0 的一条构造性候选解释**（与"没有健康窗""信号无冗余内容"并列，第四次收窄）。

### 3.3 方案表（按"零代码优先"排序）

| 方案 | 旋钮 | 现状→建议 | 预期效果 | 代价/风险 |
|---|---|---|---|---|
| **F1 加重衰老** ⭐ | `senile_mult` | 1.4 → **2.5–3.0** | 老年维持成本↑ ⇒ **老年个体更易饿死** ⇒ 把"到期死"**转为"竞争死"**（死亡与表现挂钩） | **零代码**；总死亡流量↑（N 可能低于上限） |
| **F2 基础代谢↑** | `base_metabolism` | 0.6 → 0.8–1.0 | 全体维持成本↑ ⇒ 饿死↑（更选择性）；同时压低人口 | 零代码；风险：可能全面崩塌，须冒烟 |
| **F3 软顶造窗** | `soft_cap_target` | 无 → 0.6–0.8×K | N 不顶格 ⇒ 竞争真实 ⇒ 饿死↑（**PC-1 开关已建**） | 开关已有 |
| **F4 资源稀缺化** | `capacity_per_area`/`regrowth_rate` | 40 / 0.5 → 降 | 直接提高饿死占比；与 patchy 联合 ⇒ "斑块争夺" | 零代码 |
| **F5 幼体成本↑** | `growth_mult` | 1.6 → 2.5–3.0 | 幼体维持成本↑ ⇒ **幼体死亡↑**（最选择性的死亡：只有吃饱的幼体能长大） | 零代码 |
| **F6 捕食通量↑** | 见 §二 | ⇒ 被捕食占比↑ | 最具选择性（健康/高能量个体更不易被吃） | 需改代码（C 档） |
| ⚠️ **F7 缩短寿命** | `lifespan_mult` | 1.0 → 0.3 | **反直觉：老死占比会升高**——总死亡流量由出生侧决定 ⇒ 老死率↑ ⇒ 占比↑。但**成熟年龄同比提前 ⇒ 世代加快** | **不要用它降老死占比**；它服务"加快世代"这个**不同目标** |

**推荐顺序（R135 纪律：一次一个单变量 + 冒烟）**：**F1 先做**（零代码、直接命中"到期死→竞争死"）→ 看死因结构变化 → 再 F3/F5 → F6 随 C 档。

**预注册判据（建议）**：选择性死亡占比（(饿+捕)/总）从 **~35% 提到 ≥60%**；同时报 ρ 与世代数（对照"选择压是否变可测"）。
