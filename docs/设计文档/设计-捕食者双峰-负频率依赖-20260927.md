## 〇、一句话结论

**E-034 已证明：现行捕食公式下 `W(g)` 无内部谷 ⇒ 双峰在数学上不可能，根因是"缺频率依赖"
（W 在'E 固定'近似下与种群组成无关 ⇒ `D' = W_mm` ⇒ CSS⇔ESS ⇒ 无分支点）。**
**本稿的正路 = 给捕食公式引入负频率依赖（NFDS）：让"攻击型（高 g16）的收益随其在种群中的频率上升而下降"，
使 `W(g, m)` 在内部出现**适应度极小**（Geritz 1998 分支点）—— 双峰从"不可能"变成"参数窗口内可演化"。**
给出 3 个候选机制（猎物侧 apostatic / 捕食者侧自我抑制 / 攻防共演化）+ 预注册判据三层 + 风险。

## 一、背景：为什么"负频率依赖"是正路（E-034 的精确化）

### 1.1 E-034 证伪了什么（一句话）

现行公式 `W(g) = (1-g)^k·F + 1[g>gate]·[p(g)·s(g)·E_prey·r − p(g)·c]` 中：
`p(g)`（出手概率）与 `s(g)`（成功率）**同时随 g 单调增** ⇒ 捕食收益是"双重正反馈" ⇒
**`W(g)` 全区间单调（至多一个 gate 跳变拐折），无内部极小** ⇒ 破坏性选择必要条件不满足 ⇒
g=1 是吸收边界，种群只单向收敛，长不出双峰（18/18 参数组合实测确认）。

### 1.2 但 E-034 留下了正路的钥匙

证伪文档 §四 明确指出根因：**"W 在'E 固定'近似下无频率依赖（缺 `W_mr`）⇒ `D' = W_mm` ⇒ CSS ⇔ ESS ⇒ 分支点不存在"**。

这正是自适应动力学（adaptive dynamics）的标准结论：**进化分支（evolutionary branching）本质上是频率依赖现象**——
Geritz et al. 1998 的整个框架建立在**适应度函数依赖种群组成** `s(y; x₁, x₂)` 上：
当奇异点 x* 是**适应度极小值**（fitness minimum）而非极大值时，两个方向的突变都能入侵 ⇒ 种群分裂（分支）。
**没有频率依赖，就没有"极小"；有负频率依赖，稀有型有利，中间态被排斥 ⇒ 谷出现 ⇒ 双峰可演化。**

### 1.3 负频率依赖在自然界是维持多态的主力机制

- **Clarke 1962（apostatic selection，反定型选择）**：捕食者不成比例地捕食**常见**猎物型（搜索意象/更多遇见），
  **忽视稀有型** ⇒ 常见型频率↓、稀有型频率↑ ⇒ 达到平衡 ⇒ **多态被维持**。
  —— 这恰好是"捕食者-猎物 g16 分化"的生态学原型：猎物因被捕食压力分化出"稀有有利"的表型多样性。
- **NFDS 统一定义**（2023 综述）：与自身丰度上升相关的**每个体适应度下降** —— 维持多态、多样性的第一机制。

⇒ **我们项目要做的 = 在现行捕食公式里把"频率依赖"这一项补回来**，其余不动。

## 二、三个候选机制（含数学形式，预注册用）

> 记号：g = g16（攻击基因，∈[0,1]）；`p(g)` = 出手概率；`s(g)` = 成功率（现行公式）；
> `f_hi` = 攻击型（g > gate）在**目标群体**中的频率（口径见 §四-0）；`λ` = 频率依赖强度（新参数，默认 0 = 现行公式逐位不变）。

### 方案 A：猎物侧 apostatic 选择（主方案，最贴 Clarke 1962）

**机制**：被捕食风险随猎物型的频率上升而上升 —— 捕食者**目标选择偏向常见猎物型**、忽视稀有型。
实现：成功率乘"猎物稀有度折扣" `s(g) → s(g)·(1 − λ·f_target)`，其中 `f_target` = 目标猎物（低 g16 群）中
该猎物表型（按 g16 分箱）的频率。

**直觉**：当素食端（低 g16）种群内部出现分化时，常见表型被盯上、稀有表型有"逃逸窗口" ⇒
素食端内部出现稀有有利 ⇒ **素食端的多样性被捕食压力维持**（而不是被单向压成一种）。
同时攻击端（高 g16）吃到的猎物变"滑"（常见型变少、稀有型难找到）⇒ 攻击收益边际下降 ⇒ 高 g16 端也被抑制。
**两端同时被"频率"拉回 ⇒ 中间谷出现。**

**数学形式（预注册三选一，待解析扫描定）**：

```
A1:  s'(g) = s(g) · (1 − λ · f_target)                    # 线性折扣
A2:  s'(g) = s(g) · (1 − λ · (f_target − f_avg))          # 相对平均频率（全种群平均）
A3:  s'(g) = s(g) · exp(−λ · f_target)                    # 指数折扣（强非线性）
```

### 方案 B：捕食者侧自我抑制（猎物稀缺的负反馈）

**机制**：攻击收益随攻击者频率上升而下降 —— 高 g16 个体越多，可捕猎物密度/可得性越低，
成功率与猎物能量都降 ⇒ **攻击型扎堆时互相拆台**（竞争猎物 + 捕食效率稀释）。

**数学形式（预注册）**：

```
B1:  W_pred(g) *= (1 − λ · f_hi)      # 攻击收益乘"攻击者频率"折扣
B2:  s'(g) = s(g) · (1 − λ · (f_hi − f_hi_avg))   # 相对频率
```

**直觉**：这是"捕食者内卷"—— 高 g16 的个体优势在种群普遍高攻击时消失 ⇒ 高 g16 端自我抑制 ⇒
与素食端（低 g16）之间出现负斜率区间 ⇒ 内部谷候选。

### 方案 C：攻防共演化（Red Queen 路线，远期）

**机制**：猎物防御 g16 与捕食者攻击 g16 **频率耦合**（Dieckmann & Marrow 1995 类）：
攻击收益依赖"攻击者 g16 相对猎物 g16 的分布差" ⇒ 双方在 g16 轴上追逐，产生**持续的多样化压力**。
**本稿只登记、不展开**（需要两群体共演化 + 更复杂的频率统计，成本高；先看 A/B 能否成立）。

## 三、预注册判据（三层分报，参照 E-034/E-030 格式）

> 纪律：三层各自独立报；第一层不过 ⇒ 后两层不用跑（解析先行，成本分钟级）。

### 第 0 层 · 仪器自检（防自我证伪，必须先行）
- **判据 0**：`λ = 0`（关闭频率依赖）时，`W(g)` 扫描结果与 E-034 **完全一致**（无内部谷、g=1 吸收边界）
  ⇒ 证明"仪器没坏"（引入频率项是唯一变量）。复用 E-034 的 200,001 点网格扫描法（`experiments/analyze_bimodal_fitness.py`）。

### 第一层 · 机制成立（解析/数值，分钟级）
- **主判据 ①**：引入频率项后，`W(g)` 在 g∈(gate, 1) 内部出现**适应度极小值**（`dW/dg` 变号 + `d²W/dg² > 0`，
  且极小值显著低于两侧——阈值沿用 E-034 的 slope 判据并修复其 TOL 丢谷缺陷）；
- **副判据 ②**：极小值位置 g* 随 λ 单调变化（强度扫描 λ ∈ {0.1, 0.3, 0.5, 1.0}），且参数窗口存在
  （不是单点奇点）；
- **不可放行**：① 不成立 ⇒ 该方案直接淘汰（不是调参问题，是机制没接上）。

### 第二层 · 演化涌现（跑批，n=6 同 E-030 功效口径）
- **主判据 ③**：g16 分布**双峰/宽方差** —— 处理臂（λ>0）终态 g16 分布出现**双峰**（BC 判据须换零分布，
  E-030 教训：0.555 阈值是均匀分布的 BC 值 ⇒ 本批须用"λ=0 对照臂的分布"作零分布，不能裸用绝对阈值）；
- **副判据 ④**：多样性维持 —— g16 方差/多样性指标（如 std、Shannon）处理臂 > λ=0 对照臂（配对 6/6）；
- **对照臂**：λ=0 臂必须仍是**单向收敛**（g16→0 或 →1，E-030 扫荡复现）⇒ 证明双峰是频率依赖带来的。

### 第三层 · 生态效应（与主线衔接）
- **副判据 ⑤**：捕食者-被捕食者共存 —— 处理臂终态 N 不崩（> 对照的 10–30% 崩盘率）、
  且**捕食死亡占比保持非零**（说明捕食生态位真在运行，不是靠关捕食）；
- **副判据 ⑥**：多态对应生态位 —— 双峰两峰的**捕食死亡率/素食产能**存在显著差异（峰间分工，不是纯遗传漂变）。

  全局频率作对照（简单但可能与空间解耦）—— 两口径都须写进 summary 的 provenance（补 `git_commit`/`config_fingerprint`/旋钮回声，R225 P0 教训："数字没有出处"）。
2. **改动点（估计）**：捕食段成功率/收益公式（`sphere_engine.py` L3595+ 与 Rust `_resolve_attacks` 对应段）
  加频率折扣项 + 新参数 `freq_dep_lambda`（默认 0 = 现行公式逐位不变 = 回滚点）+ 频率统计（邻居 g16 直方图）；
  约 60–100 行 + 双路径逐位对拍（λ=0 时）。
3. **参数扫描（第一层先行）**：λ × {A1,A2,A3,B1,B2} 解析扫描（分钟级），选出现内部谷的最小组合

4. **与主线关系**：双峰是 **R152 C 档**（远期特性），**不阻塞** S2/C3 主线；本设计稿只是把"正路"钉下来，

## 五、风险与反证

| # | 风险 | 对策 |
|---|---|---|
| 1 | **加了频率项也不出现分支**（参数窗口窄或机制接错） | 第一层解析扫描先行（分钟级）；三个方案 + 两种频率口径 = 6 组合，全灭才判路线失败 |
| 2 | **λ 太强 ⇒ 振荡/崩盘**（Red Queen 极限、E-033 个体迁徙教训：观测位移=随机游走本底） | 强度扫描从 λ=0.1 起；判据 ③ 要求"双峰但 N 不崩"双条件 |
| 3 | **频率项把 λ=0 基线搞漂**（C7 逐位对拍破坏） | 新参数默认 0 ⇒ 现行公式逐位不变（回滚点）；任何改动先双路径对拍绿 |
| 4 | **双峰是遗传漂变/搭车假象**（E-030 教训：均值降+方差塌=扫荡；g18 搭车教训） | 判据 ④ 配对报（同 seed λ vs 对照）；判据 ⑥ 要求峰间生态位差异 ⇒ 排除纯漂变 |
| 5 | **局部频率统计的性能税**（每 tick 统计邻居 g16 直方图） | 复用稀疏化 B 的惰性/局部结算思路；先冒烟测开销，超预算则降频（每 N tick 统计一次） |

**反证预设**：若 6 组合（3 方案 × 2 口径）第一层全灭（无内部谷），或第二层 ③④ 全阴性（n≥6、功效足够）
⇒ **"本世界结构下捕食公式负频率依赖不足以产生双峰"** —— 结论照实上报，
转向：① 频率依赖放在别的基因/交互上（如食物竞争、配偶选择）② 或接受"捕食双峰不是本世界可涌现特性"。
**不修判据、不延批。**
