## 二、代码事实（逐行可核）

### 2.1 仲裁档的四模式显著度**只读气味，不读信号码本**

`[代码]` `sphere_engine.py:3072-3088`：

```python

```
⇒ **四模式的输入全部是"自己格的环境量"，没有一个来自"同伴发来的码"**。

### 2.2 模式内选格**整段替换**了融合 score（含信号解读项）

`[代码]` `sphere_engine.py:3151-3160`：
```python

    score = np.where(_md==0, _sf[nb],              # feed:  只看食物气味
```

🔴 **关键**：仲裁档走`if` 分支，**融合档那套（含 `_interpret` 信号解读，`:3180-3187`）根本不执行**。

### 2.3 `kin` 通道 ≠ D2 信号

`[代码]` `sphere_engine.py:2724-2726`：
```python
if "kin" in ch: out["kin"] = (flat, np.ones(P))   # 所有活体个体
```
⚠️ **`kin` 是"同类在场"的环境场（含自己），不是"谁在发信号、发的什么码"**。

**两者的差别**（这决定能不能叫"融入"）：

| | D2 信号（`signals`） | `kin` 通道 |
|---|---|---|
| 载体 | `_marks`（每 tick 写1 个码，寿命 50 tick） | 环境场（由个体位置自动注入） |
| 内容 | **可被学习的内容**（`_interpret` 码本，Steels 对齐） | **只有"谁在场"** |
| 方向性 | 有（发信者指定接收者） | 无（弥散全场） |
| 🔴 是否可学 | ✅ D2 核心机制 | ❌ 只是个密度场 |

⇒ **把 `kin` 接进仲裁 ≠ 把 D2 信号接进仲裁**。前者已实现，后者**完全没做**。

`[代码]` `config.py:1163-1171` 的互斥表里，仲裁档**禁掉**了 D2 相关的机制。核心是这条：

`[代码]` `:3710`：
```python
_hm2_on = _hm_on and not _asm_on    # 仲裁档下HM ②关闭
```

`[代码]` `:4048` 快路径门槛里，`arbitrary_codebook` / `d2_asym` / `d2_softmax` 等都会把 `_batch_ok` 关掉。

**⇒ 仲裁档与 D2 是"两套决策架构"，架构级互斥。** 这不是 bug，是 R238 的有意设计：
- 仲裁档 = **WTA 选模式 → 模式内只认环境**
- D2 = **码本解读→ 加进融合 score**

🔴 **两者是两种不同的"信号哲学"**：仲裁档说"模式由环境决定，环境定行为"；D2 说"信号内容可学习，改变行为"。

## 四、三个可选方案（供天平选）

### 方案 A：🔴 **只跑仲裁，不带 D2**（现状，零改动）
**做法**：`--asm-mode arbitration --mode on`，但 D2 的 `arbitrary_codebook` 等**保持现批设置**。
**归因**：干净（仲裁单变量）。
**代价**：🔴 **信号对行为无影响**（解读项被屏蔽）⇒ **测不到"信号能否切模式"**——而这恰恰是 R238 说的"服务 C3"的核心命题。

### 方案 B：🟡 **让 `sal_join` 吃"信号解读"而非"kin 场"**（改一行接线）
**做法**：`sal[2] = w_join · Ŝ_interp(nb_signals) · (2·g13−1)`，即把"聚集"的显著度来源从"同类在场"换成"**读到的同类信号码**"。
**依据**：这才是"信号能切模式"的最小实现——信号不再只是 score 里的一个小项，而是**决定生物处于哪个模式**。
**🔴 代价**：
- 破坏 12 项互斥（须解开 `arbitrary_codebook` 与仲裁的互斥）
- 🔴 **等于部分放弃 D2 的码本对齐机制**（`_interpret` 是 Steels 对齐的载体）
- 🔴 **三路径对拍全部要重做**（Python 参考/Rust `movement.rs`/向量化，`:3710-3818`）

### 方案 C：🟡 **新增第 5 模式 `respond`（应答）**（纪元级）
**做法**：加一个模式，显著度 = "收到的信号强度"，进入该模式时行为 = 趋近发信者。
**依据**：最贴近自然界（蚂蚁信息素 = 环境场 + 同伴调解）。
**🔴 代价**：**必须扩基因位**（`AGENTS.md` 记预留位已全部接管）⇒ **纪元级变更**。
