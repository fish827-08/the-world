### 3-2 引擎钩子（D-1）· 最小记账，2 行 append

**问题**：逐块被捕食死亡**坐标**在纯探针侧不可得（`[代码]` 多路核实）：
- `predation_mask` 是 `_step_population` 内**每 tick 局部数组**（:4521 建 → :4663/:4690 置 → :4767 并 `dead` 后弃），tick 后无痕；
- `self._duel["kills"]`（:4666/:4693）与 `death_cause_totals()`（:2740-2742 Counter）均为**计数**无位置；
- `energy_ledger()` 仅全局聚合；尸体阵列 `_corpse_energy` 无法区分饿死/被捕食死 ⇒ 不能替代归因。

**方案**（"最小偏离 + 默认零成本"；v2 已按镜 F5 落 3 元组）：
```python
# __slots__ 追加（硬约束：不登记运行期 AttributeError，:551-560 明注）
"_rd_pred_kill_log",
# 构造器：self._rd_pred_kill_log = None
# 捕食结算两处致死点（:4663 / :4690，"kills += 1" 邻位；两处同式）：
if self._rd_pred_kill_log is not None:
    # 🔴 F5：3 元组 = (稳定 id, 死亡格, 当时 tick)——`prey` 槽位号同 tick 后段
    #   压缩（:5061）即失效，不能作跨窗 join 键；id/tick 供 Q-C 相关（接线批）。
    self._rd_pred_kill_log.append(
        (int(self._id[prey]), int(self._flat[prey]), int(self._tick)))
```
- `(稳定 id, 死亡格 flat, tick)`；**flat 语义** `[代码]`：移动在步骤 5，捕食结算在其后 ⇒ 结算点 `_flat[prey]` = 猎物当 tick 死亡格（T11b 合成锚钉死——真跑 arity 亦锁）；
- **零 RNG 消费 / 零能量改动 / 零行为改动**；默认 `None` ⇒ 两处分支均不进 ⇒ **逐位等价**（T11a 锁）；
- 生命周期：载体在 `run` 装配段（`--rd-instruments` 且 Python 路径时）`e._rd_pred_kill_log = []` 安装；每 rd 窗末**排空**（`log[:] = []`）⇒ 内存 O(窗内死亡数)；**F6（v2）**：drain 遇 `None`（快照续跑经 `cls(config)` 重建引擎 ⇒ 钩子静默回 `None`）⇒ **fail-loud `SystemExit`**（不得 `or []` 伪装"本窗无杀"）；**rd 批禁续跑**（resume 直接拒，须 `--fresh`）——两处均 T9-F6 锁；
- **Rust 路径 fail-loud**：`--rd-instruments` + `e._sim_core is not None` ⇒ `SystemExit`（钩子只在 Python 捕食段；C1 本批全 Python 路径本就满足 §八 D2 纪律）；
- **成本** `[推算]`：每 run ≥1k–4k 次 append ≈ 亚毫秒级；`__slots__` +1 槽位零布局开销。

**裁决记录（v2）**：D-1 = **已裁接受**（R396① 最小必要偏离：无该钩子 ⇒ Q-A/Q-B 空间维度整体不可测 ⇒ 批废；备选皆死路——纯探针重算不可行／尸体归因不分死因／per-tick 全量导出偏离更大）。F5（3 元组）＋F6（fail-loud＋禁续跑）＝镜预审整改项，已实装于 `task/C1-IMPLEMENT`（T11/T14/T9-F6 锁）。
