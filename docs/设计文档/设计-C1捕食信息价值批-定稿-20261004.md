### 3-2 引擎钩子（D-1）· 最小记账，2 行 append

**问题**：逐块被捕食死亡**坐标**在纯探针侧不可得（`[代码]` 多路核实）：
- `predation_mask` 是 `_step_population` 内**每 tick 局部数组**（:4521 建 → :4663/:4690 置 → :4767 并 `dead` 后弃），tick 后无痕；
- `self._duel["kills"]`（:4666/:4693）与 `death_cause_totals()`（:2740-2742 Counter）均为**计数**无位置；
- `energy_ledger()` 仅全局聚合；尸体阵列 `_corpse_energy` 无法区分饿死/被捕食死 ⇒ 不能替代归因。

**方案**（"最小偏离 + 默认零成本"）：
```python
# __slots__ 追加（硬约束：不登记运行期 AttributeError，:551-560 明注）
"_rd_pred_kill_log",
# 构造器：self._rd_pred_kill_log = None
# 捕食结算两处致死点（:4663 / :4690，"kills += 1" 邻位；两处同式）：
if self._rd_pred_kill_log is not None:
    self._rd_pred_kill_log.append((int(prey), int(self._flat[prey])))
```
- `(个体槽 idx, 死亡格 flat)`；**flat 语义** `[代码]`：移动在步骤 5（:3601 注释），捕食结算在其后 ⇒ 结算点 `_flat[prey]` = 猎物当 tick 死亡格（T11b 合成锚钉死；若该锚不过 ⇒ 实现层改用结算前快照，属实现修正不属设计变更）；
- **零 RNG 消费 / 零能量改动 / 零行为改动**；默认 `None` ⇒ 两处分支均不进 ⇒ **逐位等价**（T11a 锁）；
- 生命周期：载体在 `run` 装配段（`--rd-instruments` 且 Python 路径时）`e._rd_pred_kill_log = []` 安装；每 rd 窗末**排空**（`log[:] = []`）⇒ 内存 O(窗内死亡数)；
- **Rust 路径 fail-loud**：`--rd-instruments` + `e._sim_core is not None` ⇒ `SystemExit`（钩子只在 Python 捕食段；C1 本批全 Python 路径本就满足 §八 D2 纪律）；
- **成本** `[推算]`：每 run ≥1k–4k 次 append ≈ 亚毫秒级；`__slots__` +1 槽位零布局开销。

**请裁**：D-1 对 M0 规格 §三"探针侧首选（🟢 不改引擎）"是**最小必要偏离**（无该钩子则 Q-A/Q-B 空间维度整体不可测 ⇒ 批废）。备选均为死路：①纯探针重算 = 不可行；②尸体归因 = 无法区分死因；③per-tick 全量导出 = 偏离更大。**R225 请 PI 就 D-1 单独裁一行**（§九-1）。
