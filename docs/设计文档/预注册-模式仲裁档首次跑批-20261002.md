**判据**：B 臂 `mode_share` 四模式**均 > 0 且均 < 1**（不塌缩到单一模式）。

| 情形 | 判定 |
|---|---|
| 存在某模式占比 ≥ 0.999（≈100%） | ❌ **塌缩**（模式没起作用，或某模式吞掉全部） |
| 存在某模式占比 ≤ 0.001（≈0） | ❌ **缺模式**（该模式不可达） |
| 四模式均 ∈ (0.001, 0.999) | ✅ **通过** |

🔴 **反证（预注册写死）**：若 B 臂 `mode_share` 与 A 臂（fusion）**完全相同** ⇒ 说明仲裁没生效（接线错）⇒ 判"**机制未生效**"，**不得**解释为"仲裁无效应"。

### Q2（红线）：dithering

`[代码]` Bryson 的头号风险（`config.py:1069` 注释：最小锁定防 dithering）。
**判据**：切换频率 `sw_rate = sw_n / (N_alive × ticks)`，须满足

$$\text{sw\_rate} \le \frac{1}{\text{hold\_ticks}} = \frac{1}{20} = 0.05$$

| 情形 | 判定 |
|---|---|
| `sw_rate > 0.05` | 🔴 **dithering 红线触发** ⇒ 机制在，但参数不合适 |
| `sw_rate ≤ 0.05` 且 `hold_block_n > 0` | ✅ 锁定机制在起作用（挡下了本应切换） |
| `sw_rate ≤ 0.05` 且 `hold_block_n == 0` | 🟡 锁定从未被触发（可能 hold_ticks 太大） |

### Q3（生态门）：仲裁会不会把生态搞崩

`[代码]` 生态稳定前置门（R3/R6）：**先过生态门，才准谈其他判据**。

| 指标 | 红线 | 依据 |
|---|---|---|
| **灭绝** | B 臂在≥5/6 seed 中 N 稳定 > 0 持续到目标 tick | R3/R6 硬门 |
| **K（承载力）** | 🔴 **≤30% 跌幅** | 沿用 S2 判据①的止损线 |
| **饿死占比** | 相对 A 臂 **+≤8pp** | 沿用 S2 判据③的实测幅度（2.8–8.8pp） |

⚠️ **若 K 跌幅 > 30%** ⇒ 判"**止损**"（机制代价过大）⇒ **但仍要报告 Q1/Q2**，因为那是机制信息。

### Q4（探索/利用）：探索模式占比是否合理

`[代码]` `base_explore=0.2` 意为"探索的时间占比下限倾向"。

| 情形 | 判定 |
|---|---|
| `explore` 占比 ∈ [0.05, 0.60] | ✅ 合理 |
| `explore > 0.60` |🟡 过度探索（趋化失效，等价于随机游走） |
| `explore < 0.05` | 🟡 探索不足（可能困在局部最优） |
