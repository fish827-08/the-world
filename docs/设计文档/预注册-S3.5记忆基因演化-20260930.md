# 预注册：S3.5 · 记忆基因演化（g22 选择压；天平 2026-09-30；fish 批准后开跑）

## 一、要回答的问题

记忆权重基因 **g22**（`Gene.MEMORY_WEIGHT=22`，13.11 接线；eff = cfg_gain × 2×g22，仅 memory_v2 路径消费）在 **memv2 开启的世界里是否被自然选择**？

- S3 已证**机制级**：记忆改善空间利用（判据 A 24/24 过门）；
- S3.5 测**演化级**：记忆的机制收益是否转化为对 g22 的选择压（个体差异 ⇒ 可遗传 ⇒ 可被选择）。
- **方向不由我们预定**：若记忆净收益 > 成本 ⇒ 选择抬升 g22；若记忆是净成本（S3 判据 B 显示留守型探索成本 −4.3%）⇒ 选择压低 g22。**两个方向都是有效结论**；无漂移 = 2000t 内不可测（诚实分层）。

## 二、装置与规模（自校准对照设计）

- 世界 = S3 同款（480×960 / patches=1700 / pop=10000 / bg_low 0.4+0.05 / rd on / **质心优化版 main @`444bc98+`**）；
- 两臂：`mem_on`（memv2 开 ⇒ g22 被消费）vs `mem_off`（memv2 关 ⇒ **g22 不被消费 = 纯漂变对照**）；
- **自校准**：g22 漂移的 null 噪声尺度由 off 臂自身种子间漂移给出（配对差的 SD），不用外部假设；
- 规模：**16 seed = 149–164**（与 42–148 全错开）；2000 tick；sample 250；
- 执行：**本机**（4–6 路并行；优化后单 run on 臂 ≈5–8 min）ETA [推断] ≈ **30–60 min**；
- 探针改造（云归）：S3 探针 + 每 sample 追加 3 列：`g22_mean` / `g22_p10` / `g22_p90`（活体 `eng._genes[:N, Gene.MEMORY_WEIGHT]`，N=len(eng._flat)）；
- 跑前 `rd_resume_smoke.py`；产物入数据仓。

## 三、预注册判据（跑前锁死；不修判据、不挑种子）

| # | 判据 | 口径 | 判定线 | 依据 |
|---|---|---|---|---|
| **A（主门·选择显形）** | `g22_mean` 配对差（on−off）@t=2000 | 逐 seed 配对；效应量 = 中位差 | 判定线 = **\|中位差\| > 2×SD_null**（SD_null = off 臂配对差 SD，自校准）⇒ 选择显形；**方向如实报**（正=记忆被青睐 / 负=成本主导） | 对照臂给 null；2SD 控制假阳性 |
| **B（支持·分布形态，只报不设门）** | `g22_p90 − g22_p10` 宽度配对差 | 报告轨迹 | — | 方向选择会收窄/移动分布 |
| **C（支持·轨迹，只报不设门）** | g22_mean 的 tick 轨迹（500→2000） | 报告单调性/拐点 | — | 早锁定 vs 渐进漂移 |

**登记三条反例（防事后自欺）**：
1. **漂变主导**：on 臂无方向漂移 ⇒ 2000t 不足或选择极弱——如实记，不得用"接近 2SD"当成功；
2. **门控证伪**：off 臂 g22 也同向漂移 ⇒ 与记忆无关的全局漂移（如初始化偏差）⇒ A 不成立；
3. **样本量边界**：16 seed 的配对检验功效有限（效应量小时判"纪元不足"而非阴性）。

**判定分层**（R149 形态）：一主（A）+ 两支持（B/C）；三态 + 第四态「纪元不足」（趋势存在但未达 2SD ⇒ 长批/加种子后复测）。

## 四、判读与下一步

- A 显形且为正 ⇒ 记忆被自然选择 ⇒ "信息价值 → 适应度"链条打通，S3/S3.5 双门齐过 ⇒ S4（扇形记忆）升级动机充分；
- A 显形且为负 ⇒ 记忆净成本被选择淘汰 ⇒ 触发"记忆成本专项"（增益/衰减参数标定纪元）；
- 未显形 ⇒ 纪元不足登记，并入后续长批（如旗舰 60k 挂 g22 统计）。
