# digital-life-sphere 语言涌现扩展 L1~L6 技术汇总

> 分支：`feature/l1-patchy`（从 `main` 切出，不碰 main）
> 版本：v0.5 → v0.6（L1~L6）
> 目标：在有限死规则内让生命自发涌现智能与语言（明确不使用 LLM）

---

## 一、总体架构

### 1.1 技术栈

| 层 | 技术 | 职责 |
|----|------|------|
| 世界层 | Python | 球面网格 60×120=7200 格、光照温度、资源场、信号场 |
| 引擎层 | Python + NumPy | 单 tick 流程 0~9、数组化 SoA 推进、繁殖/死亡/清理 |
| 加速核 | Rust + PyO3 | 热点循环下沉（移动决策/捕食/文化学习/数值管线） |
| 观察层 | Python | 统计聚合、世代追踪、快照桥（WebSocket） |

### 1.2 引擎单 tick 流程（_step_population）

```
0  温度/光照计算
1  光合作用（g8 光合基因）
2  代谢耗能（g1 代谢倍率 × 年龄系数）
3  维持耗能（恒温 g9 / 基础消耗）
3.5 植物化增强（g19，光合×(1+g19)）
4  进食（同格均分，不欠账）
4.4 工作记忆写入（食物丰富格记录到 4 槽）
4.5 信号发射（g15，田字格 16 模式，耗能 0.1）
5  移动决策（g14 感知 + g13 群居 + 信任 + 记忆 + 解读表）
5.5 捕食（g16，饥饿驱动攻击）
5.6 信任学习（真信号+ / 假信号-）
6  年龄推进
6.5 文化学习（幼体向邻格成体学习解读表）
7  死亡判定（饿死 / 老死 / 被捕食）
8  繁殖（成熟 + 冷却 + 能量门槛，基因遗传+突变）
8.5 愉悦度更新（RPE 预测误差驱动）
9  清理尸体 + 数组压缩
```

## 二、L1~L6 分级详解

### L1：斑块资源（空间异质化）

**目标**：语言涌现五要素第一步——资源空间异质化，让生物有"值得交流的信息"（哪里有食物）。

**实现**：
- `ResourceConfig` 新增 7 个斑块参数：`patch_count / patch_radius / patch_capacity_mult / patch_regrowth_mult / background_fill / patch_seed / patchy`
- `ResourceField` 守恒分布：
  - **容量守恒**：Σ_capacity 与 uniform 相等（背景容量倍率自动计算，保证 >0）
  - **再生守恒**：面积加权 patch_mult×patch_frac + bg_mult×bg_frac = 1
  - 初始食物**不守恒**（斑块格填满、背景格贫瘠——这是 patchy 的核心特征）
- patch 中心选择用**独立 rng**（patch_seed=config.seed），不消费引擎 self.rng → 同 seed 下 uniform/patchy 个体初始分布完全一致
- patchy 模式下 Rust regrow 回退 Python（Rust 侧暂未支持空间倍率）

**实验**（`experiments/patchy_vs_uniform.py`，2000 tick，N=500）：
- 总食物守恒（差异 <1%）
- 种群 0/3 灭绝
- 空间聚集未显现（无感知基因，预期内——L1 只加基础设施）

**测试**：`tests/test_patchy_resource.py` 18 例全过

---

### L2：信号场 + 愉悦度系统

**目标**：语言涌现的物理载体（信号场）+ 内在动机系统（愉悦度，超越食物/繁衍的第三驱动力）。

#### 2.1 田字格信号场（`world/signal_field.py`）

- 每个格子设为田字格 4 子格 → 2^4 = **16 种标记模式**，uint8 存储（低 4 位）
- `duration=50 tick` 衰减，覆盖写入，批量读写
- 生物可写入（g15 发射）和读取（移动决策中感知）
- 16 模式 = 足够的符号空间（类比音素/词位）

#### 2.2 愉悦度系统（RPE 预测误差驱动）

四数组 SoA 存储：
| 数组 | 形状 | 含义 |
|------|------|------|
| `_valence` | (N,) | 情绪效价 -1~1（瞬态，RPE 响应） |
| `_arousal` | (N,) | 唤醒度 0~1（\|RPE\| 大→高唤醒） |
| `_expectation` | (N, 120) | 预期表（120 情境，EWMA 学习） |
| `_baseline` | (N,) | 基线（慢漂移，习惯化） |

**核心机制**：愉悦 = 实际获得 − 预期获得（RPE = reward − expectation）
- 120 情境编码：能量5档 × 食物4档 × 邻居3档 × 信号2档
- EWMA 学习 α=0.05（慢半拍，那半拍就是愉悦来源）
- 乐观初始化 0.8×max_reward（逼生物探索：预期高→现实可能超预期→愉悦）
- 繁殖继承 + 噪声 N(0,0.02)
- baseline 慢漂移（习惯化——长期愉悦/不愉悦会被适应）

**测试**：`tests/test_signal_field.py` 11 例 + `tests/test_pleasure.py` 9 例全过

### L3：感知基因（g14）+ 信号基因（g15）

**目标**：让生物能感知环境（g14）并发射信号（g15），形成"感知→信号→感知"的信息循环。

#### 3.1 g14 感知基因

移动决策综合得分：
```
score = perc × (食物×0.5 + 信号×0.5×trust) + 群居×密度 + 记忆×0.3×perc + 解读表×0.4×perc
```
- perc = g14（感知权重，越高越看重食物和信号）
- trust = 个体信任度（L5 学习，被骗过的个体忽略信号）
- 记忆 = 工作记忆中的食物格（L5）
- 解读表 = 文化传递的信号解读（L5）

#### 3.2 g15 信号基因

- 发射概率 = g15 基因值
- 模式 = 状态哈希（能量2位 + 食物1位 + 邻居1位 = 4位 → 16 模式）
- 发射耗能 0.1（修复后，原 0.5 导致基因被淘汰）
- 信号持续 50 tick

**关键发现（5000 tick 实验）**：
- g14 被保留（0.522→0.554）——感知有利
- **g15 被淘汰（0.473→0.301）**——发射耗能 > 接收收益，沉默者适合度更高
- 这是演化诚实反馈：没有接收者的信号系统必被沉默者摧毁

**g15 修复**（在 L4 提交中）：
- 发射成本 0.5→0.1
- 移动决策信号权重 0.3→0.5（食物×0.5+信号×0.5）
- 信息增益 0.3→0.5

**测试**：`tests/test_perception_signal.py` 10 例全过

---

### L4：捕食（g16）+ 植物化（g19）

**目标**：引入种间竞争（捕食）和生态位分化（植物化），增加选择压力和生态多样性。

#### 4.1 捕食（g16）

- 攻击概率 = g16 × 0.2 × 饥饿度（能量低才攻击，饱食不攻击→避免过度捕食）
- 攻击耗能 0.1（无论成败）
- 成功率 = clip(能量比 × (0.5+g16×0.5), 0.1, 0.9)
- 成功：获猎物 40% 能量 + 20% 胃粮，猎物标记 PREDATION 死亡
- `DeathCause.PREDATION` 新增枚举

#### 4.2 植物化（g19）

- 移动概率 = g0 × (1-g19)（扎根越深越不动）
- 光合收益 × (1+g19)（扎根越深光合越强）
- 统一在 stage1 后补，保证双路径（Python/Rust）一致

#### 4.3 gene_count 扩展

16 → 24 位，为 g17 食性/g18 防御/g20 享乐/g21 处理位/g22 信任阈值/g23 预留。

**实验**（2000 tick，N=500，patchy，seed=42）：
- g16 攻击基因呈现**频率依赖选择**（0.510→0.577→0.399）：密度高时捕食有利、密度低时不利
- trust 信任度先升后降再回升（0.501→0.944→0.376→0.456）：信任学习机制在工作
- g15 信号基因修复后维持在 0.31~0.46，未被完全淘汰

**双路径对拍修复**：
- 死亡+繁殖判定统一用 Python 重算（因为捕食/植物化在 Rust stage2 之后改变 energy）
- died 字段漏算 predation 的 bug 修复

**测试**：`tests/test_l4_l5.py` 10 例（捕食/植物化/信任/记忆/文化）

### L5：信任学习 + 工作记忆 + 文化传递

**目标**：语言涌现的三大认知基础设施——信任（防欺骗）、记忆（时空上下文）、文化（代际传递）。

#### 5.1 信任学习

- `_trust` 初始 0.5，范围 [0,1]
- 真信号（移动到有信号+有食物的格子）：trust +0.05
- 假信号（有信号但无食物）：trust -0.1
- 移动决策中信号权重 × trust（信任度低的个体忽略信号）

#### 5.2 工作记忆

- 4 槽 round-robin 记录食物丰富格（食物比例 >0.3）
- 移动决策中记忆格在邻格 → +0.3×perc 加分
- 4 槽容量 = 语言涌现的必要条件（有限记忆→信息压缩→符号化）

#### 5.3 文化传递（Kirby 迭代学习模型简化版）

- `_interpret` (N,16) 解读表：每个信号模式（0~15）对应一个值，正=移向、负=逃避
- 幼体（age < 成熟年龄）向邻格成体学习：EWMA 收敛 α=0.1
- 繁殖继承 + 噪声 N(0,0.1)
- **这是语言涌现的核心机制**：代际传递 + 学习瓶颈 → 自发涌现共享信号系统

**长实验发现**（60 万 tick 实验，只跑到 6000 tick 被终止）：
- tick 4000 种群爆发到 4998（上限 5000），g15=0.765
- **trust 从 0.906 崩溃到 0.005**（种群爆发后信号大量出现但多为假信号）
- 文化多样性 cult_div 仅 0.035（解读表趋同——可能是文化进化的早期阶段）
- N=5000 时性能仅 10 tick/s → 触发 L6 性能优化

### L6：Rust 下沉性能优化

**目标**：N=5000 时性能从 ~10 tick/s 提升到可在 2 小时内跑完 60 万 tick。

#### 6.1 性能分析（cProfile @ N≈4500）

| 热点 | 占比 | 调用次数/tick | 来源 |
|------|------|--------------|------|
| `np.isin` (in1d) | 58% | 3666 | 移动决策/捕食/文化学习的逐个体循环 |
| `_step_population` Python 代码 | 18% | — | 引擎主循环 |
| numpy ufunc reduce | 10% | 21317 | np.max/min/any 等 |
| `_mean` | 10% | 2850 | 文化学习解读表均值 |
| `np.flatnonzero` | 5% | 3146 | 各类掩码筛选 |

**关键发现**：引擎默认 `use_sim_core=False`，之前的性能测试一直跑在纯 Python 路径。

#### 6.2 下沉的模块（sim_core/src/）

| 文件 | 功能 | 消除的热点 |
|------|------|-----------|
| `movement.rs` | 移动决策（g14） | np.isin + np.max/min + np.argmax + np.array + Python循环 |
| `predation.rs` | 捕食（g16） | np.isin + Python循环 |
| `culture.rs` | 文化学习（L5） | np.isin + numpy._mean + Python循环 |
| `l4_l5.rs` | 捕食+文化学习合并 | 共用一次 CSR 构建，消除重复开销 |
| `lib.rs` | PyO3 绑定层 | 长度/越界/形状校验 |

**已有 Rust 模块**（L6 之前）：
- `regrow.rs`：资源场再生
- `consume.rs`：批量进食结算
- `step_vectors.rs`：stage1（光合/代谢/维持）+ stage2（移动扣费/年龄/死亡/冷却/繁殖候选）

#### 6.3 关键技术

**CSR 格式 cell→个体列表**：
- 每 tick 构建一次：cell_counts → cell_indptr（前缀和）→ cell_indices
- 捕食和文化学习共用一次构建（l4_l5.rs 合并）
- 替代 `np.isin(flat, nb)`（O(N) 集合查找）→ O(邻格个体数) 直接索引

**统一邻居表 `_nb_table`**：
- 构造时一次性算好 (n_cells, nb_stride)，普通格 8 邻、极点格 cols 邻，未用位置填 -1
- 消除 `self.world.neighbors()` 的重复调用（flat_to_rc/clip/rc_to_flat）

**双路径 RNG 消费顺序一致**：
- 移动决策：预生成 `rand_choice`（得分无差异时随机选），按移动个体顺序
- 捕食：预生成 `rand_prey`（选猎物索引）+ `rand_success`（成功判定），按攻击者顺序
- Rust 和 Python 都用预生成数组（按索引访问），保证同 seed 同结果

**排序+去重对齐 np.isin**：
- Rust 收集邻格个体后 `sort_unstable() + dedup()`
- 与 Python `np.isin`（集合操作，返回按个体升序）结果顺序一致
- 极点格邻居列表有重复，去重保证猎物列表/成体列表无重复

**单邻居特殊情况**：
- `len(nb)==1` 时直接选，不消费随机数（与 Python 一致）

#### 6.4 性能结果

| 场景 | 优化前 (纯Python) | 优化后 (Rust下沉) | 提升 |
|------|-------------------|-------------------|------|
| N=5000, tick/s | 5.7 | **116.7** | **20.5×** |
| 60万 tick 耗时 | 29.2 小时 | **1.43 小时** | 在 2h 限制内 |
| N=500, tick/s | ~117 | ~200+（预估） | — |

**cProfile 验证**：下沉后 `np.isin` 调用从 3666 次/tick 降为 0（use_sim_core=True 路径），三大热点循环完全消除。

#### 6.5 对拍验证

三层对拍策略：
1. **函数级**：同一种群分别走 Python 参考实现和 Rust，assert 输出逐位相等（1ULP 容差）
2. **引擎级**：同 seed 两个引擎（use_sim_core 开关），逐 tick TickStats + 最终内部数组逐位比较
3. **全量 pytest**：98 通过（3 已知失败：植物化断言太严 + regrow 1ULP ×2）

## 三、实验数据汇总

## 四、当前瓶颈与后续优化方向

### 4.1 当前瓶颈（use_sim_core=True @ N=5000）

L6 下沉后，三大热点循环（移动/捕食/文化）已消除。剩余可能的瓶颈：

| 候选瓶颈 | 占比（预估） | 说明 |
|----------|-------------|------|
| 信号发射（步骤4.5） | ~5% | 仍有 Python 循环（遍历发射个体写信号场） |
| 繁殖（步骤8） | ~5% | 遍历繁殖候选，生成子代基因（含突变噪声） |
| 愉悦度更新（步骤8.5） | ~3% | 向量化但 _expectation (N,120) 数组较大 |
| NumPy 数组拼接/压缩 | ~5% | 每 tick 的 concatenate/delete（繁殖/死亡后） |
| Python 引擎主循环 | ~10% | _step_population 的 Python 代码本身 |
| Rust 函数调用开销 | ~3% | PyO3 边界转换（数组切片/校验） |

### 4.2 后续优化方向（按收益排序）

**L7a：信号发射 + 愉悦度更新下沉**
- 信号发射：批量写入信号场，消除 Python 循环
- 愉悦度：120 情境编码 + RPE 计算，可向量化或下沉
- 预计收益：+10~15%

**L7b：繁殖下沉**
- 子代基因生成（遗传+突变）是逐个体操作，Rust 循环更快
- 需处理 RNG 消费顺序（突变噪声用预生成数组）
- 预计收益：+5~10%

**L7c：数组拼接优化**
- 繁殖/死亡后用 `np.concatenate` / `np.delete` 重建数组，每 tick 多次
- 改用预分配大数组 + 有效长度标记（slots 模式），避免频繁分配
- 预计收益：+5~10%，且降低 GC 压力

**L7d：多线程并行（Rayon）**
- 移动决策/捕食可并行（个体间无依赖，除了能量更新的竞态）
- 需处理 RNG 顺序（每个线程独立 rng 或预生成全部随机数）
- 预计收益：+50~100%（多核），但实现复杂度高

**L7e：patchy 模式 Rust regrow 支持**
- 当前 patchy 模式 regrow 回退 Python（~3% 耗时）
- Rust 侧加 patch_mask/空间倍率支持
- 预计收益：+3%

### 4.3 硬件升级建议

项目纯 CPU 单线程，GPU 完全用不上，16G 内存绰绰有余：
- **云租赁**：阿里云/腾讯云高主频计算型 4核8G，按需 ~0.8 元/h，单次 60 万 tick 实验 <1.5 元
- **本地 i7-12700H**：单核性能与云环境相当，预计 100~130 tick/s @ N=5000
- 升级硬件最多 +50%，而 Rust 下沉已带来 20× 提升

## 六、语言涌现机制总结

### 6.1 已实现的语言涌现要素

| 要素 | 实现 | 层级 |
|------|------|------|
| 空间异质化 | 斑块资源（食物分布不均） | L1 |
| 信号载体 | 田字格 16 模式信号场（50 tick 衰减） | L2 |
| 内在动机 | 愉悦度 RPE 系统（超越食物/繁衍的第三驱动力） | L2 |
| 感知能力 | g14 感知基因（移动决策综合食物+信号+群居+记忆+解读） | L3 |
| 信号发射 | g15 信号基因（状态哈希→16 模式，耗能 0.1） | L3 |
| 种间竞争 | 捕食 g16（选择压力） | L4 |
| 生态位分化 | 植物化 g19（生产者 vs 消费者） | L4 |
| 防欺骗机制 | 信任学习（真信号+ / 假信号-，信号权重×trust） | L5 |
| 时空记忆 | 工作记忆 4 槽（有限记忆→信息压缩→符号化） | L5 |
| 文化传递 | 解读表 (N,16) 幼体向成体 EWMA 学习（Kirby 迭代学习） | L5 |

### 6.2 语言涌现的核心机制

文化传递（L5）是语言涌现的核心：
1. 每个个体有 16 维解读表（每个信号模式对应"移向/逃避"的值）
2. 幼体向邻格成体学习（EWMA 收敛 α=0.1）——代际传递
3. 繁殖继承 + 噪声——变异来源
4. 信任学习过滤假信号——选择压力
5. 有限工作记忆 4 槽——学习瓶颈（Kirby 模型的关键：学习瓶颈→可压缩性→组合性）

**预期涌现路径**：随机信号 → 偶然有用的信号被信任 → 文化传递固化 → 解读表趋同（共享信号系统）→ 组合性（信号模式组合表达更复杂含义）→ 语法（结构化组合规则）

### 6.3 当前观察到的现象

- g15 信号基因在高密度下有利（0.765 @ N=5000）
- trust 信任度在种群爆发后崩溃（0.906→0.005）——假信号泛滥
- cult_div 文化多样性低（0.035）——解读表趋同，可能是共享信号系统的早期阶段
- 需要更长时间（60 万 tick 以上）和多 seed 重复实验来验证语言涌现
