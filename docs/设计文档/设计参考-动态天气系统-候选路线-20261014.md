## 一、现状（代码事实，评估前先对齐）

1. **环境场是构造期一次性静态场**，不进快照、每 tick 零成本（从 config 确定性重建）：`world/env_field.py:9-19` 头注释、构造体 `env_field.py:137-287`。
   链路：H 地形 → T 温度 → q 饱和水汽 → Pr 降水 / Et 蒸散 → A 汇流 → W 水分 → f_g/f_c 因子 → 斑块容量与再生。
2. **降水 / 蒸散是"气候态"，不是天气事件**：`Pr = q×(1+orographic×H)`、`Et = et_frac×q`、净产水 `max(Pr−Et,0)`（`env_field.py:178-180`）。每格有一个恒定产水率，没有"今天下雨、明天晴"。
3. **温度有昼夜与季节，但水分场不吃**：`temperature = 基温 + 昼夜`（`light_and_temperature.py:400`）；季节由 `tilt_rad` 黄赤交角 + `season_period` 驱动，太阳赤纬 `δ(t)=tilt_rad·sin(2πt/period)`（`simulation/config.py:43-48`）。这套 δ(t) 目前**只驱动光照 illumination 与实时温度**；`env_field` 的水分场 W 完全不随 tick 变。
4. **全仓库 grep 无任何动态天气**：weather / rainfall / cloud / wind / storm / monsoon 均无实现（`world/`、`simulation/` 下零命中）。
5. **地形静态、不侵蚀、海拔非物理**：H 归一化到 [0,1]，`lapse_c=20` 是"全程温差"现象学常数（`config.py:1499`），H 没有真实海拔单位，也没用真实递减率。
6. **极点是唯一出水口**（priority-flood），低洼连成"极海"，probe 实测被抬升格约 50.8%（`env_field.py:41-46`）。

## 二、现状缺口（"要改变的现状"是什么）

1. **无时间维度**：降水 / 水分恒定，没有雨季旱季、好年成坏年成；生物不承受非生物的时间波动。
2. **无大气环流，缺副热带沙漠**：只靠 Magnus 会得出"越暖越湿"，纬向降水是赤道单峰、单调向两极递减。真实世界约 20–30° 有副热带高压沙漠（撒哈拉、阿拉伯、澳洲内陆），当前模型复现不出（本次 seed42 实测地图的降水 / 容量子图证实，赤道对称、单调变干）。
3. **海拔非物理**：`lapse_c=20` 是无量纲常数，没有真实海拔尺度与递减率。
4. **地形不侵蚀 + 极海**：静态未侵蚀噪声 + 极点出水口，缺真实河流塑造，且约一半格被抬升成极海。

## 三、硬约束（任何候选都不得破坏）

1. **默认关 + 逐位等价**：新机制默认关（`enabled=False` 或对应 sensitivity=0），关档与现状逐位等价（C7 回滚点）；现有 `EnvFieldConfig` 已立此规矩（`config.py:1471-1473`）。
2. **守恒**：f_g/f_c 按面积权均值 = 1 归一，Σ容量逐位守恒、Σ名义再生零阶守恒（`env_field.py:26-28, 291-302`）。任何动态波动**只能在空间 / 时间上再分配，不能凭空造水**；动态方案必须给长期（一个完整周期）守恒不变量与测试。
3. **RNG 纪律**：随机天气用独立流 `default_rng([seed,salt,常数])`，不消费引擎 `self.rng`（同噪声流先例 `env_field.py:154`）。
4. **快照与可重建**：静态场不进快照。**一旦引入随时间变化的水分场，动态状态必须进快照、或能从 config + 已消费的独立 RNG 流确定性重建**——这是新架构点，须显式设计。
5. **双路径对拍**：env_field 目前只在 Python 路径（`enabled ∧ use_sim_core` 直接报错，`sphere_engine.py:840-842`）；动态天气同样先落 Python，禁止静默 no-op。
6. **可证伪**：每个候选都要预注册"它应当产生什么可观测现象"，配零模型对照；未过 L0–L4 判据不写"涌现"。
7. **性能预算**：s2 为 480×960 = 460,800 格；当前构造期汇流约 0.3s、每 tick 零成本。动态方案必须给单 tick 成本，不得让每 tick 退化为全网格 O(n) 重算气候。
8. 数据 / 一次性脚本不入主仓；提交用明确 pathspec（禁 `git add .`）。

## 四、候选路线（由简到繁 C0–C4）

### C0｜海拔尺度物理化（顺带小修，低成本）

- 做什么：给 H 一个真实海拔尺度（如 `max_elevation_m` 4000–6000 m），把 `lapse_c=20` 换成真实递减率 Γ≈6.5 ℃/km（湿绝热；干绝热约 9.8）：`T = base_t − Γ×elevation_km`。
- 物理：环境递减率约 6.5 ℃/km。
- 改动：`env_field.py:175` 温度公式 + `EnvFieldConfig` 增 `max_elevation_m` / `lapse_per_km`（保留 legacy=现行以逐位等价）。
- 牵出的前置问题：海拔 0 应是海平面，须先理清与"极海填充面"（`env_field.py:41-46`）的关系。
- 影响：纯静态，不碰守恒 / 快照 / 性能；开关保逐位等价。
- 价值：垂直温度分层更物理，但**不改变大格局**（不解决沙漠、不引入天气）。属"顺手校准"。
- 风险：低。

### C0b｜真实海拔 + 海平面 → 海洋 / 湖泊（构造期静态，零 tick 成本，是 C4a 的水汽源前置）★ owner 2026-10-14 提

- **owner 想法**：有了地形，再给真实高度，应该能**自发涌现海洋和湖泊**。
- 结论：可行，且**一半机制已存在**（priority-flood 填洼本就在做"水往低处流、填满洼地"，`env_field.py:198-237`）。
- 做什么：
  1. 把 H 映射为真实海拔（承接 C0 的 `max_elevation_m`），定一个**海平面 sea_level = 0 m**；
  2. **海洋**：海拔 < 海平面的格 = 永久水域（球面无边界，低于 0 m 自然成海，不再需要"极点当唯一出水口"这个假设）；
  3. **湖泊**：内流闭流盆地（填洼后有水面但无溢流口、或水面低于溢流口）= 湖；
  4. 河流沿用现有 D8 汇流（`receivers`/`acc`/`river_mask`），注入湖或海。
- **"涌现"的两层要说清**：
  - 海陆分布 / 湖泊位置 = 地形 + 海平面规则的**构造期确定结果**（不是每 tick 动态，但合理——地形决定哪里存水）；
  - 真正动态的现象（湖水位随旱雨季涨落、内流湖强烈蒸发变咸水湖、河流改道 / 三角洲、海冰进退）要等 **C4a 水循环闭合后才涌现**。
- **关键协同：海洋是水汽源（重要）**。当前模型"每格自己产水、桶永远满"，没有"水从哪来"。有了海洋 + C4a 的风，才构成真实闭环：**海洋蒸发 → 风搬运水汽 → 陆地抬升 / 辐合凝结降水 → 河流入海**；由此涌现"沿海湿润 / 内陆干旱、季风、迎风坡雨影"。**因此 C0b 应在 C4a 之前或同期，是 C4a 的前置（提供水汽源、地形基准、汇流终点）。**
- 必须处理的失真：seed42 现状 `flood_filled = 234021/460800 ≈ 50.8%` 格被抬升（`env_field.py:41-46`）——因为没有海平面、且把极点当出水口，低洼连成"极海"。引入海平面后要重设填洼基准（填到 0 m 而非极点），并调地形生成的海拔分布使陆/海比例合理（可能需给陆地抬升偏移，避免球面大部分被淹）。
- 影响：纯静态、构造期一次、零 tick 成本、不进快照（config 可重建）；新增"海 / 湖 / 河"标识层。**需先解决与 `env_field ∧ resource_dynamics` fail-loud 同口径的对拍**（水域产能 / 容量如何定义）。
- 风险：中低（主要是地形分布标定与极海假设的替换）；属"静态就能落地、立刻丰富世界"的一档，与 C1 同期性价比高。

### C1｜气候态加 Hadley 环流（静态，解决副热带沙漠）★ 高性价比

- 做什么：仍是静态气候态，但在净产水 / 降水上叠加一个**纬度环流函数**，模拟 Hadley 胞——赤道上升支（多雨 ITCZ，约 ±20°）与 20–35° 下沉支（干旱副热带高压）。使纬向降水从"赤道单峰"变为"赤道雨林峰 + 副热带低谷 + 温带次峰 + 极地"的真实多带。
- 物理：赤道空气上升凝雨、在副热带下沉绝热增温抑制对流 → 世界主要沙漠（撒哈拉 / 阿拉伯 / 澳洲）。理论参照 **Held-Hou 1980** 简化 Hadley 模型（轴对称、角动量守恒、辐射冷却与下沉支平衡）。
- 实现思路（待评估，非定论）：
  - 最简：给 Pr 或 net 乘一个只关于纬度的环流调制 g_circ(lat)，由少量物理参数定（ITCZ 半宽、下沉支纬度、下沉强度），并按面积权均值归一以保守恒。
  - 进阶：用 1D 能量平衡模型（EBM / 湿静能 moist-EBM）自洽求纬向降水，而非手调函数。
- 改动：`env_field.py:178-180` 附近，新增 circ 调制 + `EnvFieldConfig` 开关与参数；纯静态、构造期一次。
- 影响：不碰时间 / 快照 / 性能；归一化保守恒；开关保逐位等价。
- 可检验（预注册）：纬向降水 / 产能在 20–30° 出现显著低谷（沙漠带）；u 与 |lat| 由单峰变多带；容量场出现副热带低产能带。
- 价值：**以最小架构代价立刻补上真实世界最大的空间失真之一**，把世界从"单调一条带"变成"雨林–沙漠–温带–极地"多带，空间异质性大增。
- 风险：中低。关键是别再写成"手调函数写死结果"——倾向用可推导的物理参数（Held-Hou / EBM），并保留"无环流"对照。

### C2｜雨带季节移动（ITCZ 季节摆动，时间维度第一步）

- 做什么：让降水 / 水分的纬度中心随太阳赤纬 δ(t) 南北移动（ITCZ 摆动、季风、雨季旱季）。**复用已有但目前只驱动光照的 δ(t)**（`config.py:43-48`）。
- 物理：ITCZ 随太阳直射点季节南北移动（北半球夏季偏北、南半球夏季偏南）。
- 实现思路：构造期预计算 N 个季节相位的水分场（如 12 份，类似 light_and_temperature 的相位缓存），按 tick 插值；f_g/f_c 变成时间函数，`resource_field.py:616-618` 每 tick 取当季因子。
- 影响：**引入时间依赖**；若相位完全可由 tick 确定性重建则不新增状态；每 tick 成本≈索引 / 插值（可接受）；一个完整季节周期的面积权均值仍 = 1（周期守恒）。
- 前置硬问题：`env_field ∧ resource_dynamics.enabled` 现在直接 fail-loud（`config.py:1479-1480`，动态因子与容量重算未对拍），必须先解。
- 可检验：食物丰度带随季节南北迁移；旱 / 雨季产能周期。
- 价值：让环境"动起来"，是迁徙、储藏、季节繁殖等行为的驱动源；与已有光照季节对称。
- 风险：中。

### C3｜随机天气事件（马尔可夫 / 泊松，时间波动·旱涝）

- 做什么：在区域尺度加天气状态机（晴 / 云 / 雨，或连续降水异常），事件概率由本地气候态（C1 的 Pr）调制；产生围绕气候态的**零均值**波动（旱年 / 涝年、持续干旱、连阴雨）。
- 物理：天气 = 气候上的短期随机扰动。可用泊松降雨事件 + 指数衰减土壤水，或区域马尔可夫链（生态 / 水文模型常用）。
- 实现要点：降水 = 气候态 ×（1 + 天气噪声）；噪声在**区域尺度相关**（天气系统不是逐格独立白噪声）、零均值、有自相关（持续期）。
- 影响：**真正的动态状态**，必须进快照或 RNG 可重放；严格长期零均值（否则漂移破坏守恒）；区域聚合计时，控制单 tick 成本。
- 可检验：产能时间序列出现自相关波动；极端旱涝频率；生物丰度 / 行为对非生物波动的响应。
- 价值：施加非生物时间压力（环境波动是 r/K 选择、风险对冲 bet-hedging、储藏、迁徙的重要驱动），**演化意义最大的时间机制**。
- 风险：中高。零均值守恒、动态状态快照、空间相关尺度、与容量重算对拍都是硬活。

### C4｜空间天气（云 / 水汽输运 / 地形降水动态）

- 做什么：云团 / 水汽沿盛行风在球面上平流，遇地形抬升凝结（动态迎风坡 / 雨影区），蒸发–输运–降水闭合。
- 参照：轻量程序化做法（Oasea 的云 / 风暴 / 蒸发，Gleba 按地形算年降雨统计的全球气候模型），**不是**完整 GCM。
- 影响：高。每 tick 全网格平流 / 凝结，O(n) 动态计算；性能、快照、守恒需重设计；风场可能要从 C1 环流导出。
- 价值：最像真实天气，能动态产生雨影与局地气候；但对当前"无生物纯斑块世界"阶段性价比最低。
- 风险：高。原建议本期不做；但 owner 2026-10-14 已明确终局意图（见下方 **C4a**，C4 是其目标形态），改为分阶段长期方向，不一步到位。

### C4a｜涌现式大气环流（owner 2026-10-14 直提：加风、水由天气运输、底层规则"冷空气更重"）★ 终局方向

- **owner 原话意图**：后续加天气系统，**水要由天气运输**；要**加风**，天气由风带动；底层只写一条规则——**冷空气更重（热空气更轻）**。即不写死环流 / 风向 / 雨带，而是落"温差→密度差→压力→风"的底层规则，让风、水汽运输、降水**自组织涌现**。这与本项目"只落底层规则、现象自组织"的哲学一致，是动态天气的**终局形态**。
- **物理依据（已联网核实，非凭空）**：大气科学的**单胞模型（single-cell model）**证明——在"地表均匀、太阳直射赤道、**暂不考虑地球自转（无科里奥利力）**"下，只需**压力梯度力**，就会涌现"赤道暖空气上升、高空向极、冷却下沉、近地面回流"的巨大热力直接对流环（即 Hadley 环流）。这说明环流**不需要写死**：加热不均（纬度→温度，已有）+ 冷空气重（下沉）/ 暖空气轻（上升）+ 压力梯度 → 风与环流自发形成。
- **"一条规则"实际是"一小组守恒规则"（每条都是底层物理，不写死结果）**：
  1. **温度→密度/气压**：冷空气密度大 → 气压高（"冷空气更重"的落点；热空气低压）。
  2. **压力梯度力**：空气从高压（冷、重）流向低压（暖、轻）= 风；强度由压力差决定。
  3. **质量守恒（连续性）**：空气总量守恒，流入 = 流出（否则气压发散 / 出负值）。
  4. **垂直运动（2D 球面无垂直维，是关键难点）**：用"水平辐合 = 上升、辐散 = 下沉"近似，或显式加一层垂直速度；暖空气上升（赤道）、冷却下沉（副热带）。
  5. **水汽是风携带的标量**：地面蒸发向大气供水（**受地面水量约束——无水可蒸发则蒸发为 0，治当前"越暖越湿"失真**）；水汽随风格式平流（advection）。
  6. **凝结降水**：空气上升冷却或遇地形抬升、达到饱和（Magnus q）就凝结 → 降水落回地面（部分进土壤 / 汇流），闭合水循环。
  7. 全程满足**大气质量守恒 + 水量守恒**。
- **预期涌现（不写死、用于事后判据）**：赤道暖湿空气上升凝结→赤道雨带 ITCZ；高空空气向极冷却、副热带下沉（干、晴）→**副热带沙漠自然涌现**；近地面风回流（信风）；水汽从蒸发区被搬运到凝结区（水由天气运输）；迎风坡多雨、背风坡雨影。后续若加科里奥利力（地球自转）再涌现三胞环流（Hadley/Ferrel/Polar）、西风带、季风与季节摆动。
- **分阶段（每阶段独立可验证，降风险）**：
  - **C4a-0 = C1 静态环流**：先让副热带沙漠这个"结果"存在（低成本、纯静态），作为涌现版的**对照基准与回归锚**。
  - **C4a-1 气压 + 风（不带水）**：仅加温度→气压→压力梯度风场，验证"温差能否涌现赤道辐合 / 副热带辐散的环流结构"（零模型：均匀温度下应无定常风）。
  - **C4a-2 水汽平流 + 蒸发**：蒸发受地面水量约束，验证水汽被风从蒸发区搬运。
  - **C4a-3 凝结降水**：上升 / 抬升饱和凝结，闭合水循环，验证雨带、沙漠、雨影**涌现**。
  - **C4a-4（可选）科里奥利力 + 季节**：地球自转 → 三胞环流 / 西风带；δ(t) 季节 → 雨带摆动 / 季风。
- **必须评估的技术难点**：
  1. 2D 球面的垂直运动表达（散度近似 vs 显式垂直层）；
  2. 数值方法选型：浅水方程 / 格子流体（CA fluid / stable fluids）/ 格子玻尔兹曼（lattice-Boltzmann）/ 简单压力平流，在守恒性、数值稳定性（不产生负气压、不发散）、460k 格性能间权衡；
  3. 时间尺度：大气变化快，可能需要"大气子步"与生物 tick 解耦（多子步）；
  4. 动态场进快照 / 确定性可重建；大气质量与水量守恒的不变量与测试；
  5. 科里奥利力可先关（单胞模型不需要），作为默认关的后续档。
- 与 C1 的关系：**不矛盾、不替代**。C1 是"把结果写对"的静态近似（立刻、低成本、给当前纯斑块世界用，且作为 C4a 的对照基准）；C4a 是"让过程涌现"的动态终局（自组织、最符合项目哲学）。C4a 成功后，C1 的写死函数可撤回（保留为回归对照）。

### 不做｜完整通用环流模型 GCM

- 解大气 / 海洋流体力学、辐射、云微物理（CESM、MIROC，或专门的 GCM 游戏如 Glorgorian），超百万行、超算规模、目标不是演化涌现。**明确排除。**

## 五、关键架构决策（轻舟评估时必须逐条回答）

1. **静态还是动态**：C0/C1 静态（构造期、不进快照、零 tick 成本）；C2 争取"相位缓存 + 确定性重建"不增状态；C3/C4 引入真动态，必须解决快照 / 可重放。
2. **动态守恒**：时间波动长期零均值、空间再分配；给出守恒不变量定义与测试（类比现有 `conservation_check`）。
3. **与 resource_dynamics 的未验证组合**：`env_field ∧ resource_dynamics.enabled` 现在直接报错（`config.py:1479-1480`），任何动态水分都要先设计并对拍容量重算路径。
4. **性能预算（2026-10-14 话事人已实测 s2，沙箱 `/opt/python3.12`，numpy 向量化）**：
   - 静态构造（含噪声 / 填洼 / 汇流整套 env_field）：约 **2.1 s，仅启动一次、零 tick 成本**。
   - 当前纯斑块世界单 tick 参照：约 **28 ms**（C 批 57s/2000tick）。
   - **全分辨率 480×960 = 460,800 格**：单个 numpy 大气子步（气压→8 邻居梯度→风→水汽平流→凝结）约 **116 ms**，每 tick 3 个 CFL 子步约 **349 ms**——是当前 tick 的 12 倍，**不可接受**。
   - **粗网格（天气本就是大尺度，可与生物细网格解耦）**：2× 粗（240×480=115k 格）单子步 19 ms；**4× 粗（120×240=28.8k 格）单子步 4.2 ms**。
   - **粗网格 + 时间解耦（大气每 10 tick 推进一次、每次 3 子步）均摊**：4× 粗网格约 **1.4 ms/tick（≈ +5%）**、2× 粗约 5.7 ms/tick（≈ +20%）；全分辨率则 +122%。
   - 内存：新增气压 / 风 / 水汽 / 雨 4 个 float64 场，全分辨率约 **15 MB**（粗网格更少），非瓶颈。
   - **结论与约束**：动态大气必须走"**粗网格 + 大气时间步与生物 tick 解耦（多子步、低频率）**"，且流体规则计算最适合下沉到 **Rust sim_core**（可再快数倍，且避免 numpy 大数组临时分配）；Python 路径先对拍验证。目标：动态天气增量控制在每 tick 个位数百分比。
5. **独立 RNG 与 fingerprint**：新随机流进指纹（跨档续跑被拦），commit / manifest 写明"指纹变、行为不变"。
6. **极海 / 海平面 / 海陆（C0b）**：C0 与 C0b 牵出"elevation 0 = 海平面"，替换现有"极点当唯一出水口"的极海填充（`env_field.py:41-46`，seed42 50.8% 格被填）；须定义海 / 湖 / 河标识层与对应产能 / 容量口径，并使海洋成为 C4a 蒸发水汽源（闭环：海洋蒸发→风输运→陆地降水→河流入海）。

## 七、青梧倾向（供参考；轻舟可凭联网证据推翻）

- **首选 C1（静态 Hadley 副热带）**：不引入时间维度、不动快照 / 守恒 / 性能、可逐位等价，却能补上真实世界最大的空间失真（副热带沙漠），让世界立即多带化、空间异质性大增——"改变现状"性价比最高。
- **同期做 C0 + C0b（真实海拔 + 海平面海陆 / 湖泊）**：C0 是物理校准；C0b 构造期零 tick 成本就能让海 / 湖 / 河涌现，并**为 C4a 提供海洋蒸发水汽源**（水从哪来），应排在 C4a 之前或同期。
- **性能已实测、可控（见第五节第4条）**：静态 0 成本；动态全分辨率硬跑会慢约 12 倍，**必须走"天气粗网格（约 4×）+ 大气时间步与生物 tick 解耦（每 10 tick、3 子步）+ 必要时 Rust 下沉"**，实测均摊仅约 +5%/tick、内存约 15 MB。性能不是否决项，是架构约束。
- **时间维度 C2 先于 C3**：C2 复用现成 δ(t)、相位可确定性重建、不增状态、风险更低；C3 演化价值大但快照 / 守恒 / 对拍是硬活，等生物层启动前后再做更有意义。
- **终局 = C4a 涌现式大气环流（owner 2026-10-14 直提）**："冷空气更重→压力梯度→风→水汽运输→凝结降水"这条底层规则链最符合项目哲学，能让风、副热带沙漠、雨影、水汽输送**自组织涌现**，且物理上由单胞模型背书。但它是动态流体系统，**不一步到位**：先做 C0b/C1 静态把海陆与沙漠结果做出来当对照锚与水汽源，再按 C4a-1→4（先气压风、再水汽、再凝结、最后自转/季节）分阶段验证。
- **完整 GCM 不做**（解流体力学的超算级气候模型，目标不同）。
- 无论选哪条：**先出实施设计 + 预注册（含零模型对照），按"加新机制标准流程"走，不得直接写码。**
