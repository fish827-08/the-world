# 多位编码 v0 设计稿（零机时）—— 「让位置可被传」到底差什么

> **触发**：R126 §四 队列第 5 项 / R128 §三 预注册口径的直接推论（「消除冗余 ≠ 产生可行动信息；**要传位置需多位编码**」）
> **输入**：fish 2026-09-19 14:3x 的机制构想（记忆容量基因化 / 长短期分层 / 感知 9×9 / 一信号多格）
> **状态**：🟡 **设计稿，未实施**；跑批需令（R117/R118）。**本稿不碰引擎代码。**
> **基线**：`the-world/main` = `061ff71`+（09-19 14:3x）

---

## 〇、一句话

**带宽早就够，缺的是"结构"。** 接收者每 tick 已经能读 4–8 个格上的符号（空间位宽）+ 50 tick 的标记寿命（时间位宽），
但它的解读表是「**码 → 一个标量**」（`_interpret` 形状 `(n,16)`）——**对"码出现在哪个方位"完全不敏感**。
⇒ 在这种结构下，**把码位从 4 位扩到 16 位也不会有任何区别**：接收者只能把它读成"附近有东西／强度多大"。
所以 v0 的第一刀**不是加码位，而是给解读表加"方位"这一维**。

## 一、fish 构想的四条 × 代码事实（逐条核过）

| # | 构想 | 现状（`[代码]` 出处） | 判定 |
|---|---|---|---|
| ① | **记忆容量由基因决定**（上限 32） | `_work_memory = np.full((n, 4), -1)`（`sphere_engine.py:414`）；`_mem_ptr` 轮转 4 槽（`:902`）；预留位 g17/g18/g20/g21/g22/g23（`genes.py:55-61`）**够用** | ✅ **可行、便宜**，但有三个坑（见 §三 A′） |
| ② | **长/短期记忆分层**（长期 = 短期的 1/4，短期 = FIFO） | 🔵 **短期记忆已经是 FIFO**：4 槽 round-robin，最新覆盖最旧（`:902-903`）。「长期」= 再叠一个**不轮转**的数组 | 🟡 **可做，但建议后置**：同一机制上叠第二层，违反"每档只测一个变量"的项目纪律 |
| ③ | **感知半径 4 格 ⇒ 9×9 去角** | 🔴 **与实现不符**：`perception_radius ∈ {4, 8}` 的语义是**邻居个数**（4 = 十字＝冯诺依曼，8 = 九宫＝摩尔），**感知范围 = 1 格**，不是 4 格距离（`config.py:316` 硬断言只允许 4/8；`sphere_engine.py:285` 同） | ⚠️ **不是"改个数字"**：扩到 4 格距离 = **重定义 C1（信息不对称）**⇒ 必须纪元声明 + 同批对照 |
| ④ | **一次信号传多格**（32 位 = 8 格 × 4 位） | 发射 = **每人每 tick 写 1 个码到**「**自己所在的格**」（`self.signals.write_many(e_flat, patterns)`，`:975`）；接收者读 `nb`（4/8 格）上的码（`:1128`）；标记**寿命 50 tick**（`SignalField(..., duration=50)`，`:370`） | 🟡 **半对**：「多格」已存在，但**多格是"多个发射者各写各的格"**，不是"一个发射者写多个格"；「32 位」= 8 邻居 × 4 bit 是**接收者可读符号数**，不是"一个信号的内容" |

**两处概念澄清（都影响设计）**：

1. **"感知 8 格的信息" ≠ "读 8 格的符号"**。生物**已经**能直读邻居格的**连续量**环境状态（`food_ratio` / `densities` / `sig_present`，`sphere_engine.py:1019-1032`）——那不受位宽限制，不需要"多位编码"。
   需要编码的只有**符号**（`_marks`，4 bit/格）。⇒ "多位"**不需要扩容感知**。
2. **32 槽 ≠ 8 位二进制**：32 个槽位需要 **5 bit** 索引（8 位二进制可表示 0–255）。基因是连续值 ⇒ 容量只能取离散档（2 bit 给 4 档：4/8/16/32），这一点不影响结论，只影响写法。

## 二、🔴 结构诊断（本稿核心；`[代码]` 逐行核过）

| 环节 | 代码事实 | 后果 |
|---|---|---|
| 解读表形状 | `self._interpret = rng.normal(0, 0.3, size=(n, 16))`（`:429`） | 每个体一张 **「码(16) → 标量」** 表 |
| Python 决策消费 | `interp = [self._interpret[idx, int(s)] ...]`；`score = score + 0.4 * perc * interp`（`:1128-1135`） | 码出现在**哪个邻居格**，贡献**完全相同** ⇒ **方位信息被抹掉** |
| 学习信号 | 移动到有信号的格后：`self._interpret[idx, m] += lr * (1.0 - ...)`（`:1064/:1234`） | 强化是**全局**的（该码 +1 / −1），与方位无关 ⇒ **学不出"方向含义"** |
| Rust 路径 | `step_movement(..., self._interpret[:P], ..., signal_marks, self._nb_table...)`（`:1030`） | 同一契约（`_interpret` 是 (n,16) 展平） ⇒ 改结构须**双路径同步 + 逐位对拍**（F-D2/A2 约束） |

**结论**：`_interpret` 的「码 → 标量」形态是**结构性天花板**。E-021 测到的 `Δ_content/Δ_full ≈ 0.23`
（码义只占信号作用的约 1/5，大头是"有信标"）与这条诊断**同向**：接收者拿不到可分辨的**指向**，只能把符号当"这里有东西"的强度提示。

## 三、建议路线（分档，每档只回答一个问题）

### A′ 档（**建议先做**，零新通道）：记忆的**行为价值**先立起来

- **问题**：*个体自己记住的富食格，有没有行为价值？*
- **现状（结构性掐死）**：决策只在**记忆格落在 `nb` 内**（即 1 格邻域）时加 `0.3 × perc`（`:1124-1126`）
  ⇒ 记忆格在 nb 内 = 它**本来就能直读** ⇒ 这个加成**按构造就是冗余奖励**，几乎不可产出行为差异。
- **改法**：把 `mem_in_nb`（是不是邻居）换成**朝向梯度**——按记忆格相对当前格的方位，给 `nb` 中**对应方向**的候选格加分（`cos` 相似度或 4 方位量化）。
  ⇒ 记忆**不在** nb 内时也有用 ⇒ 第一次让"记住"具备**非冗余**的行为含义。
- **成本**：1 处决策式 + Rust 同步 + 极性测试。**零新通道、零纪元声明争议**（不涉 C1/C3 前提）。
- **为什么先做**：连"**自己**记住的位置都不改变行为"时，"把位置**传给别人**"必然更弱——先花最小代价把前提钉死。

### A 档（枢纽）：给解读表加**方位**维度

- **改法**：`_interpret` 由 `(n, 16)` → **`(n, 16, nb_stride)`**：同一个码出现在第 `j` 个邻居格 ⇒ 对 `score[j]` 的贡献 `W[i, c, j]`。
  码本身**不用改**（仍是 4/8/16 档）⇒ **"方向"由此可被表达**，而语义仍**完全由学习/遗传决定**（初始随机、可遗传、可漂移——任意性保持）。
- **口径**：初始 `W` 对 `j` 取同值 ⇒ **与现档逐位等价**（保证回归可对拍；这就是本档的"开关=旧行为"回退路径）。
- **风险**：参数量 ×(nb_stride)；学习样本稀疏 ⇒ 需**功效核算**；双路径同步。
- **预注册口径**：对照 = 现档（`W` 方位无差）同批同 seed；主指标 = 门控确认口径的 ρ（继承 Q1v2 §四）；三态（可判定性）沿用 Q1v2。

### B 档（真正的"多位"）：位置内容进码

- **改法（最小版本）**：4 bit 切分为 `[方向 2 bit（4 方位）| 距离 1 bit（近/远）| 保留 1 bit]`
  ⚠️ **但"切分"只是设计上的**——生物不知道哪 2 位是方向；它只有"码 → 效果"的学习通道
  ⇒ **实际能否用起来，取决于 A 档是否已让方位可被表达**（这就是为什么 A 档在前）。
- **必须同时满足的前提**（缺一即预期 null）：
  1. **记忆有行为价值**（A′ 档）；
  2. **发送者获益通道 C3**（现状：发送者**无回报**，`_last_sender` 被 `_oracle_on` 门控且未接入决策）
     ⇒ 若发送者没理由发真话，码位再多也只是**噪声位宽**；
  3. **接收者的注意力/学习瓶颈**（C2）：不设瓶颈时它可直接扫 4–8 格，符号的边际价值仍低；
  4. **世界信息值钱**（C8：`lat_r2 ≤ 0.9`；patchy 已满足 0.317）。
- **位置必须用"相对量"**：记忆里存**绝对 flat 坐标**（实现便利，`:414`），但**信号/决策只允许用相对方位 + 距离桶**
  —— 绝对坐标是**设计者参照系**，生物拿不到、也不该拿到（fish 的直觉正确，代码层面也支持：相对量不需要新增任何全局参照）。

### C 档（fish 的 ① ② ③）：容量 / 分层 / 大感知

| 项 | 建议 | 理由 |
|---|---|---|
| 记忆容量基因化（①） | 🟡 **可做，排 A′ 之后** | 便宜（预留位够），但：**(a) 快照不兼容**（`work_memory` 从 (P,4) → (P,K) ⇒ `SNAPSHOT_VERSION` 升级 + 旧档回退）；**(b) 继承语义**（子代**整数组继承**，`:1534/:1549` ⇒ 容量不同需截断/补 `-1`）；**(c) 基因×适合度在饱和区制下必假阴性**（教训 13：饱和时繁殖=抽签）⇒ 必须**先分层区制**再判 |
| 长/短期分层（②） | 🟡 **建议后置到 A′/A/B 之后** | 现有 4 槽**已是 FIFO**；分层 = 在同一机制上叠第二层 ⇒ 违反"每档一个变量"。🔵 一个**代码级支持点**：`_capacity` 空间固定 ⇒ **富食格位置长期有效** ⇒ "长期记忆"在语义上说得通（不是空中楼阁），但仍是**第二变量** |
| 感知扩到 9×9（③） | 🔴 **不建议现在做** | ① 与现实现语义不符（是"邻居个数"不是"距离"）；② 硬断言只允许 4/8，改动会碰 C1 定义；③ 它**降低**区域内信息不对称（直读变多）⇒ 与"让信号有价值"**方向相反** |

## 四、对 fish 四条构想的**结论表**（先结论）

| 构想 | 我的判断 | 一句话理由 |
|---|---|---|
| 记忆容量由基因决定（≤32） | ✅ **对，但要后置** | 便宜且语义自洽；坑在快照/继承/饱和区制下的假阴性 |
| 长期 + 短期分层 | 🟡 **可做，不必现在做** | 短期 FIFO 已存在；先解决"记忆有没有用"，再谈分几层 |
| 感知 4 格 = 9×9 去角 | ⚠️ **与代码不符** | 4/8 是邻居**个数**；扩距离=重定义 C1，且方向与目标相反 |
| 一信号传多格（多位） | ✅ **对，但真正的瓶颈不是位宽** | 位宽（4–8 符号/格·tick + 50 tick 寿命）已存在；缺的是**方位维度** |
| "方向是几由它们自己发现" | ✅ **完全正确，且必须这样** | 设计只提供**可能性**（方位可表达、码可组合），语义留白 = 项目"任意性"原则（构念纪律：只保证结构可能，不预设内容） |

## 五、前提与风险（诚实标注）

1. **功效**：内评 09-19 §三 实测——12k × 6 seed 的双侧 0.05/80% 可检出阈 ≈ **Δρ 0.07–0.11**
   ⇒ "全不显著"只能读作"排除了大效应"。**每加一层机制，可检出阈不会变小** ⇒ 后续档必须**先算功效再定 seed 数**（教训 2/9）。
2. **区制混淆**：同 seed 仅换一个开关即跨区制已复现 6 次 ⇒ 配对分析**必须报区制匹配子集**（本稿配套改动见 §六）。
3. **纪元声明**：A 档若改变行为（初值同值则否），B 档必然改码义 ⇒ 须按"纪元变更 + 同批对照"处理，不得跨纪元合并。
4. **双路径**：A/A′ 都要动决策路径 ⇒ Python/Rust 同步 + 逐位对拍（A2 约束）；RNG 消费顺序不得变。
5. **时序**：本稿**不含任何跑批**；A′ 档实施与跑批均需令。

## 六、预注册判据草案（**写死，禁事后调**）

- **主指标**：门控确认口径的 ρ（Q1v2 §四 规则②），对照 = 现档同批同 seed
- **判定**：三态 —— `pass`（CI 下界 > 0 且 ≥ 功效推导出的门槛 `μ*`）／`undecidable`（可判定 seed < 3）／`fail`
- **附加（必须并列报）**：全配对 + **区制匹配子集**（同 seed 两臂同态）；两者冲突 ⇒ 判 **不可判**，不得挑对自己有利的那组
- **配套工具改动（本次已落地）**：`gate_pair_analysis.py` 增 §④b 区制匹配子集（内评 09-19 §二 建议）

## 七、决策点（给 fish / `[所有者]`）

1. **顺序**：是否同意「**A′（记忆方位梯度）→ A（解读表加方位）→ B（位置进码）**」，而把容量/分层/大感知（C 档）排在后面？
2. **A 档的"方位粒度"**：4 方位（十字邻域天然）还是 8 方位（含对角）？前者与 `perception_radius=4` 一致，后者需 `=8` 档。
3. **C3 是否前置**：B 档若不做发送者回报通道，是否接受"预期 null 且不可读作编码无用"的预注册？（我的建议：**要么先做 C3，要么把 B 档的结论口径限定为"管道可达性"**）
4. **容量基因（①）** 是否与 A′ 同批做（同批 = 两个变量 ⇒ 不可归因；我建议**分开**）？
