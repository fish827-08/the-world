## 一、🔴 先决发现（3 条代码级事实，**影响能否直接开做**）

### F1：`nb_max` 是 **stride（120）**，不是实际邻居数（8）——社交项被**静默弱化 15 倍**

```python
# sphere_engine.py（符号锚点：__init__ 内 _nb_table 构造 / 移动决策段 nb_max）
nb_stride = max(8, self.world.cols)          # ← max(8, 120) = 120（极点格要整行 120 邻）
self._nb_table = np.full((n_cells, nb_stride), -1, ...)
...
nb_max = float(self._nb_table.shape[1])      # ← 120，被当"邻居数"用
densities = occ.astype(np.float64) / nb_max * smw
```

`[实测]`（`tools/wave2_perception_probe.py`，本稿新件、零 RNG）：

| 量 | 读数 |
|---|---|
| `_nb_table.shape[1]`（stride） | **120** |
| 每格**实际**邻居数 | 众数 **8**、极区 **120**；唯一值 {8, 120} 家族 |
| `densities` 非零格 | n=197、mean **0.00846**、max 0.0167 |
| 感知项典型量级（`perc=0.5`、`fr≈0.5`） | **0.125** |
| ⇒ **社交项 / 感知项** | **0.068**（若按 8 归一化应 ≈ **1.02**） |

⇒ ① 注释写「归一化 `bincount(0~8)`」而代码除以 **120** ⇒ **C9 型（文档声明 ≠ 代码实际）**，
    量级 **15 倍**；这与 g13「仅弱群居」的长期观测**一致**（可能是一部分原因，非唯一）。
⇒ ② 更急的是**连带后果**：本波要重建 `_nb_table` 以支持 span=2 ⇒ stride 由极区决定
    **120 → 240**（行 58 是 132）⇒ 若仍用 `shape[1]` 当分母，**社交项会再被静默压小 2 倍**。

🔴 **处置（本波必须做，且是"不动语义"的）**：把归一化改成**显式冻结常量**
`society_norm: float = 120.0`（= 现值，保证 span=1 时**逐位等价**），并在注释里写明
"这是 stride 的冻结值，**不是**邻居数（8）；改它 = 改社交项量级 = 构造级"。
⚠️ **不**趁机"修回 8"——那会让社交项**增强 15 倍**，是**另一个**构造级变更，须单独裁定（见 §八.3）。

### F2：`perception_span` 与 `perception_radius` 是**两个正交维度**（命名必须写清）

| 参数 | 语义 | 取值 | 现状 |
|---|---|---|---|
| `perception_radius` | **邻居个数/形状**（4=正交、8=含对角） | {4,8}，`config` 硬断言 | 已有 |
| `perception_span`（本波新增） | **感知半径（跳数）** | 1（默认）/ 2 | 新增 |

⇒ 组合语义：`span=1 & radius=8` = 8 邻（现状）｜`span=2 & radius=8` = 8+16 = **24 格**（普通格，
`[实测]` 见表）｜`span=2 & radius=4` = 4 + 8 = 12 格。
🔴 **必须写进 docstring**：否则后人读 `perception_radius=8` 会以为"范围恒 1 格"（本仓已有此误名史）。

### F3：极区退化 ⇒ span=2 的候选集**最大 240**，不是 24

`[实测]`（同探针）：

| 行 | ring1 | ring1+2 |
|---|---|---|
| 普通行（15/29/30/31/45） | 8 | **24** |
| 行 58（邻带） | 8 | **132** |
| 行 59（极点带） | **120** | **240** |

⇒ ① 若不做闸，极点带个体的**逐候选 score 评估**从 8 涨到 240（**30 倍**）⇒ 决策段成本爆炸；
⇒ ② 与 L2 的 `far_cap=32`（"strict 2 圈 > 32 ⇒ 不可冲刺"）**同族** ⇒ **建议用同一把闸**：
    **`perception_cap: int = 32`；某格的 ring1+2 规模 > cap ⇒ 该个体 `span_eff = 1`**（降级，不是报错）。
    按上表：普通格 24 ≤ 32 ⇒ 生效；行 58（132）、行 59（240）⇒ **自动降级为 1 格**。
⇒ ③ 必须在产物里报告 `span_downgrade_frac`（否则"视野扩了"在极区**看似无效**会被误读成 no-op）。

## 二、五项机制逐条落点

### 2.1 `perception_span`（统一感知：资源 / 信号 / 猎物 / 威胁）

**落点**（符号锚点）：
- `SimulationConfig` 或 `SubposConfig` 同级新增 `perception_span: int = 1` + `perception_cap: int = 32`
  （⚠️ `config.py` 归 `[所有者]` 本轮独占 ⇒ 由他加，我只给字段表）
- `SphereEngine.__init__` 的 `_nb_table` 构造：按 `perception_span` 决定"一圈/两圈"；
  **保留 `-1` 填充 + 单独一张 `_nb_len`（每格实际邻居数）** —— 后者是 F1 的正解，也让
  `nb_max` 不再需要假借 stride。
- 消费方**全部自动获得 span**（这是"统一参数"的价值）：
  `sig_present[nb]`（`(self.signals._marks > 0)`）｜`densities[nb]`｜`_seek_field[nb]`｜
  `_agg_field[nb]`（L1 恐惧 + S3 血条恐惧）｜`food_ratio[nb]`（资源感知）｜`nb_sigs = _marks[nb]`（信号解读）。

**语义边界（写进 docstring）**：
- **看得见 ≠ 够得着**：`attack_range` 恒 **1**（猎物仍只从 `world.neighbors(cell)` 取）⇒ 机制链是
  "**远处看见 → 朝它走（score/追猎项）→ 进到 1 格内 → 出手**"。这正是 R173 §五.1 要的、
  也是 L1 追猎**第一次有真实机制依据**（不再依赖盲选补丁）。
- 跳数语义在极区退化（已知）⇒ 由 F3 的 cap 兜住；**球面距离**仍属未做（登记，见 §九）。

**冒烟验证项**：`mean_candidates_per_decision`（应 ≈24 而非 8）｜`span_downgrade_frac`｜
`perception_span` 读回（C4）｜关档 `digest == (573985, 8171.692943)`（**span=1 ⇒ 逐位等价**）。

### 2.2 可见性门："看见才出手"（**射程保持 1**）

**落点**（符号锚点：捕食段 `attackers = np.flatnonzero(...)`）：

```python
# 现状
attackers = np.flatnonzero(
    (attack_gene > pcfg.attack_gene_gate) & (self.rng.random(P) < attack_prob)
)
# 波 2（新增一个合取项；**不新增任何 rng 调用**）
_vis = _visible_prey_count(span_eff)          # 视野内猎物个体数（格域 bincount 聚合，零 RNG）
attackers = np.flatnonzero(
    (attack_gene > pcfg.attack_gene_gate) & (self.rng.random(P) < attack_prob)
    & (_vis > 0)
)
```

🔴 **RNG 形状保持（H2 家族）**：`self.rng.random(P)` **仍按全体 P 消费**，只是结果多与一个布尔相与
⇒ **每 tick 抽取数与关档完全一致** ⇒ 与 L2 位域契约同族。**必须写成测试**（源码级断言：本段无新增 `rng.`）。
🔴 **必须与 span **同批**（R166 §四.9 的绑定关系）**：现在 76–89% 的出手是"看不见也打"；
只加门不扩视野 ⇒ 出手机会**几乎归零** ⇒ 捕食通量崩到 0。
⇒ 反退化读数（**必报、不判**）：`visible_prey_n / attackers_nominal_n`（门后/门前）与
`skip_no_visible_prey`（并入现有 `_duel` skip 家族，**不新造计数器家族**）。

### 2.3 去掉"两段式盲选"（R148 偏离 2 的前提已消失）

**为什么现在可以去掉**：R148 批准盲选的理由是"感知恒 1 格 ⇒ 对距离-2 一无所知 ⇒ 给它算 score 是**凭空造信息**"。
span=2 ⇒ **该前提消失** ⇒ 距离-2 的格是**可观测**的 ⇒ 直接纳入候选、按 score 选。

**落点**（符号锚点：L2 第二段 `targets[i] = int(self._far_cells[... rand_choice[i] // 100 ...])`）：

| | 现在 | 波 2 建议 |
|---|---|---|
| `dash=False` | 在 **ring1** 候选上按 score 选 | **不变** |
| `dash=True` | 在 `_far_cells`（strict 2 圈）上**均匀盲选** | 在 **ring2 候选上按 score 选** |

🔴 **两个候选集**（ring1 / ring2）**必须都保留**：因为"走多远"由 `dash` 决定、而 `_mult` 的成本乘子
是按 `dash` 给的（`dash ⇒ ×(1+κ(2^p−1))`）。若改成"单一候选集 + 按距离计费"，会出现
**"宣布走 2 格、实际只走 1 格却付 2 格钱"**（或反之）⇒ 语义与成本脱钩。故：
**保持"先决定走多远、再在该距离的候选集里按 score 选"**（最小改动、成本语义自洽）。
🔴 **RNG 形状**：`rand_choice` 仍按个体抽取、`% 100` 仍用于 dash 闸 ⇒ **`// 100` 字段变为未使用，
但抽取形状不变** ⇒ H2 保持 ✅（必须写测试）。
🔴 **L1 反退化断言必须重做**（R173 §五.3 点名）：候选数 8 → 24 ⇒
`score` 的**跨候选差异变小**（多出的 16 格通常更远/更空）⇒ 旧阈值可能失效。
⇒ 做法：`seek_flat_frac` **判据保留**，**阈值按新候选数重算**：
`flat` 的定义仍是"该项对全部候选取同值"，但**分母 = 新候选数**；报告须同时给
`candidates_per_decision` 与 `seek_term_mean`（供人核对量级）。
⚠️ 另：`_l1_dec_n`（求值个体数）不变 ⇒ 新旧**不可直接比**，必须带 `candidates_per_decision`。

### 2.4 `cell_occupancy_cap`（单格个体上限，默认 3）

**落点**：移动决策段（score 层剔除）+ L2 ring2 候选集（同排除）。
`occ` **已经有**（`occ = np.bincount(self._flat[:P], minlength=n_cells)`，移动前占用）⇒ **零额外成本**。

```python
_crowded = occ >= cap                      # 格域布尔（一次算，逐候选索引）
...
score = np.where(_crowded[nb], -np.inf, score)
```

🔴 **三条硬约束（写进设计稿即契约）**：
1. **只约束"进入"，不约束"留在"**：落本格（`steps=0` / 目标 = 自身）**不受 cap 限制**
   ⇒ 否则"已在格上的个体被挤出世界"（R173 §五.4 明确）。
2. **必须定义兜底**（否则出现"全 −inf" ⇒ `argmax` 平局 ⇒ 静默落进满格）：**若全部候选 score = −inf
   ⇒ 该个体留在本格**，并计 `cap_stay_n`。⇒ cap 永不因"平局回退"被破坏。
3. **成本口径**：被迫留在本格 **不收移动费**（没移动）。⚠️ 这是**理论上的能量补贴**（省一次移动），
   但触发条件是"**所有**邻居 ≥ cap"（当前密度 0.27 个体/格 ⇒ 极罕见）⇒
   **冒烟必须报 `cap_stay_frac`**，并预注册上限（建议 `< 5%`；超了说明 cap 太紧或密度异常）。

🔴 **为什么用 score 层 −inf 而不是"落格失败留原格"**（沿用 R173 §五.4 的三条理由）：
与 fish 的语义一致（"总有些生物吃不到食物" ⇒ 它们**知道满了、会去别处**）｜(b) 会让"移动失败"
成为新的隐性筛子（谁离满格近谁倒霉）⇒ 归因不干净｜(a) 与既有 score 构造同族，**可单条断言**。

**判据（不判科学、只判接线）**：`cap_blocked_n > 0`（真触发过）｜`occupancy_max ≤ cap`（除本格外）
｜`cap_stay_frac` 报告。

| **D 全开** | **2** | **3** | **0.6/0.4** | 0.5 | 交互（视野让"去找别处"变得**可执行**） |

🔴 **C 臂的两机制不可再拆**（同批）：拆开都测不出效果（§2.5 的依赖）。
🔴 **D 臂是"机制链闭环"臂**：cap 逼迫离开拥挤格 + span=2 让它**知道**哪里不挤 ⇒ 这是
fish 那句"**总有些生物无法吃到食物**"的**可执行版本**。

### 4.2 判据

| 类 | 判据 | 口径 |
|---|---|---|
| **主** | `g16` 直方图 `D_shape` **双峰** | 沿用「一主两支持 + 三态 + 第四态」；报 `ΔD`、锁死 `D_null` |
| 支持① | `g18`（机动性）双峰 | 须超 A 臂漂变基线 |
| 支持② | **行为分化**：`dash_frac`/`still_frac`/`cap_stay_frac` 在两端的结构性差异 | 不是"均值差"，是**分布** |
| 操作检查（**不判**） | `visible_prey_n > 0`（B/D）｜`cap_blocked_n > 0`（C/D）｜`mean_candidates_per_decision ≈ 24` | **= 0 ⇒ 该机制是 no-op ⇒ 判「不可执行」**（不是"无效应"） |
| 反退化 | `seek_flat_frac` / `fear_flat_frac`（阈值按新候选数重算）｜`span_downgrade_frac` | 报告，不判 |

| 生态门 | N 轨迹不崩（软顶饱和；**人口级读数按 R165 降级为"饱和构造值"**） | 不判科学 |

## 九、已知限制（登记，不在本波解决）

1. **跳数 ≠ 球面距离**：极区"1 跳"= 整条纬度带（120 格）⇒ span=2 的语义在极区不等价；
   本波用 `perception_cap` **降级**兜住，**球面距离**仍属未做（L1L2 稿已登记）。
2. **`perception_radius(4/8)` 的硬断言**仍在（`config`）⇒ `span=2 & radius=4` 的组合**未做单测**（新增）。
3. **`cap` 只按个体数**，不按质量/体型（fish 提过"体能 600"⇒ 未来可能要"格容量按质量"）。
4. **`social_norm` 冻结**是"保持现状"，**不等于**社交项量级"正确"（见 §八.1）。
5. 本波**不动** `uniform` 世界的"移动恒劣于静止"结论（设计稿 §10.2 的限定）⇒ 臂实验必须用 **patchy**。
