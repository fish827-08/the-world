## 〇、一句话

**把「自己有多饿」接进移动决策**，让**饿的个体更主动去找、饱的个体更愿意留在食物上**。

现状（`[代码]` 逐段核过）：移动打分公式里**完全没有能量项** ——

```
score(邻居) = perc × ( food_ratio[邻居]×0.5 + 信号×信任 ) + 社交×密度 + 记忆项
选方向 = argmax(score)                       ← sphere_engine.py:3251-3255（Rust 同式 movement.rs:101-103）
每 tick 是否移动 = rng.random < move_prob    ← move_prob = g0 × (1−g19) × (1−stay_prob)（:2967-2968）
```

⇒ **一个快饿死的个体与一个刚吃饱的个体，行为完全一样**：同样概率移动、同样权重看食物/信号。
这既不符生物学直觉，也让我们**缺一条"压力 → 寻找"的直接通道**。

## 一、机制（三个可选调制，首批只开 ①）

**饥饿度**：`hunger = clip(1 − energy / max_energy, 0, 1)`（0 = 吃饱，1 = 快饿死；`self._energy` / `ocfg.max_energy`）

| # | 调制 | 公式 | 作用 |
|---|---|---|---|
| **①** | **移动倾向**（走/停） | `move_prob_eff = clip( move_prob × (1 + α·(hunger − h_mid)/(1 − h_mid)), 0, 1 )` | 饿 ⇒ 更愿意出走；饱 ⇒ 更愿意驻留（留在食物上繁殖） |
| **②** | **感知权重**（方向） | `perc_eff = perc × (1 + β·(hunger − h_mid)/(1 − h_mid))` | 饿 ⇒ 食物项权重上升（社交/信号项相对被压）＝ **资源压力改变信息使用优先级** |
| ③ | （后置）**离家倾向** | 饿 ∧ 自己格 `food_ratio` 低 ⇒ 额外加权"记忆点方向"（复用已实现的 `memory_gradient="orientation"` / `_memory_orientation_cos`） | 跨斑块迁移；**须与 S3 记忆改造同批** |

- 默认参数建议：`α = 0.5`、`β = 0.5`、`h_mid = 0.5`（`h_mid` = 中性饥饿度，此点上下才产生差异）。
- ③ 之所以后置：它依赖"记忆点真的有跨斑块引导价值"，而那是 S3 的题；单独做会与 S3 抢同一个解释力。

## 三、预注册判读（写死，事后不得改线）

**主判据**

- **饿死占比下降**（rd 开档 × 同 seed 配对，按 seed 分层：多数 seed 一致为负即通过）

**支持判据**

- **单位能量位移效率** = 位移格数 ÷ 移动耗能（上升）
- **离开低食格的比例**（自己格 `food_ratio` 低于阈值时的出走率，上升）
- **判据②（斑块异质性）不降**（HM 不应把 S2 造出来的异质性抹平）

**🔴 必须预登记的反例（否则会自我欺骗）**

1. **"饿死加速"悖论**：走得多 ⇒ 移动耗能多 ⇒ **饿死可能反而上升**。⇒ 判读**同时**看 `饿死率` 与 `平均能量`，只看位移会得出相反结论。
2. **迷路**：1 格感知 + 走得更勤 = 更快的随机游走 ⇒ 可能**更快走出斑块**。⇒ 若如此，正确结论是"HM 需要与感知跨度（R230 第 1 步）**配套**"，而不是"HM 无效"。
3. **基因交互**：`g6`（MOVE_COST）/ `g19`（ROOTING）频率可能漂移 ⇒ 须一并报告，避免把"基因演化"误读成"机制效应"。

**❌ 禁止**：在饱和世界（现状，饱和度 0.94–0.96）测试 —— 没有值得去的地方，"更愿意走"只会变成"更快的随机游走"。**必须 S2 过门后同批或紧随**。

## 五、与其它机制的关系

- **与 R230 感知跨度**：互补。HM 管"愿意走多远"，span 管"能看多远"。**先 HM 后 span**（HM 更便宜、且不动构造）。若 HM 显出"迷路"反例 ⇒ 提前 span 臂的理由就从"想扩"变成"有必要"。
- **与 S3 记忆改造**：③ 号调制是 S3 的一部分（都用 `memory_gradient="orientation"`）⇒ **不要并行实施**。
- **与 C3**：② 号调制是"C3 回报通道"的天然前置 —— 如果饿的个体更愿意听信号，信号才可能产生发送者收益。**C3 实施时应把 HM 当作已有基底**。
