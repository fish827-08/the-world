## 一 两个假设（精确定义 + 机制链 + 为什么现读数分不开）

### 1.1 H1「世界饱和（世界缺空间异质性）」

- **定义**：现有世界里，个体一生踩过的**富食格**几乎全在"脚边同一片斑块内" ⇒
  无论记忆保留多少、记多久，**史里就没有远格可记** ⇒ 记忆格到当前格距离**天然小**。
- **机制链**（`[代码]`＋`[实测 argv]`）：
  ① 写入条件 `grid > FOOD_RICH_LEVEL × capacity`（`config.py:533` 常量 0.5；`sphere_engine.py:3577-3580`，比较符为 `>`）；
  ② 装置 = `--device s2`：480×960 / patches 1700 / radius 2（Chebyshev，`config.py:97-98`）/ bg_low 0.0/0.0（纯斑块 A 支）
     ⇒ 富食域 ≈ 1700×25 格 ≈ **9.2%** 面积；`[推算]` 斑块平均间距 ≈ **16.5 格**；
  ③ 定稿记述"饱和度全域 0.94–0.96"（`[文档]` 定稿 §P1-c 根因段）——若成立 ⇒ 个体长期驻留富食区，不需远行 ⇒ 踩点史=驻留史 ⇒ 全在近处。
- **修复路径** = 回 S2 造空间异质性（**不是**改记忆）。

### 1.2 H2「记忆策略只记最近 4 格」

- **定义**：个体**确有**远足踩点（曾踩过离现在很远、甚至跨斑块的富食格），但引擎记忆是
  4 槽环形缓冲（`_work_memory (P,4)` 初值 −1，`sphere_engine.py:1361`；全局单指针逐写 tick `(ptr+1)%4`，`:3572-3594`）
  ⇒ 每次新写入覆盖最久槽 ⇒ **旧踩点（含远格）被系统性擦除** ⇒ 槽内只剩近处。
- **修复路径** = 记忆策略改造（容量/保留策略），不动世界。

### 1.3 为什么现有读数分不开 + 判别量推导

🔴 两假设对 **P1-c 现测的两个量**（保留槽距离分布／可直读率）给出**同一预测**：都小。
⇒ 直接重测 P1-c **永远判不出根因**（这正是定稿要求"先判根因"而不是"重测 P1-c"的原因）。

🟢 **判别量 = 反事实被擦除集（erased set）**：

> 探针侧给每个个体维护**独立 FIFO 踩点日志**（写入规则与引擎逐字相同），
> 每个采样 tick 取"日志里**除最近 4 条之外**的部分"（= 若记忆容量 4→16，这些格**本会保留而现被擦除**），
> 算它们到当前格的球面距离。

- 若 **H1** 真：个体**全史**没有远格 ⇒ 被擦除集也**近**（可直读率高、中位距离小、与保留集读数≈持平）。
- 若 **H2** 真：全史有远格、只是被擦掉 ⇒ 被擦除集**远**（可直读率低、中位距离大、显著差于保留集）。

两条**诚实披露**：

- ⚠️ 披露①：反事实口径 = **每体独立 FIFO**，不是"引擎全局指针环的 16 变体"
  （全局指针语义含跨个体相位；而 H2 的修复语义是容量/策略 ⇒ 每体 FIFO 才是正确反事实；两口径对"远格是否存在"的判别无方向性差异）。
- ⚠️ 披露②：日志与引擎真实写入存在 **≤1 tick 相位差** —— 引擎 4.4 段在**移动之前**求值
  （`sphere_engine.py:3600-3601` 注释："此段 `_flat` 尚未变化（移动在步骤 5）"），探针在 `step()` 返回后观测；
  亚格步进档（`subdiv 80`）单 tick 位移 ≪ 判读尺度（2.83 / 16.5 格）⇒ 对距离分布为一阶小量；
  另设"写 tick 计数对账"诊断列（见 §2.2）兜底。

### 2.2 Tier-1（判别主力）：新探针 `experiments/p1c_erasure_probe.py`

**装置（与 P1-c 逐字相同，单一变量=只加观测）**：`--device s2 --ticks 3000 --sample 100`；
seeds **207 / 208 / 209 / 210**；`signal_alphabet="8"`、`memory_v2=False`、`rd` 关、`use_sim_core=False`。
探针**纯观测**：只读引擎数组 + 探针侧日志，不调引擎任何写方法、不消费主 RNG ⇒ 轨迹不受扰动。

**实现要点**：

1. **既有列全保留**：直接复用 `p1c_distance_probe.measure()` ⇒ 列集 ⊇ P1-c CSV，保证可对拍。
2. **每 tick（非采样 tick 也更新；统计只在采样 tick）**：
   - 事件检测：`rich = grid[cur] > 0.5×capacity[cur]`（**与引擎逐字同式** `:3577-3580`）；
     命中者把当前格 append 进该体 FIFO 环（环深默认 64，见 3）。
   - **被擦除集 E**：环中"除最近 4 条之外"的条目（K16 窗 ≤12 条/体；K64 窗 ≤60 条/体）。
   - 统计列（每采样）：
     - `pea_*`：K16 窗**全部**条目（`pea_n / pea_d_med / pea_d_p90 / pea_frac_d0 / pea_frac_dle1 / pea_frac_read_moore`）；
     - `pep_*`：K16 窗 **d>0 子集**（与 P1-c `pos_*` 同口径）——🔴 **主判据用 `pep_*`**；
     - `pep64_*`：K64 窗 d>0 子集（**预注册次判**，零额外机时，供 §五 复核①）。
   - 诊断列：`eng_wr_ticks`（窗内 `_mem_ptr` 前进次数 = 引擎写 tick 数 `[代码] :3593-3594`）
     vs `probe_rich_ticks`（窗内探针检出 ≥1 事件的 tick 数）——二者应接近（相位差 ≤1 除外）；
     偏差过大 ⇒ 事件检测口径有误 ⇒ **fail-loud 停跑**。
3. **身份重映射**：引擎死亡=保序压缩（`_id` 与 `_work_memory[:P]` 同 `keep` 掩码，`:5061 / :5128-5129`；
   `_id` 自 `np.arange` + 追增 ⇒ 升序不变式）⇒ 探针按 `_id` `searchsorted` 重映射环行；
   升序不成立 ⇒ **fail-loud**（不回退，回报）。
4. **前置读回 fail-loud**（同 p1c `:200-209` 风格 + 扩充，R6.6「仪表先冒烟」）：
   `signal_alphabet=="8"` / `memory_v2 is False` / `rd off` / `use_sim_core False` / `patches==1700` /
   `_id` 升序 任一不符 ⇒ `SystemExit` 拒跑。
5. **`--dm-guard <stored csv>`（硬门）**：跑完后把共享列的 30 个采样点与
   `the-world-data/p1c/p1c_s207_t3000_v2.csv` 逐行比对（排除 `ms_per_tick_window`；同 `round(,4)` 口径），
   **任一不等 ⇒ `SystemExit`**。seed=207 必开 —— 它是"探针观测于与 P1-c **逐位同世界**、
   读数可直接对锚 0.862"的程序化证明（T3 已实测重跑 20/20 行逐位一致，可行性成立）。
6. 产物：CSV（行级 fsync，R263）+ `*.summary.json`（含各 seed 池化 + 总池）；
   命名 `p1c_erase_s{seed}_t3000.csv`；落 `_trash_local/p1c_erase/` ⇒ 证据包入数据仓（同 T3 纪律）。

**代价**：每 tick 增 O(P) 观测（P≈1.3×10⁴，`[推算]` +0.1–0.5 ms/tick ≈ +0.5% 级）——部署后 1-run 冒烟实测确认（R6.6）。

## 三 预注册判据（🔴 **跑前锁定**；判读权=天平；本稿被审/被锁前的修订以锁定稿为准）

### 3.1 主判据（K16 擦除集，d>0 子集，池化口径）

| # | 量 | H1 带 | H2 带 | 灰区 |
|---|---|-------|-------|------|
| P1 | `pep_frac_read_moore`（被擦除集可直读率，口径 B） | **≥0.80** | **≤0.50** | 0.50–0.80 |
| P2 | `pep_d_med`（被擦除集 d>0 中位距离，口径 A，单位=格） | **≤2.0** | **≥3.0** | 2.0–3.0 |

- 确认判带成立还需 P1、P2 **同向**；异向（如 P1 落 H1 带而 P2 落 H2 带）⇒ 报"**判别不出（判据内冲突）**"。
- `pea_*`（含 d=0 全条目）与 `pep_*` 方向矛盾 ⇒ 同一结论。

### 3.2 差分判据（结构性预测锁）

ΔR = `pos_frac_read_moore`（保留集，同 run）− `pep_frac_read_moore`（擦除集）

- **ΔR ≤ 0.05** ⇒ H1 型（历史≈近期，无远格可擦）；
- **ΔR ≥ 0.25** ⇒ H2 型（被擦的远多于保留的）；
- 与 §3.1 整体同向才可判；矛盾 ⇒ "判别不出"。

### 3.3 一致性与显著性锁

1. **种子一致**：≥3/4 seeds 的 `pep_frac_read_moore` 落同一带 ⇒ 才可判。
2. **离界余量**：池化值与最近带界之差 ≥ 2×**种子间 SD**（防贴线判）。
3. **H2 附加 SNR**：SNR =（0.862 − `pep_frac_read_moore` 池化）/ 种子间 SD **≥2**
   （相对 P1-c 保留集水平的下跌须 2σ 级；0.862 = P1-c `pos_frac_read_moore` `[实测·数据仓]`）。

### 3.4 若 H1 真／若 H2 真，各会看到什么（R358 必写项）

| 观测量（Tier-1，K16） | 若 **H1** 真（史里无远格） | 若 **H2** 真（有远格被擦） |
|---|---|---|
| `pep_frac_read_moore` | 高（≥0.80；与保留集 0.862 同带） | 低（≤0.50） |
| `pep_d_med` | 小（≤2.0 格，斑块直径 2.83 内） | 大（≥3.0 格，跨出斑块尺度） |
| ΔR（保留−擦除） | ≈0（≤0.05） | 大（≥0.25） |
| `pea_*` 方向 | 与 `pep_*` 同向 | 与 `pep_*` 同向 |
| 侧证：几何（T0a） | 与判读无直接联动 | 世界里远格必然存在（≥5 格） |

### 3.5 阈值锚点与理由（跑前可改、跑后不可）

- **0.862** = P1-c 保留集（d>0）可直读率 `[实测]`；**2.83** = 斑块直径上限 √(2²+2²)（radius=2 Chebyshev `[代码]`）；
  **16.5** = 斑块平均间距 `[推算]`。
- **0.80** = "基本持平"下沿（0.862 − 0.06，留种间波动余地）；**0.50** = 多数条目出 Moore（远格定性证据）。
- 判读权归天平；若 D4/天平在锁定时改阈值 ⇒ 以**锁定稿**为准执行。

### 3.6 判后动作（预写）

- 判 **H1** ⇒ 走"回 S2 造空间异质性"路线（世界改造后**重测 P1-c** 才谈 M1 重启）。
- 判 **H2** ⇒ 另立"记忆策略改造"设计（容量/保留策略；纯设计稿走正常流程）。
- 🔴 两条共同红线（定稿）：**不得只改 `mem_bit` 判据**；**不得因判 H2 就擅自开 M1**。
