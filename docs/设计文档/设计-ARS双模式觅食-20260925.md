## 0. 一句话

**别让生物"看得更远"（两条路都试过，SNR 都堵死），让它按"最近有没有吃到"切换行为模式：没吃时走直线大步，刚吃时原地打转——这就是跨 6 亿年、跨所有类群验证过的 Area-Restricted Search（ARS）。卡点2 缺的是搜索模式，卡点1 缺的是滞留的退出期限，一个机制同时解。**

---

## 1. 项目背景

**digital-life-sphere** 是数字生命模拟项目：
- **世界**：经纬网格球体（60×120 = 7200 格），含光照/昼夜/季节温度场。
- **食物分布**：13.5 起 `distribution="patchy"` + `bg_production_zero=True`——食物聚成 ~30 个斑块（半径 2 扩散，约 14% 的格子有食物），其余 86% 是零产能荒漠。斑块格容量 ×3、再生 ×3。
- **生物**：Python+NumPy 编排、Rust(PyO3) 热核。个体按基因决定移动概率/感知/社交等，移动打分公式：
  ```
  score(邻居) = perc × (food_ratio[邻居]×0.5 + 信号×信任) + 社交×密度 + 记忆项
  ```
  候选为 1 圈 8 邻（`perception_span=2` 表已建但默认关）；所有候选得分相同时随机选邻居。
- **繁殖**：子代继承亲代所在格；只有 t=0 创始代均匀随机撒点。
- **目标**：语言/信息结构（D2）涌现，所有行为机制须可被选择压检验、默认关时逐位等价（C7 digest 纪律）。

## 2. 问题描述（两个卡点，实为同一根因）

### 2.1 卡点2：生物不知道怎么找食物，只会随机移动

- 荒漠里 8 个邻居 `food_ratio` 全为 0 → 食物项对每个候选贡献相同 → 得分平局 → **每 tick 随机选邻居 = 布朗运动**，位移 ~√t。
- 类比：生物在看不到岸的海里划船，视力 1 格、无方向感，即使每天能划很远，撞上岸全靠运气。
- 后果：
  - 创始代 86% 直接掉进荒漠饿死；存活全靠"出生点离斑块近"的彩票 → **种子间数量随机，地形没起作用**。
  - 离开斑块后找到下一块食物的概率极低。

### 2.2 卡点1：发现食物就赖着不走，食物利用率低

- 一旦在斑块上，邻居全有食物 → 食物项把分数钉在斑块内部；斑块格 ×3 持续再生 = 永久饭票。
- 生物**没有离开机制**：斑块被吃空前不走，且无"附近还有更好斑块"的感知（视野只有 1 格）。
- 后果：已发现的斑块被少数个体霸占，**大量未发现的斑块永远无人使用**。

### 2.3 此前两条路为什么失败（关键教训）

| 尝试 | 结果 | 根因 |
|---|---|---|
| 食物梯度感知 | SNR 堵死（设计稿自述：食物带移动比个体随机运动慢 17–20 倍） | 需要**远处的信息**，距离远了信噪比不够 |
| 13.8 日历—罗盘定向迁徙（R198，判定未成立） | 迁徙臂 ρ(Δφ, g23)=+0.0247，**与"迁移项恒为 0"的阴性对照臂 ρ=+0.0241 相同**；方向一致率仅 30–37% | 迁移项是**与食物脱钩的全局推力**，只是把随机游走幅度放大 2.3–2.6×，高 g23 个体并不定向 |

**共同教训：两条路都试图给生物"远处的信息"。而本项目的感知半径太小、斑块太稀，任何"远处信息"都信噪比不足。**

## 3. 自然界案例调研（2026-09-25 检索）

| # | 案例 | 关键机制 | 证据 | 对本项目的启示 |
|---|---|---|---|---|
| ① | **ARS 跨类群**（原生生物、线虫、昆虫、鸟、哺乳、人类） | 遇食→慢速+高转向（斑块内）；无食→快速+直线（斑块间） | PNAS 2019：墨西哥纳瓦采蘑菇者 GPS 轨迹符合 ARS + 边际值定理预测；模拟证明 ARS 可优于无条件 Lévy/布朗 | **双模式状态机即第一版核心** |
| ② | **Lévy 飞行**（信天翁、鲨鱼、蜜蜂） | 罕见长步长（~10–100km）+ 短步集群，幂律 μ≈2 | 信天翁 GPS：Lévy 段捕获猎物质量近每日能量需求 4 倍；Lotka-Volterra 模型：Lévy 中间指数在破碎栖息地**防止种群灭绝**（过度扩散遇不到斑块，正常扩散过度开发斑块） | 搜索模式加"大步长概率"基因，跨荒漠找远斑块 |
| ③ | **蛾子气味追踪** | 闻到→逆风直行（surge）；丢失→横向扫掠（cast）。**只需二值"有没有"，不需要浓度梯度**——湍流羽流的瞬时浓度差异不可靠 | Annual Reviews / PLOS ONE：单阈值探测器即可完成源定位（optomotor anemotaxis） | **直接绕开本项目的 SNR 困境**：本地"吃到没"是 100% 可靠信号 |
| ④ | **蚂蚁信息素** | 发现食物→回程撒标记→巢友跟随并加强（正反馈）；未用轨迹挥发消退 | 综述：轨迹强度 ∝ 加入数量；未用轨迹数小时内消退 | 第二层：个体标记食物位置，接 D2 信号系统 |
| ⑤ | **Trapline 路线记忆**（蜜蜂、蜂鸟） | 20+ 次觅食航次后建立稳定多目的地路线；行程缩短 80% | 雷达追踪：蜜蜂 26 次航次只试 120 条路线中的 20 条；蜂鸟记住数千朵花、8–12 个月不忘 | 第三层：工作记忆升级为"食物路线"，依赖成熟信息结构 |
| ⑥ | **边际值定理（Charnov 1976）** | 边际取食率降到环境平均（含旅行时间）时离开；富环境 GUT 更短 | 经典理论 + 大量实测（GUT 跨斑块类型恒定、富环境更短） | 滞留模式的退出 = 成功窗口衰减，**涌现 MVT，不用手写"环境平均"** |

**核心洞察：自然界从不要求动物"看得远"。ARS 的切换条件只有一个——本地的"最近有没有吃到"。** 这个信号无信噪比问题、无时序不确定性，且跨所有类群收敛到同一解。

## 4. 落地方案

### 4.1 状态机（核心机制）

```
        吃到食物（任何一格 intake > 0）
   ┌──────────────────────────────────┐
   │                                 ▼
┌──────────┐  (tick − last_feed > 窗口)  ┌──────────┐
│ 搜索模式  │ ──────────────────────────▶ │ 滞留模式  │
│ extensive │ ◀────────────────────────── │ intensive │
│ 走直线·大步 │   吃到食物（intake>0）    │ 高转向·短步│
│ 移动概率↑  │                            │ 移动概率↓  │
└──────────┘                            └──────────┘
```

- **搜索模式**（荒漠中）：生物大致沿直线走（相关随机游走），位移从 ~√t 变 ~t；偶发大步长跨荒漠。
- **滞留模式**（斑块上）：保持原打分（`food_ratio` 主导），自然在斑块内打转；但**超过成功窗口没再吃到就自动切回搜索**——这就是"吃空就走"，且是涌现的边际值定理，不是"赖到地老天荒"。
- 拥挤效应白送：斑块上同类越多 → 人均吃到的越少 → `last_feed` 更新越慢 → 部分个体自动切搜索散开。

### 4.2 第一层：ARS 双模式 + 直线惯性（最小闭环，先做）

| 改动 | 位置 | 说明 |
|---|---|---|
| 个体数组 `last_feed_tick[i]` | `sphere_engine.py` 进食步（step 4，consume 后）一行：吃到就 `= self._tick` | 比 EMA 更简单、零新参数 |
| 个体数组 `heading[i]` | 移动步后更新为上一步移动方向（0–7） | 供 cos 项计算直线惯性 |
| 新基因位 `pers`（搜索模式直线惯性强度） | `genes.py` 新增（先查 RESERVED 空位；注意 g23 已被 13.8 `MIGRATE_BIAS` 占用） | 可演化：荒漠环境 pers 应高，森林应低 |
| 新基因位 `hunger_window`（成功窗口，tick 数） | `genes.py` 或全局 config（二选一，先做 config 旋钮） | 超过窗口没吃到 → 切搜索模式 |
| 打分公式 | `sphere_engine.py:2628` 附近 + `movement.rs` 同步（或默认关走 Python 路径） | 饥饿时：`score += pers × cos(heading → 候选格)`；饱腹时保持原式 |
| 移动概率 | 移动判定段 | 饥饿时提高 `move_prob`，饱腹时降低（自然停留） |
| 配置 | `config.py` 新增 `ArsConfig`（默认关） | 关档逐位等价，符合 C7 digest 纪律 |

### 4.3 第二层（探索仍不够时再加）：Lévy 大步长

- 饥饿时以概率 `lvy_prob`（基因）走 2 圈远（复用 `_far_cells` 或 `perception_span=2` 候选表）。
- 对应自然界②：破碎栖息地防止灭绝的中间指数搜索。

### 4.4 第三层（接 D2 信号系统）：蚂蚁式标记

- 发现富斑块的生物在原地留下持久信号标记；其他生物朝高信任度标记方向走。
- 正反馈 + 挥发衰减 → 信号第一次有"食物位置"语义 → 正好是语言涌现主线要的东西。
- **不与第一层同时做**，等 ARS 跑通、个体能稳定觅食后再上。

### 4.5 与 13.8 的关系（不同时间尺度，不冲突）

- ARS = **个体级觅食行为**（tick 尺度，决定"下一格去哪"）。
- 13.8 日历罗盘 = **种群级季节长程移动**（世代尺度，决定"夏天去哪块大陆"）。
- ARS 是底层：个体得先能"找到饭、吃完、换个地方找"，季节迁徙才有意义。R198 失败的教训正是在没有 ARS 时强加上层推力。

## 7. 实施顺序

1. **第一层最小闭环**：`last_feed_tick` + 模式切换 + 直线惯性 + `pers` 基因（默认关）。

## 8. `[外鉴]` 审阅意见（追加于 2026-09-25 16:03 实钟；外部参考级，与 `[内评]` 冲突以所有者裁定为准；按 R126 本意见入文 ≠ 批准开工）

### 8.1 总判定

**方向赞同**：用"本地二值摄入事件"做模式切换，正是文献里的 enhancement 机制（蛾子 surge/cast 的标准定义），跨类群收敛判断属实（PNAS 2019 那篇已对题核实，标题与结论相符）；MVT 涌现退出、三层分批、"底层先于 13.8 上层推力"的归因，均认可。**但 §8.2 两处会直接自断判据，须先改；§8.3 七条口径在设计稿定稿时钉死；§8.4 是第二层的措辞红线（不阻塞第一层）。**

### 8.2 实施前必改（两处）

1. **§六 风险4 缓解会杀死 §五 主判据**：主判据 =「荒漠出生个体存活率 ARS开>关」；把创始代撒点改到 `patch_mask` 内 ⇒ 荒漠出生样本不存在 ⇒ 主判据不可证伪。**主判据批保持均匀撒点**（那正是 ARS 的天然试验场）；"斑块撒点"如需采用，另立"种群恢复批"分开贴标。若 ARS 救不回荒漠出生，让主判据诚实失败，不得把问题修到看不见。
2. **§五 支持2 复用 E-030 误读模式**："末 N 的 seed 间方差下降"单独不采信——均值降 + 方差塌 = 扫荡（E-030 原案教训）。判据须配对**预注册的均值地板**（seed 均值 N ≥ 某阈），地板不过则方差降记"不适用"。

### 8.3 定稿时钉死的口径（七条）

3. **§六 风险2 的 P6 量级门在荒漠构造性不可满足**：荒漠格 food_ratio 恒 0 ⇒ 食物项恒 0 ⇒ 搜索模式下 ARS 项必然 100% 主导。把"ARS 项不超过觅食项"的适用范围限定为"**斑块内/边缘**"；荒漠主导是设计目标，不是退化（文案写明，免得日后被判违规）。
4. **§4.2 `last_feed_tick` 语义**：记"**咬到**"（本次结算 intake>0 事件），不是"站在食物格"。满舱/胃容量上限（C9 双口径）时停在富斑也可能摄入=0 ⇒ 窗口起算、自动离斑——这是 **MVT-正确**的行为，但判定必须写死在设计稿，否则跨批读数被能量封顶/胃容量口径搬道。
5. **命名走事件式**：`ticks_since_feed`、`mode=intensive/extensive`；正文与代码不得以"饥饿/饱腹/satiety"引入第二层语义（13.x 时代"纯能量阈值"口径同族先例）。
6. **§五 缺机制归因拆分**：ARS = 直线惯性(pers) + 滞留(降 move_prob) + 窗口退出，三条耦合通道。至少补臂：**pers-only（窗口=∞）** 与 **窗口敏感性 {0.5×, 1×, 2×}（含预注册上限）**——否则阳性说不清谁干的、阴性分不清是机制坏还是参数坏（w_seek"上限+两档"同款先例）。
7. **反退化项须配漂变零模型**：pers 均值漂移在有限 N 下漂变/搭车即可造出（g18 教训）——按 seed 配对、与默认关臂同批对照，不报合并样本。
8. **"60 代存活率"写明单位**：本项目个体寿命 2400–19200 tick，"60 代"是 tick 还是世代会被两种读法（口径纪律）。
9. **极地豁免**：经纬网格上的"直线"在极区伪弯曲（8 邻方向收敛；极点邻格=120 是旧坑）。heading 过极更新规则要么写死要么极区不入 ARS；存活/反退化读数**分纬度带报、不按合计读**（几何探针 Q1 合计被极区放大的同一课）。

### 8.4 第二层（§4.3）措辞红线（不阻塞）

10. **"Lévy"改称"类 Lévy / 双尺度混合"**：8 邻网格 + 最大 2 圈构造不出幂律尾，那只是两个步长尺度。文献公案备查：Edwards et al. 2007（*PLoS Biol* 5:e83）把信天翁/熊蜂/鹿的幂律判回指数分布，后续原位记录部分翻案；而"自相关/分箱伪影本身可造表观幂律"已被证明（`Bridging the gulf between correlated random walks and Lévy walks`, J. R. Soc. Interface）。若将来做幂律判据：**指数估计用 MLE，禁 log 分箱最小二乘**。
11. 反向弹药（建议移进 §三 当第一层正当性）：Lévy 最优（μ≈1.5）的成立域是"目标稀疏 + **非破坏性**觅食"；本项目斑块可耗尽 + ×3 再生 = **半破坏性**区制，文献预言最优本就偏向面积偏置（ARS/Brownian）——**"先做第一层"有理论依据，不只是工程顺序**。
