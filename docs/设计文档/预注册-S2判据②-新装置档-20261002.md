## 二、为什么必须在新档重测（三条）

1. **旧测跑在抽奖装置上**。旧档 `bg_low 0.4/0.05` 有 `from_field` 单格抽奖缺陷（R319/R326），
   ⇒ 每个 seed 的世界类型随机为 **A 支（纯斑块）或 B 支（全图可产）**，**两臂不是同一类世界**。
2. 🔴 **R242 的"rd 双稳态"极可能就是抽奖本身**。R242 记录：「seed44 on 臂未出走 ⇒ K=8681 繁荣；
   seeds42/43 出走 ⇒ 被压至 654–1903」——而轻舟今日逐位复现的支别是 **42/43 = B 支、44 = A 支**
   ⇒ **所谓"双稳态"很可能就是"B 支 vs A 支"**，不是 rd 的动力学性质。
   ⇒ **R243 据此把判据改成「吸引子归属」这个决定，前提也需重新检验**。
3. **R326 撤绿洲带后，世界类型已统一**（新档 0/12 抽奖）⇒ 现在才有条件做**干净的双臂对照**。

## 四、判据（**预注册，开跑前锁定**）

### 4.0 🔴 判读前必做的前置步：**先刻画吸引子**（R243 ① 的遗留要求）

判读**第一步**不是比数值，而是**按 K 轨迹给每个 run 归类**（繁荣 / 压制 / 崩溃），
并**明确报告**：同一 seed 的 on/off 是否落在**同一吸引子**内。
- 若同 seed 两臂落在**不同吸引子** ⇒ 该 seed 的配对差**不可直接比**，须单列（R243 已作废"多数票 pass/fail"）。
- **不得**在未归类前使用任何 pass/fail 或多数票口径。

### 4.1 主判据 —— **斑块级饱和度的空间异质性由 rd 造成**

- 指标：`patch_sat_var`（斑块间饱和度方差）与 `patch_sat_range`（极差），**取末态（t=40 000）**。
- **判据**：`on > off`，**按 seed 分层，分层后 ≥4/6 个 seed 一致为正**。
- 必要条件（同时报，不作主判）：**on 臂 `patch_sat_var > 0` 且显著**（斑块之间确实不同）。

### 4.2 支持判据（各报数值，**各自独立判阴**）

| # | 指标 | 期望方向 | 说明 |
|---|---|---|---|
| S1 | `never_visited_patch_cell_frac`（未访斑块格占比） | on **<** off | rd 把个体逼向更多斑块 |
| S2 | `patch_sat_mean`（斑块平均饱和度） | on **<** off | 斑块被耗竭 |
| S3 | `pop`（承载力 K） | on ≤ off，且**降幅 ≤ 50%** | **止损红线**（R229：>50% 才判负） |
| S4 | `l2_visited_gini`（访问聚集度） | 仅报数值 | 分化度，不作判据 |

### 4.3 三态 + 第四态

- **成立**：4.1 通过 **且** on 臂异质性 >0。
- **不成立**：4.1 反向或多层后为正的 seed ≤3/6。
- **纪元不足**（第四态，R149/R151）：若任一群落 <30 代 或 有效 tick <40 000 ⇒ **判"纪元不足"，不作正负结论**。

### 4.4 预先写死的反证条件

出现下列任一 ⇒ **直接判"不成立"**，不得靠追加批"再试试"：
- on 臂 `patch_sat_var` 中位 **≤** off 臂；
- 分层后为正的 seed ≤3/6；
- on 臂 K 降幅 >50%（**同时记止损**）。

4. 边界：不改引擎、不改装置档、不动任何在跑批（F-R9）。
