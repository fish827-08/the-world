## 二、实现要点（与规格逐条对齐）

1. **设备依赖**：仪表读 `_marks/_age`（SignalField 内部）、`_flat/_id/_genes`、
   `_nb_table/_pole_nb`（世界邻接）、`_mem_bit_on/n`（引擎计数器）。全部只读。
2. **步序事实（已全仓核）**：步内 `signals.tick()`（`sphere_engine.py:2843`，衰减/过期清零）
   → 发射写 marks（`:3664` `write_many`，**全仓唯一 marks 写点**）
   → 移动决策读 marks（步 5）。⇒ **步末 `_marks` 逐位等于移动实读图**。
3. **G1**：16 桶 bincount（`marks_hist_i`，全 N 格；hist 总和 ≡ 480×960 = 460800），
   熵 = `-(p·log2 p).sum() / log2(16)`（**分母照规格字面 log2(16)** ⇒ 15 符号理论满值
   ≈ 0.977，跨批对比时须知）。
4. **G3**：新写格判别 = `age == duration`（tick 先于写 ⇒ 步内唯一新写特征）；
   连续串：同格连续 tick 写 ⇒ 断串时入 `hist[min(k,8)]`；歧义（同格多写者）判定
   = 续接上 tick → 最长串 → 最小 id；`g3_orphan_n` 为审计量（新写格无任何候选 ⇒ 应恒 0，
   已逐行验 0）。
5. **G4**：直接读引擎 `_mem_bit_on/_mem_bit_n`。⚠️ **alphabet="16" 下该通路不在**
   （计数器只在 "8" 分支累加，`:3647-3649`）⇒ s3 默认档 g4 恒 n/a(NaN)，装配时 stderr 警告。
   要 G4 数据须装置切 `signal_alphabet="8"`（P1-a 前提）。
6. **G5**：决策时点图 = **本步末 `_marks`**（§二-2 事实）；has_sig 由 agent 移动前位置
   （`last_flat`）× `_nb_table/_pole_nb` 同式判定；位移 = 两端都在的 agent
   （id searchsorted 配对，`_id` 非升序 ⇒ RuntimeError fail-loud；新生/死亡排除）。
   方向码 = `(dr+1)*3 + sign(dc)+1`，静止 = 4；两列 = 9 槽方向的
   TV 距离（`g5_dir_diff`）与静止率差（`g5_move_diff`）。单侧为空 ⇒ NaN。
7. **续跑守卫**：resume 时读已有 CSV 表头，与 `--m0-instruments` 开关不一致 ⇒
   stderr + `exit(2)`（防列错位）。⚠️ 语义边界：resume 段的 M0 统计**只覆盖本段**
   （`g3`/run 桶为段内累计），跨段拼接时须按段解读。
8. **已知近似**：极区行（`rows==top/bottom`）has_sig 用 `_pole_nb` 行判定（与引擎同源，
   但位移方向在极点坍缩，`dc` 做了环形折算，仍为近似）；G3 归因按位置近似
   （同格多体歧义率随密度升：t=250 约 3.5% → t=2000 约 47%，另 pattern=0 写入会清格，
   对 G3 不可见——两类偏差都在高密度端显著，判读时须知）。
## 三、🔴 两项须砚锁口径的发现（G5）

### 3.1 决策图时刻（实现期发现并已修，附证据）

初版取"上步末 marks"做决策图 ⇒ 与引擎实读差 6–512 格/步（发射在移动**前**）。
修正为步末图后，用**类级**包装 `_move_decide_v2_batch` 截获实读图（实例打补丁不可行，
`SphereEngine` 有 `__slots__`），**100/100 tick 逐位零差**。
修正幅度（旧→新，big smoke 同 run 对比）：计数 ≤15 体/窗；θ 列最大绝对差 ≈ 0.0118
（t=250：0.6030→0.5912）。⇒ 交付版数字比初版低 0–2%（相对）。

### 3.2 `g5_dir_diff` ≡ `g5_move_diff` 坍缩（数据事实，非 bug）

8 个采样窗全部满足 `dir_diff == move_diff`（到浮点尾差 1e-16）。代数原因：
无信号组 ≈ 94% 静止（414/439、289/299、235/251），有信号组 ≈ 33–41% 静止
⇒ 8 个非静止槽的分差全部同号 ⇒ TV ≡ |Δ静止率|。

**但方向行为确实不同**：剔掉静止槽后的**条件分布** TV ≈ 0.30–0.33（三个采样点），
只是被静止率主导掩盖。⇒ **提案**：M0 先按现两列交付；若砚认条件分布更有信息量，
后续可加第三列 `g5_dircond_diff` = 仅"有位移"子集上的 8 向条件 TV（~10 行改动）。
**本规格已锁，未加列**，等砚裁定。
