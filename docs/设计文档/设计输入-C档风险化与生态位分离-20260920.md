# 设计输入 · C 档「风险化 + 生态位分离」（fish 2026-09-20 23:4x 选定）

> **性质**：**设计输入**（非设计稿）——由 fish 裁定方向与要素，[本地开发] 出实现侧设计稿、[外鉴] 出文献侧。
> **前置**：E-030（A-连续）已证伪"凸 trade-off 单独足够"（捕食不盈利 ⇒ g16 被扫到 0.088）；R137 补充帖核算了捕食经济学。
> **纪元**：本档为**构造级变更 = 新纪元**（改成功率公式 + 目标选择 + 专性化阈值 + 数值），与既有各批不可比。

## 一、fish 定的要素（原话整理，不可增删）

1. **提高攻击成本 + 提高捕食获取能量**（风险化：高风险高回报）
2. **压低杂食收益**：让「捕食者收益 ≈ 被捕食者吃斑点收益 **>** 杂食收益」
3. **捕食基因阈值**：超过阈值 ⇒ **完全不能吃斑点**；同时**捕食成功率与获取能量大幅提升**
4. **数值平衡是硬要求**："不然必定偏向一方"
5. **成功率公式要改**：现"成功率 ∝ 攻击者能量占比"**不合理**，须**加入捕食基因差加权**（差大易成功、差小难成功）
6. **目标选择要改**：现"随机吃邻格"须改为**有选择性**（用户："这个机制需要改一改"）
7. 后期加**庇护所**

## 二、现状机制与问题（天平核查，供设计稿起点）

| 环节 | 现状 | 问题 |
|---|---|---|
| 攻击者选择 | `g16 > 0.3` 且 `prob < g16 × 0.2 × 饥饿度` | 越饿越攻击 |
| **成功率** | `clamp(能量比 × (0.5+g16×0.5), 0.1, 0.9)`，`能量比 = E_self/(E_self+E_prey)` | 🔴 **「饥饿陷阱」**：越饿越想打 × 越饿成功率越低 ⇒ 攻击惩罚饥饿者 ⇒ g16 被扫 |
| 猎物选择 | 邻格**均匀随机** | 无"鹰吃鸽"结构 ⇒ 无表型选择性 |
| 收益 | `transfer_ratio=0.4`（抢 40% 能量） | 成功率过低时期望 ≈ 0 |
| 成本 | `attack_cost = 0.1`（**`max_energy=300` 的 0.03%**） | ⚠️ 名义成本**几乎免费** |
| 实测 | 平均成功率 **3.02%**（5504 名义攻击 / 166 成功） | ⚠️ **分母口径疑虚高**：Rust 侧 5 个 `continue` 分支（`energy ≤ attack_cost`、`prey_list 为空`、`已被 mask` 等）都算"失败"⇒ 真实出手成功率被低估（**建议老工拆分母重报**） |

## 三、天平建议的实现形态（待老工/外鉴/内评复核）

### (a) 成功率公式（替换现式）

```
success = clamp( base + k_diff × (g16_self − g16_prey) + k_abs × g16_self , floor, ceil )
```
建议初值：`base=0.30 / k_diff=0.50 / k_abs=0.40 / floor=0.15 / ceil=0.85`

| 场景 | 计算 | 结果 |
|---|---|---|
| 高 g16 吃低 g16（0.9 vs 0.1） | 0.30+0.50×0.8+0.40×0.9 | **0.85（封顶）** |
| 同类互吃（0.9 vs 0.9） | 0.30+0+0.36 | 0.66 |
| 中等互吃（0.5 vs 0.5） | 0.30+0+0.20 | 0.50 |
| 弱者吃强者（0.3 vs 0.7） | 0.30−0.20+0.12 | 0.22 |

⇒ 满足 fish 的"**差大易成功、差小难**"，且**去掉能量比项**（消除饥饿陷阱）。

### (b) 猎物选择（替换均匀随机）

三案，建议**案 2**：
1. 硬门槛：只能攻击 `g16_prey < g16_self − δ`
2. **加权抽样（建议）**：`w_j ∝ exp(−β × g16_prey)`，β≈2.0 ⇒ 优先吃温和型但不绝对（保留随机性 ⇒ 可进化）
3. 能量优先：优先吃能量高的（"肥羊"）

### (c) 专性化阈值

- 在现有连续 `forage_tradeoff_k` 之上加**硬阈值**：`g16 > T`（建议 **T=0.6**）⇒ 吃斑点效率 = **0**
- ⚠️ **风险**：阈值以上若收益更高 ⇒ 全员跳上去（"全员捕食者"会真的发生，且这次是数值造成的）
  ⇒ **必须靠 §四 平衡把它锁成双稳**（否则单边统治）

### (d) 数值（含关键提醒）

| 参数 | 现状 | 建议 | 理由 |
|---|---|---|---|
| `attack_cost` | 0.1 | **1.0–1.5** | 相对 `max_energy=300`，0.1 等于免费；提高后还自带"有本钱才敢赌"的门槛（`energy ≤ attack_cost` 自动禁止攻击） |
| `transfer_ratio` | 0.4 | **0.7–0.8** | 配合风险化：赌赢了要大赚 |
| `forage_tradeoff_k` | 0（关） | **2.0–3.0**（凸） | 压低杂食 |
| 专性阈值 `T` | 无 | **0.6** | fish 要求 |
| `success_floor/ceil` | 0.1 / 0.9 | 见 (a) | —— |

## 四、数值平衡框架（fish 的硬要求 → 可执行判据）

**三方期望收益**（设计目标）：

| 表型 | 吃斑点效率 | 捕食成功率 | 期望总收益 | 目标 |
|---|---|---|---|---|
| 纯食草（g16≈0） | 1.0 | — | `R_herb` | 基准 |
| **杂食（g16≈0.3–0.5）** | 打折 | 低 | `R_mix` | **必须最低**（`R_mix < min(R_herb, R_pred)`） |
| **专性捕食（g16 > 0.6）** | **0** | 高 | `R_pred` | **≈ `R_herb`**（等收益 ⇒ 双稳/分化） |

**预注册判据（建议）**：
- 主：`g16` 分布**双峰**（配 10-bin 直方图 + 同方差 shuffle 置换零分布；**BC 单用已证失效 E-030**）
- 副：① 两峰均值稳定（各 ≥10 tick 连续）② `pred_frac` 与 `R_pred/R_herb` 比值 ③ **g15 是否随能量安全边际变化**（承接 R137 的成本×生存风险假说）
- 阴性结案条款：若仍单向扫荡 ⇒ 「数值侧单独不足以维持多态」入档
