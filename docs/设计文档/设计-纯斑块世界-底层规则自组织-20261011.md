## §二 现状盘点（真实代码锚点；供拍板时核对"我们其实有什么"）

### 2.1 现有"斑块"是三层东西 [代码]

1. **装置层（静态几何）**：`ResourceField` 的 `distribution="patchy"`——`patch_count` 个随机中心（独立 RNG 流 `patch_seed`，不消费引擎 RNG）+ 邻居扩散 `patch_radius` 层 → 二值 `_patch_mask`（`world/resource_field.py:165-180`）；斑块格与背景格两套容量/再生倍率（`:223-231`、`:552-576`）。
2. **旗舰档现状**：`--device s2` = 480×960 + **patches=1700** + pop=10000 + rgm=1.195 + **背景纯零产能**（`tools/device_presets.py:45-48`）——即现状旗舰已是一个"斑块世界（背景归零）"。
3. **生命周期层（rd）**：`ResourceDynamicsConfig`（默认关，`simulation/config.py:1206-1276`）给斑块"休耕/死亡/重生/同行轮作"——**但损伤全部来自"被吃量"**（`world/resource_dynamics.py:353` 起的 intake 累计）。
   🔴 **关键推论：无生物 ⇒ intake≡0 ⇒ rd 全链惰性**。所以 M0/M1 无生物模式里的 rd = no-op（这正是本稿 M1 的"动态源"只有"再生 + 光温 + 季节"的原因；rd 的斑块生命周期要等"有生物的世界"才活起来）。
4. **季节层（已实现）**：`LightConfig.tilt_rad/season_period`（默认 0=关，`simulation/config.py:46-63`）+ `light_sensitivity`（R196 光驱动再生，"绿浪"，`:88`）——**开季节 = M1 唯一的真动态分化源**。
5. **纬度层（已实现）**：`t_equator=30 / t_pole=-20` 温度梯度 + 面积权重（极点格容量 ≈ 赤道的 2.6%）——纬度已是一层"天然地形"，M1 的分型至少会复述它。

### 2.2 无生物运行的可行性 [代码]

- `initial_count >= 1` 硬断言（`simulation/config.py:357`）；现役探针先例 = 构造后置改 0（`experiments/smell_perf_probe.py:60`、`experiments/day_conservation_probe.py:65-76`）。
- N=0 时 `_step_population` 早退（`simulation/sphere_engine.py:3344-3347`）；资源再生在同一 tick 的**更早**步骤先跑（`:2895-2967`）⇒ 场照常演化。

## §五 M1：现状规则下的观察（控制组）

- **2×2 格**：{季节 off, 季节 on} × {seed 1..5}（rd 不设列——无生物下惰性，单独留一条 no-op 证据）。
- **观察**：见 §八。预测（写死，防事后解释）：
  1. 季节 off：全部斑块 ~80 tick 内填满容量（`regrowth_rate 0.5` × 温度因子 vs 容量 40 级）⇒ 类型仅由静态量（纬度温度、面积）分开 ⇒ **"分型"= 复述输入梯度**（这本身就是零模型本底）；
  2. 季节 on：候选三类动力学——**恒饱和 / 季节性脉动 / 极区永不饱和** ⇒ 真动态分型的第一层（但驱动 = 纬度 + 季节参数，仍属输入驱动）。
- **判据执行**：照 §八 全跑一遍——**即使预期阴性**：阴性库是本线最有价值的本底之一（M2 的"增量"要靠 M1 基线作差）。

## §六 M2：地形（承接 ENV-FIELD）

- **管线照 ENV-FIELD §二**：H（静态高程）→ 温度 lapse-rate 修正（新增小项）→ W（降水 − 蒸散 + 径流累积，气候态静态档）→ P 因子（`water_sensitivity`，默认 0 = 逐位等价）。
- **地形生成选型（本稿对 ENV-FIELD H2 的升级建议）**：
  - **推荐：3D 噪声在球面采样**——用 3D simplex/value-fBm 噪声在每格中心单位球向量上采样：**无极点失真、无经度接缝**（球面在 3D 里天然连续），比"经纬网格上跑 2D 噪声"干净一个量级 [通用技术]；实现 ≈ 百行独立模块 + 独立种子流。
  - ENV-FIELD H2（粗网格 + 拉普拉斯平滑 + 双线性插值）优点：复用 `world/smell_field.py:224-243` 已入库已过审实现；但其稿自注"球面近似 v1 口径"（极点/缠绕是近似）。
  - ⇒ 不做死锁：v0 用 3D 噪声（更干净），**保留 H2 为对照档**。
- **分型归因设计（关键，防止"复述输入"被误判为自发）**——三重对照：
  1. **平地对照**（H≡0 其余同）：分型必须消失，否则分型源另有其物；
  2. **地形置换零模型**（H 数值空间打乱）：边缘分布不变、空间结构破坏 ⇒ 类型的空间连贯性必须崩 ⇒ 证明"地理"而非"分布"在起作用；
  3. **seed ×5 重现性**（k* 与聚类中心）。
- **可选增量（默认关，单开关）**：季节之外的**稀有扰动**（干旱/火周期驱动斑块镶嵌移动——C4"稀有事件"维的候选）——独立开关，默认关，判读走独立预注册。
- **变更面（照 ENV-FIELD §五，实现时逐条打勾）**：乘子层（`resource_field.py:552-576`）+ 容量层（`:223-231`）+ 四算路守卫（**开档 = Python 单路 + 构造期 fail-loud 拦 Rust**，Rust 下沉后置）+ sparse/lazy 显式退场（manifest 一行）+ **不占基因位**（gene_count 不动）+ 快照面（静态派生场默认不进快照 ⇒ 零兼容风险）。

## §七 M3：河流（承接水文学最小形式）

## §八 判型协议（观察侧；引擎零标签）

1. **斑块定义（两条口径并列）**：
   - 口径 A（装置）：沿用 `_patch_mask` 连通域（对照用）；
   - 口径 B（观测，**推荐主用**）：场快照上的"高产能连通团块"（阈值连通域）——即使将来撤了装置 mask 也能立。
2. **特征向量（每斑块）**：⟨面积, 纬度, 平均 H/W/容量, 产能密度, 季节振幅, 相位, 饱和度时序特征（均值/方差/自相关）, 距河距离, （有生物后）rd 状态占比⟩。
3. **分型**：数据驱动聚类（k-means/GMM；k 由 BIC/轮廓系数 + **敏感性表 2–5 强制报告**）。
4. 🔴 **判据四条（全过才算"自发分型"）**：
   - C-a **跨 seed 重现**：k*≥2 且 ≥5 seed 聚类中心一致（ARI 均值 > 阈值）；
   - C-b **空间连贯**：类型标签空间聚集显著优于置换零模型（Moran's I / 邻接纯度）；
   - C-c **时间持久**：稳态窗内标签跨时间 ARI 高于零模型；
   - C-d **归因成立**：关闭对应机制（地形/河流）后 C-a..C-c 失败 ⇒ 分型可归因于该底层规则。
   （数值阈值归预注册锁，**不写在本稿里**。）
5. **零模型三件**：平地对照 / 地形置换 / 参数与 seed 横扫（§六）。
6. **反退化闸（照 ENV-FIELD §八-7 五道闸）**：群系标签不进引擎状态/判据前置；k 敏感性强制报；命名只在汇报层出现。
7. **供给守恒衔接**：开地形/河流后全球 Σ名义再生位移必须钳住（否则抹掉 C4"稀缺"前提）——容差数值归预注册（ENV-FIELD §二-5 归一化条款）。

## §九 外部先例（"模拟大自然"调研摘要）

- **自组织植被斑块（与"斑块自发分型"最直接的先例）** [文献]：半干旱区 tiger bush / 条带植被——水从裸土再分配到植被斑块（局部正反馈）⇒ 斑点/条带/迷宫纹；"格局是气候与人类影响的指纹"（Barbier et al. 2006；Deblauwe et al. 2012 条带迁移；Meron 2012 综述）；仙女圈（PNAS 2016）与 PNAS 2025"自组织=旱地韧性机制"证明：**无潜在异质也能由反馈产生类型化空间格局**。
  ⇒ 对我们的意义：(i) 若要"无地形输入也分型"，学的是这条线（M4+ 备选）；(ii) 其定量方法（斑块形状/大小/边界复杂度/连通性/谱分析）可直接借用到 §八。
- **DEM 水文 / 河网提取（M3 算法库）** [文献]：单流向 D8/Rho8/DEMON/D∞ 与多流向法（Holmgren 1994）；洼地/平坦区处理；Jenson & Domingue 1988；O'Callaghan & Mark 1984；自适应流量分配指数（Qin et al. 2007）；中文综述《基于 DEM 的流域特征提取综述》。
- **地貌演化模型 LEM（"地形本身会演化"的路径）** [文献]：河道下切（stream-power）+ 坡面扩散是最简方程族（Chen, Darbon & Morel 2014 综述；FastScape/CHILD 系）；**我们的取舍**：构造期给一张地形，不模拟造山——LEM 只借"坡面/河道侵蚀"概念备用。
- **Daisyworld（经典先例）** [常识]：两种反照率雏菊 + 同质规则 ⇒ 自发温度调节（Watson & Lovelock 1983）——"有限死规则 ⇒ 自平衡"的教科书例，与本线精神一致（我们做纯场版，无生物）。
- **总取舍**：全部借"机制最小形"，**不引外部代码/依赖**；一切以"无基因位、物理量、可逐位对账"为准。

## §十一 土地雷与守卫（实现前逐条过）

1. **极区拓扑**：`neighbors()` 极区有向非对称（AGENTS.md landmine）⇒ 涉及邻域的场生成/汇流必须回退全量或显式豁免。M2 用 3D 噪声**完美绕开生成步**；M3 汇流显式处理（§七）。
2. **等距投影失真**：面积权重已有；距离一律球面距离（《设计-多位编码v0》教训）；`patch_radius` 是"邻居层数"不是距离。
3. **sparse_fields**：开档后 lazy 前提破坏（ENV-FIELD §五-4 已论证）⇒ **显式退场 + manifest 一行**；新写点必须带 `# sparse:` 标注（AST 守卫 `tests/test_sparse_write_guard.py`）。
4. **快照**：新场优先做"静态派生量"（不进快照，零兼容风险）；动态场才升 `SNAPSHOT_VERSION`（现值 3，`sphere_engine.py:6330`）。
5. **RNG**：地形/河流随机初始化走**独立流**，不消费引擎 RNG（`patch_seed` 先例 `resource_field.py:167`）；流名 + seed 进 manifest。
6. **Rust 路径**：开档 = Python 单路 + 构造期 fail-loud（H3 型先例 `sphere_engine.py:1026-1036`）；Rust 下沉为独立卡（函数级 + 引擎级双对拍）。
7. **逐位等价**：全部新开关默认关 ⇒ 旧档 digest/C7 不动（回归安全红线，C7 基线 `(574887, 11266.746993)`）。
8. **术语**：见 §〇（"纯斑块"双义已澄清）。
