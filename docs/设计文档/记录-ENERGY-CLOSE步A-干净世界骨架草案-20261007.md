# 记录 · ENERGY-CLOSE 步A ③ 干净世界骨架草案（A2 闭环单测 与 双臂 S0 共用）

> 产出者：澜舟（开发·二线）｜2026-10-07 深夜｜分支 `task/ENERGY-CLOSE`（基线 `edb2f61`）
> 性质：**零行为面草案**——只定义接口与目录，不改 main、不动现役引擎、不开卡动工。
> 缘起：立场帖 §三/§五 提出的复用建议——A2 的"合成闭环世界"与双臂 S0 的"≤500 个体秒级小世界"
> 本质是同一个东西（**一个能逐 tick 说清每单位能量归属的最小世界**），一次工两份产出，可省 2–3 人日。
> 归属：S0 的**实验设计**归镜（2×2 双臂）与砚（判据），本件只负责**工程骨架**。

---

## 一、要解决的问题

现役 `SphereEngine`（6,671 行）不能直接当 A2/S0 的容器，四个硬约束：

1. **不可枚举的状态面**：5 个质量/能量载体 + 20 处写点 + 67 个 `np.zeros` 状态数组 ⇒ 守恒断言写不出来（见同批 `通道枚举` 文档 §〇/§二）。
2. **性能墙**：正式档 480×960 下网格固定下限 31.4–61.2 ms/tick，与个体数无关 ⇒ "秒级小世界"必须换网格档，不是换参数。
3. **RNG 流耦合**：`use_sim_core=False` 下 Python 路径每 tick 消费顺序与基因/装置绑定 ⇒ S0 双臂"同 RNG 流"是硬条件，现役引擎里做双臂必须冻结全部装置开关，等于重造。
4. **默认关等价门**：任何新装置默认关 ⇒ 现役世界里 A2 永远只能在"旧装置量级报告"档跑，拿不到硬零门。

⇒ 结论：**A2 硬零门 + S0 双臂都必须活在一个新的小容器里**，这个容器就是本草案。

## 二、定位与边界（先说不做什么）

| 做 | 不做 |
|---|---|
| 5 账户显式化（E/S/G/C/F 或等价物）为**类型化字段**|复刻现役引擎的基因/行为面|
| 逐 tick 通道账（注入/散逸/逃逸三类，接口层强制填写）|下沉 Rust（骨架阶段纯 Python）|
| 双臂同构（一次构造、两个参数化分支、同 RNG 流）|任何"涌现"判据的实现（归砚/镜）|
| 秒级：500 个体 / 10k tick 在 1 秒内跑完|兼容旧快照格式（骨架无存档语义）|
| 变异即变红（每通道带可注错的计数器）|接 `experiments/` 的 CSV 列面（sidecar 自成一格）|

🔴 **骨架不是新引擎**。它存在的目的只有两个：给 A2 一个能设硬零门的容器，给 S0 一个能双臂对拍的容器。
若重构裁定成立，它是内核原型机的**起点**；若不成立，它退回为 A2 的单测夹具——两种结局都有用，这是本件的低赌注性质。

## 三、接口草案

目录：`s0_kernel/`（长期分支，**不进 main**，合并候 PI）

```
s0_kernel/
  __init__.py
  accounts.py      # 5 账户 + 单位/换算域（质量 vs 能量）唯一真源
  channels.py      # 通道注册表：每条 = (id, 类型∈{INJ,TRF,DIS,ESC}, from账户, to账户, 站点标签)
  world.py         # 最小世界：网格(可配 rows/cols) + 个体数组 + step()
  books.py         # 三账本：independent ledger，tick 首末实测 ΔΣ + 逐通道累加
  arms.py          # 双臂构造器：同 seed → 两条配置路径，RNG 流分离且可断言同流
  closed_loop.py   # 合成闭环世界预设（零逃逸：INJ≡DIS，供 A2 硬零门）
```

核心抽象三条：

```python
@dataclass(frozen=True)
class Channel:
    cid: str            # "photo" / "regrow" / "corpse_cap" / ...（对齐通道枚举文档编号）
    kind: str           # "INJ" | "TRF" | "DIS" | "ESC"
    src: str | None     # 账户代号；None = 外部
    dst: str | None     # 账户代号；None = 系统外
    site: str           # 现役引擎行号锚（"E1@:5059"），便于把骨架结论回灌主引擎
    signed: bool = True # 🔴 带符号账：ESC/DIS 必须以正数记"离开量"，不得写进 TRF 抵消
```

```python
class World:
    def step(self) -> dict[str, float]:
        """每个写能量的动作必须经 self.book.move(ch, amt) / self.book.inject(ch, amt)
        登记后**再**改数组；未登记的写点 ⇒ 当场 raise（fail-loud，新工具四律）。"""
```

```python
class Books:
    def delta_sigma(self) -> float        # tick 首末实测总量差（不读通道账，独立）
    def from_channels(self, kind) -> float # 只加该 kind 的通道账（不读实测，独立）
    def close(self) -> float              # delta_sigma − (INJ − DIS − ESC)；闭环档必须 == 0
```

🔴 两条**独立性**纪律（照镜 A1/A2 分离的工程落点）：`delta_sigma()` 内部禁止调用 `from_channels()`，
反之亦然；`close()` 是唯一的会合点。骨架层用私有属性 + 一条单测断言"两者源码不互读"防退化。

## 四、性能预算（为什么"秒级"做得到）

| 项 | 正式档现值 | 骨架目标 | 依据 |
|---|---|---|---|
网格档|480×960 = 460,800 格|**≤ 30×60 = 1,800 格**|网格固定下限 31.4 ms/t 主要来自 46 万格的场运算；缩到 1.8k 格 ⇒ 场成本 ≈ **1/256**|
个体|稳态 ~2 万|**≤ 500**|边际成本 11–14 µs/个体/tick ⇒ 500 个 ≈ **5.5–7.0 ms/tick**|
通道账|无|-|每 tick 8–11 个 `sum()` 级操作 ⇒ **<0.1 ms**（实测基准：10k 个体求和 0.0038 ms，`invariant_cost.json`）|
**合成**|61.2 ms/tick（2 车道稳态）|**目标 < 10 ms/tick**|⇒ 10k tick ≈ **<100 s**；500 个体 1k tick ≈ **<10 s**|

⚠️ 诚实标注：`<10 ms/tick` 是**外推**（网格成本按面积线性缩），未实测；骨架第一版交付时
必须带一张自测表把它转成 `[实测]`。云启（2c/1.9G）单核即可，不需排队 ⇒ 与批跑窗口零冲突。

## 五、双臂 S0 的挂载点（不越镜/砚的界）

- `arms.py` 只保证**机制**：同一 `seed` 派生两条独立 rng，`armA`/`armB` 只在**一个被测通道**上不同，
  其余参数逐项相等并由 `assert_arms_comparable()` 硬校验（含"同 RNG 流形制"）。
- 双臂**测什么**（私有信息载体的有无）**不由本骨架定**——等镜 §三 的 2×2 设计稿与砚的判据。
- 🔴 预注册红线（立场帖 §三 原话）："`两臂皆否 ⇒ S0 尺度不可裁决`"这一出口必须在跑之前写进预注册，
  骨架提供 `arms.py::declare_inconclusive_exit()` 把它变成代码里的一句，而不是事后解释。
