# 设计：R97「增益校准档」— oracle 仪器校准的最小变更

> 提出人：`[本地开发]` | 时间：**2026-09-15 23:0x（Asia/Shanghai）** | 依据：**R97**（所有者 22:24 帖，条件预授权）
> 性质：**设计稿（未实施）**。流程按 R97：**① 本设计 → ② 上板（所有者核）→ ③ 预注册 → ④ 实施 → ⑤ C 重跑**
> 边界（R97 原文）：G-A 只问"**仪器能否检出「有净收益的通信」**"，**不**检"代价信号／障碍原理"假设。

---

## 一、目标与不可逾越的边界

| 项 | 内容 |
|---|---|
| **目标** | 让 oracle 阳性对照能达到 `ratio ∈ [1.2, 1.5]`（>1 ⇒ 发送者**有净收益**），从而 G-A 问的是"仪器能否检出**正的**选择差" |
| **为什么必须是 >1** | `ratio = 1` 时发送者净收益 = 0 ⇒ 选择差 = 0 ⇒ 漂变主导 ⇒ **判定点落在中性边界上，结论被目标位置决定**（R88 的立规理由） |
| **绝对边界** | 本档**登记为仪器校准档**，**绝不参与任何科学结论**；不得写进"信号有无价值"的论证（R89） |
| **不做** | 不改科学臂的默认参数；不改 G-A 的"⑤ ∧ ⑥"结构；不动 D-24 已判结论（R98 确认不重开） |

---

## 二、为什么必须改构造（当前不可达）

`[实测]`（D-27④-B，修复版 12 run）：

- 修复 F-R16 后，**`ratio ≤ 1` 由 C-9 保本封顶严格保证**（回归钉死）；实测最大 **0.9283**。
- C-9 额度式（`sphere_engine.py`）：`budget = SIGNAL_COST × emit_count[id] − oracle_gain[id]`
  ⇒ 逐发送者终身回馈 ≤ 成本 × 发射数 ⇒ 求和 ⇒ `ratio ≤ 1`。
- ⇒ **无论 `donation` 取何值，`ratio` 都到不了 1.2**；剂量扫描已证实（线性外推 d≈3.94 不可采信：R²=0.67、RMSE=0.094、且剂量-响应**非单调**）。

⇒ 结论：**必须改"额度式"本身**，而不是继续调 `donation`。

## 三、最小变更设计

### 3.1 显式开关（唯一新参数）

```python
@dataclass
class OracleConfig:
    ...
    gain_multiplier: float = 1.0     # 🔧 R97 增益校准档：额度倍数。1.0 = 现状（保本封顶，逐位兼容）
```

- **默认 1.0** ⇒ 关档时行为与现状**逐位一致**（沿用 `reputation_weight` / `oracle.enabled` 的先例：新增参数必须有默认值，`from_dict` 旧存档回退）。
- CLI：`a4_verify_capacity.py --oracle-gain-multiplier`（**仅 `--arm oracle` 生效**，沿用已有守卫模式：非 oracle 臂传了**直接报错**，不静默忽略）。

### 3.2 额度式变更（一处）

```python
budget = gain_multiplier * EMISSION_COST * self._emit_count[safe] - self._oracle_gain[safe]
```

⇒ 结构性上限由 `1.0` 变为 **`gain_multiplier`**：
`ratio = min(gain_multiplier, 转化率 × donation / SIGNAL_COST)`

### 3.3 禁静默改科学臂（三重防线）

| # | 防线 | 内容 |
|---|---|---|
| a | **CLI 守卫** | 已有：非 `oracle` 臂传剂量/增益参数 ⇒ `SystemExit`（不静默 no-op） |
| b | **summary 自证** | `switches` 记录 `oracle_gain_multiplier`；manifest 增 `is_calibration_arm = (gain_multiplier != 1.0 or donation < SIGNAL_COST)` |
| c | **C5 断言** | 校准臂必须**显式登记**；未登记而 `gain_multiplier != 1` ⇒ **硬失败**（防"悄悄改坏科学臂"） |

### 3.4 C5 语义更新（v2）

| 臂类型 | 判据 |
|---|---|
| **科学臂**（`gain_multiplier == 1.0`） | 保持现状：`donation ≥ SIGNAL_COST`（否则保本不可达 ⇒ 该臂**不得用于 G-A 阳性判定**） |
| **校准臂**（`gain_multiplier > 1.0`） | 🔴 `gain_multiplier ∈ [1.2, 1.5]`（**超出区间即失败**）；且必须带 `is_calibration_arm=True` |

> 说明：校准档的 `ratio` 上限 = `min(m, 转化率·d/SIGNAL_COST)`。若 `m > 1.5` 会把对照做得过强（失去"最小充分"意义），故**上限也钉死**。

### 3.5 新档下的可达区间与标定式（`[实测]` 参数代入）

`[实测]` D-27④-A 转化率 c（= applied/emissions）：`d=0.674→0.102`、`1.0→0.201`、`1.5→0.132`、`2.0→0.118`（**随区制波动，非单调**）。

| m | d | 预期 `ratio = min(m, c·d/0.1)` | 落在 [1.2,1.5]？ |
|---|---|---|---|
| 1.5 | 1.0 | `min(1.5, 0.201×10) = 1.5` | ✅ |
| 1.5 | 0.674 | `min(1.5, 1.02) = 1.02` | ❌（转化率低时够不到） |
| 1.3 | 1.0 | `min(1.3, 2.01) = 1.3` | ✅（更稳） |
| 1.2 | 1.0 | `1.2` | ✅（贴下限） |

⇒ **建议标定点：`donation = 1.0` 固定，`gain_multiplier = 1.3`**（预期 `ratio ≈ 1.3`，位于区间中部）。
⚠️ 因 c 在 seed 间波动大（本批逐 run 0.047–0.36）⇒ **必须实测复核**：跑 3 seed，若 `ratio` 未落 [1.2,1.5] ⇒ 在区间内微调 m（**≤2 轮**，标定≠改判据）。

## 六、风险与诚实提示

| 风险 | 说明 |
|---|---|
| **"校准档"被误引用为科学结论** | 最大风险。防线 = §3.3 三重 + R89 措辞纪律 + 板上登记 |
| **m 抬上去后生态门** | 回馈变多 ⇒ 可能改变种群动态（O-5）。§四 的批必须同时记 N/pred_frac，**并分层报**（R38③） |
| **转化率非单调** | §3.5 的预期值可能不中 ⇒ 允许 **≤2 轮**区间内微调，但**不得**借机改判据 |
| **与 R88"不自行实施构造级变更"的关系** | R97 已**条件预授权**本档；若 `fish` 否决 ⇒ **原样回退**（设计稿即作废，不留半成品） |
