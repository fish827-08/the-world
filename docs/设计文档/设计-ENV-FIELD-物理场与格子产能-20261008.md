## §〇 一句话结论

把"斑块"从**人为二值层**（30 个种子 + 半径扩散 + 两套倍率）换成**连续物理场**（高程 → 气候态水分 → 与既有光/温合成格子产能 `P`），在工程上有**一条唯一落点**（`resource_field.py:552-576` 的 `np.where(pm, …)` 乘子层 + `:223-231` 的二值容量层）和**四条算路**（Python 全场／Python 惰性／rd 段／Rust 两函数）；
性能上只要把新场定成**构造期静态场 + 每 tick 一个乘子**，代价落在 ≈ **+0.2~2.5 ms/tick** 量级（我实测：乘子 0.16 ms、追加 clip+pow 2.3 ms；对照引用值 130 ms/tick ⇒ ≈ +0.1~1.9%）⇒ **过得了轻舟 C1 T10 门（≤1.10）**；
真正贵的是"每 tick 重算水场"（实测邻域扩散 16.3 ms/tick ≈ 2.1×），本稿**不把它做成默认档**，并给出它若必须存在时的唯一合规形态（照气味场三条红线 ⇒ ÷s² ÷k ≈ 0.06 ms 级）。
工程量主源不是那几毫秒，而是**双路径对拍重建 + 行为链替代（记忆觅食目标）+ 存档兼容**——这三项在形态 (a) 下可以后置、在形态 (b) 下同批全部到期（对比见 §六）。

## §二 场定义（四件套 v0）

**总原则**：每张场都是 **① 构造期算一次 或 ② 每 k tick 算一次**，绝不"每 tick 全场稠密重算"（这条不是我发明的，是项目已审门通过的红线，见 `simulation/config.py:1300-1301` 气味场条款）。

### 2-1 高程场 `H`（静态）

- **是什么**：全球连续标量场，`H: cells → ℝ`，均值 0、幅度可调（抽象单位，不冒充米）。
- **来源（二选一，我默认推荐 H2）**：
  - **H1 球谐叠加**：`H = Σ_{l≤L} Σ_m A_lm Y_lm(θ,φ)`（随机相位/幅度谱）。优点：解析、平滑、可讨论"特征尺度"；缺点：要引 `sph_harm` 一类设施（新依赖），构造期 `O(n_cells·L²)`。
  - **H2 粗网格 + 球面插值（推荐）**：在 `rows/s × cols/s` 粗网格上生成噪声场，做 k 次**粗网格五点拉普拉斯平滑**，再用双线性插值回全分辨率。优点：**复用项目已入库且已过审的同族实现**（`world/smell_field.py:224-230 _laplacian_coarse` 经度周期/纬度夹取 + `:234-243 _interp_cells`），零新数学设施、成本 ÷s²；缺点：频谱被粗网格截断（特征尺度 ≈ s 格，这恰好是要的"地形尺度"语义）。
- 🔴 **RNG 纪律（新工具四律之一）**：H 的随机初始化**不消费引擎 `self.rng`**，走**独立派生 `default_rng`**（现役先例 = `resource_field.py:167/218` 的 `patch_seed` 独立流）。理由：消费引擎 RNG ⇒ 同 seed 下全部既有批的随机序列位移 ⇒ 逐位等价门与历史读数全废。
  - ⇒ 待裁点 7：**复现性口径变更**（格局来源从 `patch_seed` 换为"场方程参数 + 独立流名"）归砚，卡规"复现性仅在含随机初始化时归砚"在本条成立（H2 含随机粗网格）。
- **消费**：水分场（§四）；**不进**移动/穿越/感知（纪元二 v0 不做地形障碍——`sphere_engine.py:1568` 现注释"不做地形障碍过滤，球面无障碍"是既有设定，改它属行为变更，本稿不提）。

### 2-2 水分场 `W`（气候态，静态档默认）

`W = 净收入(降水 − 蒸散) + 径流累积`，逐格连续、非负。

- **降水 `Pr`**：`Pr = 持水能力(T) × 抬升修正(H)`。
  - 持水能力用简化饱和曲线（Magnus/Tetens 型 `a·exp(b·(T−T0))`，只用既有 `lt.temperature(cells, tick)`）；
  - 抬升修正 = `H` 的局部坡向/高度项（粗网格差分，**不引入 `np.roll` 作正式邻域**，见 §三-2）；
- **蒸散 `Et`**：`Et = g(T, 光照)`（用既有 `lt.illumination`/`photoperiod`，不新建光场）。
- **径流累积 `A`**：顺 `H` 降坡把 `Pr−Et` 往下游汇（D8 单流向为 v0；多流向 TBA 列为可选），`A` 大的格 = 汇/河道，`A≈0` 且 `Pr−Et` 负 = 干旱。
- **更新频率**：默认档 = **构造期气候态一次**（用年/季平均的 LT，不逐 tick）⇒ 每 tick 成本 0。动态档（水分随季节逐 k tick 演化）= 可选，见 §四-3 与 §七-3。
- 🔴 `W` 是**状态量吗**：默认档不是（静态派生量，不进快照 ⇒ 破等价风险为零、存档面零改动）。动态档才是 ⇒ 必须进快照（§五-5），本稿默认档避开这一整块工程量。

### 2-5 格子产能函数 `P`（唯一新增机制本体）

**形制刻意与既有两项同构**（照 `resource_field.py:536-551` 的"clip→pow→乘"写法）：

```
growth(cell,tick) = regrowth_rate
                  × T因子          # 既有：clip((T+20)/20,0,1)^temp_sensitivity
                  × L因子          # 既有：clip(ill,0,1)^light_sensitivity（可选归一化）
                  × Water因子      # 新增：clip(W/W_ref,0,1)^water_sensitivity
                  × (Budget因子)   # 待裁点 1，v0 不启用
```

- 🔴 **默认关逐位等价**：`water_sensitivity = 0.0` ⇒ `Water因子` 恒 1 ⇒ 整块跳过（照 `config.py:85/88` 与 `light_sensitivity` 完全同型的"回归安全"设计）。这是新工具四律第 1 条，也是 C7 digest 不动的前提。
- **容量连续化**（与 `growth` 同批）：`_capacity = base_cap × k(W)` 替换 `resource_field.py:223-231` 的三档 `np.where(patch_mask, ×3.0, bg_low, bg)`。
  - `k(W)` 形如 `clip(W/W_ref, 0, k_max)^cap_sens`，默认档 `cap_sens=0` ⇒ 恒 `1` ⇒ 逐位等价。
- 🔴 **归一化条款（本稿新增的硬要求，数值归砚）**：开档后 **全球 Σ名义再生 的位移必须被钳住**（候选实现 = 照 `light_normalize` 先例 `config.py:89` 做全球均值归一，或显式给出 K 尺子重标定）。

## §四 水文学最小形式（v0 = 三件，可判别为先）

1. **降水**：`Pr = 持水(T) × 抬升(H)` —— 只用既有 LT 与 `H`；无新常数以外的自由参数（`a/b/T0` 三个 + `H` 幅度）。
2. **汇流累积**：`A = accumulate_downstream(Pr−Et, H)`（D8）。这是"河流从物理场涌现"的最小可判别形式：**给定 H 与气候态，河是算出来的，不是摆出来的**。
   - 实现成本：**构造期一次** `argsort` 顺坡序 = 我实测 **8.2 ms @460,800**（一次性）；逐 tick 重排 = 8.8 ms ⇒ **静态档下这条不进 tick 预算**。
3. **河道/水体（可选档，默认关）**：`A > A_thr` 的连通带 = 命名层对象；`W += 汇水项`。
   - 动态水文（水分随季节逐 `k` tick 演化）**不是默认档**。若 PI/鱼要它：唯一合规形态 = **照气味场三条红线**（`config.py:1296-1301`）：降采样 ÷s² + 每 k tick ÷k + 源注入稀疏 ⇒ 我实测全场 4 轮邻域扩散 16.3 ms 折算 ≈ **16.3/64/4 ≈ 0.06 ms/tick** 量级。🔴 但注意：气味场那套的"源稀疏"在这里**不成立**（降水是全球性源，不是点源）⇒ 实际只有 ÷s² ÷k 两个因子生效，且动态水会改变 `W` ⇒ `P` 逐 tick 变 ⇒ **惰性再生的"净格恒静"前提二次破裂**。这条要在实现前与轻舟同算（她 `sparse_fields` 线的立论基础之一被本机制触碰）。
4. 🔴 **"不硬编码河=肥沃带"的落字方式**：全链路里**没有**任何 `if 河道: 产能×k` 的分支；河只体现在 `W` 的值里，`W` 只通过 §二-5 的 `Water因子` 进产能。审门可 grep 验证：`river`/`biome`/`forest` 一类命名**零命中**引擎状态与判据路（砚 §三-3 五道防退化硬闸的同一手法）。
