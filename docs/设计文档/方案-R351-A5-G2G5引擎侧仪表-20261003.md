## 〇、TL;DR（三句话）

1. **G2（码本共享率）**：算法已有权威实现（`observatory/statistics.py:132 codebook_convergence` ＋ 唯一权威入口 `d2_metrics` `:308/:323`），码本已进快照（`:6167/:6401`）。缺口只在**探针接线**（M1 批探针每采样点调一次）＋**n/a 标记**（`arbitrary_codebook=False` ⇒ 恒 1.0 无判别力 ⇒ 报 n/a 而非 1.0）⇒ **零引擎改动**。
2. **G5（行为改变率）**：引擎已有**整套反事实探针**（D-18 ⑥，`signal_response_stats() :5309`：Δ_full／Δ_content／暴露率）。**硬约束**：只活在「`info_structure.enabled` ∧ `perception_radius=4` ∧ `softmax_tau>0`」的 softmax 分支（`:4324-4354`），其余档 Δ 恒 0（**"假 0"而非"没测"**；门控臂有 fail-loud 守卫拦截 `:1488-1505`，普通批无守卫 ⇒ 靠口径标记兜底）⇒ **G5 可读性完全取决于 M1 装置怎么定**：
   - 装置 = softmax+asym 档 ⇒ 开 `measure_signal_response=True`，**零引擎改动即有 G5**（方案 A）；
   - 装置 = argmax 档 ⇒ 需新增 argmax 反事实（方案 B：3 个 Python 决策点 + 计数 + 测试）；
   - 装置 = Rust 路径 ⇒ 报 n/a 先例（`:5714`）或 `movement.rs` 同步实现（方案 C，成本最高，不建议本期）。
3. **附带发现（读码级、证据确凿）**：`_resp_delta_content_sum` **未进快照** —— 存档只存了 Δ_full 四项（`:6256-6259`），恢复同理（`:6585-6588`）；而 Δ_content 在同一探针里逐 tick 累加（`:4347`）、用于 `resp_b_content_delta`（`:5319`）。⇒ **续跑后该读数偏低**（分母继续涨、分子清零）＝ `:6250-6252` 注释点名的 **F-R7 同型坑**。建议随 G5 实施批一并修（存＋恢复＋旧档回退＋靶向测试）。

### 2.1 已有资产：D-18 ⑥ 探针家族（反事实＝真仪表）

## 三、方案（impl-ready 规格；待 §四 对齐点锁定后实施）

### 方案 A（前提：M1 装置可走 softmax+asym 档）—— 零引擎改动

1. **探针接线**（一处）：M1 批探针每采样点追加
   `signal_response_stats()`（7 项，`:5320-5331`）＋ `d2_metrics()`（含 `codebook_conv`）⇒ CSV 增列。
   ⚠️ 两函数均返回**累计口径**；窗口差分留给后处理（与 s2 探针既有的累积量处理同法）。
2. **预注册写死**：装置 = `enabled ∧ radius=4 ∧ τ>0 ∧ use_sim_core=False ∧ measure_signal_response=True`；含 R6.8 两臂开关断言。
3. **冒烟（R6.6）**：同 seed 同 tick，`measure_signal_response` True/False 两跑 ⇒ **digest 全等**（纯观测证明）；`exposed=0` ⇒ 输出 **n/a 而非 0**。
4. **成本**：探针每次暴露决策多 2 次小 softmax 重算（`:4327-4345`，R123 已付此价）＋ 每采样点一次码本聚合 ⇒ 相对 run 时长可忽略。

### 方案 B（M1 装置 = argmax 档）—— 小改 3 个 Python 决策点

- **新增反事实**（纯观测，与 ⑥ 同规格）：
  - `flip_full`：score 去掉两通道后的 argmax ≠ 实际 pick；
  - `flip_content`：只去内容项后的 argmax ≠ 实际 pick。
  - 平局判据沿用同式（`max−min < 1e-9`）＋ 同 `rand_choice` 取平局（保确定性）。
- **落点（3 处同式，作全仓一致性写入规格）**：
  1. 参考循环：score 组装 `:4116-4168` → 选择 `:4355-4358`；
  2. 批量快路径 `_move_decide_batch`：score `:3161-3192` → pick `:3193-3199`（只对 `has_sig` 行）；
  3. 记忆 v2 批量路径 `_move_decide_v2_batch`：score `:5629-5649` → pick `:5650-5656`。
- **语义说明（两者不可混）**：argmax 档下翻转率**就是**确定义 "行为改变率"（R43 禁用翻转率是**softmax 采样语境**下的纪律，不适用于真 argmax 档）。
- **计数与导出**：新增计数（沿用 ⑥ 风格）＋并入/并列 `signal_response_stats`（新字段双端存档，避免 §〇.3 同族缺陷）；靶向测试 4 例（有信号/无信号/平局/关档）+ **开/关仪表 digest 全等**对拍。

### 方案 C（Rust 路径）—— 本期不建议

- 本期报 n/a（先例 `:5714`）；若未来 M1 必须走 Rust ⇒ 在 `movement.rs` 实现同款反事实＋重编＋Python/Rust 对拍，成本最高。**建议：M1 预注册直接避开 Rust 档**（G5 是 M1 判据之一，不值得为它背 Rust 实现）。

### 附加件：R4.6b「信号省路效应」（v1.4 `:371` 建议入 M1 辅助读数）

- **口径**：按"决策时暴露（视野内 ±）"分组，累计每组的**移动步数/移动耗能** ⇒ 后处理组间均值差（"附近有信号的兽走得更省"）。
- **成本**：决策点 O(1) 累计，零机时。
- ⚠️ **定义陷阱**：暴露必须按**决策时候选集**判定（`nb` 上的 `nb_sigs`），**不得**用"移动后落点有信号"（那是结果不是条件）。
- 建议：随方案 A/B 一并接线，**不进 M1 主判据**（v1.4 定位是辅助读数）。
