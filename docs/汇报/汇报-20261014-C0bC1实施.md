### 3.4 性能实测 `[实测]`

## 四、待裁项（发现与报告设计冲突，按纪律停下报 A/B/C，未自行改设计）

### A. 🔴 盐湖恒 0 —— §5.2 的淡/咸二分在本模型下结构退化 `[实测+推断]`

* 现象：s2/seed42 及陆比 0.2/0.3/0.5 三档、4 个 seed 下 `salt_lake_cells` **恒 0**；
  `inland_roots`（不达海的链终点数）在 s2 = **0**（60×120 微型档 = 6）。
* 根因（数学事实，非实现缺陷）：填洼面上每格接收者链 `filled` **严格下降** ⇒ 链终点只能是
  「海洋格」或「非海洋极点根」；而 priority-flood 保证**每个洼地都有溢流口** ⇒ 湖自身永不是终点。
  于是「溢流链是否达海」这条判据在本模型里几乎恒判「达海」（淡水）。
  若改用原始地形面判闭合性，则**洼地定义即"无下坡出路"** ⇒ 会全判盐（同样退化）。
  真实的内流湖需要**水量收支**（入不敷出 ⇒ 终端湖），那属于 §5.3 机理注/C4a-2 的动态蒸发约束。
* 选项：
  * **A1（现实现，零设计偏移）**：保持字面规则，盐湖层本期恒空并在汇报中标注「结构不可达」。
    代价 = §7-② 里程碑判据「盐湖标签齐全」不达标。
  * **A2（加一条水量判据）**：`盐湖 = 湖格 ∧ 流域产额 < 蒸发需求`（§2.2-⑤ 水桶一句话规则的静态形）。
    代价 = **新增一个自由参数/口径**，与 §5.2「只需贴标签层」不同 ⇒ 需 owner 批准口径变更。
  * **A3（本期撤盐湖标签）**：把「湖」只作为单一水体层交付，淡/咸二分推到 C4a-2 批（与判据②一起测）。
* 会话建议 = A1（本批已交付）+ 把 A2 列进 C4a-2 设计要点；**请裁**。

### B. 🔴 band「面积权归一=1」与「全球产水总量不变」不可同时成立 `[实测]`

* 验收原文把两件事写在一起：「band 面积权归一=1（全球产水总量不变）」。二者互斥：
  `ΣPr = Σ q(T)·(1+oro·H)·band(φ)` 中 q 与 band 都是纬度的**正相关**函数 ⇒ 归一乘子不能保持 ΣPr；
  叠加 `yield = max(Pr−Et, 0)` 的 clip（谷被截在 0，不能再降）⇒ 实测 **Σ 产水 +17.7%**
  （`w_mean` 12.0857 → 14.2203；C0b+C1 档 15.8201）。
* 选项：**B1（现实现）** 面积权归一=1（与 f_g/f_c 同纪律，判据字面达标），把 Σ 位移如实呈报；
  **B2** 改按 ΣPr 加权归一（ΣPr 恒等），则 band 的 AWM ≠ 1（字面判据不达标）；
  **B3** = 二者不可兼得（一个乘子不能同时满足两个正交归一条件），需 owner 指定以哪个为准。
* 会话建议 = B1 交付 + 请裁是否改 B2；**K 尺子/供给位移对生态门的连带影响留给跑批批次的预注册处理**。

### C. ⚠️ 守恒①「海陆比恒等，容差 1e-9」在离散网格不可严格 `[实测]`

* 分位阈值必然落在某格上 ⇒ 实现陆比与目标的残差下界 = 该格面积占比（s2 实测 9.5e-7）。
* 本批拆成两条可严格校核的形式：**①a** 海比 + 陆比 == 1（分划互补，残差实测 **0.0** ≤1e-9）；
  **①b** |实现陆比 − 目标| ≤ 单格面积（并作为扫参读数上报）。验收 ±0.5% 远端达标。
* 只需 owner/复核认可这条口径改写（无代码改动）。

### 另两项实施口径澄清（代码现实逼出，非设计变更，一并报备）

1. **极点行必须与海洋格一起作 priority-flood 种子**：`_nb_table` 里极点行除规范槽（col 0）外全是
   `-1` 占位，且相邻纬度带经 `rc_to_flat` 坍缩只指回规范槽 ⇒ 非规范极槽在邻居图上**孤立**，
   只按 §5.2 字面「种子=海洋格」构造会触发既有 fail-loud（"仅覆盖 M/N 格"）。
   与旧口径的本质区别 = 极点不再决定全球填洼面（不再产生 50.8% 伪极海），只在极地点自身高程处
   作局部出边 ⇒ 不达海的洼地由此成为内流盆地。已写进模块头「C0b 的结构性近似」+ 提交信息。
2. **「湖 = filled > H_m」的判据面**：实现用 `filled > h_routed + 1e-12`（即 §5.2「复用语义」那句的
   现行 `flood_filled` 判据），而非原始 `h`——平滑面 `h_r` 才是填洼的参照面；开/关档同一条判据，
   且 E16 断言「湖格数 == flood_filled」把这条口径钉住。
3. **河层阈值**：沿用 §5.2 的字面 `acc ≥ P98`（**全球** acc 的 98 分位）再交 ∧陆 ∧非湖。
   ⚠️ 实测在微型档 60×120 下该层会退化为空（洋面根吃掉右尾）；s2 实测 1,879 格（0.41%）、
   C0b+C1 档 2,599 格 ⇒ 正式档不空。若复核希望标度无关，可改成「陆上 acc 的 P98」——
