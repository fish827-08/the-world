## 顶置交裁项：§2.4 字面分支 vs §3.2 数量级分支，两头都踩线

**数据（seed 42 / s2 / 2000t，全 `[读数]`）：**

- arm2（置换对照）C-b **显著**：d2 纯度 0.6033、z=5.40；d3 0.6316、z=8.77（通过线 z>3）。
- arm3/arm4（处理）在各自 k\* 下 **C-b 超 arm2**：arm3 0.9917（z=11.05）/ arm4 0.7355（z=6.76）。

**两条预注册判据原文**（`docs/预注册/预注册-纯斑块世界-四臂-20261011.md`）：

- §2.4：「若 arm3/4 的 C-b 显著 **且** arm2 不显著 ⇒ 「地理结构」起作用…；**若 arm2 同样显著 ⇒ 连贯性来自几何特征（area/lat），与地形无关——按此读，勿翻转**」⇒ 字面触发**负向**分支。
- §3.2：「若簇被 f3/f4/f5 主导 **且** C-b 超 arm2 ⇒ 记录「产能格局被 E→W→P 链重塑」（C-d 部分成立）」⇒ 字面触发**正向**分支。

两判据设计意图本可互补（§2.4 管「连贯性归因」、§3.2 管「格局是否重塑」的记录），但字面结论一个说「与地形无关」、一个说「被 E→W→P 链重塑」——**直接互斥**。我不翻转任何一条，原样交裁。

**三件佐证（判读后补，非预注册判据；已登记预注册《修订留痕》）：**

1. **fair-k 复核 → 增量塌缩**：四臂全部钉死 k=2 时，z_d2 = 9.06 / 10.51 / 11.05 / 10.33（arm1-4）——统计上**不可分**。own-k\* 下 arm3/4「超 arm2」的增量主要骑在 k 选择自由度上（null 均值随 k 变；且四臂轮廓系数全挤在 0.44–0.53 窄带 ⇒ k\* 本身脆）。
2. **Magnus 纬度压印（机制发现）**：corr_cell(u, |lat|) = −0.936(arm2) / −0.984(arm3) / −0.931(arm4)，而 corr_cell(h, |lat|) ≈ 0。⇒ 即使 H 被完全打乱（arm2 的置换是真置换：sorted(h2)==sorted(h4) 为 True、corr_cell(h,|lat|)≈0），T = base_t(lat) − lapse_c·H 过 Magnus 非线性后，**u 场仍被纬度强压印** ⇒ **arm2 不是纯净几何零模型**，「arm2 显著 = 纯几何」的推断链在机制上不干净。
3. **径流型簇差动证据（本批最稳的差动信号）**：高 CV × 河格富集簇出现在 **arm2**（河格占比 15.2% vs 基线 1.95%，白噪碎块水系）与 **arm4**（6.6% vs 1.93%，连贯河道），**arm3 无**（runoff_gain=0）⇒「runoff_gain 自身造出一种新簇型」有差动证据；地形连贯性改变的是该型的**空间形态**（碎 vs 连贯），不是有无。

**三选一供裁（附我的倾向）：**

- **A**：按 §2.4 字面收口——「连贯性主要由几何（纬度/面积）承载；本批不判地形归因」。与 fair-k 塌缩 + Magnus 压印一致。
- **B**：按 §3.2 字面记录——「产能格局被 E→W→P 链重塑」（以 own-k\* 增量为准）。⚠️ 需接受 k 选择自由度；fair-k 下该增量不显著。
- **C（我建议）**：两读并列、本批不下单侧结论；若要接着走，下一批 amend 预注册（① C-b 主判据钉死 fixed-k；② 明示 Magnus 混杂；③ 如需去混杂——臂内关 base_t 纬度梯度，或把 u 对 |lat| 回归取残差再入聚类）。开不开下一批、是否仍限 ≤4 run / ≤2000 tick，听你。
