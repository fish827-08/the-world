## 二、本批物理范围（严格按报告 §6 C4a-1，不得超范围）

### 物理链（因果方向，不许颠倒）

```
太阳年平短波 S(φ)  →  地面吸收 S(1−α)（α 按 surface_type，C0b 已备料）
                   →  地表温度 T_surf（EBM：C·∂T/∂t = S(1−α) − (A+BT) + D∇²T，隐式扩散）
                   →  单层大气（地面以长波/感热/潜热加热大气；大气对短波近透明）
                   →  大气质量 proxy + 静力平衡 → 气压 P
                   →  压力梯度力 −∇P/ρ（+ Rayleigh 阻尼，无科氏力）→ 风 u
                   →  风的水平散度 ∇·u = 垂直运动代理（暖区辐合上升 / 冷区辐散下沉）
```

- **方程（climlab 口径，只借方程不搬库）**：`C·∂T/∂t = S(1−α) − (A+BT) + D∇²T`
  - A=210 W/m²（出射长波常数项）、B=2.0 W/(m²·K)（长波线性化斜率）、D=0.555 W/(m²·K)（经向扩散，参数化"风+洋流送热"）、C≈4.2×10⁷ J/(m²·K)（10 m 水当量；海陆按 surface_type 的 c 区分）。
  - 解析自洽锚：全球均值 T̄=(S̄(1−α)−A)/B=(340×0.7−210)/2 ≈ **+14 ℃**。
- **本批风是"诊断式"响应场，不是完整浅水动力学**：温度由 EBM（隐式扩散）决定，气压/风由温度**诊断**推出；**风本批不反过来显式平流热量**（热量仍走隐式扩散 D∇²T，代表风对热量的统计再分配）。显式热平流 −∇·(vT) 在 C4a-2 起风场动态化后才上，届时 D∇²T 降级为次网格/数值滤波项（报告 §2.1-⑤）。
- **辐合/辐散 = 垂直运动代理**：暖（赤道）上升 → 近地面低压、高空高压；冷（极地）下沉 → 近地面高压。无自转 + 唯一水平力为压力梯度力 ⇒ **每半球一个热力直接环流（单胞）**，赤道辐合、副热带辐散，这是本批唯一要验证的环流结构（报告 §2.2-①）。

## 四、★潜藏 bug 与违背自然规律自查清单（owner 特别要求，逐条对照）

### 一、能量守恒（最容易凭空造热/漏热）

1. **收支闭合**：每 tick 全球面积权积分必须满足 `C·ΔT = ∫S(1−α) − ∫(A+BT)`（扩散项全球积分为 0，是内部再分配）。进探针 + 单测，给实测残差。
2. **隐式扩散必须对称、耗散非正**：D∇²T 在球面面积权下是自伴算子。验证两张恒等式：任意场 `∫∇²T·dA = 0`、`∫T·∇²T·dA ≤ 0`。不对称的离散会凭空造热或耗散。
3. **纬度面积权 cosφ 不能漏**：所有经向通量/积分/拉普拉斯都要乘纬带面积 cosφ。漏乘是球面最常见 bug，会造成极地冷/热偏差。验证：均匀输入给均匀输出；旋转对称输入给旋转对称输出。
4. **温度单位（开尔文 vs 摄氏度）**：EBM 的 (A+BT)、理想气体 P=ρRT 用**开尔文**；项目现有温度场是 ℃。必须在边界明确转换，禁止拿 ℃ 直接代入辐射/状态方程。这是最隐蔽的"违背自然规律"单位 bug。
5. **入射 S 用年平、不用瞬时**：S 是年平均日照（赤道高、极地低），与光照模块的瞬时 illumination（含昼夜/季节）是两套，别混用；季节在 C4a-4，本批不做。
6. **扩散稳定性**：显式扩散受 Δt < Δx²/(4D) 限制（高纬 Δx 小最严），故优先**隐式**；任何不稳定先查步长，别加非物理平滑。

### 二、气压与风（最容易把方向/因果搞反）

7. **风必须从高压吹向低压**：`u ∝ −∇P/ρ`，近地面赤道是低压 → 风向赤道辐合。符号反了会出现"赤道辐散"。最小测试：单个暖斑，近地面风向暖斑辐合。
8. **暖升冷沉**：暖区垂直速度 w>0（上升）、近地面气压低；副热带冷沉区近地面气压高。验证 w 与 T 异常正相关。
9. **气压不能直接 P∝T 硬写**：气压是空气柱重量，要经**单层大气质量 proxy + 静力平衡**（dP/dz=−ρg、P=ρRT）。直接 P=P0·T/T0 会让气压处处与温度同向，违背"暖区近地面低压"，是典型违背自然规律。
10. **必须有 Rayleigh 阻尼（−u/τ）**：本批无科氏力、无粘，水平能量唯一去处是阻尼；没有阻尼风会无限加速发散。τ 用边界层物理时间尺度（量级"天"），标定后写进配置，不许随手取 1。验证：恒定强迫下风趋于有限稳态。
11. **质量连续**：∇·u 对应垂直运动，球面全球积分 `∫(∇·u)·dA = 0`（辐合总量=辐散总量）。

### 三、球面拓扑与数值稳定

12. **纬向周期接缝**：经度 0/360 处场、梯度、通量连续，不能有缝。
13. **极点整圈邻域**：极点格的邻域是整圈纬度带（项目已有极点坍缩表），大气场的拉普拉斯/梯度/通量在极点不能重复计数或漏计（C0b 已踩过同款极点坑，大气场同构）。
14. **CFL 按高纬最小格距**：3 子步 × Δt 100–200 s 起步；不稳**先加极地滤波（FT/经向谱滤波），不要全局限小步**。
15. **非负/有限 fail-loud**：T(K)>0、P>0、质量>0；任意子步出现 NaN/Inf/负质量直接报错，禁止静默截断。
16. **上下采样保守恒**：主 480×960 ↔ 天气 120×240 的映射必须面积守恒（粗化=面积权聚合、细化=守恒展开），简单线性插值会丢能量/质量。
