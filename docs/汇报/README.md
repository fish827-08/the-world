## 约定

1. **一报一文件**：命名 `汇报-YYYYMMDD[-主题].md`；同日多报加主题后缀（如 `汇报-20261011-可视化骨架.md`）。
2. **只增不改**：新进展=新文件；对已发汇报的补充以"追记（时间）"附在文末，不重写正文。
3. **写法**：结论先行 → 证据分级（`[实测]` / `[读数]` / `[推断]`）→ **待 owner 决策项单独成节并顶置**。
4. **入库**：随 git 提交与推送（主仓 main）。
5. 状态类内容（当前在哪、下一步）写进 `docs/项目状态.md`（活文档），汇报只记"发生了什么 + 要您定什么"。
