## 二、评估范围在 v14 基础上的新增项（逐项给结论、来源链接、文件:行锚点）

**A. 能量平衡（EBM，最高优先，是风的燃料）**
- 现状以代码为准：`world/light_and_temperature.py` 只有入射日照几何（`illumination`/`photoperiod`/
  `base_temperature`/`temperature`），温度仍为基温 + illum×day_boost 写死，**无反照率 / 红外出射 /
  热容量 / 热扩散**。
- 评估：经典 EBM（Sellers/Budyko/North 1969–75）方程
  `C·∂T/∂t = S(1−α) − (A+BT) − ∇·(vT) + D∇²T` 在 480×960 球面的离散；红外系数 A/B、扩散系数 D、
  热容量 C、反照率 α 的取值与单位（让稳态赤道/极地温度落在真实区间）；**热扩散（隐式代表风，静态 C1 用）
  与热平流（显式风带热，C4a 主导）如何取舍**；扩散项数值稳定性（隐式扩散避免步长受限）。
- 蓝本：**climlab（Brian Rose，github brian-rose/climlab，过程导向，含零维/扩散/湿 EBM、辐射、
  季节、热容量、MeridionalMoistDiffusion）**——A 层首选，取其过程分解与方程。

**B. 大气被地面加热机制 + 热物性三件套（随 C0b 表面类型逐格赋值）**
- 机制：大气对太阳短波近乎透明，**地面吸收短波后以长波（红外）/ 感热 / 潜热加热大气**；高空冷源于
  远离地面热源 + 空气上升绝热冷却（干 ≈9.8 / 湿 ≈6 / 环境 ≈6.5 ℃/km，即 `lapse_c` 所指）+ 红外散热。
- 三件套：**反照率 α（吸多少）**、**比热容 c→热容量 C（升温快慢/存多少，水 4186 vs 岩石 ~800，约 5.3 倍）**、
  **导热率 k（往地下传多快，陆地浅层 / 海洋整层混合）**。
- 评估：海/湖/河/陆/（未来雪冰）各表面类型的 α、c、k 取值；这些如何进入能量平衡方程与表面温度计算；
  由此**不写死**涌现海陆风、季风、季节滞后、沿海温和 / 大陆性、沙漠昼夜温差。
- 净效应：C0b 不只决定"哪里有水"，还决定"哪里升温快、哪里是热库"。

**C. C0b 海陆 / 湖泊 / 海洋水汽源（构造期静态，零 tick）**
- 真实海拔 + 海平面（sea_level=0）在球面生成海陆；内流闭流盆地成湖；河流沿用 D8 汇流入海/湖；
  **替换"极点当唯一出水口"假设**（seed42 现状 50.8% 格被填成极海失真，需重设填洼基准与陆海比例）。
- 评估标准做法：sea-level fill、closed basin、endorheic lake、continental shelf；海/湖/河/陆产能与
  容量口径；海洋作为 C4a 蒸发水汽源的闭环（海洋蒸发→风输运→陆地降水→径流入海）。
- 蓝本：**SimpleHydrology（weigert）、TerraForge**（粒子液滴侵蚀、浅水管道、stream-power 下切）。

**D. C4a 涌现式大气环流（球面浅水，动态）**
- 评估：单胞模型（无自转、仅压力梯度力）涌现 Hadley 的成立条件；2D 球面垂直运动表达
  （水平辐合/辐散 vs 显式垂直层）；数值方法（浅水 / stable fluids / CA 流体 / LBM / 简单压力平流）
  在守恒性、稳定性、460k 格成本间权衡；水汽守恒平流（上风/半拉格朗日）；"蒸发受地面水量约束"
  如何打破"越暖越湿"；大气子步与生物 tick 解耦。
- 蓝本：**SWAMPE（Python，二维浅水大气环流，模块化，可改宜居行星）**——B 层首选；
  NOAA Simplified-Physics Atmosphere GCM（单 notebook 原始方程）、qgs（准地转大气+浅水海洋）。
- 分阶段：**C4a-1 先做"能量平衡自洽温度场→气压→风（不带水）"**，验证辐射加热不均能否涌现赤道辐合 /
  副热带辐散（零模型：均匀入射、关扩散、关自转）；再 C4a-2 水汽+热平流、C4a-3 凝结降水、C4a-4 自转季节。

**E. 开源蓝本逐个核对（借物理不搬库，全部给链接 + 许可证）**
- 能量/气候：climlab（A 层）、OpenSCM two-layer / simplEarth（热容量、季节）；
- 大气：SWAMPE、NOAA 简化 GCM、qgs；Breeze（Julia/GPU，只取公式）；
- 水文/地貌：SimpleHydrology、TerraForge（C/D 层）；
- 地质：GAIA（地幔/板块，仅评估，**本期不做**）；
- 洋流：Stommel–Munk / Sverdrup（风驱动 gyre，C 层，值得做但不阻塞）；
- 一体化：davidar sim-glsl（GPU，**只参考逻辑，禁抄代码**）。
- 每个蓝本回答：**能否只借方程 / 数值格式 / 过程结构在我们架构重写**（第三方库可能依赖编译件/GPU/
  外部随机，直接引入违反红线）。

**F. 最小充分地基 5 件 + 里程碑（放生物前）**
1. A 能量平衡闭环；2. C0b 海陆湖河（水汽源）；3. C1 静态副热带沙漠（C4a 对照锚）；
4. C4a 动态涌现大气（风/水汽/热平流/降水）；5. 土壤水薄层（生物"喝水"接口）。
- 给出这 5 件的**依赖顺序与里程碑**（建议 C0b→C1→C4a-1→C4a-2/3→土壤水），每步配**可验证涌现判据 +
  零模型**；地质侵蚀/沉积、雪线冰川、洋流、C3 给"何时做/不做"的触发条件；板块/完整 GCM/云微物理/
  冰期明确不做。

## 四、性能预算（话事人已实测，需复核并细化）

- 静态构造整套 env_field 约 2.1s（仅启动一次、零 tick）；当前纯斑块单 tick ≈28ms。
- 全分辨率 480×960=460,800 格动态大气：单子步约 116ms、每 tick 3 子步约 349ms（慢约 12 倍，不可接受）。
- **粗网格 4×（120×240=28.8k）+ 大气每 10 tick 推进、每次 3 子步：均摊约 1.4ms/tick（≈+5%）**；
  2× 约 +20%。热扩散是邻居 Laplacian、热平流多平流一个温度场，粗网格下再 +20–30% 仍可控。
- 新增气压/风/水汽/雨 4 个 float64 场全分辨率约 15MB（非瓶颈）。
- 结论：动态大气走"**天气粗网格（约 4×）+ 大气时间步与生物 tick 解耦 + 必要时下沉 Rust sim_core**"，
  目标每 tick 个位数百分比；报告需给推荐天气网格分辨率、更新频率、子步数与实测 ms/tick。

## 五、红线复述（评估与后续实现都不得违反）

- 禁 GPU；禁外部随机数（CountingRNG、新机制用独立 RNG 流，不消费引擎 self.rng）；
- Python↔Rust 双路径逐位对拍；新机制默认关、关档逐位等价（C7 回滚点）；
- 质量/能量/水量守恒，给长期（一个完整周期）守恒不变量与测试；动态场进快照或可确定性重建；
- 数据（.npz/.csv/results）不入主仓；一次性脚本不入主仓；提交用明确 pathspec（禁 git add .）；
- 未过 L0–L4 不写"涌现"；每个新机制都要配零模型（均匀/关扩散/关自转）可证伪；
- 只本仓库 the-world.git（main），数据仓 the-world-data.git；勿碰其他项目仓库。
