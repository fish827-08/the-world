## 施工范围（严格按评估报告 §5，不得超范围）

### Step 1：C0b（真实海拔 + 海平面 + 海/湖/河/陆表面层）——按报告 §5.2

- H 米制化（`peak_altitude_m=4500`），`lapse_c` 换真实 Γ=6.5 ℃/km；
- 海平面 = 按 **`land_fraction=0.30`**（地球 0.292，默认）在 H_m 上取分位阈值；`coast_gamma=1.0`（e^γ 海岸重映射，本期默认 1.0）；
- priority-flood 种子由"极点行"改为"海平面格"，**取消极点唯一出水口**（消 seed42 50.8% 格被填成极海的失真）；
- 湖 = `filled > H_m`；**淡水湖 vs 盐湖 = 沿 receivers 溢流链是否达海**（O(n) 并查集/标签传播；嵌套盆地本期按单层溢流面近似）；
- 大陆架 = ocean ∧ (H_m > sea_level − `shelf_depth_m=200`)；
- 河 = receivers 链终点 ∈ {海,湖} 且 acc ≥ P98（river_mask 重定义，旧 P98 读数层保留兼容）；
- 产出 `surface_type` 层 + `sea_level_m / lake_mask / salt_lake_mask` 读数；
- 配置字段：`c0b_enabled=False`、`land_fraction=0.30`、`peak_altitude_m=4500.0`、`shelf_depth_m=200.0`、`coast_gamma=1.0`；`from_dict` 旧档无键 ⇒ 回退默认=关；含断言（陆比∈(0,1)、shelf≥0、γ>0、峰高>0）。
- **热物性 α/c/k（报告 §2.3-④）本期只做"surface_type→参数"的查表常量备料，不接能量方程**。逐格热物性驱动 + 能量平衡是 C4a-1（件①，审后第二批），勿提前接线。
- **守恒不变量 3 条进探针与单测**：① 海陆面积比 == 1−land_fraction（分位定义，容差 1e-9）；② 流域闭合 Σ陆地产水 = Σ入海 + Σ入湖蓄 + Σ盐湖蓄；③ surface_type 计数与 filled/acc 掩码逐位一致。
- 判据：seed42 海比 ∈ 目标 ±0.5%；湖数 >0 且最大湖流域闭合；"极海"消失（对照 50.8% 失真）；对照臂 = 陆比扫描 0.2 / 0.3 / 0.5。

### Step 2：C1（静态副热带沙漠带）——按报告 §5.3

- 形式：`Pr = q(T) × (1 + orographic·H) × band(φ)`，双高斯带 `band(φ)=1+A_wet·G((φ−φ_itcz)/σ_wet) − A_dry·G((φ−φ_dry)/σ_dry)`，G(x)=exp(−x²)；
- 默认：φ_itcz=0°、σ_wet=8°、φ_dry=±27°、σ_dry=12°；幅度按"**副热带谷底 Pr < Et ⇒ yield=0**"标定（et_frac=0.5 ⇒ 谷底 band<0.5）；
- **band 面积权均值归一 = 1**（保持全球产水总量不变）；
- **只改降水侧形状，不碰 Et**；蒸发受地面水约束（Manabe 水桶）留 C4a-2；
- 配置：`c1_enabled=False`、`itcz_deg=0.0`、`itcz_width_deg=8.0`、`dry_deg=27.0`、`dry_width_deg=12.0`、`wet_amp`、`dry_amp`（断言 + 旧档回退默认）；
- 判据：纬带三层结构（赤道峰 / 20–30° 谷，谷底 yield≈0，带宽 15–25° / 温带次峰）；k=2 尺度可见、k≥3 不引入混杂；C0b 同开时同纬沿海 vs 内陆梯度；
- 零模型：无 band（现默认）。
