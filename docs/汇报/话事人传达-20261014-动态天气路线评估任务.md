## 二、为什么做（要改变的现状）

当前环境场（`world/env_field.py`）是构造期一次性静态场：有"气候"（年均降水 / 温度），
**没有"天气"**（无云 / 风 / 雨带 / 降水事件），且只靠 Magnus 公式导致"越暖越湿"，
**复现不出真实世界 20–30° 的副热带沙漠**（seed42 地图已证实，赤道单峰、单调向两极变干）；
海拔 `lapse_c=20` 也是非物理的现象学常数。owner 希望补上能**真正改变世界格局**的机制，
而不是堆花架子。

## 四、选型与设计的硬标准（不得越过）

1. **默认关 + 关档逐位等价**（C7 回滚点）；新机制默认 `enabled=False` 或 sensitivity=0。
2. **守恒**：Σ容量 / Σ名义再生的面积权均值归一不得被破坏；动态波动只能再分配、不能凭空造水，
   必须给长期（一个完整周期）守恒不变量和测试。
3. **独立 RNG 流**（不消费引擎 `self.rng`）；动态状态必须进快照或可由 config + RNG 确定性重建。
4. **先落 Python 路径**（env_field 与 Rust sim_core 同开现报错，`sphere_engine.py:840-842`）；
   必须先解 `env_field ∧ resource_dynamics.enabled` 的 fail-loud 未对拍组合（`config.py:1479-1480`）。
5. **性能**：s2 为 460,800 格，给单 tick 成本预算；静态近零、动态不得退化为每 tick 全网格重算气候。
6. **可证伪**：推荐路线必须给"应当产生什么可观测现象"和零模型对照，按预注册流程走（L0–L4）。
7. 一切以代码为准，给文件:行锚点；数据 / 一次性脚本不入主仓；提交用明确 pathspec。

## 五、青梧的初步倾向（供参考，轻舟可凭联网证据推翻）

- 首选 **C1（静态 Hadley 副热带）**：不引入时间维度、不动快照 / 守恒 / 性能、可逐位等价，
  却能补上最大空间失真（副热带沙漠），让世界立即多带化（雨林–沙漠–温带–极地），性价比最高。
- 同期或紧随 **C0（海拔真实化，Γ≈6.5 ℃/km）** 作为物理校准。
- 时间维度 **C2（雨带季节移动，复用现成 δ(t)）先于 C3（随机天气事件）**；C3 演化价值大但
  快照 / 守恒 / 对拍是硬活，等生物层启动前后再做。
- **C4 空间天气本期不做，完整 GCM 不做。**
