## 裁定三：下一里程碑 = 分尺度判据（先修"尺子"）

- C 批的真正教训是 **fixed-k=2 判据分辨率不足**：自然档下纬度主结构（corr≈−0.92）掩蔽地形局部效应，Δz=0.12 是"测不出"，不是"地形无效"。
- 下一步做**分尺度判据**：
  - k=2 认纬度主结构；k≥3（或多尺度 k 谱）看地形 / 次级结构；
  - 或在固定纬度带内做局部对比（控住纬度后看地形）；
  - 判据升级后应能同时：①复现自然档"纬度主导"，②在更细尺度检出现实存在的地形局部效应。
- 该里程碑与"动态天气"线的关系：**先并 main（裁定二）→ 天气线（C1 等）评估与落地 → 分尺度判据**。分尺度判据同时作为验证 C1 是否真造出副热带沙漠带的尺子。具体排期由轻舟按依赖关系给出，owner 批准的大方向是"先把环境层尺子和物理都做扎实，再放生物"。
