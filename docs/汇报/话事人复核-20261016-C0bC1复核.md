## 四、三待裁项口径确认（A1 / B1 / ①a①b）

**A. 盐湖恒 0 → 采 A1（保留空层 + 标注结构不可达，判据延 C4a-2）。**
理由：盐湖是"内流盆地 + 蒸发>补给"的**动态水量收支**概念；构造期 priority-flood 语义下所有湖沿溢流链可达海，无静态盐湖是数学必然，非缺陷。A2 要引入"蒸发需求"这一**无物理标定的自由参数**，且蒸发受地面水约束已明确排期 C4a-2，现在塞违背"只落底层规则"；A3 撤标签不如 A1 保留空层（surface_type 枚举完整、C4a-2 零成本接入）。话事人按 owner 既定原则选 A1。

**B. band 归一与总量互斥 → 采 B1（面积权 AWM=1，接受 Σ 产水临时 +17.7%，C4a-3 守恒降水消除）。**
理由：C1 是 owner 10-16 已批准的**临时对照靶子**，其唯一使命是"把雨林/沙漠/温带的形状位置摆对"，AWM=1 是无量纲形状乘子的正确归一；B2 强行总量守恒反而破坏形状归一纪律，且只给一个"即将拆除的靶子"凑守恒。当前 N=0 无生物，绝对产水尚未被生态承载力消费，不存在长期污染；C4a-3 水循环闭合后全球产水由"蒸发=降水"守恒律自然锁死，+17.7% 不进终局。K 尺子/供给位移对生态门的连带，留待跑批预注册处理。

**C. 守恒① 容差 → ①a/①b 拆分（口径，零代码改动，非选择题）。**
离散网格分位阈值必落某格，`|陆比−目标|` 下界 = 单格面积比（s2 实测 9.5e-7），1e-9 严格恒等在数学上不成立。拆为：①a 互补式 `area_complement_resid=0.0`（严格守恒，保 1e-9）+ ①b `|陆比−目标|≤单格面积`（作扫参读数，±0.5% 远端达标）。话事人实测两者均成立，口径正确。

## 五、两个跨平台工程问题（非本批缺陷；随 C4a-1 批修，不阻塞冻结）

1. **digest 测试钉死单平台绝对值，Linux 上假红（e15/e25）。**
   现状：`tests/test_env_field.py` 的 `_C0B_OFF_DIGEST` 钉的是 Windows 60×120 绝对值；digest 用 `tobytes()` 对 ULP 敏感，跨平台（numpy/fBm 浮点）有微差，Linux 上 e15/e25 必红（经典例：default/sens0 期望 `3cfd06bd…`、Linux 实得 `95ed7f51…`）。**逻辑本身正确**（§二 同平台前后全等已证），但云端/未来接手多为 Linux，假红会被误读为"回滚点破"。
   修复建议（轻舟评估，倾向 a）：a) 测试改为**平台无关的同平台前后对拍**——断言"开档关场 == 关档基准场"这一相对不变量，而非某个固定 hex；或 b) 按 `sys.platform` 分档维护期望值（维护成本高）。**不接受**为变绿而放弃逐位严格性。

2. **Rust 二进制换环境/改源码后必须重编（本次再踩，与 2026-09-26 云归事故同款）。**
   现状：沙箱 `site-packages/sim_core.so` 为 09-25/09-26 编译，`genes.rs/lib.rs` 09-29 改名重排后未重编，`validate_gene_wiring` 报 `MEMORY_WEIGHT(22,22)` 这类"值同却判漂移"（lib.rs 注释已记同款事故）。话事人在沙箱执行 `cargo build --release`（需补 `LIBRARY_PATH=/opt/python3.12/lib`，因 sysconfig `LIBDIR` 指向不存在的 `/install/lib`）后替换安装，**该测试立即转绿**（快速闸 3 failed→70 passed）。
   修复建议：ONBOARDING/接手指南加"环境就绪检查"——拉代码/新环境/改过 `sim_core/src` 后、跑 Python↔Rust 对拍前，必须重编并安装（`maturin develop` 或 `cargo build --release` + 安装），并以 `validate_gene_wiring` 作为自检；附本机沙箱的库路径兜底（`/opt/python3.12/lib`）。
