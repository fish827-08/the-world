## 一、项目定位与目标

**一句话**：在经纬球面网格上运行「世界—生命」闭环仿真的数字生命实验平台；不设适应度、
不注入奖励，检验信号与行为结构能否在有限死规则下自发出现。

- 正式装置：**480 × 960 = 460,800 格**，必须显式 `--device s2`；60 × 120 只是代码默认值与
  微型冒烟档，吃默认值会与历史读数不可比。
- 仿真回路**不使用 LLM**；LLM 只在外围参与分析与文档。
- 非目标：完整 GCM、体素三维世界、跨硬件逐位一致、人工适应度。

### L0–L4 判据阶梯

| 层 | 判据（原始定义，未改动） |
|---|---|
| L0 信号稳态 | g15 稳态值 > 0.5，≥5 种子可复现，且过生态门 |
| L1 携带信息 | 信号与环境/情境互信息显著高于漂移零模型 |
| L2 任意性 | 能指与所指解耦，跨群体码本分化不能由热扩散解释 |
| L3 组合性 | 有限符号集表达复合含义且新个体可学 |
| L4 语义接地 | 符号稳定锚定世界状态，并可用于欺骗 |

**结项结论**：L0–L4 **未获端到端检验**。大气判据门未过（J1 = FAIL、J2 = FAIL 终局）；
J3 端到端耦合检验按冻结版启动 P0 前置检查后，因 P0 未过而归档 **NOT-RUN（未执行）**，零耦合数据。
按「未测得」如实记载——不写「证伪」，也不写「涌现」。

## 二、方法

### 2.1 世界与个体

- 球面网格：等距圆柱投影，极区格子面积 ∝ cos φ；光照、季节、能量平衡气候、地形、资源、
  信号、气味、亚格移动。
- 个体：小型实数基因 + 固定行为公式；无显式适应度函数，选择来自差异生存与繁殖。
- 双实现：Python 参考路径 + Rust/PyO3 加速路径，要求**逐位一致**（函数级与引擎级对拍）。

### 2.2 实验纪律

- 跑批前写预注册，冻结判据/阈值/窗口/种子，并记录哈希；
- **执行与判读分离**：执行线只报数，独立验证线按冻结判据判读；
- 机械审对提交做 M1–M8 核对（路径、哈希、读数、根目录白名单等）；
- 负结果与正结果同表入账；
- 停手规则：前置门不过即 NOT-RUN，不绕过、不延期；
- 失败集合按「集合逐名」对账，不看通过总数。

详见 [04-方法与纪律-20261024.md](04-方法与纪律-20261024.md)。

## 六、结构性发现（本项目最高价值产出）

### 6.1 信号边际价值 = 0（构造性诊断）

原信号内容是发射者自身状态的硬编码公式（`e_bin*4 + f_bit*2 + n_bit`），其中食物位与邻居位
是接收者本就可直接感知的量。由此：

- 接收者从信号中得到的**边际信息为零**；
- 发射仍需付出成本；
- 选择因此倾向关闭信号（g15 下降、模式数塌缩）。

配套实验（E-028/E-029）与后续复核（R136）给出分层读数：行为层存在性 6/6 正向（中位
+0.0827），但内容层效应仅 +0.0062（约为行为层的 7.5%）；直接死因主要来自**发信号的成本**，
而不是「内容完全无用」。因此本节是**对机制设计的结构性诊断**，不是单因子实验证明；它解释
的是「为什么调参无法救活这条线」。

### 6.2 表达力天花板

有限维实数基因 + 固定行为公式只能张成有限维行为流形，与语言所需的离散组合无限性存在结构性
不匹配。**在本装置与本表达力载体下**，这种组合性未被测得或实现；E-021 的
`Δ_content/Δ_full ≈ 0.23` 是支持该限制的一个**旁证**（`[判读]`；门控归因口径，`n_eff=3`），
不是表达力的直接测量。**瓶颈在表达力载体，不在世界保真度**——
这是重启时的第一优先方向。

### 6.3 K=2「双稳态」是装置 bug

早期观察到的 K=2 留守/出走双稳态，最终定位为 `from_field` 用背景第 0 格反推全局倍率：
该格约 40% 概率低产，造成装置漂移。修复与直读改造（R320/R328）后，该「双稳态」结论作废。
这是「未验证装置上的正结果可能是幻觉」的直接案例，也是本项目方法论纪律的动因之一。

### 6.4 其他已记录的结构性现象

- **Magnus 纬度压印**：温度经 Magnus 非线性映射后，纬度暗通道被压印进水分场，使置换零模型
  不纯净（corr −0.936 / −0.984 / −0.931）。因此 C 批只在无纬度通道时看到地形增量
  （P1 Δz=+10.68 PASS vs P2 Δz=+0.12 fail）。
- **kin 通道为占位实现**：旧 `sphere_engine` 中的亲缘通道未真实实现，相关结论不可引用。
- **感知 bug**：「信息不对称导致生态崩溃」的原判基于 `nb[:4]` 半平面 bug，整批作废。

## 八、大气线：J1 = FAIL、J2 = FAIL、J3 = NOT-RUN

### 8.1 两条路线与两个基准

- **乙（自研 Rust 干核 `atmo_core`）**：P1 能力门 FAIL（13 FAIL / 2 PASS；`umax` 发散至
  3.8e107，CFL 3.65095），随后冻结留档，不作回退保险丝。
- **甲（SpeedyWeather.jl 0.23.0）**：先跑**干 Held–Suarez 基准**，P1′ = PASS（13/13 能力、
  15/15 读数），随后 **J1 = FAIL 终局**；再跑**湿 Aquaplanet 基准**，**J2 = FAIL 终局**。
  P1′/J1 与 J2 不是同一个基准，不能把 P1′ PASS 当作 J1/J2 的依据。

### 8.2 J1 = FAIL（干 Held–Suarez）

15 项读数 13 PASS / 2 FAIL：

- `CONS-MASS` = **4.12793e-5**（阈值 1e-6；f64 归因臂 4.43961e-5，同为 FAIL）；
- `CONS-POLAR-TREND` = **0.334148**（阈值 0.01）。

归因分列：`CONS-MASS` 为 ln(ps) 表示效应；`CONS-POLAR-TREND` 与 69–78° 带变率有关，但
该归因对口径/精度敏感（签门件记录的原生对照脚本未入证据目录；独立方法给出不同量级/符号）。
两项判据均未放宽，失败照实入账。

### 8.3 J2 = FAIL（湿 Aquaplanet）

12 项能力 10 PASS / 2 FAIL：

- `AQ-TOA` = **7.016983 W/m²**（阈值 5）；
- `CONS-WATER` = **1.079661e-3**（阈值 1e-3；Option 3 归一化 1.077105e-3 仍超）。

rev3 诊断对既有 J2 数据复算：候选窗 day60–120 的 `AQ-TOA` = 7.867649、
`CONS-ENERGY` = 2.744521 双 FAIL；对照窗 day90–120 为 6.050132 / 1.080679 双 FAIL。
day90–120 只是对照，不是许可的代替路线；短窗即使某条 PASS，也属窗口效应，不是判据被修好。
水账诊断中 `clip_growth` 占 gate 残差 +112.453%（day30–120），同窗
`|true_closure|/ΣP` = 2.8414e-5，未达到 R1 的 `<1e-5` 条件。另有 30 天（day0–30）在线 q
收支的分解残差代理 3.28e-6（`diagnostic_only`）；它**不是** 120 天真闭合，也**不能**与门窗
day30–120 直接比较。

### 8.4 J3 = NOT-RUN（未执行）

按 FROZEN rev3（内部冻结件 525 行，LF sha `e69da203…0ba5282`；公开副本脱敏，副本哈希见
05 §4.1）执行 P0-1…P0-11：

| 项 | 状态 |
|---|---|
| P0-1 / P0-2 / P0-3 | **实质未过** |
| P0-4 / P0-5 / P0-7 / P0-11 | 被前置阻断 |
| P0-6 / P0-8 / P0-9 / P0-10 | 通过 |

根因：J3 的 ON 臂需要甲湿核的在线构造形态，但 main 上唯一可构造的**真实核**是干
`atmo_core`，其 `export` 不含 `precip`（`SyntheticCore` 只是合成链路用的核，不具备甲湿核
形态）。按冻结件构造 ON 臂即在 `bridge.py:155` 触发
`ValueError: core.export 缺 'precip'`（已实测复现）。因此：

- **零耦合数据**；C0 双跑、20 run、P0-11 均未执行；S/D/C/I/E 判据全部未执行、无判读；
- 按冻结件 §七.1 / §8.1#1 归档 NOT-RUN；
- 项目所有者裁定 **③ 暂缓**：J3 归档终局，不重启、不延期。

J3 不改变 J2 的 FAIL，也不构成任何「证伪」。
