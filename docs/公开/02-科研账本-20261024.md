## 一、口径与阅读须知

1. **机制层 ≠ 涌现层**：本页正结果均为机制层结论，按既定裁定不作为 L0–L4 证据。
2. **正式装置**：480 × 960 = 460,800 格，必须显式 `--device s2`；60 × 120 只是冒烟档。
3. **跨纪元不可直接比**：2026-10-17 大气时间步从 45 s/tick 改为 36 s/tick；开档读数中的
   `u_*`、`cfl_*`、`*_mm_yr`、`residence_days` 等跨纪元不可直接比较。
4. **口径冲突优先采信最新签门件/实验记录**；本页对易混口径逐项标注。

## 二、正结果（机制层）

### E-038 记忆减少未访斑块格

| 项 | 内容 |
|---|---|
| 装置 | S2 480×960、1700 斑块、pop 1e4、bg 0.4+0.05、rd；仅 `memory_v2` 变 |
| 样本 | 24 seed（101–124）× on/off = 48 run，2000 tick |
| 主判据 | 未访斑块格 on−off |
| 读数 `[实测]` | **24/24**；中位 **−2.92pp**、均值 −3.02pp，全部负向；出走型 3 seed 生存 **+15~23%** |
| 判定 `[判读]` | PASS（信息价值 ∝ 空间分异） |

**限定**：机制层；生存增益只在出走型世界出现，不可外推到所有世界。

### E-040 气味使零食物沙漠可穿越（批 A）

| 项 | 内容 |
|---|---|
| 装置 | 同 E-038 装置 + 气味 food/prey、`use_in_move` |
| 样本 | 24 seed（125–148）× on/off = 48 run，2000 tick |
| 主判据 | l1 覆盖 |
| 读数 `[实测]` | 主门 **23/24**；l1 配对差中位 **+0.84pp**；唯一负例 seed 127（−0.22pp）；pop 24/24 升（中位 +284） |
| 判定 `[判读]` | PASS（≥14 线） |

**易混口径**：**24/24 不属于 E-040**。24/24 是四通道新装置的 A 门（原始记录 **E-048** 的
A 门，本文简称 **E-048A**，见下）。

### E-041 记忆提高承载量（旗舰 60k）

| 项 | 内容 |
|---|---|
| 装置 | 旗舰 480×960、60k tick、bg 0.4 |
| 样本 | 4 seed（169–172），同 seed 配对 4 run |
| 主判据 | K 同 seed 配对 |
| 读数 `[实测]` | 12,561→26,847；19,082→23,496；10,861→29,984；82→18,634；前 3 seed +23.1%~+176.1%，seed 172 分母接近灭绝（82），比值 227.244× 失真，应读绝对值；同向 **4/4** |
| 判定 `[判读]` | 机制层正向；**B 侧主门未过**（E-042） |

**「8/8」的正确理解**：旗舰记忆臂共 8 seed（165–172；A 支 5 + B 支 3），K 比值
1.231–227.244，同向 **8/8**。E-041 是其中 169–172 的 **4/4 配对**子集；8/8 不是「8 个
独立实验全部通过」，也不是把配对两侧简单相加。同批 B 侧门（E-042）为 FAIL。

### E-043 记忆扩大个体活动范围

| 项 | 内容 |
|---|---|
| 装置 | 旗舰 20k、sample 200 |
| 样本 | 4 seed（189–192）× 2 = 8 run |

### E-048A 四通道新装置 A 门（补充）

| 项 | 内容 |
|---|---|

**与 E-040 的关系**：不同装置、不同判据，**不得混用**；对外写作时必须写明「E-040 主门
23/24；E-048A A 门 24/24」。

### 其他机制层观察（不作主结论）

- **E-044**（设计 2）：出走=死路，8/8 同向，死亡率 1.76× / 2.94×——支持「信息价值依赖空间
  分异」的解释。
- **E-028**：行为层存在性 +0.0827（6/6），内容层仅 +0.0062（约 7.5%）；仅仪器校准用途。
- **E-037**：早期「K=2 双稳态」读数，后因背景倍率抽奖 bug 作废（见 §四.3）。
