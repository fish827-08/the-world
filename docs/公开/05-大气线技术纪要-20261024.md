乙线用干 Held–Suarez 动力做世界气候输入。P1 能力门 15 条 mandatory：

处置：乙线冻结留档——不删代码、不删测试、不再作为 P1 的回退保险丝。重启须 owner 明令 +

### 3.2 J1 = FAIL（终局；干 Held–Suarez）

J1 是质量/极区趋势守恒门，基准为干 Held–Suarez。协议：120 天、`dt=144 s`、46 个快照
（days 30–120，每 2 天）、seed 42、IC `iso_w1`；签门日期 2026-10-21。15 条读数
**13 PASS / 2 FAIL**：

| 判据 | 读数 | 阈值 | 判定 |
|---|---|---|---|
| `CONS-MASS` | **4.12793e-5**（f64 复算 4.43961e-5） | ≤ 1e-6 | **FAIL** |
| `CONS-POLAR-TREND` | **0.334148** | ≤ 0.01 | **FAIL** |

归因（不改变判定）：

- `CONS-MASS`：模型预报 `ln(ps)`，判据测 `ps` 的线性均值，存在**表示效应**；极帽代理后
  仍为 1.2840e-5 / 1.5141e-5，仍超 1e-6；极帽约 0.126% 无数据。
- `CONS-POLAR-TREND`：J1 签门件归为 69°–78° 带的变率（不是极帽伪放大），并记录原生最外
  1/2 环同段斜率 −0.285 / −0.239（`|wind|` 口径目标 +0.2995、原生 −0.3855）。**该原生对照
  脚本未入证据目录**：后续 AV 用文档化独立方法复算得原生 **+0.0462 / +0.1285（纬向平均）**、
  **+0.1808 / +0.0072（|风|）**，与目标 +0.334 同号同量级 ⇒ 「非极帽伪放大」有独立方法支持；
  但 f64 最外环反号（−0.0799 / −0.0531、−0.3610 / −0.3780）⇒ **归因对口径与精度敏感**，
  只作登记，不作稳定性结论。
- f64 臂同配置复算为 12 PASS / 2 FAIL（同两条），说明**门判定**不是 float32 精度问题；
  `CONS-DET` 在 f64 臂为 `NOT_RUN`。极区趋势的**归因**仍对精度敏感（见上条）。

处置：判据未放宽；J1 **FAIL 终局**，不追溯、不改判、不降阈值。owner 2026-10-21 裁：
R-6 维持 1e-6；R-7 采 (c)（极区语义/选行仅前瞻 v2，不追溯）；R-2 维持注记；R-1 追认结案。

### 3.3 J2 = FAIL（终局；湿 Aquaplanet）

J2 是湿 Aquaplanet 基准门。12 项能力 **10 PASS / 2 FAIL**；15/15 读数全部产出，无 `NOT_RUN`：

| `CONS-WATER` | **1.0796610734062958e-3**（相对） | ≤ 1e-3 | **FAIL** |

**已列出的 5 条能力读数 PASS**：`CONS-CFL` 0.6708、`CONS-ENERGY` 0.897948、
`AQ-ITCZ-P` 5.1055、`CONS-POLAR-AMP` 1.0932、`CONS-DET` 0（12 项能力合计 10 PASS /
2 FAIL）。**3 条工程登记不混入能力 PASS**：E-ITCZ
`AQ-ITCZ-LAT` −13.2314（双 ITCZ 位于 ±13.231°，赤道非全局最大；负号是浮点并列 argmax 的
符号，不是半球选择）、E-MASS `CONS-MASS` 3.38335e-5（v1 判 FAIL）、E-POLAR −0.15075
m/s/day（v1 判 PASS）。E-MASS 的 3.38335e-5 是 J2 口径，**不是** J1 的 4.12793e-5；
且 **J2 无 f64 对照臂**（J1 有），精度效应未检验，不宣称排除。E-POLAR 是**单侧趋势门**

**`AQ-TOA` 归因（开放问题，不影响 FAIL）**：判据窗口为 days 76–120（23 个快照）的瞬时
`sw_toa − lw_out` 全球面积加权均值。同一 IC 的五年自旋末段（day1700–1820）净 TOA 均值为
−0.285688 W/m²、SST 斜率 2.1589e-07 K/day；门跑后 50% 净 TOA 为 +7.017 W/m²（区间诊断
+6.868），SST 斜率 +0.00233 K/day。−0.285688 是**连续积分**的末段参照，不是重启后或受控

**`CONS-WATER` 归因（不改变判定）**：E−P 与 dW/dt 同号且量级相近，残差约为 P 的

水账闭合的物理解释**。

## 八、工程教训

1. **能力门与判据门必须前置于耦合门**：J1/J2 未过时启动 J3，最终只能归档 NOT-RUN；先证明
   装置能跑，再谈端到端。
2. **干核不能当湿核的替代品**：`atmo_core.export` 缺 `precip` 是接口级事实，不是参数问题；
   fail-loud 比静默近似更诚实。
3. **批式 runner ≠ 在线适配器**：J2 的批式 `j2_run` 不能满足 J3 的在线构造需求；工程缺口
   必须在预注册前解决。
4. **判据冻结与执行分离有效**：J1/J2 的 FAIL 没有被事后调阈值或换窗口救回；rev3 诊断也
   只作为诊断留档，不产判据引用。
5. **停手规则有效**：P0 未过 ⇒ NOT-RUN，避免了用替代装置产出不可比读数。
