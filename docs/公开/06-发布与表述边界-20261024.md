## 二、证据等级

引用任何数字时必须带等级：

| 等级 | 含义 | 例子 |
|---|---|---|
| `[实测]` | 有读数与产物，可按记录复算 | digest、门跑读数、E-编号实验 |
| `[判读]` | 按预注册判据作出的 PASS/FAIL/NOT-RUN | J1 = FAIL、J2 = FAIL、J3 = NOT-RUN |
| `[汇集]` | 从既有件摘录，未新增分析 | 本公开报告中的汇总表 |
| `[待实测回填]` | 尚无读数 | 不得写成已测 |

**规则**：

- 预算值、估计值、目标值不得冒充实测值；
- 读数必须对应具体 commit / 装置 / 种子 / 窗口；
- 未执行的判据一律写 `NOT-RUN`，不写「预计」「应该」「趋势上」；
- 失败按**失败集合逐名**对账，不看总数；已知 flake 单名过滤并注明。

### 3.1 允许

- 「机制层：记忆/气味/活动范围有可测效应」——并附样本量与限定；
- 「结构性负诊断：信号边际价值为零是构造性的；表达力存在天花板」；
- 「J1 = FAIL、J2 = FAIL（终局）」；
- 「J3 = NOT-RUN（未执行），零耦合数据」；
- 「L0–L4 未获端到端检验」；
- 「工程与方法学资产可复用」；
- 「判据、阈值、窗口、种子未事后改动」。

### 3.2 禁止

| 「接近通过」「趋势有利」「只差一点」 | J1/J2 为 FAIL 终局；不得软化 |

| 「单 ITCZ」「极区债已清」「气候正确」 | J2 为双 ITCZ（±13.231°，赤道非全局最大）；J1 `CONS-POLAR-TREND` FAIL；工程登记的单项 PASS 不能反推「极区债已清」 |

## 四、科学结论的边界

### 4.1 可以主张

1. 世界引擎是确定性的，Python/Rust 双路径逐位一致，冻结 digest 可复算；
2. 记忆、气味、活动范围在机制层有可测效应（有样本量与限定）；
3. 信号边际价值为零是构造性的；有限维基因 + 固定行为公式存在表达力天花板；
4. 若干负结果与一个装置 bug 的归因；
5. 一套可审计的预注册/冻结/分离/机械审方法。

### 4.2 不可以主张

1. 类语言信号已经涌现，或接近涌现；
2. 大气装置已通过守恒/气候门；
3. 世界耦合已检验（J3 未执行）；
4. 机制层正结果可外推到涌现层；
5. 项目证明了「语言不可能涌现」——只证明了**在本装置与表达力载体下未测得**，以及
   结构性瓶颈的位置。

## 八、维护、问题与重启

### 8.1 维护态

项目已结项。仓库保持只读精神：

- 不新开实验；
- 不重开 J1/J2 门；
- 不重启 J3（已归档 NOT-RUN；owner 裁定 ③ 暂缓、不延期）；
- 不追溯修改已冻结判据、阈值、窗口、种子；
- 不把结项后的新分析混入既有签门件。

构建/文档问题可以通过 issue 或 PR 报告；修复不得改变科学记录。提交前请先跑档②并报告
失败集合。**不要在 issue/PR 中粘贴凭据、内网地址或个人路径。**

### 8.2 重启条件

若未来重启，必须：

1. 先取得 owner 的**新裁定**（本轮 ③ 暂缓为终局，不自动续期）；
2. 另立**新预注册**，不追溯本轮任何 FAIL；
3. 先解决表达力载体选型与 D2 码本方向（优先级高于继续加世界保真度）；
4. 先过生态门（≥5 seed 多数存活至目标 tick，N > 0 持续 50k tick）；
5. 若重开 J3，先补齐「在线湿核适配器」工程缺口；大气可用静态气候（C0b + C1），
   不需要更高保真；
6. 新判据不得引用本轮 FAIL 作为「接近通过」的依据。
