## 1. Positioning and goals

**One sentence**: a digital-life experiment platform running a closed world–life simulation on a
latitude–longitude spherical grid; no fitness function and no injected reward, testing whether
signal use and behavioural structure can arise spontaneously under a small set of fixed rules.

- Formal device: **480 × 960 = 460,800 cells**, requiring an explicit `--device s2`; 60 × 120 is
  only the code default and a micro-smoke device — using the default makes readings incomparable
  with the historical record.
- The simulation loop **does not use an LLM**; LLMs participated only in peripheral analysis and
  documentation.
- Non-goals: a full GCM, a voxel 3-D world, cross-hardware bit-exactness, artificial fitness.

### L0–L4 criteria ladder

| Level | Criterion (original definition, unchanged) |
|---|---|
| L0 signal steady state | g15 steady-state value > 0.5, reproducible in ≥5 seeds, and passes the ecological gate |
| L1 carries information | mutual information between signal and environment/context significantly above a drift null |
| L2 arbitrariness | signifier and signified decoupled; cross-population codebook divergence not explained by heat diffusion |
| L3 compositionality | a finite symbol set expresses composite meaning and new individuals can learn it |
| L4 semantic grounding | symbols stably anchor world state and can be used for deception |

**Closure conclusion**: L0–L4 were **not tested end-to-end**. The atmospheric criteria gates did
not pass (J1 = FAIL, J2 = FAIL, final). The J3 end-to-end coupling test started its P0
prerequisite checks under the frozen version, failed those prerequisites, and was archived
**NOT-RUN (not executed)**, with zero coupling data. It is recorded honestly as "not measured" —
not "falsified", and not "emergence".

## 2. Methods

### 2.1 World and individuals

- Spherical grid: equirectangular projection, polar cell area ∝ cos φ; insolation, seasons,
  energy-balance climate, terrain, resources, signals, odour, sub-cell movement.
- Individuals: small real-valued genomes + fixed behavioural formulas; no explicit fitness
  function; selection comes from differential survival and reproduction.
- Dual implementation: Python reference path + Rust/PyO3 accelerated path, required to be
  **bit-exact** (function-level and engine-level cross-checks).

### 2.2 Experiment discipline

- Write a preregistration before running; freeze criteria/thresholds/windows/seeds and record
  hashes.
- **Separation of execution and judgment**: the execution line reports numbers only; an
  independent validation line judges against the frozen criteria.
- A mechanical audit checks commits M1–M8 (paths, hashes, readings, root whitelist, etc.).
- Negative and positive results enter the ledger with equal weight.
- Stop rule: if a prerequisite gate fails, the result is NOT-RUN; no bypass, no extension.
- Failure sets are reconciled by **name-by-name set comparison**, not by total pass count.

See [04-方法与纪律-20261024.md](04-方法与纪律-20261024.md).

## 6. Structural findings (the project's highest-value output)

### 6.1 Signal marginal value = 0 (constructive diagnosis)

The original signal content was a hard-coded formula of the emitter's own state
(`e_bin*4 + f_bit*2 + n_bit`), where the food bit and neighbour bit are quantities the receiver
could already perceive directly. Therefore:

- the **marginal information** the receiver gets from the signal is zero;
- emitting still incurs a cost;
- selection therefore tends to switch signals off (g15 falls, mode count collapses).

Companion experiments (E-028/E-029) and later review (R136) give layered readings: behavioural-layer
presence is 6/6 positive (median +0.0827), but the content-layer effect is only +0.0062 (about
7.5% of the behavioural layer); the direct cause of death is mainly the **cost of emitting**, not
"the content is completely useless". This section is therefore a **structural diagnosis of the
mechanism design**, not a single-factor experimental proof; it explains "why tuning cannot save
this line".

### 6.2 Expressivity ceiling

Finite-dimensional real-valued genomes plus fixed behavioural formulas can span only a
finite-dimensional behavioural manifold, structurally mismatched with the combinatorial
unboundedness required for language. **In this device and with this expressivity carrier**, such
compositionality was not measured or implemented; E-021's `Δ_content/Δ_full ≈ 0.23` is a
**supporting side observation** (`[judged]`; gated attribution, `n_eff=3`), not a direct
measurement of expressivity. **The bottleneck is the expressivity carrier, not world fidelity** —
this is the first priority on restart.

### 6.3 K=2 "bistability" is an apparatus bug

The early K=2 stay/disperse bistability was eventually traced to `from_field` inferring a global
multiplier from background cell 0: that cell under-produced with about 40% probability, causing
apparatus drift. After the fix and the direct-read change (R320/R328), the "bistability"
conclusion is void. This is a direct case of "a positive result on an unvalidated apparatus may
be an illusion", and one motivation for the project's methodology discipline.

### 6.4 Other recorded structural phenomena

- **Magnus latitude imprint**: after the nonlinear Magnus mapping of temperature, a latitudinal
  hidden channel is imprinted into the moisture field, making the permutation null impure
  (corr −0.936 / −0.984 / −0.931). Hence batch C saw a terrain increment only when the
  latitudinal channel was absent (P1 Δz=+10.68 PASS vs P2 Δz=+0.12 fail).
- **kin channel is a placeholder**: the kinship channel in the old `sphere_engine` was never
  truly implemented; related conclusions must not be cited.
- **Perception bug**: the original judgment that "information asymmetry caused ecological
  collapse" was based on the `nb[:4]` half-plane bug; the whole batch is void.

## 8. Atmospheric line: J1 = FAIL, J2 = FAIL, J3 = NOT-RUN

### 8.1 Two routes and two benchmarks

- **Yi (self-developed Rust dry core `atmo_core`)**: P1 capability gate FAIL (13 FAIL / 2 PASS;
  `umax` diverged to 3.8e107, CFL 3.65095), then frozen for the record, not kept as a fallback
  fuse.
- **Jia (SpeedyWeather.jl 0.23.0)**: first the **dry Held–Suarez benchmark**, P1′ = PASS (13/13
  capabilities, 15/15 readings), then **J1 = FAIL final**; then the **wet Aquaplanet benchmark**,
  **J2 = FAIL final**. P1′/J1 and J2 are not the same benchmark; P1′ PASS must not be used as
  evidence for J1/J2.

### 8.2 J1 = FAIL (dry Held–Suarez)

15 readings, 13 PASS / 2 FAIL:

- `CONS-MASS` = **4.12793e-5** (threshold 1e-6; f64 attribution arm 4.43961e-5, also FAIL);
- `CONS-POLAR-TREND` = **0.334148** (threshold 0.01).

Attribution is separated: `CONS-MASS` is an ln(ps) representation effect; `CONS-POLAR-TREND` is
related to variability in the 69–78° band, but the attribution is sensitive to convention and
precision (the native control script recorded in the sign-off was not placed in the evidence
directory; independent methods give different magnitudes and signs). Neither criterion was
relaxed; failures are recorded as failures.

### 8.3 J2 = FAIL (wet Aquaplanet)

12 capabilities, 10 PASS / 2 FAIL:

- `AQ-TOA` = **7.016983 W/m²** (threshold 5);
- `CONS-WATER` = **1.079661e-3** (threshold 1e-3; Option 3 normalization 1.077105e-3 still over).

rev3 diagnostics recomputed on existing J2 data: the candidate window day60–120 has `AQ-TOA` =
7.867649 and `CONS-ENERGY` = 2.744521, a double FAIL; the control window day90–120 is
6.050132 / 1.080679, also a double FAIL. day90–120 is only a control, not a permitted alternative
route; even if a short window PASSes one criterion, that is a window effect, not a fixed
criterion. In the water-budget diagnostic, `clip_growth` accounts for +112.453% of the gate
residual (day30–120); in the same window `|true_closure|/ΣP` = 2.8414e-5, failing R1's `<1e-5`
condition. Separately, the 30-day (day0–30) online q-budget decomposition-residual proxy is
3.28e-6 (`diagnostic_only`); it is **not** a 120-day true closure, and **cannot** be compared
directly with the gate window day30–120.

### 8.4 J3 = NOT-RUN (not executed)

Executed P0-1…P0-11 under FROZEN rev3 (internal frozen file 525 lines, LF sha
`e69da203…0ba5282`; the public copy is sanitized, see 05 §4.1):

| Item | Status |
|---|---|
| P0-1 / P0-2 / P0-3 | **substantively not passed** |
| P0-4 / P0-5 / P0-7 / P0-11 | blocked by prerequisites |
| P0-6 / P0-8 / P0-9 / P0-10 | passed |

Root cause: J3's ON arm needs the online construction form of the Jia wet core, but the only
constructible **real core** on main is the dry `atmo_core`, whose `export` lacks `precip`
(`SyntheticCore` is only a synthetic-chain core and does not have the Jia wet-core form).
Constructing the ON arm under the frozen document triggers `ValueError: core.export 缺 'precip'`
at `bridge.py:155` (reproduced). Therefore:

- **zero coupling data**; C0 dual runs, 20 runs and P0-11 were not executed; S/D/C/I/E criteria
  were all not executed, with no judgment;
- archived NOT-RUN under frozen §7.1 / §8.1#1;
- the project owner's ruling **③ defer**: J3 is archived as final; no restart, no extension.

J3 does not change J2's FAIL and does not constitute any "falsification".
