## §一 一页结论（三选一）

**主结论＝(a) 口径重复成立；(c) G6 仪表 bug 排除；(b) 发射率真降被 (a) 吸收。**

1. **(a) 成立 [实测×独立路]＋[代码]**：发射＝伯努利 `rand_emit < signal_gene`（`sphere_engine.py:3613` 预生成、`:3636` 判定），每窗期望发射率 ≈ 群体 g15 均值 × 支付能力占比（`:3638` can_afford 滤除）。逐 seed 独立重算：`emit_rate_ratio` 与 `g15_ratio` **符号一致 8/8**，|比值差| max=0.0188／mean=0.0068；逐窗 Pearson r 逐 seed 0.755–0.976、**合并 160 窗 r=0.9839**。⇒ 判读稿 §四-1「J1×J2 方向 8/8 共动 [待核]」的 **[待核] 就此闭合为 [实测]**：E-056 J2（发射率不降）4/8 判负**不是独立证据**，是 J1（g15 升降）经发射码路的**机械投影**——两读数共享人口/基因组成协变，J2 无超出 J1 的信息量。
2. **(c) 排除 [实测×独立路]**：CSV 累计列（`g6_emit_events_cum`/`g6_emit_person_ticks_cum`）合并比重算的 `emit_rate_ratio` 与 summary 原生值 **8/8 逐位等值（maxΔ=0.00e+00）**；逐窗列自洽（`g6_emit_rate_window` ≡ Δevents/Δpt，maxΔ=0）；`g4_mem_bit_frac ≡ on/n` 逐行自洽（maxΔ=0）；`emit_events_total>0` 8/8（百万级人·次）⇒ 仪表在记真发射，无"恒零/漂移"形态。
3. **zero_pat=0 语义＝结构必然，非异常 [代码]**：`emit_zero_pattern_n` 计数对象是 **pattern==0 的"清格写"项数**（`s3_memory_probe.py:595/:661-666`），**不是**"发射次数为零"。E-056 装置 `signal_alphabet="8"`（summary meta `signal_alphabet_effective="8"`），"8" 档 `code_offset=1` ⇒ pattern ∈ {1..8}，**码 0 结构不可达**（`sphere_engine.py:118-119/:135-153`；对照："16" 档 offset=0 时 state=0 才是合法清格写）。⇒ zero_pat=0 全批是**预期值**；同时 A2「含 0 码」减扣条款对本批为 no-op（与判读稿 §三-42 口径注记一致，互证）。**"zero_pat=0 是否仪表 bug／是否等于没发射"两问皆消解。**
4. **(b) 吸收 [实测]＋[推断]**：不存在独立于 g15 的"发射率真降"证据——逐 seed |emit_ratio − g15_ratio|≤0.019，群体 g15 近中性（ratio_mean≈1.0044，判读稿原数）⇒ 发射率任何微降都落在 g15 漂移的机械传导范围内。[推断] 若支付能力占比有独立漂移，会被窗级 r<1 的残差吸收，本批未见系统性残差形态。
5. **G4 附项（PI 裁定 C 之一并）[实测]＋[代码]**：`g4_mem_bit_frac` 首读 0.596–0.643 复算等值、列内自洽——数据面无异常。口径冲突定位＝**纪元/档位混线**：「mem_bit 通路不在⇒G4 不可测」是 **alpha≠8**（SMOKE 期 alpha-16 载体）的记载（仪表装配告警仅在 `_alpha ≠ "8"` 时打出，`s3_memory_probe.py:621-624`）；本批 alpha-8 装置下 mem_bit 累加路径常驻（`sphere_engine.py:3655-3657`），且其输入 `_work_memory` 的写入（`:3598-3602`）与 rd_mode 无关 ⇒ **rd-off 下 G4 出读数是本档设计行为，不是口径漏洞**。跨纪元禁比（R14/R218）照守：0.596–0.643 不与 SMOKE 数值比较。**G4 读数之路线适用性仍归 PI/mirror 裁定，本稿只清算数据面。**

**后果条款（判读侧）**：此后 M1/L0 族批次中 `emit_rate_*` 与 `g15` **不得作两条独立证据并引**；要测"发射行为本身"（超出口径投影），需归一化读数（如 发射率/g15 均值＝支付能力占比探针）或 random-signal 对照臂——**属装置需求建议，不属本清算职权，上板仅作登记**。
