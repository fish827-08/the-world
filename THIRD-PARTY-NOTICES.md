This repository does **not vendor** third-party source code or binaries. Dependencies are
installed by the user from their upstream package registries and remain under their own
licenses. This file records the direct dependencies and the license obligations that matter for
redistribution.

The project's own code and documentation are licensed under Apache-2.0 (see `LICENSE`).

## Attribution texts

MIT and BSD licenses require preserving the upstream copyright notice and permission text when
the corresponding code is redistributed. Since this repository does not redistribute those
packages, the authoritative notices are shipped in the installed packages
(`*.dist-info`, `node_modules`, `~/.cargo/registry`). If you create a binary distribution that
bundles them, include the license files from those packages.

The Apache-2.0 license text applicable to this project is in `LICENSE`. Upstream Apache-2.0
components with their own NOTICE files (notably Apache ECharts) must retain those notices if
their code is bundled.
