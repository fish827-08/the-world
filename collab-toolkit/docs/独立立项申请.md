## 二、为什么值得独立立项

1. **受众不同**：主仓是科研平台（引擎/实验/判据）；collab-toolkit 是**多会话 AI 团队协作机制**——
   这套机制（零号规则 + 写入锁 + 板面体检 + 成本度量）对任何"多 AI 代理共仓协作"的项目都可复用，
   与 the-world 的科学内容零耦合。
2. **变更节奏不同**：引擎代码受"批跑期间不动"约束；协作工具需要快速迭代（锁 v1.0 → v1.1 仅隔数小时）。
3. **风险隔离**：协作工具出 bug 不得影响科学产物——独立目录 + 独立测试 = 爆炸半径清晰。
4. **治理透明**：独立仓让"协作成本度量"（裁定密度 19/天等）有单一落脚点，回应 P4"治理膨胀"批评时
   可直接指向工具与数据，而非口头承诺。
