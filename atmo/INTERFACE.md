## 0. 术语与硬口径（先读这一节，它是所有争议的仲裁依据）

| 项 | 口径 | 为什么 |
|---|---|---|
| 纬度索引 | **`j = 0` 是最南行，向北递增**（升序） | 与 `world/sphere_world.py:74` 的 `_lat[r] = -π/2 + (r+0.5)·Δφ` 同向；A17 已因反向表吃过**静默南北镜像**的亏 |
| 经度索引 | **`i = 0` 是 0°E，向东递增**，范围 `[0, 360)`，**周期性** | 与 numpy 习惯一致；跨接缝用 `(i±1) mod nlon` |
| 数组布局 | `float64`，**C 序**，3D 形状 `(nlev, nlat, nlon)`，索引 `arr[k, j, i]` | 层优先便于按层向量化；C 序保证 `numpy.ravel()` 与 Rust 逐字节同序 |
| 单位 | **全 SI**（m, s, K, Pa, kg/kg, W/m², rad）；**角度在接口层用度、核心内部用弧度** | 例外要显式写在字段表里，禁止"约定俗成" |
| 零度经线 | 0°E；**不用 -180..180** | 一种口径，不做兼容 |
| 外部表入口 | 任何外部数据（ExoPlaSim/观测/重映射结果）**必须显式声明纬序**并在读入时断言；北→南的源要翻转 | 同上，A17 教训 |
| 默认关 | `AtmoConfig.enabled = False`；`atmo_core` **不 import 任何 world/ 模块** ⇒ A3 接线前世界 digest 不可能变 | 派工 §二 |
| 一切"表" | **禁止**在核心内写"日照分布表""气候态表""预设降水图案"；太阳位置只能由轨道参数解析算出 | 派工 §三；AV 有写死审计门 |

## 1. 职责切分（**这一节是本契约最重要的一条裁定请求**）

派工 §三 与 §四 在"太阳几何"上有重叠（A1 写了"公转/自转 ⇒ 太阳高度角 ⇒ 大气顶短波"，A2 第 1 项也写了"太阳几何/短波"）。本草案按**能力边界**切开，请总审确认：

## 2. 网格

### 2.1 类型与分辨率

| 档 | nlat × nlon | 类型 | 格点数 | 用途 |
|---|---|---|---|---|
| **T21（默认）** | **32 × 64** | Gaussian（P₃₂ 的根） | 2 048 | 第 1–3 周开发与能力门主档；与既有 ExoPlaSim T21 表同族，便于对照 |
| **T31（升级）** | **48 × 96** | Gaussian（P₄₈ 的根） | 4 608 | 若 T21 判据通过、需要更细的急流/涡统计 |
| 规则经纬（备选） | 同 nlat×nlon | 等距纬度 | 同 | 仅在"必须与世界网格逐格对齐"的调试场景；**不作正式档** |

**为什么默认 Gaussian**：① 无极点格（极点不是奇异行，算子不需特判）；② 面积权由高斯求积给出，全球积分的离散误差极小（Σw/2 = 1 到 1e-15）；③ 与 `atmo_bridge/remap.py`（A17 已实现、已验证 4e-16 守恒）同族，A3 直接复用。

**代价（必须写进风险）**：Gaussian 网格的**纬向格距在极区急剧收缩** ⇒ 显式积分的 CFL 在极区不成立，见 §7.2。

## 3. 垂直坐标：8 层 sigma（地形跟随）

选 sigma 不选 p：世界有海拔（`world/env_field.py` 的地形），p 坐标在地形处要做遮蔽（massless layer）处理，第一版不引入这个复杂度。

| k | `sigma_half` 下界 | `sigma_full` 中心 | `p` @ ps=1013.25 hPa | 近似高度* |
|---|---|---|---|---|
| 0 | 0.00 | **0.025** | 25.3 hPa | 29.5 km |
| 1 | 0.05 | **0.095** | 96.3 hPa | 18.8 km |
| 2 | 0.14 | **0.200** | 202.7 hPa | 12.9 km |
| 3 | 0.26 | **0.330** | 334.4 hPa | 8.9 km |
| 4 | 0.40 | **0.475** | 481.3 hPa | 6.0 km |
| 5 | 0.55 | **0.625** | 633.3 hPa | 3.8 km |
| 6 | 0.70 | **0.775** | 785.3 hPa | 2.0 km |
| 7 | 0.85 | **0.925** | 937.3 hPa | 0.6 km |
| — | 1.00 | — | 1013.25 hPa | 0 km |

\* 近似高度 = `H·ln(ps/p)`，`H = 8000 m`，**只用于读表定位，不是模式量**。

- 定义：`σ = p / ps`，`σ_half[0] = 0`（模式顶），`σ_half[nlev] = 1`（地表）。
- 层中心压力 `p_k = ps · sigma_full[k]`（**诊断量**，每步由 `ps` 重算）。
- 垂直速度 `w ≡ σ̇`（**单位 s⁻¹**，不是 m/s！），边界条件 `σ̇(σ=0) = σ̇(σ=1) = 0`。
- 8 层是**下限**：T21/L8 能跑出 Held–Suarez 的定性结构（急流/涡），但定量（急流位置、EKE）会粗；是否 L12/L20 见 §11 OPEN-6。

## 4. 状态数组（prognostic + 诊断）

全部 `float64`，C 序，`(nlev, nlat, nlon)`（`p`/`ps` 见下）。

| 名 | 形状 | 单位 | 类型 | 说明 |
|---|---|---|---|---|
| `u` | `(nlev,nlat,nlon)` | m/s | **prognostic** | 纬向风，**向东为正** |
| `v` | `(nlev,nlat,nlon)` | m/s | **prognostic** | 经向风，**向北为正** |
| `w` | `(nlev,nlat,nlon)` | **s⁻¹** | **prognostic** | **σ̇ = dσ/dt**；顶/底为 0 |
| `T` | `(nlev,nlat,nlon)` | K | **prognostic** | 层中心温度（不是位温） |
| `ps` | `(nlat,nlon)` | Pa | **prognostic** | 地表气压，由质量连续方程推进 |
| `q` | `(nlev,nlat,nlon)` | kg/kg | **prognostic（但干动力不动它）** | 比湿；A1 恒保持 0，A2 接管。放进来只为固定内存布局 |
| `p` | `(nlev,nlat,nlon)` | Pa | **诊断** | `p_k = ps·sigma_full[k]`；每次 `step()` 写出，**不参与 digest** |

**派生（不进状态、按需算）**：`Φ = g·z`、`ω = dp/dt`（Pa/s）、`θ = T·(p/p0)^κ`、`ρ = p/(R_d·T)`、`wz`（m/s）。

## 6. 方程集（本契约覆盖的两个模式）

**模式 A：2 层浅水（第 1 周）** — `u, v, h₁, h₂` 两组，`h = 层厚`。
```
∂u/∂t = -(u·∇)u - f×u - g∇(h₁+h₂) + 扩散 + 滤波
∂h/∂t = -∇·(h·u)
```
用途：Rossby 波速、位涡守恒、斜压不稳定起涡（AV 判据）。

**模式 B：8 层原始方程（第 2–3 周）** — sigma 坐标、静力平衡、干空气。
```
du/dt = -f k×u - ∇Φ - (σ̇/ps)·∂p/∂σ ...   （水平动量）
dT/dt = (κT/p)·ω + Q_HS/(cp·)             （热力学；Q_HS = Held–Suarez 牛顿冷却）
∂ps/∂t = -∫₀¹ ∇·(ps·u) dσ
∂(ps·σ̇)/∂σ = -∂ps/∂t - ∇·(ps·u)          （质量连续）
∂Φ/∂lnσ = -R_d·T                          （静力平衡）
```
`Q_HS`（Held–Suarez）：`-k_T(φ,σ)·(T - T_eq(φ,σ))`，参数全部进 `AtmoConfig.held_suarez`（见 §9.4）。

> 离散细节（Arakawa C 格点 vs 谱、半隐式 vs 显式）**不属于接口**，由 A1 内部决定并在周报里说明；接口只固定"输入什么、输出什么、确定性如何"。

## 7. 时间步与耦合节拍

### 7.1 参数

| 参数 | 默认 | 允许范围 | 说明 |
|---|---|---|---|
| `dt_atmo` | **288 s**（W2 起；v1.0.3 更正） | **288–900 s**（但 900 实测不可用，见下） | 内部子步的**稳定性上限**（不是固定步长） |
| `tick_seconds` | 36 s（世界默认；360 为 A20.3 的慢档） | 36 / 360 / 1200 | 世界 tick 时长，由 A3 传入 |
| `step_mode` | `"tick_multiple"` | 见 §11 OPEN-1 | 耦合节拍口径 |

> **v1.0.3（2026-10-20，MINOR，审 A1 W2 时签发）**：`dt_atmo` 默认/范围从 `900 s / 600–900` 更正为
> **`288 s / 288–900`**。依据（A1 W2 实测 + 总审独立复核）：
> - A1：`dt=900` NaN@40 步、`dt=600` NaN@289 步（扰动初值）；**只有 `dt=288` 稳跑 3000 步/10 天**（质量漂移 −2.2e-13 声明值）。
> - 总审独立（等温静止初值）：`dt=900` **NaN@74 步**（复现不稳）；`dt=288` 300 步 0 NaN、两次逐位、≈12.8 ms/步。
> - `dt=288 = 36 s × 8` ⇒ `tick=36 s` 时 **k=8**、**109,500 交换/年**（365 d）；A3 的时钟实现无需改公式，只改配置默认值。
> - 后续若用半隐式/更好滤波提升到 600/900，须走变更单 + AV 复核；在此之前**默认 288**。


### 7.2 极区 CFL（`[实测]`，c = 300 m/s 的外重力波）

| 网格 | 赤道 `dx` | 极行 `dx` | `dt=600` 赤道/极行 | `dt=900` 赤道/极行 |
|---|---|---|---|---|
| T21 | 624.7 km | 46.2 km | 0.29 / **3.89** | 0.43 / **5.84** |
| T31 | 416.8 km | 20.7 km | 0.43 / **8.71** | 0.65 / **13.06** |

⇒ **极区必须有滤波/子步**（§7.4），这不是"优化"，是能不能跑的问题。

### 7.3 耦合节拍（**推荐口径 M2′：tick 整数倍**）

设定：atmo 的步长必须是世界 tick 的**整数倍**，且不超过 `dt_atmo`。这样 (a) 不超稳定上限，(b) 时钟零漂移，(c) 子步数确定。

```
if tick_seconds <= dt_atmo:
    k   = floor(dt_atmo / tick_seconds)      # 每 k 个世界 tick 推进 1 步
    n_sub = 1
    dt_step = k * tick_seconds
else:
    n_sub = ceil(tick_seconds / dt_atmo)     # 一个 tick 内拆 n_sub 步（= 派工字面口径）
    k   = 1
    dt_step = tick_seconds / n_sub
```

四种现实组合（`k` = 每几步交换一次边界）：

| `tick_seconds` | `dt_atmo` | `k` | `n_sub` | `dt_step` | 含义 |
|---|---|---|---|---|---|
| 36 | 900 | **25** | 1 | **900 s** | 每 25 个世界 tick 交换一次 ⇒ **35,040 步/年**（365 d；A3 勘误：原写"1.5 万步"有误，2026-10-20 v1.0.1 更正） |
| 36 | 600 | 16 | 1 | 576 s | 同上，步更密 |
| 360 | 900 | 2 | 1 | 720 s | 每 2 tick 交换 |
| 360 | 600 | 1 | 1 | 360 s | 每 tick 交换（最贵） |
| 1200 | 900 | 1 | 2 | 600 s | 一 tick 内两步 |

**派工字面口径 M1**（`n_sub = ceil(tick_seconds/dt_atmo)`，每 tick 都推进）在 `tick=36` 时退化为 **dt=36 s、每年 87.6 万步**——比 M2′ 贵 **25 倍**，且没有稳定性收益。**本草案推荐 M2′**，把 M1 保留为 `step_mode="tick_split"` 的兼容开关。**请总审裁定（OPEN-1）**。

### 7.4 极区处理（周 1 最简可用版）

1. **纬向 1-2-1 平滑**（作用在**倾向**上，保持纬向平均不变）：`|φ| > φ_f`（默认 60°）的行，施加 `n(φ)` 次，`n` 从 0 线性增到 `n_max`（默认 4）。
2. **极行拉平**：`|φ| > 80°` 的行，对 `u,v` 的纬向扰动按 `cos²φ` 权重衰减。
3. 参数进 `AtmoConfig.polar_filter`（`phi_start_deg=60, n_max=4, phi_flat_deg=80`），**默认开**（它属于稳定性，不是物理）。
4. `diag` 必须输出 `cfl_max`、`cfl_lat_deg`、`cfl_k`（最坏点位置），AV 据此判"滤波是否真的压住了极区"。

### 7.5 交互边界

- **只在耦合步边界交换**：A3 在 `step()` 前后读写 §5/§8.3 的场；`step()` 内部不回调 Python、不读外部可变状态。
- `step()` 是**纯函数式**的：`(state, forcing, dt) → (state′, diag)`，同样的输入逐位得到同样的输出。

## 8. Python 接口（PyO3 扩展 `atmo_core`）

### 8.1 模块级

```python
import atmo_core as ac

ac.__version__          # "0.1.0"（扩展版本）
ac.INTERFACE_VERSION    # "0.1.0-draft" → 冻结后 "1.0.0"
ac.contract()           # dict：布局/单位/索引/字段名/digest 规格（A3 启动时断言用）
```

### 8.2 网格与状态

```python
g = ac.grid_spec(nlat=32, nlon=64, nlev=8, kind="gaussian")
#   → dict，键见 §2.3；所有一维数组 float64、C 序

st = ac.make_state(g, T0=288.0, ps0=101325.0)
#   → dict{"u","v","w","T","p","ps","q"}；u/v/w/q 全 0，T 均匀 T0，ps 均匀 ps0，p 已按 sigma 填好
#   ⚠️ v0 只接受 nlev=8（其他层数显式报错；升层见 §11 OPEN-6）
```

### 8.3 推进与诊断（**签名已定，实现按周推进**）

```python
diag = ac.step(st, forcing, dt=900.0)
#   st      : §4 的 dict（原地更新；返回 None 或新 dict 的取舍待定，见 OPEN-5）
#   forcing : dict{"sst","mask","h","alb","seaice","orbit","held_suarez", ...}
#   dt      : 秒
#   diag    : dict{
#       "cfl_max": float, "cfl_lat_deg": float, "cfl_k": int,
#       "mass": float, "mass_rel_err": float,
#       "energy": float, "energy_rel_err": float,
#       "tmin": float, "tmax": float, "ps_min": float, "ps_max": float,
#       "nan_count": int, "step_index": int, "time_s": float,
#   }
```

### 8.4 算子（AV 单独验，与 `step` 同一套离散）

```python
ac.divergence(u, v, g)      # → (…, nlat, nlon)
ac.vorticity(u, v, g)       # → 同上
ac.gradient(f, g)           # → (dfdx, dfdy)
ac.laplacian(f, g)          # → 同上
ac.coriolis(g)              # → (nlat,)
```
接受 2D `(nlat,nlon)` 或 3D `(nlev,nlat,nlon)`；**纬向周期、经向不周期**。

### 8.5 太阳几何（A1 交付，见 §1）

```python
s = ac.solar(orbit, t_seconds)
# orbit: dict{"year_s","rotation_period_s","obliquity_rad","eccentricity",
#             "equinox_offset_s","solar_constant_w_m2","radius_m"}
# → dict{"cosz": (nlat,nlon), "toa_sw": (nlat,nlon) W/m²,
#        "subsolar_lat_deg": float, "subsolar_lon_deg": float,
#        "earth_sun_dist_au": float}
```
`cosz = max(0, sin φ·sin δ + cos φ·cos δ·cos H)`，`H` = 时角；`toa_sw = S0·(a/r)²·cosz`。
**纯解析，逐时算出，不许查表**（AV 会扫常量图案）。

### 8.6 确定性摘要

```python
ac.digest(st)                  # → 16 位十六进制（FNV-1a 64）
ac.digest(st, ["u","T"])       # 只哈希指定字段（调试用）
```
**digest 覆盖的字段与顺序固定**：`u, v, w, T, ps, q`（`p` 是诊断量，**不哈希**）。
字节序：每个 `f64` 的 `to_le_bytes()`，按 `k→j→i` 遍历，字段间不插分隔符。跨平台（Windows/Linux x86-64）应逐位一致。

### 8.7 出口场导出（**v1.0.2 新增，MINOR**；A3 二轮实测缺此签名）

```python
fields = ac.export(st, g)      # → dict，至少含 A1 负责的出口场
#   {"t2m":  (nlat,nlon) K,
#    "u10":  (nlat,nlon) m/s,
#    "v10":  (nlat,nlon) m/s}
```
- **A1 负责**：`t2m/u10/v10`（按 §10 的 v0 公式；实现后 `placeholder=false`，仍是外推近似要保留 `approx=true` 标记）。
- **A2 负责**：`precip/cloud/sw_sfc/lw_sfc` 由 A2 物理模块单独产出，**不出现在 `ac.export` 的必填键里**；
  A3 负责把 A1 的 `export` 与 A2 的输出**组装**成 §10 完整出口 dict；缺失键填 0.0 并标 `placeholder=true`。
- **禁止**：A1 在 `export` 里猜降水/云/辐射；A3 不得用 `st` 自行反推 A1 已负责的字段（唯一真源）。
- A3 的 `ModuleAtmoCore` 适配器按本签名对接；A1 交付前允许其 `NotImplementedError`（A3 已如此实现，不返回假数据）。

## 10. 出口场（atmo → 世界，A3 消费）

| 键 | 形状 | 单位 | 谁算 | v0 口径 |
|---|---|---|---|---|
| `t2m` | `(nlat,nlon)` | K | **A1** | 最低层 `T` 按干绝热递减率外推到 2 m：`T2m = T[7] + 0.0098·(z[7] − 2)`。**是近似，不是地表能量平衡**（后者要等 A2 的陆面模块） |
| `u10, v10` | `(nlat,nlon)` | m/s | **A1** | `u10 = u[7]·ln(10/z0)/ln(z[7]/z0)`，`z0 = 0.1 m`（可配）；`z[7]` 由静力积分得 |

| `cloud` | `(nlat,nlon)` | 1 | A2 | v0 恒 0 |

## 12. 变更规则

1. **冻结后**任何字段名/形状/单位/索引方向/时间的改动 = **接口变更单**（一页：改什么、为什么、影响谁、谁批），总审签后才动。
2. 新增**可选**字段（不改变已有键语义）也走变更单，但可标 `MINOR`（`1.0.0 → 1.1.0`）。
3. **禁止**：改纬度索引方向、改 `w` 的单位、改 digest 的字段顺序——这三项一动，历史读数全部作废。
4. 每次交付必须附：`INTERFACE_VERSION`、commit hash、`atmo_core.contract()` 的输出。
