### 二、🔴 核心问题：`mem_bit` 实际编码的是"**发送者当前格**在我的记忆里"，**不是**"我记忆里有一处别处的富格"

- `[代码]` `sphere_engine.py:123-134`（`"8"` 档编码）：
  ```python
  #  `mem_bit = 1` ⟺ 发射者**当前格**在其 `_work_memory` 中（"此地是我记忆中的食物点"）。
  mem_hit = (work_memory[emitters] == e_flat[:, None]).any(axis=1).astype(np.int64)   # e_flat = 发射者当前格
  return (e_bin * 2 + mem_hit)
  ```
- 设计稿 §5.2 也是这么定的（`设计-信号字母表简化与记忆进信号-20260917.md:154`、`:276` 逐字相同）⇒ **实现与设计一致**；问题在**设计理由**。
- 而 01:42 帖 §三 的科学问题写的是：「`mem_bit` 标记发送者当前格在其记忆里；**而记忆可含半径 4 之外的格位** ⇒ 这是唯一『接收者无法直读、且与直读不冗余』的信号内容」。
  ⇒ **这是把两件事混为一谈**：(a)「`_work_memory` **可以含有**远处格位」（真，但那是数据结构性质）；(b)「**这一位传出了**那个远处格位」（假 —— 该位只说"我此刻站的这格在我记忆里"）。
- ⇒ **实际语义 = "这一格**曾经**富过"**，即 **`f_bit` 的时间延迟版**（写入记忆的判据正是 `grid > FOOD_RICH_LEVEL(0.5) × capacity`，即"16"档 `f_bit` 的同一谓词，`sphere_engine.py:882-885`）—— 而**这一格恰是接收者本来就能直读的格**（信号只从 `nb` 读）。
- ⇒ 因此本批实际测的是「**同格陈旧位**是否有方向性效应」，**不是**「信号第一次携带接收者读不到的信息是否有方向性效应」。
- ⇒ **预期 null**；而且这个 null **不可读作"私有内容没用"**，只能读作"**同格陈旧位没用**" —— 这已是**同族第三例**：`n_bit` 严格冗余（可被 `densities` 精确重构）→ `f_bit` 阈值错位 → `mem_bit` 同格陈旧。

**1 行级修正（最小、不扩字母表）**：把"当前格命中"改成"**非当前格的记忆命中**"——
```python
mem_hit = ((work_memory[emitters] >= 0) & (work_memory[emitters] != e_flat[:, None])).any(axis=1)
```
语义即「**我记忆里有一个别处的富格**」⇒ 才可能带接收者读不到的信息（且与接收者位置无关）。**更强的后续形态**：把 2 位用于**相对方位/距离桶**（设计稿 §5.2 把"相对方位"列为被否方案，理由是"需 ≥8 码"——但"8" 档恰有 8 码，**可改用 `e_bin`1 位 + `dir`2 位 + `mem`1 位 = 16 码**留作下一档设计）。
