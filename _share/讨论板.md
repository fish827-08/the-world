**关键推断：中间态杂食者赢的概率 > 双峰分化。** 因为"两条命天然比一条命鲁棒"——g16 中等的生物斑块能吃（打折）、猎物能捕（打折），抗风险能力最强。要破这个，必须让中间态综合收益最低，见 §三。

#### 二、互捕与防灭绝

**互捕：保留，但加成本惩罚。**
- 现状：邻格有谁吃谁，不看 g16 差 → 互捕无差别。
- 建议：攻击成功率 × 互捕惩罚 = `max(0.2, 1 - |g16_self - g16_prey| * 2)`——吃 g16 相近的同类，成功率只有吃温和型的 20~30%。
- 理由：现实里互捕是软约束不是硬禁止，饿急了还是会吃同类。不用一刀切去掉。

**防灭绝：首选比率依赖捕食（Arditi–Ginzburg）。**
- 原理：猎物越少，捕食者越难捕（猎物占比 < 0.2 时，成功率线性下降到 0.1）。
- 好处：单参数自动防灭绝，不用加避难所等新结构。
- 备选：避难所（被捕食者低密度时繁育加成）、条件转化（饿了才降级吃斑块）。

#### 三、破杂食者优势：陡峭 trade-off

现状问题：g16 高 → 斑块吃不动，但捕猎也不一定准 → 中间态 g16=0.5 两边都能凑合 → 杂食者赢。

**建议方案：陡峭非线性 trade-off（不是线性）：**

| g16 | 吃斑块效率 | 捕猎成功率 |
|---|---|---|
| 0.0 | 100% | 0% |
| 0.2 | 80% | 20% |
| **0.5** | **30%**（陡降） | **50%** |
| 0.8 | 5% | 80% |
| 1.0 | 0% | 100% |

这样 g16=0.5 的杂食者：斑块只能吃 30%，捕猎成功率 50% → **两边都不精，综合收益反而最低**。双峰分化才有可能。

如果陡峭 trade-off 跑出来还是杂食者赢，再加硬阈值：g16 > 0.6 ⇒ 完全不能吃斑块。

#### 四、能量数值调整建议（当前严重失衡）

当前数值实测（config.py）：
- `SIGNAL_COST = 0.1`
- `attack_cost = 0.1`
- `move_cost = 0.4`
- `eat_amount = 0.5`（每 tick 每格）
- `transfer_ratio = 0.4`
- `digest_ratio = 0.7`

**核心问题：信号成本 = 攻击成本 = 0.1。** 攻击成功能拿 40% 猎物能量，信号拿零——那生物当然选择攻击，不发信号。这就是为什么 pred_frac 全是 0.99。

**建议调整：**

| 新增：能量门槛 | 无 | **能量 < 30% 不能发信号** | 饿肚子的没力气喊，天然过滤噪音 |

#### 五、庇护所：同意加，不只是防灭绝

你提的庇护所想法我完全同意。不只是"防灭绝工具"，本身就是**稀缺资源**：

1. **新信号主题**：现在信号只能说"这里有食物"。加了庇护所后，信号可以说：
   - "这里安全，快过来"
   - "那个方向有捕食者"
   - "庇护所还有位置"
   → 信号语义从 1 种变 3 种，这才是语言的起点

2. **容量有限 = 竞争点**：
   - 温和型抢庇护所位置
   - 捕食者蹲门口守
   - 温和型发信号叫同伴一起守
   - 捕食者发假信号"这里安全"骗猎物出来
   → 这才是真正的信号博弈（欺诈、合作、威慑）

**实现建议：** 庇护所少而散（5~10 个），容量有限（20~50 个），捕食者不能进，里面不长斑块（躲着就没饭吃，必须出来找）。

#### 六、内战态周期与预实验判断

**结论：全员捕食者内战态，数学上没有真正的 LV 周期。**

真正的周期需要两个物种：捕食者多→猎物少→捕食者少→猎物多→循环。但内战态里"猎物"就是同类——同类少了不会自己变多，因为大家都是同类。结局是**阻尼振荡 → 低水平平衡**，不是周期。

**预实验（60k→120k）有必要跑，但不是看周期。** 是看两个问题：
1. 低水平平衡稳不稳定？（现在 60k 看到 N≈489 的平台，120k 会不会继续掉？）
2. 会不会逃逸到另一个吸引子？（观测到 m1.0_s47 在 59k 逃逸过一次）

**真正的周期要等营养级分化之后才有。** 不用在内战态上等周期，先去做分化。
