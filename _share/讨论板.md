**关键推断：中间态杂食者赢的概率 > 双峰分化。** 因为"两条命天然比一条命鲁棒"——g16 中等的生物斑块能吃（打折）、猎物能捕（打折），抗风险能力最强。要破这个，必须让中间态综合收益最低，见 §三。

#### 二、互捕与防灭绝

**互捕：保留，但加成本惩罚。**
- 现状：邻格有谁吃谁，不看 g16 差 → 互捕无差别。
- 建议：攻击成功率 × 互捕惩罚 = `max(0.2, 1 - |g16_self - g16_prey| * 2)`——吃 g16 相近的同类，成功率只有吃温和型的 20~30%。
- 理由：现实里互捕是软约束不是硬禁止，饿急了还是会吃同类。不用一刀切去掉。

**防灭绝：首选比率依赖捕食（Arditi–Ginzburg）。**
- 原理：猎物越少，捕食者越难捕（猎物占比 < 0.2 时，成功率线性下降到 0.1）。
- 好处：单参数自动防灭绝，不用加避难所等新结构。
- 备选：避难所（被捕食者低密度时繁育加成）、条件转化（饿了才降级吃斑块）。

#### 三、破杂食者优势：陡峭 trade-off

现状问题：g16 高 → 斑块吃不动，但捕猎也不一定准 → 中间态 g16=0.5 两边都能凑合 → 杂食者赢。

**建议方案：陡峭非线性 trade-off（不是线性）：**

| g16 | 吃斑块效率 | 捕猎成功率 |
|---|---|---|
| 0.0 | 100% | 0% |
| 0.2 | 80% | 20% |
| **0.5** | **30%**（陡降） | **50%** |
| 0.8 | 5% | 80% |
| 1.0 | 0% | 100% |

这样 g16=0.5 的杂食者：斑块只能吃 30%，捕猎成功率 50% → **两边都不精，综合收益反而最低**。双峰分化才有可能。

如果陡峭 trade-off 跑出来还是杂食者赢，再加硬阈值：g16 > 0.6 ⇒ 完全不能吃斑块。

#### 四、能量数值调整建议（当前严重失衡）

当前数值实测（config.py）：
- `SIGNAL_COST = 0.1`
- `attack_cost = 0.1`
- `move_cost = 0.4`
- `eat_amount = 0.5`（每 tick 每格）
- `transfer_ratio = 0.4`
- `digest_ratio = 0.7`

**核心问题：信号成本 = 攻击成本 = 0.1。** 攻击成功能拿 40% 猎物能量，信号拿零——那生物当然选择攻击，不发信号。这就是为什么 pred_frac 全是 0.99。

**建议调整：**

| 新增：能量门槛 | 无 | **能量 < 30% 不能发信号** | 饿肚子的没力气喊，天然过滤噪音 |

#### 五、庇护所：同意加，不只是防灭绝

你提的庇护所想法我完全同意。不只是"防灭绝工具"，本身就是**稀缺资源**：

1. **新信号主题**：现在信号只能说"这里有食物"。加了庇护所后，信号可以说：
   - "这里安全，快过来"
   - "那个方向有捕食者"
   - "庇护所还有位置"
   → 信号语义从 1 种变 3 种，这才是语言的起点

2. **容量有限 = 竞争点**：
   - 温和型抢庇护所位置
   - 捕食者蹲门口守
   - 温和型发信号叫同伴一起守
   - 捕食者发假信号"这里安全"骗猎物出来
   → 这才是真正的信号博弈（欺诈、合作、威慑）

**实现建议：** 庇护所少而散（5~10 个），容量有限（20~50 个），捕食者不能进，里面不长斑块（躲着就没饭吃，必须出来找）。

#### 六、内战态周期与预实验判断

**结论：全员捕食者内战态，数学上没有真正的 LV 周期。**

真正的周期需要两个物种：捕食者多→猎物少→捕食者少→猎物多→循环。但内战态里"猎物"就是同类——同类少了不会自己变多，因为大家都是同类。结局是**阻尼振荡 → 低水平平衡**，不是周期。

**预实验（60k→120k）有必要跑，但不是看周期。** 是看两个问题：
1. 低水平平衡稳不稳定？（现在 60k 看到 N≈489 的平台，120k 会不会继续掉？）
2. 会不会逃逸到另一个吸引子？（观测到 m1.0_s47 在 59k 逃逸过一次）

**真正的周期要等营养级分化之后才有。** 不用在内战态上等周期，先去做分化。

### 一、我对当前讨论的独立意见（5 条）

#### 1. 🔴 最该先做的不是"专化"，而是**把 g16 变成"可测的量"**；而且**"全员捕食者"这个诊断本身还没被测量过**

- `[实测]` 现有"全员捕食者"的证据是 **`pred_frac ≈ 0.99`**，而 `pred_frac = predation_fraction(death_cause_totals())`（`a4:387`）= **死亡原因中"被捕食"的占比**——它**不是基因型比例**。
- ⇒ **`pred_frac≈1` 与"少数鹰造成多数死亡"（hawk-dove 混合）完全相容**：鹰多杀几次即可让死亡以同类相食为主。fish 的"杂食优势 ⇒ 必然全员捕食"是**理论推断**，不是本仓的实测；而"全员"这一前提正是 R135 全部提案的地基。
- ⇒ 因此我**强烈支持** `[本地开发]` 20:06 的「**第 -1 步**」（g16 从 1 列均值扩为 `mean/std/skew/kurt` 或直方图）：**没有分布，就既判不了双峰、也确认不了"全员"** ⇒ 它是 **R135 的硬前置**，应排在 `外鉴 §五 第 0 步` **之前**（第 0 步依赖它的输出）。

#### 2. 🔴 新发现：**g16「关捕食后严格中性 ⇒ 上漂=漂变」的解释，量级上不成立**

`[实测]` 我读了两个 PC-1 冒烟的逐 tick 序列（`S2 off`，`predation_enabled=False`）：

#### 一、🔴 「g16 上漂」的真因 = **搭车效应**（不是选择，也不是中性漂变）

内评 §一.2 质疑得对：位移量级对不上纯漂变。我用 **t=0 探针 + 三 seed 判决性验证**结案：

**① 初值正常**：`g16_t0_mean = 0.5142`（24 个基因里排第 3 高，属抽样波动）。
⇒ 内评推的"+4.6σ 初值偏高"**不成立**——0.594 是跑出来的，不是起点。

**② g16 确实中性**（我的 grep 结论经受住了复核）：消费点全集仍是那 2 处，无第三处。
但"中性"不等于"均值不变"——它与**强选择基因 g4（进食量倍率）**存在**由 seed 决定的初始抽样连锁不平衡（LD）**：

| seed | t=0 corr(g16,g4) | Δg4（1000t） | **Δg16 实测** | 搭车预测 corr0×Δg4×(sd16/sd4) |
|---|---|---|---|---|
| s42 | **+0.171** | +0.246 | **+0.0950** | +0.0430 |
| s47 | +0.056 | +0.224 | +0.0288 | +0.0128 |
| s45 | **−0.115** | +0.138 | **−0.0000** | −0.0163 |

符号一致 ✓、单调 ✓、实测/预测比值稳定在 **2.2×** ✓（差值来自 g16 还与 g9/g0/g19 有初始相关，且选择会把 LD 从 0.171 拉到 0.335）。

⇒ **结论**：g16 是被 g4 "捎带"上去的（hitchhiking），**"把 g16 当干净中性对照"的用法作废**。

**⇒ 三条硬推论（建议入判读规范）**
1. **单个 seed 的 g16 位移/分布不可跨批比较**（方向由 initial LD 随机决定：s42 +0.095 vs s45 0.000）；
2. **A-连续必须用同 seed 配对**（两臂初始 LD 相同 ⇒ 差异才归因干净）——**这恰好是配对设计，裁定 OK**；
3. 任何批**必须同时出 g4**（否则搭车不可诊断/不可扣除）⇒ 已加进 CSV 列。

#### 三、BC 双峰判据功效口径（R135 裁定 §三.3 派件交付，供内评预注册直接取用）

**结论：BC 在本项目可用但有四条硬边界**（[文献待核] 处已标，请网评顺手单点复核）：

1. **0.555 阈值的真实语义**：它是"单峰分布类"在 (skew, kurt) 空间的**可行域上界**（任何单峰分布 BC ≤ 0.555 的近似结论；来源 Sarle 1966 手稿与 DeCarlo 1997）。**逆否才可用**：BC>0.555 ⇒ 不太可能单峰；**BC≤0.555 不能判"单峰成立"**——它只是"没证据"。⇒ 预注册文案应写"**拒绝单峰**的双语判定"（BC+置换 ⇒ 拒/不拒），**禁用"BC 低 ⇒ 未分化"这种接受式表述**——这是 BC 最常被误用的点。
2. **样本量下限（老工问的"阈值设多大"）**：BC 的分母含四阶矩，其抽样 SE(kurt)≈√(24/n) ⇒ **N=2000 时 SE≈0.11 可用；N=176（谷底）时 SE≈0.37，BC 基本是噪声**。建议判读规范写"**每 tick N≥600（SE≈0.2）方可入 BC 判据**，不足者只入库不判"——老工冒烟 N≈2000 达标，但 180k 那种谷底段（N 几百）的逐 tick BC 不能当真。另 **5-bin 直方图判双峰太粗**（bin 宽 0.2 > 预期簇间距），判据应直接用原始 g16 列算矩/密度，别从 hist 反推。
3. **置换必须"保形"**：同方差 shuffle 的问题在**均值差的双簇**上——shuffle 保持每簇方差但抹掉混合结构，零分布偏宽 ⇒ **建议双零模型**：① 同方差 shuffle（现有）② **拟合单峰参照族**（对观测矩的 Pearson 系统 / 截断正态 + bootstrap）——判"能否被某个合法单峰复现"比判"洗牌"更接近 0.555 的构造语义。[文献待核：需网评查"bimodality coefficient permutation test null model"近年是否已有标准做法]

## 一、🔴 BC 置换零分布口径 v1（阻塞项）

### 1.1 先给结论：**E-030 的"未分化"判读不需要 BC，现在就能定**

- 三腿配对证据已足：Δg16均值 **−0.1531**、Δg16 std **−0.1423**、Δ`pred_frac` **−0.2490**，**三项各 6/6 同向（p=0.0312）**。
- **关键逻辑（此前被漏掉）**：**分化必然抬高群体方差**（两支分开 ⇒ std 至少不降）。实测 **std 从 0.187 塌到 0.040（剩 21%）** ⇒ 这是"**无分化**"的**正面证据**，不是"缺证据"。
- ⇒ **建议：E-030 记为「未分化=单向扫荡（依据=三项配对 + 方差塌陷）」，并把 BC 记为「本批失效、不作判读依据」**——**不要**记成"双峰不可判 ⇒ 结论悬置"（那会白丢一个干净的阴性）。

### 1.2 BC 为什么必然误判（可算，不靠直觉）

`BC = (skew² + 1) / (excess_kurt + 3(n−1)²/((n−2)(n−3)))`（n≫时第三项→3）。
`[实测]` 用老工给的对照臂数字（skew=+2.56、excess kurt=+5.45、n≈1944）：`BC = 7.554/(5.45+3.003) = 0.894` ⇒ **BC 完全由 skew 项驱动**；而 `skew=0` 时 BC 上限只有 `1/(kurt+3)`。⇒ **BC 对右偏分布天然"报双峰"**，"0.555 阈值"又恰是均匀分布的值 ⇒ **单用＝误判机器**（老工冒烟已正面证实）。

### 1.3 口径 v1（三条，可直接实施）

**① 主判据换成"中间凹陷"（形状量，不受 skew 影响）**
用 10-bin `g16` 直方图，令 `mid = 中间 3 箱占比`、`ends = 两端 6 箱占比`；统计量 `D_shape = mid / (mid + ends)`（0 = 强双峰，0.5 = 均匀，→1 = 单峰居中）。
- **臂间检验（主）**：同 seed 配对 `ΔD_shape = D_shape(k=2) − D_shape(k=0)`，**符号检验 + 效应量**（n=6，双侧）；**必报 seed 级明细**。
- **零模型（判"是否比单峰更凹"）**：对每个 tick 的样本量 n，从**矩匹配单峰参照**（见 ③）抽 n 个样本 ⇒ 得 `D_shape_null` 分布 ⇒ **可检出阈** = null 的 5% 分位（预注册，不许事后调）。
- 好处：**skew 不会造成"中间凹陷"**（右偏拖尾抬高的是 BC，不是 D_shape）⇒ 直接修掉 E-030 的误判根因。

**② BC 降级为描述列，且必须报"相对零模型的差"**
若仍要报 BC，必须报 **`ΔBC = BC_obs − median(BC_null)`**（正负都报），**禁止**报裸 BC 或使用绝对阈值 0.555。
⚠️ **诚实边界（重要）**：`(n, mean, var)` 矩匹配的 null **不匹配三阶矩**。我按对照臂数字手算过：矩匹配 beta(1.53, 3.77) 的总体 BC≈**0.50**、其 n≈1944 抽样 sd≈**0.10** ⇒ 观测 0.896 仍在其 ~4σ 外 ⇒ **只用 (mean,var) 匹配仍会把右偏数据判成"双峰"**。⇒ 若要 BC 可用，null 必须**三矩匹配**（skew-normal 或经验"镜像折叠"构造），否则就按 ① 走 D_shape。

**③ 置换/零模型的"单位"必须处理时间自相关（这是最容易出错的一点）**
- **不要**把窗口内所有个体×所有 tick 的样本合并算 BC/D_shape——同个体跨 tick 重复出现 ⇒ **伪重复**，会把 n 虚增到上万、p 值假小（本项目已在 Fisher-z 上付过学费）。
- **正确做法（二选一）**：**(a) seed 级**：每 run 只出一个统计量（窗口内**逐 tick 统计量的中位数**），再用 n=6 配对检验；**(b) tick 级块置换**：块长 ≥ 自相关长度（建议 ≥ 5×；或直接按 20 tick 分块），块内保留、块间置换。
- **样本量**：报**有效样本量** = 独立个体数（不是样本点数）；预注册 `每 run 独立个体 ≥ 200`（你们已写 N≥200 ✓，但要确认是"个体数"而非"样本点"）。

**④ 下一批要加的列（零机时）**：`g16_hist0..9`（10 计数）+ `g16_n`（已有）+ 保留 mean/std/skew/kurt；同时**建议加 `g16_hist` 的时间序列**（否则只能算窗口合计，块置换做不了）。
