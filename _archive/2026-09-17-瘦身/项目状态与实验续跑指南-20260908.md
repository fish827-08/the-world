## 一、今日工作详细说明（2026-09-08）

### 1.1 大世界100万tick长实验（分段续跑）

- **配置**：200×400=80000格，初始2000个体，上限12000（密度15%），目标100万tick
- **方式**：cron定时任务每15分钟触发，每次续跑15000 tick（云环境后台任务限制约6-7分钟）
- **进度**：从0跑到448000 tick（44.8%），共完成约30个分段
- **速率**：云环境2核AMD EPYC，稳定态38-57 tick/s（波动大，受共享云环境CPU资源影响）
- **结果**：g15信号基因稳定在0.694（94.9%个体携带），max_gen=25
- **停止原因**：用户要求停止云端续跑，改用本地快照继续

### 1.2 小世界100万tick实验（已完成）

- **配置**：60×120=7200格，初始500个体，上限3240（密度45%）
- **结果**：100万tick完成，g15=0.257，max_gen=55，平均速率358 tick/s
- **语言分析**：综合评分58.68/100，无语言迹象（信号-语境互信息=0）

### 1.3 大世界数据分析与涌现特性评估

- **关键发现**：大世界低密度环境中g15=0.694，是小世界（0.257）的2.7倍
- **信号场实际状态**：24%的格子有信号（CSV统计sig_density=0是bug），信号模式75%集中在模式14
- **结论**：信号基因成功进化，但信号行为未形成语言（模式趋同、无语境关联、更新慢）
- **基因协同**：g15↔trust强正相关(+0.853)，信号与信任协同进化

### 1.4 L9分支代码审核（feature/l9-terrain-season）

- **内容**：地形系统（水域/山地/平原）、季节系统（黄赤交角+四季）、尸体能量守恒（死亡→尸体→食腐→分解→资源）
- **质量评价**：代码质量很高，设计严谨，默认全关不影响现有行为，启用时自动回退Python路径
- **发现问题**：食腐愉悦度(scavenge_joy)定义了但未在代码中使用（遗漏）
- **建议**：修复食腐愉悦度遗漏后可合并

### 1.5 快照模式 vs 连续模式验证

- **结论**：完全一致，逐位对拍通过（energy/stomach/age差异均为0）
- **关键修复**：_mem_ptr（工作记忆循环指针）必须保存，否则恢复后重置导致energy不一致
- **SNAPSHOT_VERSION=2**：配置指纹校验+RNG状态保存+完整状态恢复

### 1.6 性能优化（已合入main）

- **L7d Rayon多线程**：4个热路径并行化（step_vectors stage1/stage2、pleasure_update、regrow），N>2048自动启用
- **L7f光照温度Rust下沉**：LightTempRust类，Rayon并行，就地修改numpy数组，大世界整体加速2.38x
- **光照温度缓存**：每tick只算1次（原来8次），预计算cos_lat/col_rad永久缓存
- **大世界越界修复**：movement.rs硬编码[i64;128]数组改为Vec动态分配（大世界cols=400时极点格邻居数=400>128）

## 四、后续实验续跑指南

### 4.1 用快照继续跑大世界实验

**前置条件**：
- Python 3.10+，已安装依赖（numpy等）
- sim_core.so已编译（Rust扩展，可选但强烈推荐，性能提升10x+）
- 编译命令见4.4节

**续跑命令**（从snapshot_large.npz恢复，继续跑到100万tick）：

```bash
cd digital-life-sphere

# 本地性能好，segment可以设大（如10万tick），不用像云环境那样受限制
python3 experiments/run_long_experiment.py \
  --rows 200 --cols 400 \
  --ticks 1000000 \
  --tag large \
  --initial 2000 \
  --segment 100000 \
  --density-cap 0.15
```

**参数说明**：
- `--rows 200 --cols 400`：世界大小（必须与快照一致，否则配置指纹校验失败）
- `--ticks 1000000`：目标总tick数（从快照当前tick继续，不是从头跑）
- `--tag large`：快照文件名前缀（snapshot_large.npz）和输出CSV前缀（long_large.csv）
- `--initial 2000`：初始个体数（仅用于新建实验，快照恢复时忽略）
- `--segment 100000`：每段tick数（本地可以设大，云环境受6-7分钟限制只能设15000）
- `--density-cap 0.15`：种群密度上限（15%，max_count=80000×0.15=12000）

**脚本行为**：
1. 检查`snapshot_large.npz`是否存在
2. 存在则从快照恢复（load_snapshot classmethod），不存在则初始化新实验
3. 跑`--segment`指定的tick数，每2000 tick追加统计到CSV
4. 段结束后立即保存快照（覆盖原文件）
5. 如果未达到`--ticks`目标，脚本退出（需要再次调用或用循环）

**循环续跑（本地无人值守）**：

```bash
# 方法1：简单while循环
while true; do
  python3 experiments/run_long_experiment.py \
    --rows 200 --cols 400 --ticks 1000000 \
    --tag large --initial 2000 --segment 100000 --density-cap 0.15
  # 检查是否完成
  tick=$(python3 -c "import numpy as np; print(int(np.load('snapshot_large.npz')['tick']))")
  if [ "$tick" -ge 1000000 ]; then
    echo "实验完成！tick=$tick"
    break
  fi
  echo "当前tick=$tick，继续..."
done
```

## 五、关键发现与结论

### 5.1 世界规模对信号基因进化的决定性影响

| 指标 | 小世界(45%密度) | 大世界(15%密度) | 差异 |
|------|-----------------|-----------------|------|
| g15信号基因 | 0.257 | **0.694** | +0.437（2.7倍） |
| g15>0.5占比 | ~30% | **94.9%** | +65% |
| trust信任 | 0.918 | 0.992 | +0.074 |
| max_gen(100万tick) | 55 | 25(44.8万) | 世代间隔更长 |

**结论**：低密度大世界环境中，信号基因被自然选择强烈保留。小世界高密度下信号基因被淘汰（因为信号是公共品，搭便车者更有优势），大世界低密度下信号的传播距离和价值更高。

### 5.2 语言尚未涌现

- 信号-语境互信息=0（信号不指代任何环境信息）
- 信号模式高度趋同（75%集中在模式14）
- 文化多样性偏低（cult_div=0.117）
- 信号更新慢（年龄均值47.7/50上限）

**根本原因**：
1. 生物移动太快（最短寿命绕世界20圈）→ 文化全局混合 → 无方言分化
2. 无地理隔离 → 信号模式全局趋同
3. 信号发射无语境关联 → 信号无指代意义

### 5.3 方案A负面结果

方案A（食物信号+信任奖励+繁衍优势）初期有效（g15从0.157回升到0.406），但长期衰减到0.234（低于基线0.375），trust崩溃到0.029。根因：信号是公共品，搭便车者比发射者更有优势；trust加权繁殖让欺骗者更快繁衍。

## 六、后续开发建议（按优先级）

### P0：语言涌现关键条件

1. **降低移动速度**：每2-3 tick才能移动1格，或增加移动能耗。当前生物最短寿命绕世界20圈，导致文化全局混合。
2. **启用地形系统**（L9分支）：水域不可通行+山地高能耗，创造地理隔离，让不同区域形成不同信号模式（方言）。
3. **信号-语境选择压力**：让信号发射与特定语境（食物丰富、捕食者出现、求偶）关联，并让接收者因正确解读而获得适应度收益。

### P1：性能与稳定性

4. **修复sig_density统计bug**：CSV中sig_density=0但实际有信号。
5. **L9分支食腐愉悦度修复**：scavenge_joy定义了但未使用。
6. **L9 Rust路径支持**：当前启用地形/季节/尸体时自动回退Python，性能下降10x+。

### P2：扩展特性

7. **L9尸体能量守恒完善**：当前是基础版，可增加食腐者基因位、尸体视觉信号等。
8. **L10种子传播完整版**：依赖L9尸体系统。
9. **L8地形完整版**：用值噪声替代随机散布，增加森林/沙漠/温度偏移。

## 七、已知问题与注意事项

1. **云环境后台任务限制**：约6-7分钟超时，segment不能超过15000 tick（大世界N=12000时）。本地无此限制。
2. **sim_core.so平台相关**：云环境编译的.so不能在Windows用，本地需重新编译（生成.pyd）。
3. **配置指纹校验**：快照恢复时配置必须完全一致，否则拒绝恢复。世界大小、密度上限、种子等都不能改。
4. **load_snapshot是@classmethod**：返回新实例，不是修改当前实例。用法：`engine = SphereEngine.load_snapshot(path, config)`。
5. **_mem_ptr必须保存**：工作记忆循环指针，遗漏会导致恢复后energy不一致。SNAPSHOT_VERSION=2已修复。
6. **Rayon并行阈值**：PAR_THRESHOLD=2048，N<2048用单线程避免调度开销。当前大世界N=12000会自动启用多线程。
7. **regrow 1ULP误差**：Rust release FMA优化导致，5个测试失败，已知问题不影响正确性。
