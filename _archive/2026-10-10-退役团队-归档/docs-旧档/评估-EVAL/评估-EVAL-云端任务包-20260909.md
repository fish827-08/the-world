## 二、云端今晚任务（独立于后续 D2，可立即执行）

### 任务 1：世代压缩敏感性扫描（D3 数据采集，最优先）

目标：确定 rotation_period 压缩到什么档位，"世代时间"从 ~18.9k tick/代 压到 100~300 tick/代，同时生态不断裂。

批次（小世界 60×120，patchy，200k tick，每档 2 seed 起步）：
```
# rotation_period 2400（对照组，=当前行为）
python experiments/run_long_experiment.py --rows 60 --cols 120 --ticks 200000 --segment 50000 --tag gen_rp2400_s1 --seed 42
# 压缩档
python experiments/run_long_experiment.py --rows 60 --cols 120 --ticks 200000 --segment 50000 --tag gen_rp1200_s1 --seed 42 --rotation-period 1200
python experiments/run_long_experiment.py --rows 60 --cols 120 --ticks 200000 --segment 50000 --tag gen_rp600_s1  --seed 42 --rotation-period 600
python experiments/run_long_experiment.py --rows 60 --cols 120 --ticks 200000 --segment 50000 --tag gen_rp300_s1  --seed 42 --rotation-period 300
```
判读指标（每 2000 tick 已在 CSV，加打点后看 max_gen 增率 + g14/g15 曲线 + N 稳定性）：
1. **max_gen 净增**：期望 200k tick 内从 25 代级提到 500~2000 代级
2. **生态稳定性**：N 是否仍能在 50k tick 内拉满密度、老死比例不崩（换代太快不应触发大灭绝）
3. **g14/g15 方向**：压缩后选择梯度是否开始显现（对照 rp2400 的漂变样）
产出：results/gen_scan/ 汇总表（每档 max_gen/世代间隔/终局基因/trust/cult_div），回写 experiments/ 下新 CSV 并提交分支 `feat/gen-scan`。

## 三、云端后续主任务（D2 信息结构重构，科学杠杆最高）

在 main 上新开分支 `feat/info-structure`，只做四件事（严格按评估 M2，别加别的）：

1. **学习瓶颈**：解读表不遗传；幼体从有限 (信号,后果) 观察样本归纳（Kirby 链条枢纽）
