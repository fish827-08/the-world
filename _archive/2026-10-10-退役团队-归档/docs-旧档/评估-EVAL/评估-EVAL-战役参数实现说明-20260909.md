## 一、为什么需要这两个参数

主实验形态目标 = "千代 × 10 seed × 四臂对照"。D3 实测：
- 世代间隔 ≈ 7.3 × rotation_period（生态无压力时世代被寿命上限锁死）
- rp=300 时 100 万 tick ≈ 445 代，达不到千代
- 单压 rp<200 会破坏昼夜节律语义

因此需要两个独立旋钮，绕过"压 rp 破坏光照"的限制：
1. **lifespan_mult** — 缩放寿命基准（不动昼夜），世代缩短到 500~1100 tick
2. **stay_prob** — 停驻率，配合 D2 感知半径 4 邻 = 等效扩世界 4~8 倍零算力

---

## 二、lifespan_mult（寿命基准缩放）

### 配置

| 项 | 值 |
|----|-----|
| 归属 | `OrganismConfig.lifespan_mult` |
| 默认 | 1.0（旧行为） |
| 范围 | (0.05, 8.0]，`__post_init__` 断言 |
| CLI | `--lifespan-mult`（run_long_experiment + run_ensemble） |

### 公式

```python
def _lifespan(self, g3):
    day = float(self.config.light.rotation_period)
    mult = float(self.config.organisms.lifespan_mult)
    return day * mult * (1.0 + g3 * 7.0)
```

### Rust 零改动方案（关键）

Rust `step_vectors_stage1/stage2` 内部用 `day_len` 推导成熟/老年年龄。Python 调 Rust 时把 **`day_len` 参数传 `day_len × lifespan_mult`**：

```python
_day_len_eff = day_len * float(self.config.organisms.lifespan_mult)
self._sim_core.step_vectors_stage1(..., _day_len_eff)
self._sim_core.step_vectors_stage2(..., _day_len_eff)
```

- Rust 无感、ABI 不变、双路径对拍自动成立
- 纯数值缩放，**不新增/删除任何 RNG 消费**
- Python 参考实现均改用 `_lifespan()`，两侧一致性由引擎级对拍测试兜底

### 行为影响

| mult | 寿命基准 | 世代间隔（估算） | 100万tick世代数 |
|------|---------|----------------|----------------|
| 1.0 | 2400 tick | ~17500 tick | ~57 代 |
| 0.5 | 1200 tick | ~8750 tick | ~114 代 |
| 0.25 | 600 tick | ~4400 tick | ~227 代 |
| 0.1 | 240 tick | ~1750 tick | ~571 代 |
| 0.05 | 120 tick | ~880 tick | ~1136 代 |

> 实际世代间隔受生态压力影响，上表为无压力上限估算。战役推荐 mult=0.1~0.25 区间。

## 三、stay_prob（停驻率）

### 配置

| 项 | 值 |
|----|-----|
| 归属 | `SimulationConfig.stay_prob` |
| 默认 | 0.0（旧行为，每 tick 必移判定） |
| 范围 | [0.0, 0.95)，`__post_init__` 断言 |
| CLI | `--stay-prob`（run_long_experiment + run_ensemble） |

### 公式

```python
_stay = float(self.config.simulation.stay_prob)
move_prob = genes[:, Gene.MOVE_PROB] * (1.0 - genes[:, Gene.ROOTING]) * (1.0 - _stay)
```

### RNG 契约（最重要）

**保持每 tick 消费 P 个 uniform 不变**（`self.rng.random(P)` 原样），只改阈值 `move_prob`：
- 移动个体变少，但 RNG 位置不变
- Python/Rust 两侧用同一公式，引擎级对拍自动成立
- **严禁**用"额外 random 决定停驻"（会移动 RNG 位置，摧毁对拍）

### 行为影响

| stay_prob | 移动概率倍率 | 等效效果 |
|-----------|------------|---------|
| 0.0 | ×1.0 | 旧行为 |
| 0.5 | ×0.5 | 移动减半，等效世界密度感知减半 |
| 0.8 | ×0.2 | 移动大幅减少，生物更多停驻在资源丰富区 |
| 0.94 | ×0.06 | 接近上限，几乎不移动 |

> 配合 D2 感知半径 4（Von Neumann），stay_prob=0.5~0.8 可等效扩世界 4~8 倍（生物活动范围缩小 = 感知到的世界变大），零算力成本。

## 四、兼容性

| 维度 | 处理 |
|------|------|
| 默认值 | lifespan_mult=1.0, stay_prob=0.0 → 与旧行为完全一致 |
| `from_dict` 旧存档 | dataclass `__init__` 自带默认值，缺失键自动回退 |
| `fingerprint()` | `asdict` 自动含新字段，不同参数指纹不同 |
| 快照 | 配置存进快照，恢复时参数一致；纯数值参数不影响快照版本号 |
| Rust ABI | 零改动（day_len 参数传缩放后的值，Rust 无感） |

## 六、影响面总结

| 模块 | 改动 | 风险 |
|------|------|------|
| `simulation/config.py` | OrganismConfig 加 lifespan_mult + 断言；SimulationConfig 加 stay_prob + 断言 | 低（默认值=旧行为） |
| `simulation/sphere_engine.py` | `_lifespan()` 加 mult；Rust 调用 day_len 传缩放值；move_prob 乘 (1-stay) | 中（双路径对拍已验证） |
| `experiments/run_long_experiment.py` | 加 --lifespan-mult / --stay-prob CLI 透传 | 低 |
| `experiments/run_ensemble.py` | 加 CLI 透传 + manifest 记录 | 低 |
| Rust sim_core | **零改动** | 无 |

## 七、战役推荐参数组合

| 目标 | lifespan_mult | stay_prob | rotation_period |
|------|--------------|-----------|-----------------|
| 千代战役（基础） | 0.1 | 0.0 | 2400 |
| 千代 + 等效扩世界 | 0.1 | 0.5 | 2400 |
| 千代 + D2 感知半径4 | 0.15 | 0.3 | 2400 |
| 超千代（1500+代） | 0.05 | 0.0 | 2400 |

> 实际参数需本地实验验证生态稳定性后定案。mult 太小可能导致幼体来不及成熟就老死（成熟年龄=寿命×maturity_fraction=0.15），需确保 mult > maturity_fraction 相关下限。
