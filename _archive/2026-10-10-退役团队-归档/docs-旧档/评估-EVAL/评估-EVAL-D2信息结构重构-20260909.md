## 一、背景与动机

### 1.1 问题诊断

D1 零模型四臂实验结论（见《评估-EVAL-D1零模型结果-20260909.md》）：

| 指标 | 结论 |
|------|------|
| g15 | 四臂均无一致方向（中性漂变），信号基因无选择压 |
| trust | sigdis 臂 trust 恒=0.5 → trust 是信号存在的副产品，不是社会合作 |
| cult_div | 四臂均趋同（~0.001）→ 趋同是热扩散机械必然，与信号无关 |
| neutral | 种群灭绝 → 基因恒0.5设计缺陷 |

**根因**：当前信号系统被机制结构性排除了语言涌现的可能：

1. **信号无指代**：pattern = 硬编码状态函数（能量档×4 + 食物×2 + 邻居），信号含义是物理决定的，无需学习
2. **解读表整表遗传**：子代直接 copy 亲代解读表 + 噪声，Kirby 学习瓶颈被短路
3. **文化学习=热扩散**：EWMA 向邻居成体均值收敛 = 图拉普拉斯迭代，全局趋同无多样性
4. **感知完全对称**：8 邻居全知，无信息不对称，生物无需依赖他人信号
5. **移动决策=argmax**：确定性选择，无探索，无通信协商空间

### 1.2 D2 设计目标

引入四大机制，为语言涌现创造最小充分条件：

| 机制 | 解决的问题 | 理论来源 |
|------|-----------|---------|
| 学习瓶颈 | 解读表整表遗传 → 幼体从有限样本归纳 | Kirby 迭代学习模型 |
| 任意性码本 | 信号=硬编码状态 → 信号pattern可任意映射 | Saussure 任意性原理 |
| 信息不对称 | 8邻居全知 → 感知半径4+噪声+softmax | 有限理性/信息不对称 |
| Steels对齐 | 无协商机制 → 同格相遇解读表+码本对齐 | Steels 语言博弈模型 |

## 二、四大机制实现细节

### 2.1 机制1：学习瓶颈（Learning Bottleneck）

**核心思想**：解读表不再遗传，幼体出生时随机初始化，通过观察"信号+后果"样本逐步归纳信号含义。学习样本数有限（瓶颈），迫使信号系统结构化、可压缩。

**实现位置**：`simulation/sphere_engine.py`

- **繁殖时**（~line 1040）：
  ```python
  if ifcfg.enabled and ifcfg.learning_bottleneck:
      child_interp = self.rng.normal(0.0, 0.3, size=(K, 16))  # 随机初始化
  else:
      child_interp = self._interpret[ri].copy() + normal(0, 0.1)  # 旧版遗传
  ```

- **幼体观察学习**（移动决策后，~line 700）：
  ```python
  # 仅幼体（age < learning_maturity_ticks）且学习计数未满
  learners = mi[young & can_learn]
  for idx in learners:
      mark = signal_marks[target_cell]
      if mark > 0:
          if has_food:
              interpret[idx, mark] += lr * (1 - interpret[idx, mark])  # 正向强化
          else:
              interpret[idx, mark] -= lr * (1 + interpret[idx, mark])  # 负向强化
          learning_count[idx] += 1
  ```

**参数**：
| 参数 | 默认值 | 说明 |
|------|--------|------|
| `learning_rate` | 0.15 | 每次观察更新步长 |
| `learning_samples_max` | 60 | 单个体最大学习次数（瓶颈宽度） |
| `learning_maturity_ticks` | 1200 | 幼体学习窗口（tick） |

### 2.2 机制2：任意性码本（Arbitrary Codebook）

**核心思想**：信号 pattern 不再是状态的硬编码函数，而是通过个体可遗传码本映射 `pattern = codebook[state]`。码本可突变、可通过 Steels 对齐在群体中趋同，使信号含义成为文化约定而非物理决定。

**数据结构**：
- `_codebook: (N, 16) uint8` — 每个个体 16 个状态，每个状态映射到一个信号模式(0~15)
- 初始恒等映射 `codebook[state] = state`（与旧版行为一致）

**实现位置**：
- **信号发射**（~line 620）：
  ```python
  state = e_bin * 4 + f_bit * 2 + n_bit  # 状态0~15
  if ifcfg.enabled and ifcfg.arbitrary_codebook:
      patterns = self._codebook[emitters, state]  # 码本映射
  else:
      patterns = state.astype(np.uint8)  # 旧版恒等
  ```

- **繁殖时码本遗传+突变**（~line 1055）：
  ```python
  child_codebook = self._codebook[ri].copy()
  cb_mut = random((K,16)) < codebook_mutation_rate
  child_codebook[cb_mut] = integers(1, 16)  # 突变位映射到随机模式
  ```

**参数**：
| 参数 | 默认值 | 说明 |
|------|--------|------|
| `codebook_mutation_rate` | 0.02 | 码本每位突变概率 |

### 2.3 机制3：信息不对称（Information Asymmetry）

**核心思想**：生物不再全知全能。感知半径从 8（Moore 全邻）缩减到 4（Von Neumann 上下左右），感知到的食物/信号加高斯噪声，移动决策用 softmax 温度采样替代 argmax 确定性选择。信息不对称迫使生物依赖他人信号获取信息，为通信创造选择压。

**实现位置**：Python 路径移动决策（~line 750），D2 启用时走 Python 路径（Rust 侧暂未下沉）。

- **感知半径4**：
  ```python
  if d2_asym and len(nb) > 4:
      nb = nb[:4]  # 只取 Von Neumann 四邻
  ```

- **感知噪声**：
  ```python
  fr = food_ratio[nb] + normal(0, perception_noise)
  sp = sig_present[nb] + normal(0, perception_noise)
  ```

- **softmax 采样**：
  ```python
  if d2_softmax:
      exp_s = exp((score - max(score)) / tau)
      probs = exp_s / sum(exp_s)
      u = random()  # 消费主rng保对拍
      target = nb[searchsorted(cumsum(probs), u)]
  ```

**参数**：
| 参数 | 默认值 | 说明 |
|------|--------|------|
| `perception_radius` | 4 | 4=Von Neumann, 8=Moore |
| `perception_noise` | 0.05 | 感知噪声σ |
| `softmax_tau` | 0.15 | softmax温度（0=argmax旧行为） |

### 2.4 机制4：Steels 对齐（Steels Alignment）

**核心思想**：当两个生物在同一格相遇时，概率性地让它们的解读表和码本相互对齐（带噪声）。这是语言协商的机制——通过反复互动，群体逐渐形成共享的信号约定。

**实现位置**：文化学习段后（~line 850 Rust路径，~line 920 Python路径）。

```python
# 同格相遇
for cell in crowded_cells:
    cell_idx = individuals_in_cell
    shuffle(cell_idx)
    for (i, j) in pairs(cell_idx):
        if random() < alignment_rate:
            # 解读表对齐（浮点EWMA）
            diff = interpret[j] - interpret[i]
            interpret[i] += step * diff + noise
            interpret[j] -= step * diff + noise
            # 码本对齐（离散概率替换）
            if arbitrary_codebook:
                cb_mask = random(16) < step
                codebook[i, cb_mask] = codebook[j, cb_mask]
```

**参数**：
| 参数 | 默认值 | 说明 |
|------|--------|------|
| `alignment_rate` | 0.1 | 相遇时对齐概率 |
| `alignment_step` | 0.15 | 对齐步长 |
| `alignment_noise` | 0.02 | 对齐噪声σ |

## 四、初步实验结果

### 4.1 D2 全机制（默认参数）

配置：小世界 60×120, patchy, D2 全机制开启, use_sim_core=False

| tick | N | g15 | max_gen | trust |
|------|---|-----|---------|-------|
| 100 | 89 | 0.487 | 0 | 0.558 |
| 2600 | 11 | 0.525 | 3 | 0.464 |
| 5100 | 7 | 0.634 | 6 | 0.366 |
| 9000 | **灭绝** | - | - | - |

**结论**：默认参数太激进，种群在 9000 tick 灭绝。g15 在灭绝前有上升趋势（0.49→0.63），但生态无法维持。

### 4.2 问题分析

种群崩溃的可能原因：
1. **学习瓶颈+任意性码本同时开启**：幼体既没有继承解读表，码本也可能与群体不同 → 幼体完全无法理解信号
2. **感知半径4+softmax**：信息减少+随机性增加 → 觅食效率下降
3. **码本趋同需要时间**：Steels 对齐使码本趋同，但在趋同之前信号沟通效率低
4. **学习窗口可能不足**：1200 tick 内观察不到足够的信号-后果对

### 4.3 参数调优建议

**渐进式开启**（推荐）：
1. **第一阶段**：只开学习瓶颈 + Steels 对齐（关闭任意性码本和信息不对称）
   - 验证学习瓶颈本身是否能产生文化多样性
   - 信号仍然是硬编码状态函数（有指代），但解读表需要学习
2. **第二阶段**：加入任意性码本（保持感知半径8，无噪声，tau=0）
   - 验证码本+Steels对齐能否形成共享信号约定
3. **第三阶段**：加入信息不对称（感知半径4+噪声+softmax）
   - 验证信息不对称是否为信号创造选择压

**参数调优方向**：
| 参数 | 当前默认 | 建议调优范围 | 理由 |
|------|---------|-------------|------|
| `learning_rate` | 0.15 | 0.1~0.3 | 太低学不会，太高不稳定 |
| `learning_samples_max` | 60 | 40~100 | 瓶颈太窄学不会，太宽无瓶颈 |
| `learning_maturity_ticks` | 1200 | 1200~2400 | 寿命1~8世界日(2400~19200 tick)，1200可能太短 |
| `codebook_mutation_rate` | 0.02 | 0.005~0.02 | 太高码本多样性过高，太低无探索 |
| `alignment_rate` | 0.1 | 0.1~0.3 | 太低趋同慢，太快无多样性 |
| `perception_noise` | 0.05 | 0.02~0.1 | 太高信息不可靠 |
| `softmax_tau` | 0.15 | 0.05~0.2 | 太高太随机，太低无探索 |
