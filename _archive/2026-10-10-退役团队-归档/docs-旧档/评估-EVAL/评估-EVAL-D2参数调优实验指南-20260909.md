# D2 参数调优实验指南

> 日期：2026-09-09  
> 分支：`feat/info-structure`  
> 目标：找到生态稳定（N>1000 持续 50000 tick）且 g15 无补贴从 0.5 上升的参数组合

---

## 一、实验原则

### 1.1 渐进式开启（核心原则）

**禁止一次性开启全部四大机制**。默认参数已验证会导致种群 9000 tick 灭绝。必须按以下顺序逐步开启，每步确认生态稳定后再进入下一步：

```
阶段0（基线）→ 阶段1（学习瓶颈+Steels）→ 阶段2（+任意性码本）→ 阶段3（+信息不对称）
```

### 1.2 单变量调优

每次只调一个参数，报告前后对照。禁止合并调参（无法归因）。

### 1.3 生态稳定判据

| 指标 | 稳定阈值 | 说明 |
|------|---------|------|
| N（种群数量） | > 1000 持续 50000 tick | 不灭绝、不崩溃 |
| max_gen | > 20 | 有足够世代观察进化 |
| g15 趋势 | 非单调下降 | 不被自然选择彻底淘汰 |

### 1.4 g15 上升判据（验收门）

- 初始 g15 ≈ 0.5（随机初始化）
- 最终（50000+ tick）g15 均值 > 0.55 且趋势上升
- 3 seed 方向一致（排除漂变）

## 二、阶段0：基线确认

**目的**：确认 D2 关闭时行为与旧版一致，生态稳定。

```bash

  --rows 60 --cols 120 --ticks 50000 --segment 25000 \
  --tag d2_baseline --seed 42
```

**预期**：N≈3240（45%密度），g15≈0.4~0.5（漂变），trust≈0.9，cult_div≈0.001

## 三、阶段1：学习瓶颈 + Steels 对齐

**开启机制**：
- `learning_bottleneck = True`
- `steels_alignment = True`
- `arbitrary_codebook = False`（信号仍为硬编码状态函数，有指代）
- `perception_radius = 8`，`perception_noise = 0.0`，`softmax_tau = 0.0`（无信息不对称）

**目的**：验证学习瓶颈本身是否能产生文化多样性，解读表从"遗传"变为"学习"后生态是否稳定。

### 3.1 实验命令

```bash
# 先跑默认参数
.venv/bin/python experiments/run_long_experiment.py \
  --rows 60 --cols 120 --ticks 50000 --segment 25000 \
  --tag d2_s1_default --seed 42
```

> 注意：当前 `run_long_experiment.py` 可能不支持 D2 参数 CLI 透传。需先在脚本中添加 `--info-structure` 或直接修改 `SimConfig`。临时方案：写一个独立的实验脚本 `experiments/run_d2_experiment.py`，接受 D2 参数。

### 3.2 参数扫描（单变量）

| 参数 | 基线值 | 扫描范围 | 步长 |
|------|--------|---------|------|
| `learning_rate` | 0.15 | 0.05, 0.1, 0.15, 0.2, 0.3 | - |
| `learning_samples_max` | 60 | 30, 60, 100, 150 | - |
| `learning_maturity_ticks` | 1200 | 600, 1200, 2400, 3600 | - |
| `alignment_rate` | 0.1 | 0.05, 0.1, 0.2, 0.3 | - |
| `alignment_step` | 0.15 | 0.05, 0.1, 0.15, 0.3 | - |

### 3.3 判读

| 观察项 | 稳定信号 | 危险信号 |
|--------|---------|---------|
| N | > 1000 持续 | < 100 或灭绝 |
| g15 | 0.4~0.6 波动 | 单调下降到 < 0.2 |
| cult_div | > 0.01（比基线高） | ≈ 0.001（与基线无差异=学习瓶颈失效） |
| learning_count 分布 | 多数个体达到上限 | 多数个体 < 5（学习机会不足） |

**阶段1通过条件**：生态稳定 + cult_div 显著高于基线（学习瓶颈产生了文化多样性）。

## 四、阶段2：加入任意性码本

**在阶段1稳定参数基础上**，开启：
- `arbitrary_codebook = True`

**目的**：验证码本+Steels对齐能否形成共享信号约定，信号从"物理指代"变为"文化约定"。

### 4.1 参数扫描

| 参数 | 基线值 | 扫描范围 |
|------|--------|---------|
| `codebook_mutation_rate` | 0.02 | 0.005, 0.01, 0.02, 0.05 |

### 4.2 判读

| 观察项 | 稳定信号 | 危险信号 |
|--------|---------|---------|
| 码本多样性（群体内码本差异） | 先高后低（趋同） | 持续高（无法趋同=信号沟通失败） |
| 码本-状态映射一致性 | 群体内多数个体对同一状态映射到同一pattern | 完全随机 |
| g15 | 上升趋势 | 下降到 < 0.2 |
| N | > 1000 | 灭绝 |

**新增指标：码本趋同度**
```python
# 计算群体内码本的 pairwise 一致性
def codebook_convergence(codebook):
    # 对每个状态，计算群体中最常见映射的比例
    convergence = []
    for state in range(16):
        mappings = codebook[:, state]
        most_common = np.bincount(mappings).max()
        convergence.append(most_common / len(mappings))
    return np.mean(convergence)
```
- 收敛度 > 0.7 = 群体形成了共享码本
- 收敛度 ≈ 1/16 = 0.0625 = 完全随机

**阶段2通过条件**：生态稳定 + 码本趋同度 > 0.5 + g15 不下降。

## 五、阶段3：加入信息不对称

**在阶段2稳定参数基础上**，开启：
- `perception_radius = 4`
- `perception_noise = 0.05`
- `softmax_tau = 0.15`

**目的**：验证信息不对称是否为信号创造选择压（生物需要依赖他人信号获取信息）。

### 5.1 参数扫描

| 参数 | 基线值 | 扫描范围 |
|------|--------|---------|
| `perception_radius` | 4 | 4, 6（中间值） |
| `perception_noise` | 0.05 | 0.02, 0.05, 0.1 |
| `softmax_tau` | 0.15 | 0.05, 0.1, 0.15, 0.3 |

### 5.2 判读

| 观察项 | g15上升信号 | 危险信号 |
|--------|------------|---------|
| g15 | 从0.5上升到>0.55，3seed一致 | 下降或漂变 |
| signal_density | 上升（更多生物发射信号） | 下降 |
| 信号-食物相关性 | 正相关（信号能预测食物） | 零相关 |
| N | > 500（信息不对称降低觅食效率，N可能下降） | 灭绝 |

**阶段3通过条件（验收门）**：生态稳定 + g15 从 0.5 上升（3 seed 一致）。

## 六、实验脚本模板

由于 `run_long_experiment.py` 暂不支持 D2 参数 CLI 透传，使用以下模板：

```python
# experiments/run_d2_experiment.py
import argparse, json, numpy as np
from simulation.config import SimConfig, InfoStructureConfig
from simulation.sphere_engine import SphereEngine

def main():
    p = argparse.ArgumentParser()
    p.add_argument('--rows', type=int, default=60)
    p.add_argument('--cols', type=int, default=120)
    p.add_argument('--ticks', type=int, default=50000)
    p.add_argument('--seed', type=int, default=42)
    p.add_argument('--tag', type=str, default='d2')
    # D2 开关
    p.add_argument('--learning-bottleneck', action='store_true')
    p.add_argument('--arbitrary-codebook', action='store_true')
    p.add_argument('--info-asymmetry', action='store_true')
    p.add_argument('--steels-alignment', action='store_true')
    # D2 参数
    p.add_argument('--learning-rate', type=float, default=0.15)
    p.add_argument('--learning-samples-max', type=int, default=60)
    p.add_argument('--learning-maturity-ticks', type=int, default=1200)
    p.add_argument('--codebook-mutation-rate', type=float, default=0.02)
    p.add_argument('--alignment-rate', type=float, default=0.1)
    p.add_argument('--alignment-step', type=float, default=0.15)
    p.add_argument('--perception-radius', type=int, default=4)
    p.add_argument('--perception-noise', type=float, default=0.05)
    p.add_argument('--softmax-tau', type=float, default=0.15)
    args = p.parse_args()

    cfg = SimConfig()
    cfg.world.rows = args.rows
    cfg.world.cols = args.cols
    cfg.simulation.seed = args.seed
    cfg.simulation.use_sim_core = False  # D2 暂未下沉 Rust

    d2 = InfoStructureConfig(enabled=True)
    d2.learning_bottleneck = args.learning_bottleneck
    d2.arbitrary_codebook = args.arbitrary_codebook
    d2.steels_alignment = args.steels_alignment
    d2.learning_rate = args.learning_rate
    d2.learning_samples_max = args.learning_samples_max
    d2.learning_maturity_ticks = args.learning_maturity_ticks
    d2.codebook_mutation_rate = args.codebook_mutation_rate
    d2.alignment_rate = args.alignment_rate
    d2.alignment_step = args.alignment_step
    if args.info_asymmetry:
        d2.perception_radius = args.perception_radius
        d2.perception_noise = args.perception_noise
        d2.softmax_tau = args.softmax_tau
    else:
        d2.perception_radius = 8
        d2.perception_noise = 0.0
        d2.softmax_tau = 0.0
    cfg.info_structure = d2

    # 保存 manifest
    manifest = vars(args)
    manifest['config'] = cfg.to_dict()
    with open(f'experiments/manifest_{args.tag}_s{args.seed}.json', 'w') as f:
        json.dump(manifest, f, indent=2, default=str)

    e = SphereEngine(cfg)
    stats = []
    for t in range(args.ticks):
        e.step()
        if e._extinct:
            print(f'灭绝 at tick {t}'); break
        if t % 1000 == 0:
            g15 = float(e._genes[:, 15].mean())
            N = len(e._id)
            trust = float(e._trust.mean())
            print(f'tick={t}, N={N}, g15={g15:.3f}, trust={trust:.3f}')
            stats.append({'tick': t, 'N': N, 'g15': g15, 'trust': trust})

    # 保存结果
    import csv
    with open(f'experiments/long_{args.tag}_s{args.seed}.csv', 'w', newline='') as f:
        w = csv.DictWriter(f, fieldnames=['tick', 'N', 'g15', 'trust'])
        w.writeheader()
        w.writerows(stats)

if __name__ == '__main__':
    main()
```

## 八、常见问题

### Q1: 种群灭绝了怎么办？
A: 检查是哪个阶段。阶段1灭绝→降低学习瓶颈激进度（增大 learning_samples_max、learning_maturity_ticks）。阶段2灭绝→降低码本突变率。阶段3灭绝→降低信息不对称（增大 perception_radius、减小 noise、减小 tau）。

### Q2: g15 不上升怎么办？
A: 检查信号是否有选择压。如果 signal_density 很低，说明生物不发射信号（g15 低）。可能需要检查信号发射是否有能量收益（当前信号发射消耗能量但无直接收益，依赖间接的信息共享收益）。

### Q3: cult_div 不升高怎么办？
A: 学习瓶颈可能失效。检查 learning_count 分布——如果多数个体学习计数很低，说明观察学习机会不足（信号太少或幼体寿命太短）。增大 learning_maturity_ticks 或 signal_gene 初始值。

### Q4: 码本不趋同怎么办？
A: 增大 alignment_rate 或 alignment_step。但注意太大会导致多样性丧失。检查群体密度——如果密度太低，相遇机会少，对齐效率低。
