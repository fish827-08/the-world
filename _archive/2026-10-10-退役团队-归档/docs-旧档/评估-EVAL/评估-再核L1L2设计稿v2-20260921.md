## 三、四项新发现

### N1 🔴 12k ≈ 9 代 ⇒ 主判据（稳定多态）结构性不可达 —— **本件最重要**

`[实测]` E-030 同纪元 12 run（数据仓 `the-world-data/_rerun_logs/cstep3acont/*`，cap ON）：
**`final_max_gen_highwater` = 7,7,7,8,8,9,10,11,11,14,15,25（中位 9.5）** ⇒ **12k tick 只跑出 9 代上下（最快世系）**。
对照：180k run `max_gen` = 215（≈837 tick/代）、300k ≈ 316 代。

**为什么这是结构性问题**：主判据要判的是**稳定多态（分化）**，这是**世代尺度**的量，不是 tick 尺度的量。

- 漂变：每代 sd = `sqrt(p(1−p)/(2N_e))`；9 代累计 = `3·sqrt(p(1−p)/(2N_e))`；`N_e≈200` ⇒ **≈0.075**（p=0.5）。
- 选择：9 代频率位移 ≈ `9·s·p(1−p) = 2.25 s`。要压过漂变需 **s ≳ 0.03–0.05**。
- 而 L1 项量级 ≈ 食物项的 2%（N2）⇒ 预期 `s ≪ 0.01`。

⇒ **12k 内 g16 的 `D_shape` 主要反映漂变**（A 臂零模型会（正确地）抓到它 ⇒ 判据很容易落在"未分化"），而**这个"未分化"不代表机制无效**——正是 R148 想避免的那种不可解释 null。
🔴 **加 seed 数救不了**：seed 只降**噪声**，不增**世代**。

**建议（请所有者裁）**：

- **(a) 加"纪元充足"前置门**：`final_max_gen_highwater ≥ 30`（经验阈值，可裁）方进入分化判读；否则判为**第四态「纪元不足 · 判据不可执行」**（与 R3 生态门同构：门不过 ⇒ 不下正负结论）。
- **(b) 预算重排**：同机时下 **3 seed × 40k 优于 6 seed × 12k**（世代是瓶颈）；或**两段式**：12k 筛查（只读闸门 D + 效应方向）→ 对 |ΔD| 超阈的 2–3 seed 续跑到 40–60k 再判分化。
- **(c) 措辞降级**：12k 版只能写"**分化的初始迹象**"，**不得**写"分化 / 未分化"。

### N2 🔴 猎物池自熄 + 闸门 D 阈值算错（含一处口径混用）

**机制**：`prey_occ = 1[该候选格含 ≥1 个 g16 ≤ gate 者]`，seek 项 ∝ `g16_i × prey_occ`。
⇒ **捕食者变多（g16 上移）⇒ 猎物池缩小 ⇒ 该项自熄**：若群体像 300k run 那样整体升到 0.3 以上（`[实测]` 引 R144：300k g16 直方图 **100% 落在 0.3–0.6**、单峰 ~0.40），则 **`prey_field ≡ 0`、seek 项 ≡ 0**（L1a 完全失效）。这是**设计内生的自限**，不是 bug ⇒ 必须**预注册为允许结局**（"猎物池枯竭 / 狂奔捕食"），否则将来会被读成"机制没接线"。

**量级自检有一处口径混用**：§三 用 `prey_occ ≈ 0.27`。0.27 是**每格平均占用**（`[实测]` `ak2_s42` 中位 `N=1943.5` ⇒ λ = 1943.5/7200 = **0.270**）或**群体低 g16 占比**，而 `prey_occ` 是**候选格 0/1 指示量**。正确期望：

```
E[prey_occ] = 1 − exp(−λ·p_low)   # 该格至少有一个低 g16 个体
λ = 0.270（实测占用）｜p_low ≈ 0.30（t0：g16_mean 0.514 / std 0.300 ⇒ 近均匀）
⇒ E[prey_occ] ≈ 0.078        ← 不是 0.27
⇒ E[seek 项] ≈ 0.5(w)·0.5(g17)·0.5(perc)·0.4(g16)·0.078 ≈ 0.0039   # B 臂
              C 臂（w=0.25）再减半 ≈ 0.0020
```

（`[推断]`：Poisson 占位 + 个体独立；真实有空间聚集 ⇒ 实际命中率会**偏高**，但不会回到 0.27。）

🔴 **后果**：**闸门 D 的 `seek_term_mean > 0.01` 会在接线完全正确时失败**（B 臂 ≈0.004 / C 臂 ≈0.002）⇒ 该阈是"拍出来的数"，会把一个正确的批挡在闸门外，或被迫记"参数依赖"。
**改法（四条）**：

1. **解析期望对照**（最强的反退化断言）：报 `E_hat = w_seek_max · mean(g17) · mean(perc) · mean(g16) · mean(prey_occ)`（全部**实测**量），要求实测 `seek_term_mean` 落在 `E_hat ± 3se` ⇒ **口径对 = 接线对**；
2. **相对份额**替代绝对值：`share_seek = E|seek| / (E|seek|+E|fear|+E|food|+E|soc|)`，预注册下限（建议 0.5%）与上限（不得 >50%）；
3. **新增判读前置门**：`frac(g16 ≤ gate)` 时间序列须**非零**（建议 ≥5% 且覆盖 ≥50% run 长度）；否则"分化"判据**不可执行**，改判**「猎物池枯竭」**结局；
4. **可选对照臂 E′**（1 行变体、仪表臂、**不进合取**；R148-7 已空出 E 槽位）：`prey_field = 任意占格者`（v1 定义）⇒ 直接回答两问：**分化是不是低 g16 过滤造出来的？自熄是不是该过滤造成的？**

### N3 闸门 D 判法（Q5 的正面答复）：不够严，且反退化断言的**层级**错了

现写法两处问题：① `seek_term_mean > 0.01` 是绝对值（N2 已证其错）；② "`fear_term_mean` 在各 trait 档上非恒定 0" 是**个体级**判据，抓不到"**逐候选恒定 ⇒ no-op**"这一形态 —— 而这正是 R148-1 认账的那个 no-op，只是搬到了 fear 项上。

🔴 **可证条件**：`danger = nb[agg_field[nb] > 0]`；若某个体的**每个候选格**都在 `danger` 里，则 `cos_to_danger ≡ 1` ⇒ fear 项对**所有候选**同值 ⇒ softmax/argmax **逐位不变 = no-op**。
当前相（λ=0.270、个体高于 gate 者约 0.7）⇒ 每邻域危险格 ≈ `8·(1−exp(−0.27·0.7)) ≈ 1.4` 个（`[推断]`）⇒ **尚未退化**；但**高密度 / 高 g16 相**（如 300k 那类 N≈K、g16 ≥ 0.3 的相）会退化。

**⇒ 闸门 D 改为四条**：

1. **反退化断言（必须跨候选）**：逐个体报 `std_c(seek 项) > 0` / `std_c(fear 项) > 0` 的**比例**（`seek_ndeg_frac` / `fear_ndeg_frac`），要求 ≥10%（可裁）；
2. **剂量极性**（唯一能测"权重真接上"的端到端检验，C6 精神）：B/C 两臂 `seek_term_mean` 比值 ≈ **2.0**（预注册区间 [1.5, 2.5]）；
3. **硬零对照**：`w_seek_max = 0 ⇒ seek_term_mean ≡ 0`（补；`w_fear=0 ⇒ fear_term ≡ 0` D 臂已有 ✓）；
4. **反事实决策改变率（建议升为主判据）**：复用已有 ⑥ 探针机制（`_delta_full_by_id` / `_delta_content_by_id`，`:1602-1617` 同族），算 `Δ_L1 = P(选中格 | L1 开) − P(选中格 | 去掉 L1 项)` 的均值与翻转率 ⇒ **直接测因果影响**，与量级无关，天然抗"看起来接好了"。

**补充诊断**：每邻域 `#危险格` 与 `#低 g16 个体` 的分布（解释 fear/seek 在两个相里何时退化）。

## 四、功效与「有效 n」口径（Q4 的完整答复）

### 4.1 「有效 n」三级口径（可操作定义）

1. **主推断单位 = run（seed）**：所有 p 值一律在 **seed 级**算（配对 ΔD；符号 / 符号秩 / **置换**，n = n_seed）。🚫 禁止把个体或 tick 池化算 p（伪重复）；连续量不必假设正态（同批跨 seed 生态相差异极大 ⇒ 用置换/秩更稳）。
2. **run 内若要给 n_eff**：`n_eff_within = T / (2·τ_int)`，`τ_int` = 该统计量逐 tick 序列的**积分自相关时间**（初始正序列估计）。请报 `d_shape_series`、`tau_int_shape`、`n_eff_within`。
3. **个体级 n_eff**：只用"**同一 tick、同一世代类**"的个体（**不跨 tick 重复**），并报**设计效应** `DEFF = 1 + (n̄_c − 1)·ICC`（c = 空间簇 / 家系）⇒ 让读者看到朴素 n 被夸大多少。
4. **新增一等观测量**：`final_max_gen_highwater`（N1 的前置门需要它；现已在 summary 里，但未进判据表）。

### 4.2 预跑设计：三条硬要求

1. **预跑只估方差，不估效应**：`ΔD_target` 必须**先于预跑**由理论/先验预注册（用预跑观测到的效应去定 n ⇒ 噪声被当信号，功效虚高）。
2. **估的是配对差**：`s_Δ = sd(D_B,i − D_A,i)`（同 seed 配对），**不是**水平 sd（水平 sd 含 seed 间生态相变异，实测其量级巨大：E-030 12 run 被捕食死亡 **36–20485** ⇒ 跨 seed 会整体换相）。
3. **3 seed 锁不住 n**：df=2 时 σ 的 95% CI ≈ **[0.52, 6.3]×ŝ**（χ² 区间）⇒ 用点估计定 n 与拍脑袋无异。要么预跑 **4–6 seed**（df 3–5，CI 收到 ×2.8–3.6），要么接受宽区间并**按上界保守取 n**，并把 **n(σ) 曲线整条报出来**。

**可直接用的数**（配对 t、α=0.05 双侧）：`MDE = t_{0.975,n−1}·s_Δ/√n`

| n_seed | 3 | 6 | 10 | 20 |
|---|---|---|---|---|
| MDE（× s_Δ） | **2.48** | **1.05** | 0.72 | 0.47 |

⇒ 6→10 只买到 −32%，6→20 才 −55%；**6→3 要付 2.4 倍代价**。

4. **与 N1 的交互（决定性）**：seed 只降**噪声**，不增**世代**。若效应被世代限制（N1），n 从 6 加到 20 也检不出 ⇒ **预算应优先加到 tick 长度**，seed 数够做 seed 级配对即可（≥6）。**预跑同理**：4k ≈ 3 代，`D_shape` 的 seed 间 sd 在 4k 上估出来的是"**初始相**的 sd"，与 12k/40k 的判读窗口不同相 ⇒ 请至少让预跑**覆盖目标长度**，或明确声明该 sd 只作下界使用。

### 4.3 判定态扩成 5 态

`分化 / 分化证据不完整 / 未分化` 三态之外，加两个**"不可执行"态**：
**④ 纪元不足（未达世代门）** ｜ **⑤ 猎物池枯竭（L1a 失效）**。
后两态**不是失败**，而是**必须能说出的机制结局**（同 R3 生态门精神：门不过 ⇒ 不下正负结论）。

## 五、D_shape 仪器最终口径（与外鉴 `55f149e` §四 合流，一次成文）

**主判据**：`D_shape = mid/(mid+ends)`（10 箱、个体直方图、**同 run 内配对**）。

1. **单位**：seed 级（§4.1）；报 `ΔD = D_obs − median(D_null)`；`D_null` **锁死** = 同 n 矩匹配单峰 + **seed 级 / 块置换**；
2. **bin 起点平移第二口径**（外鉴①）：半箱平移后**同向**才算过（防 bin 伪影）；
3. **镜像折叠单峰 null**（外鉴②，同意）：右偏单峰可造中心亏缺 ⇒ 加第二零模型（BC 的"矩匹配不匹三阶矩"批评**对 D_shape 同样成立**）；
4. **mixture-BIC 分离度描述列**（外鉴③）：`|μ₁−μ₂| / 合并 sd`，**只报不进合取**；
5. **两级措辞红线**（外鉴④）：**"拒单峰" ≠ "两分量为真"**；后者须 bootstrap LRT 过（与"未过判据不得写涌现"同构）；
6. 稳健量（IQR / 5–95 分位差）作主、方差作描述；`d_shape_series` + `τ_int` 入档（§4.1）；
7. **新增机制列**：`g16 空间自相关 / 同型相邻对频率`（外鉴 C.2 请求）+ **`frac(g16 ≤ gate)` 时间序列**（N2）；
8. 🚫 仍禁止：均值变化 / dash 用得多 / 弱效应 读成"分化"。
