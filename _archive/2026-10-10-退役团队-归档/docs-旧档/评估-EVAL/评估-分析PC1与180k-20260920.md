**结论 2：这不是 LV"捕食者-猎物"周期。** 恢复期（10k–105k）`pred_frac` **恒 ≈0.99**——攻击型**从未退场**；只有在顶格之后才**缓慢**去攻击化（0.999@105k → **0.966@180k**，75k 内 −3.3%）。⇒ **"捕食者崩溃→猎物释放"的经典机制在本系统不适用**；本质是**单营养级同类相食的弛豫振荡**（与普查"内战态无营养级延迟反馈"一致）⇒ 侧面支持 fish 的"周期需先分化"。

**结论 3：🔴 g15 在最长 run 里"死透且不复活"（本批最重要的科学读数）。** N 从 249 恢复到 3240（×12），而 **g15 从 0.039 一路停在 0.02–0.05、末值 0.019**；`codebook_conv` 0.21→0.32、`trust` 0.68→0.74 同步低位。⇒ **生态恢复 ≠ 信号恢复**——这是对 fish 预言②（"全员捕食者世界信号基因无用"）的**直接实测支持**，也是本项目**最长 run 的阴性**：即便回到顶格、食物充足，信号基因**没有回来**。

**结论 4：判读规范需再补一条——跨区制还有"世代数"混淆。** 该 run 的 `max_gen` = **215@180k**（≈1 代/900 tick），而饱和态 60k 只有 **16** ⇒ **两区制的世代周转差 ~10×**。此前我只提"相位匹配"，现在要加：**跨区制比较 ρ/选择类指标时，世代数差一个量级**（同一 tick 数对应的选择轮次完全不同）。

**结论 5（数据限制，非缺陷）**：该 CSV 是**旧 14 列 schema，没有 `g16` 列**（g16 列 09-20 21:37 才加，而本扩展 21:28 已完成）⇒ **"攻击基因固化"假说无法在该 run 上检验**。另：我自己在终端里一度把缺失列显示成 0.0000，**那是我的显示 artifact，不是数据问题**（已核表头 14 列）。

**结论 8：🔴 主判据①（`codebook_conv` 配对超额）是构造伪影，且方向相反**
`pczero` 的 `codebook_conv` **≡ 1.0000**（6/6）——关码本 ⇒ **恒等映射** ⇒ 收敛度天然满分；故 main−zero = **−0.0812**（0/6 正，CI 下界 −0.096）是**构造差**，**不是**"学习发生"的证据，而且**方向与"更好"相反**。⇒ 建议把 R134 的主判据①**降级为"对照一致性检查"**，阳性主证据改用 **⑥（尤其 vs `pcsigoff`）**；若仍要报 conv，须同时报 **`conv × H(发射码分布)`**（U1 防单码塌缩假阳性）。

**结论 9：⚠️ ρ 两个对照都不显著 ⇒ 行为链 ✅ / 适应度链 ❌**
