## 背景（为什么需要这两个参数）

主实验形态目标 = "千代 × 10 seed × 四臂对照"。D3 实测（见 `评估-EVAL-D3世代压缩结果-20260909.md`）：
- **世代间隔 ≈ 7.3 × rotation_period**（生态无压力时世代被寿命上限 `_lifespan=day×(1+g3×7)` 锁死）
- rp=300 时 100 万 tick ≈ 445 代，**达不到千代**；单压 rp<200 会破坏昼夜节律语义

因此需要两个独立旋钮，绕过"压 rp 破坏光照"的限制：
1. **lifespan_mult** —— 缩放寿命基准（不动昼夜），世代缩短到 500~1100 tick
2. **movement.stay_prob** —— 停驻率，配合 D2 感知半径 4 邻 = 等效扩世界 4~8 倍零算力（评估共识 5，Q4 降速优先不扩世界）

## 任务 1：`lifespan_mult`（寿命基准缩放）

**Spec**：`SimConfig` 新增字段 `lifespan_mult: float = 1.0`（`__post_init__` 断言 >0.05 且 ≤8）。
归属建议：放 `OrganismConfig`（寿命是生物属性；与 `rotation_period` 解耦）。

**实现**：引擎 `_lifespan(g3)`（sphere_engine.py ~line 393）：

```python
def _lifespan(self, g3):
    day = float(self.config.light.rotation_period)
    mult = float(self.config.organisms.lifespan_mult)
    return day * mult * (1.0 + g3 * 7.0)
```

**关键：Rust 侧零改动方案**：`step_vectors_stage1/stage2` 内部用 `day_len` 推导成熟/老年年龄。Python 调 Rust 时把 **`day_len` 参数传 `day_len × lifespan_mult`**（等效压缩，Rust 无感、ABI 不变、双路径对拍自动成立）。Python 参考实现均改用 `_lifespan()`，两侧一致性由现有引擎级对拍测试兜底。

**必须保持的契约**：不新增/删除任何 RNG 消费（纯数值缩放）；`fingerprint()` 自动含新字段（`asdict`），旧存档 `from_dict` 回退 `mult=1.0`。

**CLI 透传**：`run_long_experiment.py` 加 `--lifespan-mult`（默认 1.0）→ `_make_config` 写入；`run_ensemble.py` 同款透传（供系综扫描）。

**测试**（tests/test_lifespan_mult.py，≥7 例）：
1. `_lifespan(g3)` 在 mult=0.5 时 = day×0.5×(1+g3×7)（单元）
2. mult 不影响 RNG 消费顺序：同 seed 下 mult=1 vs 2 前 100 tick 个体数序列长度相等
3. 双路径对拍：mult=0.5 引擎级 TickStats + 内部数组逐位一致（use_sim_core 开关）
4. mult=0.25 下世代间隔显著缩短（50k tick max_gen 大于 mult=1 对照）
5. fingerprint 含 lifespan_mult；不同 mult 指纹不同
6. old snapshot（无 mult 字段）加载回退 1.0

**验收**：pytest 全绿 192+；对拍通过；一次 20k tick 冒烟（mult=0.25 不出灭绝异常）。

## 任务 2：`movement.stay_prob`（停驻率）

**Spec**：`SimConfig` 新增字段 `stay_prob: float = 0.0`（0=旧行为每 tick 必移判定，向后兼容；断言 0≤stay_prob<0.95）。归属建议：新增 `MovementConfig` dataclass 太散，放 `SimulationConfig`（与 social_move_weight 同列，已是移动决策参数容器）。

**实现**：移动判定（sphere_engine.py 步骤 5，Rust 路径 ~line 640 / Python 路径 ~line 656）：

```python
move_prob_full = genes[:, Gene.MOVE_PROB] * (1.0 - genes[:, Gene.ROOTING])
move_prob = move_prob_full * (1.0 - stay_prob)   # 停驻：统一调低移动概率
```

**RNG 契约（最重要）**：**保持每 tick 消费 P 个 uniform 不变**（`self.rng.random(P)` 原样），只改阈值 `move_prob` —— 移动个体变少但 RNG 位置不变；Python/Rust 两侧用同一公式，引擎级对拍自动成立。**严禁**用"额外 random 决定停驻"（那会移动 RNG 位置，摧毁对拍）。

**CLI 透传**：`--stay-prob` 进 run_long_experiment + run_ensemble。

**测试**（tests/test_stay_prob.py，≥6 例）：
1. stay_prob=0.8 vs 0：同 tick 位移量显著下降（移动均值/统计）
2. 双路径对拍：stay_prob=0.6 引擎级逐位一致
3. RNG 对齐：stay_prob 只改阈值不改随机消耗（对拍即证）
4. fingerprint 含 stay_prob
5. stay_prob=0 完全等于旧行为（对拍 1:1）
6. 触发 assertion：stay_prob=1 抛错

**验收**：同上。
