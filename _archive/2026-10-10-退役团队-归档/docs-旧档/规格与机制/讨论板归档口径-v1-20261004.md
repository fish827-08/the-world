## 三、切点选择（唯一锚点）

**规则**：从最新帖倒推，保留**本归档触发时刻往前 24 小时**内的全部帖在新板；更早的搬入归档件。

**锚点格式**：切点行必须唯一命中 `### [署名] · YYYY-MM-DD HH:MM`。

**大小兜底**：若 24h 内容仍 >300KB（罕见，如第 11 轮 4 天 741KB 场景），缩窗至 12h 或 6h，或按 R 编号段切；宁可多留不留新板仍超阈值。

**禁止**：切点选在**未落定讨论中**的帖之前（会割裂上下文）；优先选在 R 编号闭合处（如 R<末> 之后）。

## 四、零内容丢失对表（三档校验）

### 档 1：字节数对表（工具自检）
```
归档前 board 字节 = 归档件字节 + 新板字节 − 归档件头 − 新板头新增
```
容差 ±1%（头部说明文字允许少量增补）。

### 档 2：帖数对表（工具自检，已实现）
```
grep -c "^### \[" 归档件 + grep -c "^### \[" 新板 = grep -c "^### \[" 归档前
```
`tools/archive_board.py:103-105` 已硬检查 `posts == n_posts_after`。

### 档 3：R 编号连续对表（口径新增，人工兜底）
```bash
# 归档前后各跑一次，R 全集必须一致：
grep -oE "R[0-9]{2,3}" _share/讨论板.md | sort -u > /tmp/after.txt
grep -oE "R[0-9]{2,3}" _share/archive/讨论板-<本轮>.md | sort -u > /tmp/before.txt
comm -3 <(sort -u /tmp/before.txt /tmp/after.txt) <(sort -u /tmp/after.txt /tmp/before.txt)
# 期望：无输出（R 全集相等）
```

> ⚠️ **三档同时过 ⇒ 才算零内容丢失**。任一档不通过 ⇒ 回滚重跑（第 11 轮曾因此回滚，见 `_archive/归档记录.md` 过程登记）。

## 五、只增不删纪律（F-R10）

**根因**：本机环境 Python `os.remove` 失败（`SHFileOperationW 0x2`），反复尝试会 SIGTERM 杀进程。绕行三律见 `collab-toolkit/README.md`。

**在归档中的具体化**：

| 动作 | 允许 | 禁止 |
|------|------|------|
| 归档件写入 | `write_text` 一次性写；文件不存在时创建 | 覆盖已存在归档件（工具守卫已拒） |
| 原板内容 | append-only 搬入归档件 | 逐行 delete / 截断 |
| 新板头部 | **重写**置顶区/快照/未落定项/归档说明 | 删除任何已发帖 |
| 归档件头 | 加"归档说明"头（含轮次、切点、检索指引） | — |

> 📌 归档≠删帖。原板内容**逐字节**进归档件；新板是**归档件之外的剩余 + 新板头**，不含任何"删减后"的旧帖。

## 七、工具执行

**唯一指定工具**：`tools/archive_board.py`（第九轮起入库；幂等三重守卫）

**用法**：
```bash
python.exe tools/archive_board.py \
    --cut "### [署名] · YYYY-MM-DD HH:MM" \
    --arch 讨论板-YYYYMMDD.md \
    --round 第十三轮 \
    --pin-file <置顶文本> \
    --head-file <快照+未落定项+归档说明> \
    --dry-run   # 先跑 dry-run 看字符数
```

**禁止**：自写临时脚本执行归档（第 11 轮教训：草稿件 `_trash_local/_archive_board_11.py` 漏搬三节 ⇒ 违反 append-only）。若工具守卫过严，走**缺陷上报**（镜审 → PI 裁定 → 补工具），**不绕过工具**。

**归档前后各跑一次体检**：
```bash
python.exe collab-toolkit/tools/board_check.py check --net
```
预期：归档前 size 错误 1 项；归档后 size 错误 0 项（新板 <300KB）。
