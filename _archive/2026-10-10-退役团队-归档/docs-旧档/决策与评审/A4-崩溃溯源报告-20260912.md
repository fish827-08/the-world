## 零、结论（一句话）

**info-asym ON 的生态崩溃，根因是一处方向偏置 bug**：`perception_radius=4` 的实现用 `nb[:4]` 取了 Moore 8 邻的**前 4 个**，而邻居表列序是 `[上左, 上, 上右, 左, 右, 下左, 下, 下右]` ⇒ 个体**永远只能向北或向西移动**（看不到 右/下左/下/下右）。空间移动被单向锁死，觅食与招募退化，N 单调衰减。

**这不是"信息不对称太强"，也不是资源不足**——控制实验证明：把前 4 个邻居换成**任一各向同性**的 4 邻子集，生态即恢复到对称基线。

## 二、代码侧（`[代码]` 断链定位）

### 2.1 断掉的链路（基线 `015c715`）

**`simulation/sphere_engine.py:752-753`**（D2 信息不对称移动决策，Python 路径）：

```python
nb = np.asarray(self.world.neighbors(int(self._flat[idx])))
# D2-3 信息不对称：感知半径4（Von Neumann，只取前4个邻居）
if d2_asym and len(nb) > 4:
    nb = nb[:4]          # ← 断链：取的是"前4个"，不是"正交4个"
```

邻居表列序由 **`world/sphere_world.py:230-231`** 固定：

```python
drow = [-1, -1, -1, 0, 0,  1,  1,  1]
dcol = [-1,  0,  1, -1, 1, -1,  0,  1]
# 列序 = [0]上左 [1]上 [2]上右 [3]左 [4]右 [5]下左 [6]下 [7]下右
```

⇒ `nb[:4]` = **`{上左, 上, 上右, 左}`** —— **只有"北"和"西"两个方向**。

### 2.2 文档意图 vs 实现（矛盾）

- `simulation/config.py:264`：`perception_radius: int = 4  # 感知半径：4=Von Neumann(上下左右)` ← **意图=正交上下左右**
- `sphere_engine.py:751` 注释："感知半径4（Von Neumann，只取前4个邻居）" ← **注释自认 Von Neumann，代码却不是**
- `simulation/config.py:275` **有**断言 `perception_radius in (4, 8)`

### 2.3 方向审计（`[实测]` 结构 + 抽样）

`experiments/a4_attrib_data.py` §A：普通格 `nb[:4]` 的 `(drow,dcol)` 抽样 5/5 全为**非南向**：
`[(-1,-1),(-1,0),(-1,1),(0,-1)]`。该性质由 `_build_neighbor_cache` 的固定列序**对全部普通格恒成立**（结构保证）。

### 2.4 影响面

`[代码]` 全仓检索：`nb[:4]` 仅此一处（基线 `:753`，**已修**）。
Rust 侧 `sim_core/src/movement.rs` **不实现** `perception_radius`——D2 asym 会强制走 Python 路径
（`sphere_engine.py:650` `_d2_asym`）⇒ **无需 Rust 对拍改动，也不破坏双路径契约**。

## 三、机制链（`[代码]` + `[实测]`，含 `[推断]` 标注）

1. `[代码]` ON 时 `nb[:4]={上左,上,上右,左}` ⇒ 每个移动者**只能向北或向西**；
2. `[实测]` `buggy_r4` 三段崩塌 + 出生塌陷（1.2/1.3）；
3. `[实测]` 同期食物**全程满仓**、存活者**能量充裕** ⇒ 不是"世界没粮"、不是"能量破产"；
4. `[推断]` 单向移动破坏"就近趋食"的空间策略：个体无法朝食物真实方向走，觅食效率下降；
   且 `score` 的 `soc × densities` 项叠加单向移动，使局部越挤越挤；
5. `[推断]` 幼体存活/成熟受抑（成熟需 ≈360–2880 tick）⇒ **能繁殖的个体骤减**；
6. `[实测]` ⇒ **出生率跌破死亡率**，N 单调衰减至低位徘徊；
7. `[实测]` 反事实：换成各向同性 4 邻后 N 恢复对称基线（1.2）。

> **对既有判据的含义（R8）**：本崩溃是**失败模式**，不构成对"payoff 通道是否可达"的任何证实或证伪。

## 四、控制实验：病因是"方向偏置"，不是"邻居数=4"

即 1.2 的 E1 矩阵。**两个各向同性的 4 邻子集都能撑住，唯一崩的是有向偏置子集。**
⇒ 病灶 = **方向偏置（各向异性）**，与"只看 4 个邻居"这一被测条件无关。

反事实（`experiments/a4_probe_out.txt`，patchy/500 口径，仅作机制演示）：仅把邻居顺序改为"正交优先"，
`noise=0.05`、`tau=0.15` 照旧，**N 由 11 回升到 855（且仍在上升）**。

## 五、对"最小修复"的指向（第 2 步，已执行）

- **修什么**：把 `nb[:4]` 改为**真正的 Von Neumann（上/左/右/下）**选取（新增
  `SphereWorld.neighbors_von_neumann`，引擎一处调用）；
- **不修什么**：`perception_radius`（C1 被测条件）、`perception_noise`、`softmax_tau`、信号成本、资源参数——**一个都不动**；
