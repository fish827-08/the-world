## 一、P0-1 分通道能量记账（🔴 最高优先）

### 1.1 引擎侧：按 **当前 g16 三分箱** 累计

分组定义（**每 tick 按个体当前 g16 现算**，不用出生标签——防杂交后失效）：

| 组 | 条件 |
|---|---|
| `lo` | `g16 < 1/3` |
| `mid` | `1/3 ≤ g16 ≤ 2/3` |
| `hi` | `g16 > 2/3` |

**每 tick 每人 5 条通道**（有则加、无则 0）：

| 通道 | 定义（对应现有代码） |
|---|---|
| `intake_forage` | 消化产能 `digest × eat_efficiency`（`sphere_engine.py:897`） |
| `intake_pred` | 捕食转移 `energy[prey]×transfer_ratio` + `stomach[prey]×stomach_transfer` 折算部分（`l4_l5.rs` / 参考路径） |
| `cost_meta` | `base_metabolism×metab_mult×age_mult + homeo_upkeep×homeo`（`:911-913`；**不含**光合收益，光合单列可选） |
| `cost_move` | 移动能耗 |
| `cost_attack` | 出手成本（**含失败**，`:92` in `predation.rs`） |

### 1.2 建议的记账方式（工程上最省、且能出 median）

**每 tick、每组**计算 `net_i = intake_forage + intake_pred − cost_meta − cost_move − cost_attack`，然后**当场**取：

- `n`（该组人数）
- `mean(net)` / `var(net)`（用 `sum`、`sumsq` 累加，末期一次算）
- **`p10 / p50 / p90`**（`np.percentile(net_group, [10,50,90])`，**当 tick 算完即弃**，只把统计量入时间序列）

⇒ 这样**不需要**保样本，也不用直方图近似；**p50 直接就是 fish 要的"中位数"**。
⚠️ 组内 n=0 时写 `None`（**不要写 0**，R120 口径纪律）。

### 1.3 落盘（🔴 列名锁定）

**CSV 新增列**（建议 16 列，每 tick 一行）：

```
g_lo_n,  g_lo_net_mean,  g_lo_net_p50,  g_lo_net_var
g_mid_n, g_mid_net_mean, g_mid_net_p50, g_mid_net_var
g_hi_n,  g_hi_net_mean,  g_hi_net_p50,  g_hi_net_var
forage_in_mean, pred_in_mean, mean_energy, prey_energy_mean
```

（最后四项：`forage_in_mean` = 全球人均食草摄入/tick；`pred_in_mean` = 全球人均捕食摄入/tick；`mean_energy` = 存活个体平均能量；`prey_energy_mean` = **被击杀瞬间的猎物平均能量**——**这一项是 R141 解方程的关键输入**，请在捕食成功处累计 `E_prey` 与该 tick 击杀数。）
