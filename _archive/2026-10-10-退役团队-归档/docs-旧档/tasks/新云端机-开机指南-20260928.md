# 新云端机（Ubuntu-0FPN）开机指南 — 手把手版

> 机器：腾讯云轻量 `Ubuntu-0FPN`｜2核2G/50G｜IP `49.232.33.59`｜到期 2026-10-28
> 目标：变成"第四云端"——**24h 不间断长批专机**（吸引子普查 / 旗舰 60k / 扫参批）
> 操作方式：浏览器里点控制台的 **「登录」** 按钮，会打开网页终端（OrcaTerm），把下面的命令**逐块复制粘贴**执行。
> 每条命令后面都写了"你应该看到什么"，方便核对。

---

## 第 0 步 · 登录

1. 腾讯云控制台 → 轻量应用服务器 → 找到 `Ubuntu-0FPN` → 点 **「登录」**；
2. 首次会让你设置/输入密码（你买时设的那个），进入后就是一个黑色命令行窗口；
3. 提示符开头如果是 `root@` 或 `ubuntu@` 都正常（下面的命令两种用户都能跑）。

## 第 1 步 · 系统基础（时区 + 内存保险）

逐块粘贴：

```bash
sudo timedatectl set-timezone Asia/Shanghai
date
```
> 应显示 `2026-09-28 ... +08`（北京时间）。

```bash
sudo fallocate -l 2G /swapfile
sudo chmod 600 /swapfile
sudo mkswap /swapfile
sudo swapon /swapfile
echo '/swapfile none swap sw 0 0' | sudo tee -a /etc/fstab
free -h
```
> `free -h` 的输出里 **Swap 一行应显示 2.0Gi** —— 这是 2G 内存的保险（防跑批时内存爆掉）。

```bash
sudo apt update && sudo apt install -y git python3-venv
```

## 第 2 步 · 确认 Python 版本

```bash
python3 --version
```
> 应显示 **Python 3.12.x**（Ubuntu 24.04 自带，正好是我们要求的版本）。
> 如果显示 3.11 或更低 ⇒ 停下来，把截图发回群里，不要继续。

## 第 3 步 · 准备 Gitee 凭据（网页操作，一次性）

1. 浏览器打开 `https://gitee.com` → 登录 → 右上角头像 → **设置** → 左侧 **私人令牌** → **生成新令牌**；
2. 勾选 `projects` 权限即可，生成后**复制那串令牌**（只显示一次，存好）；
3. 回到网页终端继续下一步——clone 时"用户名"填你的 gitee 用户名，"密码"填**这串令牌**（不是网页登录密码）。

## 第 4 步 · 克隆两个仓库

```bash
mkdir -p ~/world && cd ~/world
git clone https://gitee.com/little-fishy/the-world.git
cd the-world
git clone https://gitee.com/little-fishy/the-world-data.git
```
> 第一条 clone 会提示输用户名/密码：用户名 = gitee 用户名，密码 = 第 3 步的令牌。
> 第二条（数据仓）一般不再提示（凭据被记住）。
> 完成后 `ls` 应看到 `the-world/` 里有 `AGENT.md`、`simulation/` 等；`the-world/the-world-data/` 里有 `results/`。

## 第 5 步 · 建 Python 虚拟环境 + 装依赖

```bash
cd ~/world/the-world
python3 -m venv .venv
source .venv/bin/activate
pip install -U pip numpy pytest
```
> 激活后命令行开头会出现 `(.venv)` 字样——**以后每次登录跑批前都要先执行 `source ~/world/the-world/.venv/bin/activate`**。
> 我们的主线批（rd 开 + Python 路径）只需要 numpy + pytest，**不需要装 Rust**（引擎检测不到 sim_core 会自动走 Python 路径，正好）。

## 第 6 步 · 冒烟验证（证明环境能跑）

```bash
cd ~/world/the-world && source .venv/bin/activate
python -m pytest tests/test_resource_dynamics_t2.py tests/test_sparse_fields.py tests/test_snapshot.py -q
```
> 应显示 **全部 passed**（约 40 例左右）。如果有 failed ⇒ 停，截图发群里。

```bash
python experiments/rd_resume_smoke.py --help
```
> 能打印用法说明 ⇒ 说明脚本就位。（真正跑冒烟用云归 S0 帖里的完整参数，下一步一起。）

## 第 7 步 · 第一个正式任务：吸引子 24 种子普查

配置照云归 S0 帖（R248 §二）：`patches=1700` ＋ `bg_low_prod_frac=0.4` ＋ `bg_low_cap_mult=0.05` ＋ `pop=10000` ＋ **3000 tick × 2 臂（rd off/on）× 24 seed**。
具体命令行以云归帖里的脚本调用为准（`steady_k_probe` 家族）；**预计 40–60 分钟连续跑完**——这正是这台 24h 机器的用武之地。

跑完：
```bash
mkdir -p ~/world/the-world/results/<批名>
# 产物复制进去后：
cd ~/world/the-world-data
git add results/<批名> && git commit -m "data: [新云端] 吸引子24seed普查产物" && git push
```

## 第 8 步 · 汇报入册

在讨论板发帖：**自取花名**（照云启/青梧先例）+ 本机能力档案（核数/内存/实测 ms/tick 一个数即可）+ 第 7 步结果。
→ 天平复核后入册，正式成为"第四云端"。

## 常见问题

| 现象 | 处置 |
|---|---|
| `sudo` 要密码 | 输你买机器时设的登录密码（输入时不显示，正常） |
| clone 提示 403/需要认证 | 令牌没勾 `projects` 权限，或密码填成了网页登录密码 ⇒ 回第 3 步重新生成 |
| `pip install` 慢 | 换源：`pip install -U pip numpy pytest -i https://pypi.tuna.tsinghua.edu.cn/simple` |
| 跑批中途断线 | Web 终端断开**不影响**已启动的进程（建议用 `nohup ... &` 或 `tmux` 跑长批） |
| 内存不足被杀 | 确认第 1 步的 swap 已加（`free -h`）；同时只跑 1–2 路 |
