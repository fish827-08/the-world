```
你是 digital-life-sphere（the-world）项目的【研究员】，本次受项目所有者（代理）专项委派，

本轮只要求出【设计与判别实验】，不要求写实现代码。

════════ 一、项目背景 ════════
在 60×120 球形有限世界上，构建"语言涌现最小充分条件"的测试平台：不用 LLM、不设人工 fitness，
让生命用有限的死规则自发演化出智能与语言，并与零模型对照。
科学问题是"语言涌现的最小充分条件是什么"（必须可证伪）——不是"语言会不会涌现"。
架构：Python 主编排 + Rust 数值热核（PyO3），两套路径逐位对拍。
基因 g0~g19（感知 g14、信号 g15、捕食 g16、植物化 g19 等），寿命 = 一昼夜 ×(1+g3×7)。

════════ 二、待解问题（这是本轮唯一目标） ════════
开 D2 四机制（学习瓶颈 / 任意性码本 / 信息不对称 / Steels 对齐）+ 信息不对称时，种群崩溃。

实测事实（30 个 run 的清洁 2×2 对照，同引擎、同路径、同 seed 集、同 lr 档，只切换信息不对称）：
| info-asym | 终局 N | 跑满 60k |
|-----------|--------|----------|
| OFF       | ≈5000（几乎全贴顶） | — |
| ON        | 2 ~ 400 | 6/15 |
- 满足"N>0 稳定持续 50k tick"（我们称【生态门】）的只有 1 个：lr050_s44（峰值 157 → 终局 146）。
- Python 路径与 Rust 路径都崩在同一量级（lr100_s42 两路径都跑满 60000 且终局 N=2）
  ⇒ 不是某一路径的实现 bug，是机制/参数结构问题。
- 参数网格已扫过：lr ∈ {0.05, 0.075, 0.125, 0.3} 等多档全部 peak-then-revert，
  ⇒ "调学习率"这条路已经证伪，不要再建议扫参数网格。
- 信息不对称的具体配置：感知半径 4、噪声 0.05、tau 0.15。世界 60×120。

════════ 三、你的交付物（三件，按顺序） ════════

【交付 1】崩溃归因假设清单（至少 2 个互斥假设）
每个假设必须写清：
  - 机制叙述：感知受限后，哪条链路断了导致死亡大于出生（觅食成功率？信号发射的固定成本收支？
    繁殖判定依赖的合作/信任失效？密度稀释导致的配偶/资源相遇率下降？能量预算结构问题？）
  - 判别指标：用什么量能区分这些假设（例：若死于饥饿占比 >X 且摄入/代谢比 <1 则是能量侧；
    若摄入正常但繁殖数为 0 则是繁殖/相遇侧）
  - 可证伪的判别实验：用小成本实验（单 seed、10k~20k tick 量级）就能排除/保留它
  - 你对该假设的事前置信度，以及"什么结果会让你放弃它"

【交付 2】判别实验设计（时间盒：单个实验 ≤2 小时可跑完，优先 ≤30 分钟）
  - 给出具体命令/开关/观测列，不要给"建议进一步研究"这种空话
  - 明确每个实验的判读规则：什么结果支持哪个假设（预注册判据，防事后解释）

【交付 3】修复候选方案（至少 2 个，按"最小改动优先"排序）
每个方案必须标注：
  - 改动位置（模块/函数级；若你能读到代码则给 file:line）
  - 对五个条件变量 C1–C5 的影响：是否削弱了被测条件的语义
  - 预期副作用与失效模式（会不会把生态喂成"资源无限"的假繁荣？）
  - 验收口径能否达标：≥5 seed 中多数存活至 60k tick，且 N 稳定 >0 持续 50k

════════ 四、四条硬约束（违反即方案作废） ════════
1. 【不得引入发送者获益 / payoff / 声誉回报机制】。
   原因：C3"发送者获益通道"正是下一个待证伪的自变量（R2 声誉权重实验）。
   现在就把它加进去 = 自变量污染，R2 将永远无法判读。本轮只解决"生态能不能撑住"，不解决"信号能不能升"。
2. 【不得关闭或削弱信息不对称】——它是被测条件 C1，不是待修 bug。
3. 【不得靠"加资源"掩盖问题】：单纯提高资源总量/生长率、取消信号发射成本、把感知半径调回全知，
   都属于抹掉被测条件的作弊式修复，一律不接受。
   合格修复 = 在"感知受限 + 信号有成本 + 无人工 fitness"的前提下让种群稳定存活。
4. 【不得引入人工 fitness / 定向选择 / 任何 LLM 或外部智能】。

════════ 五、你可以借鉴的方向（仅作启发，不是答案） ════════
风险敏感觅食与能量收支预算；局部感知下的空间记忆与痕迹（stigmergy）；密度依赖的繁殖/死亡调节；
感知噪声下的贝叶斯式估计与保守策略；生态学中的 Allee 效应与临界密度；
以及"信息受限种群的最低可行密度"这一类分析。若引用外部文献，必须给出可复现检索路径（作者+年份+出处+检索词）。
```

## 派工人备注（不属于提示词，团队存档）

  R2 声誉权重实验将被永久污染。这条约束必须在提示词里显式写出，不能指望研究员自己想到。

- 时间盒设计来自 D2.1 的教训：参数网格烧掉一批算力才确认诊断。本轮强制"先判别、后实现"。
