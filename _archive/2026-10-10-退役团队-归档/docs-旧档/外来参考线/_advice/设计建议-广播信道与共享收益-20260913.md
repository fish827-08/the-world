## 〇、三句话回答你的三个问题

| 你的问题 | 一句话回答 |
|---------|-----------|
| **「共享收益」怎么定义？** | 把**发送者的适合度接到"接收者做对动作"这件事上**（`u_S = ρ·u_R`，ρ=1 即 Lewis 纯协调）。注意：**生物学对"信号"的定义本身就要求它对发送者有利**（Maynard Smith & Harper 2003）——"共享收益"不是额外奖励，它是**信号之所以是信号的定义要件**。 |
| **信号本来无意义，怎么确立它指代什么？** | **不需要确立，也不需要指定。** 生物学上的路径是 **cue（线索）→信号**（ritualization）：先有**接收者**学会利用一个副产品线索，**然后**发送者因接收者的反应而获益，双向选择把它固化成信号。契约式的"指代"是**事后可从外部测量**的统计关系：描述性意义 = `P(状态|信号)`，指示性意义 = `P(动作|信号)`。**"任意编码"不是缺陷，是必需的**（它就是 L2 任意性判据）。 |
| **改声音式广播，会不会大幅降性能？** | **不会，可以忽略**：从"逐发射者枚举周围格"改为**累积声场**后是 `O(K·C + N)` ≈ **每 tick 1.4 M 次浮点**（R=8），NumPy 约 **3–10 ms/tick**，相对你当前 D2 的 **234 ms/tick** 只占 **1.5%–4%**；Rust 下 **<0.5 ms/tick**。**真正的风险不在性能，而在三处语义冲突**（见 §3.4）——其中最严重的一条：**广播会实质改写 C1，它不是 bug fix。** |

## 一、「共享收益」的严格定义

### 1.1 形式化

设世界状态 `s ∈ S`；发送者观测到 `s`（或其私有部分）；发射信号 `m`；接收者选择动作 `a`。
双方收益为 `u_S(s, a)` 与 `u_R(s, a)`。

**共享收益（common interest / payoff coupling）** 定义为：

```
u_S(s, a) = ρ · u_R(s, a),      ρ ∈ [0, 1]
```

| ρ | 含义 | 对应 |
|---|------|------|
| ρ = 1 | **纯协调**：发送者与接收者的能量由**同一个结果变量**决定 | Lewis 1969 / Skyrms 2010 标准信号博弈 |
| 0 < ρ < 1 | **部分共同利益**：这是生物界的常态 | Godfray 1991 诚实信号；Zahavi 障碍原理 |
| ρ = 0 | 纯冲突：只能靠障碍成本维持诚实 | 可留作后续"欺骗实验"的极端档 |

**落到你的引擎**（最小可判定形式）：

```
energy[sender]   += b_S · 1[ a == â(s) ]      # 只有"接收者做对"才给
energy[receiver] += b_R · 1[ a == â(s) ]
```

`â(s)` = 状态 `s` 下的正确动作。**η 注意：收益挂在"做对"上，不挂在"发射"上。**

### 1.2 三个必须同时成立的前提（缺一条，共享收益就空转）

1. **`s` 对接收者不可见**（私有信息）——否则接收者的策略不需要信号，信号拿不到任何选择压；
2. **接收者的策略以信号为输入**（`a = π_R(m, 局部观测)`）——否则信号改变不了任何结果；
3. **`b_S` 的量级要够大**——大到 `信号选择系数 ≫ 漂变`。你 G3 实测 `σ(g15)=0.130`，
   若 `b_S` 小到"做对与做错的能量差"落在死亡率的日内波动内，**再跑 60k 也测不出来**（这是可预先核验的门槛，不是事后解释）。

> **可核验的前置判据（建议预注册）**：先算**入侵适合度**——"恒发信号"突变体 vs "恒不发"突变体的能量收支差 `ΔE`。
> 要求 `ΔE > 日内能量波动 σ_E`，否则该参数档**不具备可测性**，不必开跑。

### 1.3 与 C3（声誉/间接互惠）的区分（这条必须写死，否则 R2 会被污染）

| 维度 | **共享收益（本修点）** | **C3 声誉/间接互惠（R2）** |
|------|----------------------|--------------------------|
| 收益来源 | **同一次交互的共同结果** | **未来**交互中被别人挑中 |
| 是否需要记忆 / 伙伴选择 | **不需要** | **必须需要**（否则退化为外生加分） |
| 是否内容相关 | **是**（做对 ⇔ 读懂了 `s`） | 当前 R2 形态是"内容无关" |
| 时间尺度 | 即时 | 跨回合 |
| 对 R2 自变量的污染 | **无** | — |

> ⚠️ 这张表就是 `docs/外来参考线/_advice/设计建议-20260912.md` §6.1 那条提醒的形式化版本：
> R2 若实现为"给发信号者一个与内容无关的得分加成"，则结论是**定义性**的。
> **共享收益通道**才是那条"既有正回报、又不与 C3 混同"的路。

## 二、考证：信号如何获得"指称"（你的核心疑问）

### 2.1 你的直觉是对的：信号一开始确实是"无状态"的

这不是设计缺陷，而是**文献里的标准起点**。四条独立线索指向同一个结论。

#### （1）生物学路径：**cue（线索）→ 信号**（ritualization）

`[文献]` **Tinbergen 1952** 提出的 **ritualization**：信号大多**不是凭空出现的，而是从线索演化来的**。
`[文献]` **Maynard Smith & Harper 2003** 明确区分：

> **cue**：一个行为或性状的附带产物，对它的利用**不以发送者利益为目的**（如受伤的鹿跛行 → 狼读到"好抓"）。
> **signal**：**因"能够改变接收者行为"这一效果而演化出来**的行为或性状。
> **"The benefit to the signaler is key. It differentiates signals from cues."**

经典例子（`[文献]` Scott-Phillips et al. 2012 综述）：
- **狗龇牙**：最初是攻击前动作的**副产品**（线索）⇒ 接收者学会据此提前逃跑 ⇒ **发送者也因对方退让而获益** ⇒ 双向选择把龇牙固化成威胁信号。
- **尿液标记领地**：最初只是恐惧时排泄的副产品 ⇒ 后来成为领地信号。

> ★ **对你的设计最重要的一点**：**顺序是"先有接收者的解读，后有发送者的利用"。**
> 你问"怎么确立一个信号指代什么"——答案是：**它由接收者的反应被选择出来，不由发送者指定。**
> 所以你的引擎只要提供**接收者会解读**这件事（解读表 / 学习），指称就会自己长出来。

#### （2）契约论路径：意义是**任意的**，靠对称破缺收敛（Lewis / Skyrms）

`[文献]` **Lewis 1969**《Convention》；**Skyrms 2010**《Signals: Evolution, Learning, and Information》（Oxford UP）。
`[文献]` **Huttegger, Skyrms, Smead, Zollman 2010**, *Evolutionary dynamics of Lewis signaling games*, **Synthese 172:177–191**。

核心：信号与状态的对应是**纯约定**的；从一个 signalling system 出发，**把所有信号置换一遍仍是均衡**。
意义在**收敛到某一个约定**的对称破缺中产生。

★ **而且 Skyrms 给出可测量的定义**（这正是你要的"怎么知道它指代什么"）：

```
描述性意义（descriptive） = P( state | signal )      ← 信号能预言什么状态
指示性意义（indicative）  = P( action | signal )      ← 信号能预言什么动作
```

**⇒ 你不需要知道信号指代什么，你测量它。** 这两个条件分布 + 置换零模型，
就是一个**可以写进判据、且不依赖"符号/指示符"叙事**的指标。
（比现在的 `signal_context_mi` 更好：后者受 `f_bit` 硬编码污染，而条件分布可以逐状态对比。）

#### （3）认知科学路径：符号靠什么"接地"（Harnad 1990）

`[文献]` **Harnad, S. (1990). *The Symbol Grounding Problem.* Physica D 42:335–346.**

> 符号不能靠别的符号获得意义——**"用汉语词典学汉语"**是学不会的。
> 必须自下而上接在**非符号表征**上：**iconic**（感觉投影的类比）+ **categorical**（特征检测器）。

**对你的引擎的直接含义**：
- 信号要接地，就必须接在**世界的可感知量**上（食物量、温度、捕食者距离）；
- 而现在 `pattern = e_bin×4 + f_bit×2 + n_bit` 接的是**发送者自己的能量档** ——
  **那是"指示符"，且接收者本来就能直接观测它** ⇒ 接地失败 + 信息价值为 0（正是 §3.1 的病根）。

#### （4）机制路径：具体**怎么固定**下来（Steels 语言游戏）

`[文献]` **Steels, L. (1995).** *A self-organizing spatial vocabulary.* **Artificial Life**（Naming Game 首次发表）；
**Steels 1997/1999** Talking Heads 实验。

机制三部：**discrimination game**（把世界切成有区分度的类别）→ **guessing game**（发送者出词、接收者猜所指）
→ **只有成功才强化**（success-based reinforcement）+ 歧义消除 ⇒ 约定收敛。

★ **对你的引擎的硬要求**：**必须有"成功/失败"判定**。
你 `_web_eval` 的 **W-F4 已判定"缺 Steels 失败反馈"** —— 这不是细节，
**没有失败反馈就没有"发明新词"的驱动力，词表无法对齐**。

#### （5）符号学分类（用来给 L2 判据定位）

`[文献]` **Peirce** 的三分：**icon**（相似）/**index**（因果相连，**不可伪造**，如红鹿吼声反映体型）/**symbol**（任意约定）。
你的目标是 **symbol**，而 symbol 的充分条件里**必须包含"任意性"与"约定性"** ——
这就是 `L2` 判据的文献锚点。

### 2.2 综合结论（直接回答"怎么确立一个信号指代什么"）

| 层次 | 结论 |
|------|------|
| **哲学层** | 符号的指称**不能在符号系统内部被定义**（Harnad 的"汉语词典"困境）。它必须接在非符号的感知上。 |
| **生物学层** | 指称从**线索**起步：接收者先用它，发送者后受益，于是被选择固化（ritualization）。 |
| **博弈论层** | 指称是**约定**（任意、可置换）；靠对称破缺收敛；**可从外部测量**为两个条件分布。 |
| **工程层** | 你**不需要**给信号赋语义。你只需要给三件事：**(a)** 发射条件于一个只有发送者知道的状态；**(b)** 接收者动作依赖信号、且有成败判定；**(c)** 成败改变双方能量。 |

**⇒ "无状态的信息"不是要修的 bug，而是设计前提。** 要修的是**它接错了对象**（接在自己能量档上，而不是接在世界状态上）。

## 三、声音式广播信道的评估

### 3.1 把你的提案规格化

| 你的要求 | 规格化 |
|---------|--------|
| 向一个方向发送 / 或圆形传播 | 圆形（用户已接受方格近似）；建议做成可选度量 `grid_L2 / grid_L1 / grid_L∞` |
| 传播格数与能量消耗正相关 | **半径 R 是可演化性状**：`R = 1 + round((R_max−1)·g24)`；成本 `c0 + c1·R^α` |
| 挨着时能量最小 | `R=1`（相邻）成本最低；**`c0 > 0` 是硬要求**（否则退回"信号免费"——那个已被你们否决的 B 方案） |
| 超过最大格就结束、不驻留 | **硬截断 R_max**；每 tick **清零重算**（不驻留） |
| 一定格数内一定听得到 | `a(r)=1 for r ≤ r0`（保证半径） |
| 超过后递减，对应听到概率 | `a(r)=exp(−(r−r0)/λ)`；`p_hear = clamp(κ·sensitivity·a(r), 0, 1)` |
| 新基因"敏感性"放大听到概率 | 见 §3.4 冲突 4：**会与发射强度退化**，必须给敏感性配成本 |

### 3.2 ★ 关键架构：**累积声场**，不要逐发射者枚举

```
① scatter：emit_amp[c] = Σ_i amplitude_i · 1[pos_i == c]      ← 只有发射者参与
② 位移累加：sound[c] = Σ_k w_k · shift(emit_amp, offset_k)     ← K 次 O(C) 位移
③ gather：p_hear[agent] = clamp(κ · s · sound[pos_agent])      ← O(N) 采样
```

**成本 `O(K·C + N)`，与种群规模 N 解耦。**（对比：逐发射者枚举是 `O(N·K)`。）

| 项 | 数值 |
|---|---|
| `C`（格数） | 7200 |
| `K`（R=8 圆盘内格数） | ≈ **197**（πR²） |
| 每 tick 场累加 | 197 × 7200 ≈ **1.42 M 次浮点** |
| NumPy 实测估算 | **3–10 ms/tick** |
| 你当前 D2 每 tick | **234 ms**（3.9 min / 千 tick @N=5000） |
| **相对开销** | **+1.5% ~ +4.3%** |
| Rust 实现 | **< 0.5 ms/tick** |
| 改 `grid_L∞`（方形，可分离） | `K` 197 → 2×(2R+1)=34 ⇒ **再省约 5×** |

> **结论：性能不是问题，可忽略。** 你担心的"大幅降低性能"不会发生。
> 唯一真实成本是 **每个接收者每 tick 一次伯努利抽样 = +N 次随机数**（与现有感知噪声同量级）。

### 3.3 可行性：改动量估计

| 能力 | 现状 | 估算改动 |
|------|------|---------|
| 世界尺寸 | 已 CLI 参数化（`--rows/--cols`） | 0 行 |

### 3.4 🔴 五个必须解决的冲突（都比性能重要）

#### 冲突 1（最严重）：**这会实质改写 C1，它不是 bug fix**

现在 `perception_radius = 4` 把个体视野限制在 4 格 —— 这是 **C1 信息不对称的核心机制**。
一旦信号能传 8 格，个体就获得了**感知半径之外的信息**。
⇒ **C1 的语义被改变了。**

你们 R12 之所以能把 `nb[:4]` 定性为 bug fix，理由是"半径仍 4、仍 4 格、噪声与 softmax 不动"。
**广播完全不同：它是新增了一条跨半径通道。**

> **处置建议（与你们自己的纪律一致）**：把它**预注册为一个新条件**（如 **C6 传播信道**），
> 在 manifest 里记录 `signal_channel: broadcast / local`，并在 `AGENTS.md` 条件表里显式登记。
> **否则就是重演"机制被静默改变"这一类事故**——你 R14（`radius=6` 静默 no-op）刚处理过一次。

#### 冲突 2：**顺序反了 —— 必须先接回报通道，再开广播**

广播改变的是"**谁能收到**"，**不改变"发送者为什么要有回报"**。

- 在修点 B 之前开广播：**成本 ↑**（传更远更贵）+ **收益仍为 0** ⇒ **只会加速 g15 灭绝**。
- 在修点 B 之后开广播：**收益被放大** —— 一个发射者能修正**多个**接收者的行为，
  而成本只随半径增长 ⇒ **这才是"信号值得发"的经济学来源**。

⇒ **正确顺序：B（共享收益）→ 广播。**
（附带好处：广播正是**副产品互利**（by-product mutualism）最自然的形态——"我喊一声很便宜，你听懂了我们都赚"。）

#### 冲突 3：**广播 = 公开信道 ⇒ 必然引入窃听（eavesdropping）**

你引擎里有捕食（g16）。捕食者会顺着声音找过来 ⇒ 广播变成"自曝位置"。

**这既是最坏情况，也是最好的情况**：
- 最坏：信号变成负债，g15 被打死；
- 最好：涌现出**真实的诚实信号权衡**，甚至可能演化出"只在同类附近发 / 降低音量 / 只在安全时发"的策略。

⇒ **建议把它当观测量，而不是要消除的问题**：
测量**捕食者位移是否向声源偏移**（`Δrow/Δcol` 与 `sound` 梯度的相关）。
这本身就是一个**可发表的行为结果**，而且是你的引擎独有的优势（纯 LSG 沙盒做不出来）。

#### 冲突 4：**「敏感性」与「发射强度」是退化参数（degenerate）**

两者都只通过乘积 `sensitivity × amplitude` 影响听到概率 ⇒ **基因组层面不可分辨**，会一起漂移。

两个修法：
- **(a) 给敏感性配成本**（灵敏的耳朵耗能）⇒ 打破退化，且"听力成本"本身是很好的选择压来源；**推荐**；
- (b) 只保留一个基因（`R`），敏感性设为常数。

> 顺带：**`R` 与 `g15` 分离成两个性状，是这次改造最大的科学收益**——
> "喊多远"变成可演化性状后，你就能观测到**信号半径的演化方向**，这比"发不发"信息量大得多。

#### 冲突 5：**球形几何 —— 你的正方形网格不是平的**

`[代码]` `world/sphere_world.py:79` 的 `_area = cos_lat/cos_lat.max()` 意味着
**同一格的经度方向物理距离随纬度收缩**；`[代码]` `:148-150` 极点整行坍缩为 1 格。

⇒ 在**格坐标**里画圆，在**球面**上是被拉长的椭圆；极区 K 个格子在物理上挤成一团。

**必须显式二选一，并写进 manifest**：

| 方案 | 做法 | 优点 | 代价 |
|------|------|------|------|
| **(i) 格空间距离** `grid_L2` | 直接按 `(dr,dc)` 算 | 简单；与现有 Moore-8 感知一致，**结果可与历史数据对比** | 物理上各向异性 |
| **(ii) 物理空间距离** | 列偏移除以 `cos(lat)` | 接近真实声学 | offset 表不再固定 ⇒ 成本上升；极区需特判 |

**建议首轮用 (i)**，manifest 记 `signal_metric: grid_L2`。

### 3.5 ★ 一个有用的推导：**最优半径是存在的，而且可解析**

用你的设计（保证半径 `r0` + 指数衰减 `λ` + 成本 ∝ 覆盖面积）推一下：

**收益**（到达的接收者数量，密度 ρ，`R ≥ r0`）：
```
B(R) = b·ρ·[ πr0² + 2πλ(λ+r0) − 2πλ·e^{−(R−r0)/λ}·(λ+R) ]      → 随 R 饱和
      ↑ 保证半径内的接收者      ↑ 衰减区接收者（R→∞ 时趋于常数 2πλ(λ+r0)）
```
**成本**：
```
C(R) = c0 + c1·R^α
```
对 `α = 2`（成本 ∝ 覆盖格数）求极值，**R 恰好约掉**：
```
dB/dR = c'(R)  ⇒  b·ρ·2πR·e^{−(R−r0)/λ} = 2c1·R
                ⇒  R* = r0 + λ · ln( πbρ / c1 )
```

**这个结果有三个直接可用的含义**：

1. **存在唯一内点最优 `R*`**：由 **衰减长度 λ** 与 **收益/成本比 `πbρ/c1`** 共同决定。
   ⇒ 你的设计（"一定格数内保证听到 + 超过后衰减"）是**自洽的**——正因为有衰减，收益会饱和，才出现了内点最优。
   **若不加衰减，`α=2` 下净收益 ∝ R²，只会有角点解（顶到 R_max 或缩到 R_min），不会有最优中间值。**
   这一点验证了你加衰减的必要性。
2. **可预注册判据**：`R 基因` 的演化稳态应当落在 `R*` 附近，而不是顶到 `R_max`。
   若观测到**顶到 R_max** ⇒ 说明收益未饱和（λ 太大 / 密度太高），或成本系数 `c1` 太小。
3. **参数选择的量纲指导**：想让 `R*` 落在 4–8 格，就取 `λ ≈ 2–3`、`r0 ≈ 2`，
   并调整 `b/c1` 使 `ln(πbρ/c1) ≈ 1–2`。

> **推荐参数**：`r0 = 2`、`λ = 3`、`R_max = 12`（留出搜索余量）、`α = 2`、`c0 > 0`。
> 预期演化稳态 `R* ≈ 5`（= 2 + 3·ln(πbρ/c1)），与现有 8 邻感知同尺度，**结果可与老数据对比**。

### 3.7 参考实现骨架（Python 侧关键片段）

```python
# world/signal_field.py
class SignalField:
    """每 tick 重算的瞬时声场。不驻留 —— 禁止跨 tick 累积。"""
    def __init__(self, world, r_max, r0=2.0, lam=3.0, metric="grid_L2"):
        self.world = world
        self.offsets, self.weights = self._build_table(r_max, r0, lam, metric)
        self._field = np.zeros(world.size, dtype=np.float32)

    @staticmethod
    def _atten(d, r0, lam, r_max):
        if d > r_max:
            return 0.0
        return 1.0 if d <= r0 else float(np.exp(-(d - r0) / lam))

    def _build_table(self, r_max, r0, lam, metric):
        offs, ws = [], []
        for dr in range(-r_max, r_max + 1):
            for dc in range(-r_max, r_max + 1):
                d = {"grid_L2": (dr * dr + dc * dc) ** 0.5,
                     "grid_L1": abs(dr) + abs(dc),
                     "grid_L∞": max(abs(dr), abs(dc))}[metric]
                if d == 0.0 or d > r_max:
                    continue
                offs.append((dr, dc)); ws.append(self._atten(d, r0, lam, r_max))
        return np.asarray(offs, np.int16), np.asarray(ws, np.float32)

    def compute(self, emit_flat, emit_amp):
        self._field.fill(0.0)                          # ① 清零：禁止驻留
        src = np.zeros_like(self._field)
        np.add.at(src, emit_flat, emit_amp)            # ② scatter：仅发射者参与
        f = self._field
        for k, (dr, dc) in enumerate(self.offsets):    # ③ 固定顺序 ⇒ 确定性
            f += self.weights[k] * np.roll(np.roll(src, dr, 0), dc, 1)
        np.minimum(f, 1.0, out=f)                      # ④ 饱和
        return f
```
> 生产实现把 `np.add.at` 换成 `np.bincount`（更快），或整体下沉 Rust。
> 极点行（`row=0 / row=59`）需要用既有 `_pole_map` 修正 `np.roll(axis=1)` 的错位。

# 引擎内：听到概率（⚠️ 必须用 counter-based RNG，勿用全局 np.random）

## 五、一句话总结

- **「共享收益」** = 把发送者的适合度接到"接收者做对"上（`u_S = ρ·u_R`）；**它是"信号"的定义要件，不是附加奖励**；与 C3 的区别是"即时共享结果" vs "跨回合被挑中"。
- **信号不需要被赋予指代**：先有接收者的解读（cue→signal 的仪式化），后有发送者的利用；指称可从外部**测量**为 `P(状态|信号)` 与 `P(动作|信号)`；**"任意编码"是必需的，不是缺陷**。要修的只有一处：**别把指称接在自己的能量档上**。
- **广播可行、性能可忽略（+1.5%~4%）**，但**必须先做共享收益、必须先把它预注册为新条件 C6**；否则只会加速 g15 灭绝，并重复"机制被静默改变"的事故。

# 六、追加（2026-09-13 00:31）—— 冲突 1 的缓解方案 · 「16 通道」成本 · ★ 一个比性能更严重的问题

> 本轮由所有者追问触发：① 用"敏感性拉满也只有 25% 听到概率 + 递减 + 需连发"来缓解冲突 1；
> ② 大量生物同时发声会让全图遍布声音；不同模式（频率）不能相互覆盖 ⇒ 是否要按 16 个模式各存一个场？那样性能消耗大吗？

## 6.1 关于你的缓解方案（p ≤ 25% + 递减 + 需连发）

**判断：它降低了扰动幅度，但没有移除通道 ⇒ 它仍然是一个新条件。**

| 项 | 结论 |
|----|------|
| 是否解决了冲突 1 | **没有**。信息仍然越过 `perception_radius=4` 的边界 —— 边界被"概率化"了，但没被取消 |
| 是否让冲突 1 变得**可辩护** | **是**。因为可以给出扰动上界（见下），所以它是一个**有界的**新条件，而不是"偷偷换了机制" |
| 正确的处置 | **不要声称"C1 未改"**。把 `{broadcast OFF}` 臂明确标为 **C1 臂**，`{broadcast ON}` 臂标为 **C6 臂**，两臂都跑、报告差值。这样 C1 的原语义**仍然可测**，C6 的新增效应也**可分离**。 |

### 信息量上界（这条可以用来论证"扰动有界"，建议写进预注册）

把"没听到"视为**擦除**（erasure），擦除信道容量为 `C = p · log₂|M|`：

```
p = 0.25，实际在用模式 |M| = 4（F-M3 实测：16 模式只用 4 个）
⇒ 单次发射最多传递 0.25 × 2 = 0.5 bit
⇒ 连发 k 次最多 0.5k bit（且有上限，因为模式空间只有 4 个）
```

对比：个体自身 4 格视野每 tick 可提供的信息量远高于此。
⇒ **广播是一条"低带宽、有界"的附加信道，不是对局部感知的替换。** 这是把 C1 改动**量化**而不是回避。

### ⚠️ 你的原话里有一处语义冲突，必须二选一钉死

"**最大可以听到的概率……是 25%**" 与 "**比如 5 格 100%**" 不能同时成立。给两档参数化，选一档写进预注册：

```
p(r) = 1.0                                    r ≤ r_lo            （保证半径）
     = clip(1 − (r − r_lo)·Δ, 0, p_cap)       r_lo < r ≤ R_max    （衰减段）
     = 0                                      r > R_max           （硬截断）

甲（算术递减）  r_lo=5, Δ=0.25, p_cap=1.0
   p: 5→1.00, 6→0.75, 7→0.50, 8→0.25, 9→0     ⇒ 有效射程 8 格

乙（远场恒 25%） r_lo=2, Δ=0.25, p_cap=0.25
   p: 2→1.00, 3..R_max→0.25                   ⇒ 远场恒定弱可闻，必须连发
```

### "必须连发"是一个**新成本轴**，也是好特性（但要预注册）

`p < 1` 使"重复发射"成为**可靠性来源**：连发 `k` 次被听到的概率为 `1 − (1−p)^k`。

| 单次听到概率 p | 达 90% 检测所需连发次数 k |
|---|---|
| 0.75 | 2 |
| 0.50 | 4 |
| **0.25** | **8** |
| 0.10 | 22 |

**含义**：
- 成本从"半径 × 一次"变成"**半径 × 连发次数**" ⇒ 成本空间二维化，`R*` 的解析解（§3.5）要一并带上 `k`（净收益里乘 `1−(1−p(r))^k`）⇒ 会有一个最优的 **(R, k) 组合**，比单参数更有意思；
- 出现"**静默但存在**"这个策略（不发更省，赌别人发）⇒ 这是典型的公共品搭便车问题，**会被选择压检验**，属于好现象；
- 真实生物信号普遍用**重复/冗余对抗噪声**，所以这一条在机制上是对的。

## 6.2 「16 通道」成本核算（回答"性能消耗不大吗"）

### 内存：完全不是问题

| 规模 | 单场 | 16 通道稠密场 |
|------|------|--------------|
| C = 7,200（60×120，当前） | 28.8 KB | **460 KB** |
| C = 72,000（约 200×360） | 288 KB | **4.6 MB** |

### 计算：这才是问题，先给公式

```
cost(每 tick) = |在用通道数| × K × C            K = 半径 R 内格点数（仅取决于 R 与度量）
```

| 方案 | 每 tick 元素运算量（C=7,200） | NumPy 估算 | Rust 单线程 |
|------|------------------------------|-----------|------------|
| 单标量场（1 通道） | K·C = 1.42 M | 3–10 ms | < 0.5 ms |
| **16 通道稠密场** | 16·K·C = 22.7 M | **30–200 ms** | 5–20 ms |
| 16 通道 + 可分离 `grid_L∞` | 16·2·C·17 = 3.9 M | 10–30 ms | ~2 ms |
| 只建**在用**通道（实测 4/16） | 4·K·C = 5.7 M | 10–40 ms | ~2 ms |
| 在用 4 通道 + 可分离 | 4·2·C·17 = 0.98 M | 3–10 ms | < 1 ms |
| （C=72,000 时，16 通道稠密） | 227 M | 不可行 | ~0.2 s/tick ⇒ 60k tick ≈ 3.3 h |
| （C=72,000 时，4 通道 + 可分离） | 9.8 M | 30–100 ms | ~10 ms ⇒ 60k tick ≈ 10 min |

**结论**：
- **NumPy 下"16 通道稠密场"会吃掉你整个 tick 预算**（你现在是 234 ms/tick）——你的担心是对的；
- **Rust + 可分离度量 + 只建在用通道**之后，成本降到可接受（60k tick 分钟级）。这又一次说明 §4.1「整 tick 下沉 Rust」是前置条件；
- **世界面积是最强的成本放大器**（线性）：C 从 7,200 增到 72,000 就是 10× 成本。⇒ **广播实验不要在大世界上做**（见 6.3）。

### 四条必须用的优化

1. **一次散射解决所有通道**：`np.bincount(pattern_of_emitter * C + cell_of_emitter, weights=amp, minlength=16*C)` —— 一个调用同时完成"分模式 + 分格"的累加，避免 16 次循环。
2. **一个 `(16, C)` 数组上做 K 次 roll**，而不是 `K×16` 次独立 roll —— element 量相同，但 NumPy/PyO3 调用开销从 `16K` 降到 `K`，这是 NumPy 下 5–10× 的实测差距。
3. **优先用可分离度量**：`grid_L∞`（方形）把 `K·C` 换成 `2·C·(2R+1)`（R=8 时 1.42M → 0.24M，**5.8×**）；只有最终确认批才用 `grid_L2` 圆盘。
4. **只 materialize 在用通道**（实测你只用 4/16 ⇒ 4× 节省）。通道集合 `active = unique(pattern of emitters)` 每 tick 重算，成本 O(N)。

> ❌ **不要用 4 个 bit-plane 代替 16 通道**：那样只能得到"每一位的多数"，得不到"每个模式的强度"，
> 而"谁是赢家"恰恰是信道承载的信息（见 6.3）。

## 6.3 ★★ 真正严重的问题：接收者怎么读一个**拥挤**的信道

### 我上一份建议在这里有个错误，主动更正

§3.6 我写过"叠加规则 = `min(Σ, 1)`（多发射者更响，chorus 效应）"。
**在稠密种群下这条建议是错的**：若全场都饱和到 1.0，则"声音强度"这个量**不再携带任何信息**。
**本条作废**，替换为下面 6.3 的方案。

### 定量：全图变亮是**密度**决定的，不是半径决定的

一个格点被至少一个发射者覆盖的概率：

```
P_cover = 1 − (1 − πR²/C)^N          C = 7,200
```

| R | K ≈ πR² | N=25 | N=50 | N=100 | N=200 | N=500 | N=5000 |
|---|---------|------|------|-------|-------|-------|--------|
| 2 | 13 | 4% | 8% | 16% | 29% | 58% | ~100% |
| 4 | 50 | 16% | 29% | 50% | 75% | 97% | 100% |
| 8 | 201 | **50%** | 75% | 94% | **99.6%** | 100% | 100% |

**读法**：
- **R=8、N=200 时已覆盖 99.6% 的格点** ⇒ 你的担心成立，而且门槛很低；
- 但注意 **R=2、N=500 也覆盖 58%**。⇒ **决定因素是密度 `N/C`，不是 R。**

而你们的种群常态是**顶到承载上限 5000**（世界 7,200 格 ⇒ **密度 69%**，R19 实测 8/10 臂在 tick 5000 即达 N≈5000）。
⇒ **在满员球面上，"有没有声音"这个量完全没有信息**。

### 正确做法：按模式分通道 + 接收者从通道分布中抽样（鸡尾酒会模型）

```
loudness[p, c]  =  第 p 个模式在格 c 的强度（p = 1..16，每 tick 重算）
w_p             =  loudness[p, pos] / Σ_p loudness[:, pos]        # 通道竞争权重
p_detect        =  clamp(κ · s · Σ_p loudness[:, pos], 0, 1)      # 是否听到任何东西
m               ~  Categorical(w)   （当 p_detect 命中时；counter RNG）
```

**语义**：**模式之间是竞争关系（谁最响听谁），不是相加关系。**
- 与你的直觉完全一致（"不同模式不能相互覆盖"）；
- **不会全局饱和**（归一化而非求和）；
- 生态上等价于"**听到最近/最响的那个**"，这是自然的；
- 成本 **O(16)/接收者**，确定性（counter RNG），可并行。

**推论（重要）**：广播信道承载的是"**谁的信号最强**"，**不是"有没有信号"**。
⇒ 因此实验必须报告两个新的可观测量：
- `occupancy` = 有信号格点占比（信道拥挤度）
- `mean_channels_heard` = 平均每格同时可闻的模式数（信道竞争度）

## 6.4 落到你们的路线：广播实验**必须在 Tier 1 做**

| 结论 | 依据 |
|------|------|
| **不要把广播实验放在满员球面上做** | N/C = 69% ⇒ 信道退化为"全图有信号"，`occupancy ≈ 1`，无信息 |
| **放到 mini-world，并把密度当作显式协变量** | N=100 / C=900 ⇒ 密度 11%，此时 R 才是有效自变量 |
| 报告 `occupancy` 与 `mean_channels_heard` | 否则无法判断信道是否已经饱和（这是**静默失效**的典型形态） |
| 预注册 `(R, k)` 二维最优的预期位置 | 成本二维化后，`R*` 需带上连发次数重新求；观测到的稳态若顶到 `R_max` 或 `k_max` 即说明收益仍过强 |

> ⚠️ **最后一条风险提示**：把广播放进满员大世界，最可能的结果不是"性能爆炸"，
> 而是**性能还行、但信道静默失效**（occupancy≈1、每格可闻模式数≈16、`w` 变成均匀分布）。
> 这正好是你们账本里最危险的那类缺陷——**不报错，但产出假结论**。
> 因此 §3.8 的"驻留检测"要再加两条断言：**`occupancy` 不得恒为 1；`w` 不得恒为均匀分布**。
