# 演化生物学参照 — 世界底层规则设计参考

> **定位**：本材料是鱼提出、交团队讨论评估的参考资料，**不是决定**。若 PI 最终选择重构世界，可在设计底层规则时参照本文的演化生物学原理与映射建议。
>
> **核心原则**：只规定底层（物理/化学/演化层面的简单通用规则），不规定宏观现象（果实、森林、捕食、物种、语言）。宏观现象应从底层规则的相互作用与演化中涌现。

## 一、六条核心演化原理（底层规则的设计依据）

1. **能量/物质守恒与流动**：能量唯一入口是太阳（随昼夜/纬度变化），物质守恒只转换形态，食物链每级传递有损耗（热力学第二定律）。
2. **可遗传变异**：基因变异产生新特征，是演化的原料。
3. **差异化生存与繁殖（自然选择）**：不同特征的个体留下后代数量不同，有利特征频率上升。
4. **生态位分化**：不同策略利用不同资源，减少竞争，是形态/物种分化的基础。
5. **协同演化**：物种间相互作用（捕食-猎物、寄生-宿主、互利）驱动双方演化，形成军备竞赛或稳定共生。
6. **生殖隔离**：基因流中断+差异化选择+足够世代→生殖隔离→新物种形成（生物学物种概念的判据）。

## 二、主题一：捕食关系与"先天恐惧"如何刻进基因

### 2.1 自然界的真实机制

关键认知：**基因刻进去的不是"知识"，而是"对特定刺激的反应倾向"。**

老鼠天生怕猫，不是基因里写了"猫是天敌"，而是基因编码了一条神经通路：对猫尿中特定化学物质（Mups 蛋白）的嗅觉受体 → 触发杏仁核恐惧反应 → 逃跑。这个通路的基因变异在选择中被保留——不怕猫的老鼠更容易被吃掉，留下的后代少。

演化逻辑：
1. 世界里先有了捕食者（选择压力存在）。
2. 种群中随机出现"对捕食者相关刺激产生逃避反应"的变异。
3. 有这个变异的个体存活率高、后代多。
4. 该变异在基因池中频率上升，最终成为种群普遍特征。
5. 捕食者和猎物双方互相驱动（军备竞赛），关系稳定。

**没有捕食者，"害怕天敌"这个基因就没有选择意义，会随机漂变消失。选择压力是前提。**

### 2.2 对我们世界的映射

**可作为底层规则写入：**
- 通用感知通道：生物能感知形状、运动、气味、声音等物理特征。
- 感知-反应的通用基因机制：对每类刺激有基因控制的反应权重（接近/逃避/攻击/无反应）。基因编码"对 X 刺激的反应倾向"，不编码"X 是天敌"。
- 攻击/防御作为可演化基因：每个生物有攻击能力和防御能力参数。

**必须留给涌现：**
- "世界上有捕食者和猎物"的分类。
- "老鼠怕猫"这种具体知识。
- 具体的捕食关系。

**落地顺序**：先有通用能量获取+攻击防御（捕食可能涌现），再有感知-反应基因（恐惧可能演化）。顺序不能反。

## 三、主题二：物种形成与生态位分化

### 3.1 自然界的真实机制

物种形成（speciation）需要三个条件：
1. **基因流中断或减弱**：地理隔离（山脉/河流/沙漠）、生态隔离（利用不同资源）、时间隔离（繁殖期不同）。
2. **差异化选择压力**：两个亚种群所处环境/生态位不同，自然选择方向不同。
3. **足够世代让差异积累，最终产生生殖隔离**（再相遇也不能产生可育后代）——这是生物学"物种"的判据。

经典案例：达尔文雀——同一群岛，不同岛的食物不同，雀的喙形在选择中分化，最终成为不同物种。

### 3.2 我们世界为什么没有物种分化

- **无性繁殖**：没有交配，也就没有"生殖隔离"概念，严格说不存在生物学意义上的"物种"。
- 所有生物共享一个基因池，基因通过繁殖直接传递。
- 世界连通、均匀，没有地理隔离。
- 没有稳定的生态位分化（大家吃同样的食物、用同样的策略）。

在无性繁殖下，更准确的说法是"**策略簇/形态簇**"——不同策略的稳定共存，而不是生物学物种。

### 3.3 对我们世界的映射

**可作为底层规则写入：**
- 空间异质性：地形/资源分布不均，为分化提供条件。
- 通用能量获取规则：不同策略（吃植物/吃肉、移动多/少、昼/夜）在选择中分化。
- （远期）有性繁殖+交配偏好基因：为真正的物种形成提供前提。

**必须留给涌现：**
- 具体的物种分类。
- 具体的生态位划分。

## 四、主题三：有性/无性繁殖的起源与分化

### 4.1 有性繁殖的起源

最早的生命都是无性繁殖（二分裂）。有性繁殖不是"为了繁殖"被发明的，很可能是**借用**（exaptation）来的：

**起源路径：环境压力下的细胞融合 + DNA 修复**
- 单细胞生物在饥饿/DNA 损伤时，两个细胞融合成一个二倍体细胞。
- 融合后可以用对方的完整 DNA 做同源重组修复。
- 环境改善后，通过减数分裂回到单倍体。
- 酵母至今保留这个模式：饥饿时单倍体融合成二倍体，条件好时减数分裂产孢子。

这个"融合→修复→减数分裂"循环最初是为了**生存和 DNA 修复**，不是为了繁殖。后来被借用为繁殖方式，附带产生了基因重组的好处。

### 4.2 有性繁殖的双重代价

1. **雄性代价**：无性繁殖每个个体都能直接产后代；有性繁殖只有一半（雌性）直接产，种群增长速率理论上减半。
2. **基因打破代价**：重组会打破已经适应环境的基因组合。

### 4.3 有性繁殖的收益（为什么被保留）

1. **红皇后假说（最受支持）**：生物和病原体/寄生虫在军备竞赛。有性繁殖产生基因多样的后代，其中一些可能对新病原抗性；无性后代基因相同，病原一旦适应就可能全灭。"你必须不断奔跑才能留在原地。"
2. **缪勒棘轮**：无性繁殖中有害突变不可逆地积累（没有重组无法清除），长期走向灭绝；有性繁殖通过重组能产生无有害突变的后代。
3. **加速适应（Fisher-Muller）**：有性繁殖能把不同个体身上的有利突变组合到同一个后代；无性中有利突变只能各自独立积累。
4. **DNA 修复**：减数分裂重组修复损伤——这可能是最初的功能。

### 4.4 无性/有性的共存与分化

自然界不是非此即彼：
- **兼性有性**：平时无性快速扩张，环境压力时切换有性产生多样后代。蚜虫（夏天孤雌、秋天有性产卵越冬）、水蚤、酵母都是。这是"环境好时克隆自己，环境差时买彩票"的最优策略。
- **专性无性**：完全放弃有性，如某些全雌性蜥蜴、很多植物块茎繁殖。通常是从有性祖先次生丢失的，物种往往较年轻——长期无性会因缪勒棘轮和红皇后走向灭绝（"无性是演化死胡同"，例外如蛭形轮虫已无性 8000 万年）。
- **专性有性**：如哺乳动物、鸟类。

### 4.5 分化的驱动条件

- 环境稳定 → 无性有利（已适应的基因组合不被打破，繁殖快）。
- 环境变化/病原压力大 → 有性有利（基因多样性应对变化）。
- 种群小、遗传多样性低 → 有性重组收益更大。
- 有害突变率高 → 有性的清除作用更重要。

核心：**没有绝对最优的繁殖方式，只有最适合当前环境的方式。** 兼性策略之所以常见，就是因为它能按环境切换。

### 4.6 对我们世界的映射

**可作为底层规则写入（重构后期）：**
- 不规定"必须有性"，让繁殖方式可演化：设一个基因控制有性繁殖倾向（0=纯无性，1=纯有性，中间=兼性，按环境/内部状态切换）。
- 有性繁殖要带真实代价：需要找到配偶（时间/能量成本）、基因重组打破已适应组合、配子分化代价。
- 有性繁殖要带真实收益：基因重组、后代多样性、（远期）DNA 修复。
- 让演化决定：在什么环境压力下有性倾向被选择、什么环境下无性被选择、兼性是否稳定。

**一个值得观察的涌现预测**：如果繁殖方式可演化，世界会不会自发出现"环境好时无性、环境差时有性"的兼性策略？

**现实困难（要诚实）：**
- 有性繁殖需要"交配"机制（相遇、识别、基因交换）。
- 需要配子/性别分化，或者从同配生殖（两个相同配子融合，无性别）起步。
- 这是重构后期的大改动，不是第一步。
- 但它是真正物种形成（生殖隔离）的前提，也是研究"重大演化创新如何涌现"的绝佳对象。

## 五、捕食关系的演化（能量获取视角）

### 5.1 自然界的真实机制

底层是**能量获取效率**：
1. 最初不同生物只是竞争同一资源。
2. 某些个体体型大、有攻击能力，发现"直接吃掉竞争者"比"和竞争者抢食物"更高效——肉的能量密度远高于植物。
3. 攻击/防御能力在选择中分化：有的特化攻击（捕食者），有的特化防御/逃跑（猎物）。
4. 频率依赖选择维持稳定：捕食者太多→猎物减少→捕食者饿死；捕食者太少→猎物增多→捕食者有更多食物。形成 Lotka-Volterra 式振荡。

### 5.2 对我们世界的映射

**可作为底层规则写入：**
- 通用能量获取规则：生物可尝试获取任何"防御低于自身攻击能力"的实体能量。不规定"捕食"，吃植物和吃动物是同一规则的不同表现。
- 攻击/防御作为可演化基因。

**必须留给涌现：**
- 具体的捕食者-猎物关系。
- 具体的食物链结构。

## 六、底层规则 vs 宏观现象：总映射表

## 七、建议的落地顺序（若重构被采纳）

每一层都过 C7 逐位对拍，再往上盖：

1. **统一能量-物质循环**（守恒、太阳能入口、通用分解归还）
2. **通用生命内核**（能量/物质/稳态/基因/繁殖/死亡，动植物共用）
3. **植物生物化**（静态策略，森林/草原是聚集涌现）
4. **通用 item/附着系统**
5. **通用反应/分解框架**
6. **通用能量获取**（攻击/防御参数，捕食/食草/食腐同构）
7. **感知-反应通用基因机制**（先天恐惧/偏好可能演化）
8. **空间物理**（温度/水/地形，促进分化）
9. **信号物理**（能量模式，不规定意义）
10. **（远期）有性繁殖+交配偏好**（真正物种形成的前提）

## 八、诚实的困难与风险

1. **植物建模粒度是最硬的技术岔路口**：逐株实体（最真实、能自然选择，但实体数爆炸、性能压力大）vs 格级生物量（性能好，但个体选择粒度粗）。必须在动手前定。
2. **重构期会有一段时间"没有新结论、看不到宏观现象"**：涌现要在干净世界里重新长，需要耐心。
3. **涌现需要时间和空间异质性**：世界太均匀连通，分化困难。
4. **有性繁殖是大改动**：需要交配机制、配子/性别分化，是重构后期才考虑的。
5. **"通用"和"可归因"要平衡**：规则太少长不出东西，太多特殊规则又变回硬编码。
6. **性能**：植物个体和 item 数量会大增，必须向量化设计。

## 九、语言策略与验证（工程约束参考）

- 重构探索期用 Python 建内核（规则在变，迭代快、正确性优先）。
- 等规则定型、C7 锁定后，只把真正的热点下沉 Rust。
- 独立验证从"长期维护两套完整实现"降级为：golden digest 基线 + 守恒/不变量断言（Σ能量物质）+ 下沉时一次性对拍。但绝不归零——项目刚因 bug 让大量实验白跑，这个节骨眼不能放弃独立验证。
