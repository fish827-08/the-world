=== 设计效应（design effect）近似 ===
  deff ≈ 1 + (m̄-1)·ICC，m̄ = 簇内平均个体数，ICC = 簇间方差/(簇间+簇内)
  本项目未直接测 ICC（需个体级 y 的方差分解）=> 用『簇级 rho 的离散度』做上界提示：
  main    : 跨 seed rho sd=0.0769  平均 n=51291
            若将该 n 视为独立 => 名义 SE≈1/sqrt(n-3)=0.004416
            但簇级只有 3 个点 => 真实可分辨的 rho 差异分辨率 ≈ 该 sd=0.0769（差 1~2 个数量级）
  control : 跨 seed rho sd=0.0365  平均 n=48338
            若将该 n 视为独立 => 名义 SE≈1/sqrt(n-3)=0.004548
            但簇级只有 3 个点 => 真实可分辨的 rho 差异分辨率 ≈ 该 sd=0.0365（差 1~2 个数量级）
  oracle  : 跨 seed rho sd=0.0587  平均 n=65241
            若将该 n 视为独立 => 名义 SE≈1/sqrt(n-3)=0.003915
            但簇级只有 3 个点 => 真实可分辨的 rho 差异分辨率 ≈ 该 sd=0.0587（差 1~2 个数量级）

=> 结论：个体级 n≈10^4 给出的 SE 被严重低估；簇级 n=3 才是诚实分辨率。
