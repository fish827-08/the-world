## 一、🔴 BC 置换零分布口径 v1（阻塞项）

### 1.1 先给结论：**E-030 的"未分化"判读不需要 BC，现在就能定**

- 三腿配对证据已足：Δg16均值 **−0.1531**、Δg16 std **−0.1423**、Δ`pred_frac` **−0.2490**，**三项各 6/6 同向（p=0.0312）**。
- **关键逻辑（此前被漏掉）**：**分化必然抬高群体方差**（两支分开 ⇒ std 至少不降）。实测 **std 从 0.187 塌到 0.040（剩 21%）** ⇒ 这是"**无分化**"的**正面证据**，不是"缺证据"。
- ⇒ **建议：E-030 记为「未分化=单向扫荡（依据=三项配对 + 方差塌陷）」，并把 BC 记为「本批失效、不作判读依据」**——**不要**记成"双峰不可判 ⇒ 结论悬置"（那会白丢一个干净的阴性）。

### 1.2 BC 为什么必然误判（可算，不靠直觉）

`BC = (skew² + 1) / (excess_kurt + 3(n−1)²/((n−2)(n−3)))`（n≫时第三项→3）。
`[实测]` 用老工给的对照臂数字（skew=+2.56、excess kurt=+5.45、n≈1944）：`BC = 7.554/(5.45+3.003) = 0.894` ⇒ **BC 完全由 skew 项驱动**；而 `skew=0` 时 BC 上限只有 `1/(kurt+3)`。⇒ **BC 对右偏分布天然"报双峰"**，"0.555 阈值"又恰是均匀分布的值 ⇒ **单用＝误判机器**（老工冒烟已正面证实）。

### 1.3 口径 v1（三条，可直接实施）

**① 主判据换成"中间凹陷"（形状量，不受 skew 影响）**
用 10-bin `g16` 直方图，令 `mid = 中间 3 箱占比`、`ends = 两端 6 箱占比`；统计量 `D_shape = mid / (mid + ends)`（0 = 强双峰，0.5 = 均匀，→1 = 单峰居中）。
- **臂间检验（主）**：同 seed 配对 `ΔD_shape = D_shape(k=2) − D_shape(k=0)`，**符号检验 + 效应量**（n=6，双侧）；**必报 seed 级明细**。
- **零模型（判"是否比单峰更凹"）**：对每个 tick 的样本量 n，从**矩匹配单峰参照**（见 ③）抽 n 个样本 ⇒ 得 `D_shape_null` 分布 ⇒ **可检出阈** = null 的 5% 分位（预注册，不许事后调）。
- 好处：**skew 不会造成"中间凹陷"**（右偏拖尾抬高的是 BC，不是 D_shape）⇒ 直接修掉 E-030 的误判根因。

**② BC 降级为描述列，且必须报"相对零模型的差"**
若仍要报 BC，必须报 **`ΔBC = BC_obs − median(BC_null)`**（正负都报），**禁止**报裸 BC 或使用绝对阈值 0.555。
⚠️ **诚实边界（重要）**：`(n, mean, var)` 矩匹配的 null **不匹配三阶矩**。我按对照臂数字手算过：矩匹配 beta(1.53, 3.77) 的总体 BC≈**0.50**、其 n≈1944 抽样 sd≈**0.10** ⇒ 观测 0.896 仍在其 ~4σ 外 ⇒ **只用 (mean,var) 匹配仍会把右偏数据判成"双峰"**。⇒ 若要 BC 可用，null 必须**三矩匹配**（skew-normal 或经验"镜像折叠"构造），否则就按 ① 走 D_shape。

**③ 置换/零模型的"单位"必须处理时间自相关（这是最容易出错的一点）**
- **不要**把窗口内所有个体×所有 tick 的样本合并算 BC/D_shape——同个体跨 tick 重复出现 ⇒ **伪重复**，会把 n 虚增到上万、p 值假小（本项目已在 Fisher-z 上付过学费）。
- **正确做法（二选一）**：**(a) seed 级**：每 run 只出一个统计量（窗口内**逐 tick 统计量的中位数**），再用 n=6 配对检验；**(b) tick 级块置换**：块长 ≥ 自相关长度（建议 ≥ 5×；或直接按 20 tick 分块），块内保留、块间置换。
- **样本量**：报**有效样本量** = 独立个体数（不是样本点数）；预注册 `每 run 独立个体 ≥ 200`（你们已写 N≥200 ✓，但要确认是"个体数"而非"样本点"）。

**④ 下一批要加的列（零机时）**：`g16_hist0..9`（10 计数）+ `g16_n`（已有）+ 保留 mean/std/skew/kurt；同时**建议加 `g16_hist` 的时间序列**（否则只能算窗口合计，块置换做不了）。

## 二、D 线：校准批判据复核

### 2.1 净收入口径（主判据 `|净收入差|/食草 ≤ 20%`）

- ✅ **窗口/聚合**：4k–8k 窗口 + **逐 tick 统计量取中位**（禁全程平均）✓ 与 §1.3③ 同一条纪律。
- 🔴 **必须补"通道外溢检查"**（并入外鉴 §四.3）：同类相食的收益有一大块是**竞争削减**（吃掉同类 ⇒ 斑点竞争者少 ⇒ 幸存者**食草**收入升），这笔账**记在食草腿** ⇒ **通道记账系统性低估捕食策略的总适应度** ⇒ `≤20%` 可能在捕食策略**实际更优**时被判"等化成立"（**假阴性**）。
  **建议判据补一条**：`净收入(捕食腿) + Δ食草腿相对对照的增量 ≤ 20%×食草`，或至少在报告里**同时报**这两项并声明"未计入间接收益"。
- 🔴 **死因账目须锁口径**（并入外鉴 §五.2）：`w_e`（能量脆弱性）与饿死通道**互相搬运**死因 ⇒ 跨批/跨臂比 `pred_frac` 前须声明"死因口径含/不含 w_e"。
- 🟡 **三腿必须同能量口径**：`I_forage` 与 `C`（代谢/攻击成本）要说明是"摄入能量"还是"净存留"；`stomach`（胃粮）与 `energy` 两账别混。

### 2.2 方差副判据 `Var(捕食) > Var(食草)`

- ⚠️ **两侧量纲/口径不同**（两条腿的收入分布），**不能用跨腿独立 t**；必须**同 run 内配对**（逐 seed 一个 ΔVar），再做 seed 级符号/置换检验。
- ⚠️ **方差比对离群极敏感**（捕食是稀有高收益事件 ⇒ 方差被少数击杀支配）⇒ 建议改用**稳健风险量**（IQR 或 5–95 分位差）作副判据，方差作描述列。
- ⚠️ **方向与阈值须预注册**，且**先做功效预跑**（见 2.3）——"单侧不等式"在 n=6 下几乎判不动。

### 2.3 20% 阈值的功效（必须跑前算）

- 该判据是"**比值型点阈值**"（我方反复踩过：R88 中性边界、ρ v2 地板、Q1 绝对带）。**必须**用现成数据的 seed 间离散做功效预跑：给定 6–8 run，可检出的 `|Δnet|/食草` 最小值为 `t·s_d/√n ÷ 食草`。
- 若算出来可检出阈 > 20% ⇒ **20% 不可检**（要么加 run，要么把判据改成"等化方向 + CI"式）；若 ≪20% ⇒ 阈值太松，须收紧或加副判据。**这一步零机时，做完才能定 20% 是否合理。**
