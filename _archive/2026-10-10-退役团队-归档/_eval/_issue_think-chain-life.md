## 概述

您好！我克隆了本仓库并独立验证了 v3/v4/v5 的核心结果，发现 README 中的头条结论与仓库自带数据/代码存在多处不符。以下全部可复现：验证脚本用仓库自带的 `best_tribe_*.pt` 权重 + `language_analysis_v5.py` 的 `analyze()` 原样运行。

---

## 1. ★ 头条结论"v5 组合性 0.463"无法复现

README 声称："**v5 组合性 0.575 综合涌现分、组合性 0.463（epoch 135）**"。但：

| 来源 | 组合性 |
|------|--------|
| README (train期最佳, epoch 135) | 0.463 |
| 仓库自带 results_v5/final_evaluation.json（best模型确定性评估） | **0.061** |
| 独立复现（best_tribe_*.pt + 3×确定性评估） | **0.068** |
| 随机策略基线（20次均值） | 0.020 |

- 0.463 实际出现在 **epoch 10**（epoch 135 处为 0.394），README 标注的 epoch 有误。
- 该值是**训练中期单次测量**的孤立尖峰，仓库保存的最佳模型（epoch 135 所选）确定性评估只有 0.061，与随机基线（均值0.02、极端值0.34）几乎无差别。
- 尖峰极不稳定：0.463→0.056、0.423→0.051、0.450→0.139（相邻分析点内崩塌）。

**结论："组合性突破 0.45"无法从仓库任何产物复现，不能作为支撑结论的证据。**

---

## 2. "sym2→形状跨8代反复涌现"证据列表存在事实错误

README 声称 sym2 在 epoch 10/25/50/55/135/140/215/230/250/275/290 最佳对应"形状"。逐条核对 history.json 后：

- **epoch 230/275/290 的 sym2 最佳维度实际是 color，不是 shape**（例如 epoch 230: shape=0.119 < color=0.126）。
- epoch 50/55/135/140/215 处 sym2 也是 color 为优（MI 差值极小）。
- 实际 sym2=shape 的 epoch 仅 8 个（10/25/50/55/135/140/215/250），占全部61次评估的 13%，跨 6 个代（非 8 代）。
- 二项检验：若 sym2 每 epoch 在 color/shape 间随机二选一，P(≥8次shape) ≈ **1.0**，与随机无异，不能支持"稳定演化吸引子"。
- 这些"形状对应"的 MI 仅 0.08–0.18，远低于 sym2 常态（color MI 0.20–0.42）。

**结论："sym2→形状跨代反复涌现"是噪声，不是吸引子；且 README 引用的部分数据与仓库不符。**

## 3. v4 的"颜色MI 0.399"张冠李戴

README 声称 v4 达到 sym1-颜色 MI=0.399。但 results_v4/history.json 中全部位置-语义 MI 最大仅 **0.012**（v4 代码的 `language_analysis_v4.py` 训练期统计）。0.399 实际是 **v5 epoch 100** 的数据（results_v5/history.json），被误标为 v4。

---

## 4. 训练期测量与最终评估口径混用

同一模型在"训练中期单次随机测量"和"最终确定性3-epoch评估"下分数差异巨大：

- v3：训练期组合性 0.004–0.064 vs 最终评估 0.584–0.705（我复现 0.584，与 README 0.705 不符）
- v4：训练期 0.003–0.016 vs 最终评估 0.183（我复现 0.418）
- v5：训练期 0.05–0.46 vs 最终评估 0.061

README 的核心结论（"0.183→0.463 提升 153%"）正是混用两个口径得出的：v4 的 0.183 是最终确定性评估，v5 的 0.463 是训练中期单次测量。**同一口径下 v5(0.061) 反而低于 v4(0.183)**，"显式指称博弈提升组合性"不成立。

---

## 5. 指标代码缺陷：food_type 维度恒为 0

`language_analysis_v5.py` 中上下文标签为 `type_large/type_small`（environment_v5.py: `f'type_{...}'`），而指标过滤用 `food_type_*` 前缀，导致该维度 NMI 恒为 0。README 宣称的"3个语义维度"实际只有 2 个有效，组合性公式（0.5×多样性+0.5×MI强度）的分母失真，加剧了分数抖动。

---

## 6. 建议

1. 存档 epoch 10（组合性0.463）的模型权重，若能在多次确定性评估中稳定复现 >0.4，结论才可成立。
2. 统一采用"最终模型确定性评估"为唯一报告口径。
3. 修正 v4/v5 指标数字（当前 README 与仓库数据不符）。
4. 修复 food_type 标签命名。
5. 报告随机策略基线值，以证明指标有判别力。
