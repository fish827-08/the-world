## 二、🔴 **新发现：两个生态区制混淆了 g15 解读**（评审未识别）

### 2.1 数据（`[实测]`，逐 run 重算）

| 臂 | N_end | born | **max_gen** | **捕食占死因** | g15_end | **区制** |
|----|-------|------|------------|--------------|---------|---------|
| cb1_s42 | 5000 | 69043 | **10** | 67.8% | **0.771** | 饱和（封顶） |
| cb1_s43 | 5000 | 45648 | **7** | 49.9% | **0.660** | 饱和（封顶） |
| cb1_s45 | 5000 | 33884 | **9** | 40.4% | **0.803** | 饱和（封顶） |
| cb1_s46 | 4999 | 36353 | **7** | 24.6% | 0.171 | 饱和（封顶） |
| cb1_s44 | 497 | **145598** | **143** | **99.8%** | **0.044** | 捕食主导（崩溃尾） |
| cb0_s44 | 334 | **135824** | **141** | **99.8%** | 0.025 | 捕食主导（崩溃尾） |

### 2.2 这个模式说明什么

**① g15 高的三个 run（s42/s43/s45，终局 0.66–0.80）全部是"饱和封顶"区制，且 `max_gen` 仅 7–10 代。**
**② g15 最低的两个 run（s44，终局 0.04/0.02）反而是"捕食主导"区制，`max_gen` 高达 141–143 代。**

⇒ **g15 上升出现在"几乎没在演化"的 run 里；而在选择最强（出生 13–14 万、141+ 代）的 run 里，g15 掉到近 0。**

**这不是"适应性演化"该有的形状。** 两个可能解释，都与"信号有用"相悖：

- **解释 A（漂变 / 无有效选择）**：`max_gen` 7–10 代 ⇒ **样本量太小**，g15 的上升完全可能是漂变。而饱和意味着**繁殖受硬顶配给**（本项目已知：满员时按数组下标配给），**选择压在繁殖环节被结构性削弱**。
- **解释 B（信号无信息价值）**：在 N=5000 的饱和格（63% 密度）上，邻居信号恒被点亮（`[代码]` `:774` 在感知半径内读信号），**发射对所有接收者都是冗余的** ⇒ g15 不承载功能价值，其上升无功能含义。

### 2.3 对"臂间分离"的后果

评审 §三 写：

> "这是项目第一次出现「臂间分离」：4 机制臂 3/5 出现持续高发射倾向，3 机制臂 0/4 出现。"

`[实测]` 但按区制分层后：**cb1 的 3 个高 g15 run 全部落在饱和区制**，而 cb0 的 4 个 run 中：
- cb0_s44 是捕食主导（99.8%）——**与 cb1_s44 同区制**，二者 g15 都低（0.025 vs 0.044）
- cb0_s42 终局 N=4998（饱和区制）——**g15 仅 0.217**，是该区制里最低的

⇒ **"4 机制 vs 3 机制"的分离，与"饱和 vs 捕食主导"的分离，在现有数据上不可区分。**
**臂间分离的方向仍在（cb1 有 3 个高值、cb0 一个都没有），但归因给"码本"目前证据不足——它同样可以归因给"落入哪个生态区制"。**

### 2.4 🔴 一个更根本的方法论问题：g15 是什么

`[代码]` `simulation/sphere_engine.py:590-612`：

```python
signal_gene = genes[:, Gene.SIGNAL_STRENGTH].copy()
rand_emit = self.rng.random(P)
emitters = np.flatnonzero(rand_emit < signal_gene)   # ← g15 = 每 tick 发射概率
```

⇒ **g15 是"发射意愿"的基因，不是"信息量"。** 它的上升只说明"更爱发信号"，**与信号是否携带信息无关**——这一点评审 §二 已正确指出（列为问题 1）。**但在饱和区制下，连"更爱发"本身都不承载功能含义**（解释 B）。
