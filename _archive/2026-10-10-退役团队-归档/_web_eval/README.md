## 三、工作方式

1. 每次检查从 `FACTS.md` 看已确认事实，避免重复检索
2. 检索词记录在核查单里，保证可复现
3. 结论带 `[文献]/[网络]/[推断]/[待核]` 标签
4. 与 `_eval/` 的 Gate 判定相互引用但不越界
