## 三、检索与恢复

- **按名找**：`grep -r "<关键词>" _archive/`；或全仓 `git log --all --oneline -- "<路径>"`。
- **看历史**：`git log --follow "<新路径>"` 一路追到原位置。
- **恢复文件**：`git mv _archive/<批次>/<文件> <目标位置>`（历史完整，零损耗）；取旧版内容可 `git show <旧commit>:<旧路径>`。
- **再归档**：`git mv` 进 `_archive/<日期>-<批次>/` → `归档记录.md` 登记 → 本页更新。

## 四、纪律

1. **只移动、不删除**（F-R10）：归档 = `git mv`；物理删除仅限纯运行时垃圾（锁/缓存）。
2. **每批必登记**：`归档记录.md` 一行一事（原位置/去向/原因）；大批次在批次目录内留 `README.md` 清单。
3. **活动区引用去向要能对**：搬迁批结束跑 `tools/ref_check.py` 对表（迁移前快照 vs 迁移后），新增断链归零；历史引用面（冻结件/叙事件）以排除清单记录、不回头改。
