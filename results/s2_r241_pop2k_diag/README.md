# R241 pop=2000（降投放数）+ 门B 专项诊断

用户指令：「能不能降低初始投放数再试试，还有B门也测一下」

## 文件
- `gateb.py` —— 门B（L1 探索度）三口径专项判读脚本
- `dispersal_probe.txt` —— 个体是否离开出生斑块的诊断输出
- `barrier_probe.txt` —— 零食物沙漠屏障假说的验证输出
- `placement_probe.txt` —— 初始投放的空间分布

## 结论摘要
1. pop=2000 批次：L0 确证轮休；L1/L2 仍不显形（各 0/3）；主门不通过。
2. 降 pop **并未**让门B显形，反而覆盖率更低（13–16% vs pop=20000 的 77–83%）。
3. 根因（新发现）：**零食物沙漠不可穿越** —— 个体 97–100% 时间待在斑块格，
   而斑块格仅占全球 2.78%。访问集 = 出生斑块集，2000 tick 内固化，之后永不扩张。
   ⇒ 跨界探索在几何上不可能 ⇒ rd 无法在探索维度产生差异 ⇒ 门B结构性不可能通过。
