## 4. R-6：CONS-MASS 的归因（只给读数与归因，**不改阈值**）

**结论：不是 float32/ln(ps) 量化；是"预报量取 ln(ps)、判据测 ps 线性全球均值"的结构效应。**

| 量（覆盖域，Δsinφ 权） | f32 (run1) | f64 |
|---|---|---|
| 漂移 max（@day 100） | **4.1279e-5** | **4.4396e-5** |
| 漂移 期末 | 1.9338e-5 | 1.8178e-5 |
| Δ⟨ln ps⟩ 期末 | +7.2657e-6 | +6.7151e-6 |
| var(ln ps) 首 → 末 | 5.4035e-5 → 7.8397e-5 | 5.4037e-5 → 7.7218e-5 |
| ½Δvar | +1.2181e-5 | +1.1591e-5 |
| **闭合** Δ⟨ln ps⟩+½Δvar vs 末端漂移 | 1.9447e-5 vs 1.9338e-5（**0.6%**） | 1.8306e-5 vs 1.8178e-5（0.7%） |

- **量化不可能是主因**：float32 存 ln(ps) 的每个值相对误差 ≤ ~7e-7，且快照间不累积；
  实测漂移 4.1e-5 比它大 ~60×，且 f64 同为 4.4e-5。
- **机制**：模式预报量是 ln(ps)，⟨ps⟩=⟨exp(ln ps)⟩ 会随 ln ps 的均值漂移与方差增长而升高；
  半方差项 +1.2e-5、均值项 +7e-6，两项即解释覆盖域读数。此机制与 NF 无关 ⇒ Float64 不改善。
- **覆盖域不确定性**：把极帽按最外环值补齐（代理）后漂移 max 为 **1.2840e-5（f32）/1.5141e-5（f64）**，
  仍 >1e-6。全空间是否严格守恒**无法由导出场判定**（极帽 0.126% 无数据）。
- **待裁（R-6）**：阈值 1e-6 是否预设"线性 ps 预报量/带质量修正器"；是否新增半方差登记项。
  AV **不自行改阈值**。无论 owner 如何裁，**在现行冻结阈值下本条为 FAIL**。
