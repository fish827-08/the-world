## 6. Option 3 质量口径执行（rev1.1 §11.2）

预注册只规定"质量归一化 + E-MASS 偏置登记"，未逐字给公式。AV 采用**字面全球均匀质量修正**并在本件写死口径以便复核：

```
W_norm(t) = W(t) · mean_ps(0) / mean_ps(t)
```

读数：

| 口径 | `CONS-WATER` 相对值 | 阈值 | 结论 |
|---|---:|---:|---|
| 原始（冻结判据） | **1.0796610734062958e-3** | ≤1e-3 | FAIL |
| Option 3 归一化 | **1.0771052495871015e-3** | ≤1e-3 | 仍 FAIL |
| 参考：W/days 错切到 `[1:]`（**非判据**，仅证明窗口非空转） | 1.0666845431669691e-3 | ≤1e-3 | 仍 FAIL |

水账明细（原始）：`P = 3.9841439671115705e-05 kg m⁻² s⁻¹`、`E = 3.9871178018708876e-05`、`dW/dt = +7.275359911453363e-08`、`residual = E − P − dW/dt = −4.301525152136219e-08`、`W: 31.253756483982066 → 31.81948847069668 kg/m²`。归一化后 `residual = −4.291342382086653e-08`、`dW/dt = 7.265177141403797e-08`。

**结论**：E−P 与 dW/dt 同号且量级相近，残差是 P 的 ~1.08e-3；质量归一化只改变 ~0.24%，**不能把 CONS-WATER 拉回 ≤1e-3**。按 rev2 §二，"CONS-WATER 仍能力；Track A 后若门跑仍 >1e-3 ⇒ J2 FAIL，不降级、不调阈值"——本件照此判 **FAIL**。
