### 1.2 为什么季节关（先于数据写定）

- 世界 `season_period=1200 tick` 在 36 s/tick 下是 **12 小时一年**；甲以 `follow_world_season=True`
  跟随世界会得到 12 小时「年」，产生昼夜/年循环混叠。
- 世界默认无季节（`tilt=0`、`season_period=0`）⇒ A3.1 §1.3 的 `year_s` 回退到
  `year_ticks × tick_seconds = 2400×365×36 = 31,536,000 s = 365 d`，倾角为 0。
- 因此 J3 **明确 scope-out 季节耦合**；不声称「季节响应」。世界与甲都无季节，二者一致。

   J3 很可能以 **INCONCLUSIVE-E** 收场。这是允许结局，但 owner 须在放行前知悉：
   **32–38 h 的批次可能只换来一个「未判读」**。
2. **成本**：20 run CPU 总时 ≈32–38 h、K=4 墙钟 ≈8–10 h；**>48 h 停批报 owner**（§2.1），不得静默缩 tick；并行仅按 §2.3 执行。

### 2.3 执行调度（rev3，先于数据写死）

| 项 | 值 |
|---|---|
| 并行度 K | **4**（owner 2026-10-24「本机可以适当并行」；本机 20 核） |
| 批次 | **5 批 × 每批 4 run**：同一 seed 的 `{ONα, ONβ, OFFα, OFFβ}` 同批并发（s=42…46） |
| 主机 | **仅本机单机**；禁止跨机混跑（E-042 已证跨机非逐位） |
| 进程隔离 | 每 run 独立进程、独立输出目录、独立临时目录；不共享对象/缓存/socket |
| 线程 | `OMP_NUM_THREADS=1`、`OPENBLAS_NUM_THREADS=1`、`MKL_NUM_THREADS=1`、`NUMEXPR_NUM_THREADS=1`、`JULIA_NUM_THREADS=1`；BLAS/FFTW 各 1 线程 |
| 内存门 | 用 P0-11 实测 ON/OFF 单 run 峰值 RSS；若 `2×RSS_ON + 2×RSS_OFF > 0.6×开工时可用物理内存` ⇒ **K 降为 2**（每批 1 ON + 1 OFF），报告记录；**只许降不许升** |
| D1 检查 | 每批完成后立即核 α/β 逐位（§5.2）；任一 `(seed,臂)` 不一致 ⇒ 按 D FAIL 停手，**剩余批次不启动**；不得换 seed/重跑规避 |
| C0 | 2 遍独立；可在 P0-11 之后与第 1 批并行；C0 与在线 run 必须同 IC、同 120 天自旋、同 `dt_step=576` |
| 失败处理 | 任一 run 因基础设施（OOM/进程被杀/缺 manifest）失败 ⇒ **整批作废重跑**（同参数、同主机），记录原因；**不得**挑成功 run 进入判读 |
| 审计 | 每 run manifest 记录 K、批次、环境变量、峰值 RSS、wall、核版本；批报告记录 CPU 总时与墙钟 |

> **为什么敢并行**：D1 的逐位一致性是算法与 RNG 消费顺序的函数，不依赖墙钟；只要每进程单线程、
> 独立构造、无共享状态，结果应与串行同。**若 D1 在并行批次失败且归因于调度/共享状态，停手报 owner；
> 是否改回串行由 owner 裁（需 rev4），不得自行改装置。**

## 四、偏差带定义（引用附件 A，不重算）

### 4.1 六项登记偏差与 J3 用法

| ID | 登记读数（附件 A §二） | J3 中的强制处理 | 表述上限 |
|---|---|---|---|
| **B-TOA** | **+7.016983 W/m²**（rev2 门后 50%） | C-ENERGY 报原始净 TOA + 扣除 B-TOA 后的残差；残差阈值见 §5.3 | 不得写「能量平衡达成」；只写「扣除登记偏差后的残差」 |
| **B-WATER** | **1.079661e-3**（post-clip q 口径）；真闭合 **3.28e-6** | 水账**两列并列**：`C1-gate`（含裁负）/`C1-true`（D1 分解残差 proxy）；不得只取前者判优劣 | 不得写「水守恒通过」；只写「登记偏差扣除后」 |
| **B-MASS** | **3.3834e-5 / 120 天** | 延续 Option 3：质量归一化 + 已知偏置登记；J3 窗阈值见 §5.3（**非线性、按 20 天子窗标定**，不做线性外推） | 不得写「质量守恒通过」 |
| **B-ITCZ** | 双 ITCZ；argmax **−13.2314°** | 降水带位置只作协变量记录；**不得**作 J3 单侧结论 | **禁用「单 ITCZ」** |
| **B-POLAR** | **−0.15075 m/s/day** | 极区结论单独 scope；J3 极区只记录不判 | 不得写「极区债已清」 |
| **B-RES** | T32/L8（3,168 点 / 48 环 / 无极点，±87.16°） | 不外推到完整天气/中尺度；只作展望 | 不得写分辨率无关结论 |

### 4.2 判定带 `B_J3`（耦合增量的偏差带）

附件 A 要求「`|增量| < 偏差带 ⇒ INCONCLUSIVE`」。J3 把该带**先于数据**操作化为：

```text
B_J3 = max( 2 × SE(Δ_s),  0.05 × median(N_end | OFF, α, s=42…46) )
SE(Δ_s) = sd(Δ_s, ddof=1) / sqrt(5)
Δ_s = N_end(ON, s, α) − N_end(OFF, s, α)
```

- `2×SE`：5 seed 配对均值的 **2×SE 带**（t₄ 下覆盖约 88%，**探索性**；**不宣称 95%**）。
- `0.05×median(N_end|OFF)`：**偏差地板**（OFF 臂 α 遍、5 seed 中位数），用作「未解析偏差」的保守替代。
  六项已知偏差中只有 C 类可在本件量化扣除；**生态指标没有经批准的偏差传播系数**，
  故不另加生态偏差项——这是**披露的限制**，签门件必须原样写，不得把它写成「已校正」。
- 若 `B_J3 > 0.5 × median(N_end|OFF)` ⇒ 判定带过宽（underpowered）⇒ **INCONCLUSIVE** 且停手（§7.5）。
- 「偏差带吞主效应」在本件的操作化 = `|Δ̄| < B_J3`（`Δ̄` = 5 seed 配对均值）。

## 五、五类判据（阈值先于数据，跑后不得改）

### 5.1 S — 稳定性

| ID | 检查 | 阈值 | 时点 |
|---|---|---|---|
| **S1** | 非有限值 | 大气状态每步、出口场每交换、世界/生物每 tick 记录：**0 个 NaN/Inf** | 全 20 run + C0 |
| **S2** | 大气极值带 | `T ∈ [100, 400] K`；`ps ∈ [1e4, 2e5] Pa`；`|u|,|v| ≤ 250 m/s`；`q ∈ [0, 0.1] kg/kg`；`t2m ∈ [−150, 100] °C`；`precip ≥ 0` 且 `≤ 1e5 mm/yr` | 每步/每交换 |
| **S3** | CFL | 大气 `CFL ≤ 1.0` | 每步 |
| **S4** | 世界/生物极值 | `N ∈ [0, 100000]` 整数；`npp ≥ 0` 有限；`capacity ≥ 0`、`amount ≥ 0`；个体能量有限 | 每 tick |
| **S5** | 自旋含入 | 上述 S1–S3 覆盖 120 天自旋（18,000 步）+ 生产（3,125 步），共 **21,125 步/run** | 全 20 run |

**判定**：20/20 run 全部满足 ⇒ S PASS；任一违例 ⇒ S FAIL（停手，不得调参救）。

### 5.2 D — 确定性（沿用 CONS-DET 口径）

| ID | 检查 | 阈值 |
|---|---|---|
| **D1** | 同 seed、同臂、α/β 两遍独立重建后：逐 tick `N(s)` 整数列**完全相同**；`run_digest` 相同；终局 `resource.amount`/`capacity` sha256 相同；逐交换气候样本（tick/t2m/precip/u10/v10）**逐位相同**；大气 digest 序列**逐位相同**；生物出生/死亡/谱系计数相同 | 5/5 seed × 2 臂 = **10/10 (seed,臂) 对** |
| **D2** | 任一不同 | ⇒ D FAIL；报告首次分歧的 seed/臂/tick/字段；**不得**换 seed 重跑规避 |
| **D3** | C0 双跑 | 大气账本/digest 序列逐位相同；否则 C 类不可判 |

**判定**：D1 全过 ⇒ D PASS；否则 D FAIL。

### 5.3 C — 守恒（扣除已知偏差后判）

账本窗：自旋后 `t=0` 起的**第 2..3,125 次交换**（`flux_mode=:interval`；首快照为占位，
`flux_valid_from_snap=2`），覆盖 `(0, 20.827] 天`；能量用瞬时 canonical `sw_toa/lw_out` 同窗均值。

| ID | 读数 | 阈值 | 说明 |
|---|---|---|---|
| **C1-true** | `|dW_true − Σtaps| / ΣP`（裁负前水量；taps 不含 Clip） | **≤ 5e-5** | **D1 分解残差代理口径**，不是独立「真闭合」测量；20–22 天子窗实测 **1.289e-5–3.734e-5（5/5 >1e-5）**，5e-5 = 实测最大 ×1.34。**不得**写成「谱一致真值」；注册 120 天真闭合 3.28e-6 仅作参照。定义沿用台账 §45 |
| **C1-gate** | post-clip q 口径相对残差 | **≤ 2.0e-3** | 20–22 天子窗实测 **3.115e-5–1.485e-3**（4 个 20 天窗 6.425e-4–1.485e-3；22 天窗 3.115e-5；最大 1.485e-3）；2e-3 = 最大 ×1.35 = 注册值 1.079661e-3 ×1.85。窗长与残差**无单调关系**（实测 20 天窗可高于 90 天窗），一律按实测标定、不做线性外推；**不得**只报此列 |
| **C2** | `|ΔM| / M`（质量，Option 3 归一化） | **≤ 3e-5** | 质量漂移是**窗口最大漂移、非线性**，不做线性外推；20–22 天子窗实测 **5.340e-6–1.906e-5（3/5 >1e-5）**；3e-5 = 实测最大 ×1.57，仍低于注册 120 天 3.3834e-5 |
| **C3** | `resid = mean(net_toa) − 7.016983` | **`|resid| ≤ 5.0 W/m²`** | 沿用 J2 v1 的 ±5 W/m² 能力阈值；**不是**新阈值。**协议披露**见本节表后段落 |
| **C4** | 水/质量/能量读数与 C0 双跑一致 | 逐位 | C0 与在线 run 的大气 digest 序列须一致；否则停 |

> **C3 协议披露（写死，评审 §5.2）**：`B-TOA = +7.016983 W/m²` 是 **rev2 协议**（重启、dt=600、day30–120 后 50%）的登记值；
> J3 是 **dt_step=576、连续自旋后 20.83 天**。C3 **只是**「J3 窗是否复现登记偏差量级」的一致性检查，
> **不是**重新判 J2、**不是**「能量平衡达成」。实测旁证：20 天子窗 `net_toa` **5.418–7.807**，对 7.016983 的残差
> **−1.60…+0.79**，均在 ±5 内 ⇒ C3 **非空洞但宽松**，报告须原样披露，不得据此写「能量平衡」。

**判定**：C1-true/C1-gate/C2/C3/C4 全过 ⇒ C PASS；任一不过 ⇒ C FAIL（停手）。
**表述**：C PASS 只能写「扣除附件 A 登记偏差后，耦合窗账本在带内」，**不得**写「守恒通过」。

### 5.4 I — 耦合增量

| ID | 指标 | 定义 |
|---|---|---|
| **I1（主）** | `N_end` | 末 `W=500` tick（s=49,501…50,000）的 `N` 均值；每 run 一个值 |
| **I2（次）** | `B_end` | 同窗 `energy_sum` 均值（生物能量单位） |
| **I3（次）** | `NPP_end` | 同窗 `npp_land_mean` 均值（世界 NPP 单位） |

**配对与判定（先于数据）**：

1. 只用 **α 遍**做判读；β 只作 D1 确定性。α≠β ⇒ D FAIL，I 不判。
2. `Δ_s = N_end(ON,s,α) − N_end(OFF,s,α)`，s=42…46；`Δ̄ = mean(Δ_s)`；
   `SE = sd(Δ_s, ddof=1)/√5`；`B_J3 = max(2SE, 0.05×median(N_end|OFF,α,42…46))`。
3. **I PASS（检出增量）** ⇔ `|Δ̄| ≥ B_J3` **且** ≥4/5 个 `Δ_s` 与 `Δ̄` 同号。
4. **I INCONCLUSIVE** ⇔ `|Δ̄| < B_J3`；或 3/5 及以下同号（均值被单 seed 驱动）。
5. **I 不设 FAIL**：无增量 ≠ 失败；只判「检出/未检出」。
6. **删失检查**：任一 run 的 `N_end ≥ 0.99×max_pop` ⇒ 主指标被上限删失 ⇒ **INCONCLUSIVE**（停手）。
7. 报告：`Δ̄`、`Δ̄ ± 2SE`、`Δ_s` 逐 seed、效应量 `Δ̄ / median(N_end|OFF)`、`B_J3` 分解。
8. I2/I3 只报告，不作 PASS/FAIL；不得事后把 I2/I3 换成主指标。

### 5.5 E — 生态前置门（R3/R6）

| ID | 检查 | 阈值 |
|---|---|---|
| **E1** | 每臂存活 | **≥3/5 seed** 满足 `N(s) ≥ 1` 对**所有** `s ∈ [1, 50,000]`（即 `N>0` 持续 50k tick；目标 tick 仍存活） |
| **E2** | 任一臂 E1 失败 | ⇒ **INCONCLUSIVE-E**：生态类不下任何正/负结论；S/D/C 可照报；停手报 owner |
| **E3** | 两臂都过 E1 | ⇒ 才允许做 I 类判读 |
| **E4** | g15 | J3 **不读** g15；R3/R6 原文的 g15 前置门在本件按同一逻辑施加到 I1 主指标 |
| **E5** | 存活曲线 | 无论门是否通过，逐 seed 报 `first_zero_tick`、`min_alive`、峰值、终局 |

**表述**：E2 触发时，报告只能写「生态前置门未过，未判读增量」，**不得**写「耦合有害/有益」。

## 七、停手规则（预注册，不得事后改）

1. **P0 未过**（§8 任一前置）⇒ **NOT-RUN**；停手报 owner；不得用占位数据/临时核/改 dt 绕过。
2. **S/D/C 任一 FAIL** ⇒ 停手；只许修引入非确定性的**代码 bug**（写 commit 与原因），修后**全量重跑**；
   不得改阈值/窗口/种子/指标。若修复改变装置语义 ⇒ 新预注册。
3. **E2（任一臂生态门未过）** ⇒ 停手报 owner；生态增量**不判**；不得写正/负结论；
   不得换 `init_pop`/seed/资源参数重跑（那是改装置）。
4. **第一次 INCONCLUSIVE-I** ⇒ 停手报 owner，附 `B_J3` 分解与逐 seed `Δ_s`。
   同一装置重复跑**不算第二次 attempt**（确定性会复现同一读数）。
   第二次 attempt 必须是**新预注册（attempt-2，另立文件名；不得以本件 rev bump 代替）**，且只许预注册**一个**变更（提高耦合强度 / 延长积分 /
   改变聚合窗，三选一，先于数据写死）；attempt-2 仍 INCONCLUSIVE ⇒ **永久停手**报 owner，

5. **判定带过宽**（`B_J3 > 0.5×median(N_end|OFF)`）⇒ INCONCLUSIVE + 停手；不得以「带太宽」为由改阈值。
