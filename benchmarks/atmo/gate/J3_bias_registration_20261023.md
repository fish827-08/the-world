## 一、原则（四条）

1. **J2 = FAIL 不追溯、不改判、不降阈值**；本件不构成 J2 PASS，也不得被引用为「J2 已通过」。
2. **J3 放行条件 = J2 已知偏差登记入册 + 协变量记录**，不是 J2 全绿。
3. **J3 结论的表述上限**：只能声称「在登记偏差下的相对效应 / 耦合增量」；
   不得声称真实地球气候、不得声称超出 L0–L4 阶梯的涌现。
4. **偏差带优先于主效应**：若 J3 观测增量落在偏差带内 ⇒ 判 **INCONCLUSIVE**，不得判 PASS。

## 三、J3 判据框架（只判耦合，不判气候）

J3 预注册须在跑任何耦合实验**之前**固定下列五类，A3 起草、评审冻：

1. **稳定性**：连续 N 天无 NaN、无发散、极值在预注册带内（N 与带由 J3 预注册钉死）。
2. **确定性**：同 seed 双跑逐位（沿用 CONS-DET 口径）。
3. **守恒**：耦合系统自身账本闭合；大气侧按 B-TOA / B-WATER / B-MASS 作为**已知偏置扣除后**判。
4. **耦合增量**：生物/生态指标 vs「同配置、无耦合」基线的差；必须给误差带。
   - `|增量| < 偏差带` ⇒ **INCONCLUSIVE**（不是 PASS，也不是 FAIL）。
5. **生态前置门（R3/R6）**：g15 任何判读前须过生态门（≥5 seed 多数存活至目标 tick、N>0 持续 50k tick）；
   未过 ⇒ 不得下正/负结论。

**禁用**：为让结果好看而新增/放宽阈值；事后挑窗口；把 INCONCLUSIVE 写成 PASS。
